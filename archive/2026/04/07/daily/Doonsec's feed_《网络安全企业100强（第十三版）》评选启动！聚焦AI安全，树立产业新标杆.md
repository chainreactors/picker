随着人工智能技术深度重构网络安全产业格局，AI安全能力己成为衡量企业核心竞争力的重要标尺。即日起，安全牛正式启动《网络安全企业100强（第十三版）》评选工作，本次评选将AI安全能力作为重要评估指标，同时升级优化传统评价体系、创新申报模式，旨在发掘兼具硬核技术、落地实效与创新引领力的网络安全企业，重点凸显企业在AI安全领域的核心优势，为行业提供专业精准的选型参考，推动网络安全产业向AI原生、智能防御的高质量发展阶段迈进。

作为安全牛深耕十二载的权威评选，本次第十三版网络安全企业100强评选立足产业AI新变局，旨在发掘兼具综合实力与AI安全核心优势的产业新标杆。

**一、本次评选核心亮点：锚定AI安全，多维考评更专业、更落地**

本次评选围绕AI安全创新升级，在全维度考评企业综合竞争力的基础上，重点聚焦AI安全能力评估，让评选更贴合产业发展实际，更具行业参考价值：

1. **核心聚焦AI安全：**将AI安全作为重要评估方向，既全面考评企业综合实力，又精准挖掘企业在AI安全领域的技术积累、产品落地和前沿探索能力；
2. **直击价值痛点为多方赋能：**帮安全企业明晰AI安全赛道发展方向，为金融、能源、政务等甲方用户提供AI安全与综合安全建设等多重选型需求，引导产业资源向AI安全核心赛道和优质企业集聚，推动AI安全与传统安全技术深度融合、场景落地；
3. **拒绝概念化申报：**所有申报指标均需提供真实佐证材料，AI安全相关指标为审核重点，通过材料核验、实地走访等多种方式，确保评选结果真实反映企业实际实力；
4. **挖掘AI原生细分赛道标杆：**界定AI原生安全企业标准，对这类企业专项标注、重点考评，同时设置突破性成就加分，表彰在AI安全领域具备全国乃至全球影响力的企业，树立细分赛道与综合领域双重标杆；
5. **申报模式全程线上更高效：**摒弃传统Excel填报模式，启用专属线上网络申报通道，实现申报、材料提交、数据审核全流程数字化，大幅提升企业申报效率，保障数据规范性。

**二、指标设置核心要点：核心突出+多维兼顾**

本次评选总基础分100分，另设最高10分突破性成就加分，最终得分上限110分。

五大评价维度科学分配权重、精准设计指标，其中AI安全能力表现为独立一级维度，独占25%评分权重，是本次评选的重要评分模块，指标设置重点突出、贴合实战。

|  |  |  |  |
| --- | --- | --- | --- |
| **一级维度** | **分值** | **核心特点** | **二级核心指标** |
| 核心技术实力 | 30分 | 融入AI安全技术布局，重技术落地与积累 | 技术布局（含AIGC安全治理等）、产品成熟度、研发投入、发明专利、权威认证等 |
| AI安全能力表现 | 25分 | 重要核心维度，全链路考评AI安全能力 | AI驱动安全实现、AIGC检测覆盖、AI 模型防控、自研算法 / 数据集、产品落地、前沿探索、标准制定等 |
| 市场与行业渗透力 | 25分 | 关键行业落地，兼顾综合市场实力 | 营收规模与增长、关键行业覆盖、市占率优势、典型客户影响力等 |
| 可持续发展基础 | 15分 | 关注安全研发团队，考评企业长期发展潜力 | 财务健康、研发团队稳定性、三年技术路线、生态合作、数据合规等 |
| 合规与社会责任 | 5分 | 坚守经营与AI安全合规底线 | 近三年重大负面事件处理情况等 |
| 突破性成就加分项（非必填） | 最高10分 | 重点聚焦AI安全，兼顾行业重大成果 | 国家级项目、国际奖项、国际标准、核心技术出口等 |

第十三版网络安全企业100强评选核心指标体系

**三、全程线上网络申报，要求佐证材料**

本次评选首次启用线上网络申报通道，实现申报全流程数字化，操作更便捷、数据更规范，同时要求上传佐证材料。

申报对象：国内合法经营的网络安全技术、解决方案及服务提供商，包括综合型领军企业、垂直领域专家型企业、符合标准的AI原生安全企业、量子安全/零信任等创新赛道探索者，凡具备网络安全综合实力，且有AI安全相关技术积累或产品落地能力的企业，均可参与申报。

**四、评选预期：以综合实力为基础，选出AI安全与综合能力双优的标杆企业**

本次评选始终坚守“以实力评企业、以落地树标杆、以专业促发展”的初心，所有评审流程、打分标准，均围绕“综合竞争力为基础，AI安全能力为重要核心”设计，最终要选出符合评选定位、兼具综合硬实力与AI安全核心优势的100强企业及专项标杆，让评选结果成为行业发展的“风向标”：

1. **分级定档，划分企业层级：**按综合得分将入围企业划分为卓越级（≥90分）、领先级（75-89分）、培育级（60-74分），精准反映企业在网络安全行业的综合层级，同时标注各企业AI安全能力等级，为行业提供双重参考；
2. **专项标注，发掘多类型标杆企业：**在100强榜单基础上，专项公布AI安全细分榜单，同时保留综合型领军、垂直领域专家等特色标注，既发掘AI安全赛道标杆，又树立综合领域榜样；
3. **分析报告输出，全方位赋能产业发展：**同步发布《2025-2026网络安全产业发展核心洞察》报告，既分析AI安全赛道的技术创新与场景落地情况，又梳理网络安全产业整体发展脉络，为全行业提供专业、全面的发展参考；
4. **成果落地，为多方提供决策依据：**评选结果将成为行业用户AI安全选型与综合安全建设、产业资本赛道布局与企业投资、政府部门产业引导与政策制定、企业自身发展规划与战略调整的重要依据，真正实现评选价值落地。

**五、全程专业保障：公正公开、免费参与、严格保密**

为确保评选结果的权威性与公信力，本次评选提供全流程专业保障，让每一家参评企业都能公平、公正参与：

1. **全程免费参与，无任何附加费用：**本次评选不向申报企业收取任何报名、评审、材料审核、榜单发布等费用，所有参评企业均按统一标准考核，确保评选的纯粹性；
2. **信息严格保密，保障企业权益：**线上申报通道专属加密管理，专人负责企业申报信息与材料管理，对AI模型技术文档、核心商业数据、客户合同、审计报告等所有材料严格保密，可按企业要求签订正式数据保密协议；
3. **多维度核验数据，杜绝虚假申报：**通过现场材料抽查、公开数据检索、实地企业走访、电话核实等多种方式，对企业申报的AI安全能力、产品落地、营收数据等进行全面核验，确保评选结果真实客观。

**六、评选整体流程：全线上推进**

|  |  |  |
| --- | --- | --- |
| **阶段** | **时间规划** | **核心工作内容** |
| 1.申报启动 | 即日起 | 正式开启线上专属网络申报通道。 |
| 2.企业申报与材料上传 | 申报启动日起至4月30日 | 企业在线填报申报表，按要求上传相关佐证材料；审核材料完整性，对必填项进行重点核验，对材料不全或不准确企业进行补充提醒。 |
| 3.专业评审与数据核验 | 材料收集截止后15个工作日（5月下旬） | 精细化打分；对存疑数据进行多维度核验，对AI安全等能力突出的重点企业进行实地走访验证。 |
| 4.入围复审与榜单核定 | 专业评审结束后10个工作日（6月初） | 汇总各指标得分计算综合成绩，按标准分级；对入围企业进行整体复审，重点复核AI安全等重点指标评分与佐证材料；核定100强榜单及各专项标杆名单。 |
| 5.评选成果正式发布 | 榜单核定后5个工作日内（6月中旬） | 正式发布100强榜单、AI安全等各专项标杆名单。 |
| 6.产业发展报告发布 | 榜单发布后15个工作日内（7月初） | 发布《2025-2026网络安全产业发展核心洞察》报告。 |
