— AI + 安全，正在GitHub上掀起一波开源浪潮

几千人点星的项目，半年冒出来十几个

最近安全圈在传一份榜单。

GitHub上，一批“AI黑客工具”星数疯涨。几千人点星的项目，半年内冒出来十几个。

它们干的事出奇一致：把渗透测试里那些重复、繁琐、要经验的活儿，交给AI大模型去干。

我把这份流传的榜单整理了出来，TOP10逐个讲给你听。全部开源、全部免费。

先说红线：以下工具只能用于自己搭建的靶场和SRC平台授权范围内的目标。对未授权系统测试，违反《网络安全法》，后果自负。

工具是刀，用在哪，决定你是白帽子还是罪犯

PART

第一梯队：AI渗透智能体

TIER 1 · 3000★ 以上

TOOL 01

#### Strix

**4,017★**

榜单第一名。AI自主渗透智能体，你给它一个目标地址，它自己规划测试路径、发现漏洞，还会实际验证这个漏洞是不是真存在，末了再出一份报告。相当于把一个初级渗透工程师装进了代码里。

TOOL 02

#### Shannon

**3,690★**

同样走自主渗透路线，特点是端到端：从信息收集到漏洞验证一条龙，中间不需要人插手。和Strix并称**“AI渗透双子星”**。

TOOL 03

#### Claude-Red

**3,011★**

基于Claude大模型的红队自动化框架。把红队常用的攻击思路和技战术写进了提示词工程，让大模型按红队工程师的方式思考。

TOOL 04

#### Claude-OSINT

**2,479★**

开源情报（OSINT）收集自动化。挖SRC的第一步永远是信息收集：子域名、资产、指纹、泄露信息，以前手动查一天，它帮你压缩到一杯咖啡的时间。

PART

第二梯队：垂直场景利器

TIER 2 · 200-900★

TOOL 05

#### Shock

**819★**

轻量级AI漏洞扫描Agent。胜在小巧，配置要求低，新手第一台电脑就能跑。

TOOL 06

#### SRC挖洞助手

专攻国内SRC场景的宝藏工具，自动生成符合补天、漏洞盒子格式的漏洞报告。多少人漏洞挖出来了，报告写得一塌糊涂被打回，它就是治这个的。

TOOL 07

#### communityTools

**498★**

安全社区工具集合导航。相当于一个“工具的工具”，按场景帮你找到该用的那一款。

TOOL 08

#### bountyscope

**406★**

赏金目标资产梳理。批量整理各大SRC平台的悬赏范围和资产清单，帮你快速判断“这个目标值不值得打”。

TOOL 09

#### Black-cat

**304★**

黑猫，信息收集加Web指纹识别二合一。名字凶，干的活其实是最基础的侦察。

TOOL 10

#### public-battle-builder

**225★**

公开靶场环境一键搭建工具。前面说了“只能在靶场练”，它就是帮你把靶场搭起来的那个。榜单收尾，实至名归。

注：榜单整理自社区分享，星数为统计时点数据。开源项目更新频繁，具体功能与星数请以GitHub实时页面为准。
