## Summary

* Port gcc.c-torture compile cases into `test/compile/`, with `SKIPPED.txt` for preprocessor, nested functions, GNU VLS, DFP, `va_arg_pack`, and C99-incompatible GNU89 tests (implicit decls, return mismatch, falling off `main`).
* Tighten sema to C99: undeclared calls are errors, `return` must match the function type, and non-void `main` must return a value.
* Fold `sizeof` of named objects only after type-check so `T a[sizeof g / sizeof *g]` gets the real length (fixes `builtin_memmove` / `memmove_chk` crashes). `__builtin_memmove` now returns `void*`.
