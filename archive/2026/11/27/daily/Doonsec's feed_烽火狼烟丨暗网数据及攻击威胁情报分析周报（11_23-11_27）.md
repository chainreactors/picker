**01.**

**重点数据泄露事件**

**美国Todoist生产系统数据疑似泄露**

泄露时间：2026-11-23

泄露内容：Todoist是美国Doist公司推出的任务管理与待办事项应用，全球用户超过5000万。该公司披露，攻击者利用窃取的版本控制系统凭据进入其生产环境，下载了约6%用户的邮箱地址、旧版SHA1口令散列与账户创建日期，并获取少量用户的API令牌、Slack集成令牌以及部分任务、评论中出现凭据的内容。

泄露数据量：未涉及

关联行业：软件服务

地区：美国

**英国盖特威克机场落客缴费系统数据疑似泄露**

泄露时间：2026-11-24

泄露内容：盖特威克机场是英国伦敦的主要国际机场之一。据报道，落客区的AutoPay自动缴费系统遭未授权访问，客户姓名、联系方式、住址与邮箱、车牌号、落客地点与进出时间、支付记录及部分卡信息可能外泄。机场已第一时间暂停该系统，向英国信息专员办公室报告并通知受影响客户，航班与停车场运行未受影响，调查仍在进行。

泄露数据量：未涉及

关联行业：交通

地区：英国

**比利时法兰德斯82个市镇居民数据疑似泄露**

泄露时间：2026-11-25

泄露内容：法兰德斯是比利时北部的一个大区。据披露，一家为当地回收公园提供数据存储服务的中央服务器遭入侵，约120万名居民与工作人员的姓名、地址、出生日期、性别、国家登记号、身份证号与IBAN银行账号被窃取，部分市镇还涉及车牌信息。分析显示，部分市镇的数据已在暗网出售。

泄露数据量：约120万

关联行业：政府

地区：比利时

**国际足联内部数据疑似泄露**

泄露时间：2026-11-25

泄露内容：国际足联（FIFA）是总部位于瑞士苏黎世的国际足球联合会，负责组织世界杯等国际赛事。该组织系统遭未授权访问，被窃取的是个人与业务信息。此前一个黑客组织声称从FIFA的微软环境窃取超过12GB数据，并在勒索未果后将数据公开，内容据称涉及身份与出入境文件、财务记录、法律文件与治理信息。FIFA表示正配合执法机构调查，未披露受影响人数。

泄露数据量：未涉及

关联行业：体育

地区：瑞士

**日本福岛县就业咨询窗口邮箱账户数据疑似泄露**

泄露时间：2026-11-25

泄露内容：福岛县是日本东北地区的一级行政区。该县披露，其设立的福岛故乡就业信息中心咨询窗口所委托运营方的电子邮箱账户遭第三方未授权访问，可能外泄约0.2万名咨询者的姓名、联系方式与咨询内容等信息。县政府已停止相关邮箱使用、要求运营方加强访问控制，并开始通知可能受影响的咨询者，同时就事件原因与影响范围展开调查。

泄露数据量：约0.2万

关联行业：政府

地区：日本

**02.**

**热点资讯**

**美国财政部金融犯罪执法局遭网络入侵下线部分系统**

美国财政部金融犯罪执法局（FinCEN）披露遭遇网络安全事件，其部分系统出现未授权访问。该局负责收集银行等金融机构提交的可疑活动报告及银行保密法申报，事发后已将部分系统下线作为预防措施，银行保密法电子申报网站仍可访问，但部分服务暂时不可用。该局未说明被访问及下线的具体系统，也未说明是否造成数据泄露或由何方所为，暂未发现组织宣称负责。为缓解影响，该局延长了受影响申报方的提交期限，其他银行保密法义务仍然有效。

消息来源：

https://thehackernews.com/2026/11/us-treasurys-fincen-takes-some-systems.html

**Electrolux智能热水器被曝向境外云平台回传数据**

一名乌克兰用户发现其购买的Electrolux EWH 80智能热水器持续向域名mqtt.cloud.rusklimat.ru发起连接，该域名经查询解析到Yandex Cloud。该品牌为瑞典所有，产品页面未提示与境外云服务的关联。设备通过MQTT遥测上报温度、能耗与开关状态等数据，可反映家庭作息与使用习惯。该用户已将设备断网，并表示更换设备存在困难。研究人员指出，物联网设备即使看似普通，也可能在用户不知情的情况下将家庭数据传输至第三方服务器。

消息来源：

https://cybernews.com/security/electrolux-smart-water-heater-russian-cloud-connection/

**黑客入侵24台Check Point管理服务器**

安全研究机构披露，攻击者使用AI驱动的攻击工具针对Check Point安全管理服务器发起攻击，至少24台服务器被入侵，涉及22家机构，覆盖金融、能源、政府、交通、制造等行业。攻击者动用约99个IP地址完成扫描、利用与控制，多数IP来自一次性网络基础设施，并借助自动化扫描与利用流水线先攻陷一台文件服务器作为中转据点，再窃取防火墙数据库与内部证书颁发机构文件、签发新证书、卸载安全策略。攻击者还使用Nmap、Chisel、Impacket等工具进行内网侦察与横向移动。

消息来源：

https://thehackernews.com/2026/11/hackers-compromise-24-check-point.html

**印度银行业务系统遭AI辅助攻击造成未授权交易**

印度计算机应急响应小组发布警示称，攻击者正利用AI辅助手段对该国信息通信技术资产发动攻击，已导致银行、金融服务机构以及为政府相关支付提供支持的技术服务商发生未授权金融交易。攻击者并未直接攻击支付接口，而是滥用业务应用与服务商工作流，修改业务记录或审批关系，再借合法支付流程完成交易，从而规避告警。该机构同时发现AI驱动的智能体攻击框架被用于自动化侦察、快速生成漏洞利用、并行入侵及按目标反馈调整攻击脚本。

消息来源：

https://thehackernews.com/2026/11/ai-assisted-cyberattacks-trigger.html

**攻击者通过假冒GTA 6客户端投放窃密木马**

安全研究人员披露，攻击者借助游戏GTA 6的热度搭建假冒网站，宣称提供可在主机上通过网络串流方式运行该游戏的Windows客户端，诱使访客通过ClickFix手法在运行对话框中粘贴并执行PowerShell命令。该命令会绕过执行策略，从恶意站点下载脚本并运行，最终安装窃密木马，可窃取浏览器保存的密码、Cookie、访问令牌、API密钥、屏幕截图和加密货币钱包数据。由于Rockstar尚未推出官方PC版本，此类假冒客户端更易取得玩家信任。

消息来源：

https://cybernews.com/security/hackers-gta-vi-info-stealing-malware/

**03.**

**热点技术**

**网络间谍组织借助IPFS后门攻击电信与航空目标**

安全研究人员披露一个此前未被记录的网络间谍组织，主要针对塞浦路斯的电信企业、航空公司和关键基础设施。该组织使用名为KuboShell的后门，将命令与控制流量隐藏在星际文件系统IPFS网络中，并部署Homa后渗透框架，后者是黑客组织MuddyC2Go的重实现。攻击链借助AI生成的虚假简历人设，诱骗目标点击链接下载所谓完整简历，从而在系统中植入后门；同时投递MeshCentral与NetLock RMM等合法远程管理工具维持访问。

消息来源：

https://thehackernews.com/2026/11/iran-aligned-volant-manticore-uses-ipfs.html

**黑客组织伪装SoftEther VPN建立隐蔽远程访问通道**

安全研究人员发现，某黑客组织疑似使用开源SoftEther VPN Bridge的自定义版本建立隐蔽远程访问。该变体被重命名为NtMonitor VPN，冒充某公司的网络监控软件，并替换了多个原有HTTP端点，使流量看起来像普通Web应用请求，同时修改注册表与文件特征以清除可识别的检测指纹。样本仍保留部分原始路径信息，说明其只对外部交互进行伪装。该工具可在受害网络与攻击者基础设施之间建立隧道，为后续横向移动和数据窃取提供稳定通道。

消息来源：

https://thehackernews.com/2026/11/webworm-suspected-of-modifying.html

**Roblox作弊工具被用于投递窃密恶意软件**

安全研究机构分析近年Roblox作弊工具相关搜索量发现，Roblox作弊工具的搜索量超过了2200万次，占所研究游戏作弊搜索总量的一半以上。攻击者借助玩家尤其是未成年人对免费作弊工具的需求，通过视频平台、搜索引擎和聊天群组分发作弊程序，实际投放的是可窃取密码、银行登录信息、Discord令牌与摄像头画面的恶意软件。研究指出，儿童往往忽视下载此类工具时的安全警告，且部分恶意程序会要求管理员权限，导致进一步扩大影响范围。

消息来源：

https://cybernews.com/security/roblox-fake-cheats-malware-risk/

**ScreenConnect漏洞遭利用来劫持MSP技术人员主机**

安全研究人员披露，攻击者正利用ConnectWise ScreenConnect一个已修复的严重客户端漏洞攻击托管服务提供商服务器。该漏洞允许访客身份向正在连接的技术人员主机传输并执行恶意载荷。监测显示，攻击者盲目扫描服务器并发送大量运行文件请求，某服务商技术人员工作站被植入批处理脚本后，脚本解码Telegram机器人令牌并上报，随后下载伪装成Windows更新的安装包，启动指向攻击者中继的恶意ScreenConnect客户端，整个过程约9秒。攻击者借此获得对技术人员主机的远程访问权限。

消息来源：

https://thehackernews.com/2026/11/hackers-exploit-critical-screenconnect.html

**语音钓鱼团伙INCEPTION通过窃取凭据实施数据勒索**

某厂商披露，此前被评估为与ShinyHunters勒索团伙关联的威胁集群O-UNC-053可能已更名，并以INCEPTION名义继续活动。该集群通过语音钓鱼诱骗目标在钓鱼页面输入凭据并批准多因素认证，其钓鱼套件可拦截认证流程、窃取凭据与验证码，但无法绕过通行密钥和Okta FastPass等抗钓鱼方式。得手后攻击者访问SaaS应用并窃取敏感数据，再以在泄露站点公开相威胁实施勒索。该组织近期注册的域名多带有legal字样。

消息来源：

https://thehackernews.com/2026/11/okta-links-shinyhunters-associated.html

**04.**

**热点漏洞**

**OTRS SQL注入漏洞（CVE-2026-93584）**

OTRS是一款开源的工单与客户服务管理平台。在2024.3.1至2026.8.1版本中，其Survey接口的RequestGet()方法将攻击者可控的调查键直接拼入SQL查询，未使用参数化语句。未认证远程攻击者可注入任意SQL表达式，无需有效调查键或已存在的调查请求，即可读取工单信息，并通过布尔或时间盲注提取数据库账号可访问的敏感数据，利用前提是外部前端可被访问。

影响版本：OTRS >= 2024.3.1，OTRS <= 2026.8.1

**Kerberos Agent认证绕过漏洞（CVE-2026-135208）**

Kerberos Agent是Kerberos.io提供的开源视频监控代理。在3.14.4之前版本中，鉴权中间件在密钥缺失时会回退到硬编码密钥TOBECHANGED，未认证攻击者可用该密钥签署携带任意用户名与角色声明的HS256令牌，绕过认证访问/api与/config路由，获取RTSP、ONVIF、Hub及加密密钥，修改配置并停止摄像头。

影响版本：Kerberos Agent < 3.14.4

**Xen Orchestra认证绕过漏洞（CVE-2026-133469）**

Xen Orchestra是用于管理、备份与委派XCP-ng及XenServer虚拟化基础设施的平台。在6.9.2与6.10.1之前版本中，REST接口的Cookie解析会把authenticationToken=j:%7B%7D解析为空对象，令牌提供程序将空对象视为未过滤查询并返回首个未过期令牌，从而以该令牌属主身份通过认证；随后/users/me/authentication\_tokens路由会返回可复用的登录令牌。该漏洞已在野利用。

影响版本：Xen Orchestra < 6.9.2，Xen Orchestra >= 6.10.0，Xen Orchestra < 6.10.1

**Wing FTP Server会话劫持漏洞（CVE-2026-135171）**

Wing FTP Server是一款跨平台FTP服务器。在8.2.8之前版本中，管理员会话标识由进程、时间、ServerID与客户端IP等可预测状态派生，未认证攻击者可借助service\_get\_license.html端点作为有效性预言机枚举候选标识，并重放活动会话，获得包括Lua控制台在内的管理权限。

影响版本：Wing FTP Server < 8.2.8

**WeKan越权访问漏洞（CVE-2026-136623）**

WeKan是一款开源看板式任务管理应用，支持多用户协作和看板导出。WeKan存在越权访问漏洞。该漏洞产生的原因是Exporter.buildCsvStream()忽略了禁止导出和匿名化导出的用户设置。攻击者可利用该漏洞，看板阅读者或公开看板的未认证用户可调用CSV导出端点导出全部卡片，并泄露成员、指派人和提及字段中的真实用户名。

影响版本：WeKan <12.78
