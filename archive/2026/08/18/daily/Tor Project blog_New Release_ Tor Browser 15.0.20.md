# New Release: Tor Browser 15.0.20

by [ma1](/author/ma1)
| August 18, 2026

![](/new-release-tor-browser-15020/lead.png)

Tor Browser 15.0.20 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.20/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.19 is:

* All Platforms
  + [Bug tor-browser#45204](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45204): Rebase Tor Browser stable onto 140.14.0esr
  + [Bug tor-browser#45219](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45219): Backport Security Fixes from Firefox 154
* Windows + macOS + Linux
  + Updated Firefox to 140.14.0esr
* Android
  + Updated GeckoView to 140.14.0esr
* Build System
  + All Platforms
    - [Bug tor-browser-build#41839](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41839): Backport tor-browser-build-browser#41831: Update libevent to 2.1.13
    - [Bug tor-browser-build#41850](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41850): Update keyring/torbrowser.gpg for new subkey and updated expiration date of the main key
  + Windows + Linux + Android
    - Updated Go to 1.25.13
