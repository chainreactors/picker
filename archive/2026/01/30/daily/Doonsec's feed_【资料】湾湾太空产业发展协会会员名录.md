这份文件是由台湾太空产业发展协会（TSIDA）与台湾太空中心（TASA）共同发布，是一份2025年度会员厂商目录与产业能力报告。以下为其内容结构与重点解读：

一、文件结构与组成

|  |  |
| --- | --- |
| 模块 | 内容说明 |
| 封面与前言 | 明确由TSIDA与TASA共同发布，理事长为吴宗信（TASA主任兼任TSIDA理事长）。 |
| 产业总览 | 概述台湾太空产业2024年发展成果，涵盖卫星制造、地面设备、卫星服务、发射载具四大领域。 |
| TASA介绍 | 详述台湾太空中心（TASA）的组织转型、历史任务（FORMOSAT系列）、未来计划（如FORMOSAT-8/9、B5G低轨卫星、发射场选址）。 |
| 会员厂商目录 | 按九大专业领域分类，列出102家机构会员与19位个人会员，提供每家公司简介、产品亮点、联系方式。 |
| 附录与索引 | 提供厂商分类索引、联系方式、出版信息。 |

 二、产业总览重点（2024年成果）

|  |  |
| --- | --- |
| 领域 | 关键数据与趋势 |
| 卫星制造 | 北部为卫星结构/载荷制造中心，桃园增长最快；台中、高雄亦有贡献。 |
| 地面设备 | 占台湾太空产业88.9%，全球市占率2.8%，强项为导航芯片、射频模块、网络设备。 |
| 卫星服务 | 新兴业者加入，卫星通信成主力，卫星电视广播衰退43%；服务聚落集中于台北/新北，延伸至宜兰。 |
| 发射载具 | 政府主导，吸引复合材料、精密制造厂商投入火箭研发与制造。 |

三、TASA（台湾太空中心）角色与计划

|  |  |
| --- | --- |
| 项目 | 内容 |
| 组织转型 | 2023年改制为行政法人，隶属国家科学及技术委员会（NSTC）。 |
| 历史任务 | 自主研发FORMOSAT-17、Triton气象卫星，建立完整卫星开发能力。 |
| 未来计划 | ✅FORMOSAT-8（光学遥测 constellation）✅FORMOSAT-9（SAR雷达卫星）✅B5G低轨通信卫星实验✅小型发射载具✅国家发射场选址与建设 |

四、九大专业领域与代表厂商（部分）

|  |  |  |
| --- | --- | --- |
| 领域 | 代表厂商 | 亮点产品/服务 |
| 测试与设备 | iST（宜特）、Keysight、Rohde & Schwarz | 太空环境测试、辐射测试、卫星EMC/热真空/振动测试 |
| 系统整合 | Compal（仁宝）、Chunghwa Telecom、PEGATRON 5G NTN | 卫星终端、卫星通信系统整合 |

| 保险与安全 | 暂无具体厂商列出 | 提及需发展太空保险机制 |

五、TSIDA协会角色与目标

|  |  |
| --- | --- |
| 功能 | 说明 |
| 成立背景 | 2019年由TASA倡议成立，非营利组织，推动台湾太空产业发展。 |
| 会员结构 | 截至2025年1月，共102家机构会员、19位个人会员。 |
| 主要任务 | ✅搭建产学研合作平台✅举办TASTI（台湾太空国际年会）✅推动国际拓商与跨国产学合作✅协助台湾打入全球太空供应链 |

六、结论与观察

台湾太空产业已具备：

完整供应链：从卫星制造、地面设备、发射服务到应用服务。

国际竞争力：地面设备全球市占2.8%，RF、天线、复材、测试具出口实力。

政策支持：TASA主导国家计划，TSIDA整合民间资源。

新兴能量：CubeSat、LEO通信、SAR、相控阵天线、太空环境测试等快速崛起。

未来挑战：

发射能量不足：尚无可用的国家发射场，依赖国外发射。

太空法制缺位：缺乏国家层级的太空法案与监管框架。

保险与资本机制待建：太空保险、创投、融资机制尚未成熟。
