**网络安全动态 — Cyber Daily**

2026.11.02

国家互联网应急中心提示关于新型僵尸网络VeilDHT大范围传播的风险

关键词：VeilDHT僵尸网络

2026年10月30日报道。国家互联网应急中心监测发现新型僵尸网络VeilDHT大范围传播，主要感染Linux服务器与IoT设备，累计感染超4万台。该木马具备DDoS攻击、远程控制、反向代理等完整功能，建议用户及时修复漏洞、强化口令、监测相关IoC并隔离受感染设备。

Source:https://mp.weixin.qq.com/s/nYrmahLRnWBgZJdCZ3z8lQ

LXD 和 MicroCloud 漏洞允许攻击者在无私钥情况下冒充可信客户端

关键词：证书伪造    权限提示

2026年11月01日报道。Canonical 的 LXD 和 MicroCloud 存在严重漏洞CVE-2026-112816（CVSS 10.0）。攻击者获取可信客户端的公钥证书并具备网络访问HTTPS API权限，即可冒充该客户端，获得虚拟机访问权限，甚至提升至宿主机root权限。

Source：https://thehackernews.com/2026/11/critical-lxd-and-microcloud-flaw-cvss.html

某云应用托管平台安全漏洞导致客户 AI API 密钥遭滥用

关键词：API密钥

2026年10月31日报道。某云应用托管平台遭遇安全事件，攻击者解密并窃取客户环境变量中的敏感凭据，导致多个客户的 AI API 密钥被未经授权使用。

Source:https://www.bleepingcomputer.com/news/security/northflank-security-breach-leads-to-abuse-of-customers-ai-api-keys/

共享的 ChatGPT 链接可在会话中运行攻击者代码并读取私密聊天

关键词：跨域攻击    沙箱逃逸

2026年10月31日报道。安全公司发现ChatGPT共享链接存在严重漏洞，攻击者可构造恶意链接，诱使用户点击Preview按钮后，在其已登录会话中执行任意代码，读取未共享的私密对话。

Source:https://thehackernews.com/2026/10/a-shared-chatgpt-link-could-run.html
