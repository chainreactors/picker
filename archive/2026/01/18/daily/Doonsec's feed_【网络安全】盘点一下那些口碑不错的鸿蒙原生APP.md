# 1.ClashBox

Clash Box是一款专为华为鸿蒙系统（HarmonyOS NEXT）打造的原生网络代理应用程序，采用先进的 ArkTS 语言与 ArkUI 框架进行开发，充分发挥了鸿蒙系统的技术特性，为用户带来流畅、稳定且易用的代理体验。作为 HarmonyOS NEXT 首款代理软件，Clash Box 支持 Vmess、Shadowsocks 等多种主流代理协议，具备出色的兼容性与连接稳定性，能够满足用户科学上网与网络调试的多元化需求。

在功能设计上，Clash Box 提供了完善的网络管理工具，包括实时网络速率监控、流量统计、分流模式切换（规则模式、全局模式、直连模式）以及节点管理等核心功能。软件还支持多端智能适配，针对平板、折叠屏甚至 PuraX 等不同设备进行了专属 UI 优化，并完美支持深色与浅色模式切换，确保在各类设备上都能呈现出色的视觉效果。此外，应用还提供访问控制功能，允许用户灵活设置黑白名单，精细化管理特定应用程序的代理行为。

Clash Box 的界面设计采用现代简约的卡片式布局，以蓝色为主色调，搭配独特的蓝色猫咪头像品牌标识，不仅功能强大，更兼具时尚美感。软件持续迭代更新，不断优化用户体验，是鸿蒙用户进行网络代理操作的理想选择。

# 4.Remy

Remy是一款由麒硕创新技术（深圳）有限公司开发的创新性3D空间记录应用，其Slogan"拍摄视频生成3D空间"精准概括了核心功能。作为一款荣获华为应用市场"年度手机应用"奖项的应用，Remy已获得超过157万次安装，用户评分高达4.5分，充分证明了其出色的用户体验和技术实力。

该应用基于先进的3D重建技术，让用户能够像拍摄普通视频一样，通过手机摄像头捕捉生活中的真实三维空间。与传统的照片或视频记录不同，Remy生成的"沉浸空间"不再是扁平的影像，而是可以自由进入、360度环视、深度体验的立体记忆场景。用户可以在其中自由漫游、转动视角、放大细节，获得身临其境的回忆体验。

Remy提供了丰富的创意功能，包括"AI 3D重建"一键生成可交互的3D场景、"五光十色"、"灵动生长"等多样化的特效滤镜、登场动效以及[RFX]特效视频功能。此外，应用还支持全景照片浏览，让用户可以像"逛街"一样探索记录的空间细节。2026年1月发布的1.4.1版本进一步优化了物体模式的处理时间和横屏操控体验，持续提升用户的使用感受。

# 9.HttpShark

HttpShark 是一款专为移动端开发者与测试工程师打造的 HTTP/HTTPS 抓包及网络调试工具。它能够实时捕获并解析设备上的所有网络请求与响应，帮助用户快速定位接口问题、验证接口逻辑、排查前后端交互故障。

该软件功能全面且专业：支持发起 HTTP 请求进行接口调试，支持按应用进行流量过滤，支持Hosts映射、请求屏蔽、请求重写与请求映射等高级功能，同时提供 JSON、HTML、图片等多种数据格式的解析能力，以及编码转换、二维码识别等实用工具。界面采用深色主题，适配移动端操作习惯，让网络调试工作更加高效便捷。无论是开发调试、安全研究，还是学习网络协议，HttpShark 都是您随身携带的得力助手。
