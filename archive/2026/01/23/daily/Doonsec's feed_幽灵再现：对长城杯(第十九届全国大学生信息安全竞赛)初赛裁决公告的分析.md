一、裁决概况

    本次裁决公告登榜队伍共260支，覆盖辽宁、浙江、湖北、广东、重庆、陕西六大赛区。其中可核查的被裁决队伍257支（含1支重复队伍），不可核查的被裁决队伍3支。因大赛官方已于昨日上午关闭排行榜，相关核查均基于已有数据开展，数据可在文末下载。

    重复队伍为"CloudEver"，该队伍同时出现在《初赛裁决公告 - 附件.pdf》第224行、第231行。结合排行榜数据核查，云南大学共5支队伍参赛，仅设"CloudEver"一支对应队伍，无其他名称近似该队的参赛队伍。

二、数据概况

    本次分析基于初赛裁决公告附件数据，共涉及260支违规队伍，涵盖154所学校、29个省份、6个赛区，共78种不同的违规类型。所有违规队伍均被处以"取消参赛队伍资格"的处罚。

三、违规类型分析

3.1 主要违规类型TOP5

1. 串题违规：69次，占比26.5%。表现为与其他队伍串题，违反参赛规程禁止项；
2. WP高度相似：17次，占比6.5%。提交的解题报告内容高度相似，存在抄袭嫌疑；
3. 未按规定提交解题文件：16次，占比6.2%。未遵守比赛文件提交要求；
4. WP截图与思路相同：13次，占比5.0%。解题截图和思路完全一致，明显违规；
5. 串题+未提交录屏：9次，占比3.5%。同时存在多种违规行为。

3.2 违规特点分析

* 串题是主要违规形式：单纯串题及串题+其他违规的总占比超过30%
* 文档抄袭严重：各类WP相关违规占比约18%，反映学术诚信问题
* 违规行为多样化：78种不同违规类型，说明违规情况较多
* 部分队伍使用AI工具：存在使用互联网大模型辅助解题的违规行为

四、地域分布分析

4.1 赛区违规情况

1. 浙江赛区：73队（28.1%）- 违规最严重赛区
2. 辽宁赛区：44队（16.9%）- 违规数量第二多
3. 湖北赛区：43队（16.5%）- 与辽宁赛区接近
4. 重庆赛区：42队（16.2%）- 违规数量较多
5. 广东赛区：39队（15.0%）- 华南地区违规集中区
6. 陕西赛区：16队（6.2%）-   违规相对较少
7. 查找失败：3队（1.2%）-     信息缺失

前5大赛区违规队伍占比超过90%，是监管的重点区域。

4.2 省份违规情况TOP10

1. 江苏省：35队（13.5%）
2. 河南省：21队（8.1%）
3. 四川省：19队（7.3%）
4. 浙江省：18队（6.9%）
5. 山东省：17队（6.5%）
6. 湖南省：16队（6.2%）
7. 北京市：16队（6.2%）
8. 江西省：15队（5.8%）
9. 安徽省：13队（5.0%）
10. 河北省：12队（4.6%）

前10省份违规队伍占比超过70%，地域集中度较高。

五、学校违规情况分析

5.1 违规严重学校TOP10

5.2 学校违规分布特点

* 单校多队违规：2所学校各有6队违规，1所学校有5队违规，5所学校各有4队违规
* 普遍违规现象：80所学校各有1队违规，占比51.9%，说明违规现象具有普遍性
* 名校也违规：知名高校也存在违规队伍，需要引起重视

六、分数情况分析

6.1 总分分布

* 最高分：1742分（高分段也存在违规）
* 最低分：201分
* 平均分：1071分
* 中位数：1116分

违规队伍分数分布广泛，从低分到高分段均有涉及，说明违规行为与队伍实力无明显相关性，各类水平的队伍都存在违规倾向。

6.2 违规队伍理论知识分与CTF分对比

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 分数类型 | 平均分 | 占比 | 最高分 | 最低分 |
| 理论知识分 | 237分 | 23.9% | 300分 | 60分 |
| CTF分 | 834分 | 76.1% | 1462分 | 101分 |

1. CTF分占比显著高于理论知识分，平均占比76.1%
2. 理论知识分相对稳定，大部分队伍得分在240分左右
3. CTF分差异较大，反映违规队伍在实践能力上的差距
