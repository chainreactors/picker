# New Release: Tor Browser 15.0.16

by [boklm](/author/boklm)
| June 17, 2026

![](/new-release-tor-browser-15016/lead.png)

Tor Browser 15.0.16 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.16/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.16 is:

* All Platforms
  + Updated NoScript to 13.6.24.1984
  + Updated OpenSSL to 3.5.7
  + [Bug tor-browser#45044](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45044): NS 13.6.19.902 DocStartInjection regressed
  + [Bug tor-browser#45046](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45046): Rebase Tor Browser stable onto 140.12.0esr
  + [Bug tor-browser#45054](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45054): Backport Security Fixes from Firefox 152
* Windows + macOS + Linux
  + Updated Firefox to 140.12.0esr
* Android
  + Updated GeckoView to 140.12.0esr
* Build System
  + All Platforms
    - [Bug tor-browser-build#41802](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41802): Remove the tor daemon requirement for signing
  + Windows + Linux + Android
    - Updated Go to 1.25.11
