3月16号，一条不起眼的官宣，在科技圈炸了锅。

阿里成立了一个新事业群：Alibaba Token Hub（ATH）。
更关键的是，这个群由CEO 吴泳铭亲自带队，和电商、阿里云平级。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/TVljsu2eAicJf9nDO5YFJYKZwjjMTQPqhngVndicQiceSnn0WAL3G2r2ichSdTsf8GhrTl3Z6Y3excoibHficUw12R4JYLdvD2ricGMJma7Z7ssCrw/640?wx_fmt=jpeg)

第一眼看到这个新闻，我的感觉是：
阿里，终于动真格的了。

01 一场迟到的“大整合”

以前阿里的AI是什么状态？
散。

通义千问有自己的团队，夸克有自己的LLM，淘天业务线偷偷练模型，钉钉也有独立的研发力量。

表面上是“多点布局”，实质上是重复造轮子、资源内耗、用户记不住。

行业里有句话：
大厂不做AI，是等死；做了AI，是内耗死。

阿里这次重组，就是奔着解决内耗去的。
说白了：不能再让各个业务线自搞一套了。

Alibaba Token Hub包括5个组成部分：

（1）通义实验室：也就是Qwen大模型

（2）MaaS业务线：构建高效开放的模型服务平台和技术体系，支撑全行业AI生态。

（3）千问事业部：包括千问APP，打造最好的个人AI助手。

（4）悟空事业部：打造B端AI原生工作平台，将模型能力深度融入企业工作流。

（5）AI创新事业部：探索各类AI创新应用，快速验证新模式、新市场。

谷歌当年把DeepMind和Google Brain捏在一起，才出了Gemini；
OpenAI把研究、工程、商业化拧成一股绳，才敢不断挑战极限。

阿里现在做的，就是把散落的AI能力“收编”成一支正规军。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/TVljsu2eAicIpibJ8Qpl4n2XqYFa6zY1lSEZicdMpWyBzx61u6YM7X2vFMscWjLhagQ5LMASJkbsUXibV7cOlnJcYYCWBKyYODEKrsicaR4Nt8DQ/640?wx_fmt=jpeg)

以下是吴泳铭全员信：

各位阿里人：

当下正处于AGI 爆发前夜。大量数字化工作将由数以百亿计的AI Agent来支撑，而这些AI Agent将由模型产生的Token支撑运行，成为人类与数字世界交互的主要载体。

面向这一历史性机遇，集团决定正式成立Alibaba Token Hub（ATH）事业群，建立以“创造 Token、输送 Token、应用Token”为核心目标的新组织。

Alibaba Token Hub事业群由我直接负责，强化各AI业务战略协同，以AI重塑工作方式，保持敏捷组织。具体业务包括：

通义实验室：创造领先的多模态模型，不断追求基础模型能力上限，为集团和业界提供最领先模型。

MaaS业务线：构建高效开放的模型服务平台和技术体系，支撑全行业AI生态。

千问事业部：打造最好的个人AI助手。

悟空事业部：打造B端AI原生工作平台，将模型能力深度融入企业工作流。

AI创新事业部：探索各类AI创新应用，快速验证新模式、新市场。

以上调整即日生效。一起全力以赴！

02 ATH到底要干嘛？

一句话总结：
让阿里AI“从一堆技术”变成“一条战线”。

旗下五大板块，分工其实很清晰：

- 通义实验室：负责技术底座，守好“大模型根基”。
- MaaS平台：给行业提供API、模型和工具，做B端生意。
- 千问事业部：主打个人AI助手，面向普通用户。
- 悟空事业部：推企业AI应用，这是钉钉未来的核心赛道。
- AI创新事业部：试错新业务，找新机会。

这不是简单的“合并部门”，而是把AI变成阿里的第二增长曲线。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/TVljsu2eAicI2Y5ibexSGrwWawkX3GO1vpgcN1zTw8S3auEK6w4rg8zIRFjSUCuS50ZHKnViawApSRXFITGJJzWq6PXZ0gfBqS0WNYPWydXibo0/640?wx_fmt=jpeg)

03 为什么阿里现在必须“卷”AI？

因为它的处境，真的不轻松。

字节跳动有豆包，轻装上阵，流量凶猛；

腾讯有元宝，背靠微信生态，追击速度惊人；

百度文心一言深耕多年，牢牢占据C端认知；

就连初创公司，都能靠一款爆品杀出重围。

阿里不是没有实力：

Qwen系列模型长期稳居 HuggingFace 全球顶尖梯队，性能甚至不输不少国外大模型。
但问题是——这些实力没拧成一个拳头。

所以吴泳铭这次挂帅，其实是在回答一个问题：
在AGI时代，阿里到底凭什么还能站在第一梯队？

答案就是：
整合、统一调度、集中火力。

04 市场在猜：这是阿里“One Company”2.0？

当年阿里有“One Company”，把电商、云计算、数娱统一战略。
今天这场重组，隐隐有股“大中台、小前台”的味道回归。

技术中台统一了，
产品战略统一了，
算力资源统一了，
对内减少内耗，对外统一作战。

对于外界来说，这就是阿里重新建体系的信号。

05 最关键的问题：接下来怎么打？

重组只是“把弹药装到枪上”。
能不能打中目标，看三个指标就够了：

1. 悟空事业部的企业落地成绩（B端是阿里基本盘）
2. 千问助手的日活、留存（C端是用户心智战场）
3. 通义大模型的API调用量（商业化的核心标尺）

没有这三项，再华丽的架构也只是图纸。

06 最后说一句

科技圈喜欢喊“颠覆”“革命”“弯道超车”。
但阿里这次动作，让人闻到的是一种沉稳的杀气。

它不喊口号，它直接重组；
它不喧嚣，它让模型自己说话；
它不玩概念，它先把能力整合成体系。

对于普通打工人、互联网从业者、科技行业观察者来说：
这是AGI大战进入下半场的标志之一。

阿里上船了。
接下来，就是看它能不能驶进真正的深水区了。
