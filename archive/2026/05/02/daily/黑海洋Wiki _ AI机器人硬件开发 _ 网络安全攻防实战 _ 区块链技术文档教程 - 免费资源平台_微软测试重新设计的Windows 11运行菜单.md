# 微软测试重新设计的Windows 11运行菜单

发布时间:
2026-05-02
分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
3135

微软公司正在测试其对 Windows 11 运行菜单更新，提供一个现代化的界面，该公司表示该界面更快并支持深色模式。该重新设计现正向新实验通道中的 Windows 11 预览体验成员推出。微软公司在一篇博客文章中表示，在发现 “使用率非常低” 后，公司决定放弃运行菜单中的“浏览”按钮——一个指向用户文件的快捷方式。取而代之的是，微软增加了对新命令 “~\” 的支持，该命令指向你的用户目录。微软表示，公司使用来自命令面板的代码构建了新的运行菜单，命令面板是一个可通过PowerToys获得的实用工具，允许你快速运行命令、打开网站、搜索文件等。
