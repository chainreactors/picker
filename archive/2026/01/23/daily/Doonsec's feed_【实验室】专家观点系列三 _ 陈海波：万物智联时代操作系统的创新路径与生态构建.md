**编者按：**

基础软件质量控制与技术评价工业和信息化部重点实验室（以下简称“实验室”）作为首批工信部认定的重点实验室之一，始终致力于基础软件产业创新发展研究、关键技术突破及公共服务体系构建，服务国家重大专项及基础软件重点产业链。为强化实验室技术引领与产业赋能作用，现梳理其2025年度学术委员会专家观点形成系列内容，为行业提供前瞻性思考。

 以下文章基于上海交通大学教授、实验室学术委员会委员陈海波的《万物智联时代操作系统的创新之路》专题发言整理而成。文章指出，开源鸿蒙通过“元OS”架构、AI与系统深度融合、安全隐私一体化等技术创新，正逐步构建起面向万物智联时代的数字底座。同时，借助开源模式与产学研协同机制，我国操作系统生态已从“全面参与”迈向“蓄势引领”，为全球智能终端操作系统的演进提供了中国方案与中国智慧。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXriahPYu00wrfS23Y75aOGrTFVYywFHicmLZRGC5bfXaNvBA0Y0H4KSUbQ/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)

上海交通大学教授、实验室学术委员会委员陈海波

**一**

**万物智联趋势与智能终端操作系统的发展机遇**

1.1 智能化成为终端发展的主旋律

当前，终端设备正从“功能执行”向“主动智能”跨越，智能化程度向“协作自治”“专业指导”方向迈进。AI大模型与智能体（Agent）的兴起，推动终端从“作诗”走向“作诗+做事”，实现复杂任务的规划、分解与协同执行。智能终端操作系统需与AI深度耦合，实现面向大模型与智能体的资源抽象、调度优化与交互升级，从而支撑更高阶的智能体验。

目前，操作系统与AI的融合呈现三种演进形态：

* AI外挂式：AI能力以附加服务形式存在，系统未深度适配，存在开销大、交互局限等问题；
* LLM as OS：以大模型为核心重构操作系统，虽能发挥AI潜力，但颠覆现有生态，且对硬件与交互的确定性保障不足；
* 系统与AI深度融合：在兼容现有软件生态的基础上，将AI能力内生于操作系统内核与资源管理层，实现高效、安全的智能增强。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXrfoMXjYhQ6PicG3JONea7Q6RyU7Q2P4EPAgZ5zx0YkjLfCDdViasy7P3w/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=2)

1.2 我国开源创新从“全面参与”走向“蓄势引领”

我国开源生态日益成熟，软件开发者数量近千万，开源贡献度位居全球第二。开源已成为软件创新的主流范式，通过“合纵连横”促进产业链协作，提升研发效率与系统韧性。开源鸿蒙作为我国首个面向万物智联时代的智能终端开源操作系统根社区，正通过开源协同机制，汇聚产学研力量，推动操作系统技术从“跟跑”向“并跑”乃至“领跑”转变。

1.3 后摩尔时代软件与架构创新成为性能提升关键

随着摩尔定律演进放缓，单纯依赖工艺进步带来的性能提升日益有限。通过软件优化、算法改进与系统架构创新，成为延续算力增长的重要路径。操作系统需在调度、内存、存储、通信等层面实现突破，以系统级创新释放硬件潜能，应对万物智联时代高并发、低延迟、高可靠的应用需求。

1.4 终端形态泛在化呼唤OS架构革新

万物智联时代设备形态呈现爆发式增长（可穿戴、XR、车载、机器人等），输入/感知与输出/反馈方式也日趋多元（多模态融合、新型交互）。传统“一个OS对应一种设备”的模式难以适应场景碎片化需求。操作系统需向“元OS”架构演进，通过可灵活组装的操作系统能力集合（OS Kit），实现“一套架构、按需部署、千行百业适配”的目标。

**二**

**开源鸿蒙关键技术创新探索**

2.1 元OS架构：统一底座支撑泛在设备

开源鸿蒙提出“元OS™”架构理念，通过高度弹性的内核设计与模块化能力组合，实现多样化设备的统一架构支持。

2.2 AI与系统深度融合的路径实践

开源鸿蒙积极推进AI能力的内生融合：

* AI亲和资源管理：面向大模型与智能体优化调度策略，支持低开销推理与动态资源分配；
* 智能交互框架：支持多模态输入与沉浸式交互，为Agent化应用提供系统级支撑；
* 安全隐私一体化：通过TEE（可信执行环境）、分离式安全容器、模型感知的隐私控制等技术，保障端侧AI模型与用户数据的安全。

2.3 系统性能与可靠性的跨越式提升

（1）内核创新

鸿蒙内核基于微内核架构，具备高安全、高性能、高弹性等特性，已通过CC EAL6+、ISO 26262 ASIL D等行业最高等级安全认证，并在智能终端场景的动态性能上较Linux提升20%以上。

（2）可证明并发创新

开源鸿蒙在可证明并发领域取得系列突破：

* 攻克文件系统并发验证难题（RefFS、AtomFS）；
* 提出VSync、CLoF、BBQ等高可靠并发协议，在学术顶会（ASPLOS、SOSP、OSDI）发表多项成果，并获ASPLOS等最佳论文奖。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXrFnUbyibQELZcNibtZZcjfrbhjN317ZmzFSAkeQbe9bDLNmQUwSwdIXmQ/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=3)

（3）渲染架构革新

提出D-VSync（Decoupled VSync）架构，实现渲染与显示的分离，通过“提前渲染、按需显示”机制，有效平缓负载峰值，提升图形处理的实时性与能效。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXroMs1HjiaSzicz5bbgd8CSs7A8AakribCcsaXCXOd4R13sQ0xttVZ9oLCQ/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=4)

（4）文件系统创新

EROFS（Enhanced Read-Only File System）已成为业界事实标准，被Android采纳为默认只读文件系统，在全球数十亿终端中部署，相比EXT4随机读性能提升20%~300%，系统升级包体积下降5%~10%。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXrSnORkP8IqEiaQhLmHOyUoeYxPwpXOvANt6ea6lWaDzJjHluW4Anu9ew/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=5)

（5）数据搬运服务化

Copier作为OS原生异步拷贝服务，通过隐藏延迟、硬件加速、消除冗余拷贝等手段，实现内存复制效率的显著提升。实验显示，其在Redis等场景中性能提升达1.8倍，视频解码时延降低3%~10%。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXrf4juZNPTwJyBeoPhicZKanHnWwkYvHgpx4w4xNmrXQ0b7OboR2H1lZg/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=6)

2.4 安全与隐私保护的系统级构建

开源鸿蒙构建了覆盖硬件、内核、框架的全栈安全体系：

* “鸿匣子”智能安全处理系统：基于TEE保护端侧大模型与隐私数据，支持分布式安全融合；
* 安全内存融合技术：将TEE内存封装为块设备，提升安全内存利用率；
* 分离式安全容器：实现管理与保护分离，最小化可信计算基（TCB），兼顾安全与性能。

**三**

**开源鸿蒙的产学研协同生态**

3.1 技术生态：开放共建，千行百业赋能

开源鸿蒙已形成覆盖消费电子、金融、交通、教育、能源等多个行业的生态体系：

* 累计发布70余个行业发行版、1550余款软硬件产品；
* 贡献者超10000人，代码行超1.3亿行，成为发展最快的开源操作系统根社区之一。

3.2 学术研究：前沿成果持续融入

上海交通大学等高校与科研机构围绕智能终端操作系统的一系列前沿研究，正在逐步融入到开源鸿蒙技术生态中：

* MobiAgent：可定制移动Agent系统框架，支持复杂任务编排；
* SmallThinker：面向端侧部署的高效大语言模型系列；
* 安全容器与TEE架构：基于上海交通大学ChCore内核的轻量安全容器方案。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXrsHM5040QbiaUWTkNQS6B6LXYDtZDmUYuLsrZpjtNc2W0Kf6ic3WV7fibw/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=7)

3.3 人才培育：多层次培养体系构建

开源鸿蒙通过技术俱乐部、城市论坛、技术大会等形式，构建覆盖高校、企业、开发者的立体化人才生态：

* 与100余所高校成立技术俱乐部或开发者协会；
* 年度技术大会吸引线上线下超18万人次参与；
* 新成立“开源鸿蒙教育委员会”，推动课程建设与教材开发。

![图片](https://mmbiz.qpic.cn/mmbiz_png/df6VWfFVdT7pA5vO2xK1yR3ibxwcQmSXrCNxzHIR7GxWXh5s5bZsxYKV4r8iaSbQz7zI3YPYj1CmTsUSZhNnnebg/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=8)

3.4 课题牵引：攻坚操作系统核心难题

通过发布《终端操作系统十大挑战方向》等开放性课题，吸引上百位产学研专家参与，形成60多项年度课题，其中60余项由高校团队承接，部分已结题并贡献于主线代码，形成“问题导向、协同攻关”的研发新模式。

**四**

**挑战与未来展望**

4.1 技术挑战

* AI与系统深度融合的工程化难题：如何平衡性能、功耗与隐私安全，实现智能资源的动态调度与保障；
* 超异构设备统一架构的持续优化：面对海量设备类型与场景差异，需进一步提升元OS架构的弹性与轻量化水平；
* 开源生态的可持续运营：如何保持社区活力、保障代码质量、促进国际协作，仍需机制创新。

4.2 发展建议

* 持续深化AI原生的系统设计：构建“系统即智能”的新型范式，满足多智能体的运行和调度需求；
* 加强跨学科交叉创新：融合操作系统、人工智能、安全计算、人机交互等领域前沿成果，实现架构级突破；
* 推动国际开源协作：在保持自主演进的同时，积极参与全球标准制定与开源治理，提升国际话语权；
* 完善人才培养与评价体系：通过课程认证、竞赛激励、实习通道等方式，培育兼具系统思维与工程能力的复合型人才。

4.3 未来展望

开源鸿蒙作为我国在基础软件领域的重要创新实践，已初步构建起“技术 + 生态 + 人才”三位一体的发展格局。面向万物智联的广阔未来，操作系统将继续向“泛在化、智能化、协同化”方向演进。通过持续的技术迭代、生态拓展与国际合作，我国有望在智能终端操作系统领域实现从“蓄势引领”到“全面引领”的历史跨越，为全球数字化发展注入中国动能。

**五**

**结论**

万物智联时代对操作系统提出了更高要求：需具备泛在适应能力、智能内生特性、安全可信保障与开放协同生态。开源鸿蒙通过元OS架构、AI融合设计、性能突破与安全增强等一系列创新，正逐步构建起面向未来的数字基座。与此同时，我国开源生态的成熟与产学研协同机制的深化，为操作系统的可持续发展提供了坚实支撑。未来，应继续坚持“软件定义、开源协同、智能原生”的发展路径，推动我国操作系统技术从“并跑”向“领跑”迈进，助力全球万物智联愿景的早日实现。
