GMSSH是一款以人工智能为助力，注重极致效率与美学体验的桌面级高性能服务器管理系统，其采用独特的“核心引擎专有且生态全开源”发展模式，一方面依靠闭源核心引擎来保证服务达到极致稳定与安全，另一方面又全面向开源社区敞开怀抱，开放全场景扩展可能性以及生态共建权限。

它将传统命令行式服务器管理高不可攀的操作门槛完全打破，无需在目标服务器上部署完整的桌面环境，就能为传统的Linux与Windows服务器带来沉浸式，图形化的一站式管理体验，使服务器管理变得简便且直观。GMSSH借助微内核架构，进程级沙箱隔离以及内核级零拷贝数据传输这类核心技术，达成远胜同类工具的高可用性，低延迟性能以及全链路安全保障，对于个人开发者和运维团队来说，它是管理多台服务器时不可错过的最佳选择。

## 核心特性一览

1. **AI 驱动的智能运维**：内置 AI 能力赋能全流程服务器管理，大幅提升运维效率，降低操作门槛
2. **微内核高可用架构**：核心引擎`ga_main`采用轻量化高性能微内核设计，与业务逻辑完全解耦，仅负责生命周期管理与流量调度，从架构层面保障核心服务稳定
3. **进程沙箱隔离机制**：所有功能模块与第三方插件均以独立子进程运行，单插件 / 应用崩溃仅影响自身，不会波及核心服务与其他功能，同时自带进程自动恢复能力
4. **内核级极致传输性能**：采用 Unix Domain Socket (UDS) 实现内核内存直传，完全绕过传统 TCP/IP 网络栈，实现零拷贝传输、微秒级低延迟，同时杜绝端口扫描风险，安全性拉满
5. **全开放开源扩展生态**：提供功能强大的多语言 SDK，支持使用 HTML/JS/Vue/React 等前端技术，或 Python/Go/Rust 等后端语言开发自定义应用 / 插件，无限拓展产品能力
6. **一站式全场景管理能力**：覆盖 SSH 一键登录、图形化文件管理、实时资源监控、进程全生命周期管理、Docker 容器管理、WAF 防火墙配置、计划任务、磁盘管理等全运维场景
7. **私有化部署 + 全链路安全**：支持私有化部署，完整掌控数据主权；内置严格的身份认证与权限校验机制，所有上架应用均经过安全审计，杜绝恶意操作与数据泄露风险

## WEB 端全功能管理（本文重点）

GMSSH 不仅提供了功能完善的桌面客户端，还内置了开箱即用的 WEB 管理服务，让你可以通过任意浏览器，随时随地管理你的服务器，实现跨设备、全场景的运维操作。同时支持生产环境 UDS 高性能模式与开发调试 HTTP 端口模式，兼顾生产安全与开发便捷性。

### 第一步：开启并访问 WEB 管理服务

首先在 GMSSH 桌面客户端的设置界面中，找到 GMSSH 服务的运行地址与端口，复制该地址。

### 图形化文件管理，告别命令行繁琐操作

点击文件管理入口，即可直接看到服务器系统内的全量文件与文件夹，以完全图形化的形式呈现，支持文件的新建、删除、复制、粘贴、拖拽上传下载、权限修改等全操作，无需记忆任何 Linux 命令，新手也能轻松管理服务器文件。

值得一提的是，GMSSH 无需在目标服务器安装任何桌面环境，即使是极简安装的命令行版服务器，也能获得完整的图形化文件管理体验，同时凭借底层的 IPC 协议与高性能传输能力，大文件传输也能保持稳定高速。

### 可视化进程管理，系统状态一手掌控

在进程管理模块中，你可以实时查看服务器所有进程的运行状态、CPU 与内存占用情况，支持按资源占用排序，一键结束异常占用、无响应的进程，快速定位系统性能瓶颈，高效完成服务器资源调优。

依托 GMSSH 的进程隔离架构，所有进程操作均在严格的权限管控下执行，不会误操作影响核心系统服务，保障服务器运行稳定。

### 更多实用运维工具，覆盖全场景需求

除了上述核心功能，GMSSH 还内置了大量开箱即用的专业运维工具，包括 Docker 容器可视化管理器、WAF 防火墙配置、计划任务管理、磁盘分区与用量管理、日志分析工具、Redis GUI 等，几乎覆盖了服务器运维的全场景需求，真正实现「一个工具，管理所有」。

应用层采用无状态、轻量化的 JSON-RPC 2.0 协议，实现了后端语言无关性，所有工具均可通过官方 SDK 进行扩展与定制，满足不同用户的个性化运维需求。

## 拥抱开源，共建 GMSSH 生态

GMSSH 始终坚信开源社区的力量，除了自主维护开源项目外，还通过资金、授权等多种形式赞助众多开源项目，同时全面开放了生态共建能力，欢迎所有开发者参与到 GMSSH 开源生态的建设中来。我们倡导尊重、共情、包容的社区氛围，所有参与者均需遵守社区行为准则，共同打造安全正向的开源环境。

### 你可以参与的贡献方向

* 🔌 **自定义应用 / 插件开发**：基于 GMSSH 官方 SDK，开发解决特定运维场景问题的工具，比如各类数据库 GUI、日志分析插件、自动化运维工具等
* 🐛 **问题修复与优化**：参与 gmssh-plugin-sdk、gmssh-official-apps 等开源仓库的问题修复与代码优化
* 📝 **文档完善与翻译**：优化 SDK 开发文档，或将文档翻译为更多语言，降低全球开发者的使用门槛
* 💡 **功能与 API 建议**：向官方提出 SDK 新增 API、功能优化的建议，共同完善产品能力

### 开发与上架流程

GMSSH 提供了完善的开发者文档与快速上手教程，你可以直接通过官方开发者入口快速开启应用开发。开发完成后，你可以向 gmssh-marketplace 仓库提交 PR，或通过官方网站提交上架申请。

所有提交的应用都会经过官方团队的严格安全审计，确保无恶意操作与安全风险，审核通过后，你的应用将上架至 GMSSH 官方应用中心，面向所有用户开放，同时你还将获得官方认证的「GMSSH Contributor」专属徽章！
