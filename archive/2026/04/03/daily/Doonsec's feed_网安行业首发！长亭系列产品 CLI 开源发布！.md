**01**

**CLI：AI 智能体时代的首选交互方式**

Chaitin Workspace CLI（Command Line Interface，命令行界面）是一种通过纯文本输入命令来操作计算机的交互方式，用户输入指令后系统即可直接执行，无需图形界面操作。

2026年初，Google 团队开源GWS（Google Workspace CLI ），短时间内 GitHub Star 数突破18k，被行业称为 AI智能体的“数字手臂”。3月底，飞书、钉钉、企业微信先后开源CLI工具，让智能体能直接操作即时通讯平台（IM 平台）。

**长亭科技开源CLI（****Chaitin Workspace CLI****）**，是国内网络安全企业的首次能力开放，将企业级安全产品的核心能力开放到CLI生态，帮助企业打通智能体落地安全能力的最后一公里。

**02**

**什么是长亭科技产品统一 CLI**

统一、标准的产品生态操作入口，AI智能体可原生调用企业级产品的核心能力，真正实现“沟通即执行”

提供旗下流量安全、漏洞扫描、端点安全等企业级产品CLI调用能力，产品防御能力和检测精度行业领先

天然适配大语言模型的处理逻辑，大幅提升AI任务执行的成功率与稳定性

保持持续迭代，提供更加丰富的CLI交互接口
