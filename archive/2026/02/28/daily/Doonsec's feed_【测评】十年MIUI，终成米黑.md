# 前情提要

作者是多年小米用户，至今也差不多10年了，从钉子户到顶级旗舰再到性价比全都有长时间使用体验，也从MIUI的辉煌一路到 MIUI沦为过街老鼠。

此处仅记录使用时间超过2年的机型进行叙述，部分机型使用不足一年则不提及。

机型为：小米6、小米8、小米10至尊纪念版、红米K40、红米K70

# 亲身体验

#### 小米6

第一个超过2年的机型--小米6，不得不说是小米曾经的巅峰，在那时候MIUI是最棒的代名词，层出不穷的新功能、快速处理的社区反馈、积极讨论的后续优化、最强的ROOT社区，造就了我内心中的最佳。

但！我不认为小米6是一部好手机，因为它不是全面屏。它好就好在能ROOT，并且有大量的社区爱好者为此进行创作，拥有最简单的ROOT流程和最丰富ROOT模块，甚至在官方放弃的情况下依然有庞大的用户群体进行维护。

***此时已经有一些苗头了，例如：控制中心下滑死机、控制中心下滑后内容消失、开机后需息屏等待几分钟后使用、开机后立马使用将导致肉眼可见的卡顿甚至死机、系统未响应、各种软件未响应、抖音打开会卡顿较长时间，直播页面甚至会彻底未响应、从通知栏进入应用大概率卡死和卡顿、微信白屏死机、耗电会随着系统更新不断增加等等各种问题。***

#### 小米10至尊纪念版

当年被誉为机皇，也是小米首次冲击高端市场，很遗憾我被雷军欺骗了，首发购入了小米10至尊纪念版，包装确实豪华，三个120也很吸睛，但除了充电的120w，其他都不实用。

**可以看一下前几年写的文章，在购买了电池更换服务并进行更换的时候，小米售后对手机进行了全面检查，在确认没故障和问题之后进行了更换，但更换之后出现了屏幕损坏的情况。当场与售后询问时对方表现极其恶劣，多次强调与小米售后无关，虽然更换之前检查是没有问题，更换后出现屏幕损坏，那也跟他们无关，极致的甩锅。同时我要求提供监控录像和书面情况描述，证明手机损坏，但被拒绝，既不给我看监控，也不愿意出具损坏证明。**

**但我此时依然相信小米会给出解决方案，因此我购买了K70作为临时使用。可惜在我投诉以后，小米官方对售后进行了调查，并通知我在维修前进行过全面检查，该手机没有问题，屏幕完好，但是维修后立刻出现屏幕损坏，跟小米没有关系。**

**很好笑吧，维修前进行全面检查，没有出现任何问题，但是维修后立马损坏，却跟小米无关？（我依然保留了录音证据，并在多处备份）**

这是第一次对小米的彻底失望，但远不是最后一次，因为！在小米6上所出现的问题，在后续的小米8、小米10至尊纪念版、红米K40上依然存在！！！

那么为什么在有小米10至尊纪念版的情况下，我又购买了红米K40呢？因为NT小米在一次系统更新包里写入了错误内容，导致更新系统的用户无法开机，甚至无法点亮。我前往小米售后中心需要提前预约，因为当天故障售后人数爆满，无法及时处理了，我去的时候至少有四十几台小米10至尊故障，因此购买了K40作为临时用机。

很抽象吧，这就是大品牌小米。

#### 红米K70

这是最后一台小米的设备了，因为小米在预热MIUI15的时候其他家纷纷推出自家的全新自研系统，此时小米作出了一个极其抽象的决定————改名。MIUI15预热到一半就改名成澎湃系统重新预热，现在依然能搜索到当年部分的MIUI15预热信息。

![](https://mmbiz.qpic.cn/mmbiz_jpg/et2dt16VCeV0IZDWe795N6OnFbhWJzNVeicr8YDKc4ykwvVG9QyA9ct6pfSkvAmzuohRL13qSNA6ezVtw5dS2XySuWkXZjYvcVEibr421eTYU/640?wx_fmt=jpeg&from=appmsg)

可惜MIUI15虽然改名成澎湃OS，但是本质不变，多年来的陈年老BUG依旧存在，甚至除了系统名修改了，其他的安装包、进程等等内容依然用的是MIUI，所以又怎么可能改善使用体验？

# 脱离苦海

于2026年01月13日-15日，K70再次连续遭遇微信死机后，我忍无可忍了，开始大量搜索资料，对比各家系统后，我决定更换阵营，加入伟大的ColorOS。

购买了一加ACE6，并在到手后立刻对比小米所遇到的各种问题，震撼的发现，原来外面没下雨。

从一月份至今已经一个多月了，体验到现在发现ColorOS真的极佳，简述一些对比MIUI让我印象深刻的颠覆性体验吧。

#### 流畅度

开机之后不再出现桌面卡死、密码解锁卡死、控制中心显示异常及卡死； 应用动画不再是通过增加白屏延迟来优化“顺畅度”（小米的优化逻辑就是增加启动时间，拉长白屏显示时间来制造伪流畅，甚至不敢说是增加流畅度，而是增加顺畅度），而是实打实的进入启动动画再进入。我不知道该怎么描述这种感觉，就是一种快速但不卡顿的样子；通知栏跳转应用内不再会出现卡死内容的情况，抖音启动也不会出现卡顿；开再多应用也不会出现一顿一顿的情况；**甚至在双列以上显示的时候，点击进入会有对应位置逐渐放大的动画，退出的时候也不是白屏然后回到上一级，而是缩小并逐渐返回上一级，极其流畅！！！**

#### 使用体验

双指按下启动的小布能直接识别屏幕内容，提供全屏保存或文字提取、翻译转文档等等极其实用的功能；**侧边键按下直接触发小布记忆快速记录当前页面及衍生内容，例如抖音内截图后会自动读取整个视频或文章的内容并进行AI总结和备份，同时保留一键跳转到对应原址和按APP分类，这个功能真的无敌**；每次更新都是有意义的，目前大概经历了4次更新，全都是实用功能或新功能的实现，而不是小米的“合并X月安全漏洞，优化顺畅度”虚假更新；终于能在软件内点击通知栏是跳转到对应页面而不是强制把当前页面变成小窗的NT逻辑；在游戏等横屏界面下点击通知信息是以小窗的方式启动，而不是像小米一样覆盖当前应用来启动，导致游戏中断（360都他喵的不敢这样做）；终于能跟PC端进行联动，剪切板同步、视频截图快速同步、远程操作等等（目前只有辣鸡小米不支持与PC端联动）；还有极多体验上的提升，方方面面的碾压MIUI，我只能说体验了你就知道了，特别是打游戏不再发热和卡顿掉帧（小米云控，用过都说牛）。

#### 缺点

有没有缺点呢？当然有，但是部分缺点是个人习惯问题，例如上滑的最近任务管理只能堆叠或者平铺，每个进程卡片都极大，很容易误触（当然，目前用了一段时间以后习惯了也就好了）；云同步的云相册不支持批量删除，只能在相册里批量删除后同步，有些体验不佳；目前只遇到过这两个问题，其他方面完全没有。

#### 游戏体验

很多人会比较在意这个东西，我也略微讲讲吧。目前来说打王者之类的是全程稳定不掉帧的，不过因为一些英雄的问题，我是锁在90帧，并且是不会发热的，同时一小时大概消耗8-10%的电量，基本上打一整天游戏是没问题的。并且是可以边打边充，只有微微发热，不影响游戏；AI实验室，也就是屏幕识别，会自动记录对方召唤师技能还有多久冷却，挺实用的，其他游戏不知道是什么类型的效果。

# 总结

从各方各面来说，ColorOS对比MIUI来说都是全方面的碾压，甚至广告这块也远远少于MIUI，从社区关注度来说，修复问题的速度也是很及时的，很多BUG我都还没遇到就被官方修复并推送了。更不用说小米现在更加过分的对老设备进行电池强制锁容，5000的电池直接被锁到只剩下3300，真的绷不住。

个人不会再推荐购买小米及红米的任何设备，因为就连系统维护都只有1-2年，如果买的是联发科芯片，甚至2年内只会有寥寥三四次系统更新，曾经吃过的亏会是将来的预警！！

就连售后都一塌糊涂，睁着眼睛说瞎话，完全不承担任何责任，即使知道是维修后导致的损坏，也不退款也不赔偿，完全没有任何保障。

**记住一句话：小米产品纸面配置没输过，但使用体验从没赢过。**

或许未来某一天还会再次相信小米，但这样的MIUI可能不会有未来的某一天了。

**绝望不是一蹴而就的，是数年来的不断累积的失望、从不理睬的态度、蛮横无理的自大所叠加出来的，小米只适合做方案集成商（利用庞大的供应链整合贴牌）而不适合做创造者（但凡涉及系统，自研的都是一塌糊涂）。目前来说还是推荐购买小米的小产品，例如水笔之类的，庞大的供应链早就了低成本，确实不错。**
