# XSecret 使用文档

XSecret 是一款专注于 **Text / Markdown 内容加密**的轻量级笔记工具。

### 初次运行 💻

初次运行需要设置账号密码，且有强密码规则校验。

> **长度大于12且包含字母大小写 | 数字 | 特殊符号**

![](https://mmbiz.qpic.cn/mmbiz_png/q6oCwPXyDCnHDKJVe7wlDSCCZozYZG9mqSyAicib2RTbXsCDw0zRNxJTx6ep0c2whx6fsh1jqGXWnw0tzUdJyMicjv9iaStHOfWpDKmibRsYRl6c/640?wx_fmt=png&from=appmsg)

设置密码后即可登录，同时会创建一个 **XSecret.db** 文件，所有文件的内容和图片都加密保存在数据库中。

### 右键菜单 🛠

* • Refresh -> 刷新
* • New File -> 新建文件
* • New Folder -> 新建文件夹
* • Rename -> 重命名
* • Delete -> 删除

![](https://mmbiz.qpic.cn/mmbiz_png/q6oCwPXyDCkSHzOe7lXibujRkewJUCW1VeEgcAaaicTStRURXjDgHPBU3WGje0Wibp0t39QkXXia9EVpZ5ic7DQVibcQeLcn3ecKeK1I3YmtcdUNo/640?wx_fmt=png&from=appmsg)

### 编辑｜保存｜➕ ⌨️

在菜单栏右边，有三个按钮，分别是**编辑｜保存｜插入图片**

**✍️ 编辑模式**

* • MD 文件
  在编辑模式，分为左右两栏显示，左边是编辑区，右边是预览区。

  ![](https://mmbiz.qpic.cn/mmbiz_png/q6oCwPXyDCnPsptzw00KvU2gaQeX2kZDYESCXZIPuOTxDfP85VaUMnicPsn3a84f8f5CFGkqzz0cvPdInibMtdLswUFia0XibucYFMwhLBhIQPw/640?wx_fmt=png&from=appmsg)
* • TXT 文件
  在编辑模式，编辑和预览都在同个区域

**🏷 保存文件**
保存文件后，恢复到阅读模式

**🏙 插入图片**
在编辑 MD 文件时，如果已经复制了图片，可以使用 `Ctrl+V` 直接插入图片、或者点击 ➕ 选择本地图片插入。

### 退出登陆 🔒

* • 手动退出
  手动点击图标 🔒 可退出文件管理页面，重新进入需要输入密码。
* • 超时退出
  如果 **30 min** 内无操作，即自动退出文件管理页面。
