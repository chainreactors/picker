A download must never wait for a human. git credential fill only set
GIT\_TERMINAL\_PROMPT=0, so a GUI askpass or Git Credential Manager dialog
could still hang it, and hg clone inherited the raw environment.

* add internal/childenv: NonInteractive() strips GIT\_ASKPASS and
  SSH\_ASKPASS, then appends GIT\_TERMINAL\_PROMPT=0, GCM\_INTERACTIVE=false,
  GCM\_GUI\_PROMPT=false and SSH\_ASKPASS\_REQUIRE=never
* use it for git credential fill and hg clone

Configured helpers (keychain, manager-core, ...) are still consulted; only
the fallback to asking a human is blocked.
