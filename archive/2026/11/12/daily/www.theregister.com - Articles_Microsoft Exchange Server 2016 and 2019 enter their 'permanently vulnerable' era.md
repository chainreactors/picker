Microsoft has warned customers still clinging to Exchange Server 2016 and 2019 to consider the software "permanently vulnerable" as November's security fixes arrive for Subscription Edition (SE) alone.

The warning appears in the [release documentation](https://techcommunity.microsoft.com/blog/exchange/released-november-2026-exchange-server-security-updates/4570368) for November's Exchange Server SE security update.

Looking for Exchange 2016 and 2019 information? Tough. Microsoft stated: "Exchange Server 2016 and 2019 are no longer tested for vulnerabilities and there are no updates released. If you are using those versions of Exchange, you should consider them permanently vulnerable [Microsoft's emphasis] and should upgrade your organization immediately." You have been warned.

REG AD

Support for Exchange Server 2016 and 2019 [ended](https://learn.microsoft.com/en-us/lifecycle/products/exchange-server-2019) on October 14, 2025, but the company [announced](https://www.theregister.com/security/2025/07/17/microsoft-extends-updates-for-old-exchange-and-skype-servers/564141) an Extended Security Updates (ESU) program in July 2025. The plan was that this program would end on April 14, 2026, by which time customers would surely have made the jump to a later or online version, right? The company said: "This period will not be extended past April 2026 (you do not need to ask)."

REG AD

And... of course it was. As April 2026 rolled around, and it became clear that some customers were still stubbornly sticking with the old versions, Microsoft did the equivalent of [heaving an exasperated sigh](https://www.theregister.com/security/2026/04/16/microsoft-announces-product-it-doesnt-want-anyone-to-buy/5226646) and offered another six months of paid security updates. Those final weeks also brought a separate treat: a Windows Server update [breaking Exchange Server](https://www.theregister.com/software/2026/10/19/admin-i-spent-all-weekend-on-my-servers-after-microsoft-breaks-exchange-server-with-october-updates/5303724).

This time it was serious. Microsoft released the final Exchange Server 2016 and 2019 security updates on October 13. No more patches, no more vulnerability testing, and apparently no more reprieves.
