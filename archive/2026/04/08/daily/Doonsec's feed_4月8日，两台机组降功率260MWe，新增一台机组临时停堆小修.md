4月8日，50台处于功率运行状态，2台处于运行（调试）状态， 10台机组停堆（其中：8台机组大修；2台机组临时停堆）。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/3YDEbeC7QUgWVbe8cxkneMibSySg3ngPjYOPpLFJwmEica2Fd1mPF7XQ8lFR0icwHZ56oOq2rZk9DZvzFBJXsQt83KibdWoL3vbkIq8dcQ9M4aE/640?wx_fmt=png&from=appmsg)

4月7日，51台处于功率运行状态，2台处于运行（调试）状态，9台机组停堆（其中：8台机组大修，1台机组临时停堆）。

![](https://mmbiz.qpic.cn/mmbiz_png/3YDEbeC7QUg7KTaYySpuCmE6iboMmYSJEfkDS5aZSLL5mNahEZfaKibnMlsGzGiauhxzLhCY6X7SH7BIPXRG1ribVQPAJEicnLHydpfSGUk7Ijpw/640?wx_fmt=png&from=appmsg)

结合2天的数据来看，高负荷运行机组占比高，体现了核电作为清洁能源的可靠性，虽然运行机组数量略有下降，但主要原因为计划性大修，属于正常运维范畴，随着更多机组进入大修周期，短期内运行机组数量可能继续波动。

另外做个表格对比：

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| 核电厂 | 机组 | 额定功率(MW) | 当前功率(MWe) | 瞬时负荷率(%) | 状态 | 日期 |
| 红沿河核电厂 | 1号机组 | 1119 | 1097.6 | 98.10% | 运行 | 2026/4/7 |
| 红沿河核电厂 | 4号机组 | 1119 | 1111.05 | 99.30% | 运行 | 2026/4/7 |
| 红沿河核电厂 | 1号机组 | 1119 | 851.14 | 76.10% | 运行 | 2026/4/8 |
| 红沿河核电厂 | 4号机组 | 1119 | 859.77 | 76.80% | 运行 | 2026/4/8 |

红沿河核电1、4号机组负荷率惊人地一致，分别降至76.10%和76.80%，各降功率260MWe，在观测期内保持了安全稳定运行，但在4月8日执行了大幅度的降功率操作。这种操作属于正常的电网响应或电厂运行策略调整。

![](https://mmbiz.qpic.cn/mmbiz_png/3YDEbeC7QUj3URoDoXAApXmw2nKPNFE7XwwKjfBVYKot86CJXwLQxmJjicDxQoWqO5EDer0sx8q16ZOHlE1889Jp6y1QeFAlL7ewwdxwvVHk/640?wx_fmt=png&from=appmsg)

4月8日新增的临时停堆机组，该机组此前处于运行状态，其临时停运原因需进一步关注，当前临时停堆可能属于计划外的预防性措施，而非重大安全事故。通过观察该机组是在3月8日上午与电网解列开始第7次换料大修，在4月2日观察到状态改为运行，4月8日观察到状态改为临时停堆（小修）。
