→《智能体规范应用与创新发展实施意见》发布

近日，国家网信办、国家发展改革委、工业和信息化部联合印发《智能体规范应用与创新发展实施意见》。

《实施意见》明确智能体发展要坚持安全可控、规范有序、创新驱动、应用牵引的基本原则，并提出了4个方面举措：一是夯实发展基础，完善技术底座，构建标准协议。二是守牢安全底线，明确产品准则，防范安全风险，完善治理体系，强化行业自律。三是强化应用牵引，围绕科学研究、产业发展、提振消费、民生福祉、社会治理等方向，提出19个典型应用场景。四是建设创新生态，促进产业合作，强化应用推广。

→Coinbase x402支付协议原生集成至亚马逊AI智能体支付核心

5月7日消息，Coinbase宣布，将x402支付协议及钱包基础设施原生集成至亚马逊Bedrock AgentCore Payments（AI智能体支付核心）。

此举系Amazon Web Services（AWS）首次在主流云平台为开发者提供原生加密微支付能力，可助力企业级AI智能体自主发现服务，使用USDC完成支付并执行任务，具备合规治理、预算控制、审计追踪功能。结算可在Base、Solana区块链上完成，耗时约200毫秒，费用低于1美分，无需账户、订阅或结账页面。

→Cloudflare宣布在AI重组中裁员20%

路透社报道，美国网络安全服务公司Cloudflare，宣布计划裁员约20%，裁员人数超1100人。Cloudflare首席执行官马修・普林斯（Matthew Prince）表示，此次组织重组是为适配AI工具时代的发展需求，对各团队及职能架构进行重新规划调整。

Cloudflare近三个月内部AI工具使用量暴涨超六倍。本次裁员属于内部业务流程与岗位职能重组的一部分，并非员工个人绩效问题，也不是短期成本压力导致。

→阶跃星辰新轮融资近25亿美元

5月8日，据消息人士向第一财经透露，国产大模型公司阶跃星辰将完成近25亿美元融资，并已拆除红筹架构，加速赴港 IPO 准备。最新融资中产业链资本集中入场，包括华勤、龙旗、豪威、中兴等，覆盖从整机制造到上游核心器件多个环节。截至发稿，阶跃官方暂未回应。

→商汤发布SenseNova Token Plan 首月享每5小时1500次免费额度

商汤发布日日新SenseNova Token Plan，并同步开启限时免费活动。开发者注册后，首月可享每5小时1500次免费调用配，后续将推出 Lite、Pro 等多档位套餐。据了解，SenseNova Token Plan支持商汤日日新SenseNova系列模型，包括新一代轻量化多模态智能体模型SenseNova 6.7 Flash-Lite，原生理解生成统一多模态模型SenseNova U1 Fast等。

→美团公测AI原生社区“觅游”

美团推出AI社区“觅游”，该项目由美团基础研发的AI创新产品团队打造，是面向所有大模型和Agent产品的社区生态，目前已正式进入公测阶段。“觅游”定位为首个让AI Agent拥有身份、关系与成长的共生社区。该社区将“养虾”变成一种全新的生活方式，虾在社区中可以替用户寻找赚钱机会、结识同道伙伴，让用户与虾在协作中彼此成长。

据介绍，美团希望通过发掘和拓展虾的真实价值，将“觅游”打造成一个面向未来的数字生命社区。该项目是美团在AI领域的一次创新尝试。

→腾讯混元高级研究员于文豪加盟OpenAI

5月7日，腾讯混元大模型高级研究员于文豪已于上月加入OpenAI，担任AGI研究员。据介绍，于文豪的主要研究方向为自演进大模型和智能体，学术成果已被引用5700余次，在ICLR、NeurIPS、ACL等顶级会议发表论文30余篇。他在个人社交平台表示，很高兴分享加入OpenAI的消息，期待与杰出的人们一起面对宏大目标，为构建AGI做出贡献。

→Anthropic据称考虑筹资数百亿美元 估值或飙升至近1万亿美元

据英国金融时报报道，人工智能公司Anthropic正考虑今年夏天筹集数百亿美元，以资助大规模扩展计算能力，此举将使其估值飙升至近1万亿美元，超越竞争对手OpenAI。

据报道，新一轮融资预计将对Anthropic的投前估值约为9000亿美元，募资额高达500亿美元。而OpenAI在3月完成创纪录的1220亿美元融资轮后，投后估值为8520亿美元。

→印度支付公司PhonePe推出面向商户的AI赋能集成层

5月6日消息，PhonePe宣布推出面向商户的AI赋能集成层，简化支付网关上线流程。该集成层适配AI编码助手，结合PhonePe专有“集成智能”层，旨在缩短商家集成周期。传统模式下，开发者需耗时数天研读技术文档、处理复杂问题。借助新AI代理，商家通过对话界面即可完成支付网关整合，无需专业技术能力。

→OpenAI开始向用户推出“可信联系人”功能

OpenAI开始向用户推出“可信联系人”功能，扩展安全警报选项，让所有18岁以上的用户都能选择将自己信任的人设为可信联系人。

→OpenAI推出Codex for Chrome浏览器扩展

5月8日，OpenAI正式面向谷歌Chrome浏览器推出Codex for Chrome扩展程序。该工具旨在辅助用户高效完成网页测试、跨标签页上下文读取及DevTools调用等日常操作。扩展不接管浏览器控制权，所有页面与标签页权限仍由用户掌握。此举源于团队发现超八成高频工作流发生于浏览器内，如后台管理、在线文档协作与调试任务。Codex周活用户已达400万，较年初增长8倍。

→亚马逊AI助手Alexa+正式登陆德国市场

5月8日，亚马逊宣布生成式AI助手Alexa+在德国上线。该服务以Early Access测试计划形式率先向德国用户开放，未来几周内分批发送体验邀请。测试期间全员免费；测试结束后，Prime会员可继续免费使用，非Prime用户需订阅，德奥地区月费为22.99欧元。目前Alexa+已覆盖美国、英国、加拿大、墨西哥、意大利、西班牙、德国及奥地利共八个国家。

→商汤发布轻量多模态模型SenseNova 6.7 Flash-Lite

5月8日，商汤科技正式发布新一代轻量化多模态智能体模型SenseNova 6.7 Flash-Lite。该模型面向真实工作流，支持直接理解网页、文档与图表，实现‘看、想、做’一体化。其取消视觉转文本中间层，参数更少但性能跃升，在权威智能体基准测试中达同级别多项SOTA；Token消耗降低60%，响应达毫秒级。同期上线SenseNova Token Plan限时免费活动，并开源全线办公技能SenseNova-Skills至GitHub。

→一亩田发布国内首个农业AI智能体“沃来采卖货助手”

5月8日，一亩田集团在北京正式推出国内首个农业AI智能体“沃来采卖货助手”。该智能体深度嵌入农产品交易场景，具备智能匹配供需、行情报价辅助、自动下单等功能。目前在APP内小流量上线，日均服务约100名农业从业者，覆盖找货源、议价、下单等环节，并已实现单日超1000元商业收入。此举旨在提升农产品流通效率，推动农业数字化交易升级。

→OpenAI发布三款实时语音模型，支持推理、翻译与转录

5月8日，OpenAI正式发布GPT-Realtime-2、GPT-Realtime-Translate和GPT-Realtime-Whisper三款实时语音模型，集成于Realtime API。其中，GPT-Realtime-2具备GPT-5级推理能力，支持打断处理与工具调用；Translate支持70种语言输入转13种输出，同步翻译；Whisper实现低延迟流式转录。三者分别按Token或分钟计费，旨在解决语音交互中的延迟、多语言支持及实时性难题。

→中国电信自主研发“锐鉴·AI代码安全审计平台”

中国电信大可实验室自主研发“锐鉴·AI代码安全审计平台”，以人工智能技术深度重塑代码安全审计模式，致力于为产业链数字化升级构筑智能化的安全新防线。

“锐鉴”平台是中国电信大可实验室100%自主研发的全链路自主可控代码安全审计智能体，平台以国产大模型与增强推理引擎为核心技术底座，构建了可插拔式审计技能调用架构与多层智能审计体系，实现了对业务代码的深度语义理解与全维度安全审查，为产业链数字化升级构筑起智能化的代码安全新防线。

→Robo.ai以1亿美元全资收购Neurovia AI

5月8日，美国Robo.ai Inc.宣布以1亿美元对价全资收购英国Neurovia AI Limited。此次收购旨在加速构建全球AI视频数据基础设施平台。Neurovia AI专注于AI数据处理与压缩技术。交易采用八年期股权解锁机制：交割后前四年零解锁，第四年末起分五年匀速解锁。收购完成后，Neurovia AI将作为Robo.ai全资子公司运营。
