## 完整版：

##

## 1. 写软件 / 编程开发

##

* WebDAV 网页文件管理器 — Flask 后端 + 原生前端 + SQLite（长期 unfinished，缺 CSS/JS）
* 跨平台硬件资产查看器 — Python，支持 Mac/Win/Linux，查序列号、出厂日期等
* Go 版多条件 grep 工具 — 仅实现 `-v` 过滤，支持多 `-v` 多条件（模拟管道）
* 本机 Web 服务导航页 — 端口自动扫描 + SQLite 存储 + 状态着色 + 备注/删除/同步
* 农历/公历生日倒计时 Web 应用 — Python，支持农历生日，展示距今天数
* Oh My Zsh 用法展示页 — HTML + JS，从官网取材，突出效率提升
* macOS 屏保小程序 — Python，小巧，任意键退出
* CMECloud / ZHIPU·GLM-5.1 API 测试与模型探测 — 鉴权、max\_tokens/thinking/stream 探测脚本
* Python 虚拟环境工具横纵对比分析报告 — ~12000 字，含 MD/HTML/PDF 三格式

## 2. Shell / 命令行工具与技巧

##

* 自写 shell 函数：`portinfo`（端口查进程）、`lsw`（文件名转绝对路径）
* SSH 配置：host key 变更处理（`REMOTE HOST IDENTIFICATION HAS CHANGED`）、删除多余空行
* `screen 会话内容查看`
* zellij 介绍；shell 变量（`!$` 等）梳理；macOS 进程树查看
* git status 乱码修复（全局配置）

##

## 3. 网络 / 运维 / 安全

##

* TLS 终止概念 + nginx 示例；mkcert 证书 vs `gitRepo/ssl` 证书对比
* EasyTier 子网代理排查（能 ping 通但无法访问）
* 网络安全 176 号令；网络编程端口段规范；npcap 用法（含网页链接与例子）
* API token 用量统计方法
* 高可用团体标准撰写 — 网络、软件设计、数据库、负载均衡、DNS、备份与恢复

##

## 4. 文档 / 知识 / 网页抓取

##

* 网页抓取转 Markdown（Spotlight English 文章、瀑布流书单等）
* 知识库检索（高可用相关文章）
* AI spec 文档标准探讨
* 高可用团标写作

##

## 5. 影视 / 娱乐推荐

##

* 2023 年电影推荐
* 近期流行高赞国产电视剧 / 电影推荐（含 movie-recommender 技能）
* 《钢铁侠》剧本冲突与小高潮设计分析

##

## 6. 概念学习 / 答疑

##

* Electron 是什么、能干什么
* 大模型 TTFT 全称与含义
* UPS 中 kVA 单位
* TLS 终止
* Claude Code 资料收集
* 大模型百万 token 定价对比（kimi-k3 / glm-5.2 / deepseek-v4-pro）
* Excalidraw AI 插件
* good good study 是否进牛津词典

* ima 进程清理
* 技能加载（study-planner / movie-recommender）
