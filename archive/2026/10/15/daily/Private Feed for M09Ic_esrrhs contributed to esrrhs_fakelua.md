## Background

Differential testing against a locally built **Lua 5.4.9** oracle (the system only ships 5.5), running each case on all three backends (TCC / GCC / interp), surfaced four systematic semantic divergences. This PR fixes them plus 25 required-argument guards that fell out of fix 3.

Oracle setup used for review reproduction: compile `lua-5.4.9/src/lua` locally, then run the case files through `flua --jit_type=0|1|2 --entry main` and diff against `lua`. New case files covering arity (35 cases), table-field/pcall (12), missing-argument (35) and iterator/callback (11) all report **zero divergence** after this PR.

## Bug 1 — native functions used as values

`local t = type` / `pcall(table.concat, t)` compiled and then failed at runtime with a misleading message. `semantic_analysis` now rejects native functions used as values at compile time; `math.pi` / `string.charpattern` (field reads on native tables) stay valid.
