做公众号、做小红书、拍短视频、写干货长文…… 最头疼的永远不是`idea`，而是执行：搜资料、定选题、写稿、配图、做PPT、剪视频、排版、分发……一个人要当十个人用。现在，整理了一份中文内容创作者必备 Skill 大礼包，把整个内容产线几乎全覆盖了。

这 10 个 `Skill` 全是 `GitHub` 上经过实战验证、高星开源项目，直接导入 `Claude / DeepSeek / Cursor` 就能用，免费且强大。

## 顶级 10 个内容创作 Skill 推荐

1.`guizang-ppt-skill`（归藏） —— 17k star

内容创作类最强 Skill。一句话生成杂志级或瑞士风 HTML 演示稿，自动配图、封面、动效。作者把十年设计经验浓缩其中，做汇报、做分享直接省一晚上时间。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/4T1PVwJicwk8axodoYVds9A2BldASdrTH5o3rP6RZm1E4dnDWibX1eAyCq3nWy5R1QSpamUwNQ5P0ficsuTLQcKzaUiaqTg2YBbYjnTVAVdm270/640?wx_fmt=png&from=appmsg)

```
https://github.com/op7418/guizang-ppt-skill
```

2. `guizang-social-card-skill`（归藏） —— 3.5k star

   一段文字秒出小红书竖版轮播图 + 公众号封面图。28 套版式、10 套主题，一键导出 PNG，再也不用自己抠排版。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/4T1PVwJicwk8edhfrRlE2gdeJ2WS7q0HAw8zecoEsSjO8VLIicAOJDapicZRbxAicrrhFcibkFw7gea7BH4XROJYbOazlnibBs5HWiayY8vdSyUCA8/640?wx_fmt=png&from=appmsg)

```
https://github.com/op7418/guizang-social-card-skill
```

3. `awesome-gpt-image-2`—— 7.3k star

   目前最火的生图 Skill。内置 470+ 张爆款图反向提示词 + 20 多套工业级模板，文章配图、海报、封面直接套用，效率爆炸。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/4T1PVwJicwkicoBkD7bwX92b0pRA2voSibFA6BOPxNI7CNUoW8gfzH3fwWfK8ajYXTEDkmLDmia9JoFMkqGDvNa37TIMOydmhto545njzL0jeUo/640?wx_fmt=png&from=appmsg)

```
https://github.com/freestylefly/awesome-gpt-image-2
```

4.`Humanizer-zh` —— 10k star

中文写作者人手一个。把 AI 味极重的“翻译腔”“空话套话”改成自然人话，发文前必过一遍。

```
https://github.com/op7418/Humanizer-zh
```

5.`Deep-Research-skills` —— 1.1k star

深度研究神器。让 Agent 自动列大纲、分头查资料、汇总带出处报告，写干货长文前先用它备料。

```
https://github.com/Weizhena/Deep-Research-skills
```

6.`anything-to-notebooklm` —— 5.1k star

一稿多用神器。把公众号文章、PDF、网页、视频丢进去，一键转播客、PPT、思维导图、测验，多平台分发直接起飞。

```
https://github.com/joeseesun/qiaomu-anything-to-notebooklm
```

7.`wewrite` —— 2.3k star

公众号一条龙 Skill：抓热点、定选题、写正文、SEO、配图、排版，最后还能直接推送到微信草稿箱，一个人顶一个编辑部。

```
https://github.com/oaker-io/wewrite
```

8.`Youtube-clipper-skill（归藏）` —— 2k star 长视频自动切短视频神器。自动找高光时刻、配字幕，剪切片号、二创素材效率大幅提升。

```
https://github.com/op7418/Youtube-clipper-skill
```

9.`oh-story-claudecode` —— 2.4k star

小说/网文选题脑暴利器。自动分析番茄、晋江、知乎爆款，提炼热门题材、人设、开篇方式，还能逆向拆解爆款逻辑。

```
https://github.com/worldwonderer/oh-story-claudecode
```

10.`marketingskills` —— 33k star

GitHub 上 Star 最高的营销 Skill 库，32 个技能覆盖文案、SEO、转化、品牌定位，特别适合做出海和带货内容。

```
https://github.com/coreyhaines31/marketingskills
```

这套 Skill 几乎覆盖了从选题 → 创作 → 视觉 → 分发的完整内容生产链条。

把它们导入你的 Claude / DeepSeek 项目后，内容创作效率能提升 3-5 倍不止。尤其是做公众号、小红书、知识付费的朋友，强烈建议全部收藏。
