[Edwards](/~Edwards) (42866)发表于 2026年04月29日 21时16分 星期三 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=84184&appkey=1370085986&title=%E8%8D%B7%E5%85%B0%E6%94%BF%E5%BA%9C%E4%B8%8A%E7%BA%BF%E5%BC%80%E6%BA%90%E4%BB%A3%E7%A0%81%E6%89%98%E7%AE%A1%E5%B9%B3%E5%8F%B0 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自巨龙之夜**

荷兰政府上线了它自己的开源代码托管平台 code.overheid.nl。该平台是基于 Forgejo——Forgejo 是 Gitea 的分支，是一个类似 GitHub 的 Git 软件开发和版本控制平台，支持 bug 跟踪、Wiki 和代码审查等功能。该平台托管于荷兰政府基础设施之上，所有政府机构都可以免费使用。荷兰政府表示此举是加强数字主权行动的一部分。
https://www.nldigitalgovernment.nl/news/soft-launch-for-government-open-source-code-platform/
https://code.overheid.nl/
