# 岁月是把猪饲料

2026年3月20日 10:54
[43 条评论](https://zhongxiaojie.cn/2026/03/654/#comments)

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/微信图片_20260320095801_611_42.jpg)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260320095801_611_42.jpg)

前段时间，孙燕姿开演唱会，网上的评论都是变胖了，以及说什么穿着不合体，不好看之类的。

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/4ec2d5628535e5dd848ce3692780c6fecf1b62bf.webp)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/4ec2d5628535e5dd848ce3692780c6fecf1b62bf.webp) [![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/6c224f4a20a446233fb7c3fec964131f0df3d780.webp)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/6c224f4a20a446233fb7c3fec964131f0df3d780.webp)

只是变胖的又何止是她，还有好多人也都变胖了。曾经的女神，现在变成胖女神了，还有人调侃石矶娘娘的。

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/aa18972bd40735fa991c07b66604e0a30e2408b3.webp)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/aa18972bd40735fa991c07b66604e0a30e2408b3.webp)

然而，女神们也曾经风华正茂，身材婀娜过啊。

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/8cb1cb134954092374417185e0ff8e18b2de495d.webp)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/8cb1cb134954092374417185e0ff8e18b2de495d.webp)

说到穿衣造型，其实作为一个胖女生，可塑空间就变得非常小，很多衣服或者穿搭就没那么合适，所以有时候不能全怪造型师，也不能全怪变胖的女神们。

毕竟在时光的洗礼下谁又不胖，最近带着对象运动，然而，确时常听到：『我现在吃的不多啊，还蹭蹭的长肉。现在连吃都不能吃了，还有什么乐趣？』

减肥的时候真的挺没乐趣的，第一次去拍写真的时候，肚肚还非常的突出，第二次去拍的时候，摄影师甚至问，『你上次拍照的时候带的那个束腰带了吗？』

然而，那个束腰第一次没用上，第二次想用的时候已经被我扔了。以前在记得时候，偶尔用一次对象总说：『那玩意儿不管用，你少戴吧』

真正开始减肥了，还是靠控制饮食和运动，当然，最主要的运动就是跳绳。昨天晚上在家跳的时候，竟然断了。

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/微信图片_20260320103836_614_42.jpg)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260320103836_614_42.jpg)

重新插回去之后就变得一个长一个短了，等哪天看看把那根长的也调整下。跳绳一年多，右手可能是握姿有问题，竟然磨出了茧子。翻了下记录，才发现真的挺久了。

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/微信图片_20260320103616_612_42.jpg)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260320103616_612_42.jpg)

至于跑步，其实这两年跑的并不多，主要集中在还有跑步机的时候。

[![](https://zhongxiaojie.cn/wp-content/uploads/2026/03/微信图片_20260320103710_613_42.jpg)](https://zhongxiaojie.cn/wp-content/uploads/2026/03/%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260320103710_613_42.jpg)

不过那时候跑步却没有变瘦，真正减肥还是去年，一共减掉了40斤，今年的目标是再减掉10斤。不过这个周期可能就比较长了。

岁月的猪饲料是平等的，雨露均沾，谁都躲不过，看身边的男人，多数一个个都停着大大的肚子。女生也一个个的出现了小肚子，哪怕是还没有结婚的那个同学，身材也开始走样了。

谁都想一直好看，然而，不是所有人都能抗住岁月的变迁。

好看一天是一天，就酱紫吧。
