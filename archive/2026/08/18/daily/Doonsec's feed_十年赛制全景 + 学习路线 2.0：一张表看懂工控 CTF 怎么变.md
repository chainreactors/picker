# 第一届到第九届（2017–2025）：每届决赛到底考啥

2026年8月 · JxSpark战队

期 14 讲的是 2026 第十届的**初赛**（复赛/决赛还没打）；这篇把前面**九届**（2017–2025，已完赛的）决赛，从官方手册 / 方案 / 复盘里扒一遍，看每届到底考啥、怎么一路变过来的

---

期 14 我们把 2026 第十届工控安全锦标赛的**初赛题目**拆了——复赛、决赛都还没打，那一篇只是初赛的阶段的考核。有读者问：你这号从 Modbus 讲到梯形图、又讲到车联网和锦标赛，除了开篇的时候带了一段赛事演进，前面这九届（2017–2025）复赛和决赛到底考啥？这篇就回答这个。我手里有各届的官方手册、方案、复盘，也攒了一些题目，把它们摊开，重点把每届决赛考啥从文档里抠出来，再试着总结几条规律。

**先说清，**各届的官方手册 / 方案 / 复盘我大多有，从上面能说清每届决赛是什么形式、考哪些方向。但我当年没有特意去梳理收集材料，所以手里并不全，有些年份决赛纯场景赛题而且没写wp导致可能记忆有偏差。

## 一、九届决赛形式

| 届 / 年 | 决赛形式 | 决赛考向 |
| --- | --- | --- |
| **第一届 2017** | 线下靶场 / 场景解题：工业物联网数据采集系统（物联网网关采智能电表数据转发到采集工作站），三级得分点判分 | 物联网网关协议转发、KepWare / QP452 / iEmbed 软件；交付物是「检测报告」（填检测工具 / 入口 / 参数 / 步骤截图） |
| **第二届 2018** | 线下攻防沙盘对抗（A&D 轮换）：10 套独立沙盘，每队先加固 ≤2h 再按攻击清单打他队，每套 5 个得分点 | 10 个行业场景（采油 / 输配电 / 轨交 / 风电 / 燃气 / 楼宇 / 交通 / 水处理 / 智能制造 / 化工），篡改组态画面、控制工艺流程；PLC 全系列（AB / 三菱 / S7-300/1200/1500 / 施耐德 / 欧姆龙 / GE）+ HMI（组态王 / 力控 / WINCC） |
| **第三届 2019** | 线下场景赛，连续两天，交 WriteUp + 报告 | 系统修复加固、漏洞挖掘分析、系统应急修复；真实工业场景（智能制造 / 水处理 / 化工） |
| **第四届 2020** | 巡回赛分站+半决赛实网攻防+决赛场景渗透+实体设备漏洞挖掘 | 硬件设备漏挖、场景渗透、工控层攻击（Fuzz 寄存器 / 停止命令）、业务场景攻击；任意文件上传 / SSH·VNC 弱口令 / MS17-010 双网卡横向；巡回赛考 MMS / Modbus / S7comm / OPC / 固件 / S7-200 密码 / Omron Fins |
| **第五届 2021** | 分靶场互联线下靶场（主赛场转播分靶场攻防），开放式出题，含渗透 / 网络评估 / 设备加固 / 应急取证 | 城市水务沙盘、核电、智能电厂；身份植入（Redis 未授权写公钥、弱口令、445 永恒之蓝拿权限），每轮交决赛报告（资产信息 + 身份植入步骤截图） |
| **第六届 2022** | 对抗赛（OpenVPN 接入、8 入口轮换）+ 多赛道锦标赛（望岳杯 / 江苏 / 电信 / 钢铁） | 按锦标赛参考：工业数据安全技术对抗、MMS / 恶意文件 / 留痕取证 / 密文破解 / 输配电 / 水电厂运维；钢铁赛道（烧结产线 / SCADA / 后门 / 应急） |
| **第七届 2023** | 线下闯关五轮 × 五关卡（5G + 工业乐高 + 无人机 + 边缘云）：数据采集、无人机测绘、工程分析、定点攻击、安全加固 | 三大场景（数字化运营 / 智能化运维 / 绿色化生产），石化 / 污水处理 / 石油 / 机器人 / SCADA；决赛含火力发电 / 车联网 / 轨交 / 数据跨境 / 智能制造 / 5G+石化 |
| **第八届 2024** | 多赛道并行全国总决赛；AI 靶场智能打靶（登录、选靶标、补全检测算法代码、打分） | AI 安全（深伪 / 投毒 / 对抗检测，DeepfakeBench / resnet18 / res50）；智能家电 IoT·ICS（Web / 协议 / 固件 / 逆向 / 密码 / Modbus / 组态王 / Unity Pro）；水电厂仿真；信创 PKS |
| **第九届 2025** | 第九届全国总决赛（南京，工控安全运维，50 队 / 200 人），从本届开始以国产工控为主，西门子、施耐德等估计退出历史舞台 | 工业数字孪生、国产底座（翼辉 / 东土 / 蓝卓）；涉及PLC 梯形图工艺运维 + 后门检测；工艺流程应急与恢复；工控实验箱工艺流程编写及还原；低代码平台工艺流程构建及测试；此外还是保留了一个场景是常规的CTF夺旗赛制（估计是怕纯CTF选手决赛挂零） |

## 二、考点归类（从历年题目和手册里归的）

这些考点是把历年攒下来的题碎片和手册过了一遍，能反复撞上的归成一类，能看出走向的就标出来，方便按图索骥。

| 考点类 | 考什么 | 本号对应篇目 / 真实题 |
| --- | --- | --- |
| **协议解析与重放** | S7COMM / Modbus / MMS / IEC104 / OPC / FINS / MQTT / JT808 功能码审计、Write Var 提取、重放写控制 | 期 2–6、期 14 |
| **固件逆向** | VxWorks 符号表修复、PowerPC / ARM / RISC-V / mipsel 加载、XOR / 加密载荷 | 期 14 网关固件 / Driver |
| **PLC 与组态逻辑** | 梯形图推理、组态工程密码绕过（力控 / 组态王 / Unity Pro）、国产 PLC（和利时 / 台达 / 翼辉）、IEC 61131-3 | 期 7–12、2025 决赛 |
| **场景渗透** | 资产发现、Web 入口、内网横向、控制层抵达、远程取证 五阶段 | 期 13 车联网、期 14 渗透、2020/2021 决赛 |
| **漏洞挖掘与加固** | 工程加密机制漏洞、被动 / 主动 Fuzz、启停攻击、UMAS 后门、系统修复加固报告 | 期 14、2017/2018/2019 决赛 |
| **密码与隐写** | 古典 / 现代密码、LSB / 图像隐写、文件嵌套、国密（SM2 / SM4 / SSL VPN） | 期 14 Crypto、2025 密码应用安全 |
| 车联网安全 | CAN / UDS 报文、BLE / WiFi 近场、侧信道、ECU 固件、TSP / APP 鉴权 | 期 13（22 题）、2023 决赛 |
| AI 安全 | 对抗样本、模型投毒与检测、深伪、提示注入、检测算法代码补全打靶 | 2024决赛/2025巡回赛 |

## 三、从九年决赛手册里看出来的几条规律

把这些手册和题翻完，可以看到如下几个规律：

**① 决赛靶场越来越「真实、实物」。**2017 是物联网数据采集系统（网关 + 电表 + 指示灯），2018 直接上 10 套行业沙盘（采油 / 轨交 / 化工…），2023 是 5G + 工业乐高 + 无人机 + 机器人，2024 / 2025 是水电厂仿真、工业数字孪生。越往后越不像「做题」，像「进现场」。

**② 交付物从「解 flag」变成「交报告、交加固、交代码」。**2017 / 2018 交检测 / 加固报告，2021 交场景渗透报告（资产 + 身份植入），2024 AI 靶场交检测算法代码，2025 数字孪生重「可信系统全链条构建」。纯夺旗在决赛里基本没了。

**③ 工艺和合规的权重压过了纯逆向。**2018 就要懂 10 个行业的工艺（篡改组态画面、控制工艺流程），2023 绿色化生产要会动台达机器人 / SCADA 启停，2025 要会修 ModbusTCP 链路参数和控制逻辑。不认识 PLC / 组态 / 现场工艺，决赛进不去。

**④ 协议四件套（Modbus / S7COMM / IEC104 / MMS）是永远的底盘。**哪届都在，新方向（车联网 2023、AI 安全 2024/2025、国密 2025、国产底座翼辉 / 东土 / 蓝卓 2025）是往上叠的，不是替换掉旧考点。

**⑤ 赛道越分越细。**2022 起分钢铁 / 电信 / 家电 / 石化等赛道，2025 干脆六大锦标赛（工控 / 车联网 / 石油 / AI / 密码 / 典型场景）并行。一个战队很难再「全吃」，得有专项。

## 四、怎么练（给不同底子的人）

别一上来就刷传统 CTF。工控题的核心是「协议 + 逻辑 + 现场工艺」，这三层不过，决赛基本悬空。

**纯新手：**先把四个协议（Modbus / S7COMM / IEC104 / MMS）过滤器敲熟（期 2–6），再上梯形图（期 7–12）。

**有 Web / 逆向底子：**协议四件套快速过，重点补梯形图这个「母语」和组态软件（力控 / 组态王 / Unity Pro），再进真实场景。

**工业背景（自动化 / 运维）：**梯形图你天然熟，短板在逆向和渗透链，补 pyshark / scapy 取证脚本和场景渗透五阶段；顺便把「交加固报告 / 应急修复报告」这套制式报告格式摸熟——决赛就考这个。
