《战略评估》（Strategic Assessment）是一份多学科交叉的同行评审期刊，探讨以色列国家安全和中东战略问题，由特拉维夫大学国家安全研究所（INSS）以希伯来语和英语出版。该期刊经以色列高等教育委员会规划与预算委员会认可，旨在为国家安全、网络空间和情报等领域的原创研究提供平台。期刊致力于激发和深化对国家安全研究基本问题的深入探讨，并将理论层面与政策导向的研究相结合。

这份关于联合国停战监督组织（UNTSO）的研究报告。这是一份由以色列国家社会保障研究所（INSS）于2026年2月发布的战略评估文件，作者是迭戈·萨拉马博士。

一、文件背景与核心议题

1.1 关键背景事件：安理会第2803号决议

2025年11月17日，联合国安理会通过第2803号决议，批准设立：

"国际稳定部队"（ISF）：临时性军事存在

"和平委员会"（BoP）：具有国际法人资格的过渡性行政机构，负责加沙重建框架制定与资金协调

核心悖论：该决议完全绕过了联合国在中东历史最悠久、根基最深厚的机构——联合国停战监督组织（UNTSO，成立于1948年），尽管UNTSO拥有新机制无法立即复制的资源、经验、渠道和机构记忆。

1.2 作者的核心论点

作者认为，第2803号决议对UNTSO的忽视并非意味着该组织已经过时，相反：

这暴露了机构惯性的代价

为在保留其授权的同时进行改革创造了契机

UNTSO仍拥有临时机制难以复制的独特优势

二、UNTSO的历史资产与战略价值

2.1 "单一维度"和平行动的回归

UNTSO属于后冷战时期常被忽视的"较早的、单一维度"观察员任务类型：

核心职能：监督停火、稳定接触线、管理突发事件

特点：无强制执行权、无国家建设目标

战略价值：在高风险地缘政治区域进行遏制，为脆弱的大国共识创造空间

2.2 纵向调整历史（1948-2024）

时期   关键适应

1948-1967  停战监督与联络，混合停战委员会运作

1967-1978

1967年失去总部后仍保持运作，填补UNEF I撤离后的真空

1973年后为UNEF II、UNDOF（1974）、UNIFIL（1978）提供孵化支持

至今  "先锋快速部署能力"，持续支持区域特派团生态系统

2.3 三大制度资产（即使在政治不信任环境下）

1. 嵌入式联络职能

在缺乏正式对话时发挥预防作用

减少误解，提供升级窗口期的信息传递渠道

价值来源于程序可预测性，而非政治信任

2. 常设能力基础与公信力

2024年5月数据：152名军事观察员（30国）+ 211名文职人员（47国籍）

培训、战略分析、结构化信息交流机制

与UNIFIL、UNDOF的观察员联系网络

3. 政治持久性

即使在以色列普遍怀疑联合国的背景下，以方官员仍倾向UNTSO继续存在

开放式的区域授权被认为对灵活执行和调整尤为重要

三、柏林改革框架与现代化路径

3.1 2025年柏林部长级会议的核心导向

模块化维和：组合不同模式、能力"包"，根据形势调整

能力导向：从象征性存在转向可衡量的行动绩效

技术整合：监视技术、开源情报、数据驱动方法

3.2 与UNTSO相关的三种模式

模式  描述   与UNTSO关联

模式4

停火监测和观察

UNTSO的历史核心职能

模式5

监测、观察和报告

扩大观察范围

模式6

核查

小型专家团队调查核实

3.3 现代化三大要务

1. 严格限定职责范围

专注：核查、报告、联络

避免：建设和平、人权调查、政治调解（防止"角色冲突"）

2. 技术整合

无人机（UAV）、开源情报（OSINT）、商业卫星图像

应对加沙密集城市地形、地下基础设施等挑战

3. 人员多元化与区域合法性

保留传统贡献者（挪威、瑞典、加拿大、奥地利）的核心专业知识

纳入阿联酋、约旦等区域行为体

四、针对加沙的具体模式设计

4.1 战略互补性原则

UNTSO不应成为加沙安全安排的主要执行机构，而应在边缘地带提升：

核查可靠性

事件澄清能力

4.2 "技术补充"而非"任务扩展"

面向加沙的方案是有时限的附加机制

在UNTSO现有授权下运作

配备模块化能力包、情报防火墙和争议管理机制

4.3 事件生命周期与争议管理（7步流程）

通知 → 分类 → 收集 → 初步调查结果 → 申诉窗口 → 澄清 → 结案

关键创新：将"分歧"视为正常产出类别，而非危机情况

4.4 三级失效模式与应对

级别  描述  触发条件   响应

第一级：例行分歧

机制符合基准

争议案件率<30%，结案时间≤48小时

继续运作，分歧作为数据点跟踪

第二级：系统性信誉压力

未解决争议或基准下滑

争议率>50%，结案时间>72小时，三次以上访问被拒

模式切换：缩小参数范围，启动独立审计

第三级：灾难性故障

与中立、安全或完整性不相容

人员遇袭、持续拒绝通行、系统性违反监管链

暂停和重新部署：暂停加沙特定SOP，人员重新部署至区域任务

五、信任架构：受控分歧协议

5.1 核查机制的冲突降级逻辑

核心影响：行为层面（降低不确定性、约束机会主义解读），而非关系层面

不需要政治信任，但需要：可预测的准入、严格的证据门槛、常规化流程

5.2 情报防火墙（四约束）

1. 来源限制：仅限直接观察、经认可的传感器输出、有据可查的公开信息

2. 证据链规则：时间戳、可审计、与证据清单关联

3. 不共享规则：禁止充当向外部行为者的情报渠道

4. 目的限制：严格限定于约定的验证参数集

5.3 东道国同意的维持机制

并行技术协议：双边、任务相关的交流，而非三方谅解备忘录（避免承认陷阱）

短期可续期审查周期：12个月可续期周期 + 预先商定的绩效评估

主权敏感界限：明确禁止角色扩张（如更广泛使用武力调查、平民伤害评估等）

六、政策建议与实施路径

6.1 对以色列的价值主张

与现代化UNTSO合作并非"让步"，而是：

风险管理工具：低调的事件澄清和冲突降级渠道

不要求政治信任

不要求正式承认对立政权

不会将加沙变成联合国永久的治理据点

6.2 对联合国的价值主张

通过绩效实现机构生存：证明秘书处能够使旧任务适应当前威胁形势

保护联合国免于陷入承诺无法实现的声誉陷阱

以可行性为核心，而非修辞上的吸引力

6.3 三步实施路径

步骤  内容  目的

1. 技术协议优先

通过双边技术协议或平行信函交换建立接入点、联络渠道和核查参数

将业务合作与承认政治脱钩

2. 限时试点

6-12个月试点运行，受最低运作要求（MOR）、情报防火墙和事件生命周期约束

验证可行性，明确可逆性

3. 定期绩效评估

依据失败层级进行模式切换和暂停，而非视为尴尬结果

保护人员和UNTSO现有区域作用

七、核心结论

作者提出\*\*"约束现实主义"\*\*的现代化路径：

"如果联合国和以色列希望UNTSO不仅仅是一个历史遗留机构，他们必须将改革视为在各种限制条件下需要解决的绩效问题，而不是一项旨在拓展其授权范围的愿望。"

最终选择：

路径A：将UNTSO现代化为以有效管理分歧为核心的模块化核查平台 → 继续发挥切实作用

路径B：维持现状 → UNTSO在体制上继续存在，但在战略上逐渐消失（"最糟糕的结果"）

八、文件特色与学术价值

1. 创新性：将"过时"的单一维度维和机制重新定位为当代冲突的适应性解决方案

2. 务实性：直面以色列对联合国的深度不信任，将其作为设计约束而非障碍

3. 系统性：整合历史分析、机构理论、柏林改革框架和具体模式设计

4. 政策相关性：为2025年后加沙安全架构提供具体的替代方案

这份报告代表了联合国维和研究中"回归基础"的重要思潮，强调在高度政治化环境中，程序可信度可能比政治共识更具战略价值。

一、核心命题：以色列国防军的"缺失环节"

1.1 背景：2023年10月7日的战略觉醒

作者指出，10月7日事件不仅暴露了战术失败，更揭示了以色列国家安全理论中"概念"（conceptzia）的深层崩溃：

以军兵力部署优化侧重于静态监控、遏制和防御性安抚，而非作战主动性

对手通过导弹、无人机、网络战、法律战和海上压力等手段不断调整策略

以色列的行动自由在多个维度日益受限，尤其是海上咽喉要道

1.2 核心诊断

"以色列缺乏能够将主动性转化为持续优势的作战规模手段"

现有能力存在结构性缺口：

二、战略环境："战略压缩"（Strategic Compression）

2.1 概念定义

战略压缩指以色列行动自由的逐步收窄——并非通过常规入侵，而是通过协调一致的多方向包围，利用时间优势，使以色列陷入被动应对的恶性循环。

2.2 多矢量包围格局

作者绘制了令人担忧的地缘政治图景：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/no8YFGgia2NHT7FwU6iapke0yxL1WchQzY8UsuHY8fnVVjovQLlrGMYWKemtRsTOurj16ibQFA2icSoIfy5jmzAZa8GLkknEZSbyYF9ZzVDf9pE/640?wx_fmt=png&from=appmsg)

关键动态：

伊朗"章鱼主义"：协调伊拉克、叙利亚、黎巴嫩、也门、加沙的民兵和无人机活动

土埃海军合作：2025年9月"友谊之海"联合演习——东地中海两大海军强国可能合作

大国介入：中国（港口投资）、俄罗斯（武器转让和海军存在）

2.3 海上咽喉要道的武器化

历史先例表明：

1967年：蒂朗海峡关闭

2018年以来：土耳其干预塞浦路斯近海钻探

当前：红海封锁，埃拉特贸易流量骤减

"马汉关于贸易国家海上优先地位的洞见尤其适用：一个经济命脉依赖水路的国家，必须将海上航道、能源码头和港口视为战略机构，而非民用基础设施"

三、解决方案：以色列远征军司令部（TEC）

3.1 概念定位

![](https://mmbiz.qpic.cn/mmbiz_png/no8YFGgia2NHl4qgfwK7u0DccL1HoDXYPOhk4QZ7Kpygp6rkySxuZYS1ia2UTVUkJ5nP5YmQBBAc6HJXu67j2eLxYq8zk3tXt6EGsIpMWQdJg/640?wx_fmt=png&from=appmsg)

3.2 五大指导原则

1. 主动出击而非被动应对：塑造接触而非被动承受

2. 海上机动：将海洋视为作战媒介

3. 可逆性：保持操作有时限性

4. 系统性破坏：目标是敌方力量的根基，而不仅仅是领土

5. 整合而非替代：补充空军、特种部队和动员地面部队

3.3 作战理论："系统性破坏理论"

"不是千刀万剐，而是百刀齐下，造成的损失远远超出其规模"

核心机制：

分散部署以求生存，仅在需要时集中兵力进行决定性打击

作战脉冲而非永久驻扎：短时、高强度、自主续航3-10天

累积性认知压力：使敌方决策周期超负荷运转，导致系统性瘫痪

四、组织架构：模块化旅系统

4.1 六大特遣部队旅

![](https://mmbiz.qpic.cn/sz_mmbiz_png/no8YFGgia2NGAYibLfMrXdaG5F6EkQqtxj59eJypO3PKYJtpd4A0Ia6euR0lKZ3kNXZAO3Dz9Leibf2TmsSN20r9s5LficSVfJqYAsIMRvwD8icw/640?wx_fmt=png&from=appmsg)

4.2 战术单元："舱体"（Pods）

模块化"小组"：可包含来自多个TEC旅的兵力

独立运行、快速部署

任务指挥：目标明确，执行分散，与更广泛作战设计保持连接

撤退武器化：触发拒止协议、虚假数据追踪、误导行动

五、技术支柱："Ma'arakhat Or"（光明系统）

5.1 概念

分布式认知基础设施，而非单一AI平台：

每个模块化单元集成强化型边缘计算套件

实时处理战场输入：热信号、无人机行为、信号异常

秒级更新传播：重新校准目标逻辑、打击方案、移动模式

5.2 作战效果

"大多数军队需要数年时间才能完善作战理论，而TEC只需数天即可完成调整"

通过刻意制造不可预测性：

不断调整攻击方向、电子战阵型、部署顺序

确保作战行动不会重复

敌方反制措施在形成之前就被失效

六、实施路径：十年三阶段建设

6.1 投资规模

总额：3120-4240亿新谢克尔（840-1150亿美元），分十年投入

占GDP比重：增加约1.5%-2%

对比：持续战争已造成约5400亿新谢克尔（1500亿美元）损失

七、产业与联盟战略

7.1 工业主权：从"精品创新"到"国家平台"

瑞典模式借鉴：

鹰狮战斗机、A26潜艇：开放式架构、模块化有效载荷、出口导向型设计

补偿贸易作为学习阶梯：合作开发→许可生产→设计权限

以色列路径：

专注：无人机、隐形快速攻击艇、导弹和水雷系统

采购：大型水面舰艇和潜艇（纳入联合生产和技术转让条款）

供应链：地下生产设施、分散物流、加固存储节点

7.2 美以联盟的"毕业"

"从依赖走向互惠互利，从补贴走向共同开发和共同出口"

美国角色：合作开发平台的出口担保人，提供北约/欧盟/海湾/亚洲市场的认证和政治支持

以色列承诺：遵守STANAG和开放架构标准，确保互操作性

关键条款：合作开发完成后，华盛顿不能否决符合标准的以色列第三方销售

7.3 区域联盟网络

东地中海：希腊、塞浦路斯

红海/印度洋：埃及、海湾国家、印度

远东：韩国、日本（部分合作）

TEC作为区域海上秩序的保障者，将以色列存在融入共同的商业安全叙事。

八、治国方略要求

8.1 法律与制度保障

《海洋主权法》：确保多年期非党派预算拨款

国家海洋工业基地管理局：使计划免受联盟失灵影响

每月采购委员会、每季度作战测试、年度公开/保密混合报告

8.2 人力资本

"蓝色学院"：海法、阿什杜德、阿什凯隆、埃拉特的军民结合职业教育

专业领域：海洋机器人、自主系统、流体动力学、合成材料、功能材料工程

研究生课程：流体动力学与运筹学、网络物理安全相结合
