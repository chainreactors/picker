Anthropic已正式停止第三方 AI 代理对 Claude 订阅的访问，这标志着用户在公司原生生态系统之外利用其模型的方式发生了重大转变。

据Anthropic Claude Code执行官 Boris Cherny 称，从今天（4 月 4 日）太平洋时间中午 12 点（英国夏令时晚上 8 点）开始，Claude Pro 和 Max 用户将无法再使用其现有订阅限额来运行第三方自动化工具，例如OpenClaw。OpenClaw是一款流行的开源 AI 代理框架，广泛用于电子邮件管理、网页浏览和智能家居自动化等任务。该限制首先针对 OpenClaw 实施，并将在未来几周内推广至所有第三方工具。

Anthropic 的消费者服务条款从技术上讲至少从 2024 年 2 月起就禁止未经授权的第三方工具访问，但多年来执行力度一直很松懈。

许多 OpenClaw 用户利用OAuth 身份验证漏洞（与 Claude Code 使用的登录方法相同），以固定的月费将订阅级别的 Claude 模型导入到他们的个人代理中。

Anthropic 于 2026 年 2 月正式修改了其条款以弥合这一差距，明确表示 OAuth 身份验证现在仅保留给 Claude Code 和 Claude.ai。

此次整顿行动的部分原因是问题的严重性。Anthropic 在通知邮件中指出，第三方线束对其基础设施造成了“过大的压力”，必须优先保障使用其核心产品的客户的资源。

Steinberger 表示，他和 OpenClaw 董事会成员 Dave Morin “试图说服 Anthropic，但我们取得的最好结果只是将此事推迟了一周。”

希望继续将第三方代理集成到其 Claude 账户的用户现在有两种选择：启用按需付费的“额外使用量”计费方式（费用与订阅费用分开收取），或使用标准 Claude API 密钥进行身份验证，并按 API 使用量计费。

为了减轻经济压力，Anthropic 将提供一次性抵扣，金额相当于用户的月度订阅费用，可在 4 月 17 日前兑换。此外，预购额外使用量套餐还可享受高达 30% 的折扣。选择不按新条款继续订阅的用户也可选择全额退款。

此举引发了开发者和高级用户群体的强烈反对。许多依赖 OpenClaw 和 Claude 工作流程的用户反映，现在每次交互的成本在每个代理任务 0.50 美元到 2.00 美元之间，这使得自主代理用例对于业余爱好者和独立开发者而言在经济上不可行。

批评人士认为，Anthropic 公司在推销智能体工作流程的同时，限制了构建这些工作流程的最经济实惠的途径。

这项政策转变凸显了人工智能行业更广泛的紧张关系，一方是致力于基础设施货币化的人工智能公司，另一方是寻求以开放、统一价格访问前沿模型的开发者社区。
