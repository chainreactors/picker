## Summary

* Fix native/JIT crashes and undefined behavior found in a library review: signed-division UB (`INT64_MIN // -1`), integer `for` overflow, float `2^63` as int64, table rehash `pairs`/`next` duplicates, `table.sort` NaN, `pcall`/`gsub`/`table.sort` callback arity, `FlCallClosure` >32 args, NativeObject tombstones, and `FakeluaDeleteState` per-state cleanup.
* Fix obvious wrong results: specialized-table `#` using `spec_count`, `os.time` reading stale `quick_data_` after rehash, JIT table float indices, `table.insert` OOB/`mininteger`, `string.gsub` table lookup after rehash, integer APIs that silently truncated `2^63`/NaN, utf8 negative offsets, MyS...
