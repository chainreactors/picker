# New Release: Tor Browser 15.0.25

by [ma1](/author/ma1)
| October 12, 2026

![](/new-release-tor-browser-15025/lead.png)

Tor Browser 15.0.25 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.25/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.24 is:

* All Platforms
  + Updated Tor to 0.4.9.14
  + Updated NoScript to 13.6.36.1984
  + Updated OpenSSL to 3.5.9
  + [Bug tor-browser#45377](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45377): Remove alt text from YEC 2026
  + [Bug tor-browser#45382](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45382): Backport Security Fixes from 158
* Build System
  + All Platforms
    - [Bug tor-browser-build#41885](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41885): Update changelogs as a last step in relprep.py
  + Windows
    - [Bug tor-browser-build#41890](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41890): Update sign-exe wrapper to use new Windows signing cert
