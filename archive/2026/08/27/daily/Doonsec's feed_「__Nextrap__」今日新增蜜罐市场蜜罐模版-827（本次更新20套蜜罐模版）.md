（1）zrok

zrok 是 OpenZiti 生态下的开源网络资源共享服务，用于通过零信任方式安全共享 Web 服务、文件目录与网络端口，并提供 Web 管理界面进行资源授权与访问控制。面向开发者与运维团队的临时共享与内网穿透场景；官方仓库 openziti/zrok，官网 zrok.io。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokCww7xiaq4XG1TiagN6tgmLEEibaeEdneEia3ic6uHM4UyoE41E1upjaKiamAtibS41scgmTBMasprc2ShUm4b5gohFJmA8LJHjX6zzh0/640?wx_fmt=jpeg&from=appmsg)

（2）ZrLog

ZrLog 是基于 Java 的开源博客系统，提供文章发布、分类标签、评论、主题与插件扩展，并配备基于 React 的 Web 管理后台，可独立部署搭建个人或小型团队博客站点。官方仓库 94fzb/zrlog，官网 zrlog.com。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokAQqg40qtXYQ9hIe62ffjUyYYj4XO9jSmDoKcfdf6exIhEkL4pJfMhE6zdyLMyEGwbsdsqEWUFHvSPWIgIC3dcAiapUKiaosOHKU/640?wx_fmt=png&from=appmsg)

（3）ZKEACMS

ZKEACMS 是基于 ASP.NET Core 的开源内容管理系统，通过 Web 后台管理页面、栏目、文章与站点内容，支持独立部署快速建站。官方仓库 SeriaWei/ZKEACMS，官网 zkea.net。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokCCic1bzJ4tvcWaVWoasicqCRhez9zibeZiax9PcDRz2LOh52YtJCWibLcFWFUcg7QJUt4bZbIbd8NOwPxnjOkiaZK8ns2s4bJjdW5Jg/640?wx_fmt=jpeg&from=appmsg)

（4）Zimbra Collaboration Suite

Zimbra Collaboration Suite 是企业级邮件与协作平台，提供 Web 邮箱客户端、日历、通讯录与 GraphQL 等 Web 接口，支持邮箱服务与团队协作的私有化部署。提供开源版本（Open Source Edition）；官方仓库 Zimbra/zm-build，官网 zimbra.com。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokDEbIJbfNGPK17eJicn3eOibDtH01lnPick8DOeSsqGhgmruSiaib6Hn7Za5OUejcBcJ01pzHibnR99bFQr2OEic9QgyQn89licD59pP64/640?wx_fmt=jpeg&from=appmsg)

（5）yshopmall

yshopmall（yshop 意象商城）是前后端分离的开源电商系统，支持 B2C 单商户与 B2B2C 多商户模式，提供商品 SKU、订单交易、优惠券、秒杀、拼团、分销会员与商户管理等 Web 后台与前台商城功能。基于 Spring Boot 与 Vue，可独立部署搭建线上商城；官方仓库 guchengwuyue/yshopmall，官网 yixiang.co。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokCwNRnzyZpmwVnvQXedp4mW2GVwW8oaKudniaicOmkx0YhJVBqCWeBTPaJzwrlrLE0WRwko33PPFQkNwjQVVFyDBxXSRePhqxwYg/640?wx_fmt=png&from=appmsg)

（6）YARD

YARD 是 Ruby 生态的开源文档生成工具，除命令行生成文档外还提供 `yard server` Web 服务，在浏览器中浏览与检索 Ruby 代码文档。面向 Ruby 开发者与项目维护者；官方仓库 lsegal/yard，官网 yardoc.org。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokBNxf00WaB9xFlnexLeeR1I9vfBeMXWXBWhYgHJyibZjV4ePdAYbpWaKaVE1ricaGVNqw1Js5H7NjZLX7syIp4hMzncF4DYNJKOo/640?wx_fmt=png&from=appmsg)

（7）XXL-API

XXL-API 是 xuxueli 维护的开源 API 管理与接口文档平台，通过 Web 控制台管理接口分组、版本、权限与在线文档，便于团队统一维护与调试 API。可独立部署；官方仓库 xuxueli/xxl-api。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokCOpKE3IbsqdnibB54ic3rv28Qw7QLGWftF58zbJq59UptA8z48yEpAdsL3BdNN2ZibggHRM5VLORUY38gWooQPVmqAlmD3oBKEvM/640?wx_fmt=jpeg&from=appmsg)

（8）CyberArk Conjur

Conjur 是一款具备基于网络管理界面的秘密管理系统，能够独立进行部署（开放源代码软件/企业版）。我们选择 conjur.org 作为专门的产品网站，而非供应商的主页。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2vWkqc6FokBZgib5RrWluhn1dh9H583xbKKkXBaelZSMXrCXy3gXaqOt8J3NWuKZic9UERcPut6KnhQ7K9xiculG9t9dePRHsgkWRZYNgl2wa0/640?wx_fmt=jpeg&from=appmsg)

（9）Dask

Dask 是 Python 生态中广泛使用的并行计算框架，提供了 Web dashboard 用于监控任务执行。Dask 采用 BSD-3-Clause 开源许可证，GitHub 主仓库 dask/dask 包含核心代码和 dashboard 功能，是官方源码仓库。org 是 Dask 官方项目网站，提供文档和下载，为产品官网。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokDdkm1z6xe8wsyh2H4pUfh3W2PiaKWYpjJO4nbDSlgce5DLmtnyzYh3NkXzuE6Tpr7DxIm8OKFtO9d1EM8TG49OHV4Szhic6U6hU/640?wx_fmt=jpeg&from=appmsg)

（10）Dgraph

Dgraph 被描述为分布式 GraphQL 数据库，通过 HTTP 端口提供服务（/mutate, /admin/config 等），具备 Web 服务特征，属于可独立部署的服务型软件。虽然核心是数据库，但其通过 GraphQL API 交互且常作为微服务架构中的独立服务运行，归类为 Service 最为准确（Database 为领域分类而非产品类型）。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokC0PlVaIpvWicNJJtNP31xBJtAMKVVUlktfeyA5avjrXVjVibCP1zficwSDMYwAL2StcxWXxn0pzS80Pt87nwydNXQibnF1APMzhWE/640?wx_fmt=png&from=appmsg)

（11）Docmost

Docmost 是开源 Web 应用，可独立部署运行。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokBaWBKeWG71m3yecTnl7DkfKP35YgA3ZScicHhCFFt1jI1y6BbGMomwyWKB5CdCAHPzAvcu6SgnXjKy5C8tYhAOy447dgw5VQ68/640?wx_fmt=png&from=appmsg)

（12）Eclipse Jetty

Jetty是Eclipse基金会的开源Servlet容器和Web服务器，可独立部署提供HTTP/Web服务运行能力，属于典型的Web应用基础设施产品（Middleware）。CPE标注的eclipse/jetty.project为官方源码仓库，www.eclipse.org/jetty/为官方产品官网，均为最可信的官方链接。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2vWkqc6FokBRR9stXDojZtY3qcgssh9G0m2KdvRtyDoicI5s1iaWkGynZWV2KMtOSlrxZduXibPSVr2NNG0ZvhRV6sQEiaj8v2icqR20Vqto6s2s/640?wx_fmt=jpeg&from=appmsg)

（13）eLabFTW

eLabFTW被明确描述为一款“面向研究实验室的开源电子实验室记录本”，具备基于网络的认证、登录流程以及数据库存储功能。它是一款完整的Web应用程序，具备用于实验室记录本管理的用户界面，完全符合应用程序类型的要求。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokAWZDcBfcwb5YCN3AkbVKUiar6qzaOuriaibdbP5bRkFtRia8148q5Rvmq8yP4DicaMJicnQvbGAYmibJaeiamicud0EeshyT429vmSUP2M/640?wx_fmt=png&from=appmsg)

（14）elFinder

elFinder是一个开源的Web文件管理器，使用JavaScript和jQuery UI编写，具有Web界面可独立部署运行。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokB5UyB8mUTiaf8alLTKMIk5XxIyWTxGEpIbiaB5icmIbftGmm1Alib4e8ke3FbicmYwVjGEWxnqoEVHiaiauks5iaAJXk53dbjFY2JdeMs/640?wx_fmt=png&from=appmsg)

（15）Erugo

Erugo 是一个自托管的文件共享平台（self-hosted file-sharing platform），具备 Web 界面和管理功能，符合 Web 应用定义。漏洞描述提及的「公共 Web 根目录」和「远程代码执行」进一步证实了其 Web 服务属性

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokDhhM4yCTk4pEn6xtXYtjibz5Pws3kGaw5x4bKr3IQhrmEj0ejWfQusxfFLJHzscA6SSEiaHia0ULAZss0CicT9fn3dz6rPIgnQ7ro/640?wx_fmt=png&from=appmsg)

（16）FacturaScripts

FacturaScripts 是一款开源的企业资源规划（ERP）和会计软件，具有 REST API 接口和 Web 管理界面，可作为独立 Web 服务部署运行，符合 Web 应用产品定义。漏洞描述明确标注为开源项目，且存在 GitHub 源码仓库链接。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokAY4eNf2ZFy6hse9RUXb72Qr8jZ0C1sdhz2bGeck9F4PJmPHHdB4oL1QRUGp8VkjoknMU6eQiaGCseYkMC1xvcTrico3lLglomP0/640?wx_fmt=jpeg&from=appmsg)

（17）FastapiAdmin

FastapiAdmin 是一个基于 FastAPI 构建的后台管理系统，具备 Web 界面（管理后台），可独立部署，符合 Web 应用定义。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokDLkdrzdmszXEnzWVY8sUlXUAFuKu6TofVbzQjLTm07Tiaux3FIKdyzH8lAY8Q6ks2aPjSV0g0b5v8udicIicHsHlEYb1UmLpEhqE/640?wx_fmt=png&from=appmsg)

（18）Focalboard

Focalboard 是 Mattermost 社区维护的开源项目管理工具，支持看板、表格、日历等多种视图，可自托管部署，是 Trello / Notion 类工具的常见替代选择。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokD7CYb0GvqB5LR4JwfrVE5KyOl3M4XJSeD1ANb4VnWcYdRCg0CfCjgNv7mMgliakpGPuhoy0XiamsBqEMneFdhJkECdwbrgRHcJ4/640?wx_fmt=png&from=appmsg)

（19）Frappe Press

rappe Press 是面向 Frappe Cloud 基础设施的 Web 管理应用，具备可部署的 Frappe App 形态；CVE 中可见 API 相关漏洞（CSRF/XSS），印证其 Web 服务属性。项目归属 Frappe 官方组织，开源可信。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokB9H5SwIViaKUzTEricBbRLHd9WZMoT5QmX66Ksp6Jmrh4E7ZHePLFVpnzcLQhib1RPq5NwV1kam6YoGkiaZolgcE9N5rVlGMK0SXo/640?wx_fmt=png&from=appmsg)

（20）Froxlor

Froxlor 是开源轻量级服务器管理面板，通过 Web 界面管理域名、邮箱、FTP、数据库与 SSL，适合自建虚拟主机平台。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokCdBRKT2pcnJj7r0hJibaVUbqQ3qYxPjpp6jP716rShPoJPiaAduZJ1mBz4u959uvWuGyFFHJhxjHz82KqugnMlmCxTOnG2Yx4WM/640?wx_fmt=png&from=appmsg)
