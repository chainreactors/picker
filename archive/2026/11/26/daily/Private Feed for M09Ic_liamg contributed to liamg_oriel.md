**+** under the request composer attaches a file on this machine. In the conversation, an attached file shows as a card under its message: click it to open the file in a tab, or **↓** to save a copy.

* **Picking:** Oriel's own picker, like Open Directory. Type a path (it opens on `~/`). Picking a folder steps into it, and picking a file attaches it. **Browse…** opens the system's file chooser. The file goes in as a link to a copy in the session's agent folder (`hostapi.Attach`), the same way a dropped file does, so a sandboxed agent can read it.
* **The card:** any non-picture link in a message to an absolute local path. It shows the name and size, or "missing". A click runs `editor.open` in a tab. **↓** runs `request.file.save`, which opens a Save as picker starting at `~/Downloads/<name>`. You can type a path, pick a folder to save in, or use **Browse…** for the system's save chooser. Once saved, a notice offers **Reveal**.
* **New commands:**
  + `request.file.attach` with an optional `{path}`, granted `fs.read` on that path.
  + `request.file.save` with `{path, name, to}`, granted `fs.write` on `to`.
* **General pieces:**
  + `desktop.ChooseFile` and `desktop.ChooseSave` (osascript on macOS; zenity or kdialog elsewhere), sharing the folder chooser's runner.
  + `kit.TypedPaths` and `kit.ExpandHome`.
  + Pasting files and the new button share `attachPath`.
* **Help:** `agent/requests#attach`.
