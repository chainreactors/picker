2026年7月12日，西安市教育局印发《西安市2026年高中阶段学校招生录取工作方案》。方案对普通高中招生计划、招生单元划分、志愿填报、指标到校、综合高中试点以及录取管理等作出明确规定。

其中，五区二县和西咸新区部分高中可面向城六区招生，成为社会关注的重点。需要注意的是，这并不意味着长安区、西咸新区整体并入城六区，也不意味着相关区域考生可以大规模进入城六区高中。为准确理解政策，现本人根据通知原文对主要问题作如下自问自答。 通知原文：https://www.xa.gov.cn/gk/jyly/zccs/2076480238905311234.html

# 问：2026年西安中考招生单元发生了什么变化？

答：从通知原文看，西安市高中招生仍然保留不同招生单元，并未实行全市统一招生。

城六区招生录取工作由市中招领导小组统一组织，具体包括成绩公布、志愿填报、平台录取、信息推送、录取通知书发放和录取库建立等工作。

五区二县和西咸新区则仍然属于独立招生单元，自行组织录取，并与城六区同时进行。各独立招生单元还需要在7月17日前将本区域录取方案报市中招领导小组审批。

因此，城六区与五区二县、西咸新区仍然是不同的招生录取单元，组织方式没有合并。

# 问：长安区和西咸新区是否“正式并入城六区”？

答：没有。

通知明确将五区二县和西咸新区称为“各独立单元”，并规定这些区域自行组织录取。长安区属于五区二县之一，因此仍然是独立招生单元；西咸新区同样继续作为独立招生单元组织录取。

通知中所说的“纳入城六区招生统一管理”，针对的是五区二县和西咸新区部分高中面向城六区投放的招生计划，而不是这些行政区域整体并入城六区。

简单来说，纳入统一管理的是部分学校的特定招生计划，而不是长安区、西咸新区的全部学校和全部考生。

# 问：五区二县和西咸新区的所有高中都可以面向城六区招生吗？

答：不是。

通知使用的是“部分高中学校”，同时附有两个重要条件：

一是由市教育局统筹调剂；二是这些学校面向城六区招生的计划，要纳入城六区招生统一管理。

因此，并非相关区域的所有高中都自动获得面向城六区招生的资格。具体哪些学校可以招生、每所学校投放多少计划，仍要以市教育局最终下达和公布的招生计划为准。

# 问：这一政策意味着长安区、西咸新区考生可以报考城六区高中吗？

答：通知没有作出这样的普遍规定。

通知的表述是，五区二县和西咸新区的部分高中学校可以“面向城六区招生”。按照这一表述，主要招生方向是城六区考生报考五区二县或西咸新区的部分高中，而不是长安区、西咸新区考生普遍报考城六区高中。

因此，将这一政策解读为“长安、西咸考生涌入城六区”，实际上颠倒了通知规定的招生方向。

# 问：为什么部分区外高中招生计划要纳入城六区统一管理？

答：通知没有直接说明政策背景，但从录取规则看，纳入统一管理有利于实现统一填报、统一投档和统一录取。

这些学校面向城六区投放招生计划后，相关志愿和录取需要通过西安市初中学业水平考试招生管理平台完成，不能脱离平台自行招生，也不能通过意向登记、预录取协议或者保底协议等方式提前锁定生源。

这意味着跨招生单元的招生计划仍然受到统一招生纪律和录取程序约束。

# 问：2026年普通高中指标到校政策有什么要求？

答：通知要求进一步优化定向招生分配政策。

优质普通高中，包括民办普通高中在内，其总招生计划中除单列计划以外，不低于50%的计划要定向分配到招生单元内各初中学校，民办初中同样包括在内。

这里的关键词是“招生单元内”。这意味着指标到校仍然以招生单元为基本范围，并不是全市所有初中共同竞争同一批定向指标。

城六区的优质高中定向计划在城六区招生单元内分配；各独立单元则按照各自招生录取方案执行。

# 问：特色课程班是否可以单独选拔或者定向招生？

答：不可以。

通知明确规定，各类特色课程班招生计划应当纳入统招范围，不得定向招生。

这意味着特色课程班不能脱离统一招生计划自行选拔生源，也不能以特色班、实验班或者其他名义提前招生。相关计划必须进入正式招生录取程序，由考生根据志愿和考试成绩参与录取。

# 问：城六区考生什么时候填报志愿？

答：城六区招生单元考生的志愿填报时间为7月18日至7月20日。

五区二县和西咸新区等独立招生单元考生的志愿填报时间为7月21日至7月23日。

两个时间段不同，也进一步说明城六区与各独立单元没有合并，而是继续按照不同招生单元组织志愿填报。

# 问：城六区普通高中志愿如何设置？

答：城六区普通高中志愿分为两个批次。

第一批次可以填报3所省级示范高中，考生至少要填报2所才能提交志愿。

第二批次可以填报4所省级标准化高中和其他普通高中，考生必须填满4所才能提交志愿。

同一批次内的学校志愿均为平行志愿。平行志愿并不意味着可以同时被多所学校录取，而是按照统一投档规则，结合考生成绩、志愿顺序和学校招生计划进行投档。

# 问：定向生志愿可以填报几所学校？

答：每名考生只能填报1所定向生学校。

定向生录取对象必须同时满足三个基本条件：具有指标到校资格、属于应届考生、填报了相应定向志愿。

录取时，按照考生所在初中学校分别排队，并依据考试成绩和定向志愿择优录取。未完成的定向生计划应当顺延录取完成。

# 问：体育艺术特长生可以与多所高中达成招生意向吗？

答：不可以。

每名体育艺术特长考生只能与1所招收特长生的学校达成招生意向，填报志愿时也必须填报与其达成意向的学校。

通知还规定，限报考生不得与省级示范高中达成招生意向。特长生录取成绩不得低于普通高中录取控制线的60%。

需要注意的是，达成招生意向并不等于正式录取，最终仍要按照招生计划、考试成绩和平台录取程序办理。

# 问：国际课程班录取后能否转入普通班？

答：不能。

考生可以选报国际课程班和语言班，国际课程班收费按照批准的收费标准执行。学生在就读国际课程班期间，不得转入普通班级。

因此，考生和家长填报国际课程班志愿前，应充分了解课程设置、培养方向和收费标准，不能将其作为进入普通高中的临时通道。

# 问：什么是综合高中班？

答：综合高中班是此次方案中的重要试点内容。

通知提出，有序扩大中职学校综合高中班试点范围并增加招生数量，同时鼓励具备条件的中职学校整建制转设为综合高中。

城六区招生单元设置6所试点综合高中班志愿，各独立单元则根据实际下达计划的学校数量设置志愿数，相关志愿均采用平行志愿方式。

综合高中班学生统一注册普通高中学籍，但由中职学校负责教育教学并单独编班。

# 问：综合高中班学生以后可以转入普通高中吗？

答：不能。

综合高中班学生在符合条件的情况下，可以申请转入其他综合高中班，但不得转入普通高中。

学生也可以自愿申请转为中职学籍，但转为中职学籍后，原普通高中学籍同时注销。

因此，综合高中班虽然注册普通高中学籍，但并不是进入普通高中后再转入普通班的通道，其培养方式和学籍转换规则具有明确限制。

# 问：报考普通高中需要满足哪些基本条件？

答：考生必须同时满足综合素质评价和学业水平考试要求。

报考普通高中和试点综合高中班，考生综合素质评价5个维度以及学业水平考试成绩均须达到C等级以上，包括C等级。

报考省级标准化高中和省级示范高中，要求更高。考生综合素质评价5个维度中，至少有2个维度达到B等级以上；理化生实验操作和信息科技上机操作考试中，至少有2科达到B等级以上。

也就是说，中考总分并不是唯一录取条件，综合素质评价和实验操作等级同样可能影响考生的录取资格。

# 问：城六区普通高中按照什么顺序录取？

答：省级示范高中首先录取体育艺术特长生，其次录取国际课程班、语言班、丘成桐少年班和事业办学单位教职工子女，之后再进行统招生计划和定向生计划的同步录取。

省级标准化高中和其他普通高中，依次进行体育艺术特长生录取，以及统招生和定向生同步录取。

上述批次完成后，如学校仍有未完成计划，可以进行征集志愿录取，之后再进行试点综合高中班录取。

# 问：什么情况下会进行征集志愿？

答：普通高中在正常批次录取后，如果仍有招生计划没有完成，可以组织征集志愿录取。

但通知同时规定，整个招生录取工作结束后不再进行补录。

征集志愿属于正式招生录取程序的一部分，而补录是录取结束后的再次录取。二者并不相同。考生如果在正常批次未被录取，应及时关注征集志愿安排，不能等待录取结束后再寻求补录。

# 问：考生总分相同、人数超过招生计划时，如何确定录取顺序？

答：通知规定，按照“四个条件、两项指标及学科学业考试成绩”依次进行比较。

四个条件依次为：全国公安系统一级、二级英雄模范子女，符合条件的其他军人子女，少数民族考生，以及符合条件的西安市农村独生子女户和双女户考生。

如果比较完四个条件后仍无法区分，则比较综合素质评价5个维度的等级数量，以及理化生实验操作和信息科技上机操作考试的等级数量。

如果经过上述比较后仍然同分，再按照学科学业考试成绩依次比较录取。

这说明同分录取并非简单按照报名时间或者志愿提交时间决定，而是有明确的政策排序规则。

# 问：2026年还有地方性中考加分吗？

答：通知明确提出，除国家规定的照顾政策外，其他地方性加分项目原则上一律取消。

烈士子女、因公牺牲人员子女、符合条件的残疾军人或残疾民警子女、归侨及台湾籍考生等，按照规定分别享受20分或10分的照顾政策。

部分军人子女、公安系统英雄模范子女、少数民族考生以及符合条件的农村独生子女户和双女户考生，在同等条件下优先录取。

同一考生同时符合多项照顾条件的，只按照最高一项执行，不能重复累计。

# 问：学校可以提前登记、提前承诺录取吗？

答：不可以。

通知明确禁止学校通过“意向登记”“预录取协议”“保底录取协议”“分班保证协议”等方式变相提前招生，也禁止学校组织以选拔生源为目的的各类考试。

学校不得限制或干预学生填报志愿，不得收取择校费、意向金，也不得将招生录取与捐资助学、教育基金等赞助行为挂钩。

此外，学校不得提前组织新生报名、注册、收费或者军训。

考生和家长判断招生信息是否合法时，最重要的标准是：正式录取必须通过全市中招录取平台完成，脱离平台作出的录取承诺不属于正式录取结果。

# 问：学校能否要求考生必须填报某一所高中？

答：不能。

通知要求初中学校充分尊重学生志愿，不得限制学生报考。

如果学校存在包办志愿、限制报考或干预志愿填报的行为，学生可以直接向所在区县招生办或考试管理中心投诉处理。

因此，志愿填报权属于考生本人，学校可以提供政策讲解和填报指导，但不能代替考生作出选择。

# 问：录取结束后，学校能否自行招收未被平台录取的学生？

答：不能。

全市所有学校的录取结果均通过中招录取平台统一管理，各独立招生单元的录取结果也要报市教育局审批，并统一归入全市录取库。

普通高中建立高一新生学籍时，学校学籍库必须与正式录取库保持一致。未进入录取库的学生，不能由学校自行建立普通高中学籍。

同时，通知明确规定录取工作结束后不再补录，学校不能在统一录取结束后自行招收学生。

# 问：2026年政策对城六区考生可能带来什么影响？

答：从通知原文看，城六区考生可选择的学校范围可能有所扩大。

五区二县和西咸新区部分高中，以及开展综合高中班试点的中职学校，可以由市教育局统筹调剂，面向城六区招生。这意味着部分区外高中招生计划可能进入城六区志愿和录取体系。

但具体影响大小，仍取决于最终公布的学校名单、招生计划数量、学校办学层次和考生志愿选择。仅凭通知本身，不能得出录取分数线必然下降或竞争必然加剧的结论。

# 问：如何准确概括此次政策调整？

答：可以概括为三个方面。

第一，西安中考仍然实行分招生单元组织录取，城六区、五区二县和西咸新区并未合并。

第二，跨区域招生范围有所扩大，五区二县和西咸新区的部分高中可以面向城六区投放招生计划，但必须由市教育局统筹，并纳入城六区统一招生管理。

第三，招生程序进一步规范，指标到校、平行志愿、综合高中试点、统一平台录取和招生纪律要求得到进一步明确。

因此，这一政策的准确表述应当是：部分五区二县和西咸新区高中招生计划向城六区开放，而不是长安区、西咸新区整体并入城六区。
