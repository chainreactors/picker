A code-health pass driven by desloppify: its mechanical findings, then several rounds of subjective review. Strict score went from 21.4 at the start to 83.6 (target 85). Every commit builds; one logical change each.

## Bugs fixed along the way

* **Allow rules:** `Bash(go test:*)` matched anything starting `go test` , so `go test ./... && rm -rf ~` ran without asking. A prefix rule now matches only a single command; chained, piped, redirected or substituted commands ask.
* **`ask.answer`:** an answer with no decision was treated as allow. Missing or unknown decisions now error, and the ask keeps waiting.
* **WASM load:** the plugin's grant was checked on the module's resolved path, but the unresolved path was read. Both now use one resolved path.
* **vim:**
  + `:cc!` and `:cnext!` ignored the bang; a refused jump still moved the list's entry.
  + Block `d`, `c` and `p` didn't shift the numbered registers or fill `"-` the way nvim does.
  + All checked against nvim.
* **Lua and JSON callers:** `session.focus` and `quickfix.set` broke when called from Lua or JSON. `oriel.exec_async` failed when its optional `opts` was left out.
* **Test discovery:** never used plugin-added languages.
* **Persistence:** save failures in `host/persist` are now logged instead of dropped silently.
