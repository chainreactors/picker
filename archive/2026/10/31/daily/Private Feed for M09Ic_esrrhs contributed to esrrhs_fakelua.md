## Summary

This PR addresses runtime performance regressions and hot-path overheads identified during the review of recent PRs ([#37](https://github.com/esrrhs/fakelua/pull/37)–[#43](https://github.com/esrrhs/fakelua/pull/43)):

1. **Eliminate redundant `FL_LOC_SET` stores on non-throwing JIT statements (PR [fix: Lua source locations in runtime errors, and host/build fixes #40](https://github.com/esrrhs/fakelua/pull/40) follow-up)**:

   * Emit a single file-level `static const char * const fl_lua_file` per generated C translation unit instead of repeating string literals at every statement.
   * Add `CGen::StmtCanThrow` so statements that cannot throw at runtime (pure native numeric `Assign` / `LocalVar` / `Return`, as well as `Break`, `Continue`, `Goto`, `Label`, `Empty`, `Block`) still emit `#line` directives for compiler diagnostics without writing to `fl_lua_loc` on every loop iteration.
