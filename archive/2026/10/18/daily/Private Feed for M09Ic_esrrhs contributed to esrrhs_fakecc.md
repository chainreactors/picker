## Summary

本 PR 为 FakeCC 添加完整的 **macOS arm64 (Mach-O)** 后端支持，实现跨平台编译与测试覆盖。

### 主要特性

* **Mach-O 对象文件生成**：完整的 arm64 Mach-O 可执行文件、目标文件 (.o) 和共享库生成
* **Darwin 系统调用适配**：Linux → Darwin syscall 号码转译层
* **零依赖 runtime 移植**：stdio/printf/malloc/string 等 runtime 模块在 Darwin arm64 上可用
* **TLS 支持**：Darwin 原生 thread-local storage (TLV) 描述符
* **动态链接互操作**：支持链接 libSystem、pthread，以及与 clang/gcc 生成的 .o 文件混编
* **完整测试覆盖**：CI 同时覆盖 Linux x86\_64 和 macOS arm64
* **完全自举 (Self-Hosting Bootstrap)**：内置 SHA-256 原生 ad-hoc 签名与长分支生成，两阶段自举固定点二进制逐字节一致通过

### 测试结果（macOS arm64）

| 测试套件 | 结果 |
| --- | --- |
| 单元测试 | **26/26** ✅ |
| e2e 主测试 | **2682 通过 / 0 失败 / 7 跳过** ✅ |
| Multi-TU | **110 通过 / 0 失败** ✅ |
| CLI | **21 通过 / 0 失败** ✅ |
| 两阶段自举 | **Fixed Point Reached (Byte-identical)** ✅ |

**e2e 的 7 个跳过**是架构硬限制（AArch64 除以零不触发 SIGFPE、Darwin long double 是 64 位、GNU 十进制浮点不支持），不是移植遗漏。

### 主要改动

#### 后端 (src/cg64.c, src/macho.c)

* ARM64 指令生成：支持 ADRP/ADD/BRANCH26/GOT 等 Mach-O 重定位，实现条件分支反转与长跳转（wide branches）
* Mach-O 文件生成：\_\_TEXT/\_\_DATA/\_\_LINKEDIT 段、chained fixups、TLV 描述符
* 内置代码签名：基于 SHA-256 实现原生的 Mach-O ad-hoc 代码签名，脱离宿主 `codesign(1)`
* Darwin 导入表：dyld 绑定 extern 符号（pthread\_\*、sched\_yield 等）
* 多 TU 链接：支持 fakecc↔fakecc、fakecc↔clang .o 混编
