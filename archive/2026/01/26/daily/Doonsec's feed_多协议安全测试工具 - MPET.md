02 项目介绍

项目描述

MPET (Multi-Protocol Exploitation Toolkit) 是一款专业的多协议安全测试工具，基于 Wails 框架构建的现代化桌面应用。它提供了对 25+ 种主流服务协议的连接测试、未授权访问检测、弱口令检测和漏洞利用能力，是安全研究人员和渗透测试工程师的得力助手。

核心优势

```
🚀 高效批量: 支持 CSV、Fscan、Lightx 等多种格式批量导入，支持拖拽上传🔍 智能检测: 自动识别导入结果的未授权访问和弱口令漏洞📊 可视化报告: 一键导出 Markdown 格式漏洞报告，支持自动生成漏洞截图🎨 现代界面: Vue 3 + Ant Design Vue 打造的精美 UI🔐 代理支持: 内置 SOCKS5 代理，支持认证💾 数据管理: SQLite 数据库存储，支持漏洞信息自定义🌐 跨平台: 一次构建，Windows/Linux/macOS 全平台运行
```
