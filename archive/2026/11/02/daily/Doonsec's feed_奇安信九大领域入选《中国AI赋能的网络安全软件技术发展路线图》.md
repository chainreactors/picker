近日，国际数据公司（IDC）发布了《IDC TechScape：中国AI赋能的网络安全软件技术发展路线图，2026》。奇安信凭借在“AI+安全”领域的全栈布局与规模化落地能力，在Agentic Red Teaming、Agentic Code Security、Agentic EDR、Autonomous Exposure Management、Agentic NDR、Agentic Penetration Testing、Agentic Threat Intelligence、Agentic ZTNA、AI-Enabled OT Security等9个点位入选推荐厂商，成为覆盖点位数量领先的厂商之一，全面领跑AI驱动安全新赛道。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/mSqhDgeKrPBSsQI4VA9me7RxI9ibNvVs8Ph8gAcuCtpdOXRvzv4xX7bGlg7riamJW8CtVFWjf5jdiaUxrRfSvkuQEiaibrYqucDicuFedicjLc0q1o/640?from=appmsg)

IDC在报告中指出，随着生成式AI与智能体加速进入企业生产环境，“AI对抗AI”已成为安全技术演进的核心方向。AI不仅是需要被保护的对象，更是驱动安全检测、攻击模拟、威胁分析与自动化响应的重要执行力量。本次路线图从技术采用阶段、市场热度、采用速度等维度对各项技术进行了系统评估，奇安信的入选不仅覆盖了AI赋能安全运营、攻防实战的多个核心方向，更在Agentic（智能体化）的各个关键细分场景中展现了突出的先进性。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Y5Qke3LJU5zsdiaDcLmRzxlseAic5m4A58GJyj2BLbQ8jWmBg08ZLujicyiciadkrNy5eb5BNf32l1cvjRTROqf2iaxMAXF21GDuAlTZVjsDPAWL0/640?from=appmsg)

Agentic Red Teaming：AI红队，让攻防“不眠不休”

在攻防验证领域，奇安信入选Agentic Red Teaming（智能体化红队）。传统的红队演练高度依赖顶尖安全专家，成本高、周期长。奇安信依托多年的实战攻防经验与AI技术积累，将大模型与智能体技术引入红队测试，通过模拟真实攻击者的目标导向行为，自主完成侦察、攻击路径规划与策略调整，帮助政企客户以实战化、常态化的方式验证整体安全防线。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Y5Qke3LJU5zsdiaDcLmRzxlseAic5m4A58GJyj2BLbQ8jWmBg08ZLujicyiciadkrNy5eb5BNf32l1cvjRTROqf2iaxMAXF21GDuAlTZVjsDPAWL0/640?from=appmsg)

Agentic Code Security：代码安全智能体，守护AI生成代码

随着AI辅助编程成为主流，AI生成代码的安全缺陷成为新的风险敞口。奇安信入选Agentic Code Security（智能体化代码安全）的Qcode Agents，以“专家级大脑+多智能体协同”为核心，将十余年一线攻防经验代码化，覆盖从编码、提交、合并请求到持续集成的全场景，打造“感知—分析—验证—修复—响应”的自动安全闭环。在2026年国家级AI赋能网络安全应用测试中，奇安信在“网络系统及源代码漏洞智能挖掘”场景从60个团队中斩获第一名。

Agentic EDR与MDR：终端与运营的智能进化

在终端检测与响应领域，奇安信入选Agentic EDR（终端检测与响应系统 + MDR智能安全运营平台）。奇安信将终端一体化防护能力与智能体技术深度结合，实现从终端威胁发现、自动调查到响应的全流程智能化。平台依托多智能体协同，7×24小时不间断自主完成威胁检测、告警研判、事件调查及标准化处置响应，将MTTR压缩至分钟级。

Autonomous Exposure Management：CTEM让暴露面管理从被动走向主动

在暴露面管理领域，奇安信入选Autonomous Exposure Management（自主暴露管理），代表产品为奇安信持续威胁暴露管理平台（CTEM）。该平台通过自动化、持续化的资产发现与风险评估，帮助客户摸清家底、收敛暴露面。结合AI漏洞挖掘能力，CTEM平台能够将暴露面管理从被动发现推向主动验证与处置，提前发现高危隐患、自动关联攻击路径，让“风险有清单、整改有优先级、实战有验证”。

Agentic NDR：天眼，打造AI驱动的威胁监测与分析

在网络检测与响应领域，奇安信凭借AI天眼入选Agentic NDR（智能体化网络检测与响应）。产品围绕“看见未知、精准定性、提效运营、降本减负”的核心价值，打造深度检测、动态降噪、精准研判、智能溯源四位一体的AI驱动型NDR能力体系。深度检测专注语义级分析异常流量与灰色告警，从“研判已知”升级为“挖掘未知”，提升高级威胁检出率；动态降噪通过向量化去重，相似聚合率超80%，大幅节省模型算力；精准研判秒级输出结论、洞察与处置建议，准确率达98%+；智能溯源实现自动画像与推理，画像持续进化、成果沉淀复用。基于这些能力，最终实现从海量原始告警到高价值精确告警、再到自动画像发起安全狩猎的完整闭环，完成从“等告警”到“找线索”的主动狩猎。

Agentic Penetration Testing：自动化渗透测试系统，实战化验证安全防线

在渗透测试领域，奇安信入选Agentic Penetration Testing（智能体化渗透测试），代表产品为奇安信自动化渗透测试系统（AI加特林）。该系统内置“任务规划—攻击执行—自主反思—报告生成”四大核心智能体，实现端到端无人值守作业，将复杂系统的渗透周期从数天压缩至T+1天级，帮助政企机构以实战化、常态化的方式持续验证安全防护效果。

Agentic Threat Intelligence：威胁分析数字专家，“对话即研判”提升效率

在威胁情报领域，奇安信入选Agentic Threat Intelligence（智能体化威胁情报），代表产品为奇安信威胁分析数字专家。依托“云地协同”体系，奇安信威胁情报拥有300亿+样本库、90亿+PDNS记录等海量数据基础，威胁情报准确率高达99.99%。威胁分析数字专家具备独有数据、专业工具、丰富经验三大核心优势，覆盖IOC研判、APT溯源、样本分析等30余类高频场景，并将威胁情报覆盖范围延伸至大模型、智能体等AI新型资产，以“对话即研判”大幅提升分析与响应效率。

Agentic ZTNA：以身份为核心的智能访问控制

奇安信零信任网络访问系统（ZTNA）以数据资产为中心，覆盖身份、设备、网络、应用、数据等维度，通过持续信任评估与动态访问控制不断优化访问策略，并以AI赋能策略运营，有效缓解多分支、混合办公等场景下的访问风险。

AI-Enabled OT Security：AI赋能的工控安全

奇安信将AI能力引入工控安全，面向工业协议的异常识别、资产自动发现与行为基线建模，提升对未知威胁和高级攻击的检测能力，在不影响生产运行的前提下为工业控制系统构建更智能、更自适应安全防线。

结束语：

从红队验证到代码安全，从终端、网络检测到暴露面管理，从威胁情报、零信任访问到工控安全，奇安信在IDC这份AI赋能安全技术路线图中于9个点位的入选，勾勒出公司在智能体安全时代“AI赋能安全”的全栈能力版图。当安全产业加速从“人海战术”走向“智能体主导”，谁能率先把AI真正转化为可落地、可度量、可持续进化的安全能力，谁就能在新的攻防格局中占据主动。
