## Summary

* Align native library argument validation with standard Lua 5.3 behavior
* Reject Bool/Table arguments where string or number is expected across all native libraries
* Standard Lua 5.3 allows numeric string coercion, so numeric strings are still accepted
* Numbers are still accepted for string arguments (via luaL\_checkstring coercion)

## Changes

* **string library**: reject Bool/Table for string args in `string.format` specifiers (`%d/%i/%u/%x/%X/%o/%f/%e/%E/%g/%G/%c`), `string.char`, `string.pack` `c[n]/z`, `string.packsize z`
