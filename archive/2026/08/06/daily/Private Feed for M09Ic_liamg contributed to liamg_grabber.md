Closes two SSRF guard gaps (FIX-547):

* `Internal` level now blocks `100.64.0.0/10` (RFC 6598, CGNAT) — Go's `IsPrivate` doesn't include it, but Tailscale tailnets and EKS/GKE secondary pod CIDRs live there.
* `CheckHost` now fails closed:
  + Non-canonical IPv4 literals (`0177.0.0.1`, `0x7f.0.0.1`, `2130706433`, `127.1`) are rejected outright. The pure-Go resolver can't resolve them, so the old parse-fail → lookup-fail → allow path let them through — while libc's `inet_aton` in subprocess getters decodes them to real (blocked) addresses.
