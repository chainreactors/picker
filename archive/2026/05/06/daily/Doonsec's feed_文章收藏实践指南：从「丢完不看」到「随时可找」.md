## 一、问题诊断：为什么你「丢完不看」「丢完难找」

### 症状清单（自查）

| 症状 | 原因 | 后果 |
| --- | --- | --- |
| 微信收藏夹 200+ 未读 | 收藏时冲动，回看时没上下文 | 越堆越多，心理压力越大 |
| 记得看过一篇好文章，找不到 | 没有结构化标签，只能靠记忆 | 重复搜索，浪费时间 |
| 收藏了但忘了核心观点 | 当时没做笔记，只存了链接 | 等于没看，二次阅读成本高 |
| 文章散落各处 | 微信、浏览器、备忘录、Notion... | 每个地方都有，每个地方都不全 |

**根因一句话：收藏 ≠ 阅读，链接 ≠ 知识。**

---

## 二、核心工作流：三步闭环

```
看到好文章
    ↓
[Step 1] 丢链接（微信/飞书/任何IM）
    ↓
[Step 2] 自动拆解（AI查询 + 提取核心观点）
    ↓
[Step 3] 结构化入库（多维表格 + 本地备份）
    ↓
定期回顾 → 精读/归档/删除
```

**关键原则：每一步都降低下一步的摩擦力。**

## 三、多维表格字段设计：8个字段，覆盖全生命周期

基于今天实践验证的字段结构：

| 字段 | 类型 | 作用 | 填写时机 |
| --- | --- | --- | --- |
| **标题** | 文本（主键） | 一眼识别文章主题 | 入库时自动提取 |
| **来源** | 文本 | 知道从哪来，评估可信度 | 入库时自动提取 |
| **作者** | 文本 | 建立作者信任档案 | 入库时自动提取 |
| **原文链接** | 超链接 | 需要细读时一键跳转 | 入库时自动提取 |
| **收藏日期** | 日期 | 时间维度筛选 | 自动填入 |
| **阅读状态** | 单选 | **核心驱动字段** | 人工维护 |
| **分类标签** | 多选 | 跨维度检索 | AI建议 + 人工确认 |
| **核心摘要** | 文本 | **解决「丢完不看」的关键** | AI自动生成 |
| **质量评分** | 单选 | 快速判断值不值得精读 | 入库时AI初评，人工可改 |

### 阅读状态设计（四态模型）

```
未读     → 刚入库，还没看
已读     → 快速扫完，知道讲了什么
精读     → 认真读完，有收获
待跟进   → 有价值但需要后续行动（比如实验、调研、分享给团队）
```

**为什么不用「已读/未读」二态？** 太粗糙。你需要知道是「快速浏览过」还是「认真消化过」，后者才值得搜索时优先展示。

### 标签体系设计（可扩展）

今天实践中的标签（按领域分类）：

| 领域 | 标签 |
| --- | --- |
| AI/LLM | LLM原理、Tokenization、RL、Coding Agent |

| 工具/平台 | Hermes、Trae、Playwright、MCP、WebMCP |

**标签规则：**

* 每篇文章 2-4 个标签，不超过 5 个（多了没用）
* 标签名统一，不随意创造新标签（定期 review 合并相似标签）
* 核心标签前置：最重要的放前面，筛选时一眼看到

## 四、解决「丢完不看」：强制摘要 + 评分机制

### 为什么摘要必须自动生成？

你收藏时的心态：「这篇好像有用，先存着」。你回看时的心态：「这 100 篇里哪篇值得看？」。

**摘要的作用 = 给未来的自己写一张快递单。**不用打开包裹，就知道里面是什么。

今天的实践标准（每篇 100-200 字）：

* 核心判断/结论（作者最想说的一句话）
* 关键数据/案例（如有）
* 与你的关联（为什么值得收藏）

示例：

> **agent-browser** 可访问性树+refs 节省95%Token；**Playwright** **CLI** 节省4倍；**bb-browser** 复用真实浏览器登录态绕过反爬；**Lightpanda** 轻量级引擎；**WebMCP** 网站暴露结构化工具；Chrome 146 DevTools MCP --slim 模式。

### 质量评分机制

| 评分 | 含义 | 后续动作 |
| --- | --- | --- |
| ⭐⭐⭐⭐⭐ | 必读，有颠覆性观点 | 精读 + 写笔记 + 可能输出文章 |
| ⭐⭐⭐⭐ | 优质，值得深入 | 精读 + 摘录关键段落 |
| ⭐⭐⭐ | 还行，有局部价值 | 快速浏览，标记有用段落 |
| ⭐⭐ | 一般，参考价值有限 | 只保留摘要，不深入 |
| ⭐ | 低质或已过时 | 直接删除 |

**规则：入库时 AI 初评，你可以手动调整。** 重点是**强迫自己做一次价值判断**，而不是无脑收藏。

## 六、执行建议：建立习惯，而非依赖意志力

### 每日习惯（5分钟）

```
早上/晚上打开多维表格看板
    ↓
扫一眼「未读」列，挑 1-2 篇感兴趣的快速浏览
    ↓
读完标记「已读」，有价值的标记「待跟进」
    ↓
超过 2 周还在「未读」的，直接删掉（承认不会看了）
```

### 每周习惯（30分钟）

```
周末回顾本周收藏
    ↓
「已读」中挑 1 篇最有价值的转为「精读」，写 3 点收获
    ↓
「待跟进」中检查进度，完成的归档，没完成的继续跟进
    ↓
清理低分文章（⭐⭐ 及以下，如无保留价值直接删）
```

### 每月习惯（1小时）

```
盘点标签体系
    ↓
合并重复标签，删除从未用过的标签
    ↓
统计各标签下的文章数量，发现阅读偏好盲区
    ↓
输出月度阅读总结（可选，但对知识沉淀极有价值）
```

## 九、常见问题

**Q：我没时间看，先收藏以后再看？**A：可以，但必须在 2 周内转为「已读」或删除。超过 2 周的「未读」文章，99% 永远不会看。

**Q：一篇文章涉及多个领域，标签怎么打？**A：打 2-4 个最相关的。宁可少而精，不要多而全。标签是检索入口，不是分类学。

**Q：AI 生成的摘要不准怎么办？**A：你可以手动修改。入库后点击记录，编辑「核心摘要」字段即可。

**Q：我想导出到 Notion/Obsidian？**A：多维表格支持导出 Excel/CSV，可以定期导出备份。或者告诉我，我可以帮你同步到其他工具。
