## Summary

* Add a Lua-style contiguous integer-key array region to VarTable, including capacity growth, migration from hash storage, and array-aware integer get/set paths.
* Keep JIT C runtime, native table implementation, interpreter iteration, table dumps, and struct layout consistent; pairs order is spec fields, array entries, then hash entries.
* Add cross-backend coverage for append, reverse/sparse filling, nil holes, table.insert/remove, and mixed keys.
* Mark benchmark documentation as historical because its table measurements predate this implementation.

## Validation

* Focused array-part test passes across the available JIT backends.
* The selected broader suite reported 1,140 passing tests.
* GCC benchmarks showed improvements in table-heavy cases (for example BubbleSort/200 and Sieve/5000); benchmark timing is load-sensitive on this 2-core machine.
