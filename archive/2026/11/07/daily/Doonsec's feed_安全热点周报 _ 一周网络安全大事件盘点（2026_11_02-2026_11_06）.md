本周（11 月 2 日至 11 月 6 日）安全态势呈现「关键基础组件高危漏洞集中复现、第三方供应链数据泄露多点爆发」两条主线：应用最广泛的 OpenSSH 被曝出可在无凭据条件下绕过口令认证的认证绕过漏洞，WordPress 核心升级机制、Oracle E-Business Suite 与 Windows 更新组件等高危缺陷相继获实验室复现；与此同时，Amadeus 供应链失陷波及亚洲多家航司、澳大利亚新州卫生系统遭遇大规模数据外泄，配置失误与第三方风险成为数据安全的两大突出变量。

***PART 1***

**漏洞情报**

***01***

**OpenSSH/musl 密码认证绕过漏洞**

OpenSSH/musl 密码认证绕过漏洞是高危安全漏洞（CVE-2026-123158），影响以 musl libc 编译且未启用 PAM 的 OpenSSH 7.3p1 至 10.6p1 版本，常见于 Alpine Linux、OpenWrt、Buildroot、Yocto 及部分容器镜像与云主机。攻击者在目标 sshd 开启密码认证、且系统中存在口令字段为 \* 的锁定账户与至少一个持有真实哈希的账户时，可借由向该账户提交 257 至 1024 字节的超长口令，触发 musl 的 crypt() 在超长输入下返回 \* 并与影子文件中该账户的锁定标记误判为一致，绕过 SSH 密码认证登录本应拒绝口令的账户；若目标账户具备免密 sudo/doas 权限或 PermitRootLogin 的 root 账户，攻击者可直接提权至 root，导致主机完全失陷并进一步横向移动。

***02***

**Windows Update Stack 本地权限提升漏洞**

Windows Update Stack 本地权限提升漏洞是高危安全漏洞（CVE-2026-81963），影响部分 Windows 客户端与服务器版本的 Windows Update Stack 组件。攻击者在获得低权限本地用户身份后，可借由该组件在处理更新相关操作时对权限校验不当所引发的缺陷，将权限提升至 SYSTEM 级，进而完全控制受影响主机、植入持久化后门并进一步横向移动。

***03***

**GitLab CE/EE 远程代码执行漏洞**

GitLab CE/EE 远程代码执行漏洞是严重安全漏洞，影响部分 GitLab CE/EE 版本。攻击者在具备特定网络位置或借助相关接口缺陷时，可于 GitLab 服务端执行任意代码，进而控制代码仓库、CI/CD 流水线及所关联的部署凭据与访问令牌，对研发与运维环境构成直接威胁。

***04***

**WordPress Core 竞争条件远程代码执行漏洞**

WordPress Core 竞争条件远程代码执行漏洞是高危安全漏洞（CVE-2026-119977），影响 WordPress Core 4.7.0 至 7.1.3 版本。攻击者在网站执行完整包核心更新期间，可借由升级临时目录路径可预测且可被外部访问的竞争条件（TOCTOU），于升级窗口内注入恶意配置并触发安装器执行，进而实现未授权远程代码执行，导致服务器完全沦陷。

***05***

**Oracle E-Business Suite TCF 未认证 SQL 注入漏洞**

Oracle E-Business Suite TCF 未认证 SQL 注入漏洞是严重安全漏洞（CVE-2026-101767），影响 Oracle E-Business Suite 12.2.3 至 12.2.15 版本。攻击者可在无任何认证的情况下，向默认放行的 TCF Servlet 端点（/OA\_HTML/AppsTCFServer）投递特制请求，借由输入校验缺失引发的 SQL 注入以 APPS 数据库用户身份执行任意 SQL，读取或篡改财务、采购、人力、薪资等核心业务数据，并可进一步链入操作系统命令执行。

***PART 2***

**安全事件**

***01***

**韩国总统李在明等多名高官护照信息遭泄露**

2026 年 11 月 3 日，韩国总统府就总统李在明夫妇及多名政府高官共 168 人的护照信息外泄一事召开紧急会议。据韩联社报道，今年 6 月李在明出访欧洲前，一份含 168 人个人信息的「乘客名单」文件被上传至某付费安全检测网站，字段含姓名、所属机构与职务、出生日期、护照号码及签发日期等，相关文件在外泄约 5 个月后才被政府发现且期间仍可阅览。韩国外交部称已删除相关信息、正全面深入调查，现阶段判断为信息泄露而非黑客入侵，并着手为受影响人员换发护照。

原文链接：

https://www.toutiao.com/article/7704084472308548131/

***02***

**澳大利亚新州卫生系统遭大规模数据外泄，约 10 万份文件被窃取**

2026 年 11 月 4 日，澳大利亚新南威尔士州（NSW）卫生系统确认发生数据泄露事件：一名代号「bytetobreach」的攻击者声称利用某配置不当的子域，从 NSW Health 一处独立服务器窃取约 10 万份（约 70GB）敏感文件（时间跨度自 2020 年起）。该服务器关联面向私人口腔诊所的「口腔健康服务券」网站，新州卫生称尚无患者数据受影响、仅少量第三方供应商数据可能外泄，警方网络犯罪调查部门已介入并指调查具国际因素；相关文件据称在攻击者意外导致服务器崩溃前已被获取，目前泄露规模仍待核实。

原文链接：

https://www.smh.com.au/national/nsw/100-000-documents-stolen-from-isolated-nsw-health-server-20261104-p61b78.html

***03***

**旅游科技供应商 Amadeus 遭网络攻击，亚洲多家航司乘客信息泄露**

2026 年 11 月 5 日，安全内参综合报道，受西班牙 IT 服务商艾玛迪斯（Amadeus）近日发生的网络安全事件影响，日本航空、国泰航空、韩亚航空、新加坡航空、马来西亚航空等多家亚洲航司相继确认乘客数据泄露。Amadeus 称其用于展示旅行预订信息的系统存在漏洞，攻击者可借之访问部分预订信息；各航司披露规模包括日航约 9.2 万名客户、新加坡航空约 4.6 万条预订记录（其中约 620 条含邮箱、电话、旅行证件与常旅客会员号）、国泰约 5.3 万条预订记录。各航司均表示自身 IT 系统未遭入侵、支付与财务数据未泄露，正通知受影响客户并提示警惕钓鱼。

原文链接：

https://www.secrss.com/articles/95393

***04***

**AI 生成应用平台 Lovable 衍生项目大规模暴露用户数据，逾 8 万条记录泄露**

2026 年 11 月（本周），安全研究人员扫描约 15.9 万个 AI 生成的 Web 应用后发现，其中 24,664 个基于 Lovable 及其 Supabase 集成的应用存在数据库记录随页面加载即泄露的问题，暴露逾 8 万条用户档案、1,000 余份含护照号的身份文件、20 万余条私密聊天记录及支付信息。根因在于相关应用的 Row Level Security（RLS）被禁用或配置不当，攻击者可借浏览器开发者工具提取公开匿名密钥并直接全表查询。该事件凸显 AI 低代码应用「重生成、轻安全」带来的规模化数据暴露风险。

原文链接：

https://wpnews.pro/news/lovable-data-leak-2026-24664-ai-apps-exposed-80000-user-records-via-supabase

**公安部网络安全保卫局公布 3 起不履行数据安全保护义务典型案例**

**国家数据局在「十五五」系列发布会阐释数据基础制度与数据安全治理方向**

**全国网络安全标准化技术委员会牵头制定的国际标准《匿名实体鉴别 第4部分》正式发布**

**工业和信息化部发布《关于加强智能体终端设备进网管理的通知》**

2026 年 11 月 6 日，工业和信息化部办公厅发布《关于加强智能体终端设备进网管理的通知》，针对预置安装智能体的手机、平板、可穿戴等电信终端，从智能体与终端适配验证、进网检测与涉诈风险安全评估、OTA 现网升级管理、应用分发管理等方面提出要求，明确强化权限调用、通信能力、网络与数据安全、用户权益和任务执行的管理，并要求建立日常与专项检查机制、畅通投诉举报渠道，维护用户合法权益。

**📌 本周防护提醒**

• 针对 OpenSSH/musl 口令认证绕过（CVE-2026-123158，SHole）：以 musl 为底层 libc 的 Alpine、OpenWrt 等系统及容器/云镜像尽快升级至 OpenSSH 10.6p2 或发行版修复版本并重启 sshd；升级前可临时在 sshd\_config.d 中设 PasswordAuthentication no（须先确认密钥登录可用并保留当前会话），并核查日志中 alpine、root 等本应禁用口令登录的账户是否出现 Accepted password 记录。

• 针对 WordPress Core 升级窗口竞争条件 RCE（CVE-2026-119977）：立即将站点升级至 7.1.4 及各分支修复版本，并在升级前通过 Web 服务器配置拒绝对 /wp-content/upgrade/ 目录的 HTTP 访问，同时启用 WAF 拦截异常请求。

• 针对 Windows Update Stack 本地提权（CVE-2026-81963）：及时安装微软 11 月安全更新，对暂无法自动更新的系统手动部署补丁，并加强终端 EDR 对异常提权行为的监测。

• 针对 Oracle E-Business Suite TCF 未认证 SQL 注入（CVE-2026-101767）：已部署 EBS 的单位尽快应用 2026 年 10 月 CPU 补丁，并将 /OA\_HTML/AppsTCFServer 移出 URL 防火墙放行名单、限制 EBS Web 层访问来源。

• 针对第三方供应链数据泄露（Amadeus 事件波及多家航司）：依赖外部 IT/预订/服务供应商的企业应开展第三方数据流向梳理与供应商安全评估，明确数据外发范围与泄露通报机制，并对客户发布针对性钓鱼防范提示。

• 针对 AI 生成应用的配置类数据暴露（Lovable/Supabase）：使用 Supabase 等 BaaS 的团队须为所有数据表启用 Row Level Security 并配置最小权限访问策略，避免匿名密钥被直接用于全表读取。
