不少老板觉得等保是大国企、机关单位才操心的事，自己公司小、系统也简单，应该轮不到。这个想法挺危险。法律写的是"网络运营者"，不是"重要网络运营者"，覆盖面比大多数人以为的宽。

![](https://mmbiz.qpic.cn/mmbiz_png/S8PtXrqTk4ucmibrXL3UM2bZEzvoZYReTf8DjbYsbyknMjUaV12ib7lbJJPO8EPWp5DMHBSG56EfRxInkvn3ClFoK5I7xLJ4yPYasqmMTAIic8/640?wx_fmt=png&from=appmsg)

一句话的法律依据

《网络安全法》第二十一条：网络运营者应当按照网络安全等级保护制度的要求，履行安全保护义务。只要你对外运营一个信息系统，原则上就在这条线里。

一张表，自查你在不在范围内

下面按行业和系统类型列了常见情况，对号入座就行。

|  |  |  |  |
| --- | --- | --- | --- |
| 单位 / 行业 | 典型系统 | 常见定级 | 必须做吗 |
| 政务、机关单位 | 政务网站、办公系统、数据平台 | 三级为主 | 必须 |
| 金融（银行、证券、保险、支付、网贷） | 核心交易、网银、信贷系统 | 三级，部分四级 | 必须 |
| 能源（电力、石油、燃气） | 电力调度、工业控制系统 | 三级、四级 | 必须 |
| 交通（铁路、民航、地铁） | 调度指挥、售票系统 | 三级 | 必须 |
| 电信运营商 | 基础通信网络 | 三级、四级 | 必须 |
| 医疗卫生（医院、疾控、互联网医院） | HIS、电子病历、互联网医院平台 | 三级 | 必须（互联网医院上线要等保） |
| 教育（高校、教育局） | 学籍系统、一卡通、门户网站 | 二级、三级 | 必须 |
| 电商、互联网企业 | 网站、App、小程序（收个人信息） | 二级起 | 必须 |
| 制造、工业互联网 | 工控系统、生产网 | 二级、三级 | 视系统重要性 |
| 一般企业 | 官网、OA、CRM（涉个人信息） | 二级起 | 多数要 |
| 云、物联网、大数据平台 | 各类新型系统 | 按对象定 | 必须（2.0已纳入） |

怎么看这张表

两个判断维度就够：第一，你的系统是不是面向公众，或者收集了个人信息；第二，系统一旦出问题，会不会影响公共秩序或公共利益。只要沾上一个，基本就跑不掉，至少落到二级。

另外要分清"做等保"和"被测评"。一级系统（影响很小的普通系统）可以自己定级、自己保护，不强制找机构测评；但二级及以上是强制备案、强制测评的，不备案本身就不合规。

几个常见误会

小公司不用做？不是。只要你的网站或App在收用户手机号、订单信息，就涉个人信息，大概率二级起。

纯内网、不联网就不用做？如果内网系统存了大量员工或客户敏感数据，或者中断会影响业务运转，照样可能要定级。

等保2.0把云计算、物联网、工业控制、移动互联、大数据都纳进来了，传统认知里的"老系统"很多也在范围内。

拿不准，先做个初步判断

最怕的不是要做，而是拖到公安机关找上门才动。定级定错了更麻烦，低了被打回，高了白花钱。慧等保可以帮你做一轮免费的初步定级评估：你报一下单位行业和系统情况，我们判断该不该做、大概定几级、要备什么案。先搞清楚自己在不在范围内，再决定下一步，比闷头猜省事得多。
