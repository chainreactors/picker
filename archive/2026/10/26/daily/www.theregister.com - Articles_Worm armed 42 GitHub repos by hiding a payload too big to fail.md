A new [Miasma-family npm worm](https://www.theregister.com/security/2026/06/26/miasma-campaign-poisons-20-plus-npm-packages-hunts-for-developer-secrets/5262886), originally believed to be just a test with no victims, secretly armed 42 real GitHub repositories from 11 owners, hijacking accounts as early as July and using a stealthy payload built to stay hidden from GitHub and automated scanners, according to JFrog researchers.

Threat hunters at SafeDep, an open source supply chain security firm, first spotted the [“testmetest” npm campaign](https://safedep.io/testmetest-npm-worm-miasma-variant/) last week, identifying 18 packages linked to the same operator between October 19 and October 25, including releases containing credential-stealing malware. As with earlier npm worms, the malware is self-replicating, steals credentials, and installs a wiper that deletes the home directory when the victim revokes the stolen GitHub token, the security researchers noted.

The new [npm worm](https://www.theregister.com/security/2026/10/08/shai-hulud-worm-makes-jump-to-ai-infrastructure-with-tensorlake-compromise/5302054) shares code with June’s [Miasma Phantom Gyp](https://safedep.io/miasma-worm-hits-leoplatform-20-npm-packages) worm, and adds Mini Shai-Hulud’s token-revocation wiper.

As of October 22, however, SafeDep had found no compromised third-party packages or victims. “All observed activity belongs to the operator’s own test accounts,” the team wrote.

REG AD

As with most happy-ending security stories, that proved too good to be true.

In a Monday report, supply chain security company JFrog said its [analysis proved otherwise](https://research.jfrog.com/post/beyond-testmetest-42-hijacked-github-repos/), and found the testmetest campaign operator “had already armed real repositories belonging to established developers and organizations.”

This isn’t just about timing, either, according to JFrog researchers Guy Korolevski and Yair Benamou. “The payload blobs were large enough to evade the GitHub search and API paths normally used to find this kind of compromise,” they wrote.

### How the attacks worked

The attackers planted execution hooks for AI coding assistants and development tools, including Claude, Gemini, Cursor, and VS Code, alongside polymorphic wrappers measuring 12.9 to 13.7 MB that decode a hidden CI-publisher payload. Separately, the npm worm steals credentials, modifies repositories and CI configurations, and spreads through npm packages.
