## Summary

A client now dials exactly one underlay (one `-proto`/`-server`); the session is the connection itself. Multi-path redundancy can be built one layer up (run multiple clients).

* Removes channelHub/mainPipe, throughput pipe selection, gray/dead probing (SPEEDTEST), CHANNEL\_JOIN session attachment, and ProbeInter/ProbeSize
* **Server multi-protocol listeners unchanged** — every accepted conn is an independent session; generated server config still listens on all protos
* NewClient takes scalar proto/server; client rejects repeated -proto/-server
* configgen emits single-tcp client configs
* /status reports one pipe per session (proto/addr/rttMs)
* CHANNEL\_JOIN/SPEEDTEST marked deprecated in .proto/pb.go, wire numbers kept
* Net change ~ -1256 lines; docs (README/USAGE) and CI gate updated

## Validation

* `go build ./...`, `go vet ./...`, gofmt clean
* `go test -race -skip TestE2E_FullMatrix ./...` — all pass (netem/ricmp skip without privileges, same as CI)
* Stability gate subset passes
* Manual smoke: encrypted tcp forwarding, and one server listening tcp+rudp serving two clients simultaneously

## Breaking

Old multi-`-server` client configs are now explicitly rejected; the single-channel wire format is unchanged.
