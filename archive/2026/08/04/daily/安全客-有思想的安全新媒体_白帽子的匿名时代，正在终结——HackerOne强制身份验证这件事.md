# **01В  ејәеҲ¶иә«д»ҪйӘҢиҜҒпјҡдёҚжҳҜе»әи®®пјҢжҳҜзЎ¬й—Ёж§ӣ**

8жңҲ1ж—ҘпјҢHackerOne жӯЈејҸзЎ®и®ӨпјҡжүҖжңүй»‘е®ўеңЁеҗ‘д»»дҪ• Bug Bounty ProgramжҸҗдәӨжјҸжҙһжҠҘе‘Ҡд№ӢеүҚпјҢеҝ…йЎ»е…Ҳе®ҢжҲҗиә«д»ҪйӘҢиҜҒгҖӮжІЎжңүйӘҢиҜҒпјҢдҪ зҡ„жҠҘе‘ҠеҸ‘дёҚеҮәеҺ»пјӣжІЎжңүйӘҢиҜҒпјҢдҪ жӢҝдёҚеҲ°дёҖеҲҶй’ұиөҸйҮ‘гҖӮ

дёҚжҳҜйғЁеҲҶйЎ№зӣ®пјҢжҳҜжүҖжңүйЎ№зӣ®гҖӮдёҚжҳҜеҸҜйҖүйЎ№пјҢжҳҜејәеҲ¶гҖӮ

дҪҶжңүдёҖдёӘдҫӢеӨ–пјҡVulnerability Disclosure ProgramпјҲVDPпјүпјҢд№ҹе°ұжҳҜдёҚж¶үеҸҠйҮ‘й’ұеҘ–еҠұзҡ„жјҸжҙһжҠ«йңІйЎ№зӣ®пјҢд»Қз„¶еҜ№жңӘйӘҢиҜҒзҡ„з ”з©¶иҖ…ејҖж”ҫгҖӮиҜҙзҷҪдәҶвҖ”вҖ”дҪ иҰҒжӢҝй’ұпјҢе°ұеҫ—йңІи„ёпјӣдҪ дёҚжӢҝй’ұпјҢеҸӘеҒҡиҙЎзҢ®пјҢе№іеҸ°жҡӮж—¶дёҚеҚЎдҪ гҖӮ

иҝҷдёӘеҢәеҲҶеҫҲе…ій”®пјҢеҗҺйқўдјҡеұ•ејҖгҖӮ

# **02В  йӘҢиҜҒжөҒзЁӢпјҡжҠҠиә«д»ҪиҜҒдәӨз»ҷдёҖе®¶зҲұжІҷе°јдәҡе…¬еҸё**

е…·дҪ“жҖҺд№ҲйӘҢиҜҒпјҹHackerOne зҡ„жөҒзЁӢжҳҜиҝҷж ·зҡ„пјҡ

иҝӣе…ҘдёӘдәәиө„ж–ҷйЎөйқўпјҢзӮ№еҮ»вҖқID VerificationвҖқж ҮзӯҫпјҢе…ҲзӯҫзҪІдёҖд»ҪеҸ« Rules of Engagement зҡ„ж–Үд»¶вҖ”вҖ”йҮҢйқўжҳҜе…ідәҺвҖқйӘҢиҜҒеҗҺдҪ дјҡиҺ·еҫ—жӣҙй«ҳжқғйҷҗпјҢжүҖд»ҘиҰҒйҒөе®ҲйўқеӨ–жқЎж¬ҫвҖқзҡ„и§„е®ҡгҖӮеӢҫйҖүеҗҢж„ҸеҗҺпјҢзӮ№еҮ»вҖқStart VerificationвҖқпјҢз„¶еҗҺжҠҠж•ҙдёӘйӘҢиҜҒиҝҮзЁӢдәӨз»ҷз¬¬дёүж–№е…¬еҸё VeriffгҖӮ

Veriff жҳҜзҲұжІҷе°јдәҡзҡ„иә«д»ҪйӘҢиҜҒжңҚеҠЎе•ҶпјҢеҒҡзҡ„дәӢжғ…еҫҲз®ҖеҚ•пјҡиҰҒжұӮдҪ з”Ёж‘„еғҸеӨҙе®һж—¶жӢҚж‘„дёҖеј ж”ҝеәңзӯҫеҸ‘зҡ„жңүж•Ҳиә«д»ҪиҜҒд»¶пјҢеңЁеӨ§еӨҡж•°жғ…еҶөдёӢиҝҳйңҖиҰҒжӢҚдёҖеј е®һж—¶иҮӘжӢҚпјҢе’ҢиҜҒд»¶з…§зүҮеҒҡжҜ”еҜ№гҖӮ

жіЁж„ҸеҮ дёӘзЎ¬йҷҗеҲ¶пјҡдёҚиғҪз”Ё VPNпјҢдёҚиғҪз”ЁжөҒйҮҸеҢҝеҗҚе·Ҙе…·пјҢдёҚиғҪз”Ёи¶ҠзӢұи®ҫеӨҮпјҢдёҚиғҪз”Ё SDK жЁЎжӢҹеҷЁпјҢдёҚиғҪејҖ Apple Private RelayгҖӮз”ЁдәҶд»»дҪ•дёҖдёӘпјҢиҮӘеҠЁжӢ’з»қгҖӮеҸӘжҺҘеҸ—е®һдҪ“иҜҒд»¶пјҢжү«жҸҸд»¶е’Ңз”өеӯҗиҜҒд»¶дёҚиЎҢгҖӮжҠӨз…§гҖҒеӣҪж°‘иә«д»ҪиҜҒгҖҒеұ…з•ҷиҜҒгҖҒй©ҫз…§йғҪеҸҜд»ҘпјҢдҪҶе…·дҪ“жҺҘеҸ—е“ӘдәӣиҜҒд»¶еӣ еӣҪе®¶иҖҢејӮгҖӮ

йӘҢиҜҒжҸҗдәӨеҗҺпјҢйҖҡеёё 3 дёӘе·ҘдҪңж—ҘеҶ…йҖҡиҝҮйӮ®д»¶йҖҡзҹҘз»“жһңгҖӮеҰӮжһңиҝӣе…Ҙе®Ўж ёйҳҹеҲ—пјҢжңҖй•ҝ 48 е°Ҹж—¶гҖӮд№ӢеҗҺдҪ жүҚиғҪејҖе§ӢжҸҗдәӨжјҸжҙһгҖӮ

иҖҢдё”дёҚжҳҜйӘҢдёҖж¬Ўе°ұз»Ҳиә«жңүж•ҲгҖӮиә«д»ҪйӘҢиҜҒйңҖиҰҒжҜҸе№ҙз»ӯдёҖж¬ЎпјҢеҲ°жңҹеүҚеӨ§зәҰдёҖдёӘжңҲдјҡжҸҗйҶ’дҪ йҮҚж–°йӘҢиҜҒгҖӮиҝҮжңҹдәҶпјҹиөҸйҮ‘йЎ№зӣ®зҡ„жҸҗдәӨжқғйҷҗжІЎдәҶпјҢдёӘдәәиө„ж–ҷдёҠзҡ„з»ҝиүІйӘҢиҜҒж Үеҝ—д№ҹжІЎдәҶгҖӮ

# **03В  H1 ClearпјҡжҜ”жҷ®йҖҡйӘҢиҜҒжӣҙзӢ зҡ„вҖқе®үжЈҖвҖқ**

HackerOne иҝҳжңүдёҖдёӘжӣҙдёҘж јзҡ„еұӮзә§пјҢеҸ« H1 ClearгҖӮиҝҷдёӘйЎ№зӣ®еңЁжҷ®йҖҡиә«д»ҪйӘҢиҜҒзҡ„еҹәзЎҖдёҠпјҢйўқеӨ–еҠ дәҶдёҖеұӮзҠҜзҪӘиғҢжҷҜи°ғжҹҘпјҢйқўеҗ‘зҡ„жҳҜз»ҸиҝҮзӯӣйҖүзҡ„е°‘ж•°зІҫиӢұй»‘е®ўпјҢйҖҡеёёеҜ№жҺҘдјҒдёҡзҡ„еҶ…йғЁе®үе…ЁйЎ№зӣ®гҖӮ

дҪҶжіЁж„ҸвҖ”вҖ”е°ұз®—дҪ е·Із»ҸжҳҜ Clear зҠ¶жҖҒпјҢжҜҸе№ҙдёҖж¬Ўзҡ„жҷ®йҖҡиә«д»ҪйӘҢиҜҒз»ӯжңҹд»Қз„¶дёҚиғҪиҗҪдёӢгҖӮиҝҮжңҹдәҶпјҢClear зү№жқғд№ҹдјҡеҸ—еҪұе“ҚгҖӮ

жҚўеҸҘиҜқиҜҙпјҢHackerOne зҡ„иә«д»ҪйӘҢиҜҒдҪ“зі»жҳҜеҲҶеұӮзҡ„пјҡжҷ®йҖҡйӘҢиҜҒжҳҜвҖқдҪ иҜҒжҳҺдҪ жҳҜдҪ вҖқпјҢClear жҳҜвҖқдҪ иҝҳеҫ—иҜҒжҳҺдҪ е№ІеҮҖвҖқгҖӮдҪҶеҜ№дәҺеӨ§еӨҡж•°йқ иөҸйҮ‘еҗғйҘӯзҡ„з ”з©¶е‘ҳжқҘиҜҙпјҢжҷ®йҖҡйӘҢиҜҒиҝҷйҒ“й—Ёж§ӣе·Із»Ҹи¶іеӨҹж”№еҸҳжёёжҲҸи§„еҲҷдәҶгҖӮ

# **04В  дёәд»Җд№Ҳиў«жӢ’пјҹеӨ§йғЁеҲҶжҳҜиҮӘе·ұеқ‘иҮӘе·ұ**

Veriff зҡ„иҮӘеҠЁе®Ўж ёзі»з»ҹжӢ’з»қз”іиҜ·пјҢеҺҹеӣ еҫҖеҫҖдёҚжҳҜиә«д»ҪйҖ еҒҮпјҢиҖҢжҳҜдёҖдәӣжҠҖжңҜз»ҶиҠӮжІЎеҒҡеҘҪпјҡ

иҜҒд»¶жӯЈйқўж–Үеӯ—жЁЎзіҠгҖҒжңәиҜ»еҢәзңӢдёҚжё…гҖҒжқЎеҪўз ҒзјәеӨұжҲ–иў«иЈҒжҺүгҖҒиҜҒд»¶е·ІиҝҮжңҹгҖҒз”ЁдәҶеӨҚеҚ°д»¶иҖҢдёҚжҳҜеҺҹд»¶жӢҚж‘„гҖӮиҝҷдәӣйғҪжҳҜжңҖеёёи§Ғзҡ„жӢ’з»қеҺҹеӣ гҖӮ

HackerOne зҡ„е»әи®®д№ҹеҫҲзӣҙзҷҪпјҡе…үзәҝиҰҒеҘҪпјҢж‘ҳжҺүзңјй•ңе’ҢеӨҙйҘ°пјҢз”Ё Chrome жҲ– Safari жөҸи§ҲеҷЁгҖӮеҗ¬иө·жқҘеғҸжҳҜеңЁж•ҷдҪ жӢҚиҜҒд»¶з…§пјҢдҪҶзЎ®е®һиғҪзңҒеҺ»дёҚе°‘иў«жӢ’йҮҚжқҘзҡ„йә»зғҰгҖӮ

# **05В  иҝҷд»¶дәӢзңҹжӯЈеҖјеҫ—е…іжіЁзҡ„пјҢдёҚжҳҜжөҒзЁӢпјҢжҳҜдҝЎеҸ·**

жөҒзЁӢжң¬иә«дёҚз®—еӨҚжқӮгҖӮзңҹжӯЈеҖјеҫ—иҒҠзҡ„жҳҜиҝҷиғҢеҗҺзҡ„дҝЎеҸ·гҖӮ

HackerOne жҳҜе…ЁзҗғжңҖеӨ§зҡ„жјҸжҙһиөҸйҮ‘е№іеҸ°д№ӢдёҖпјҢиҝһжҺҘзқҖе…Ёзҗғж•°дёҮеҗҚзҷҪеёҪй»‘е®ўе’Ңдј—еӨҡдё–з•Ң 500 ејәдјҒдёҡгҖӮе®ғйҖүжӢ©еңЁиҝҷдёӘж—¶й—ҙзӮ№ејәеҲ¶иә«д»ҪйӘҢиҜҒпјҢе®ҳж–№иҜҙжі•жҳҜвҖқж»Ўи¶ізӣ‘з®ЎиҰҒжұӮвҖқгҖӮзӣ‘з®Ўд»Җд№ҲпјҹеҸҚжҙ—й’ұгҖҒдәҶи§ЈдҪ зҡ„е®ўжҲ·пјҢд»ҘеҸҠи¶ҠжқҘи¶ҠеӨҡзҡ„еҸёжі•з®Ўиҫ–еҢәеҜ№и·Ёеўғиө„йҮ‘жөҒеҠЁзҡ„е®ЎжҹҘиҰҒжұӮгҖӮ

еҪ“дҪ еҗ‘ HackerOne жҸҗдәӨдёҖдёӘжјҸжҙһпјҢдјҒдёҡд»ҳиөҸйҮ‘з»ҷдҪ пјҢиҝҷз¬”й’ұз»ҸиҝҮ HackerOne зҡ„е№іеҸ°жөҒиҪ¬вҖ”вҖ”еңЁзӣ‘з®ЎзңјйҮҢпјҢиҝҷе°ұжҳҜдёҖз¬”и·Ёеўғж”Ҝд»ҳгҖӮе№іеҸ°жңүд№үеҠЎзҹҘйҒ“й’ұжү“з»ҷдәҶи°ҒгҖӮ

иҝҷе…¶е®һдёҚжҳҜ HackerOne зҡ„еҺҹеҲӣеҠЁдҪңгҖӮз«һдәүеҜ№жүӢ Bugcrowd ж—©е°ұеңЁиөҸйҮ‘йЎ№зӣ®дёӯжҺЁиЎҢзұ»дјјзҡ„йӘҢиҜҒиҰҒжұӮпјҢIntigriti зӯүж¬§жҙІе№іеҸ°д№ҹеңЁи·ҹиҝӣгҖӮж•ҙдёӘиЎҢдёҡйғҪеңЁеҫҖвҖқеҺ»еҢҝеҗҚеҢ–вҖқзҡ„ж–№еҗ‘иө°пјҢHackerOne еҸӘжҳҜжҠҠж—¶й—ҙзәҝжӢүеҫ—жӣҙзҙ§дәҶгҖӮ

# **06В  еҢҝеҗҚж–ҮеҢ–зҡ„ж¶ҲдәЎпјҡжңүдәәж¬ўиҝҺпјҢжңүдәәиӯҰи§ү**

е®үе…Ёз ”з©¶е‘ҳеңҲеӯҗеҜ№иҝҷд»¶дәӢзҡ„еҸҚеә”жҳҜеҲҶиЈӮзҡ„гҖӮ

ж¬ўиҝҺзҡ„дәәи®ӨдёәпјҢиә«д»ҪйӘҢиҜҒиғҪзӯӣжҺүдҪҺиҙЁйҮҸжҠҘе‘ҠгҖҒжҒ¶ж„ҸжҸҗдәӨе’ҢжҠ•жңәиҖ…пјҢжҸҗеҚҮе№іеҸ°зҡ„ж•ҙдҪ“иҙЁйҮҸгҖӮдјҒдёҡд№ҹжӣҙж„ҝж„Ҹеҗ‘вҖқйӘҢжҳҺжӯЈиә«вҖқзҡ„з ”з©¶е‘ҳејҖж”ҫжӣҙй«ҳеҘ–йҮ‘зҡ„йЎ№зӣ®вҖ”вҖ”H1 Clear зҡ„еӯҳеңЁе°ұжҳҜиҜҒжҳҺгҖӮ

дҪҶиӯҰи§үзҡ„дәәжңүиҮӘе·ұзҡ„зҗҶз”ұгҖӮ

зҷҪеёҪзӨҫеҢәдёҖзӣҙжңүдёҖз§ҚвҖқmeritocracyвҖңдј з»ҹвҖ”вҖ”дҪ иЎҢдёҚиЎҢпјҢзңӢдҪ жҸҗзҡ„жјҸжҙһпјҢдёҚзңӢдҪ жҳҜи°ҒгҖӮеҢҝеҗҚи®©еҫҲеӨҡиә«еӨ„й«ҳеҺӢең°еҢәгҖҒзҪ‘з»ңе®ЎжҹҘдёҘж јеӣҪе®¶зҡ„з ”з©¶е‘ҳиғҪе®үе…Ёең°еҸӮдёҺе…Ёзҗғе®үе…Ёз”ҹжҖҒгҖӮиә«д»ҪйӘҢиҜҒдёҖж—ҰжҲҗдёәзЎ¬й—Ёж§ӣпјҢиҝҷдәӣдәәжҖҺд№ҲеҠһпјҹ

жӣҙзҺ°е®һзҡ„й—®йўҳжҳҜпјҡVeriff иҰҒжұӮдёҠдј ж”ҝеәңзӯҫеҸ‘зҡ„иә«д»ҪиҜҒд»¶пјҢжӢҚж‘„е®һж—¶иҮӘжӢҚпјҢиҝҷдәӣж•°жҚ®еӯҳеңЁе“ӘйҮҢпјҹдҝқеӯҳеӨҡд№…пјҹи°ҒиғҪи®ҝй—®пјҹHackerOne иҜҙйӘҢиҜҒз”ұ Veriff еӨ„зҗҶпјҢдҪҶж•°жҚ®жөҒиҪ¬зҡ„йҖҸжҳҺеәҰе№¶дёҚй«ҳгҖӮеҜ№дәҺдёҖдёӘд»ҘвҖқдҝқжҠӨдҝЎжҒҜе®үе…ЁвҖқдёәдҪҝе‘Ҫзҡ„зӨҫеҢәжқҘиҜҙпјҢжҠҠиҮӘе·ұзҡ„иә«д»ҪдҝЎжҒҜдәӨз»ҷз¬¬дёүж–№пјҢеӨҡе°‘жңүзӮ№и®ҪеҲәгҖӮ

# **07В  еҜ№жҷ®йҖҡз ”з©¶е‘ҳзҡ„е®һйҷ…еҪұе“Қ**

еҰӮжһңдҪ жҳҜе·Із»ҸеңЁ HackerOne дёҠжҙ»и·ғгҖҒжңүзЁіе®ҡиөҸйҮ‘ж”¶е…Ҙзҡ„з ”з©¶е‘ҳпјҢиҝҷдёӘеҸҳеҢ–зҡ„еҪұе“ҚжҳҜжңүйҷҗзҡ„вҖ”вҖ”иҠұзӮ№ж—¶й—ҙиө°дёҖйҒҚйӘҢиҜҒжөҒзЁӢпјҢжҜҸе№ҙз»ӯдёҖж¬ЎпјҢдёҚз®—еӨ§дәӢгҖӮ

дҪҶеҰӮжһңдҪ жҳҜж–°е…ҘиЎҢзҡ„гҖҒиҝҳжІЎжӢҝеҲ°з¬¬дёҖз¬”иөҸйҮ‘зҡ„пјҢжҲ–иҖ…еңЁйҡҗз§Ғж•Ҹж„ҹең°еҢәзҡ„з ”з©¶е‘ҳпјҢиҝҷйҒ“й—Ёж§ӣеҸҜиғҪдјҡи®©дҪ йҮҚж–°иҖғиҷ‘пјҡеҖјдёҚеҖјеҫ—дёәдәҶдёҖз¬”еҸҜиғҪжӢҝдёҚеҲ°зҡ„иөҸйҮ‘пјҢжҠҠиә«д»ҪиҜҒд»¶дәӨз»ҷдёҖдёӘжө·еӨ–е№іеҸ°гҖӮ

иҝҳжңүдёҖдёӘе®һж“ҚеұӮйқўзҡ„еҪұе“ҚпјҡйӘҢиҜҒз»“жһңжңҖй•ҝ 48 е°Ҹж—¶гҖҒйҖҡзҹҘжңҖй•ҝ 3 дёӘе·ҘдҪңж—ҘгҖӮеҰӮжһңдҪ еҸ‘зҺ°дәҶдёҖдёӘй«ҳеҚұжјҸжҙһпјҢжғіз¬¬дёҖж—¶й—ҙжҸҗдәӨжҠўйҰ–еҸ‘вҖ”вҖ”еҜ№дёҚиө·пјҢжІЎйӘҢиҜҒиҝҮзҡ„иҙҰеҸ·иҝһжҠҘе‘ҠйғҪеҸ‘дёҚеҮәеҺ»гҖӮиҝҷж„Ҹе‘ізқҖпјҢеҜ№дәҺжғіеҸӮдёҺвҖқиөҸйҮ‘з«һиөӣвҖқзҡ„з ”з©¶е‘ҳжқҘиҜҙпјҢжҸҗеүҚе®ҢжҲҗйӘҢиҜҒеҸҳжҲҗдәҶеҹәжң¬еҮҶеӨҮеҠЁдҪңпјҢдёҚиғҪеҶҚзӯүеҸ‘зҺ°дәҶжјҸжҙһеҶҚдёҙж—¶жҗһгҖӮ

# **08В  еҶҷеңЁжңҖеҗҺ**

HackerOne ејәеҲ¶иә«д»ҪйӘҢиҜҒпјҢиЎЁйқўдёҠжҳҜе№іеҸ°ж”ҝзӯ–и°ғж•ҙпјҢе®һиҙЁдёҠжҳҜж•ҙдёӘжјҸжҙһиөҸйҮ‘з”ҹжҖҒеңЁеҗҲи§„еҢ–и·ҜдёҠиҝҲеҮәзҡ„дёҖжӯҘгҖӮеҢҝеҗҚзҷҪеёҪеӯҗзҡ„й»„йҮ‘ж—¶д»ЈпјҢеҸҜиғҪзңҹзҡ„еңЁж”¶е°ҫгҖӮ

иҝҷдёҚдёҖе®ҡжҳҜеқҸдәӢвҖ”вҖ”жӣҙи§„иҢғзҡ„е№іеҸ°ж„Ҹе‘ізқҖжӣҙеҸҜжҢҒз»ӯзҡ„иөҸйҮ‘з»ҸжөҺгҖҒжӣҙй«ҳзҡ„дјҒдёҡдҝЎд»»еәҰгҖҒжӣҙеӨ§зҡ„йЎ№зӣ®йҮ‘йўқгҖӮдҪҶд»Јд»·жҳҜпјҢзӨҫеҢәйҮҢйӮЈз§ҚвҖқд»»дҪ•дәәйғҪеҸҜд»Ҙйқ жҠҖжңҜеҢҝеҗҚеҸӮдёҺвҖқзҡ„ејҖж”ҫзІҫзҘһпјҢжӯЈеңЁиў«дёҖзӮ№дёҖзӮ№зҪ®жҚўжҺүгҖӮ

д»ҘеҗҺжғійқ жјҸжҙһиөҡй’ұпјҢе…үжңүжҠҖжңҜдёҚеӨҹдәҶпјҢдҪ иҝҳеҫ—ж„ҝж„ҸиҜҒжҳҺвҖқдҪ жҳҜи°ҒвҖқгҖӮ

иҝҷдёӘй—®йўҳз•ҷз»ҷжҜҸдёҖдҪҚжӯЈеңЁе...
