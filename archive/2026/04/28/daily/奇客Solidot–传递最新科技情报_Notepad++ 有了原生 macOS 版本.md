## Notepad++ 有了原生 macOS 版本

[![苹果](https://icon.solidot.org/images/topics/topicapple.png?123)](/search?tid=12 "苹果")

[Edwards](/~Edwards) (42866)发表于 2026年04月28日 13时34分 星期二 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=84165&appkey=1370085986&title=Notepad%2B%2B%20%E6%9C%89%E4%BA%86%E5%8E%9F%E7%94%9F%20macOS%20%E7%89%88%E6%9C%AC "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自基因突变**

流行的 Windows 文本编辑器 Notepad++ 终于有了原生 macOS 版本，但该版本不是 Notepad++ 作者侯今吾或其团队开发的，而是社区独立构建的版本。Notepad++ for Mac 使用 Cocoa 构建，支持使用 Apple Silicon 的新 Mac 以及使用英特尔 CPU 的旧 Mac。该项目没有依赖 Wine 或类似的兼容层工具，用 macOS 原生界面替换了 Windows 界面，保留了核心编辑引擎，支持插件，采用了和原版本相同的 GNU GPL v3 许可证。该项目由 Andrey Letov 等人维护。
https://notepad-plus-plus-mac.org/
