## 八、关键发现与趋势

1. **资助规模**：2009-2025年间累计联邦义务金额约**1904万美元**
2. **机构主导**：**CDC占绝对主导**（94%+），反映美国对华公共卫生合作以技术援助和系统建设为主，而非基础研究
3. **时间跨度**：项目周期普遍较长（3-5年），最新项目（NU2HJG000003）延续至**2029年**，显示长期合作承诺
4. **资金结构**：存在"双层资助"模式——既直接资助中国CDC，也通过美国高校（UCLA、约翰霍普金斯）进行间接资助，后者可能涉及研究培训和人员交流
5. **地域分布**：除北京的中国CDC总部外，还包括**云南曲靖**（肺癌研究）、**江苏海门**（疾病预防）等地方机构

### 五、合作演变特征

|  |  |  |
| --- | --- | --- |
| 阶段 | 时间 | 特征 |
| 起步期 | 2002-2005 | 机构关系建立，签署首份MOU，启动主任年会 |
| 扩展期 | 2005-2010 | 新发再发传染病合作项目启动，五年周期制度化 |
| 深化期 | 2010-2015 | 续签第二轮，应对H1N1、H7N9等疫情，扩展至全球卫生安全 |
| 转型期 | 2015-2020 | 第三轮续签，纳入中美人文交流机制，启动非洲CDC三方合作 |
| 新阶段 | 2020-2025 | 新冠合作（2020-2023视频例会），2024年启动最新五年项目（NU2HJG000003）延续至2029年 |

### 六、关键结论

1. **协议层级**：中美疾控合作存在**三层架构**——

* 顶层：卫生部长级谅解备忘录（2005/2010/2015三轮）
* 中层：CDC主任级长期合作MOU（2016年签署）
* 执行层：具体项目合作协定（如U2GGH/NU2GGH系列）

2. **资金渠道**：上传数据文件中的USAspending记录显示，美国CDC通过**合作协定（Cooperative Agreement）**形式向中国CDC提供资金，这些资金与上述政府间备忘录直接挂钩，属于框架下的具体执行项目。
3. **延续性**：尽管中美关系波动，但疾控合作展现出较强韧性——2016年签署长期MOU，2022年仍举行线上主任年会，2024年启动延续至2029年的新项目，显示双方仍将公共卫生安全视为共同利益领域。
