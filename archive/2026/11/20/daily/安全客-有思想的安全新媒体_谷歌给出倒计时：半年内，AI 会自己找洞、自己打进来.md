еҮҢжҷЁдёӨзӮ№иў«еҸ«иө·жқҘзңӢе‘ҠиӯҰпјҢиҝҷдәӢе„ҝе®үе…Ёе·ҘзЁӢеёҲйғҪзҶҹгҖӮдҪҶиҝҷж¬ЎдёҚеӨӘдёҖж ·пјҡдёҚжҳҜдәәжү“иҝӣжқҘдәҶпјҢжҳҜдёҖеҘ—зі»з»ҹиҮӘе·ұзңӢе®ҢдҪ зҡ„иҪҜд»¶жӣҙж–°ж—Ҙеҝ—гҖҒиҮӘе·ұжүҫеҮәжҙһгҖҒиҮӘе·ұеҶҷеҲ©з”ЁгҖҒиҮӘе·ұжү“иҝӣжқҘпјҢе…ЁзЁӢжІЎжңүдәәжҸ’жүӢгҖӮи°·жӯҢеЁҒиғҒжғ…жҠҘе°Ҹз»„иҜҙпјҢд»–д»¬еңЁзңҹе®һж”»еҮ»йҮҢз¬¬дёҖж¬ЎзңӢеҲ°дәҶиҝҷд»¶дәӢгҖӮ

е®үе…ЁеҶ…еҸӮд»ҠеӨ©зҡ„жҠҘйҒ“жҠҠиҝҷеҸҘиҜқж‘ҶеңЁдәҶж ҮйўҳдёҠпјҡ**AI е…ЁиҮӘеҠЁзҪ‘з»ңж”»еҮ»е°ҶеңЁеҚҠе№ҙеҶ…еҲ°жқҘ**гҖӮз»ҷеҮәиҝҷдёӘж—¶й—ҙиЎЁзҡ„дёҚжҳҜиҮӘеӘ’дҪ“пјҢжҳҜи°·жӯҢеЁҒиғҒжғ…жҠҘе°Ҹз»„пјҲGTIGпјүгҖӮд»–д»¬зҡ„еҺҹиҜқжӣҙзӣҙжҺҘпјҡеңЁиҝҮеҺ»дёҖдёӘеӯЈеәҰйҮҢпјҢGTIG йҰ–ж¬ЎеҸ‘зҺ°ж”»еҮ»иҖ…еҲ©з”ЁеӨ§жЁЎеһӢжЎҶжһ¶пјҢеңЁжІЎжңүдәәе·Ҙд»Ӣе…Ҙзҡ„жғ…еҶөдёӢпјҢе®Ңе…ЁиҮӘеҠЁеҢ–ең°е®ҢжҲҗдәҶжјҸжҙһеҸ‘зҺ°е’ҢеҲ©з”ЁгҖӮ

# дёҖгҖҒдёҖеҸ°жҡҙйңІеңЁе…¬зҪ‘зҡ„жңҚеҠЎеҷЁпјҢжҠҠеә•зүҢдә®дәҶ

и°·жӯҢжҳҜжҖҺд№ҲеҸ‘зҺ°зҡ„пјҹиҜҙиө·жқҘжңүзӮ№й»‘иүІе№Ҫй»ҳвҖ”вҖ”ж”»еҮ»иҖ…иҮӘе·ұжҠҠжөӢиҜ•жңҚеҠЎеҷЁжҡҙйңІеңЁдәҶе…¬зҪ‘дёҠгҖӮ

GTIG еңЁиҝҷеҸ°жңәеҷЁдёҠзңӢеҲ°дәҶдёҖдёӘеӨҡжҷәиғҪдҪ“жЎҶжһ¶пјҢеҗҚеӯ—еҸ«В exploit\_agentгҖӮе®ғзҡ„е·ҘдҪңжөҒзЁӢеҫҲжё…жҘҡпјҡиҜ»еҸ–зғӯй—Ё Web еә”з”Ёзҡ„жңҖж–°иҪҜд»¶жӣҙж–°пјҢеҲҶжһҗиҝҷж¬Ўжӣҙж–°еҸҜиғҪдҝ®жҺүдәҶд»Җд№ҲгҖҒжҡҙйңІдәҶд»Җд№ҲпјҢз„¶еҗҺиҮӘеҠЁе°қиҜ•жһ„йҖ еҲ©з”ЁпјҢжңҖеҗҺиҮӘе·ұжү“иҝҮеҺ»гҖӮиҝҷеҸ°жңҚеҠЎеҷЁдёҠиҝҳеӯҳзқҖиў«зӣ—зҡ„еҸ—е®іиҖ…ж•°жҚ®гҖҒдҫҰеҜҹдҝЎжҒҜгҖҒWebShell е’ҢжҡҙеҠӣз ҙи§Ји„ҡжң¬вҖ”вҖ”д№ҹе°ұжҳҜиҜҙпјҢе®ғдёҚеҸӘжҳҜдёӘе®һйӘҢзҺҜеўғпјҢдә§йҮҸжҳҜжңүзҡ„гҖӮ

еҸ—е®ізӣ®ж ҮйӣҶдёӯеңЁжі•еӣҪзҡ„еӘ’дҪ“гҖҒеЁұд№җе’Ңж•ҷиӮІзұ»зҪ‘з«ҷгҖӮи°·жӯҢзҡ„жҺӘиҫһеҫҲе…ӢеҲ¶пјҢдҪҶдҝЎжҒҜйҮҸеҫҲеӨ§пјҡиҝҷеҘ—дёңиҘҝиғҪжҺҘеӨҡдёӘеүҚжІҝеӨ§жЁЎеһӢпјҢд№ҹиғҪжҺҘжң¬ең°йғЁзҪІзҡ„ејҖжәҗжЁЎеһӢгҖӮзҝ»иҜ‘дёҖдёӢвҖ”вҖ”**й—Ёж§ӣдёҚеңЁй’ұпјҢеңЁжңүдәәж„ҝж„ҸжҗӯгҖӮ**

# дәҢгҖҒйӮЈдәӣвҖқжң¬жқҘеҸӘиҜҘеҮәзҺ°еңЁжј”з»ғйҮҢвҖқзҡ„е·Ҙе…·

и°·жӯҢзӮ№еҗҚзҡ„еӣӣдёӘжЎҶжһ¶пјҢеҒҡе®үе…Ёзҡ„дәәеә”иҜҘйғҪдёҚйҷҢз”ҹпјҡARTEXгҖҒCAIRNгҖҒCyberStrikeAIгҖҒHexStrike AIгҖӮе®ғд»¬еҺҹжң¬жҳҜз»ҷе®үе…ЁеӣўйҳҹеҒҡжё—йҖҸжөӢиҜ•е’ҢиҮӘеҠЁеҢ–йӘҢиҜҒз”Ёзҡ„ејҖжәҗе·Ҙе…·пјҢзҺ°еңЁиў«зӣҙжҺҘжҗ¬еҺ»еҪ“ж”»еҮ»е№іеҸ°гҖӮ

е…¶дёӯдёҖдёӘжЎҲдҫӢжҳҜз”Ё CAIRN жү“зҫҺеӣҪиҲӘз©әиҲӘеӨ©йўҶеҹҹпјӣеҸҰдёҖжқЎзәҝзҙўйҮҢпјҢз–‘дјјжңқйІңзҡ„й»‘е®ўз»„з»Үз”Ёж”№йҖ иҝҮзҡ„ Claude Code жү“еҢ—зҫҺе’Ңж¬§жҙІзҡ„еҠ еҜҶиҙ§еёҒдјҒдёҡвҖ”вҖ”е…ҘдҫөжҲҗеҠҹеҗҺж”№жҺү Claude Code зҡ„й…ҚзҪ®ж–Үд»¶пјҢи®©е®ғеңЁеҗҜеҠЁж—¶иҮӘеҠЁдёӢиҪҪдёҖдёӘеҸ« SOMBERMEME зҡ„еҗҺй—ЁгҖӮ

дёҠе‘Ё FBI д№ҹеҸ‘дәҶиӯҰе‘Ҡпјҡд»Һ 8 жңҲиө·пјҢеӨҡдёӘж”»еҮ»иҖ…ејҖе§ӢжҠҠ ARTEX жӯҰеҷЁеҢ–пјҢзӣ®ж ҮжҳҜйҮ‘иһҚгҖҒж”ҝеәңгҖҒз§‘жҠҖгҖҒеӣҪйҳІгҖҒеҢ»з–—еҚ«з”ҹгҖӮиҝҷдәӣиЎҢдёҡйҮҢпјҢеҫҲеӨҡеҚ•дҪҚзҡ„иҫ№з•Ңи®ҫеӨҮгҖҒжөӢиҜ•зҺҜеўғгҖҒиҖҒж—§дёӯй—ҙд»¶иҝҳжҢӮеңЁе…¬зҪ‘дёҠпјҢжӯЈеҘҪжҳҜвҖқжјҸжҙһз®ҖеҚ•гҖҒеҪұе“ҚжҳҺзЎ®гҖҒеӨ§жЁЎеһӢдёҖеӯҰе°ұдјҡвҖқзҡ„йӮЈдёҖзұ»гҖӮ

> зңҹжӯЈеҸҳеҝ«зҡ„дёҚжҳҜвҖқеҸ‘зҺ°вҖқ,иҖҢжҳҜвҖқд»ҺеҸ‘зҺ°еҲ°жү“иҝӣвҖқиҝҷдёҖж®өгҖӮеҺҹжқҘиҰҒдёҖдёӘдәәеҶҷдёүеӨ© EXPпјҢзҺ°еңЁеҸҜиғҪжҳҜдёҖжқҜе’–е•Ўзҡ„е·ҘеӨ«гҖӮ

# дёүгҖҒдёүдёӘжңҲе’Ңе…ӯдёӘжңҲпјҢиҝҷдёӨдёӘж•°еӯ—жүҚжҳҜйҮҚзӮ№

и°·жӯҢз»ҷдәҶдёӨдёӘж—¶й—ҙзӮ№пјҡжңӘжқҘдёүдёӘжңҲеҶ…пјҢж”»еҮ»иҖ…иғҪеҸ‘еҠЁжҠҖжңҜй—Ёж§ӣиҫғдҪҺгҖҒеҮ д№ҺдёҚйңҖиҰҒдәәе·ҘеҸӮдёҺгҖҒйқ еӨҡжҷәиғҪдҪ“еҚҸеҗҢе®ҢжҲҗзҡ„ж”»еҮ»пјӣжңӘжқҘе…ӯдёӘжңҲеҶ…пјҢеҫҲеҸҜиғҪеҮәзҺ°жҠҖжңҜеӨҚжқӮгҖҒе®Ңе…ЁиҮӘдё»зҡ„жҷәиғҪдҪ“ж”»еҮ»гҖӮ

дёәд»Җд№Ҳиҝҷд»¶дәӢеҜ№дёҖзәҝиҝҷд№ҲйҡҫеҸ—пјҹеӣ дёәе®ғзӣҙжҺҘеҺӢзј©дәҶдёүдёӘдёңиҘҝпјҡ

* иЎҘдёҒзӘ—еҸЈгҖӮеҺҹжқҘз”Іж–№иҝҳиғҪжҺ’дёӘдёӨе‘Ёзҡ„зҒ°еәҰи®ЎеҲ’пјҢзҺ°еңЁж”»еҮ»ж–№еңЁдҪ еҸ‘е…¬е‘Ҡзҡ„еҪ“еӨ©е°ұиғҪи·‘е®ҢдёҖиҪ®жү«жҸҸгҖӮ
* з ”еҲӨж—¶й—ҙгҖӮPHP2Shell е…¬еёғдёӨдёӘжјҸжҙһеҗҺжІЎеҮ еӨ©пјҢзҪ‘дёҠеҶ’еҮәеҮ зҷҫдёӘжүҖи°“зҡ„ PoCпјҢеӨ§йғЁеҲҶжҳҜ AI з”ҹжҲҗзҡ„гҖӮзңҹеҒҮж··еңЁдёҖиө·пјҢе®үе…Ёеӣўйҳҹеҫ—дёҖдёӘдёӘйӘҢпјҢдәәеҠӣзӣҙжҺҘиў«иҖ—е…үгҖӮ
* еә”жҖҘиҠӮеҘҸгҖӮд»ҘеүҚжҳҜвҖқеҮәдәҶдәӢеҶҚе“Қеә”вҖқпјҢзҺ°еңЁеҫҖеҫҖжҳҜвҖқдҪ иҝҳжІЎзЎ®иҜҠпјҢеҜ№йқўе·Із»ҸжҚўдәҶдёӘжҙһиҝӣжқҘвҖқгҖӮ

и°·жӯҢиҝҳжҸҗдәҶдёҖеҸҘе®№жҳ“иў«еҝҪз•Ҙзҡ„пјҡеӨ§жЁЎеһӢеҠ«жҢҒпјҲLLMjackingпјүе·Із»ҸжҲҗдәҶеёёи§„зүҹеҲ©жүӢж®өгҖӮж”»еҮ»иҖ…жӢҝеҲ«дәәзҡ„ API Key и·‘иҮӘе·ұзҡ„жҙ»пјҢиҙҰеҚ•еҜ„еҲ°еҸ—е®іеҚ•дҪҚеӨҙдёҠпјҢеҫҲеӨҡеҚ•дҪҚжҳҜжңҲеә•еҜ№иҙҰжүҚеҸ‘зҺ°гҖӮ

# еӣӣгҖҒеҲ«жҖҘзқҖд№°ж–°зҺ©е…·пјҢе…ҲжҠҠиҝҷеҮ д»¶дәӢеҒҡдәҶ

е…ЁиҮӘеҠЁж”»еҮ»жү“зҡ„жҳҜвҖқжҡҙйңІйқў + е·ІзҹҘжјҸжҙһвҖқиҝҷдёӘз»„еҗҲпјҢйҳІе®Ҳзҡ„йҮҚеҝғе…¶е®һжІЎеҸҳпјҢеҸӘжҳҜиҠӮеҘҸиҰҒжҸҗдёҠжқҘгҖӮ

1. **жҠҠе…¬зҪ‘жҡҙйңІйқўз ҚеҲ°жңҖе°ҸгҖӮ**иө„дә§жөӢз»ҳеҒҡдёҖйҒҚпјҢе…ій—ӯдёҚеҝ…иҰҒзҡ„жөӢиҜ•зҺҜеўғгҖҒж—§зүҲз®ЎзҗҶеҗҺеҸ°гҖҒдёҙж—¶ејҖж”ҫзҡ„и°ғиҜ•з«ҜеҸЈгҖӮжҷәиғҪдҪ“жҢ‘зҡ„е°ұжҳҜиҝҷзұ»вҖқз®ҖеҚ•жҙһвҖқгҖӮ
2. **иЎҘдёҒд»ҺвҖқжңҲжӣҙвҖқж”№вҖқе‘ЁжӣҙвҖқгҖӮ**еҜ№иҫ№з•Ңи®ҫеӨҮгҖҒVPNгҖҒдёӯй—ҙд»¶гҖҒJava иҝҗиЎҢж—¶иҝҷзұ»й«ҳеҚұз»„д»¶пјҢе»әз«Ӣ 24 е°Ҹж—¶еҶ…иҜ„дј°гҖҒ72 е°Ҹж—¶еҶ…дёҠзәҝзҡ„зЎ¬жҢҮж ҮгҖӮ
3. **еҜ№ PoC жіӣж»ҘжңҹеҒҡйў„жЎҲгҖӮ**жјҸжҙһе…¬ејҖеҗҺзҡ„еӨҙдёӨе‘ЁпјҢжҠҠж—Ҙеҝ—е‘ҠиӯҰйҳҲеҖји°ғдҪҺпјҢйҮҚзӮ№зңӢејӮеёёжү«жҸҸе’ҢеҲ©з”Ёзү№еҫҒпјҢиҖҢдёҚжҳҜиў«еҮ зҷҫдёӘзңҹеҒҮ PoC зүөзқҖиө°гҖӮ
4. **з®ЎдҪҸ API Key е’ҢжЁЎеһӢи°ғз”ЁгҖӮ**з»ҷжҜҸдёӘеә”з”ЁеҚ•зӢ¬еҸ‘ KeyгҖҒи®ҫйўқеәҰдёҠйҷҗгҖҒејҖи°ғз”Ёе®Ўи®ЎпјҢеҸ‘зҺ°ејӮеёёз”ЁйҮҸз«ӢеҲ»зҶ”ж–ӯгҖӮ

# дә”гҖҒж”»еҮ»дҫ§зҡ„иҙҰжң¬пјҢе…¶е®һз®—еҫ—еҫҲжё…жҘҡ

дёәд»Җд№Ҳж”»еҮ»иҖ…ж„ҝж„ҸиҠұеҠӣж°”жҗӯиҝҷеҘ—дёңиҘҝпјҹеӣ дёәж”¶зӣҠз»“жһ„еҸҳдәҶгҖӮ

иҝҮеҺ»жҢ–дёҖдёӘиғҪз”Ёзҡ„жҙһпјҢиҰҒжңүдәәжҮӮд»Јз ҒгҖҒжҮӮеҚҸи®®гҖҒжҮӮзӣ®ж ҮзҺҜеўғпјҢдёҖдёӘдәәдёҖе№ҙд№ҹеҮәдёҚдәҶеҮ дёӘй«ҳиҙЁйҮҸ EXPгҖӮзҺ°еңЁиҝҷеҘ—жөҒзЁӢйҮҢпјҢдәәеҸӘйңҖиҰҒеҒҡдёүд»¶дәӢпјҡжүҫзӣ®ж ҮгҖҒжҗӯжЎҶжһ¶гҖҒд»ҳжЁЎеһӢи°ғз”Ёиҙ№гҖӮеү©дёӢзҡ„дҫҰеҜҹгҖҒиҜ•й”ҷгҖҒеҶҷеҲ©з”ЁгҖҒжҚўиҪҪиҚ·пјҢе…ЁдәӨз»ҷжҷәиғҪдҪ“и·‘гҖӮиҜ•й”ҷжҲҗжң¬иў«ж‘Ҡи–„д№ӢеҗҺпјҢеҺҹжң¬вҖқдёҚеҖјеҫ—жү“вҖқзҡ„дёӯе°Ҹзӣ®ж Үд№ҹиҝӣдәҶе°„зЁӢгҖӮ

и°·жӯҢжҠҘе‘ҠйҮҢиҝҳжңүдёҖдёӘе®№жҳ“иў«еҝҪз•Ҙзҡ„и§ӮеҜҹпјҡиҝҷзұ»жЎҶжһ¶дјҡдё»еҠЁеҺ»еҲҶжһҗвҖқзғӯй—Ё Web еә”з”Ёзҡ„иҪҜд»¶жӣҙж–°вҖқгҖӮзҝ»иҜ‘жҲҗдәәиҜқе°ұжҳҜвҖ”вҖ”**дҪ еҸ‘зҡ„иЎҘдёҒиҜҙжҳҺпјҢе°ұжҳҜе®ғзҡ„ж”»еҮ»иҜҙжҳҺд№Ұ**гҖӮиЎҘдёҒжҸҸиҝ°еҶҷеҫ—и¶ҠиҜҰз»ҶпјҢе®ғе®ҡдҪҚеҫ—и¶Ҡеҝ«гҖӮиҝҷз»ҷеҺӮе•ҶеҮәдәҶдёӘйҡҫйўҳпјҡе®үе…Ёе…¬е‘ҠиҰҒдёҚиҰҒеҶҷжё…жҘҡпјҹеҶҷжё…жҘҡдәҶеё®йҳІе®Ҳж–№пјҢд№ҹеё®ж”»еҮ»ж–№гҖӮ

и°·жӯҢжҠҘе‘ҠиҝҳжҢҮеҮәпјҢеӣҪе®¶ж”ҜжҢҒзҡ„з»„з»ҮгҖҒе•Ҷдёҡдҫӣеә”е•Ҷе’Ңж”ҝжІ»зҪ‘з»ңпјҢе·Із»ҸжҠҠ AI з”ЁдәҺиҲҶи®әеҪұе“Қжҙ»еҠЁеёёжҖҒеҢ–гҖӮиҝҷжқЎзәҝи·ҹвҖқжјҸжҙһиҮӘеҠЁеҢ–вҖқжҳҜдёӨеҘ—зҺ©жі•пјҢдҪҶе…ұз”ЁеҗҢдёҖжү№жЁЎеһӢе’ҢеҹәзЎҖи®ҫж–ҪгҖӮе®үе…ЁеӣўйҳҹеҰӮжһңеҸӘзӣҜе…Ҙдҫөе‘ҠиӯҰпјҢеҫҲе®№жҳ“еҝҪз•ҘеҸҰдёҖжқЎзәҝдёҠзҡ„ејӮеёёеҶ…е®№жҠ•ж”ҫгҖӮ

еҜ№еӣҪеҶ…еҚ•дҪҚжқҘиҜҙпјҢиҝҳжңүдёҖдёӘзҺ°е®һе·®и·қпјҡеҫҲеӨҡиө„дә§иҝһвҖқжҲ‘еҲ°еә•иЈ…дәҶд»Җд№ҲзүҲжң¬вҖқйғҪиҜҙдёҚжё…гҖӮжҷәиғҪдҪ“жү“зҡ„жҳҜзЎ®е®ҡжҖ§пјҢдҪ зҡ„дёҚзЎ®е®ҡжҖ§и¶Ҡй«ҳпјҢе®ғи¶Ҡе®№жҳ“жүҫеҲ°е…ҘеҸЈгҖӮиө„дә§еҸ°иҙҰиҝҷд»¶дәӢиҜҙдәҶеҫҲеӨҡе№ҙпјҢиҝҷж¬ЎжҳҜзңҹзҡ„еҲ°дәҶдёҚиЎҘе°ұжҢЁжү“зҡ„ж—¶еҖҷгҖӮ

еҚҠе№ҙиҝҷдёӘж•°еӯ—пјҢдёҺе…¶еҪ“жҲҗйў„иЁҖпјҢдёҚеҰӮеҪ“жҲҗдёҖеј иҝӣеәҰиЎЁгҖӮAI жҠҠж”»еҮ»дҫ§зҡ„жүӢйҖҹжҸҗдёҠжқҘдәҶпјҢйҳІе®Ҳдҫ§еҰӮжһңиҝҳжҢүеӯЈеәҰжҺ’жңҹпјҢе·®и·қеҸӘдјҡи¶ҠжқҘи¶ҠеӨ§гҖӮзңҹжӯЈзҡ„еҲҶж°ҙеІӯдёҚеңЁи°Ғд№°дәҶжӣҙејәзҡ„жЁЎеһӢпјҢиҖҢеңЁи°ҒиғҪеңЁжјҸжҙһе…¬еёғеҗҺзҡ„з¬¬дёҖдёӘ 24 е°Ҹж—¶йҮҢпјҢжҠҠиҜҘе…ізҡ„е…іжҺүгҖҒиҜҘеҚҮзҡ„еҚҮжҺүгҖҒиҜҘзңӢзҡ„зңӢеҲ°гҖӮ
