зҫҺеӣҪзҪ‘з»ңе®үе…ЁдёҺеҹәзЎҖи®ҫж–Ҫе®үе…ЁеұҖпјҲCISAпјүж•Ұдҝғеҗ„з»„з»Үз«ӢеҚідҝ®еӨҚ Oracle Identity Manager дёӯзҡ„дёҖдёӘВ **дёҘйҮҚе®үе…ЁжјҸжҙһ**пјҢжӯӨеүҚе·Іжңүе…ідәҺиҜҘжјҸжҙһиў«В **дё»еҠЁеҲ©з”Ё**В зҡ„жҠҘе‘ҠгҖӮ

иҜҘжјҸжҙһзј–еҸ·дёәВ **CVE-2025-61757**пјҢе…Ғи®ёВ **жңӘз»Ҹиә«д»ҪйӘҢиҜҒзҡ„иҝңзЁӢж”»еҮ»иҖ…**В еңЁеҸ—еҪұе“Қзі»з»ҹдёҠжү§иЎҢд»»ж„Ҹд»Јз ҒпјҢеҜ№дјҒдёҡе’Ңж”ҝеәңзҪ‘з»ңжһ„жҲҗдёҘйҮҚеЁҒиғҒгҖӮ

жӯӨж¬ЎиӯҰе‘ҠеҸ‘еёғеүҚпјҢд»Ҡе№ҙж—©дәӣж—¶еҖҷжӣҫеҸ‘з”ҹж¶үеҸҠ Oracle Cloud иҮӘиә«зҷ»еҪ•жңҚеҠЎзҡ„еӨ§и§„жЁЎж•°жҚ®жі„йңІдәӢд»¶пјҢжҡҙйңІдәҶи¶…иҝҮ 600 дёҮжқЎи®°еҪ•гҖӮ

Searchlight Cyber зҡ„е®үе…Ёз ”з©¶дәәе‘ҳеңЁеҲҶжһҗ Oracle Cloud зҷ»еҪ•дё»жңәзҡ„ж”»еҮ»йқўж—¶еҸ‘зҺ°дәҶиҜҘжјҸжҙһгҖӮи°ғжҹҘжҳҫзӨәпјҢ1 жңҲд»ҪйҒӯж”»йҷ·зҡ„еҗҢдёҖиҪҜд»¶ж ҲвҖ”вҖ”зү№еҲ«жҳҜВ **Oracle Identity Governance Suite**вҖ”вҖ”еӯҳеңЁдёҖдёӘдёҘйҮҚзҡ„В **йў„и®ӨиҜҒиҝңзЁӢд»Јз Ғжү§иЎҢпјҲRCEпјүжјҸжҙһ**гҖӮ

иҝҷдёҖеҸ‘зҺ°жҸӯзӨәдәҶеә”з”ЁзЁӢеәҸеңЁеӨ„зҗҶиә«д»ҪйӘҢиҜҒиҝҮж»ӨеҷЁж–№йқўзҡ„е…ій”®з–ҸеҝҪпјҢеҜјиҮҙж•°зҷҫдёӘз§ҹжҲ·еңЁВ **ж— йңҖд»»дҪ•жңүж•ҲеҮӯиҜҒ**В зҡ„жғ…еҶөдёӢйқўдёҙе®Ңе…ЁжІҰйҷ·зҡ„йЈҺйҷ©гҖӮ

жјҸжҙһеӯҳеңЁдәҺ web.xml й…ҚзҪ®дёӯзҡ„В **SecurityFilter жңәеҲ¶**гҖӮиҜҘиҝҮж»ӨеҷЁж—ЁеңЁз®ЎзҗҶиә«д»ҪйӘҢиҜҒжЈҖжҹҘпјҢдҪҶдҫқиө–В **жңүзјәйҷ·зҡ„жӯЈеҲҷиЎЁиҫҫејҸзҷҪеҗҚеҚ•**гҖӮ

ејҖеҸ‘дәәе‘ҳжң¬ж„ҸжҳҜе…Ғи®ёжңӘз»Ҹиә«д»ҪйӘҢиҜҒзҡ„и®ҝй—® Web еә”з”ЁзЁӢеәҸжҸҸиҝ°иҜӯиЁҖпјҲWADLпјүж–Үд»¶пјҢдҪҶе®һзҺ°ж—¶жңӘиҖғиҷ‘ Java еҰӮдҪ•и§ЈжһҗиҜ·жұӮз»ҹдёҖиө„жәҗж ҮиҜҶз¬ҰпјҲURIпјүгҖӮ

ж”»еҮ»иҖ…еҸҜйҖҡиҝҮеңЁ URL еҗҺйҷ„еҠ В **зү№е®ҡзҹ©йҳөеҸӮж•°**В е®Ңе…Ёз»•иҝҮиә«д»ҪйӘҢиҜҒгҖӮз ”з©¶еӣўйҳҹжј”зӨәпјҢеңЁиҜ·жұӮ URI дёӯж·»еҠ В `;.wadl`В еҸҜж¬әйӘ—жңҚеҠЎеҷЁе°ҶиҜ·жұӮи§Ҷдёәж— е®ізҡ„ WADL жЈҖзҙўпјҢиҖҢеә•еұӮ Java servlet дјҡе°Ҷе…¶дҪңдёәжңүж•Ҳ API и°ғз”ЁеӨ„зҗҶгҖӮ

иҝҷз§ҚйҖ»иҫ‘е·®ејӮдҪҝж”»еҮ»иҖ…иғҪеӨҹж— йҷҗеҲ¶и®ҝй—®еҸ—дҝқжҠӨзҡ„ REST з«ҜзӮ№пјҢдҫӢеҰӮВ `/iam/governance/applicationmanagement`гҖӮ

з»•иҝҮиә«д»ҪйӘҢиҜҒеҗҺпјҢеЁҒиғҒиЎҢдёәиҖ…еҸҜеҲ©з”ЁВ `groovyscriptstatus`В з«ҜзӮ№е®һзҺ°д»Јз Ғжү§иЎҢгҖӮе°Ҫз®ЎиҜҘз«ҜзӮ№д»…з”ЁдәҺеҜ№ Groovy и„ҡжң¬иҝӣиЎҢиҜӯжі•жЈҖжҹҘиҖҢйқһиҝҗиЎҢпјҢдҪҶдјҡжү§иЎҢзј–иҜ‘иҝҮзЁӢгҖӮ

йҖҡиҝҮжіЁе…ҘеҢ…еҗ«В `@ASTTest`В жіЁи§Јзҡ„и„ҡжң¬пјҢж”»еҮ»иҖ…еҸҜиҝ«дҪҝ Java зј–иҜ‘еҷЁеңЁзј–иҜ‘йҳ¶ж®өжү§иЎҢд»»ж„Ҹд»Јз ҒгҖӮиҝҷз§ҚжҠҖжңҜе°ҶиҜӯжі•жЈҖжҹҘеҷЁиҪ¬еҢ–дёәВ **еҠҹиғҪе®Ңж•ҙзҡ„иҝңзЁӢ shell**пјҢд»ҺиҖҢиҺ·еҫ—еҜ№дё»жңәзі»з»ҹзҡ„жҺ§еҲ¶жқғгҖӮ

иҜҘжјҸжҙһе°ӨдёәеҚұйҷ©пјҢеӣ дёәе®ғВ **ж— йңҖд»»дҪ•еүҚзҪ®и®ҝй—®жқғйҷҗжҲ–еҮӯиҜҒ**гҖӮз®ҖеҚ•зҡ„иә«д»ҪйӘҢиҜҒз»•иҝҮдёҺеҸҜйқ зҡ„д»Јз Ғжү§иЎҢж–№жі•зӣёз»“еҗҲпјҢдҪҝе…¶жҲҗдёәеӢ’зҙўиҪҜд»¶еӣўдјҷе’ҢеӣҪе®¶ж”ҜжҢҒж”»еҮ»иҖ…зҡ„зҗҶжғізӣ®ж ҮгҖӮ

иҝҗиЎҢ Oracle Identity Governance Suite 12c зҡ„з»„з»Үеә”В **з«ӢеҚіеә”з”Ёзӣёе…іиЎҘдёҒ**пјҢжҲ–е°ҶеҸ—еҪұе“ҚжңҚеҠЎдёҺе…¬е…ұдә’иҒ”зҪ‘йҡ”зҰ»гҖӮ
