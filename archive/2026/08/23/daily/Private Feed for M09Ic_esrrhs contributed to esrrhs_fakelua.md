## Summary

* Add `json` native module with `json.encode()` and `json.decode()`
* Self-contained recursive-descent JSON parser/encoder, no external dependencies
* Supports: null, bool, int, float, string (with escapes/UTF-8), arrays, objects, nested structures
* Auto-detects array vs object encoding for Lua tables
* 18 unit tests covering decode, encode, and roundtrip

## API

```
json.decode('{"name":"明朝", "provinces": 3}')  → {name="明朝", provinces=3}
json.encode({name="明朝", data={1,2,3}})      → '{"name":"明朝","data":[1,2,3]}'
```
