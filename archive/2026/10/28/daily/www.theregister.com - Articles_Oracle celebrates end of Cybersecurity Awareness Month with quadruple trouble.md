Attackers are probing a critical Oracle E-Business Suite vulnerability that can lead to remote code execution (RCE), despite Oracle issuing a patch earlier this month.

Meanwhile, new analysis indicates that an Oracle PeopleSoft zero-day exploited by ShinyHunters as early as May involves three distinct vulnerabilities that can be combined to achieve RCE. Patching alone may not remove attackers from already compromised systems, particularly if they've installed web shells.

First up: [CVE-2026-101767](https://nvd.nist.gov/vuln/detail/cve-2026-101767), a critical, unauthenticated SQL injection bug in Oracle EBS that can lead to RCE.

REG AD

“Our Oracle E-Business Suite decoys recorded exploratory exploits against CVE-2026-101767, an unauthenticated SQL injection in EBS's Thin Client Framework servlet that chains to remote code execution, this morning, Oct 27,” Defused Cyber[said](https://x.com/DefusedCyber/status/2115099999973364147) in an X post.

REG AD

Horizon3 researchers found and disclosed the bug to Oracle, and the vendor [patched the issue](https://www.oracle.com/security-alerts/cpuoct2026.html) in its October release.

“An attacker can send a crafted request to the vulnerable servlet to execute SQL with the privileges of the APPS database user,” Horizon3 explained at the time. “The attack chain also enables operating system command execution with the privileges of the EBS application account.”

This means an unauthorized user can modify application data accessible to APPS, and execute commands. “Depending on the deployment, affected data may include financial, payroll, HR, and procurement records,” the bug hunters said.

The Register reached out to Oracle with multiple questions for this story - including whether it has documented any successful exploitation of CVE-2026-101767 - and did not receive an immediate response.

Moving on to the PeopleSoft-ShinyHunters fiasco: TrendAI’s Zero Day Initiative (ZDI) found and reported the PeopleSoft issues on June 10, and Oracle issued a patch under one vulnerability identifier: [CVE-2026-35273](https://www.oracle.com/security-alerts/alert-cve-2026-35273.html).

In early June, [ShinyHunters told The Reg](https://www.theregister.com/cyber-crime/2026/06/11/shinyhunters-claims-oracle-peoplesoft-0-day-hit-100-orgs/5254443) that the group hacked more than 100 organizations via an Oracle PeopleSoft zero-day, CVE-2026-35273.
