# 岗位职责

1. 负责公司 Web 应用系统的安全测试与漏洞挖掘工作；
2. 对常见 Web 安全漏洞进行验证与复现，包括但不限于 SQL 注入、XSS、文件上传、逻辑漏洞等；
3. 协助研发团队完成漏洞修复与安全加固工作；
4. 编写安全测试报告并输出整改建议；
5. 持续跟踪常见漏洞利用手法，关注安全技术发展趋势，不断提升自身安全能力。

---

# 任职要求

1. 大专及以上学历，计算机、网络安全等相关专业优先；
2. 熟悉 OWASP Top 10 常见安全漏洞原理及防护方案；
3. 具备渗透测试实战经验，能够独立完成基本 Web 渗透流程；
4. 具备良好的沟通能力与团队协作意识，责任心强，执行力高。

---

# 加分项

* 具备代码审计能力；
* 有数据安全相关经验；
* 持有 CISP 等安全相关认证；
* 能够尽快到岗优先。
