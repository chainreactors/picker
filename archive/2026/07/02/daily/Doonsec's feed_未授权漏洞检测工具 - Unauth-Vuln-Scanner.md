02 项目介绍

项目描述

一个基于 Java Swing 的未授权访问探测工具，支持批量目标、并发扫描、SOCKS5 全局代理、CSV 导出。

主要功能

```
批量目标输入（文本框或文件导入）39+ 常见未授权服务探测（Redis、MongoDB、Elasticsearch、Docker、Kubernetes、Spring Boot、Druid 等）指纹识别（支持 HTTP/HTTPS、跟随重定向、按输入 URL 路径识别）SOCKS5 全局代理（对 HTTP/HTTPS 和 socket 探测生效）扫描结果表格展示与 CSV 导出
```
