The package reorganisation we agreed on, one move per commit. Behaviour is unchanged. Two goldens moved with their tests, and no expected output changed.

**app/kit, split by what each piece is**

* `ui/widget` gets the drawing pieces that use no app types:

  + type helpers (`UIFont`, `MonoFont`, `KickerFont`, `Caption`, `Keycap`…)
  + `Scrolled` and `KeyHint`
  + side-panel `Section` and `Stat`
  + `DialogField`

  Each comes with a test. The data card and the tests' failure label now use `KickerFont` and `MonoFont` instead of their own copies.
* `app/kit/draw`: what features draw alike using app types. That's code and its popups as the editor draws them, state marks, agent parts, signs, previews, the file preview and the folder tree.
* `app/kit/edits`: a buffer's text helpers: line edits, applying hunks, `Place`, and engine notices as core notices.
* `app/kit/desktop`: the OS folder chooser.
* `app/kit/prui`: the ship pages' views, captions, PR hook events and merge checks. `kit` keeps the general `NotifyError` and `RunOrNotify`.

**Features split out of multi-plugin packages**

* From `app/sessions`: `app/tickets`, `app/repos` and `app/jobs`. What they shared moved into kit first (a ticket's session and labels, a found repo, `agentkit.ProviderNote`).
* From `app/agentui`: `app/assistant` and `app/dictation`.
* From `app/settings`: `app/plugins` (the plugin manager, its consent screen and the Plugins page).
