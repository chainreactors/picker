# 一、从独立开发到炒股炒币，我帮大家把这个过程提提速

独立开发者 → 跨境电商 → 炒股炒币 → 外卖 / 快递 / 网约车

事情是这样，我常在抖音上刷到说程序员失业后都是先独立开发者、跨境电商、炒股炒币、然后才去外卖、快递、网约车，我只是想给大家加速这个过程，比如把独立开发和炒股炒币这个步骤给大家提个速。

既然这条路避无可避，不如直接把中间这步提速。程序员想炒股，通常会陷进两个坑：

一头扎进传统量化：找框架、调参数、跑回测、对接 API 数据源，十几天过去还在搭地基，真正想验证的那套交易逻辑连一次都没跑过。

试图从零做个独立开发：搭前端看行情、写后端记账、加 AI 引擎分析，又十几天过去，系统还没打通。

我做了一套 AI 股市模拟系统，叫《富贵》。它把这两步合成一次：方向想清楚、AI Agent 按方向跑起来，我这套的结果公开摆着，打开网站就能看。不用再从框架、回测、数据源里绕一圈，也不用从零把系统搭一遍；策略方向能换成你的，数据源也能加，你想让它按谁的思路跑，就按谁的思路跑。

它不承诺替你赚钱，也不替你找工作。但它能把一套想法，从"我觉得应该这样"，变成可持续更新、有据可查、实打实的净值收益结果。

# 二、《富贵》到底是什么

一句话定义：《富贵》就是由 AI Agent 操作的股市虚拟盘，但 AI Agent 的策略方向与数据源是由自己制定的。

先说清楚它不是什么：不是你问豆包"今天该买什么"，它甩给你一个答案，你照着买。

一轮是这样走的：

```
[ 策略方向 (你制定) ] + [ 实时行情数据 (接口拉取) ] + [ 历史真实账本 (独立结算) ]                                 │                                 ▼                    [ AI Agent 决策引擎 ]                                 │                                 ▼                     [ 生成买卖指令 / 调仓仓位 ]                                 │                                 ▼              [ 写死且独立的虚拟结算系统 (计算净值/手续费) ]
```

决策层：AI 带着"真账本"在思考

策略由你定:给定一套成体系的策略框架（如：专注红利低波、只做突破形态、关注宏观驱动等），AI 严格按照框架推理，绝不瞎发挥。

真实实时数据：行情、资讯、财报数据实时拉取，不依赖 AI 脆弱的上下文记忆。

带账本运行：AI 的每一次决策，都基于当前的真实账本——净值、可用现金、持仓盈亏、历史交易纪录。

持续动态迭代：这不是"一问一答"，而是带账本的长期生存游戏。买卖完成，账本更新，下一轮基于新账本继续演进。

AI 在这些之上做判断：得出"你现在该买什么、该不该动"，而不是一个谁都能用的通用答案。

真正值钱的不是"AI 会分析"，是它按一套定好的方向、用真实行情、基于自己的账本在分析。目标只有一个：让净值增长。

结算层：AI 碰不到的独立计账系统

也就是这套环境里的虚拟计算系统：Agent 每一个操作，赚多赚少、盈利金额、手续费、持仓浮盈浮亏、净值，全由写死的系统算出来，和实盘计算方法无异，AI 碰不到这笔计算。所以 AI 无法自行编造收益、修改持仓或者美化净值。AI 可以对市场做出错误判断，但最终账目由独立系统计算，不能由它自己决定。页面上那个净值，是系统算出来的，不是 AI 说出来的。判断可以见仁见智，账只有一本。

买完，净值、现金、持仓就变了，下一轮接着这本新账往下走。所以它不是一问一答，是带着账本一直跑下去。人容易临场改主意、情绪上头、事后给自己找台阶；它不靠这些，每轮照方向、数据和账本重新判断。

# 三、公开展示与本地闭环

完全公开，不用注册登录。这不是一个想法，是已经在线上跑着的成品：www.xxx.com。打开就能看：方向是什么、AI每一轮怎么想、买了什么、为什么卖、净值怎么走，全摊在页面上。看几天，比听我讲一小时有用。

绝不造假。不是回测曲线，不是挑好看的时间段截的图，是持续跑着、赚了亏了都实时更新的公开记录。

但要说清楚公开的是什么。www.xxx.com展示的是我这一套策略方向跑出来的东西，专门挂出来给人核的。你自己那套策略、改过的方向、接进来的数据源、每一轮的执行结果，都在你自己的本地，不会跑到这个页面上，也不由我这边保管。这个网站只管展示我这套，不收集别人的东西。

# 四、《富贵》与市面上其他产品的区别

| 方案类型 | 传统做法 | 《富贵》的解法 |
| --- | --- | --- |
| 通用 AI 问答 | 凭空提问，AI 不知道你净值多少、手里有什么、上次买得对不对，给个谁都能用的答案 | 带账本决策：每轮判断踩着真实行情和你自己的账本，上一轮说过什么、买得对不对，也会一并考虑进去 |
| 量化回测软件 | 跑的是过去，参数能一直调到曲线好看 | 跑的是现在，一天天往下走，没法回头改 |
| 模拟盘 / 跟单社区 | 人在下单，看得见买了什么，看不见为什么 | 连思考依据和事后复盘都摊着 |
| 基金 / 投顾 | 黑盒，持仓一季度才露一次，更不可能按你的想法改 | 方向明写，还能换成你的 |
| 自动交易脚本 | 写死规则机械执行，不研究、不解释、不复盘 | 每轮重估，还把理由留下来 |

单独看，这些能力市场上都有。但把策略自主权、Agent 执行、独立结算、持续运行和公开验证组合在一起，是《富贵》想做的事情；我这套跑出来的结果挂在www.xxx.com上。

# 五、策略可改、数据可加、本地随心跑

www.xxx.com上那套方向是我定的，但不是锁死的。你有自己的一套，也可以整套换进来，改完下一轮 AI 就照新方向跑——这些都跑在你本地。

策略方向自由替换：如果你有一套自己的研报逻辑或交易系统，随时换掉默认方向，下一轮 AI 就完全按你的逻辑去跑。

数据源按需扩展：行情、资讯、业绩、经济数据这些接口，是 AI 每轮判断的原料，实时更新；你觉得该多看一路数据、多一个判断依据，自己接进来就行，AI 下一轮就照着新数据重新判断。

什么时候跑、跑几次、用哪个 AI，也都随你：每天定时跑，或者只在开盘前、收盘后跑；具体几点、隔多久一轮、跑几次，都自己设。它不绑死在某一家 AI 上，workbuddy、codex、zcode、trae、opencode、claude 这些主流 Agent 都能接，你平时用顺手哪个就用哪个。它还是带着账本一直往下跑，只是这个节奏由你定。

为什么不自己写一套 Harness（AI 炒股客户端）？

两个原因。一是《富贵》面向大众，不该先让人装一套陌生的东西；二是各家模型本来就在自家工具里发挥得最好——DeepSeek 用 DeepSeek 的客户端、GLM 在 zcode 里更顺手、GPT 用 codex，自己硬做一个，干不过人家官方的。与其这样，不如直接用最顺手的那个。

为什么不做成实时监控，一直盯着盘？

《富贵》是个人工具，不是商用服务；你那套跑在自己本地，我这边也没有一套专门做实时数据的后端撑着。而真正的实时行情数据，跟你在炒股软件里看到的不是一回事——那种能随时取用的实时数据是要花钱买的，个人做量化最不好搞的就是这一环；自己去取，取得频率过高会被数据源限流、封掉。所以每轮跑的时候，取的都是实时最新的真实行情，但不是挂在那儿二十四小时连轴盯；几点跑、跑几轮，你按自己能拿到的数据条件定就行。哪天你有更靠谱的数据渠道，接进来把频率提上去，也是你自己说了算。

这不是做不到实时监控，是个人工具该有的分寸。

所以《富贵》不是一个固定策略，也不只是个给人看的页面，是\*\*「策略方向 → 实时数据 → AI 执行 → 系统结算 → 账本更新」整条能力\*\*，而且每一段基本都能按你的想法修改优化。

# 六、这套工具适合谁

说到底，它适合想证明点什么的人：把自己的技术、判断、经验、投研策略，放到一个能持续跑、每轮结果都留得下来的地方，亲手折腾。

对 AI 感兴趣的人：想验证 AI 炒股到底能不能赚钱——不靠感觉，看它按定好的方向跑下来的净值。

程序员：想验证自己的技术结合 AI 能不能在金融市场变现——从数据那块入手，多接几路数据源，把广度和深度加宽，看判断会不会跟着变。

金融从业者：把自己专业的策略、想法放进去，用持续跑出来的结果验证它可不可行——不是看某一次判断准不准，是看能不能一直站得住。

资深股民：想证明自己对市场的想法、自己的投研逻辑站不站得住，净值就是最直接的记分牌。

投资内容创作者 / 自媒体博主：想证明自己说过的话——看好某个行业未来会涨、有一套投资策略、判断当前市场处于某个周期、想公开验证自己的判断。

《富贵》把这些想法变成持续跑着、带依据、带账本的记录；判断和结果都在收益那摆着，每轮判断、每次买卖、账本怎么变，本身就是能持续产出的内容素材。

共同点就一个：喜欢折腾，也愿意让结果一直摆着，由时间去回答。
