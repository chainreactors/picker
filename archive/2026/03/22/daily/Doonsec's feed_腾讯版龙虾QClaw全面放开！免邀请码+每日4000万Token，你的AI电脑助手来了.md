> 它终于对所有人开放了。

等了很久，腾讯 QClaw 终于宣布**全面放开**——不再需要邀请码，任何人都可以直接下载安装，开箱即用。

如果你之前一直听说过这个"AI 电脑助手"但没机会体验，现在是时候了。

## QClaw 是什么？

简单说：**QClaw 是一个 7×24 小时待命的 AI 电脑助手**，由腾讯出品，基于 MCP + AI Agent 架构打造。

它能做什么？你说什么，它干什么。

* 帮你整理桌面文件、处理邮件
* 定时推送热点资讯、每日简报
* 自动执行重复性工作任务
* 通过手机远程操控你的电脑

不只是一个聊天机器人——它是一个能真正"动手"的 AI 代理。

## 这次放开，有什么变化？

### 🎫 无需邀请码，直接用

之前要填写申请表、等待审核、获取邀请码——这套流程门槛挺高。现在全部取消，访问官网直接下载，扫码绑定即可。

### 💰 每日 4000 万 Token 免费配额

这是这次更新最实在的地方。

QClaw 内置了**每日 4000 万 Token** 的免费额度，日常使用（整理文件、写报告、聊天问答）完全够用，哪怕重度使用一天也很难跑满。

你可以在客户端的「设置 → 用量统计」实时查看今日消耗和剩余 Token。

## 远控通道：微信/QQ/飞书/钉钉全支持

这是 QClaw 最强的功能之一。

通过配置「远控通道」，你可以**在手机上、在聊天软件里**直接和你的 QClaw 对话，让它帮你操作电脑——无需打开电脑，无需远程桌面。

目前支持的渠道：

| 渠道 | 说明 |
| --- | --- |
| 微信（推荐） | 扫码关联，在微信联系人中直接对话 |
| 企业微信（推荐） | 扫码关联，支持企微群聊或私聊交互 |
| QQ（推荐） | 极简配置，快速接入 |
| 飞书 | 接入飞书机器人，无缝衔接办公流程 |
| 钉钉 | 接入钉钉机器人，团队协作更高效 |
| 微信客服号 | 关联客服号，历史会话长期保存 |

想象一个场景：你出门在外，临时需要查一份报告，发个微信给 QClaw——它帮你在电脑上找到文件、整理成摘要，直接回复给你。

## 怎么安装？

**第一步：下载**

访问官网 https://qclaw.qq.com[2] 下载适合你系统的客户端（Windows/macOS 均支持）。

**第二步：扫码绑定**

安装完成后，打开 QClaw，用微信扫码绑定账号，完成授权。

**第三步：开始使用**

在对话框输入指令，或者从「灵感广场」选择模板，AI 立刻开始工作。

整个流程不超过 5 分钟。
