# 阿里云安全Agentic SOC招聘AI安全研发专家

[![](/images/default-avatar.png)阿里云先知](/users/90660)·2026-11-27 15:15·2 分钟·220·招聘专区

阿里云安全Agentic SOC招聘AI安全研发专家

**职位描述：**

1. 大规模 Agent 调度体系建设： 主导或核心参与 Agentic SOC 调度底座的架构设计与研发，攻克海量安全告警并发触发场景下的 Agent 高并发调度、任务优先级队列、动态负载均衡、弹性扩缩容及推理资源/Token 配额管控难题。
2. 智能应急响应（Agentic Response）研发： 负责安全事件应急响应核心功能的设计与落地，构建多智能体协同编排与安全工具调用框架，实现告警研判、遏制隔离、处置建议与自动化闭环的端到端交付。
3. 安全与可观测底座构建： 打造面向多租户环境的 Agent 运行时安全边界与审计体系，包括代码/工具执行沙箱隔离、权限最小化控制、人工审批门禁（Human-in-the-loop）及全链路调用追踪与异常熔断自愈。
4. Agent 核心能力工程化： 推进推理规划、长短期记忆、MCP 工具生态接入及上下文工程等能力的落地，持续提升安全研判与处置的准确性与响应效率。
5. AI-Native 工程体系与跨团队协同： 推动团队向 AI 时代研发模式演进，建立覆盖 AI 辅助编码/Review、Agent 自动化评测（Eval）的新型工程规范；与安全算法、检测引擎、产品及基础设施团队紧密协同，构建“数据-模型-工程-运营”快速迭代闭环，驱动 Agentic SOC 产品化落地与核心指标（MTTR 缩短、自动化闭环率、研判准确率）持续提升。

**职位要求：**

1. 本科及以上学历，计算机科学、网络安全、人工智能等相关专业；
2. 3 年以上后端或安全产品研发经验，精通 Go / Python / Java / Rust 中至少一门语言，具备良好的系统设计能力与代码工程素养，熟悉云原生基础架构（K8s、容器安全隔离等）；
3. 深入理解 AI Agent 核心技术栈，具备任务规划、工具调用（MCP / Function Calling）、工作流编排、多 Agent 协同、上下文裁剪与模型路由的实战经验；有 LangChain、LlamaIndex、LangGraph、AutoGen 或自研 Agent Framework 经验优先；
4. 具备出色的独立分析与解决问题能力，技术自驱力强，能快速适应高节奏的产品迭代并推动跨团队落地。

**加分项：**

1. 对安全领域有深入理解，具备安全攻防、威胁检测或安全运营（SOC/SOAR）相关知识背景；
2. 有安全方向的 Agent 应用开发经验，如安全告警研判 Agent、自动化响应 Agent、威胁狩猎 Agent 等；
3. 具备全栈（前后端）开发经验，能够借助 AI 编程工具高效完成从底层服务到上层人机协同交互界面的端到端交付。

**工作地点：**

北京、杭州
