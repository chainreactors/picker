# 科技云报到：88%的企业都在用Agent，为什么赚到钱的不到一成？

科技云报到原创。

2026世界人工智能大会上，有一组数字被反复提起：全球88%的企业内部已经跑着Agent，但真正赚到钱的，不到一成。

更耐人寻味的是另一个细节——过去两年里，不少企业一度拿token的消耗量来证明自己有多“智能”，烧得越多，仿佛就越先进。

热闹了两年，Agent终于走到了要交答卷的时候。而这张答卷上的题目，也悄悄换了：不再是“你能做什么”，而是“你到底交付了什么”。

7月20日，容联云在上海世博中心办了第四届WAIC企业级Agent论坛，主题很直接——“企业级Agent的进化与商业化落地”。

这家从呼叫中心和联络平台起家、服务过两三万家企业、线上线下管着上百万坐席的公司，这两年一直在琢磨同一件事：Agent怎么才能从“用起来了”，走到“赚到钱了”。

**企业要为确定的收益买单**

88%和不到10%这组数字，是容联云产研中心副总经理唐兴才在论坛上抛出来的。

他还补了一个更扎心的观察：很多企业把token消耗量当成了自己智能化程度的标尺，消耗得多，就觉得自己走在了前面。

![]()

容联云产研中心副总经理 唐兴

但这套逻辑今年明显不灵了。

本次Waic企业级Agent论坛上，邀请到了从产业联盟到零售、金融、电子签名等一线厂商，嘉宾们从不同角度，阐述了一件事儿–AI Agent已经从消耗走到了向企业交付结果的阶段。

中关村数智人工智能产业联盟秘书长贾昊表示，行业正在经历一轮退潮：“潮水退去始见礁石，热度退去方显真章。

”C端“养虾”“养马”式的尝鲜热潮已经散去，相关项目的GitHub下载量也在往下掉。

当喧嚣落幕，留在桌面上的只剩一个冷冰冰的问题：这东西，到底帮我挣钱了没有。

做零售数字化的多点数智，副总裁张宇的感受最直接——现在的客户不再问“你的系统有什么功能”，张口就是“你有什么办法帮我提销量、降损耗”；深耕电子签名的e签宝，创始人金宏洲则一句话点破：“最终检验标准，就是客户买不买单、用不用得好。”

一场论坛下来，共识清晰得几乎不用总结：AI Agent的考核方式变了。企业不再为“可能性”付费，而是要为“确定的收益”买单。

**多数企业卡在 “工具没长进流程”**

要回答“怎么交付结果”，得先弄清楚Agent究竟是怎么一步步走进企业的。

唐兴才在演讲中给出了一套四阶段的框架，这也是容联云自己趟了四年趟出来的路。

第一阶段，是Copilot式的单点能力。人发一条指令，AI干一件小活——生成通话小结、提取标签，此时它更像人手边的一个功能，还谈不上真正的Agent。

第二阶段，是独立的任务闭环。随着模型能力提升，AI能完整跑完一个任务，比如“分析最近30天的通话里，有没有投诉风险、有没有被销售漏掉的商机”。这时人和Agent是一比一的关系，每个人配一个助理。

第三阶段，是人机协作。Agent不再只是完成孤立的任务，而要嵌进企业原本为“人”设计的业务流程里。到了这个阶段，一个人可以带着十个Agent一起干活。

第四阶段，才是纯正意义上的Agent——自主完成业务闭环。订餐、办卡、信审、回访，整件事Agent自己就能办完，全程不需要人插手。

这套框架真正的价值，是给行业提供了一把定位的尺子。

唐兴才的判断是，今天绝大多数企业，恰恰卡在第二、三阶段之间——工具是买了，但没长进流程里，自然也就产生不了价值。那10%和90%之间的鸿沟，与其说是模型的差距，不如说是阶段的差距。

容联云在推进过程中，还撞见了一个反常识的发现。

起初大家默认，应该是Agent去适应企业既有的固化流程。可真跑起来才发现，事情反过来了——是人要去适应Agent的工作方式，效率才能拉到最高。

最典型的就是坐席：过去他每天最重要的工作是背话术、背知识库，如今Agent已经把整个知识库吃得透透的，坐席的活儿，变成了审核Agent给出的建议，点“查看”、点“确认”、点“使用”。

某种意义上，他从一个话务员，变成了模型的“训练师”——每一次确认，都在把这个Agent调教得更聪明一点。

**考核不看意图识别准不准只看订单转化率**

想让Agent真正扛活，光有一个聪明的模型远远不够。容联云的做法，是把三件事一件件做实。

第一件，是让Agent“看得见数据”。企业里的CRM、工单、财务系统，原本各管各的，Agent接进来若是两眼一抹黑，就成了聋子瞎子。

容联云的解法，是在Agent和这些业务系统之间搭一层数据语义层，把订单、合同、工单这些东西抽象成Agent能理解、能调用的对象。而且整个过程不改变员工原有的操作习惯，只是把原来靠人工处理的环节，悄悄升级成智能审核或执行。

第二件，是给Agent“立规矩”。企业最怕大模型信口开河。

容联云按场景对随机性做分层管理：金融这类强合规场景管得严，零售营销场景则适当放开；具体靠Prompt提示词、Skill技能约束、编排引擎三层机制层层收口，外加一个独立的质检平台兜底，一旦输出跑偏，可以紧急熔断。

第三件，也是最见辨识度的一件——像考核员工一样考核Agent。

外呼、信审、收单，每个Agent都背着自己的KPI。

考的不再是“意图识别准不准”这类技术参数，而是订单转化率、工单了结时长、GMV贡献这些实打实的业务指标。

考核不达标，不像对人那样扣工资，而是回过头去优化评价规则、打磨模型能力。

这背后是一次身份的切换：软件时代，企业买的是工具，用得好不好是自己的事；到了Agent时代，容联云把自己放到了“劳务交付”的位置上——交付的不再是一套系统，而是一份干完的活。

**敢对KPI负责，是未来Agent的真正衡量标准**

今年6月，容联云一口气发布了Voice Agent和私域运营Agent，两款产品，也是两笔算得清清楚楚的账。

Voice Agent瞄准的，是催收、客服、营销这些最“熬人”的语音岗位。目前它在线上日均能跑约2万通会话，对话完成率约94%。

产品里最见功力的一处设计，是“催收专员Agent→催收主管Agent→真人坐席”的逐级转接——专员Agent处理不了，转给主管Agent，还搞不定，再转真人。它对准的，正是每个人都体会过的那种烦：一通电话被转了七八个部门，却始终没人真正解决问题。

私域运营Agent破的则是人力的天花板。一个运营人员，撑死了管几千到几万个客户；而Agent能一口气管到几十万。

一个大健康赛道的标杆客户，就靠它管理着8万私域客户，月度经营GMV约120万元，经营规模同比增长87%。

但最能说服企业的，还是那笔直白的成本账。

一个人工坐席，月成本5000到8000元，一天打150到300通电话就已接近饱和，还得先培训一两个月，人一走，积累的经验就清零；换成Agent，月成本2000到3000元，24小时连轴转，一天能处理2万通以上，服务标准统一，不闹情绪，而且所有经验都沉淀在企业自己手里。

容联云并不回避Agent的短板——它坦承，如今Agent的水平还达不到优秀员工，多数场景只有优秀人员的70%到80%。

但账不是这么算的：“及格线之上，加上边际成本趋近于零”，这个组合已经足够改写一家企业的用人结构。

更进一步，这笔账如今被直接写进了商业模式。容联云今年开始在催收这类能直接创收的场景里试水“效果付费”——按回款率分成，跟客户一起担风险。

当然，边界也划得很清楚：这条路目前只在能直接创收的场景走得通，像质检这种习惯了按软件付费的老场景，客户的采购习惯短期内还改不过来。这条路究竟能走多宽，仍要交给更多行业去验证。

**深耕行业的Know-how，成就真正的护城河**

论坛的圆桌环节，把话题推到了更远处。

做了十年AI商业落地研究的亿欧董事长王彬提出，真正值得关注的，是那些“语料成本为负”的公司——在外呼这样的场景里，客户是付着费在使用服务，数据却在业务过程中自然而然地产生，还天生带着泛化能力。

换句话说，别人是花钱买数据，有的公司却是一边收着钱，一边把数据攒了下来。在大模型时代，这是一个极难被复制的身位。

这也解释了容联云为什么敢在效果付费上先迈一步——Agent下半场真正的壁垒，从来不在基座模型上。

催收要懂法律法规和权限边界，健康要懂复购周期，这些行业里的Know-how，买不来，也抄不走，只能在真实的业务里，一天一天跑出来。

容联云给出的判断是，留给行业的窗口期，可能只有3到6个月。谁先把ROI跑通、率先进入规模化复制，谁就先把护城河挖了出来。

Agent的热闹，属于所有人；Agent的结果，只属于那些把它真正长进业务里的人。
