The v0.0.1 release failed at its test stage ([run 41643738234](https://github.com/liamg/oriel/actions/runs/41643738234)). This branch gets CI green on macOS and Linux and fixes what the failures turned up in the app.

**CI and the test harness**

* Spotlight was indexing everything the tests write on the macOS runner and starving them: it's off there now, and macOS runs two packages at a time.
* Tests no longer touch the network or the user's credentials (`isolate.Test` hides tokens, stubs `gh`/`security`).
* Snapshots tolerate arm64's float rounding; a snapshot waits for the gutter's explain marks; clicks wait for what they click to be drawn and settled; a scene's waits on the state draw frames, so what the loop has queued runs.
* The ghostty wasm check accepts one known variant zig builds on Zen 5 runners (`term/ghostty/wasm/VARIANTS`): one function compiles differently there, data identical.
* Many test races fixed: waits for deliveries, diagnostics, git status, the update check at start, forms' previews.

**Plugins live as long as the app**
Switching to a session in another directory moved the window by restarting every plugin, which lost in-flight events and broke tools mid-turn. Plugins now stay up and the window moves under them (`DirChanged`, `Window.Hold`, `Window.Arrived`); docs updated.
