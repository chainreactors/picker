# 一个具有黑客感的无线开源情报与信号情报平台

WireTapper 是一款尖端的无线开源情报（OSINT）与信号情报（SIGINT）平台。它就像是调查员和安全专家的“电子鹰眼”，能够让肉眼看不见的无线电信号变得可视化、可追踪、可分析。

可以直接使用python去运行web端，在github开源。

非常具有黑客感。

### 📶 支持信号情报

WireTapper 可以识别和分析来自以下来源的信号：

1、Wi-Fi 接入点和客户端，Wi-Fi 凭证泄露
2、蓝牙和低功耗蓝牙设备
3、无线闭路电视/IP 摄像机
4、车辆广播射频信号（信息娱乐系统、遥测系统、无钥匙系统）
5、耳机、可穿戴设备和智能设备
6、智能电视和物联网设备
7、基站和移动网络信标

但需要配置以下API,想搭建的考虑下。

### 🔑 API 服务

WireTapper 集成了多个外部服务以提供情报。您需要从以下渠道获取 API 密钥：

Wigle.net – 无线网络映射和发现。
wpa-sec – 分布式 WPA-PSK 审计数据库。
OpenCellID – 开源基站数据库。
Shodan – 互联网连接设备的搜索引擎。
`注意`： 使用此工具时，需要 Shodan 的 API 高级帐户 。
