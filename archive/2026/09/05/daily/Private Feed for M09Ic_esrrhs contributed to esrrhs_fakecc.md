This PR enables two GCC torture test categories that were previously skipped:

## 1. Complex function pointer declarators (930126-1.c)

K&R function declarations with function pointer return types:

```
T*L92(T*),*L15(T*),*L14(T*),*L13(T*),*L12(T*),*L11(T*),*L10(T*),*L9(T*),*L8(T*),*L7(T*),*L6(T*),*L5(T*),*L4(T*),*L3(T*),*L2(T*),*L1(T*);
```

The parser now correctly handles comma-separated declarators where subsequent declarators start with `*` (function pointer return type prefix), correctly sharing the base return type from the primary declarator.
