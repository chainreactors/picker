为适应公司业务范围调整的变化，进一步提升白帽师傅与平台的体验，**BSRC现对业务系数进行相应更新**，产品线评级范围更清晰！

注：业务系数更新生效时间为7月16日17:00～⏰

业务系数是按照百度业务线及产品的重要性来进行划分的，分为高中低三个类，每类有对应的系数范围。

**【系数 7~10业务产品线】**

主要是包括但不限于百度高体量业务及产品线的核心域名、IP及客户端，如：

* 百度搜索（www.baidu.com、m.baidu.com等）
* 百度帐号系统（passport.baidu.com）
* 百度云

+ 服务器（云服务器、轻量应用服务器等）、千帆、BOS、IAM、AIHC、RDS、CDN

* 百度 DuerOS
* 百度APP

+ 个人中心基础组件（例如订单，消息，收藏，历史等）

* 百度地图

+ 驾车：驾车算路、驾车导航、导航红绿灯、实时停车（停车推荐+实时排队/满空预测）、车道级导航、驾车新手算路、限行提示
+ 公交、步骑行：步行算路/导航、公交算路、跨城公交、骑行算路/导航、实时公交/地铁
+ 周边：美食、酒店、景点、休闲玩乐、加油站
+ 出行助手：目的地预测、常用功能、常用地址
+ 检索：精搜、泛搜
+ 数字资产：语音包
+ 语音助手：小度想想
+ 智能交通：实时路况
+ 打车、定位、推送、图像（底图）

* 百度文库
* 百度网盘
* 萝卜快跑

+ 交易系统：价格与补贴策略配置、路线选择 / 站点选择、实时计价与价格策略、下单、改派、取消、支付与结算等；
+ 运力调度系统：车辆实时调度、供需匹配、路线策略配置等；
+ 安全与风控体系：行程监控、异常预警、紧急接管、合规管理及数据等；
+ 路线与运营配置平台：路线开关管理、站点启用/禁用等；

**【****系数2~6业务产品线】**

主要是百度重要业务产品线的域名、IP 及客户端，包括但不限于：

* 7-10业务产品线中未包含的功能模块等（如百度地图下未提及的功能）
* 百度贴吧、百度知道、百度百科、百度翻译、百度输入法、百度健康、百度热搜、百度OTA、小度
* 百家号、爱企查、百度优选开放平台、橙篇、百度教育
* 百度营销、百度优选、营销通、爱采购、百度统计、企业号、度星选、基木鱼开店、爱番番
* 如流、飞桨、hogee、伐谋、秒哒、duclaw、dumate、comate、文心一言、一见

**【系数1业务产品线】**

主要是除以上系数业务产品线以外的其他业务及产品线、百度拆分业务（子公司业务、孵化业务或已出售业务，BSRC 只收影响百度域名的漏洞，如太合音乐、度小满金融等平台的问题建议直接反馈给站点官方）：

* 百度游戏
* 百度视频
* YY全民娱乐直播
* 百度阅读
* 其它等上述未提及产品

**重要说明**

**NOTICE**

* 此业务系数仅代表 BSRC 对具体安全问题的评分参考标准，后续BSRC会根据公司业务范围变化动态调整相关系数。

* 平台的评分标准特殊说明也做了相应调整。详情见BSRC官方平台，一切以官网公告内容为准：https://bsrc.baidu.com/v2/#/announce/264?language=zh
