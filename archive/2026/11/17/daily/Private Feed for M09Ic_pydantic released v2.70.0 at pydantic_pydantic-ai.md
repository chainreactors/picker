## What's Changed

### 🛡️ Security

* [GHSA-m4cr-m4qc-9hh3](https://github.com/pydantic/pydantic-ai/security/advisories/GHSA-m4cr-m4qc-9hh3) (high): With `strip_ansi=True`, Pydantic AI Harness's `ToolOutputLimits` capability removed ANSI escape sequences with a pattern that took time quadratic in the length of a line, so a tool result of a few hundred kilobytes with many unterminated escape sequences could occupy the event loop for tens of seconds to minutes. You are affected if you set `strip_ansi=True` (named `OverflowingToolOutput` before 0.13.0) and run tools whose output an attacker can influence. Fixed in `pydantic-ai-harness` 0.70.0.
* [GHSA-5m5q-5qj4-gx9h](https://github.com/pydantic/pydantic-ai/security/advisories/GHSA-5m5q-5qj4-gx9h) (high): The `jwt` pattern in Pydantic AI Harness's secret redaction backtracked in time quadratic in the length of the text it scanned, so a few hundred kilobytes of crafted text could occupy the event loop for tens of seconds to minutes. You are affected if you use `redact_secrets` or `secret_data()` with the `jwt` pattern, which is included by default, on text an attacker can influence. The fixed pattern no longer matches a JWT whose header segment contains `-eyJ`. Fixed in `pydantic-ai-harness` 0.70.0.
