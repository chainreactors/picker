## Summary

Completes IPv6 support end-to-end (follow-up to the gohome ricmp change).

* **SOCKS5**: CONNECT replies now use `ATYP=IP6` for IPv6 control connections; UDP ASSOCIATE opens the relay socket in the client's address family and returns a reachable same-family relay address.
* **SOCKS5 client test helper**: parses replies by `ATYP` instead of a fixed 10-byte read.
* **HTTP CONNECT / Shadowsocks target / config generation / pprof**: use `net.SplitHostPort`/`JoinHostPort` so IPv6 literals are bracketed correctly.
* **ricmp over IPv6**: bumped `gohome` to `v0.0.0-20261002003618-c163b37d7f64` (already merged upstream; dual-stack wildcard listen, ICMPv6 echo 128/129).
* **Tests/docs**: IPv6 e2e (PROXY/SOCKS5 CONNECT/UDP ASSOCIATE/HTTP/ricmp) and unit tests, plus an IPv6 section in USAGE.md.

## Verification

* `go build ./...`, `gofmt`, `go vet` clean
* Full `go test ./...` passes locally (proxy package)
* Privileged raw-socket tests (CAP\_NET\_RAW) pass on macOS for ricmp v4...
