> 在很多机房和弱电机房里，UPS常被戏称为“沉默的保镖”。平时不声不响，一旦停电，它就必须第一时间顶上去。但现实是：绝大多数UPS故障，并不是发生在停电那一刻，而是倒在了“平时没人管”的日常里。

01

# 为什么说 UPS 巡检不是“走个过场”？

# 一、电池是消耗品，不是“永动机”

UPS的核心在于蓄电池，而电池的寿命通常在3~5年。长期浮充、环境温度过高、单体电压不均衡，都会悄悄缩短它的寿命。

* 巡检能提前发现落后电池，避免关键时刻整组失效。

# 二、电容、风扇比你想象的更早老化

很多UPS主机“看着正常”，但内部电容鼓包、风扇转速下降，会在负载突增或切换时直接宕机。

* 定期测量波形、听音、测温，是在替你排查看不见的隐患。

# 三、参数漂移，会在最不该出错的时候出错

市电异常阈值、转旁路条件、关机延时……这些参数一旦被人误改或恢复出厂，可能在一次浪涌中就切错模式。

* 巡检就是给UPS做一次“体检+校准”。

# 四、灰尘和散热，是机房里的慢性杀手

滤网堵塞、风道积灰，会让UPS在夏天高温天频繁告警。

* 清洁与红外测温，是成本最低、收益最高的维护动作。

02

# 巡检频次（推荐）

# 一、日常/每周巡检（运维人员）

* 频次：每周1次（重要机房可每日远程查看告警）

* 方式：现场查看或通过网络管理卡（SNMP/Web）远程检查

* 内容：

（1）UPS运行状态指示灯（绿色正常/黄色告警/红色故障）

（2）有无异常声响（风扇异响、变压器嗡鸣变大）

（3）显示屏显示：输入/输出电压、负载率、电池电压、电池充电状态

（4）环境温湿度、通风是否良好，进出风口无堵塞

（5）有无漏液痕迹（阀控式铅酸电池重点看）

（6）查看是否有告警记录/事件日志（旁路、电池低压、过载等）

# 二、月度巡检（运维+电气专业人员）

* 频次：每月1次

* 额外检查：

（1）紧固端子/连接排（无明显松动、氧化、过热变色）

（2）测量UPS输入/输出/直流母线电压、电流是否正常范围

（3）检查电池组单体电压均衡性（偏差一般 ≤±0.03～0.05V/2V单体）

（4）清洁滤网、风扇灰尘

（5）核对时间、日志存储、通信链路（短信/邮件告警是否正常）

# 三、季度深度维护（厂家或持证电工）

* 频次：每季度1次（建议原厂或授权服务商）

* 包含：

（1）电池组容量核对性放电试验（放出额定容量的30%～40%，大型机房可做全核对性放电但需谨慎）

（2）内部电路板、电容、风扇老化检查

（3）静态旁路/逆变切换功能测试（在许可停机窗口进行）

（4）接地电阻、绝缘电阻检测

（5）出具维护报告并更换劣化电池

03

# 巡检执行条件与要求

# 一、人员资质

* 日常巡检 → 机房值班/运维人员即可

* 开柜检查、电气测量、电池放电 → 持特种作业操作证（低压电工），建议双人配合

* 深度保养 → UPS厂家工程师或经培训的专业维保团队

# 二、运行条件

* UPS应处于正常逆变/市电模式运行，不在正在切换/过载/电池放电状态（除非专门做放电测试）

* 电池放电试验需在负载稳定、市电可靠、备有应急方案时安排（避免完全放空导致宕机）

* 巡检时禁止断开电池组直流开关/熔丝（会导致失去保护）

# 三、环境要求

* 机房温度20～25℃（阀控式铅酸电池 电池最佳20～22℃），湿度40%～60%

* 避免粉尘大、腐蚀性气体环境

* UPS前后左右预留散热空间（通常 ≥15cm）

# 四、必须记录的内容

* 巡检时间、巡检人

* 输入/输出电压、电流、负载百分比

* 电池组总压、浮充电流、每只电池端电压

* 环境温度、异常现象及处理措施

* 告警事件及复位情况

04

# 需立即处理的告警（不停机等但速报）

· 电池故障/电池熔丝断

· 过载 > 预警阈值（通常 80%～90%）

· 旁路运行且无法切回逆变

· 机内过温、风扇故障

· 市电异常频繁闪断

#

# 写在最后

UPS的价值，不在于它能亮多少灯、响多少次蜂鸣，而在于——当你最无助的那几分钟里，它是不是真的撑得住。与其在故障后补救，不如在巡检中预防。
