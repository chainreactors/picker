## Windows Server 移除对 32 位应用的支持

[![Windows](https://icon.solidot.org/images/topics/topicwindows.png?123)](/search?tid=33 "Windows")

[Edwards](/~Edwards) (42866)发表于 2026年11月24日 22时04分 星期二 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85978&appkey=1370085986&title=Windows%20Server%20%E7%A7%BB%E9%99%A4%E5%AF%B9%2032%20%E4%BD%8D%E5%BA%94%E7%94%A8%E7%9A%84%E6%94%AF%E6%8C%81 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自星际归途**

微软宣布下个版本的 Windows Server—— Windows Server 2028——将移除允许 32 位 Windows 应用运行在 64 位操作系统上的兼容层。这意味着新操作系统不再默认包含 WoW64 兼容层——WoW64 让 32 位应用能在 64 位 Windows 环境中运行。Windows Server 最后一个 32 位版本发布于 2008 年，此后的所有版本均为纯 64 位系统。WoW64 子系统此前一直存在于 64 位 Windows 中，旨在确保 32 位应用能在 64 位系统上继续运行。但在 Windows Server 2028 中，这一 32 位兼容层将转变为可选组件，用户如有需要，可自行手动安装。微软项目经理 Elden Christensen 表示：“我们确实要移除 WoW64 子系统。此举将提升系统的安全性，特别是在防范 32 位恶意程序——这意味着 32 位恶意程序将无法在 Windows Server 2028 上运行。”此外此举也有助于减小操作系统安装后的占用空间。
