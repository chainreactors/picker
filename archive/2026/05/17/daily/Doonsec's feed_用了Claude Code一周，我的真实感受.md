# 一、 Claude Code到底是什么？

Claude Code 不是传统的“代码补全插件”，也不是你在网页上问 AI 写一段代码那种对话工具。它运行在终端里，是一个能自主工作的 AI 代理：

可以读取你整个项目目录，理解代码结构和依赖关系；

能自己执行命令、跑测试、修改文件、创建提交；

你只需要用自然语言告诉它想要的结果，它会像真人工程师一样规划步骤并执行。

对于很多工程师来说，这意味着：可以跳过“看懂全部代码 → 找库函数 → 调试测试”的繁琐过程，直接用业务语言指挥它干活。

# 二、 国内想用上Claude Code，真得费一番功夫

先说一个不太愉快的现实：在国内正常使用 Claude Code 门槛不低。

网络限制：Claude 官方服务无法直接访问。

付费：Claude Code 需要订阅，对个人来说不算便宜。（虽然也有免费的方法。。。）

注册流程：需要海外邮箱、手机号，很多人卡在这一步。

我用了大半个周末才搞定环境：找网络方案、配置 API 中转、安装 Node.js，设置 ANTHROPIC\_BASE\_URL 走第三方代理。如果你是第一次接触终端或命令行，可能会更吃力。

# 三、真实使用场景：三个通俗的例子

下面是我用 Claude Code 完成的一些实际情况，都很接地气。

## 场景1：整理家庭照片的备份文件

我家里有好几个硬盘，照片文件夹散乱不堪，文件名有各种格式（IMG\_1234.JPG、2023-01-01 北京.jpg、微信图片\_20231231.jpg）。我想按拍摄日期统一重命名，并去重。

我跟 Claude Code 说：“把这个文件夹里所有 jpg 和 png 文件，读取 EXIF 信息里的拍摄日期，如果没有 EXIF 就按文件修改时间，格式改成 2025-02-15\_001.jpg 这样，并且把完全相同的图片（不管文件名）只保留一份。” 它生成了一个 Python 脚本，自己运行了一遍，遇到了几个没有 EXIF 的老照片还主动问我“按修改时间处理可以吗？” 我确认后，几百张照片几分钟就整理完了。

## 场景2：统计我每个月的家庭开支

我把用微信和支付宝消费，导出月账单 CSV文件，但两边的格式不一样，手动合并很烦。

这次我对 Claude Code 说：“把这个目录下微信和支付宝的账单 CSV 合并成一个总表，统一列名（时间、金额、对方、类别），然后按类别统计每月支出，最后画一个简单的条形图。” 它生成了 pandas 脚本，自动识别了两种 CSV 的列差异，还帮我映射了“餐饮”“购物”等常见类别。整个过程我只需要回答几个关于类别映射的问题，一张支出统计表和图表就出来了。

## 场景3：从一堆网页里提取特定信息

例如，我想买一台二手显示器，在几个论坛和二手平台上有几十个帖子，希望把型号、价格、联系方式和发帖时间自动提取到一个 Excel 里。

我跟 Claude Code 说：“帮我写一个脚本，读取当前文件夹里所有 html 文件（我提前保存的网页），用正则或解析器找出提到的显示器型号、价格数字、联系 QQ 或微信，以及页面上的时间，输出到 Excel 里。” 它写了 Python 脚本并用 beautifulsoup4 去解析，还提示我可能需要手动调整一下不同网站的选择器。我稍微改了两个地方，就得到了一个干净的信息表，省了我一下午的手动复制粘贴。

# 四、三个惊喜与三个槽点

## 惊喜

## 理解项目全局

它能主动扫描我整个文件夹，知道哪些文件是数据、哪些是脚本，跨文件操作很顺手。

## 主动验证结果

写完代码后它会自己试跑一下，然后告诉我“成功了”或者“哪里还有问题”。这种闭环感很省心。

## 自然语言指挥复杂任务

我不用记一堆 Python 库的用法，直接用生活语言描述，它就能落地。

## 槽点

## 有时候过于啰嗦

一个小改动它也给你写一大段分析。可以提前跟它说“请简洁回答”。

## 复杂任务可能绕圈

有一次让它优化照片去重逻辑，改了好几版，每一版都有新问题，最后我手动回滚了。高阶任务还是得有人盯着。

## 错误提示不友好

出错了通常是一段堆栈信息，对我这种非专业开发来说有点吓人。不过把报错贴回去问它，它自己能解释原因。

# 五、 一些让 Claude Code 更好用的小技巧

基于一周的使用，我总结了几个适合个人日常场景的用法：

任务分步做：别一次性说“帮我做完整的家庭财务系统”，而是先“合并账单”，再“统计分类”，再“画图”。成功率更高。

给它“背景知识”：在项目根目录放一个CLAUDE.md文件，写清楚数据格式、常见规则，它会自动读取，理解更准。

保留监督权：涉及删除文件、批量改名的操作，我会先让它“只生成代码，不执行”，我审查后再让它运行。

善用“请简洁”：一开始加一句“请用尽量少的文字回答”，能有效减少废话。

# 六、顺便一提：Claude Code未来可能帮到我工作的方向

虽然公司现在不允许在工作环境用这类工具，但我一直在关注它的发展。作为信息化工程师，我最关心的是它能不能对接PLM、OA、ERP这些企业系统。

在研究过程中发现，Claude Code 已经有插件可以接入 SAP 开发环境。比如SuperClaude for SAP这个插件，能让 Claude Code 直接操作 ABAP 对象（类、函数模块、报表、CDS 视图等）。也就是说，理论上可以用自然语言指挥它去：

查看某个 SAP 标准函数的逻辑；

生成一个 Z 程序框架；

修改 RFC 接口的字段映射。

---

# 七、总结：谁适合尝试一下Claude Code？

信息化工程师、IT 从业者：如果公司允许使用，且愿意花钱，还是一个很好的提效工具。

有基本代码逻辑、但不是专业开发的人：比如数据分析爱好者、学生、小型创业者。

对 AI 编程代理感兴趣的技术爱好者：过程挺费事，但体验一下未来工作方式的乐趣还是有的。

当然，前提是你能接受在终端里工作、愿意花一两小时突破网络和配置障碍。
