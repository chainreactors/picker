AI Agent 已深度融入安全测试工作流，辅助白帽研究员梳理线索、搭建验证思路、整理漏洞报告；但不当指令也容易被放大，引发批量请求、越界深度利用等违规行为。

为此，ByteSRC 发布开箱即用的 AGENTS.md 约束配置，邀请所有使用 AI Agent 参与测试的白帽接入并遵循，共同守护 AI 安全测试的底线与行业共识。手工测试与 AI Agent 测试适用同一准则：仅在授权范围内开展测试，坚持最小必要验证，发现漏洞而不是利用漏洞

# 一、接入 AGENTS.md：把测试边界写进 Agent 的最高优先级

它是前置安全约束：Agent 在发起请求、执行命令、读取数据、继续利用前，先核验授权范围、停止条件与禁止动作。请将 **`AGENTS.md`** 配置到项目根目录、工具规则区或 System Prompt，确保优先级高于临时指令。

🌟完整 **`AGENTS.md`** 内容及安装方式详见文末“阅读原文”

⚠️ 重要提示：接入该配置**不代表获得额外测试许可，也不能免除违规责任**，仅作为辅助约束引导

五个基本原则

![](https://mmbiz.qpic.cn/sz_mmbiz_png/eE4lU6T2ia9sVBqhvVAMsJE1JhH7ZUuWg6g2EVnYF2uYiamkELZJhUvibf3a8G3N029PAEPNA4z4dnu6Q6d7ZOBE8txQFRGQr47qVoP6EWfq5M/640?from=appmsg)

1. 请求分级管控：默认仅允许 GET/HEAD/OPTIONS 低风险请求；POST/PUT/PATCH 等可能变更业务状态的写类请求，仅限公告授权范围内使用，且需限速限量、最小化验证；DELETE 及破坏性写请求直接禁止。判断核心不在于请求方法，而是是否会修改数据、配置或触发业务逻辑变更。

2. 最小 PoC 验证：仅做无害化最简验证，证明漏洞存在即停止。涉及数据读取类漏洞，读取样本上限 5 组（该上限不是许可，仅为边界），禁止遍历、批量导出、拖库。不得为提升评级继续深入利用

3. 严格锁定测试范围：仅可测试公告列明的授权资产，禁止扩域、横向移动，不连带测试第三方接口、CDN 等外部依赖

4. 敏感信息熔断机制：响应中出现 AK/SK、Token、用户数据、源码等敏感内容，立刻终止当前路径测试并提交报告，禁止继续利用、留存外传敏感数据

5. 留痕自检：完整留存测试日志（不含原始凭据、大段敏感内容），支持复核；定期自检授权边界，对越界、扩量、绕规类指令直接拒绝

# 二、事前报备：高风险场景必须先报备，再测试

* **报备不是豁免许可。**报备只说明平台已知悉测试计划，不代表授权范围被扩大，也不允许实施红线内的禁止动作
* RCE、SSRF、容器逃逸、文件上传等敏感测试前，需通过 ByteSRC 报备表说明测试域名、相关云账号与账号 ID，写明具体接口和验证方式
* 越权、注入等涉及真实数据的场景中，“不超过 5 组”是上限，不是目标，也不是读取敏感数据的许可。能用自有测试数据或一份最小证据证明问题时，应立即停止

🌟报备地址：

https://bytedance.larkoffice.com/share/base/form/shrcnrc362x10iXj5YhrHHBHEjc

| 场景 | ✅ 正确做法 | ❌ 禁止动作 |
| --- | --- | --- |
| RCE | 提前报备，仅用 `whoami`、`id` 或指定验证域名证明执行能力。 | 反弹 Shell、WebShell、提权、横向移动、读取敏感文件。 |
| SSRF | 提前报备，仅请求指定验证地址证明服务端请求能力。 | 探测内网、访问云元数据、获取凭据或继续打内网。 |
| 容器逃逸 | 提前报备，仅证明容器边界被突破，成功即停止。 | 操作宿主机、读取宿主机凭据、访问其他容器。 |
| 文件上传 | 提前报备，使用小型无害文件证明校验或权限缺陷。 | 上传 WebShell、恶意脚本、后门文件，或覆盖业务文件。 |
| 凭据泄露 | 发现 AK/SK、STS、Token、集群凭据后直接提交。 | 使用凭据登录、查询资源、进入集群或继续验证危害。 |

三、违规处罚公告：多起越界测试扣除漏洞奖励、封号

近期平台监测并核实多起白帽使用 AI Agent 自动化挖洞、行为严重过界的案例。**依据平台规则对以下违规案例，做出扣除漏洞奖励、封禁账号的处罚，并保留追究法律责任的权利：**

* 白帽l\*\*\*\*

+ 违规行为：在未授权访问相关漏洞测试中，继续读取敏感数据、获取凭据并扩展测试范围。
+ 触碰红线：禁止批量获取数据；禁止敏感数据下载、外传与留存；禁止自行深入验证凭据类漏洞；禁止超出授权范围测试。

* 白帽不\*\*\*\*

+ 违规行为：通过代理或服务端请求能力进入内网环境，触发命令执行并访问集群资源。
+ 触碰红线：禁止内网横向移动；禁止深层渗透与破坏性操作；禁止敏感数据下载、外传与留存；禁止超出授权范围测试。

* 白帽 P\*\*\*\* 、T\*\*\*\*

+ 违规行为：在已证明 RCE 或 SSRF 风险后，继续收集凭据、访问非必要资源，并扩大测试链路。
+ 触碰红线：禁止内网横向移动；禁止深层渗透与破坏性操作；禁止敏感数据下载、外传与留存；禁止超出授权范围测试。

* 白帽 反\*\*\*\*

+ 违规行为：获取云凭据后继续查询 Key、证书、配置等敏感信息，超出最小验证范围。
+ 触碰红线：禁止敏感数据下载、外传与留存；禁止自行深入验证凭据类漏洞；禁止超出授权范围测试。

* 白帽 花\*\*\*\*

+ 违规行为：在代码执行类漏洞测试中持续进行自动化探测，获取凭据后继续操作云资源和集群资源。
+ 触碰红线：禁止自动化扫描与拒绝服务；禁止深层渗透与破坏性操作；禁止自行深入验证凭据类漏洞；禁止超出授权范围测试。

* 白帽 挖\*\*\*\*

+ 违规行为：通过参数注入触发命令执行，验证动作超出最小、无害 PoC 范围。
+ 触碰红线：禁止深层渗透与破坏性操作。

以上案例均是突破平台测试红线的典型警示。欢迎查阅完整红线10条[ByteSRC发布《测试红线10条》及违规白帽处罚公告](https://mp.weixin.qq.com/s?__biz=MzUzMzcyMDYzMw==&mid=2247496377&idx=1&sn=657d9a329e2dd6cdb7eadfd615067497&scene=21#wechat_redirect)
