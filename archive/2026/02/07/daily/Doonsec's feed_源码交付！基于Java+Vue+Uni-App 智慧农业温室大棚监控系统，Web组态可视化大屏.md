智慧农业集新兴的互联网、移动互联网、云计算和物联网技术为一体，依托部署在农业生产现场的各种传感设备(温湿度、土壤水分、二氧化碳、摄像头等)通过4G网络实现农业生产环境的智能感知、智能预警、智能决策、智能分析、专家在线指导，为农业生产提供精准化种植、可视化管理、智能化决策。

然而，在传统的农业温室大棚系统建设过程中，依旧存在着诸多痛点：

* 设备难以统一管理：物联网设备协议众多，数据格式复杂，自建平台难以对设备实现统一管理。
* 开发难度大：智慧农业系统需要对接的设备类型多，开发难度大、周期长。
* 维护成本高：系统维护成本高，当设备出现故障时，难以进行远程排查、调试。

**智能温室大棚监控系统**包含（农业传感设备-IoT物联网平台-管理后台-手机App-可视化大屏），可实时远程获取温室大棚内部的空气温湿度、土壤水分温度、二氧化碳浓度、光照强度及视频图像，通过模型分析，可以自动控制温室湿帘风机、喷淋滴灌、内外遮阳、顶窗侧窗、加温补光等设备；同时，该系统还可以通过手机、PDA、计算机等信息终端向管理者推送实时监测信息、报警信息，实现温室大棚信息化、智能化远程管理。

****智慧农业温室大棚架构方案****

![](https://mmbiz.qpic.cn/mmbiz_png/0VE9kDxicLUgabvibiahxGyBYTkcMhoh7t0ich8ZyicB7ubq1nVvqoo5gENDKGexDroiaZ3zRup0jnbibIPrDAiciaNjqRxjicPMXX9mxOibRPmzG2J5ZU/640?wx_fmt=png&from=appmsg)

智慧农业平台基于Java+Vue+Uni-app开发，在微信公众号、小程序、H5移动端都能使用，代码全开源无加密，独立部署，二开很方便，还支持免费商用，能满足气象站监控、温棚监控、高标准农田监控、仓库、报表统计、设备控制、设备物模型、大屏展示等多种经营需求，自用、做二开项目都很合适。

> **App端****：**安卓系统/ios/公众号/小程序
>
> **平台端：**SpringBoot+Mybatis+ Mysql+ VUE + Netty + Redis
>
> **管理端：**SpringbooB+Mybatis+Mysql+VUE
>
> **摄像头：**接入宇视、海康摄像头

墒情监测系统：能够实现对土壤墒情的长时间连续监测，据监测需要，灵活布置土壤水分传感器;也可将传感器布置在不同的深度，测量剖面土壤水分情况。可根据用户需求监测需求增加对应传感器，监测土壤温度、土壤电导率、土壤PH值、地下水水位、地下水水质以及空气温度、空气湿度、光照强度、风速风向、雨量等信息，从数据上分析植物的生长需求，满足植物的生长。

苗情监测系统：利用高清摄像机对现场的苗情情况进行实时、动态的监控，并通过系统进行可视化展示和对比分析。实现对种植生产现场苗情的可视化监控，支持观看实时监控画面和历史监控画面;并提供智能化数据决策，让农科研究人员在远程就可以了解四情的现状，实现四情监测智能化和数字化。

虫情监测系统：无人监管的条件下，自动完成诱虫、杀虫、虫体分散、拍照、运输、收集、排水等系统作业，并实时将环境气象和虫害情况上传到智慧农业云平台。采用物理方法，如灯光诱杀、黄板诱虫等。应用化学农药，但需注意合理用药，避免环境污染和农药残留。利用天敌、生物制剂等生物方法，实现有害生物的自然控制。

灾情监测系统：气象灾害主要包括洪涝、干旱、低温冻害、大风、冰雹、沙尘暴等。重大天气变化，加强灾害预测预判，及早制定完善技术预案，适时发布预警信息，强化灾情监测评估，启动应急响应，提早落实防御措施。洪涝和干旱、早霜的防御工作，加强作物田间管理，及早落实农作物增施肥促早熟等防灾增产措施。第一时间将预警信息和应对措施通知到生产主体，主动避灾、科学防灾。强化灾情监测调度，及早发现、准确评估。

农产品溯源系统：农产品拥有唯一的身份标识，可以通过手机扫码，查看到农产品的"真实来源"，通过数据可视化大屏，就能实时了解重点辖区内的种植户、养殖户、农投品经营单位的实时数据信息，从源头进行科学管理。
