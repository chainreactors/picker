# 印度命令GitHub移除蓝牙聊天应用Bitchat

印度政府显然试图移除杰克·多西旗下离线蓝牙通讯应用 Bitchat 的 GitHub 存储库，引发了关于因开源软件的工作方式而针对其的法律依据的质疑。

杰克·多尔西周五在X上发布了来自印度内政部的通知，该通知命令 GitHub 在三小时内限制对三个 Bitchat 仓库的访问。该通知指出，这款应用的匿名、去中心化架构可能助长非法活动，并允许用户在互联网中断期间进行通信，同时使合法拦截更加困难。

此举发生在印度收紧互联网限制之际，此前新德里因涉嫌试卷泄露事件爆发了由学生主导的持续数周的抗议活动。
