## Changes

* Rewrite English and Russian README, landing pages and quickstarts around concrete tasks. Preserve detailed contracts in the reference pages and provide a complete clone-to-demo, own-note and MCP-client path.
* Add `okf search` and MCP `search_sections`, using the same deterministic lexical section retrieval layer. Results include original snippets, physical line ranges, locators and source/snapshot digests. Existing literal `search_concepts` remains compatible.
* Add `okf setup` for ordinary Markdown: preview first, explicit type policy, digest-confirmed apply, source preservation and atomic publication to a new target. Provenance and verification are not inferred.
* Fix legacy citations display, concept IDs that resemble footnotes, Unicode routes and repeated footnote backlinks. Store regression templates with Windows-safe filenames.

The document contract remains `okf_version: "0.2"`; this release tag versions the Go toolkit separately.
