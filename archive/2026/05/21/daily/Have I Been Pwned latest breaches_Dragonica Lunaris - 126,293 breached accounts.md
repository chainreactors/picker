# Dragonica Lunaris Data Breach

## What Happened

In December 2025, [the European Dragonica private server Dragonica Lunaris](https://playdragonica.eu/) suffered a data breach. The incident exposed 126k email addresses, usernames, dates of birth and bcrypt password hashes. The service operator confirmed the breach and advised it has since been fixed.

## Compromised Data

Dates of birth

Email addresses

Names

Passwords

Spoken languages

Usernames

## Recommended Actions

##### Change Your Password

If you haven’t already changed the password affected by this breach, do
so immediately on every account where it was used.

##### Enable Two-Factor Authentication

Wherever 2FA is supported, add an extra layer of security to your
account.
