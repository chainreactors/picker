## 微软将移除有 25 年历史的命令行工具 WMIC

[![Windows](https://icon.solidot.org/images/topics/topicwindows.png?123)](/search?tid=33 "Windows")

[Edwards](/~Edwards) (42866)发表于 2026年08月17日 18时03分 星期一 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85113&appkey=1370085986&title=%E5%BE%AE%E8%BD%AF%E5%B0%86%E7%A7%BB%E9%99%A4%E6%9C%89%2025%20%E5%B9%B4%E5%8E%86%E5%8F%B2%E7%9A%84%E5%91%BD%E4%BB%A4%E8%A1%8C%E5%B7%A5%E5%85%B7%20WMIC "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自抓落叶**

微软证实，今年下半年释出的 Windows 11 26H2 将移除有 25 年历史的命令行工具 Windows Management Instrumentation Command-line (WMIC)。WMIC 于 2001 年随 Windows XP 推出，允许 IT 管理员与 Windows Management Instrumentation (WMI) 交互去管理 PC 硬件和软件生态系统的不同组件，比如查看主板型号和产品密钥。WMIC 如今早已被 PowerShell 之类更强大的工具所取代，微软 Windows Server 早在 2016 年淘汰了 WMIC， Windows 10 在 2021 年淘汰 WMIC，Windows 11 也默认禁用 WMIC。
https://www.neowin.net/news/microsoft-is-removing-a-legacy-windows-feature-that-has-been-around-for-25-years/
