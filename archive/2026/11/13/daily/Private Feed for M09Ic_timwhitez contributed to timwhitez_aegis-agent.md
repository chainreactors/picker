## Summary

Rebuild the embedded Web console from scratch and align it with current agent-platform practice, plus make the whole repository test suite pass on macOS.

**Frontend (internal/webconsole/ui)** — a no-build ES-module app with vendored Preact 10.29.8 + hooks + htm 3.1.1 (no CDN, no npm runtime, CSP `script-src 'self'`), replacing `internal/webconsole/assets` and `assets-v2`.

* Shell: sidebar with searchable session list (in-progress pinned, date groups, capped groups), top bar with status/model/workdir and session actions, per-session URLs (`/s/<id>`), command palette (⌘K) and global shortcuts, mobile drawer.
* Session: collapsible tool-step groups, live activity, inline end-of-run notes, per-turn file changes, auto-follow + back-to-latest, gap-safe message paging.
* Composer: send / steer / stop in one control, Goal/Plan toggles, model picker, Starting state that mirrors server rules, failed-send drafts (rejected vs unconfirmed, never resent), per-session drafts.
* Inline Plan Mode approval and question cards (reviewed-target CAS, coverage override, receipts) instead of approval buttons scattered across inspector/composer.
