## What's Changed

### ⚠️ Compatibility Notes

* Warn with `DeprecatedModelWarning` when a request targets a model Anthropic or OpenAI has deprecated by [@dsfaccini](https://github.com/dsfaccini) in [#14038](https://github.com/pydantic/pydantic-ai/pull/14038)
* [cache] Surface OpenAI Responses `input_transformations` in `provider_details` and on the model request span by [@dsfaccini](https://github.com/dsfaccini) in [#14056](https://github.com/pydantic/pydantic-ai/pull/14056)
  + Raises the `openai` floor from 3.31.0 to 3.50.0 on every extra that installs `openai`.
* Add `capabilities` to `Agent.override` and export `AgentInstructions` and `SourcedInstruction` by [@pydanty](https://github.com/apps/pydanty) in [#12551](https://github.com/pydantic/pydantic-ai/pull/12551)
  + The private `Agent._override_root_capability` context variable now holds a `(capability, injected)` tuple. Code that reads it directly needs updating.
* Add `RealtimeSession.append_voice_instructions` for GPT-Live's voice model, and a Twilio Media Streams bridge example by [@dsfaccini](https://github.com/dsfaccini) in [#14191](https://github.com/pydantic/pydantic-ai/pull/14191)
* Leave `init=False` evaluator fields out of `Dataset` files and schemas, and stop `ClassVar` annotations breaking `to_file()` by [@pydanty](https://github.com/apps/pydanty) in [#13355](https://github.com/pydantic/pydantic-ai/pull/13355)
