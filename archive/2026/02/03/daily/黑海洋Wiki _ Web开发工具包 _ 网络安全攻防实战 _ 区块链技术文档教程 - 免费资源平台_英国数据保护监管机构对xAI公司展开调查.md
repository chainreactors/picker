# 英国数据保护监管机构对xAI公司展开调查

发布时间:
2026-02-04 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
868

英国数据保护监管机构正对马斯克旗下xAI展开调查，监管部门正加大审查力度，关注AI聊天机器人Grok被用于生成并传播对个人进行性化处理的图像。英国信息专员办公室 ( ICO ) 周二在声明中表示，这项正式调查将重点审查在生成这些图像过程中，是否存在个人数据被不当处理的情况。上月，Grok引发公众和政界强烈反弹。用户在 X 上诱导该聊天机器人在未经本人同意的情况下，生成对真实人物进行性化处理的AI图像。周二稍早，法国执法部门对 X 位于巴黎的办公室进行了突击搜查。ICO表示，其有权对xAI处以最高 1750万英镑 (约2400万美元) 或公司全球年营收4%的罚款，以较高者为准。
