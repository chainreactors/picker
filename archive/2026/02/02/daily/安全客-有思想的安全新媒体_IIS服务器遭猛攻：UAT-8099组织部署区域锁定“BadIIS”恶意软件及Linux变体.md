дёҖеңәй’ҲеҜ№дәҡжҙІең°еҢәдә’иҒ”зҪ‘дҝЎжҒҜжңҚеҠЎпјҲIISпјүжңҚеҠЎеҷЁзҡ„й«ҳж°ҙеҮҶзҪ‘з»ңж”»еҮ»е·ІеҚҮзә§пјҢж”»еҮ»иҖ…жҺЁеҮәдәҶе…Ёж–°зҡ„й«ҳеәҰе®ҡеҲ¶еҢ–жҒ¶ж„ҸиҪҜд»¶еҸҳдҪ“гҖӮжҖқз§‘ Talos е®үе…ЁеӣўйҳҹзЎ®и®ӨпјҢеЁҒиғҒз»„з»Ү UAT-8099 иҮӘ 2025 е№ҙжң«иҮі 2026 е№ҙеҲқеҸ‘иө·ж–°дёҖиҪ®ж”»еҮ»жөӘжҪ®пјҢ**ж”»еҮ»зӣ®ж ҮжҳҺзЎ®жҢҮеҗ‘жі°еӣҪгҖҒи¶ҠеҚ—еҸҠе‘Ёиҫ№ең°еҢәзҡ„еҸ—е®іиҖ…**гҖӮ

дёҺеҗ‘дә’иҒ”зҪ‘еӨ§и§„жЁЎж•Јж’ӯйҖҡз”ЁжҒ¶ж„ҸиҪҜд»¶зҡ„е№ҝи°ұж”»еҮ»дёҚеҗҢпјҢUAT-8099 дёәе…¶ж ёеҝғж”»еҮ»жӯҰеҷЁ вҖңBadIISвҖқ йҮҸиә«е®ҡеҲ¶дәҶеҢәеҹҹйҖӮй…ҚеҠҹиғҪгҖӮиҝҷж¬ҫжҒ¶ж„ҸиҪҜд»¶зҺ°е·ІеңЁд»Јз ҒдёӯзӣҙжҺҘеөҢе…Ҙ вҖңеҢәеҹҹй”Ғе®ҡвҖқ жңәеҲ¶ гҖӮ

жҠҘе‘ҠжҢҮеҮәпјҡвҖңBadIIS зҡ„ж–°еһӢеҸҳдҪ“е°Ҷзӣ®ж ҮеҢәеҹҹзӣҙжҺҘзЎ¬зј–з ҒиҮіжҒ¶ж„ҸиҪҜд»¶дёӯпјҢжҜҸдёӘзү№е®ҡеҸҳдҪ“йғҪй…ҚеӨҮдәҶе®ҡеҲ¶еҢ–еҠҹиғҪгҖӮвҖқ

иҝҷз§Қе®ҡеҲ¶еҢ–и®ҫи®ЎиғҪи®©ж”»еҮ»иҖ…жӣҙеҘҪең°дјӘиЈ…жҲҗеҗҲжі•жөҒйҮҸгҖӮиҜҘжҒ¶ж„ҸиҪҜд»¶еҢ…еҗ« вҖңдё“еұһж–Үд»¶жү©еұ•еҗҚгҖҒеҜ№еә”зҡ„еҠЁжҖҒйЎөйқўжү©еұ•еҗҚгҖҒзӣ®еҪ•зҙўеј•й…ҚзҪ®пјҢд»ҘеҸҠд»Һжң¬ең°ж–Үд»¶еҠ иҪҪ HTML жЁЎжқҝзҡ„иғҪеҠӣвҖқгҖӮеҰӮжӯӨз»ҶиҮҙзҡ„и®ҫи®ЎиЎЁжҳҺпјҢж”»еҮ»иҖ…еҜ№е…¶ж”»еҮ»зӣ®ж Үзҡ„иҝҗиЎҢзҺҜеўғ**е…·еӨҮж·ұе…ҘдәҶи§Ј**гҖӮ

жңҖд»Өдәәж„ҸеӨ–зҡ„иҝӣеұ•жҳҜпјҢиҜҘз»„з»Үзҡ„ж”»еҮ»иҢғеӣҙе·ІзӘҒз ҙ Windows зі»з»ҹйҷҗеҲ¶гҖӮе°Ҫз®Ў IIS жҳҜ Windows дё“еұһжңҚеҠЎпјҢдҪҶ Talos з ”з©¶дәәе‘ҳеҸ‘зҺ°пјҢUAT-8099 е·Іе°Ҷе…¶ж”»еҮ»е·Ҙе…·йҖӮй…ҚиҮі Linux зҺҜеўғгҖӮ

жҠҘе‘Ҡз§°пјҡвҖң2025 е№ҙ 10 жңҲ 1 ж—ҘпјҢдёҖж¬ҫ BadIIS зҡ„ Linux еҸҜжү§иЎҢдёҺеҸҜй“ҫжҺҘж јејҸпјҲELFпјүеҸҳдҪ“иў«дёҠдј иҮі VirusTotal е№іеҸ°гҖӮвҖқ

иҝҷж¬ҫ Linux еҸҳдҪ“е№¶йқһз®ҖеҚ•зҡ„з§»жӨҚзүҲжң¬пјҢиҖҢжҳҜеҠҹиғҪе®ҢеӨҮзҡ„ж”»еҮ»е·Ҙе…·гҖӮе®ғеҢ…еҗ« вҖңд»ЈзҗҶжЁЎејҸгҖҒжіЁе…ҘжЁЎејҸе’Ңжҗңзҙўеј•ж“ҺдјҳеҢ–пјҲSEOпјүж¬әиҜҲжЁЎејҸвҖқпјҢе®Ңе…ЁеӨҚеҲ»дәҶжӯӨеүҚ Windows зүҲжң¬зҡ„е…ЁйғЁеҠҹиғҪгҖӮиҝҷз§Қ**и·Ёе№іеҸ°иғҪеҠӣ**еӨ§е№…жү©еӨ§дәҶиҜҘз»„з»Үзҡ„жҪңеңЁж”»еҮ»йқўгҖӮ

жӯӨж¬Ўи°ғжҹҘиҝҳиҜҒе®һдәҶ UAT-8099 дёҺеҸҰдёҖдёӘе·ІзҹҘеЁҒиғҒйӣҶзҫӨзҡ„е…іиҒ”гҖӮTalos еҲҶжһҗеёҲеҸ‘зҺ°пјҢиҜҘз»„з»Үзҡ„ж”»еҮ»жҙ»еҠЁдёҺ WEBJACK ж”»еҮ»иЎҢеҠЁеӯҳеңЁжҳҺжҳҫзҡ„зү№еҫҒйҮҚеҗҲгҖӮ

з ”з©¶дәәе‘ҳиЎЁзӨәпјҡвҖңеҲҶжһҗзЎ®и®ӨпјҢжӯӨж¬Ўж”»еҮ»жҙ»еҠЁдёҺ WEBJACK ж”»еҮ»иЎҢеҠЁеӯҳеңЁжҳҫи‘—зҡ„иҝҗиҗҘйҮҚеҸ пјҢеҢ…жӢ¬жҒ¶ж„ҸиҪҜд»¶е“ҲеёҢеҖјгҖҒе‘Ҫд»ӨдёҺжҺ§еҲ¶пјҲC2пјүжңҚеҠЎеҷЁгҖҒеҸ—е®іиҖ…зҫӨдҪ“зӯүе…ій”®е…ҘдҫөжҢҮж ҮеқҮй«ҳеәҰеҗ»еҗҲгҖӮвҖқ

дёҖж—Ұж”»йҷ·еӯҳеңЁжјҸжҙһзҡ„жңҚеҠЎеҷЁпјҢиҜҘз»„з»Үдјҡз»“еҗҲе®ҡеҲ¶еҢ–е·Ҙе…·дёҺе•Ҷдёҡе·Ҙе…·з»ҙжҢҒжҺ§еҲ¶жқғгҖӮжҠҘе‘ҠиҜҰз»ҶжҠ«йңІпјҢUAT-8099вҖңйҖҡиҝҮ Webshell е’Ң PowerShell жү§иЎҢи„ҡжң¬пјҢе№¶йғЁзҪІ GotoHTTP е·Ҙе…·пјҢд»ҺиҖҢиҺ·еҫ—еҜ№жҳ“еҸ—ж”»еҮ» IIS жңҚеҠЎеҷЁзҡ„иҝңзЁӢи®ҝй—®жқғйҷҗвҖқгҖӮ

зӣ®еүҚпјҢиҜҘж”»еҮ»зҡ„еҸ—е®іиҖ…е·ІйҒҚеёғ вҖңеҚ°еәҰгҖҒе·ҙеҹәж–ҜеқҰгҖҒжі°еӣҪгҖҒи¶ҠеҚ—е’Ңж—Ҙжң¬вҖқгҖӮе®үе…Ёжңәжһ„ж•ҰдҝғиҜҘең°еҢәзҡ„дјҒдёҡз»„з»Үпјҡ**е®Ўи®ЎиҮӘиә« IIS жңҚеҠЎеҷЁй…ҚзҪ®**пјҢе№¶еҜҶеҲҮзӣ‘жҺ§жҖқз§‘ Talos еҲ—еҮәзҡ„ BadIIS зү№е®ҡе…ҘдҫөжҢҮж ҮгҖӮ
