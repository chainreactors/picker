对于网络工程师来说，IP地址可以说是每天都会接触到的基础知识。无论是给交换机配置管理地址、为服务器分配IP，还是排查网络故障，几乎都离不开IP地址和子网的概念。

不过，对于很多刚接触网络的朋友来说，看到 **192.168.1.10**、**10.0.0.1**、**172.16.100.5** 这些IP地址时，往往会产生不少疑惑：哪些属于A类地址？哪些属于B类、C类？两台设备到底是不是在同一个子网？为什么有时候IP地址看起来很接近，却无法直接通信？

## IP地址到底是什么？

IP地址可以理解为网络中每一台设备的"身份证"。

在IPv4中，一个IP地址由**32位二进制数字**组成，为了方便阅读，通常写成四组十进制数字，每组之间用"."分隔，例如：

```
192.168.1.100
```

实际上，它对应的是32位二进制数据，只不过平时我们很少直接使用二进制表示。

整个IP地址主要由两部分组成：

* 网络地址（Network ID）
* 主机地址（Host ID）

网络地址决定设备属于哪个网络，而主机地址则表示该网络中的具体设备。

正因为有了这种结构，互联网中的路由器才能准确地把数据发送到正确的目标网络。

## A、B、C类IP地址是怎么划分的？

早期互联网采用的是**分类编址（Classful Addressing）**。

它根据IP地址第一段（第一个字节）的数值，将IPv4地址划分为A、B、C、D、E五类。

其中，与日常网络配置关系最密切的，就是A类、B类和C类地址。

最简单的判断方法，就是看IP地址第一段数字。

### A类地址

第一段范围：

```
1 ~ 126
```

默认子网掩码：

```
255.0.0.0
```

也就是：

```
/8
```

例如：

```
10.1.1.10
36.8.100.20
58.200.1.5
```

都属于A类地址。

不过需要注意：

127.x.x.x 并不属于普通A类地址，而是专门保留给\*\*本地回环（Loopback）\*\*使用，例如127.0.0.1就是大家熟悉的localhost。

### B类地址

第一段范围：

```
128 ~ 191
```

默认子网掩码：

```
255.255.0.0
```

即：

```
/16
```

例如：

```
172.16.10.10
150.100.1.20
190.5.6.7
```

都属于B类地址。

---

### C类地址

第一段范围：

```
192 ~ 223
```

默认子网掩码：

```
255.255.255.0
```

即：

```
/24
```

最常见的：

```
192.168.x.x
```

就属于C类地址。

家庭路由器默认分配的：

```
192.168.0.x

192.168.1.x
```

几乎都是C类地址。

## 私有IP地址有哪些？

除了地址分类之外，还有三个非常重要的私有地址段。

它们不能直接出现在公网中，主要用于局域网。

分别是：

A类私网：

```
10.0.0.0/8
```

B类私网：

```
172.16.0.0 ~ 172.31.255.255
```

对应：

```
172.16.0.0/12
```

C类私网：

```
192.168.0.0/16
```

平时家庭路由器使用的192.168.1.1，就是典型的私有IP地址。

## 怎么判断两台电脑是不是同一个子网？

这才是网络工程中最常用的知识。

很多人会直接比较：

```
192.168.1.xxx
```

是不是前三段一样。

这种方法**有时候正确，有时候完全错误。**

真正决定是否属于同一个子网的，不是IP地址，而是：

> **IP地址 + 子网掩码**

举个例子。

电脑A：

```
192.168.1.10

255.255.255.0
```

电脑B：

```
192.168.1.200

255.255.255.0
```

因为：

网络地址都是：

```
192.168.1.0
```

所以：

它们属于同一个子网。

可以直接通信。

---

再来看另一组。

电脑A：

```
192.168.1.10

255.255.255.128
```

电脑B：

```
192.168.1.200

255.255.255.128
```

虽然前三段完全一样。

但是：

```
192.168.1.10

属于：

192.168.1.0/25
```

而：

```
192.168.1.200

属于：

192.168.1.128/25
```

它们已经属于两个不同子网。

如果没有三层设备进行路由，它们之间就不能直接通信。

这也是很多新手最容易踩坑的地方。

## 判断是否属于同一子网，其实只有三步

实际工作中，我一般都会让新人记住一个最简单的方法。

**第一步：查看子网掩码。**

例如：

```
255.255.255.0
```

就是：

```
/24
```

---

第二步：

分别计算网络地址。

例如：

```
192.168.10.66/24
```

网络地址就是：

```
192.168.10.0
```

---

第三步：

比较网络地址。

如果一致：

属于同一个子网。

如果不同：

不是同一个子网。

其实，本质上就是把IP地址与子网掩码进行按位与（AND）运算，只不过在很多常见场景下，我们完全可以通过网络号快速判断，而不必真的去计算二进制。

---

## 现在还需要学习A、B、C类地址吗？

很多朋友学习网络时都会发现：

教材还在讲A、B、C类地址。

而实际工作中，大家更多使用：

```
/24

/26

/27

/30

/16
```

这样的CIDR表示方法。

这是因为，现在互联网已经全面采用**无类别编址（CIDR）**，网络大小完全由子网掩码决定，而不是由A类、B类、C类固定限制。CIDR提高了IP地址利用率，也是现代网络设计的主流方式。

不过。

A、B、C类地址仍然值得学习。

因为：

* 很多认证考试仍然会考；
* 很多老设备仍然保留默认类别概念；
* 理解分类编址，有助于理解子网划分和CIDR的发展过程。

对于网络工程师来说，这依然属于必须掌握的基础知识。

---

IP地址分类看起来只是网络入门知识，但它却是理解整个TCP/IP网络体系的重要基础。

A类地址适用于大型网络，B类地址适用于中型网络，C类地址则广泛应用于家庭和中小企业网络。虽然如今已经进入CIDR时代，网络规划更多依赖子网掩码，而不是传统分类，但理解A、B、C类地址仍然有助于学习IPv4地址结构和子网划分。

在实际工作中，判断两台设备是否能够直接通信，不能只看IP地址是否相似，更重要的是**结合子网掩码计算网络地址**。只有网络地址相同，它们才真正属于同一个子网。

对于网络工程师来说，这些知识不仅是考试中的基础内容，更是日常配置交换机、路由器、防火墙以及排查网络故障时最常用的基本功。掌握这些原理，后续学习VLAN、静态路由、动态路由以及IPv6等内容，也会更加轻松。
