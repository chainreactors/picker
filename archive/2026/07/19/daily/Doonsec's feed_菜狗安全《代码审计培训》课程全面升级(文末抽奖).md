完整课程大纲与介绍

# JAVA专题

### 基础篇

* **通用学习路线与指南**

+ 建立一套"以业务为核心，架构为先导"的底层审计逻辑，具备通杀能力

* **漏洞的本质**

+ 从漏洞产生的本质出发，理解漏洞，吃透漏洞，提升审计效率

* **闭源项目常见架构审计差异与反编译**

+ 讲解常见闭源项目的不同架构差异，以及源码到手后的准备工作

* **代码审计流程与思维架构**

+ 建立从入口分析到漏洞挖掘的标准化审计流程

* **不同架构项目路由传参以及鉴权装配模式**

+ 不同架构的路由配置、接口构造与鉴权装配模式差异

* **JAVAweb开发**

+ 分割在每节漏洞审计的前置部分，在实战案例前就学会如何挖漏洞

* **AI审计调教手册**

+ Prompt 编写技巧、上下文管理与审计 agent 基础调教

---

# 鉴权审计

---

* **前台接口筛选**

+ 从成百上千的路由中快速筛选前台可访问接口

* **鉴权绕过**

+ **不安全的路由匹配模式**：框架路由特性导致的鉴权绕过
+ **凭据身份伪造**：Session 预测、Cookie 伪造、Token 硬编码等
+ **组件漏洞绕过鉴权**：Shiro、Spring Security 等历史绕过漏洞

# 漏洞审计

---

| 类别 | 内容 |
| --- | --- |
| **SQL注入挖掘** | JDBC 注入挖掘与绕过、Mybatis 注入挖掘 |

| **XXE审计** | XML 解析器安全配置与利用 |
| **SSRF审计** | 限制协议的深入利用与绕过 |
| **RCE审计篇** | 命令执行与代码执行的多种触发点 |
| **越权类审计** | 垂直越权、水平越权、实战中越权的艺术 |
| **逻辑漏洞审计** | 支付逻辑、业务状态、并发漏洞 |
| **XSS审计** | 反射型、存储型 |
