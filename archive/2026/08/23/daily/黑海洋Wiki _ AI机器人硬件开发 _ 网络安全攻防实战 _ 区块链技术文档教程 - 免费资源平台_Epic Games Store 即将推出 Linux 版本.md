# Epic Games Store 即将推出 Linux 版本

发布时间:
2026-08-23 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
2802

Epic Games最近在社区Discord群组中做了一次AMA(问我任何事)，确认Epic Games Store的Linux/SteamOS版本即将推出。

在 Discord AMA 中，一位用户提出了一项问题：“关于启动器的Linux版本，有没有任何新计划”，一位官方的Epic Games开发者回复称会是 “不久后”，但不会包含在即将到来的Epic Games Store改版的预览发布中。

此外 Epic Games 正在招聘一名安全工程师来主导 Linux 反作弊工作，所以看起来他们在Linux支持整体上有一些更广泛的计划。
