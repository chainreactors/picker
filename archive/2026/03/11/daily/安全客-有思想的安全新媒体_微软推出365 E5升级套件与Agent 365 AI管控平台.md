# 微软推出365 E5升级套件与Agent 365 AI管控平台

![]()

微软正式公布 **Microsoft 365 Copilot** 系列更新，重点围绕**AI 智能体、多模型选择与企业集中管控**，为企业办公自动化提供全面支持。

Microsoft 365 Copilot 正从传统助手式交互，升级为**可自主执行操作、完成多步骤任务**的智能体能力。微软同时推出全新套餐 **Microsoft 365 E7**，整合 Microsoft 365 E5、Copilot、Agent 365 及安全与身份产品。

### AI 智能体为核心

本次关键升级是在 Microsoft 365 核心应用中全面落地**智能体体验**。

新一代 Copilot 智能体功能将登陆 Word、Excel、PowerPoint、Outlook，并同步升级 Copilot Chat（原 “智能体模式”）。

微软还公布了 **Copilot Cowork**，目前处于研发预览阶段，由微软与 Anthropic 深度合作打造，基于 Claude Cowork 技术，用于**长时间、多步骤、持续性的复杂办公任务**。

微软同时强调 Copilot 将采用**多模型兼容**策略。

在其 Frontier 计划下，企业用户可在 Copilot Chat 中选择模型，**Anthropic Claude 与最新 OpenAI 模型将同时提供**。

### AI 统一管控平台

本次发布另一核心为 **Agent 365**，微软将其定位为**AI 智能体统一管控平台**。

该产品计划于 5 月 1 日正式上市，定价为每用户每月 15 美元，区域定价待定。

Agent 365 旨在让 IT 与安全团队能够**统一观测、治理、管理与保护企业内所有 AI 智能体**，并复用现有用户管理的基础设施、应用与安全防护体系。

微软商业事业部首席执行官 Judson Althoff 将这一管控架构与企业 AI 快速落地的风险相关联。

“智能体的开发与普及速度表明用户认可其价值，但**缺乏安全护栏会导致管控盲区、投资回报下降与真实安全风险**。”Althoff 表示。

微软同时公布了内部与早期客户的使用数据：

* 预览版两个月内，**Agent 365 注册中心已出现数千万个智能体**
* 微软内部可观测超 50 万个智能体
* 过去 28 天，智能体**日均为员工生成超 6.5 万条响应**

### 全新套餐组合

**Microsoft 365 E7** 计划于 5 月 1 日正式推出，定价每用户每月 99 美元，区域定价待定。

该套件整合：

* Microsoft 365 E5
* Microsoft 365 Copilot
* Agent 365
* Microsoft Entra
* Defender、Intune、Purview 高级安全能力

微软表示，E7 可与企业现有应用与安全体系无缝集成，并由 **Work IQ** 驱动。

Work IQ 是与企业办公场景深度绑定的智能层，为 Copilot 与智能体提供上下文支撑。

Althoff 将 Work IQ 视为区别于简单内容生成的核心优势。

“我常说，只做零样本内容生成不过是小把戏。” 他表示。

Work IQ 能够真实反映企业内部协作模式，包括人员协作关系与共用内容，并深度集成在现有工具中，用于**提升 Copilot 输出的准确性与可信度**。

### 市场应用数据

微软同时披露 Copilot 强劲增长：

* 付费席位**同比增长超 160%**
* 日活跃使用量**增长 10 倍**
* 大规模部署（超 3.5 万席位）的客户数量**同比增长两倍**

案例包括奔驰、NASA、Fiserv、荷兰国际集团、肯塔基大学、曼彻斯特大学、美国内政部、西太平洋银行等。

微软称，**世界 500 强企业中已有 90% 使用 Copilot**。

微软将本次智能体、管控与安全能力的组合，定位为**从 AI 试点走向企业规模化落地**的关键一步。

“企业不再需要更多 AI 试点，他们需要**能带来真实业务价值与增长的 AI**。”Althoff 表示。
