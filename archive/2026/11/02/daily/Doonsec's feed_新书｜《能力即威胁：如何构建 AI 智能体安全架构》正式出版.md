2026年10月29日，由赵粮、李康著，Z-ONE Global 出版的《能力即威胁：如何构建 AI 智能体安全架构》正式问世。

随着 AI 从 Chatbot 走向 Agent，机器正在从回答问题进一步参与判断、执行与决策。AI 安全面对的问题，也开始从“如何保护一个模型”，走向“如何为一个能够行动的智能系统建立安全边界”。

《能力即威胁》正是在这一变化下完成的一本 AI Agent Security 专业著作，尝试系统回答一个正在变得越来越现实的问题：当智能开始行动，我们应该如何保护它，也如何约束它。

**01**

**从“回答问题”到“采取行动”**

过去的软件，无论多么复杂，大体仍然遵循一个基本秩序：人决定，代码执行。

生成式 AI 改变了这一关系。到了 Agent，人给出目标，机器可以理解任务、规划步骤、调用工具、读取数据，并根据环境反馈决定下一步行动。机器拥有的能力，正在从“生成”进入“行动”。

这也带来了新的安全问题。

《能力即威胁》聚焦 AI Agent 从设计、开发到部署与运行过程中出现的新型安全挑战。全书讨论攻击与防御，也讨论身份、权限、RAG、MCP、Guardrails、Sandbox、AI Gateway，以及审计、治理和企业如何部署与保护 Agent。

一个错误不再只是一个错误答案。当机器能够读取数据、调用工具甚至执行任务，错误就可能成为真实的操作。真正需要回答的问题，也因此从“模型是否会犯错”，转向“当它犯错时，我们允许它走多远”。

这也是全书一个基本判断：以架构的确定性，对抗 AI 的非确定性。

**02**

**为什么叫“能力即威胁”**

“能力即威胁”并不是说 AI 的能力本身就是威胁。

读取、推理、记忆、调用工具、获得授权和执行任务，正是 Agent 创造价值的基础；但同样是这些能力，也决定了风险能够抵达的范围。能力并不等于威胁，却构成了威胁发生的条件。

因此，这本书没有停留在对新型攻击的罗列，而是沿着一条完整的逻辑逐步展开。

![图片](https://mmbiz.qpic.cn/mmbiz_png/wQYtZSkKU1ibAH4y7JBP8JWfP1AibSyN2fo9Ga7ZRVvbLft8cjNCvrHR6ZsUDYqMVMnaExN9G1cIHxvEMMR0vbesDO6cnumicjgdJEAqFmqRDA/640?from=appmsg)

第一部分从攻防不对称的变化开始，讨论 AI 如何改变成本曲线与攻击面，并由此重新审视机器速度下的安全设计原则；第二部分进入“构建”，回答如何建立 AI 驱动的防御、保障闭环与检测体系，以及机器究竟可以获得多大的自主权；第三部分转向“守护”，从智能体自身的结构与威胁出发，把纵深防御、可观测性与证据真正铺进运行中的系统。

在此基础上，第四部分进一步走向“证明”：一个智能体是否安全，不仅需要技术上的判断，也需要经受合规、测试与采购的检验；第五部分最终落到“规划”，把前面的原则、架构与方法转化为行动计划、预算与检查表。

从理解变化，到构建、守护、证明，再到行动，这五个部分构成了全书的基本路径。能力不断扩大，安全要做的不是取消能力，而是让能力拥有与之相称的边界。

**03**

**为什么是现在**

AI Security 并不是一个刚刚出现的概念，但它正在经历一次明显的变化。

寻找漏洞、生成攻击代码、分析告警、组织攻击链，这些曾经高度依赖人的工作，正在被 AI 加速甚至接手；Prompt Injection、Data Poisoning、Model Theft，以及 RAG、MCP、多模态和 Agent Identity 带来的新问题，又在不断扩大原有的攻击面。更深的变化，则来自系统本身：AI 引入了概率性，Agent 又在概率性之上加入了自主性。

这种变化已经不只存在于研究和概念中。2026 年 OpenAI 内部网络安全能力评测中的 Agent 越出预期测试环境，并进一步进入 Hugging Face 生产基础设施的事件。智能的安全能力与攻击能力，都开始从实验室中的指标走向真实世界中的行动。

这也是 Z-ONE Global 选择在此时出版《能力即威胁》的原因。

过去几年，人们不断讨论机器变得多么聪明；现在，问题正在向前一步——智能开始行动。当 AI 不再止于生成信息，而开始参与判断、执行与决策，它改变的也将不只是技术本身，而是人与机器共同构成的运行方式。

AI Agent Security 因此不再只是一个未来问题。它正在成为今天需要开始面对的工程问题。

**04**

**作者介绍**

《能力即威胁》由赵粮、李康共同撰写。两位作者长期关注网络安全与 AI 技术的发展，并从各自的专业与实践经验出发，共同完成了对 AI Agent Security 的系统性梳理与思考。

赵粮 博士,CISSP

赵博士是绿盟科技的国际业务首席运营官。他曾任绿盟科技CTO，CSO，中国计算机学会理事，中国网络空间安全协会（CSAC）常务理事，国际云安全联盟（CSA）的主要贡献者之一，中国分会的发起者和创始人，硅谷分会理事。2012年，他获得云安全联盟 Ron Knode 服务奖。2015年获得云安全联盟亚太区Cloud Security Ninja奖。2025年获得 IDC中国网络安全10大人物（名人堂）。

赵粮博士毕业于北京大学物理学系和电子学系，是国际国内多个技术论坛的讲者、主持人、程序委员会委员，也是多个行业期刊的撰稿人。

更多相关信息请访问他在LinkedIn上的个人介绍：

http://www.linkedin.com/in/zhaol

李康

李康教授是网络安全攻防（CTF）比赛领域的先驱，他是中国知名战队“蓝莲花”的启蒙导师，也是 XCTF 国际联赛的联合发起人。他曾率队闯入美国国防部（DARPA）主办的 CGC 全球自动攻防对抗赛决赛，是自动攻防与 AI 智能化漏洞挖掘领域的早期实践者。

李康教授毕业于清华大学计算机系，并取得耶鲁大学法学硕士及俄勒冈研究院计算机博士学位，曾任美国佐治亚大学计算机系终身教授与网络安全与隐私学院院长。李康教授拥有丰富的跨国企业与顶级互联网公司实战经验，曾先后出任 360 网络安全北美研究院负责人及百度首席安全科学家。李康教授长期深耕于人工智能（AI）的安全技术攻防，持续把 AI 对抗，形式化验证等技术应用到区块链，自动驾驶等领域，技术成果和发现受到华为，苹果，特斯拉等公司的公开致谢，并分别进入三星和高通的安全名人堂。
