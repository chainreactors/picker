* Strip every default-ignorable character before `ArtifactScanner` phrase matching and flag hidden variation selectors by [@mpfaffenberger](https://github.com/mpfaffenberger) in [#11475](https://github.com/pydantic/pydantic-ai/pull/11475)
* Load one instruction file per directory and nested files by default in `RepoContext`, add `walk_up`, and have `Coder` build on them by [@DouweM](https://github.com/DouweM) in [#11691](https://github.com/pydantic/pydantic-ai/pull/11691)
* Cap inlined nested instructions at 32,000 characters per conversation by default with `RepoContext(nested_max_chars=...)` by [@DouweM](https://github.com/DouweM) in [#11699](https://github.com/pydantic/pydantic-ai/pull/11699)
* Send documents of any media type `mimetypes` knows, with the format taken from it by [@arjun-krishna1](https://github.com/arjun-krishna1) in [#12365](https://github.com/pydantic/pydantic-ai/pull/12365)
* Move provider-specific native-tool fields to `provider_settings` by [@adtyavrdhn](https://github.com/adtyavrdhn) in [#7807](https://github.com/pydantic/pydantic-ai/pull/7807)
