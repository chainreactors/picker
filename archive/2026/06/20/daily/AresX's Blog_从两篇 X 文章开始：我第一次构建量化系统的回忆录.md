# д»ҺдёӨзҜҮ X ж–Үз« ејҖе§ӢпјҡжҲ‘з¬¬дёҖж¬Ўжһ„е»әйҮҸеҢ–зі»з»ҹзҡ„еӣһеҝҶеҪ•

> ж—¶й—ҙиҢғеӣҙпјҡ2026-05-12 иҮі 2026-06-21
> еҶҷдҪңе®ҡдҪҚпјҡиҝҷдёҚжҳҜејҖеҸ‘ж—Ҙеҝ—пјҢд№ҹдёҚжҳҜжҸҗдәӨи®°еҪ•гҖӮе®ғжҳҜдёҖд»Ҫйқўеҗ‘еҲҶдә«зҡ„еӣһеҝҶеҪ•пјҡи®°еҪ•дёҖдёӘдәӨжҳ“жғіжі•еҰӮдҪ•д»ҺдёӨзҜҮ X ж–Үз« пјҢеҸҳжҲҗдёҖеҘ—и¶ҠжқҘи¶ҠдёҘиӮғгҖҒи¶ҠжқҘи¶ҠдёҚж•ўиҪ»жҳ“зӣёдҝЎиҮӘе·ұзҡ„йҮҸеҢ–зі»з»ҹгҖӮ
> AI еҚҸдҪңиҜҙжҳҺпјҡиҝҷд»ҪеӣһеҝҶеҪ•з”ұ AI еҚҸеҠ©жҲ‘ж•ҙзҗҶгҖҒиҝҪй—®е’ҢеҶҷдҪңпјҢз”ЁжқҘи®°еҪ•жҲ‘д»ҺдәӨжҳ“жғіжі•еҮәеҸ‘пјҢйҖҗжӯҘжһ„е»әгҖҒжҖҖз–‘гҖҒдҝ®жӯЈдёҖеҘ—йҮҸеҢ–зі»з»ҹзҡ„иҝҮзЁӢгҖӮйҮҢйқўзҡ„еҲӨж–ӯгҖҒеҸ–иҲҚе’ҢеҸҚжҖқжқҘиҮӘйЎ№зӣ®жҺЁиҝӣдёӯзҡ„зңҹе®һиҜҒжҚ®дёҺеҜ№иҜқеӨҚзӣҳпјҢAI дё»иҰҒжүҝжӢ…жўізҗҶи„үз»ңгҖҒж”№еҶҷиЎЁиҫҫе’ҢиЎҘйҪҗйҒ—жјҸзҡ„е·ҘдҪңгҖӮ

**жӣҙж–°еҺҹеҲҷпјҡ**иҝҷд»Ҫж–ҮжЎЈд»ҘеҗҺдјҡдёҚе®ҡжңҹжӣҙж–°пјҢдҪҶдёҚдјҡжҢүвҖңд»ҠеӨ©ж”№дәҶе“ӘдёӘж–Үд»¶вҖқз»§з»ӯе ҶжөҒж°ҙиҙҰгҖӮ

жҜҸж¬Ўжӣҙж–°дјҳе…Ҳи®°еҪ•еӣӣд»¶дәӢпјҡ

* еҪ“ж—¶жҲ‘д»Ҙдёәд»Җд№ҲжҳҜеҜ№зҡ„гҖӮ
* еҗҺжқҘзі»з»ҹжҲ–ж•°жҚ®еҰӮдҪ•иҜҒжҳҺжҲ‘жғіз®ҖеҚ•дәҶгҖӮ
* жҲ‘еҒҡдәҶд»Җд№ҲеҶіе®ҡпјҢдёәд»Җд№ҲжІЎжңүйҖүеҸҰдёҖжқЎи·ҜгҖӮ
* иҝҷдёӘеҶіе®ҡз•ҷдёӢдәҶд»Җд№Ҳз»“жһңгҖҒж•ҷи®ӯжҲ–ж–°зҡ„йЈҺйҷ©гҖӮ

е…·дҪ“д»Јз ҒгҖҒе‘Ҫд»ӨгҖҒеӣһжөӢж•°еӯ—д»Қдјҡдҝқз•ҷпјҢдҪҶж”ҫеңЁз« иҠӮдёӯзҡ„иҜҒжҚ®ж®өжҲ–йҷ„еҪ•йҮҢгҖӮжӯЈж–ҮиҰҒе°ҪйҮҸеғҸдёҖзҜҮеҸҜд»Ҙз»ҷеҲ«дәәзңӢзҡ„й•ҝж–ҮпјҢиҖҢдёҚжҳҜдёҖд»Ҫе·ҘдҪңжұҮжҠҘгҖӮ

## еәҸз« пјҡжңҖејҖе§ӢеҸӘжҳҜдёӨзҜҮж–Үз«

иҝҷдёӘйЎ№зӣ®зңҹжӯЈзҡ„ејҖе§ӢпјҢдёҚжҳҜдёҖдёӘд»“еә“пјҢд№ҹдёҚжҳҜдёҖдёӘж•°жҚ®еә“вҖ”вҖ”иҖҢжҳҜжҲ‘дёҖж¬ЎиҝҮдәҺиҮӘдҝЎзҡ„вҖңжқҘйғҪжқҘдәҶвҖқгҖӮ

еҰӮжһңдёҘж јжҢүж—¶й—ҙиҜҙпјҢеңЁиҝҷд№ӢеүҚжҲ‘е·Із»Ҹзў°иҝҮдёҖжқЎж—Ғж”ҜпјҡеҸӘиҜ»еҲёе•ҶиҙҰжҲ·гҖҒжҢҒд»“е’ҢеёӮеңәз®ҖжҠҘгҖӮйӮЈжқЎзәҝеҪ“ж—¶иҝҳдёҚжҳҜйҮҸеҢ–зӯ–з•Ҙзі»з»ҹпјҢеҚҙжҸҗеүҚж•ҷдәҶжҲ‘дёҖдёӘеҗҺжқҘеҸҚеӨҚеҮәзҺ°зҡ„еҺҹеҲҷпјҡе…ҲеӯҰдјҡе®үе…Ёең°зңӢи§ҒзҺ°е®һпјҢеҶҚи°Ҳи®©зі»з»ҹжӣҝжҲ‘иЎҢеҠЁгҖӮжүҖд»Ҙиҝҷд»ҪеӣһеҝҶеҪ•жҠҠе®ғж”ҫеңЁдё»зәҝиҫ№зјҳпјҢиҖҢдёҚжҳҜеҪ“жҲҗз¬¬дёҖз« пјӣзңҹжӯЈжҠҠдәӨжҳ“жғіжі•жҺЁжҲҗзӯ–з•Ҙзі»з»ҹзҡ„пјҢжҳҜеҗҺйқўйӮЈдёӨзҜҮ X ж–Үз« гҖӮ

е®ғејҖе§ӢдәҺ 2026 е№ҙ 5 жңҲ 15 ж—ҘпјҢжҲ‘жҠҠдёӨзҜҮ X ж–Үз« дёўз»ҷ Codexпјҡ

> <https://x.com/kovainvest/status/2055026277149741399>
> <https://x.com/MMMusol/status/2054789628016931253>
> иҜ·дҪ иҜ»дёҖдёӢиҝҷдёӨзҜҮж–Үз« пјҢз„¶еҗҺеҪўжҲҗи®ЎеҲ’и®ЎеҲ’жһ„е»әдёҖеҘ—еҸҜжү§иЎҢзҡ„дәӨжҳ“зӯ–з•Ҙе®һзҺ°зЁіеҒҘзӣҲеҲ©

еҪ“ж—¶жҲ‘жғіиҰҒзҡ„дёңиҘҝе…¶е®һеҫҲжңҙзҙ пјҡжҠҠеҲ«дәәжҖ»з»“еҮәжқҘзҡ„дәӨжҳ“жЎҶжһ¶пјҢиҪ¬жҲҗдёҖеҘ—жҲ‘иғҪжү§иЎҢгҖҒиғҪеӣһжөӢгҖҒжңҖеҘҪиҝҳиғҪй•ҝжңҹзӣҲеҲ©зҡ„зі»з»ҹгҖӮжҚўеҸҘиҜқиҜҙпјҢе°ұжҳҜжғіи®©вҖңзҒөж„ҹвҖқеӯҰдјҡжҢүжөҒзЁӢжү“еҚЎгҖӮ

з¬¬дёҖзҜҮж–Үз« еҒҸиҝӣж”»пјҢи®Ізҡ„жҳҜжҲҗй•ҝиӮЎгҖҒCAN SLIMгҖҒзӣёеҜ№ејәеәҰгҖҒVCPгҖҒPocket PivotгҖҒжӯўжҚҹе’ҢеҠ д»“гҖӮз¬¬дәҢзҜҮж–Үз« еҒҸйҳІе®ҲпјҢи®Ізҡ„жҳҜзүӣеёӮеҗҺж®өгҖҒдј°еҖјгҖҒеёӮеңәе®ҪеәҰгҖҒMA200гҖҒRSI иғҢзҰ»гҖҒжҲҗдәӨйҮҸжҙҫеҸ‘пјҢд»ҘеҸҠ AI е’ҢеӯҳеӮЁжқҝеқ—иҝҮзғӯж—¶зҡ„йЈҺйҷ©гҖӮ

иҝҷдёӨзҜҮж–Үз« з»ҷдәҶзі»з»ҹжңҖж—©зҡ„йӘЁжһ¶пјҡејәзҡ„ж—¶еҖҷиҝӣж”»пјҢејұзҡ„ж—¶еҖҷжҙ»дёӢжқҘгҖӮ

дҪҶеҫҲеҝ«пјҢз¬¬дёҖдёӘзҺ°е®һй—®йўҳе°ұжқҘдәҶпјҡж–Үз« жң¬иә«е№¶дёҚеҘҪиҜ»гҖӮX йЎөйқўе…¬ејҖиҜ·жұӮдёҚеҸҜиҜ»пјҢзҹӯй“ҫеұ•ејҖеҗҺжүҚеҸ‘зҺ°жҳҜ X ArticlesпјҢе…¬ејҖ HTTP еҸҲиҝ”еӣһ 403гҖӮжңҖеҗҺйҖҡиҝҮеҸҜз”Ёзҡ„ GraphQL / зҷ»еҪ•жҖҒйЎөйқўж–№ејҸжүҚиҜ»еҲ°жӯЈж–ҮгҖӮзҺ°еңЁеӣһеӨҙзңӢпјҢиҝҷдёӘејҖеңәеҫҲжңүиұЎеҫҒж„Ҹд№үпјҡжҲ‘д»ҘдёәжҲ‘иҰҒеҶҷзӯ–з•ҘпјҢзҺ°е®һе…Ҳи®©жҲ‘еӯҰдјҡвҖңжҖҺд№ҲжҠҠж–Үз« жү“ејҖвҖқгҖӮ

жҲ‘д»ҘдёәжҲ‘иҰҒи§ЈеҶізҡ„жҳҜвҖңеҰӮдҪ•еҶҷзӯ–з•ҘвҖқгҖӮ

еҗҺжқҘжүҚеҸ‘зҺ°пјҢзңҹжӯЈдёҖзӣҙзј зқҖжҲ‘зҡ„пјҢжҳҜвҖңеҰӮдҪ•еҸ–еҫ—еҸҜдҝЎзҡ„ж•°жҚ®пјҢеҰӮдҪ•иҜҒжҳҺиҮӘе·ұжІЎжңүиҜ»й”ҷдё–з•ҢвҖқгҖӮ

## з¬¬дёҖз« пјҡжҲ‘з¬¬дёҖж¬Ўд»ҘдёәвҖңеӣһжөӢеҮәжқҘдәҶвҖқе°ұжҳҜиҝӣеұ•

жңҖж—©зҡ„зӯ–з•ҘжЎҶжһ¶еҫҲжё…жҘҡпјҡ

* еёӮеңәејәж—¶пјҢеҸӘд№°ејәеҠҝжҲҗй•ҝиӮЎгҖӮ
* жІЎжңү setup ж—¶пјҢдёҚдәӨжҳ“гҖӮ
* д№°й”ҷеҝ«йҖҹжӯўжҚҹгҖӮ
* д№°еҜ№жүҚеҠ д»“гҖӮ
* еёӮеңәиҪ¬ејұж—¶йҷҚд»“жҲ–иҪ¬зҺ°йҮ‘гҖӮ
* жүҖжңүдәӨжҳ“еҝ…йЎ»еҸҜи®°еҪ•гҖҒеҸҜеӨҚзӣҳгҖҒеҸҜеӣһжөӢгҖӮ

иҝҷдёӘжЎҶжһ¶жң¬иә«жІЎй”ҷгҖӮй—®йўҳжҳҜпјҢжЎҶжһ¶еҸҳжҲҗд»Јз Ғд»ҘеҗҺпјҢд»»дҪ•дёҖдёӘз»ҶиҠӮйғҪдјҡж”№еҸҳз»“жһңгҖӮ

еҪ“ж—¶жҲ‘з»ҷеҮәзҡ„жү§иЎҢзәҰжқҹжҳҜпјҡ

* иҙҰжҲ·и§„жЁЎ 4 дёҮзҫҺе…ғгҖӮ
* иӮЎзҘЁжұ е…Ҳи®©зі»з»ҹиҮӘйҖүгҖӮ
* е°қиҜ•дҪҝз”ЁеҲҡж·»еҠ зҡ„ LongBridge MCPгҖӮ
* еҸӘеҒҡж—Ҙзәҝж”¶зӣҳдҝЎеҸ·гҖӮ
* е…ҲеҒҡеӣһжөӢпјҢжіЁж„ҸйҒҝе…ҚжңӘжқҘеҮҪж•°гҖӮ

з¬¬дёҖзүҲе®һзҺ°еҫҲеҝ«еҶҷеҮәжқҘдәҶгҖӮйЎ№зӣ®еҪ“ж—¶иҝҳдёҚжҳҜ git д»“еә“пјҢжүӢиҫ№д№ҹеҸӘжңүдёҖдәӣйӣ¶ж•Јзҡ„еҲёе•ҶеҸӘиҜ»жҸ’д»¶е’ҢиЎҢжғ…и„ҡжң¬пјҢдәҺжҳҜжҲ‘е…ҲжҠҠжңҖе°ҸеҸҜи·‘зҡ„зӯ–з•Ҙй…ҚзҪ®гҖҒзӯӣйҖүи„ҡжң¬гҖҒеӣһжөӢи„ҡжң¬е’Ңзәёйқўи„ҡжң¬зЎ¬жӢјиө·жқҘгҖӮеҪ“ж—¶еҸҜз”Ёзҡ„ LongBridge SDK иғҪи·‘иө·жқҘпјҢжүҖд»Ҙе…Ҳиө° LongBridge ж—ҘзәҝпјҢжҢҮж•°жҲ–еӨұиҙҘйЎ№еӣһйҖҖ YahooгҖӮ

дҪҶеҰӮжһңеҸӘеҶҷжҲҗвҖңж–°еўһдәҶеҮ дёӘи„ҡжң¬вҖқпјҢиҝҳжҳҜеӨӘиҪ»дәҶгҖӮзҺ°еңЁеӣһеӨҙзңӢпјҢйӮЈдёӘйҳ¶ж®өиҷҪз„¶иҝҳиҝңиҝңз§°дёҚдёҠзі»з»ҹпјҢеҚҙе·Із»ҸдёҚжҳҜеҚ•ж–Үд»¶еҺҹеһӢпјҢиҖҢжӣҙеғҸдёҖдёӘз”Ё Node.js дёҙж—¶жӢјеҮәжқҘзҡ„еҫ®еһӢдәӨжҳ“е·ҘдҪңеҸ°гҖӮ

жңҖж—©йӮЈеҘ— Node е·Ҙе…·еҫҲеҝ«е°ұиў«дёІжҲҗдәҶдёҖз»„еҸҜйҮҚеӨҚжү§иЎҢзҡ„е‘Ҫд»Өпјҡ

* `strategy:regime` иҙҹиҙЈзңӢеӨ§зӣҳзҺҜеўғгҖӮ
* `strategy:screen` иҙҹиҙЈеңЁи§ӮеҜҹеҗҚеҚ•йҮҢзӯӣеҖҷйҖүгҖӮ
* `strategy:backtest` иҙҹиҙЈи·‘ж—ҘзәҝеӣһжөӢпјҢд№ҹиғҪеҲҮдёҚеҗҢ universeгҖӮ
* `paper:run` иҙҹиҙЈз»ҙжҠӨзәёйқўзҠ¶жҖҒгҖҒи®ўеҚ•гҖҒжқғзӣҠжӣІзәҝе’ҢеҗҢжӯҘиҜҙжҳҺгҖӮ

д№ҹе°ұжҳҜиҜҙпјҢжңҖејҖе§Ӣзҡ„йЎ№зӣ®е…¶е®һдёҚжҳҜвҖңе…ҲжңүдёҖдёӘеӨ§зі»з»ҹпјҢеҶҚж…ўж…ўеҒҡеҠҹиғҪвҖқпјҢиҖҢжҳҜеҸҚиҝҮжқҘпјҡе…ҲжңүдёҖжҠҠйӣ¶ж•ЈдҪҶе·Із»ҸиғҪе·ҘдҪңзҡ„ Node е·Ҙе…·пјҢеҶҚд»Һиҝҷдәӣе·Ҙе…·йҮҢж…ўж…ўй•ҝеҮәзҠ¶жҖҒгҖҒи§„еҲҷгҖҒзӣ®еҪ•е’Ңиҫ№з•ҢгҖӮ

еҰӮжһңз”ЁеҗҺжқҘзҡ„иҜҚеӣһзңӢпјҢиҝҷдәӣе‘Ҫд»Өе°ұжҳҜжңҖж—©зҡ„ CLIгҖӮдҪҶеҪ“ж—¶жҲ‘е№¶дёҚдјҡиҝҷж ·жғігҖӮе®ғд»¬жӣҙеғҸдёҖжҺ’дёҙж—¶ејҖе…іпјҡе“ӘдёӘи„ҡжң¬иғҪи·‘пјҢжҲ‘е°ұз”Ёе“ӘдёӘи„ҡжң¬зңӢдёҖзңјз»“жһңгҖӮй—®йўҳжҳҜпјҢдәӨжҳ“зі»з»ҹдёҚдјҡеӣ дёәе…ҘеҸЈз®ҖйҷӢе°ұе°‘дёҖд»ҪиҙЈд»»гҖӮеҸӘиҰҒдёҖдёӘе‘Ҫд»ӨдјҡзӯӣиӮЎзҘЁгҖҒи·‘еӣһжөӢгҖҒеҶҷзәёйқўзҠ¶жҖҒпјҢе®ғе°ұе·Із»ҸеңЁи§ЈйҮҠзӯ–з•ҘзҺ°е®һгҖӮ

йӮЈжү№и„ҡжң¬д№Ӣй—ҙзҡ„е…ізі»д№ҹжҜ”вҖңеҮ дёӘе°Ҹи„ҡжң¬вҖқжӣҙзҙ§пјҡ

* ж•°жҚ®жҸҗдҫӣеұӮе…Ҳе°қиҜ•иө° LongBridgeпјҢеӨұиҙҘжҲ–йҒҮеҲ°жҢҮж•°е°ұеӣһйҖҖ YahooгҖӮ
* universe еұӮиҙҹиҙЈ static еҗҚеҚ•е’Ң point-in-time жҢҮж•°жҲҗеҲҶгҖӮ
