# Atlas Menu Data Breach

## What Happened

In May 2026, the GTA V and CS2 cheat service [Atlas Menu](https://atlasmenu.net) suffered a data breach. An attacker claimed to have gained access to all Atlas systems and published the service's database to a public GitHub repository. The incident exposed 64k unique email addresses along with usernames, IP addresses, support tickets and passwords stored as bcrypt hashes.
