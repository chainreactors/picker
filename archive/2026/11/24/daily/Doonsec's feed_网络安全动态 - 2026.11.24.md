**网络安全动态 — Cyber Daily**

2026.11.24

国家互联网应急中心发布关于远控类僵尸网络家族Cling新变种大范围传播的风险提示

关键词：Cling僵尸网络

2026年11月24日报道。国家互联网应急中心监测发现，Cling僵尸网络新变种利用公共STUN服务隐藏控制指令，主要针对Linux服务器及IoT设备，旨在长期控制并投递恶意软件。2026年11月境内累计感染约5600台设备。建议修复漏洞、加强口令并监测STUN异常流量。

Source:https://mp.weixin.qq.com/s/a1f5A0UPOCOovT5j6KckmQ

iTerm2远程代码执行漏洞允许攻击者通过显示特制文件运行恶意命令

关键词：远程命令执行

2026年11月23日报道。iTerm2 在处理 Kitty 图形协议 时存在逻辑漏洞，打印包含恶意转义序列的文件即可触发远程命令执行。官方已在 3.7.9 版本修复，建议尽快升级并在更新前避免直接打印未知文件内容。

Source:https://cybersecuritynews.com/iterm2-remote-code-execution-flaw/

黑客利用关键ASP.NET反CSRF库漏洞实现未经身份验证的远程代码执行

关键词：远程代码执行

2026年11月23日报道。攻击者利用未修复的 Idunno.AntiCsrf 反序列化漏洞（CVE-2026-131914），在旧版 ASP.NET WebForms 上免登录以 w3wp.exe 权限执行代码。因其在 Page\_Load 前运行，仅换机器密钥无效；需移除组件、查日志与后门并轮换密钥。

Source:https://cybersecuritynews.com/asp-net-anticsrf-flaw-under-attack/

微软Azure漏洞遭利用以窃取客户API凭据

关键词：重放漏洞

2026年11月23日报道。微软修复了 Azure API 管理 Classic 层的一个漏洞，该漏洞曾被用于窃取客户存储的 API 凭证与密钥。微软于 11 月 18 日发现问题、19 日部署修复，但警告修复不会自动使此前可能泄露的凭证失效，受影响客户需立即轮换凭证、排查异常活动并核查运行时更新。

Source:https://www.bleepingcomputer.com/news/security/microsoft-azure-flaw-exploited-to-steal-customers-api-credentials/
