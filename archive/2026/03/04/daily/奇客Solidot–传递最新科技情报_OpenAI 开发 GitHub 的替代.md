## OpenAI 开发 GitHub 的替代

[![开源](https://icon.solidot.org/images/topics/topicopensource.png?123)](/search?tid=3 "开源")

[Edwards](/~Edwards) (42866)发表于 2026年03月04日 14时34分 星期三 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83674&appkey=1370085986&title=OpenAI%20%E5%BC%80%E5%8F%91%20GitHub%20%E7%9A%84%E6%9B%BF%E4%BB%A3%20 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自失眠**

OpenAI 正在开发一个代码托管平台，与微软的 GitHub 展开竞争。原因据称 GitHub 服务过去几个月频繁中断，导致 OpenAI 工程师们无法工作，因此他们决定开发自己能控制的新代码托管平台。该项目仍然处于早期阶段，可能还需要几个月时间才能完成。如果 OpenAI 真的推出这款产品，那么这将意味着 OpenAI 将与其大股东微软展开直接竞争。根据最新一轮融资，OpenAI 的估值达到了 8400 亿美元。
https://www.reuters.com/business/openai-is-developing-alternative-microsofts-github-information-reports-2026-03-03/
