## Summary

* Bump the public header version macros to 2.0.0 (`FAKELUA_VERSION_*` / `FAKELUA_VERSION_STRING`).
* Add a `Release` workflow that, on `master`, compares `FAKELUA_VERSION_STRING` with the previous commit and, if it changed and `vX.Y.Z` does not already exist, builds the shared library on Linux, macOS, and Windows, then publishes header + dynamic library packages to a GitHub Release.
* Add `FAKELUA_BUILD_TESTS` / `FAKELUA_BUILD_BENCHMARKS` CMake options (default ON) so the release job can skip Lua, tests, and benchmarks.
