🧰 ironclaw
是一个受 OpenClaw 启发的 Rust 智能体运行时，具备沙盒和秘密边界等纵深防御机制。Near AI ⭐️3.9k https://github.com/nearai/ironclaw

🧰 nono
内核强制沙箱 CLI 和 SDK，用于隔离 AI 代理，并提供能力控制和安全密钥注入功能。Always Further ⭐️678 https://github.com/always-further/nono

🧰 clawsec
一款适用于 OpenClaw 和 NanoClaw 代理的安全技能套件，包含审计、漂移检测和完整性检查功能。Prompt Security ⭐️549 https://github.com/prompt-security/clawsec

🧰 Crust
是一种代理安全基础设施，可在执行前拦截并阻止危险的代理行为。BakeLens ⭐️391 https://github.com/BakeLens/crust

🧰SKILLS
一套面向AI编码代理的应用安全技能，用于自动化安全检查和安全审查工作流程。Ghost Security ⭐️356 https://github.com/ghostsecurity/skills

🧰 AgentGuard
是一款用于 AI 代理的运行时防护工具，可阻止恶意技能、防止数据泄露并保护机密信息。GoPlus Security ⭐️293 https://github.com/GoPlusSecurity/agentguard

🧰 clawbands
是 OpenClaw 代理的安全中间件，用于强制执行更安全的执行路径和策略带。Sandro Munda ⭐️160 https://github.com/SeyZ/clawbands

🧰 Pipelock
是一款适用于 AI 代理的防火墙，具备 DLP 扫描、SSRF 防护、MCP 扫描和工具中毒检测功能。Lucky Pipewrench ⭐️136 https://github.com/luckyPipewrench/pipelock

🧰 openclaw-dashboard
是一个自托管的仪表盘，支持身份验证和 TOTP 多因素身份验证，用于监控 OpenClaw 代理会话、成本和内存使用情况。Tuğcan Topaloğlu ⭐️124 https://github.com/tugcantopaloglu/openclaw-dashboard

🧰 forgemax
沙盒式 MCP 网关，可将刀具表面折叠到约束界面后方，以减小爆炸半径。Laurence Postrv ⭐️121 https://github.com/postrv/forgemax

🧰 ai-bom
通过发现用于治理的代理框架、模型调用和 AI API，构建 AI 物料清单。Trusera ⭐️105 https://github.com/Trusera/ai-bom

🧰 invisible-prompt-injection
工具包，用于检测和演示内容和 Markdown 中的不可见提示符注入。赏金 ⭐️105 https://github.com/bountyyfi/invisible-prompt-injection

🧰 确定性代理控制协议 (deterministic-agent-control-protocol)
是一个面向 AI 代理的治理网关，通过 MCP 代理实现有界、可审计、会话感知的控制。Elliot Schroeder ⭐️81 https://github.com/elliot35/deterministic-agent-control-protocol

🧰 Ship-Safe
是一款面向开发者的 AI 应用安全扫描器，可检测常见攻击类型并进行密钥检查。Alhassane Samassekou ⭐️78 https://github.com/asamassekou10/ship-safe

🧰 ironcurtain
是一个安全的自主 AI 代理运行时环境，它强制执行纯文本策略约束和沙箱机制。Niels Provos ⭐️74 https://github.com/provos/ironcurtain

🧰 augustus
是一款基于 Go 的 LLM 漏洞扫描器，支持提示注入、越狱和对抗性探测，并提供报告。Praetorian ⭐️72 https://github.com/praetorian-inc/augustus

🧰 VibeGuard
是一款中间人攻击 HTTPS 代理，可在敏感数据到达 AI 代码后端之前对其进行脱敏处理。Ink Dust ⭐️71 https://github.com/inkdust2021/VibeGuard

🧰 agent-security-scanner-mcp
是一个 MCP 服务器，用于扫描 AI 编码代理的输出，以检测提示注入和不安全的包行为。Sinewave AI ⭐️70 https://github.com/sinewaveai/agent-security-scanner-mcp

🧰 SecCoderX
研究代码库，用于面向安全的 LLM 代码生成和评估工作流程。Andrew Wang ⭐️53 https://github.com/AndrewWTY/SecCoderX

🧰 moltbook-agent-guard
为 Moltbook 代理提供运行时保护，可扫描并阻止提示注入和数据泄露尝试。Nir Diamant at DiamantAI ⭐️48 https://github.com/NirDiamant/moltbook-agent-guard

🧰 aguara
是一款离线静态扫描器，用于检测 AI 代理技能和 MCP 服务器，以捕获注入、数据外泄和供应链滥用行为。Garagon ⭐️41 https://github.com/garagon/aguara

🧰 allama
一个基于 AI 代理的自托管 SOAR 式平台，用于威胁检测和响应自动化。DigiTransLab ⭐️41 https://github.com/digitranslab/allama

🧰 agentlinter
会对代理配置文件（例如 AGENTS.md 和 CLAUDE.md）进行检查，以发现风险指令模式和安全漏洞。Seojoon Kim ⭐️38 https://github.com/seojoonkim/agentlinter

🧰 agentshield
是一款用于扫描代理配置和 MCP 服务器的安全扫描器，可标记密钥、权限和钩子注入模式。Affaan Mustafa ⭐️37 https://github.com/affaan-m/agentshield

🧰 openclaw-mcp
是一个支持 OAuth2 认证的 MCP 桥接器，用于安全地连接 OpenClaw 客户端和自托管助手。Tomas Grasl ⭐️32 https://github.com/freema/openclaw-mcp

🧰 agent-safehouse
macOS 沙箱配置文件，用于强制 LLM 编码代理遵循最小权限原则。Eugene ⭐️31 https://github.com/eugene1g/agent-safehouse

🧰 AgentGate
API 网关，用于 AI 代理，并支持对敏感写入操作进行人工审批。Luis Montes ⭐️25 https://github.com/monteslu/agentgate

🧰 openclaw-skills-security
是一款以安全为先的 OpenClaw 技能包，用于审核技能中的注入和供应链风险。UseAI ⭐️21 https://github.com/UseAI-pro/openclaw-skills-security

🧰 Janee
一款 MCP 密钥代理，它会在执行时注入凭证并记录访问信息，因此代理永远不会看到原始密钥。R. Douglas ⭐️20 https://github.com/rsdouglas/janee

🧰 MCPHammer
红队 MCP 安全测试框架，用于评估服务器漏洞。Praetorian ⭐️20 https://github.com/praetorian-inc/MCPHammer

🧰 bagman-skill
为 AI 代理提供安全的密钥存储和会话密钥模式，以减少秘密泄露和注入爆炸半径。Zachary Scole ⭐️17 https://github.com/zscole/bagman-skill

🧰 openclaw-contained
一个面向代理的、具有审批工作流和完整审计日志的功能受限容器沙箱。Roman Klis ⭐️17 https://github.com/romanklis/openclaw-contained

🧰 PDF-Prompt-Injection-Toolkit
是一款用于在 PDF 中嵌入和检测提示注入载荷的红蓝队工具包。Zhihui Yu ⭐️17 https://github.com/zhihuiyuze/PDF-Prompt-Injection-Toolkit

🧰 hexstrike-ai-community-edition
一款人工智能辅助的攻击性安全工具包，适用于渗透测试和漏洞研究工作流程。CommonHuman Lab ⭐️16 https://github.com/CommonHuman-Lab/hexstrike-ai-community-edition

🧰 secretless-ai
可防止在常用 AI 编码工具和代理工作流程中，秘密信息泄露到 AI 上下文窗口中。OpenA2A ⭐️16 https://github.com/opena2a-org/secretless-ai

🧰 agentshield-benchmark
是一款针对代理安全工具的基准测试套件，涵盖注入、数据泄露、工具滥用和来源溯源。Doron Podoleanu ⭐️14 https://github.com/doronp/agentshield-benchmark
