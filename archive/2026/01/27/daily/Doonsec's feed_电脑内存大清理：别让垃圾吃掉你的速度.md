第一部分：系统盘深度清理（20分钟见效）

第一步：彻底清理临时文件

同时按下Win+R，输入%temp%回车，全选删除（跳过无法删除的）。

第二步：使用系统自带清理工具

1. 右键点击C盘 → 属性 → 磁盘清理

2. 点击“清理系统文件”

3. 勾选所有选项（尤其“Windows更新清理”和“系统错误内存转储文件”）

4. 点击确定，可释放5-20GB空间

第三步：清理应用缓存

· 微信：设置 → 文件管理 → 清空聊天记录缓存

· 浏览器：设置 → 隐私和安全 → 清除浏览数据（勾选“缓存的图片和文件”）

第二部分：软件卸载与精简（30分钟操作）

识别“流氓软件”特征：

· 名称带有“助手”、“加速”、“大全”字样

· 安装时间是你没主动操作的时候

· 频繁弹出广告或推荐

正确卸载方法：

控制面板 → 程序和功能 → 按安装日期排序，批量卸载近半年无用软件。

必装替代推荐：

· 杀毒软件：用系统自带Windows Defender即可

· 压缩软件：用7-Zip（免费无广告）

· 视频播放：用VLC播放器

第三部分：开机启动项优化（5分钟设置）

1. 按Ctrl+Shift+Esc打开任务管理器

2. 选择“启动”标签页

3. 右键禁用所有非必要程序（保留杀毒和输入法）

4. 重启电脑，开机速度至少提升30%

第四部分：大文件定位与清理（针对性解决）

使用工具：SpaceSniffer（免费绿色软件）

1. 以管理员身份运行

2. 选择要分析的磁盘

3. 直观查看哪些文件夹占用最大

4. 重点关注：下载文件夹、视频缓存、旧版安装包

常见“空间杀手”：

· 微信/QQ聊天记录（特别是群聊视频）

· 旧手机备份文件（iTunes/华为手机助手备份）

· 虚拟机镜像文件（.vhd/.iso文件）

· 已完结的项目文件夹

第五部分：进阶清理（谨慎操作）

清理休眠文件（适合台式机/不常休眠用户）：

以管理员身份运行命令提示符，输入：

```

powercfg -h off

```

可立即释放约等于内存大小的空间（如16GB内存即释放16GB）。

转移虚拟内存（C盘空间告急时）：

1. 控制面板 → 系统 → 高级系统设置

2. 性能 → 设置 → 高级 → 虚拟内存 → 更改

3. 取消“自动管理”，选择C盘 → 无分页文件 → 设置

4. 选择D盘 → 系统管理的大小 → 设置

5. 重启生效

清理后必须做的三件事

1. 运行磁盘碎片整理（仅机械硬盘需要）：

   · 右键C盘 → 属性 → 工具 → 优化

   · 选择每个盘符 → 优化

2. 创建系统还原点：

   · 控制面板 → 系统 → 系统保护

   · 选择C盘 → 配置 → 启用保护

   · 创建还原点，命名“清理后状态”

3. 建立日常维护习惯：

   · 每月第一周：清理临时文件

   · 每季度：检查启动项

   · 每年：深度清理并备份重要数据

避坑指南：哪些不能删？

· Windows文件夹及其子文件夹

· Program Files和Program Files (x86)

· Users下自己账号外的其他文件夹

· AppData下的Microsoft文件夹

效果预期与验证

清理完成后：

· C盘至少应多出20%空间

· 开机时间缩短30%-50%

· 软件打开速度明显提升

如效果不明显，可能是硬盘老化或需要重装系统。

电脑清理如同房间大扫除，定期做一次，使用时心情都会变好。记住两个原则：不确定的文件不删，重要数据先备份
