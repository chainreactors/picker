如果你花几美元买一个普通的商业代理 IP，用来抓点网页数据或者刷个票，结果查了一下出口 IP 的归属地—— **美国总统行政办公室（Executive Office of the President，简称 EOP）** 。

你敢信吗？这不是好莱坞黑客电影里的桥段，竟然是真实发生的。

在整整一个月的时间里，白宫专网（自治系统号 AS2650 ）不仅成了公共住宅代理池里的“共享节点”，甚至先后被 28 家不同的商业代理服务商 当作跳板对外转发流量。只要花几美金注册账号，全球任何一个普通买家都有可能 “借道”白宫网络上网 。

01

DISCOVERY

### 偶然扫出的大雷：236 次从白宫飞出的流量

故事的起因其实 非常偶然 。

前不久，安全团队 Layer3 Intel 上线了一套名为 “住宅代理观测站” （Residential Proxy Observatory）的全球监控系统，专门用来追踪全球范围内的 匿名代理和住宅代理节点 。

为了枚举市面上的代理池，研究人员干了一件很常规的事：像普通客户一样，在几十家公开售卖住宅代理的平台上充了点小钱，开启 全球随机轮询 （Global Rotating Access）模式，不断通过代理节点 向外发探测包 ，看看出口 IP 都在哪。

结果在翻看后台日志时，几条刺眼的记录直接让研究员看傻了眼—— 探测流量居然从 AS2650 出来了 。

稍微了解 BGP 路由和网络基建的朋友都知道， AS2650 可不是什么普通家庭宽带运营商，它的注册主体是 **美国总统行政办公室（EOP）** ，也就是直接承载 美国白宫核心办公与行政体系 的网络基础设施。

为了排除误报，Layer3 Intel 调取了 **10 月 5 日至 11 月 3 日** 整整 30 天的观测数据，并交叉比对了 **Spur** 和 **Synthient** 等多家权威威胁情报平台的公开上下文数据，最终确认了以下几个 令人后背发凉的事实 ：

236次

独立代理出口通信

26/30天

全月高频在线天数

28家

关联商业代理服务商

| 关键观测维度 | 披露数据与细节 | 安全含义解读 |
| --- | --- | --- |
| **归属自治系统** | AS2650（美国总统行政办公室 EOP） | 确认物理/逻辑出口位于白宫所属行政专网段 |
| **捕获出口次数** | 累计 236 次独立代理出口通信 | 绝非偶发路由漂移，而是长期稳定的代理驻留 |

| **涉及出口 IP 数** | 共计 6 个不同的白宫网络 IP 地址 | 可能存在多台失陷终端，或 DHCP 动态租约轮换 |
| **关联代理商数量** | 覆盖 28 家不同的住宅代理服务商 | 底层代理 SDK 存在分销机制，流量被转手卖给多家平台 |

更关键的是，Layer3 Intel 强调： 他们根本没有定向针对白宫 ，仅仅是在公开代理平台上花了点零花钱随机轮询，就撞上了这几个节点。换句话说，这段时间里任何购买了这 28 家代理服务的黑客、爬虫工程师甚至境外情报人员，都有机会 顶着白宫的官方 IP 在互联网上“裸奔”。

02

TRAFFIC PROFILE

### 流量画像追踪：是访客 Wi-Fi，还是“夜猫子”幕僚？

消息一出，很多人第一反应是：“白宫每天有那么多记者、外包人员和访客，会不会只是某个人连上了 白宫的公共访客 Wi-Fi ？”

但安全团队通过对这 236 次流量的 **时间戳分布** 进行分析后，给出了一个 更耐人寻味的推论 。监控数据显示，来自白宫网络的代理流量呈现出极其明显的作息规律：

晚间至深夜高度集中

将近一半的流量集中在 美东时间下午 5：00 到午夜 12：00 之间。

凌晨至清早几乎归零

在凌晨到清早这段时间， 代理流量几乎为零 ，完全不具备 24 小时常驻服务器特征。

这种“傍晚开始活跃、深夜下线、凌晨归零”的曲线，基本排除了 24 小时开机的机房服务器，也不太像白天人来人往、晚上清空的普通访客网络。它高度吻合一个 **“人”** 的行为特征—— 某位经常在白宫熬夜加班到深夜的内部人员 （或常驻人员），把带有代理后门的个人设备带进了白宫，并连上了专网。

甚至在 Hacker News 评论区里，有老外网友调侃创造了一个新词—— Presidential Proxy（总统级住宅代理） ，并给出了几个 非常接地气的猜想 ：

1

**山寨电视盒子（如 SuperBox 等）：** 很多工作人员为了在办公室深夜加班时看 24 小时有线电视新闻或体育赛事，会私自接上号称 “永久免费看有线电视” 的安卓机顶盒。这类灰产盒子几乎 100% 预装了商业代理 SDK——你免费看它的盗版电视，它拿你的内网带宽卖给代理商赚钱。

2

**免费 VPN 或伪装 App：** 员工手机或笔记本上安装了打着“免费 VPN”、“天气预报”、“小游戏”或“去广告插件”旗号的软件。这些软件在冗长的用户协议里夹带私货，或者干脆 静默植入代理 SDK ，只要设备亮屏联网，就会化身代理节点。

3

**驻场媒体或外包设备：** 也有资深网工指出， AS2650 地址段下可能划分了给常驻白宫新闻简报室的媒体记者（Press Corps）或非涉密行政办公使用的 独立 VLAN ，未必直接连通核心机密内网（如 SCIF 敏感隔离信息设施）。

03

ATTACK VECTOR

### 什么是“住宅代理”？为什么它是天然的后门？

对于非安全圈的读者来说，“住宅代理（Residential Proxy）”听起来像是个正经的商业名词，但在安全研究员眼里， 这个行业水深得可怕 。

在反爬虫和风控对抗日益激烈的今天，阿里云、AWS 等数据中心（IDC）的机房 IP 很容易被网站直接拉黑。于是，市场对 **“真实家庭宽带 IP（住宅 IP）”** 产生了 巨大需求 。

那么，代理服务商手里号称“覆盖全球上千万真实家庭”的 IP 是哪来的？绝大多数都不是用户知情同意租出去的，而是通过一条 隐秘的灰色产业链 ：代理商开发出轻量级的 Proxy SDK （软件开发工具包），按活跃设备数给中小型 App 开发者、浏览器插件作者、甚至是智能电视/机顶盒固件厂商发补贴。用户一旦安装了这些带毒的应用或买了杂牌智能硬件，设备就会在后台 静默建立加密隧道 ，连回代理商的控制端（C2）。

为什么这件事发生在白宫网络里，性质就彻底变了？

因为它绝不仅仅是“被白嫖了一点带宽”那么简单，背后藏着 两层致命风险 ：

1. 借刀杀人：天然的“高信誉”攻击跳板

如果攻击者通过购买代理，筛选或锁定到白宫 AS2650 的出口节点，并用它去发起网络钓鱼、密码喷洒、敏感情报刺探或漏洞扫描，目标防守方的防火墙和威胁情报系统看到的源 IP 是 **美国总统行政办公室** 。这种极高信誉度的官方 IP 不仅能轻松绕过大量基于地理和信誉的防护策略，还极易引发 严重的归因误判 。

2. 引狼入室：从代理 SDK 到内网横向移动

这才是最让白宫安全团队睡不着觉的地方。很多劣质的商业代理 SDK 在编写代码时，根本没有做严格的本地回环地址（Localhost）和 内网私有地址段（RFC1918）过滤 ！

今年安全机构 Synthient 在《A Broken System Fueling Botnets》报告中就曾揭露过一个真实案例： **Kimwolf 僵尸网络** 正是利用了住宅代理 SDK 缺乏内网隔离机制的缺陷 ，直接顺着代理隧道反向向节点所在的局域网发送探测包，寻找开启了 ADB 调试端口的安卓设备，一口气感染了超过 **200 万台** 终端。

04

GLOBAL REACH

### 连南极洲和孤岛都没逃过：无孔不入的代理黑产

白宫并不是 Layer3 Intel 在这次全球扫描中发现的唯一奇观。为了证明如今的 住宅代理 SDK 已经泛滥到了什么程度 ，报告还顺手晒出了几个位于“地球尽头”的沦陷区：

南极洲（Antarctica）

监控到了 3 次代理出口活动，IP 指向美国南极洲 麦克默多科考站（McMurdo Station） 的 Cloudflare WARP 出口。看来南极科考队员的手机或电脑也没能幸免。

圣赫勒拿岛（拿破仑流放地）

这个位于南大西洋、被称为“世界最偏远有人居住孤岛”的地方，竟然被扫出了 413 个独立代理 IP、超过 3.2 万次通信记录 ，流量平分在 Starlink（星链）和当地运营商之间。

北极斯瓦尔巴群岛（Svalbard）

全球末日种子库所在地，在朗伊尔城发现了 通过 Starlink 联网的代理节点 。

皮特凯恩群岛（Pitcairn）

南太平洋上只有几十个居民的孤岛，同样抓到了 1 个 活跃在星链上的住宅代理节点 。

从北极圈到南极科考站，从太平洋孤岛到华盛顿权力的中心——只要有智能设备和星链/宽带的地方， 灰产代理 SDK 和僵尸网络 就已经完成了渗透。
