# 2026年3月9日锡特拉岛马哈扎地区发生爆炸，造成数十名平民受伤和房屋损毁。巴林和华盛顿均将 3 月 9 日爆炸事件归咎于伊朗无人机袭击，海湾王国称此次爆炸造成包括儿童在内的 32 人受伤，其中一些伤势严重。美国中央司令部在 X 频道评论袭击当天称，一架伊朗无人机袭击了巴林的一个住宅区。

# 经开源情报分析，美国“爱国者”导弹很可能是造成巴林爆炸事件的原因，而该爆炸事件最初被认为是伊朗所为。

#

# 分析的关键在于一段从公寓楼拍摄并在社交媒体上流传的视频。视频显示，疑似“爱国者”导弹低空向东北方向飞行，随后向下倾斜并消失在视野中。1.3秒后，远处的一道闪光似乎标志着导弹爆炸。该视频最早发布时间是3月9日凌晨2点左右。专门研究数字取证的审查了这段视频，以确定它是否由人工智能生成，发现“没有明显的证据表明该视频是伪造的”。

![](https://mmbiz.qpic.cn/mmbiz_png/no8YFGgia2NG9VG8icndWMSN1PPxTIm1gfzX57m7Iyv0xFR5EIQERxpsvUHITGrhWowyVW7RpKFDJ5Dm5IPhIWFLqxmyZnicj5jbkVjpRsS3vg/640?wx_fmt=png&from=appmsg)

# 视频拍摄地位于巴林第二大城市里法的一个街区。

#

# 3月9日上午，社交媒体上发布的多段视频显示，里法马哈扎社区602号街区的居民住宅遭到破坏。

#

# 根据商业卫星图像，结合导弹飞行轨迹，可找到美国爱国者导弹发射阵地，该阵地距离在里法拍摄导弹飞行视频的地点不到半英里。

#

# 利用商业卫星图像确定，在 3 月 9 日事件发生前两天，里法发射场附近可以看到五个发射器。

#

![](https://mmbiz.qpic.cn/mmbiz_png/no8YFGgia2NFEUISNib6tWRFdaFmdviac3hP5GNAicad85nqk9dCNWTff5dFSXoEFzw2jp8OiapBKtADBWwqc5cWBzpCL4HJ6wdo13xhZoVcQGHg/640?wx_fmt=png&from=appmsg)

# 视频显示，导弹似乎是从路灯杆和建筑物之间的某个位置射出的。通过分析拍摄者在同一路灯杆左侧和卫星图像中可见建筑物右侧的视角，可以发现至少有五个发射器出现在3月7日的卫星图像中，且都位于该视角范围内。路透社/特拉维斯·哈特曼

#

根据卫星图像显示，该导弹防御系统至少从2009年起就已存在。洛克希德·马丁公司发布的新闻稿称，巴林国防军直到2024年才开始使用其自主研发的“爱国者”导弹防御系统。

分析发现，里法遗址具有一些特征，这些特征既是该地区美国“爱国者”导弹防御系统所特有的，又不同于已知的巴林运营的导弹防御系统，例如防护墙、未铺设路面的道路以及缺乏永久性建筑物。基于这些特征，研究人员得出结论，该导弹防御系统很可能由美国运营，美国使用“爱国者”导弹防御系统来保护其在巴林的军事设施。

![](https://mmbiz.qpic.cn/mmbiz_png/no8YFGgia2NF9T2aAQ7TvA3ppmyOxJlA3T871HslictOVVOAEn2icPqY7AHfribEXJ4zOzlMTs3JsaysS5iaBFhGCicc4A8nzhNkbvYxVFReBC4zM/640?wx_fmt=png&from=appmsg)

# 根据研究人员对卫星图像的分析，里法导弹发射场具备与美国在卡塔尔的“爱国者”导弹发射阵地类似的特征，包括发射装置周围的防护墙、未铺设路面的道路以及缺乏永久性建筑物。图片来源：Middlebury/Google Earth Pro via REUTERS

研究人员无法确定爱国者导弹爆炸的具体原因。但他们补充说，根据现有证据，包括地面上的损坏模式和扩散情况，导弹似乎是在飞行途中爆炸的。

分析报告称，他们的结论是，爱国者导弹有可能瞄准的是一架低空飞行的无人机，导弹和无人机的爆炸共同引发了爆炸。

分析报告称：“如果情况属实，这是一次不负责任的拦截行动，因为它危及了居民区内盟军平民的生命和家园。”

这一情景与巴林政府发言人所说的情况相符：爱国者导弹拦截了一架伊朗无人机，两者在空中爆炸。

然而，分析指出，破坏的方向以及附近没有无人机的证据表明存在另一种情况，即“爆炸是爱国者拦截导弹的弹头和未使用的推进剂引爆的结果”。

尽管巴林方面声称导弹击中了无人机，但研究人员表示这种可能性较小。

# 袭击发生后拍摄的视频和巴赫拉尼当局发布的照片显示，爆炸造成的破坏集中在马哈扎的四条街道上。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/no8YFGgia2NGbs8zCJwTIMyTlY7dC9yUXrf3KUuMzZUicjVEF465F0fEIURl2RO4ffTQ8z1BZ29v12dwEgeBwY7QiatQZ5m0jOJiaAnVZ1bAkC0/640?wx_fmt=png&from=appmsg)

研究人员查看了该街区的卫星图像，并未发现弹坑或其他局部受损区域。分析指出：“受损区域并非伊朗无人机（例如 Shehed-136）造成的集中式大爆炸，而是扩散至多个街区，这表明爆炸发生在居民区上空。”（图片来源：Middlebury/Airbus via REUTERS）

巴林电视台3月9日播出的新闻节目和政府新闻稿显示，距离主爆炸中心约400英尺（120米）的一栋房屋严重受损，内部照片显示墙上有弹片造成的孔洞。

综合所有损失来看，其结果与一枚爱国者导弹在附近路口上空爆炸的预期情况相符。分析还称，导弹碎片随后又飞了大约120米，击中了另一栋房屋。

视频中，大约8秒处出现一道闪光，但在19秒后视频结束前，始终没有听到爆炸声。这是因为光速比声速快。根据声音到达拍摄者所需的时间，爆炸地点必定在四英里（约6.4公里）以外。受损房屋距离爆炸地点约4.6英里（7.4公里），这与时间吻合。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/no8YFGgia2NEiaiayS86EGmQBNSqRLlmoFqbGSWms0liam7KcFOnGQbb4py61DMpF3VLkevSeL4v60PEZSHT9b85giaKyeDKkgL1IuCmibqh2Gvss/640?wx_fmt=png&from=appmsg)

导弹视频拍摄设备能够听到声音的距离。路透社/特拉维斯·哈特曼

3月9日，美国中央司令部在一份公开声明中谴责了伊朗和俄罗斯的新闻报道，这些报道称马哈扎事件是“爱国者”导弹发射失败造成的，并称其为“谎言”。声明称，一架伊朗无人机袭击了居民区。

路透社试图联系巴林的目击者，但多人以害怕遭到报复为由拒绝接受采访。人权观察组织记录了战争期间巴林发生的多起逮捕事件，起因是有人在社交媒体上发布袭击视频。

在疑似导弹飞行的视频中，“爱国者”导弹似乎经过了一条陡峭得多的烟迹，研究人员表示，这条烟迹很可能属于几分钟前发射的第一枚拦截导弹。

为了提高命中目标的概率，爱国者导弹通常成对发射。研究人员和路透社都无法确定第一枚导弹的下落。

研究人员表示，第二枚导弹的低弹道及其与先前发射路线的偏差可能预示着存在问题。但他们也不能排除导弹是故意朝那个方向发射的可能性。

巴林发言人表示，任何关于巴林境内爱国者导弹发生故障或发射失误的说法“都与事实不符”。

伊朗官员多次警告称，有人正试图通过所谓的“假旗行动”将阿拉伯国家直接卷入战争。
