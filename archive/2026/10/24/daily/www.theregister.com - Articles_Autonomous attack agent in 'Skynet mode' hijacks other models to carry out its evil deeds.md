Threat actors built an AI agent designed to hijack exposed AI models to run autonomous attacks, with instructions allowing it to carry out up to 100,000 steps without human approval.

The Symantec Threat Hunter Team uncovered the agent's full instruction set over the summer, trapping it in an AI honeypot, and thus giving the researchers a comprehensive view into how the operators built the attack tool and what it could do.

The captured instructions showed a single attack agent designed to scan the entire internet for endpoints that accept OpenAI-style requests without authentication - or that accept a stolen key - and then to exploit several common web frameworks, along with carrying out dozens of illicit actions. These include database theft, credential and secret harvesting, remote code execution, and cryptocurrency mining.

REG AD

In creating the agent, the operators built a malicious loop that they called “Skynet mode” that would scan for targets, infect them, deploy miners, and reinfect hosts. In total, the humans designed the AI agent to run unattended for up to 100,000 steps.

REG AD

“The jailbreak layers were largely off-the-shelf,” Symantec threat hunter Priti More told The Register. “Nothing in the individual techniques is new. What stands out is that someone wired them into a single agent that hands the planning to a borrowed model and runs for up to 100,000 steps without a human.”

Plus, as More pointed out, the attacks create two sets of victims. “The owner of the exposed endpoint pays for the inference. Any server the agent went on to break into would lose data and be put to work mining. We have no evidence yet that it got that far.”

That’s the silver lining to this discovery: the researchers have “no evidence” that the attacker used this agent in real-world attacks. However, “the kit is more than a prototype,” with the history showing the tools working “against a live target, with real-looking scan output,” More said.
