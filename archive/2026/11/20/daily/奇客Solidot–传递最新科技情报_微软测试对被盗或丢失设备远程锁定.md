![](https://icon.solidot.org/images/a7c7.png)

**来自团圆奇遇**

微软在测试一项新功能，允许企业 IT 管理员在不清除数据的情况下远程锁定丢失或被盗的 Windows 设备。被称为远程锁定（Remote Lock）的新功能已提供给运行 Build 26320.10003 或 Build 26340.10013 的 Windows 11 Insider Preview 设备。IT 管理员可通过 Microsoft Intune 自定义配置配置文件，锁定加入 Microsoft Entra 的运行 Windows 企业版、教育版或专业版的设备。一旦 IT 部门远程锁定设备，原有的 PIN 码、密码、本地管理员账户或网页登录方式将全部停止工作，设备仅能通过 Intune 解锁。用户的凭据依然有效，但只能登录其它未被锁定的设备。Windows Insider 通信主管 Stephen Lines 表示：Windows 会注销所有活动会话，隐藏所有登录选项，显示锁定屏幕。设备上的任何数据都不会被清除：设备仍处于注册和受管状态，BitLocker 保持开启，用户数据也完好无损。即便设备重启或处于离线状态，锁定状态依然有效；只有管理员才能远程解除锁定，确保用户在解锁后能从中断处继续工作。
https://www.bleepingcomputer.com/news/microsoft/microsoft-testing-remote-lock-for-lost-or-stolen-windows-devices/
