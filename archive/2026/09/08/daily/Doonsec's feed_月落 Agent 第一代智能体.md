# 月落 Agent 第一代

今天正式发布

2026 年不缺 AI 产品，缺的是一个真正属于你的 AI

自托管 · 数据不上传 · 手机远程 · Windows / Linux · 46 个内置工具

v3.5.1 · 2026 年 9 月

# 写在发布前

过去大半年，我们一直在闭门打磨一个东西。

今天，我们认为它到了。同时借鉴了网上优秀的项目，zcode，pi等等优秀的agent功能

月落 Agent 第一代，正式发布。

# 一句话介绍

月落 Agent，是装在你自己电脑里的、有手有脚、还会自己催自己的 AI 员工。

它不是网页里那个只会聊天的对话框。它运行在你的电脑上（Windows / Linux 都行），出厂自带 46 个内置工具：执行命令、读写文件、操作浏览器、连你的服务器、控制远程桌面、打电话给你、在微信里陪你聊天。

而这一切最狠的地方在于：你的数据从头到尾留在你自己的机器上。不交月费，不上传，不把你的隐私当燃料。

# 凭什么敢叫第一代？这八件事，别人给不了

## ① 46 个工具，出厂即满配

月落直接给你一支队伍。

终端命令、文件系统、浏览器自动化、SSH 远程、RDP 桌面、语音合成、声音克隆、语义记忆、定时调度、代码执行……46 个工具原生内置，不是插件市场里挑挑拣拣，是开箱满配。你说「把报表整理成 Excel 做个图表」，它写脚本、跑数据、生成文件、再自己开浏览器检查渲染效果——确认没问题才交货。

市面上的 AI 在跟你对话，月落在替你干活。

## ② 会自己催自己

AI干活半途而废，月落用机制杀死了这个通病：回合结束，大模型裁判自动上场——结合最初目标与最近约 20 轮对话判断任务是否真的完成；没完成？生成一句直指要害的督促语，让它继续推进，直到完成或达到你设的轮数上限。

实测：两轮上限，第 1、2 轮精准触发，第 3 轮绝不越界；闲聊打招呼，裁判判定已完成，一次不扰。

月落自己盯着自己。

## ③ 你的手机，是作战指挥所

不是「远程看看」的阉割版页面，是和电脑毫秒级同步的完整指挥台：

工具调用实时直播——它跑了什么命令、改了什么文件，每一步都投到你手机上

命令待审批？手机上直接点「允许」

RDP 远程桌面双指缩放、单指操控，办公室电脑揣进口袋

SSH 真终端（PTY 模式），vim、htop 随便开，手机就是一台 Linux

电脑里的代码文件，手机上直接翻、直接改、保存落盘

出门只带手机，你依然是全场最能干的人。

## ④ 一个 AI 是员工，一群 AI 是部门

月落的群聊多智能体：把不同角色拉进一个群，@谁谁干活，群主自动分派、成员并行执行、干完汇报总结。中途踢人、加人，像操作微信群一样自然。

每个角色都是独立的「人」：独立的模型（编码角色可以自己自定义自己员工、陪聊角色用别的）、独立的音色、独立的工作区、甚至自带想要工具的安装清单——压缩包拖进去，它自己把环境搭好。

别人在卖一个聊天框，你在养一个部门。

▲ 群聊：像拉微信群一样，拉一个 AI 团队

## ⑤ 10 秒，给它一个「它自己的声音」

上传 10 秒授权音频，克隆出专属音色。从此它用这个声音在微信里回你语音条、在语音通话里跟你说话，需要被克隆本人授权使用哈。

语音通话模式：按住说话 → 自动识别 → 它思考 → 用角色的声音回答 → 自动听下一句。像打电话一样自然，开车、做饭、躺床上都能指挥它干活。

## ⑥ 隐私堡垒：数据 0 上传，扫描器看不见

云端 Agent 把你的数据当燃料，月落把它当家产。

对话、知识库、声音样本、凭证，全部只存在你的电脑

公网隐身模式：未授权访问只看到 404——连这台服务器上住着一个月落这件事，都不泄露

登录爆破自动锁定、新设备需本机审批、令牌可随时重置

不依赖任何第三方 Agent 框架，模型接口自己配，Key 只存本机

它是你的员工，不是别人的眼线。

## ⑦ 喂文档变学问，定日程变自动

知识库：txt / Markdown / Word / 代码文件拖进去，自动切块向量化。之后正常聊天即可——它会在回答时自动检索引用最相关的段落，并注明来源。全部存本机，不出你的电脑。

再配上定时任务与「早安晨报」一键模板：每天早上自动查天气、报日期、结合你的待办给三条建议，推送到你手机。跑完主动汇报，从此不用你开电脑盯。

## ⑧ 一个 zip，解压即活

内置 Node.js 24 运行时、FreeRDP 引擎、全部依赖——不装环境、不配全局变量。Windows 解压双击，Linux 一行命令。并且 Windows / Linux 同版本同步发布，升级自动备份、数据无损迁移。

部署成本约等于零，因为你不需要「部署」，你只需要「解压」。

# 远程掌控，是认真的

RDP 远程桌面：FreeRDP 引擎直连，目标机不用装任何软件。手机上双指缩放、单指点按、长按右键，还有全键位虚拟键盘。

![](https://mmbiz.qpic.cn/mmbiz_png/xmichmO2XN7OZucdPODSaGnnERR2p6icEgwf3olYDUOkevc3MDWEF3G35Cg61djklv3JT9ndEdESSSzqVt4AfLBtjx25H3BAgtjUro83pL6UE/640?wx_fmt=png)

▲ RDP 远程桌面：手机直接操控远端 Windows

SSH 真终端：xterm.js + PTY 模式，vim、htop、top 全部可用，是完整交互终端。配套的网页文件编辑器，让你在手机上直接改电脑里的代码文件。

▲ SSH 终端 + 文件管理

# 第一代，我们把「稳」放在「炫」前面

三套体检全绿才出门：67 项静态检查、12 项动态测试、15 项新功能运行时实测，一条不过就不发布。

数据库级加固：并发访问排队而非报错、WAL 调优、启动一致性自检，长期开着不出幺蛾子。

内存封顶：快照只留当前回合，会话删除连带清理所有定时器与缓存，杜绝越跑越卡。

全局兜底：未捕获异常留痕不崩、僵死回合 10 分钟看门狗强制回收。

双端同步：同版本发布，升级自动备份，数据无损迁移。

# 写在最后

2026 年被叫作 Agent 元年，市面上的产品百花齐放——但绝大多数活在云端，活在别人的服务器里，月费交着，数据传着。

月落的第一代，走的是另一条路：把 AI 员工派驻到你自己的电脑里。它知道你的文件在哪、你的服务器怎么连、你的日程是什么——而这些数据，永远只属于你。

第一代只是一个开始。路还长，我们已经在走了。

月落 Agent 第一代，今天正式发布。
