引言：攻守已经换人，为什么今天必须重新学习“防”

设想这样一个场景：某天下午，你收到一封来自“财务总监”的邮件，措辞、语气和公司内部行文风格分毫不差，还附带一段声音完全还原的语音留言，要求你在下班前完成一笔转账。邮件是AI生成的，声音是AI克隆的，收款账号是攻击者精心伪造的——这不是电影中的情节，而是2025年以来真实发生、且愈发频繁的日常网络攻击。

从2025年开始，人工智能已经从“被讨论的技术对象”转变为“攻击者手中的实用武器”。AI大幅拉低了网络攻击的门槛，攻击的规模、精准度与自动化程度都实现了全面提升。新华社及多家网络安全厂商的报告一致指出，AI推动网络攻击从“广撒网”式诈骗进化为“精准制导”型攻击，运作模式也从“人在回路”转向“高度自主”，传统以特征库、规则和人工识别为核心的防御体系正在失效——这就是“攻守已换人”的真正含义。

本篇培训材料面向公司全体员工，覆盖技术岗与非技术岗，目标是帮助大家达成三方面学习目标：第一，理解AI时代网络威胁发生了哪些变化；第二，识别最常见的AI攻击手法；第三，掌握企业“人员—技术—制度”三层防御体系与个人应对行动清单。请记住：在AI攻防的新格局下，每一位员工都是企业安全防线不可或缺的一部分。

# 1  威胁全景：AI 是如何“变成黑客”的

## 1.1  AI 助力的钓鱼与社会工程

大语言模型（LLM）大幅压缩了钓鱼素材的生产成本，使其几乎趋近于零。攻击者可以借助它自动生成高度仿真的钓鱼邮件、短信与社交私信，还能动态嵌入目标企业的真实部门名称、官方公告关键词、行业术语，甚至匹配内部行文风格，攻击内容的欺骗性得到显著提升（安全内参《2025年网络钓鱼攻击态势》）。过去那些“一眼看穿”的低级钓鱼邮件，如今已经被高质量、个性化的仿真内容全面取代。

第三方研究统计显示，2025年共观测到约380万次钓鱼攻击，其中82.6%的钓鱼邮件带有AI生成特征；由深度伪造技术驱动的语音钓鱼（vishing）同比增长约1600%（vSpam《2025—2026 网络钓鱼研究报告》）。这些数据充分表明：AI钓鱼已经成为当前网络攻击最主要的入口威胁。

## 1.2  深度伪造与拟声诈骗

AI换脸、拟声技术同时打破了“眼见为实”“耳听为真”这两条人们长期信奉的朴素判断经验。公安部数据显示，仅2025年第一季度，全国AI换脸、拟声诈骗案件数量环比就激增45%，其中老年群体受骗占比达38%）；2025年全国公安机关共侦破电信网络诈骗案件25.8万起。

国际上也频繁出现此类案件：曾有攻击者克隆某科技公司CEO的声音，授权完成欺诈交易，最终造成约24.3万美元的损失。最高人民法院也指出，恶意滥用AI换脸、拟声技术让电信诈骗手法更隐蔽、更具迷惑性；2025年人民法院共审结电信网络诈骗犯罪案件4.1万件，涉及8.5万人。

## 1.3  自动化漏洞挖掘与恶意代码生成

AI不仅能够辅助生成文案，还可以帮助编写漏洞利用代码与恶意脚本，甚至能被直接整合到恶意软件的完整链条中，实现“即时（just-in-time）”代码生成，打造出更难被检测、更难追踪来源的“自适应恶意软件”（Google Cloud / Mandiant《AI risk and resilience in 2025》）。攻击者可以在攻击过程中动态编写代码，这也使得传统基于特征签名的检测手段快速失效。

## 1.4  智能体化（Agentic）攻击：AI 自主进攻

网络安全监测发现，已有攻击利用AI智能体完成工具方案规划、漏洞探寻与流量监测，其中部分代码明显由AI生成，能够在攻击过程中自动、快速编写动态代码发起攻击（新华网《“AI+”时代网络安全挑战升级》）。实现智能体化的AI具备自主决策能力，其行为的自主性与随机性大幅提升了安全防护的难度——攻击者甚至无需全程“值守”，仅需由智能体自行寻找并攻击利用目标。

## 1.5  提示注入攻击

大语言模型会在同一上下文窗口中同时处理指令与数据，天然难以区分“系统指令”和“伪装成指令的文本”，这正是提示注入风险的根源，也就是OWASP大模型应用十大风险中常年位列第一的LLM01。

提示注入可以分为两类：直接提示注入是指用户输入试图覆盖模型预设指令；间接提示注入则是攻击者将指令隐藏在网页、邮件、文档等第三方内容中，诱使模型读取内容时泄露机密数据或执行恶意操作。谷歌DeepMind、Anthropic、OpenAI、微软等机构均已开展此类攻击的防范研究，对部署大模型应用、接入相关数据的组织来说，这是必须正视的安全风险。

## 1.6  针对 AI 基础设施的攻击与数据投毒

攻击者的目标不只有“人”，还包括AI自身的基础设施。安全公司披露，有攻击者利用某开源计算框架的漏洞，劫持了大量暴露在公网上的AI计算实例（云资源）用于挖矿，就连英伟达A100数据中心级显卡也被该攻击利用（36氪/Oligo）。除此之外，攻击者还会通过向训练数据、向量数据库或第三方组件植入恶意样本，实施“数据投毒”与供应链污染，这类攻击会污染模型的输出结果，进而引发系统性安全风险。

表1 AI 主要攻击手段、典型场景与关键特征

|  |  |  |  |
| --- | --- | --- | --- |
| 攻击手段 | 典型场景 | 关键特征 | 主要风险对象 |
| AI 钓鱼 | 邮件、短信、社交私信诱导点击或转账 | 高仿真、个性化、难以一眼识别 | 全体员工 |
| 深度伪造/拟声 | 视频会议、电话冒充领导或客服 | 克隆人像与声音，“眼见为实”失效 | 财务、高管、客服 |
| AI 恶意代码 | 渗透、勒索、供应链攻击 | 动态生成、自适应、难归因 | 系统与数据 |
| 智能体化攻击 | 自主探测并利用漏洞 | 无人值守、随机性高 | 应用与基础设施 |
| 提示注入 | 大模型应用、企业AI 助手 | 指令与数据同通道处理 | AI 系统与接入数据 |
| 算力劫持/数据投毒 | AI 平台、训练供应链 | 资源被窃、模型被污染 | AI 基础设施 |

# 2  攻守为何已换人：传统防御失效的深层原因

## 2.1  攻击成本骤降，规模与速度跃升

过去，制作一封高质量的钓鱼邮件需要攻击者具备扎实的语言功底，还要投入大量时间；如今，大语言模型可以在数秒内生成多语种、多版本的仿真钓鱼内容，攻击模式也从传统“手工作坊”转向“规模化生产”，同等资源能够覆盖更大的目标群体、覆盖更多攻击渠道。

## 2.2  从“广撒网”到“精准制导”

依托AI技术，结合公开可得的组织架构、人员名单、项目动态等信息，攻击者可以快速构造出跨语言、跨文化、跨行业的精准诱饵（引自《2025全球高级持续性威胁研究报告》）。攻击不再依靠广撒网碰运气，而是可以针对目标“量身定制”，社会工程学调研和诱饵构造的效率都得到了显著提升。

## 2.3  检测与归因更难

传统防御依赖特征库与固定规则，而AI生成的文本、动态代码、自适应恶意软件会直接导致签名防御机制失效。攻击链条的每个环节都可以借助AI完成，这也让攻击更难被识别，也更难追溯到攻击源头。

## 2.4  人的因素仍是最大缺口

无论技术如何发展演进，社会工程攻击最终针对的都是人的判断力与情绪，包括紧迫感、信任感、对权威的服从心理。技术防线再坚固，只要员工出现一次误点击、一次错误的转账审批，防线就可能被攻破。这就是为什么企业需要开展全员安全培训，不能仅依赖安全部门防御的核心原因。

表2 传统威胁与 AI 化威胁的关键差异

|  |  |  |
| --- | --- | --- |
| 维度 | 传统攻击 | AI 化攻击 |
| 内容制作成本 | 高，主要靠人工 | 极低，LLM 秒级生成多语言版本 |
| 攻击规模 | 受人力与语言限制 | 大规模、多语言、多渠道 |
| 精准度 | 粗放式群发 | 个性化“量身定制” |
| 自动化 | 多为固定脚本 | 智能体自主决策、动态写码 |
| 检测难度 | 特征库可覆盖 | 签名失效、难识别难归因 |
| 人防难度 | 内容有破绽可识别 | “眼见为实”失效，更难辨别 |

# 3  如何布防接招：企业三层防御体系

## 3.1  人员防线：意识、验证与行为习惯

核心原则是“身份与指令的双重验证”。凡是涉及转账、修改密码、权限变更、信息外发等高风险操作，必须通过“第二通道”独立核实，可选择电话回拨、当面确认或是走既定内部流程，不能仅依赖邮件、视频里的声音与画面。由于深度伪造可以同时伪造形象与声音，“看起来是真的”这一判断本身已经不再可靠。

同时要培养风险识别直觉：即便对方的语气、口吻、视频形象都无可挑剔，也不排除是深度伪造的可能；异常紧迫、要求保密、要求绕过既定流程，这些都是典型的危险信号。面对不明链接、不明附件，以及要求输入账号密码的未知页面，要坚持做到一律不点击、不下载、不输入。

## 3.2  技术防线：AI 安全工具与检测

技术层面需要建设并持续更新适配AI时代的防御能力：由邮件安全网关识别AI钓鱼特征，拦截伪造图文与恶意链接；通过深度伪造检测技术对人像与声音做真实性和一致性校验；依托终端与端点检测（EDR/XDR）及异常行为分析，监控异常登录、异常转账与异常权限变更；将多因素认证（MFA）作为访问控制的关键闸门，宁可流程繁琐，也不能省略该环节。

## 3.3  制度与流程：AI 使用规范与管控

制定并宣贯公司AI使用政策，明确划定可输入AI工具的数据范围，同时界定严禁外传的敏感数据类型，包括客户隐私、财务数据、源代码、内部资料。落实权限最小化要求与分级审批制度：高价值操作必须执行分级审批，禁止由单人完成“授权—执行”的完整流程。同时要将供应链与供应商纳入统一管理，明确约束第三方及AI供应商的数据处理与安全义务，避免敏感数据经第三方AI服务发生泄露。

## 3.4  面向大模型应用自身的安全（对齐 OWASP Top 10 for LLM）

对于企业自行搭建或采购的大模型应用，应参照OWASP大模型应用十大风险（2025版）开展安全加固：提示注入（LLM01）仍是头号风险，2025年新增的系统提示词泄露，以及和向量、嵌入相关的风险同样需要重点关注。

具体落地建议包括：对输入输出内容进行过滤与分类；实现系统指令与用户数据隔离，缩小提示注入的影响范围；遵循最小权限原则设计可调用工具的智能体；针对AI应用开展对抗性测试（红队演练）；落实敏感数据最小化入库，经脱敏处理后再用于AI训练。

表3 企业分层防御体系与落地抓手

|  |  |  |
| --- | --- | --- |
| 防御层级 | 核心抓手 | 落地建议 |
| 人员防线 | 双通道验证、风险识别、钓鱼演练 | 定期开展模拟演练，将“验证”写入业务流程 |
| 技术防线 | 邮件安全、深伪检测、EDR/XDR、MFA | 上线并持续更新检测规则与威胁特征 |
| 制度防线 | AI 使用政策、分级审批、供应链约束 | 明文制度、责任到岗、纳入考核 |

# 4  员工行动清单：每个人都是防线

## 4.1  接到可疑邮件、电话或视频时，如何核实

1. 停下来：不被紧迫氛围与权威施压裹挟，先冷静判断，再采取行动。
2. 查细节：核对发件地址、链接域名、附件来源，确认上下文是否合乎常理，警惕“紧急转账”“保密处理”这类诱导话术。
3. 不执行：涉及转账、改密、信息外发、安装软件等操作，一律先走审批流程再执行，并通过第二沟通渠道独立核实对方身份。

## 4.2  使用 AI 工具的合规要点

1. 仅可使用公司批准的AI工具，不得将敏感数据输入未经认可的AI服务或账号。
2. 需对AI生成内容保持警惕：AI可能遭受提示注入攻击，也可能产生幻觉输出，不能将其结论直接用于转账、合规审核、合同签约等高风险决策。

## 4.3  发现异常时如何报告与处置

1. 请立即向公司信息安全部门或IT部门上报，留存原始邮件、相关记录与截图作为证据，不得删除、转发或扩散相关内容。
2. 若数据已疑似泄露，或是已经完成转账操作，请第一时间上报，并严格按照公司应急预案处置，切勿自行补救或拖延上报。

表4 员工日常行动检查清单

|  |  |  |
| --- | --- | --- |
| 场景 | 必做动作 | 红线 |
| 收到转账/改密指令 | 第二通道核实并走审批 | 不凭邮件或视频声音直接执行 |
| 收到可疑链接/附件 | 核对域名来源、不点击 | 不下载不明附件、不输入密码 |
| 使用AI 工具 | 只用公司批准工具、不输敏感数据 | 敏感数据严禁输入AI |
| 视频/电话疑似深伪 | 换通道回拨、核对特征 | 不因“眼见为实”放松警惕 |
| 发现异常 | 立即上报并保留证据 | 不删除、不扩散 |

结语：攻守已换人，防守有章法

攻防态势已然改变，但防守并非无章可循。AI既是威胁的放大器，也是有力的防御工具——关键在于“用AI防AI、用制度约束人、用习惯守住底线”。

每位员工都是企业安全防线的组成部分：一次身份核实、一次不点击的选择、一次及时的上报，都有可能成功阻挡一次真实攻击。请把这份材料中的防范清单落实到日常工作中，并持续关注公司发布的安全培训、钓鱼演练与应急通知，让安全成为工作习惯，而非额外负担。
