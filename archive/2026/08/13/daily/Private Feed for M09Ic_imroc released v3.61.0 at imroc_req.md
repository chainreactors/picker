## New Features

* **Add `Client.SetResolver` and `Client.SetHosts` for custom DNS on HTTP/1 and HTTP/2** — custom `net.Resolver` or static hosts-file-style hostname→IP mapping, with fail-closed behavior for unknown hosts. Closes [#169](https://github.com/imroc/req/issues/169). PR [#516](https://github.com/imroc/req/pull/516) by [@ManuelReschke](https://github.com/ManuelReschke).
* **Expose `RetryOption` for middleware read access** — adds `Request.GetRetryOption()` so middleware can read the live retry config (`MaxRetries`, interval, conditions, hooks). Closes [#475](https://github.com/imroc/req/issues/475). PR [#515](https://github.com/imroc/req/pull/515) by [@ManuelReschke](https://github.com/ManuelReschke).
