## Chrome 将正式发布 ARM64 Linux 版本

[![Linux](https://icon.solidot.org/images/topics/topiclinux.png?123)](/search?tid=7 "Linux")
[![Chrome](https://icon.solidot.org/images/topics/topicchrome.png?123)](/search?tid=154 "Chrome")

[Edwards](/~Edwards) (42866)发表于 2026年03月13日 17时50分 星期五 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83761&appkey=1370085986&title=Chrome%20%E5%B0%86%E6%AD%A3%E5%BC%8F%E5%8F%91%E5%B8%83%20ARM64%20Linux%20%E7%89%88%E6%9C%AC "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自天堂的喷泉**

Google Chromium 官方博客宣布将于 2026 年二季度正式发布 Chrome 的 ARM64 Linux 版本。该版本将包含其它平台版本相同的功能，包括 Google 账号同步、Chrome Web Store 扩展、内置翻译、Safe Browsing 保护，以及 Google Password Manager 等。ARM64 Linux 系统已经广泛使用多年，但作为最流行的浏览器，Chrome 一直没有发布官方支持版本。
https://blog.chromium.org/2026/03/bringing-chrome-to-arm64-linux-devices.html
