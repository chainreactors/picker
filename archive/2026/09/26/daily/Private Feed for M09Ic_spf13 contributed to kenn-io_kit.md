## Problem

`filepath.EvalSymlinks` cannot canonicalize a path below a Windows directory junction. A junction is a reparse point tagged `IO_REPARSE_TAG_MOUNT_POINT`, and Go 1.23 ([go#63703](https://github.com/golang/go/issues/63703)) made `os.Lstat` report it as `ModeIrregular` — neither a symlink (`IO_REPARSE_TAG_SYMLINK`) nor a directory — while `os.Readlink` still reads its target. `filepath.walkSymlinks` decides traversability from `Lstat`'s mode, so it rejects any element below a junction with a bare `syscall.ENOTDIR`, and leaves a trailing junction unresolved:

| path | `filepath.EvalSymlinks` today |
| --- | --- |
| `…\link` | `…\link`, unchanged |
| `…\link\sub` | error: "The system cannot find the path specified" |
