[Holehe](https://github.com/megadose/holehe) is a free, open-source command-line tool that takes one email address and reports which of 121 websites have an account registered to it, including Google, Instagram, Discord, GitHub and Amazon. Install it with `pip install holehe` and run `holehe` followed by the address. In the EU and UK the result is personal data, so keep it to your own addresses or an authorised investigation.

### In brief

* The pip package is version 1.61, which PyPI dates to 21 July 2022. The code on GitHub carries the same version number and has changed since.
* Of the 121 modules in that release, 101 ask a site’s sign-up form whether the address is taken, 13 use the login form and four use password recovery.
* A red `[x]` in the pip build means the module got no answer. A rate limit and a module error print the same line.
* Seven of the sites Holehe checks are in the Ransomnews stealer-log panel, and the index behind it holds 42.7 million stolen logins for them.
* EU and UK law treat the list of accounts registered to a person’s address as personal data, so a lookup on someone else needs a lawful basis.

## What is Holehe and who maintains it?

Holehe is an open-source email OSINT tool, written in Python, that checks whether an email address has an account on a fixed list of websites, and a developer who publishes as megadose maintains it on GitHub. The README puts the coverage at Twitter, Instagram, Imgur and more than 120 other sites, and its module table has 121 rows. The licence is GPL-3.0, and the README adds that the tool was built for educational purposes only.

On 23 November 2026 the repository page showed about 14,600 stars, 434 commits, around 70 open issues and nearly 50 open pull requests. [PyPI](https://pypi.org/project/holehe/) lists megadose as the package’s only maintainer. The README links a transform for [Maltego link analysis](https://ransomnews.com/maltego-osint-link-analysis-tutorial-2026/) and points to the commercial service OSINT Industries as Holehe’s online version.
