## Summary

* Add `-genconfig` to generate multi-path server config plus client configs for all proxy modes (forward / reverse / socks5 / reverse socks5)
* Raise proxy chunk/probe/buffer defaults (64KB chunk, larger MainBuffer/ConnBuffer) to match gohome 1200-class MTU
* Bump `gohome` for ricmp/rudp race fixes, quic PacketConn close, drop smux, and kcp nodelay/MTU tuning
