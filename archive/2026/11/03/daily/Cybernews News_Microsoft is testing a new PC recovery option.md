Key takeaways

1. 01

   Microsoft is testing Cloud rebuild, a Windows 11 feature that reinstalls the system from the cloud.
2. 02

   The tool can work even when a PC cannot start and does not need USB media.
3. 03

   Cloud rebuild can erase files or securely wipe a drive before reinstalling Windows.
4. 04

   The feature is rolling out gradually with Windows 11 versions 25H2 and 26H2.

---

Key Takeaways by [nexos.ai](https://nexos.ai), reviewed by Cybernews staff.

**Microsoft has introduced a new Windows 11 recovery feature, Cloud rebuild, which allows users to reinstall the operating system from the cloud, even when the device can’t start.**

The new feature doesn’t require USB media or a custom image.

Cloud rebuild is like an advanced Reset this PC feature that also downloads the target Windows image and the PC’s drivers via Windows Update.
