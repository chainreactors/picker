一、史上最大规模扩招，实习通道全开

6月25日晚间，DeepSeek官方发布成立以来最大招聘计划，覆盖算法、研发、运维、产品等7大类，合计33个岗位，北京、杭州同步招人，所有岗位均可投递实习。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/TVljsu2eAicIr0IPHEA9yu3KV96XwzMRHAYaQyfotnNg1J49Kf8b58ty4OicvaaDeKMHJmKlEfV7VfjfTCNvGicg4BmicGZf3Er1NFBNibw84qzY/640?wx_fmt=jpeg)

官方明确目标：全部门规模至少扩容一倍，区别于以往零散挖核心研究员，本次属于系统性整体扩张。公司给出极具吸引力的用人机制，新人入职即可承接核心项目，不用从边角模块做起。

投递渠道：简历发送talent@deepseek.com，邮件标题标注姓名-岗位-联系方式。

招聘海报如下

![](https://mmbiz.qpic.cn/mmbiz_jpg/TVljsu2eAicIiaiblLLSnyXkEBM3iafPGYSBRcecIia21h1SDia2ez4c2p8uFzaeBZqicURSSj62ameFXjicVnaCb888ndZEeqibys3CZ3mfVUEcJpcg/640?wx_fmt=jpeg)

二、王牌赛道：Agent Harness团队对标Claude Code

本次招聘最受关注的是今年3月新组建的Agent Harness部门，负责人崔添翼为90后技术骨干，坦言每日密集面试、人才缺口巨大。

团队核心逻辑为「Model+Harness=Agent」，Harness相当于AI智能体操作系统，负责任务拆解、上下文隔离、多工具调度。团队目标清晰，对标Claude Code打造国产代码智能体DeepSeek Code Harness，补齐AI生产力工具短板。

三、三线同步加码：多模态、基座模型、算力基建并行

1. 多模态补齐短板
招聘多模态研究员，主攻视觉编码器、图文视频理解，覆盖办公、多模态搜索等Agent场景，弥补此前多模态产品薄弱的现状。
2. 深耕基座大模型
开放预训练、持续学习、后训练等研究员岗，技术导向鲜明，拒绝单纯刷榜换取虚假指标。
3. 布局东数西算算力
算力基建岗落地北京、杭州、乌兰察布。依托当地低廉电价与低温优势搭建自有IDC，大规模储备算力资源。

四、特殊岗位：不限专业，寻找跨界天才

本次新增「AI跨界技术人才」特殊岗位，不限专业，面向拥有顶尖特长、创业经历、不走常规路线的候选人，为AGI研发吸纳多元化人才。

从单一基座模型，到Agent、多模态、算力四线并进，这次扩招，清晰亮出DeepSeek下一阶段完整布局。
