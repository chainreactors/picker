## 工作职责

1. 参与公司内部安全运营体系的建设、维护和优化，持续完善安全制度、流程与 SOP。
2. 负责发现异常并处置，安全事件响应、溯源分析与复盘总结，形成安全事件报告，并持续优化应急预案与演练方案。
3. 负责 HIDS/NIDS 设备平台维护和保障，持续提升运营效率和安全防护的覆盖率。
4. 进行 Linux 安全或流量安全的攻防研究，编写规则检测和落地防护方案。
5. 基于公司的大模型和安全能力，探索 AI 在安全运营场景的落地，不断提升运营效率。

## 岗位要求

**通用要求：**

1. 全日制本科及以上学历，计算机、软件工程、信息安全、网络空间安全等相关专业毕业。
2. 熟悉 OWASP TOP 10 漏洞的基本原理、利用方式、以及检测和防御。
3. 具备一定的编程经验，熟练使用 Python/Go/Java 其中一种或几种编程语言。
4. 具备一定的 AI 能力，熟练掌握 Workflow 类（如 n8n、Dfiy 等）或 Agent 类（如 OpenClaw、Claude Code 等）AI 工具 ，并有一定的使用经验。
5. 表达逻辑清晰，具备良好的沟通能力和跨部门协同能力。

**主机方向：**

1. 熟悉 Linux 操作系统原理及安全机制，具备系统加固与入侵排查经验。
2. 熟悉 Linux 常见的攻击手法，如提权、持久化后门、防御绕过等等。
3. 熟悉主流商业或 HIDS 产品基本原理，能将攻击手法转化为检测规则。

**流量方向：**

1. 熟练使用主流安全产品，熟悉两款主流厂商的 NDR、IDS/IPS 或全流量分析系统，能够独立完成告警研判与策略调优。
2. 熟悉主流攻击原理，深入理解常见攻击手法（如 WEB 攻击、漏洞利用、横向移动、DDoS 等）在流量侧的告警特征，具备规则编写能力。
3. 具备脚本编写能力，能够编写自动化分析脚本辅助流量数据解析。

## 加分项

1. 具备国家级／省级攻防演练经验或实战红蓝对抗经验。
2. 有 AI+安全运营的落地项目经验。
3. 有 Github 安全相关的开源项目（500 星以上）。
4. 有 linux 或通用 Web 组件漏洞的挖掘经验。
5. 持有 CISP 系列及更高级别安全优先。
6. 具备较好的输出能力，发表过有技术深度的文章，或有自己的技术博客、公众号等。

## 公司介绍

奇安信[1]成立于 2014 年，专注于网络空间安全市场，为政府、企业用户提供企业级网络安全产品和服务。2019 年中国电子战略入股，成为网络安全“国家队”；2022 年圆满完成北京冬奥会网络安全保障，创造“零事故”纪录。公司 2020 年在科创板上市，持续加大研发投入，形成八大研发平台矩阵。在终端安全、云安全等领域技术领先，连续四年在中国网安产业竞争力五十强榜单中排名第一。近年来，奇安信发力数据安全与 AI+安全，推出 QAX-GPT 安全机器人等产品，提出“AI 驱动安全”等理念，致力于成为全球领先的网络安全公司。

**奇安信网络安全部**是一个充满活力和对安全技术充满好奇心的团队，在奇安信内部被称为御林军。主要承担集团的网络安全与数据安全体系建设和治理, 防范黑客入侵，保证公司产品的安全质量, 并对产品安全漏洞进行响应和闭环, 负责集团基础网络的建设与维护，承担产品在集团现网环境实验局的使用与运营, 为产品的功能改进给出建议,并输出最佳实践。
