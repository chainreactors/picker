在 Windows 上，有一个反直觉的设计我忍了很久，估计大家也深有体会。

那就是文件大小的显示方式。

macOS 那边一直都是单位自适应的，小文件就用字节 / KB / MB，大文件就是 GB / TB……区分得清清楚楚，看一眼就知道文件有多大。

![Mac 大小.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYApchXFThYMQNVFm9o012aLIY0GaURuzzGpqz5zXdLoRX5hyIeUM68djN7xGC6XC2Ia5qSQvw5JU8uEQZ54M8aR9JPhVRTTyTVY/640?wx_fmt=png&from=appmsg)

但在 Windows 文件资源管理器，哪怕你存的是个几百 GB 的 4K 电影，详细信息视图下非得给你显示成一串长到数不清的 xxxxx KB。

![Win 大小.png](https://mmbiz.qpic.cn/sz_mmbiz_png/ib4HLZ26hYAp0zhmDVOcYHgicUadicVkxyeWJ8ZIomUNGTvRIXfVEiaia4p0v9D1XIllBvXc0gaSg125596bfMAggSmP4ye4I8eewSyfcNyGia49s/640?wx_fmt=png&from=appmsg)

每次想确认文件大小，心里都得默默做一遍除法！

不过最近有个好消息：微软终于打算把这个「老顽固」设定改掉了。

在最新的测试版里，Windows 11 迎来了两项非常接地气的「史诗级」更新！

虽说有点「致敬」macOS 的意思，但对我们用户来说，好用就是硬道理。

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0u4CHiaMhAdl8MT33E9ByxnhpYuMGja3h82BzeYpzJQ90iaTxpsibR2Qlg/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1)自适应显示：KB / MB / GB…

以前打开文件夹，看到那一长串数字，总得数半天有几位数。现在 Windows 终于学会了：文件大小的单位自适应。

1 GB 的文件就老老实实显示 1 GB，而不是类似 1,048,576 KB 的效果。

![CleanShot 2026-05-12 at 17.54.27.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYArOte7lg456CCgFCCtgfeGEiaiaUcFUSIHo84VYWpC6Vib3vOP6g4k9KB2Dt7ckA6wP5O7cyI11WMqjpoA9taaTMHJFCl2J6Z3MV0/640?wx_fmt=png&from=appmsg)

这项文件资源管理器的改进，真的很棒！希望能早日实装。

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0xU9Fvm3ILCw745js1LmpsibFNyvia4QsicUbKwqeibUyrYvx0N4CN2trBw/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 「刷新」按钮的强势回归

除了文件大小显示，另一项老用户期待已久的改动在右键菜单上。

在 Windows 11 的文件资源管理器内，右键菜单为了保持简洁，把大家用习惯的「刷新」给藏到了二级菜单里。

导致大家要么去找 F5 键，要么多点一次鼠标，非常别扭。

▲ 文件夹右键的「刷新」在二级菜单

微软这次总算听到了吐槽，在最新预览版本里，把「刷新」放回到文件资源管理器的右键菜单中。

![image (6).png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYArZBXKed8ibsmTckPdDmMKqMy9XbAtvwialTunusOtCOpqHPjxN7dLUHFKvFQnehopCkBKgbpl3mwZQxkopCc7qsCKFBPGsxDSE4/640?wx_fmt=png&from=appmsg)

大家应该还记得，早期的 Windows 11 里面，在任务栏呼出右键菜单，是没有「任务管理器」的，也是被大家吐槽一波后才给「补上」的。

![CleanShot 2026-05-12 at 18.00.01@2x.png](https://mmbiz.qpic.cn/sz_mmbiz_png/ib4HLZ26hYAq1trCY89cF8libtaEXlP67J4sFPN9TKJic4tgYZQicw9mPelyJib6J7uyy9te7FyEbkGqb5giakKwojkicia3gFX9WXurJICl9Qty7LM/640?wx_fmt=png&from=appmsg)

这种「把砍掉的功能找回来」的操作虽然槽点满满，但这种知错就改的态度，还是值得给个好评。

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0WZZD2XSfTRL4qMsKuHfseqVcjBRM0E29GIiatsL7vdPItywyXqHibNEQ/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 如果现在就想用上

「文件大小单位自适应」功能目前仅在 Windows 11 的测试 / 预览版本里面提供。

如果你也是急性子，不想等几个月后的正式推送，其实也有办法。

下载 > 安装 > 运行 Windhawk，然后在插件中心搜索 > 安装 > 启用「Better file sizes in Explorer details」。

Windhawk 官网：https://windhawk.net/
