0x01今日新增蜜罐市场蜜罐模版

---

（1）Whisper Money

隐私优先的个人理财应用，可自托管。支持多账户、交易分类、自动化规则与消费洞察；通过 CSV/XLS 导入银行流水，强调数据归属用户、不向第三方共享。技术栈为 Laravel + React（Inertia）。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokAK8clvcG1NERqXI8IMqLJOTZ6CHPwDEHLCSPiak0flfE18FdkGgPdIa1XPVAuCOSAyJLuuNRHXwwBSm7k1Kg9e2n6m0aEiaCqoM/640?wx_fmt=png&from=appmsg)

（2）EGroupware德国出品的开源协作套件（Groupware），定位为可自托管的在线办公平台。提供日历、通讯录/CRM、邮件、任务、项目管理、文件管理等模块，并可集成 Collabora、Rocket.Chat、BigBlueButton 等，有社区版与企业版。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokBpPlNaYzksmtDDTCeV4viabptNuiaI0waSyxrwIiclUhYSwXr0FobeFq7N3Wu7j0SzFTcpeFqJOzXU2UmRMYUNRLKRJfDS0fs8Co/640?wx_fmt=png&from=appmsg)

（3）OpenList

AList 的社区驱动分支，多网盘文件列表程序。基于 Gin + SolidJS，聚合阿里云盘、百度网盘、OneDrive、S3、SMB 等存储，提供 Web 浏览、预览与 WebDAV，便于统一管理与分享网盘文件。![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokAYxeH0OV30DOPmCs2Beq4DO0ZstIF3D2Fakppbqluniat1wFJFwvoVaqX2TxYib1Lp9KDhiciaglQ3Qwfz6EYKExJzCys74ESYx5w/640?wx_fmt=png&from=appmsg)

（4）Shiori用 Go 编写的轻量书签管理器，定位为 Pocket 式自托管替代。单二进制部署，支持 CLI 与 Web UI，可解析并离线归档网页可读内容，支持 SQLite/PostgreSQL/MySQL，以及 Netscape/Pocket 导入导出。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokBIgoiaJZfibxs7ib9tx2HWjNkf7m0Zn8pzSwfXdGuRvqHsW7opJKhJywqs5DaQnl0GnsbMibY7eYweOT6KVsBxEibF3YcbiatPjEyUg/640?wx_fmt=png&from=appmsg)

（5）Nu Html Checker (vnu)

WHATWG/W3C 生态中的 HTML/CSS/SVG 校验器。可作命令行批量检查，也可部署为类似 validator.w3.org/nu 的 HTTP 服务并提供 REST API，用于发现标记错误而非做合规认证。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokBiaD9p8h4E1AfRx5BuRhRYhcibh6EOaE0e9j28V0fah8XPia5SPicAkldc0T8zsprX9IGOibXWhuWy6jdxSWHPIXm4QvkrIK8rqTbQ/640?wx_fmt=png&from=appmsg)

（6）Databasir

面向团队的开源关系型数据库模型文档平台。通过 JDBC 自动同步库表结构，支持 MySQL、PostgreSQL、Oracle 等，提供文档版本对比、权限协作与 Markdown 等导出，降低手工维护文档成本。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokBcEg0KNT6GwuhcK8pHia1UqfNXVVFDHMXacfhQeibgeTS1J0F8r2HtUcxxhAKRvb82yQmO33TYgv1icBaIKG7FS9MNe5LyEnfUMs/640?wx_fmt=png&from=appmsg)

（7）Echo

高性能、极简的 Go Web 框架（labstack/echo）。基于标准库 net/http，提供基数树路由、中间件、请求绑定/校验、集中错误处理，以及 Let’s Encrypt TLS 与 HTTP/2，适合快速构建 RESTful API。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokAjVH9ibJd37OaQvStuWgT6ZfL5c4GB6OIoFl13xc80AJ64lTiaep5nNNsO2Gg8p6m5bJrlJpm3J8kV2WFxkRdibINd0853DkAicjY/640?wx_fmt=png&from=appmsg)
