##

**Part01**

## ****配置错误曝光新模型****

Anthropic PBC 内容管理系统的一处配置错误意外泄露了其正在测试的新型大语言模型 Claude Mythos。该公司周四向《财富》杂志证实，工程师已完成该模型的训练工作，目前正与早期客户进行试点测试。Anthropic 强调这是其"迄今为止构建的能力最强的模型"。

此次泄露源于公司意外将包含 3000 项资产的 CMS 文件夹设为公开可访问状态，其中包含 Claude Mythos 的发布博客草稿。文件显示，该模型定价将高于公司现有算法。

**Part02**

## ****产品架构重大调整****

根据泄露文件，Anthropic 计划改变其大语言模型的发布策略。当前旗舰产品 Claude 4.6 提供三个功能与价格各异的版本，而 Claude Mythos 的推出将新增第四个产品层级。

据悉，这款代号为 Capybara 的新型号在编程任务和推理用例上"显著"优于当前顶级产品 Claude 4.6 Opus，定价也更为昂贵。特别值得注意的是，Capybara 在网络安全漏洞检测方面表现卓越。

**Part03**

## ****网络安全领域冲击****

泄露的博客草稿警告："该模型预示着新一代能以前所未有的方式利用漏洞的模型浪潮即将到来。我们通过早期访问计划向组织开放，使其能提前强化代码库，应对即将到来的 AI 驱动攻击浪潮。"

此消息导致 CrowdStrike Holdings Inc. 和 Palo Alto Networks Inc. 等网络安全巨头的股价下跌超 5%。市场担忧 Capybara 可能使 Anthropic 在漏洞检测市场获得竞争优势。该公司上月刚推出 Claude Code Security 工具进军该领域。

**Part04**

## ****技术实力验证****

当前 Claude Code Security 工具由 Claude Opus 4.6 驱动，已证明具备出色的漏洞发现能力。Anthropic 工程师使用该工具在开源项目中发现了 500 多个高危漏洞。典型案例包括仅通过分析 PDF 工具变更日志中的开发者注释，就推断出其中存在安全缺陷。

此次泄露恰逢 OpenAI 集团完成其最新大语言模型的预训练阶段。预训练是构建模型核心能力的关键开发环节，后续将进行硬件效率、安全性和可用性等方面的优化。OpenAI 内部代号为 Spud 的新模型预计将在数周内发布。
