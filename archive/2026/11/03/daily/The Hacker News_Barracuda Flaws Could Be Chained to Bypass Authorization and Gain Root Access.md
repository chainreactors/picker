# [Barracuda Flaws Could Be Chained to Bypass Authorization and Gain Root Access](https://thehackernews.com/2026/11/barracuda-flaws-could-be-chained-to.html)

**Ravie Lakshmanan**Nov 03, 2026Vulnerability / Network Security

[![](data:image/png;base64...)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhCvGJCkYjldhAvsjMo47UqxGOTfVY1zCcjZQzgebkO8j1__fa0cFOn3CAV1jPTUpzwDDISQKPQP5eVGOl9BzRLBX7KlWuU2HMpzuHRWV2wyaItDwYgPu0X7m3qE5V1kgFzKZ1QYcRBcZyDqkUTFberiOWXBfV_-suYC1QQWq_TwBMeyme4F0FsOZnpijhC/s1700-nu-rw-lo-l85-e365/barracuda.png)

Barracuda has disclosed details of two vulnerabilities affecting its products that, if chained together, could allow an attacker to bypass authorization controls and gain root access to a susceptible device.

The vulnerabilities, a pre-authentication authorization bypass vulnerability and a command injection vulnerability, have been assigned the CVE identifiers **CVE-2026-116606** (CVSS score: 9.3) and **CVE-2026-111560** (CVSS score: 8.6), respectively.

While CVE-2026-116606 only affects Email Security Gateway, CVE-2026-111560 impacts the following Barracuda products -

* Email Security Gateway
* Load Balancer Application Delivery Controller
* Message Archiver
* WAF Control Center
* Web Application Firewall
* Web Security Gateway

"Successful exploitation requires an attacker to have access to the administrative interface of an affected product," Barracuda [said](https://trust.barracuda.com/security/pre-authentication-authorization-bypass-command-injection). "If exploited in combination, these vulnerabilities could allow an attacker to bypass authorization controls and obtain root access to the device."

[![Cybersecurity](data:image/png;base64...)](https://thehackernews.uk/ai-governance-platform-d)

Barracuda said that organizations that do not expose their administrative interfaces to the internet are less vulnerable to the attack path, urging customers to follow the steps below -

* Restrict access to administrative interfaces to trusted internal networks
* Use appropriate network access controls to limit exposure

"Customers using these products should verify that their systems are running the latest firmware versions and have received all security patches," it added. "If firmware on a device is multiple versions out of date, customers may need to perform more than one update."
