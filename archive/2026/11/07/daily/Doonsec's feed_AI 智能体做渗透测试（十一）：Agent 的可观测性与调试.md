## 1. 引言：跑起来之后，你怎么知道它干了什么

前十篇我们一路把 Agent 从「能跑」打磨到「可控」，再到「可拆分」，最后给它装上了「记忆」。到第十篇结束时，这套系统已经具备了相当完整的形态：多角色协作、工具白名单、目标 Scope 校验、记忆沉淀。

但真正把它放到真实任务里跑，你会遇到一个更棘手的问题：**它跑起来了，可你不知道它内部发生了什么。**

* • 任务跑了二十分钟，最后输出一份报告，中间它到底扫了哪些目标、调了哪些工具、为什么跳过某个端口，你一无所知。
* • 某次任务结果明显不对，你想复现，却发现同样的输入再跑一遍，结果又不一样了——因为 LLM 有随机性，中间状态没被记录。
* • 某个 Agent 卡住了，你不知道它是在等工具返回，还是在死循环里打转。
* • 出了安全事故，你想追溯「是谁、在什么时候、对哪个目标执行了哪条命令」，却发现日志里只有一句「任务完成」。
