**X 开始在 iOS 上测试独立的 X Chat 应用**
社交媒体网站 X 正在将其名为X Chat的私信服务带到一款独立应用中。该公司本周一表示，X Chat 应用的初始测试版正在通过苹果的 TestFlight 测试平台向数千名早期用户提供。测试计划在宣布后两小时已达到满员容量。根据 xAI 产品设计师迈克尔·博斯韦尔在X上发布的消息，该公司“很快”将把测试范围扩展到最初的 1000 名用户以外。“在过去的几个月里，我们一直在悄悄地为 iOS 开发一款独立的 X Chat 应用，”博斯韦尔在 X 上写道。他说：“使用它。搞崩它。我们想要你的反馈。”X Chat是 X平台现有私信功能的升级版本，该公司声称该功能是端到端加密的。
