Oasis Security з ”з©¶дәәе‘ҳеҸ‘зҺ°пјҢ**еҸІдёҠеўһй•ҝжңҖеҝ«зҡ„ејҖжәҗ AI жҷәиғҪдҪ“жЎҶжһ¶д№ӢдёҖ OpenClaw еӯҳеңЁдёҖеӨ„й«ҳеҚұйӣ¶дәӨдә’жјҸжҙһ**гҖӮиҜҘжјҸжҙһеҸҜи®©д»»ж„ҸжҒ¶ж„ҸзҪ‘з«ҷ**еңЁж— йңҖжҸ’д»¶гҖҒжү©еұ•зЁӢеәҸжҲ–д»»дҪ•з”ЁжҲ·ж“ҚдҪңзҡ„жғ…еҶөдёӢпјҢйқҷй»ҳе®Ңе…ЁжҺҘз®ЎејҖеҸ‘иҖ…зҡ„ AI жҷәиғҪдҪ“**гҖӮ

OpenClaw жҳҜдёҖж¬ҫеҸҜжң¬ең°йғЁзҪІзҡ„ AI жҷәиғҪдҪ“пјҢеүҚиә«дёә Clawdbot е’Ң MoltBotпјҢзҹӯзҹӯдә”еӨ©еҶ…еңЁ GitHub дёҠж–©иҺ·и¶… **10 дёҮжҳҹж Ү**пјҢе·ІжҲҗдёәе…Ёзҗғж•°еҚғеҗҚејҖеҸ‘иҖ…зҡ„й»ҳи®ӨдёӘдәәеҠ©жүӢгҖӮ

иҜҘе·Ҙе…·еңЁејҖеҸ‘иҖ…з¬”и®°жң¬з”өи„‘жң¬ең°иҝҗиЎҢпјҢеҸҜеҜ№жҺҘйҖҡи®Ҝеә”з”ЁгҖҒж—ҘеҺҶгҖҒејҖеҸ‘е·Ҙе…·еҸҠжң¬ең°ж–Үд»¶зі»з»ҹпјҢе№¶**д»ЈиЎЁз”ЁжҲ·иҮӘдё»жү§иЎҢж“ҚдҪң**гҖӮжӯЈжҳҜиҝҷз§ҚжһҒй«ҳзҡ„жқғйҷҗпјҢи®©иҜҘжјҸжҙһеҸҳеҫ—жһҒеәҰеҚұйҷ©гҖӮ

### ж”»еҮ»еҺҹзҗҶ

OpenClaw йҖҡиҝҮдёҖдёӘз»‘е®ҡеңЁ **[localhost](https://localhost)** зҡ„жң¬ең° WebSocket зҪ‘е…іиҝҗиЎҢпјҢиҜҘзҪ‘е…іжҳҜжҷәиғҪдҪ“зҡ„ж ёеҝғи°ғеәҰеұӮгҖӮmacOS й…ҚеҘ—еә”з”ЁгҖҒiOS и®ҫеӨҮжҲ–е…¶д»–жңәеҷЁзӯүжҺҘе…Ҙ вҖңиҠӮзӮ№вҖқ дјҡеҗ‘зҪ‘е…іжіЁеҶҢпјҢе№¶ејҖж”ҫ**зі»з»ҹе‘Ҫд»Өжү§иЎҢгҖҒж–Үд»¶и®ҝй—®гҖҒиҒ”зі»дәәиҜ»еҸ–**зӯүиғҪеҠӣгҖӮ

ж”»еҮ»д»…йңҖж»Ўи¶ідёҖдёӘжқЎд»¶пјҡ

ејҖеҸ‘иҖ…еңЁжөҸи§ҲеҷЁдёӯи®ҝй—®жҒ¶ж„ҸзҪ‘з«ҷжҲ–иў«е…Ҙдҫөзҡ„зҪ‘з«ҷгҖӮ

е®Ңж•ҙж”»еҮ»й“ҫеҰӮдёӢпјҡ

1. еҸ—е®іиҖ…еңЁж—ҘеёёжөҸи§ҲеҷЁдёӯи®ҝй—®д»»ж„Ҹж”»еҮ»иҖ…жҺ§еҲ¶зҡ„зҪ‘з«ҷ
2. йЎөйқўдёӯзҡ„ JavaScript еҗ‘жң¬ең° OpenClaw зҪ‘е…іе»әз«Ӣ WebSocket иҝһжҺҘ вҖ”вҖ” жөҸи§ҲеҷЁдёҚдјҡйҳ»жӯўи·Ёжәҗ WebSocket и®ҝй—®еӣһзҺҜең°еқҖпјҢеӣ жӯӨиҜҘиЎҢдёәиў«е…Ғи®ё
3. и„ҡжң¬д»ҘжҜҸз§’ж•°зҷҫж¬Ўзҡ„йҖҹеәҰ**жҡҙеҠӣз ҙи§ЈзҪ‘е…іеҜҶз Ғ**пјӣзҪ‘е…ізҡ„йҷҗжөҒжңәеҲ¶**е®Ңе…ЁиұҒе…Қ [localhost](https://localhost) иҝһжҺҘ**пјҢеӨұиҙҘе°қиҜ•дёҚдјҡиў«и®Ўж•°гҖҒйҷҗжөҒжҲ–и®°еҪ•
4. и®ӨиҜҒжҲҗеҠҹеҗҺпјҢи„ҡжң¬**йқҷй»ҳжіЁеҶҢдёәеҸ—дҝЎд»»и®ҫеӨҮ**вҖ”вҖ” зҪ‘е…ідјҡиҮӘеҠЁжү№еҮҶжқҘиҮӘ [localhost](https://localhost) зҡ„й…ҚеҜ№пјҢж— д»»дҪ•з”ЁжҲ·жҸҗзӨә
5. ж”»еҮ»иҖ…иҺ·еҫ—еҜ№ AI жҷәиғҪдҪ“зҡ„**е®Ңж•ҙз®ЎзҗҶе‘ҳзә§жҺ§еҲ¶жқғ**

жјҸжҙһж №жәҗжҳҜдёүйЎ№й”ҷиҜҜзҡ„и®ҫи®ЎеҒҮи®ҫпјҡ

* и®Өдёә [localhost](https://localhost) иҝһжҺҘеӨ©з„¶еҸҜдҝЎ
* и®ӨдёәжөҸи§ҲеҷЁжөҒйҮҸж— жі•и®ҝй—®жң¬ең°жңҚеҠЎ
* и®ӨдёәеӣһзҺҜең°еқҖж— йңҖйҷҗжөҒ

еңЁзҺ°д»ЈжөҸи§ҲеҷЁзҺҜеўғдёӯпјҢиҝҷдәӣеҒҮи®ҫеқҮдёҚжҲҗз«ӢгҖӮ

еңЁе»әз«Ӣи®ӨиҜҒдјҡиҜқеҗҺпјҢиҝңзЁӢж”»еҮ»иҖ…еҸҜзӣҙжҺҘж“ҚжҺ§ AI жҷәиғҪдҪ“пјҡ

жҢҮд»Өе…¶жЈҖзҙў Slack еҺҶеҸІдёӯзҡ„ API еҜҶй’ҘгҖҒиҜ»еҸ–з§ҒеҜҶж¶ҲжҒҜгҖҒд»Һе…іиҒ”иҠӮзӮ№зӘғеҸ–ж–Үд»¶пјҢе№¶**жү§иЎҢд»»ж„Ҹ Shell е‘Ҫд»Ө**гҖӮ

з ”з©¶дәәе‘ҳиЎЁзӨәпјҢеҜ№дәҺдҪҝз”Ёж ҮеҮҶ OpenClaw йӣҶжҲҗзҡ„ејҖеҸ‘иҖ…иҖҢиЁҖпјҢиҝҷзӣёеҪ“дәҺ**д»…йҖҡиҝҮдёҖдёӘжөҸи§ҲеҷЁж ҮзӯҫйЎөе°ұе®Ңе…Ёж”»йҷ·ж•ҙеҸ°е·ҘдҪңз«ҷ**пјҢиҖҢеҸ—е®іиҖ…жҜ«ж— еҜҹи§үгҖӮ

### зј“и§ЈжҺӘж–Ҫ

1. **з«ӢеҚіеҚҮзә§иҮі OpenClaw 2026.2.25 жҲ–жӣҙй«ҳзүҲжң¬**
2. зӣҳзӮ№ејҖеҸ‘иҖ…и®ҫеӨҮдёҠжүҖжңү OpenClaw е®һдҫӢпјҢеҢ…жӢ¬ IT ж— ж„ҹзҹҘзҡ„ вҖңеҪұеӯҗе®үиЈ…вҖқ
3. е®Ўи®Ўе№¶еӣһж”¶жҺҲдәҲжҷәиғҪдҪ“зҡ„дёҚеҝ…иҰҒеҮӯиҜҒгҖҒAPI еҜҶй’ҘдёҺиҠӮзӮ№жқғйҷҗ
4. дёә AI жҷәиғҪдҪ“иә«д»Ҫе»әз«ӢжІ»зҗҶзӯ–з•ҘпјҢ**жҢүдәәзұ»з”ЁжҲ·дёҺжңҚеҠЎиҙҰеҸ·еҗҢзӯүдёҘж јзҡ„ж ҮеҮҶиҝӣиЎҢз®ЎзҗҶ**

OpenClaw еӣўйҳҹе°ҶиҜҘжјҸжҙһе®ҡзә§дёә**й«ҳеҚұ**пјҢе№¶еңЁ 24 е°Ҹж—¶еҶ…еҸ‘еёғиЎҘдёҒ вҖ”вҖ” еҜ№дәҺеҝ—ж„ҝиҖ…й©ұеҠЁзҡ„ејҖжәҗйЎ№зӣ®иҖҢиЁҖпјҢиҝҷдёҖе“Қеә”йҖҹеәҰеҖјеҫ—иӮҜе®ҡгҖӮ

дҪҶйүҙдәҺиҜҘе·Ҙе…·жҷ®еҸҠжһҒеҝ«пјҢдјҒдёҡеә”еҒҮи®ҫејҖеҸ‘иҖ…и®ҫеӨҮдёӯд»ҚеӯҳеңЁжңӘдҝ®иЎҘе®һдҫӢпјҢе№¶**д»ҘеҗҢзӯүзҙ§жҖҘзЁӢеәҰжҺЁиҝӣдҝ®еӨҚ**гҖӮ
