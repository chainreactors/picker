# **дёҖгҖҒ68 дёӘжҙһпјҢдёҚжҳҜвҖқжҹҗдёҖе®¶еҺӮе•ҶеҖ’йңүвҖқ**

9 жңҲ 7 ж—ҘпјҢе®үе…Ёе…¬еҸё Adversa AI еҸ‘дәҶдёҖд»Ҫ MCP е®үе…ЁжұҮжҖ»жҠҘе‘ҠпјҢж ҮйўҳжҳҜгҖҠMCP security September 2026: Deadbugz + 3 server CVEsгҖӢгҖӮйҮҢйқўз»ҷдәҶдёҖдёӘдёҚеӨӘеҘҪзңӢзҡ„ж•°еӯ—пјҡеңЁд»–д»¬е®Ўи®Ўзҡ„ MCP жңҚеҠЎеҷЁйҮҢпјҢзҙҜи®ЎеҸ‘зҺ°В **68 дёӘеҸҜжҠҘе‘ҠжјҸжҙһ**гҖӮ

жҠҘе‘ҠзӮ№еҗҚдәҶе…·дҪ“ CVE зј–еҸ·пјҢиҝҳе…іиҒ”дәҶдёҖдёӘд»ЈеҸ·В **Deadbugz**В зҡ„ж”»еҮ»жҙ»еҠЁгҖӮ9 жңҲ 11 ж—ҘпјҢAI Governance Institute и·ҹиҝӣеҸ‘ж–ҮпјҢж ҮйўҳзӣҙжҺҘз”ЁдәҶвҖқзі»з»ҹжҖ§зјәеҸЈвҖқиҝҷдёӘиҜҚпјҢдёҚжҳҜвҖқеҒ¶еҸ‘й—®йўҳвҖқзҡ„еҶҷжі•гҖӮ

дёәд»Җд№ҲиҜҙзі»з»ҹпјҹAdversa AI д№ӢеүҚиҝҳжңүдёҖз»„ж•°жҚ®пјҡе®Ўи®ЎиҝҮзҡ„ MCP жңҚеҠЎеҷЁйҮҢпјҢ**91.8% зјәе°‘ OAuth и®ӨиҜҒ**гҖӮеҚҒеҸ°и®ҫеӨҮд№қеҸ°жІЎиЈ…й—Ёй”ҒпјҢйӮЈ 68 дёӘжҙһдёҖзӮ№йғҪдёҚж„ҸеӨ–гҖӮиҜҙзҷҪдәҶжҳҜж¬ иҙҰпјҢдёҚжҳҜиҝҗж°”гҖӮ

# **дәҢгҖҒеӣӣз§ҚжјҸжҙһпјҢжҜҸдёҖз§ҚйғҪиғҪзӣҙжҺҘжҺҸе®¶еә•**

жҠҘе‘ҠйҮҢеҪ’дәҶеӣӣзұ»пјҢйғҪжҳҜиҖҒзҶҹдәәпјҢдҪҶж”ҫиҝӣ MCP еңәжҷҜйҮҢпјҢжқҖдјӨеҠӣеҸҳдәҶгҖӮ

**SQL жіЁе…Ҙ**гҖӮз»Ҹе…ёдёӯзҡ„з»Ҹе…ёпјҢеҸӮж•°жІЎиҝҮж»ӨгҖҒжӢјжҺҘжү§иЎҢпјҢж”»еҮ»иҖ…йЎәзқҖе·Ҙе…·и°ғз”ЁзӣҙжҺҘжҠҠеҗҺз«Ҝеә“иҜ»з©ҝгҖӮ

**жңҚеҠЎз«ҜиҜ·жұӮдјӘйҖ пјҲSSRFпјү**пјҢиҖҢдё”дё“й—ЁзӣҜзқҖ**дә‘е…ғж•°жҚ®жңҚеҠЎ**жү“гҖӮиҝҷжқЎжңҖиҰҒе‘ҪгҖӮSSRF дёҚзЁҖжңүпјҢеҸҜдёҖж—Ұжү“зҡ„жҳҜдә‘еҺӮе•Ҷзҡ„е…ғж•°жҚ®з«ҜзӮ№пјҢжӢҝеҲ°жүӢзҡ„еҫҖеҫҖдёҚжҳҜжҷ®йҖҡж•°жҚ®пјҢжҳҜ**дә‘дёҠзҡ„дёҙж—¶и®ҝй—®еҮӯиҜҒ**гҖӮеҮӯиҜҒдёҖеҲ°жүӢпјҢжқғйҷҗе°ұдёҚжӯўвҖқжҹҗдёӘ MCP жңҚеҠЎеҷЁвҖқпјҢжҳҜдҪ дә‘дёҠйӮЈдёҖзүҮгҖӮ

**жҸҗзӨәжЁЎжқҝжіЁе…ҘпјҲprompt template injectionпјү**гҖӮж”»еҮ»иҖ…жҠҠжҢҮд»ӨеЎһиҝӣжЁЎжқҝйҮҢпјҢи®© AI жҷәиғҪдҪ“жҢүд»–зҡ„ж„ҸжҖқеҺ»и°ғе·Ҙе…·гҖҒиҜ»ж–Үд»¶гҖҒеҫҖеӨ–еҸ‘ж•°жҚ®гҖӮ

**и·Ҝеҫ„йҒҚеҺҶ**гҖӮ`../../`В йӮЈдёҖеҘ—пјҢи¶ҠиҝҮиҫ№з•ҢиҜ»еҲ°жң¬дёҚиҜҘиҜ»зҡ„ж–Үд»¶гҖӮ

жҠҘе‘ҠиҜҙеҫ—еҫҲзӣҙзҷҪпјҡд»ҘдёҠжҜҸдёҖзұ»пјҢйғҪиғҪеҜјиҮҙж•°жҚ®еӨ–жі„гҖҒеҮӯиҜҒиў«еҒ·пјҢжҲ–иҖ…еңЁзңҹе®һзҡ„дјҒдёҡйғЁзҪІйҮҢ**зӣҙжҺҘеҠ«жҢҒ AI жҷәиғҪдҪ“**гҖӮдёҚжҳҜзҗҶи®әжҺЁжј”пјҢжҳҜе·Із»ҸеңЁи·‘зҡ„зҺҜеўғгҖӮ

# **дёүгҖҒ91.8% жІЎжңүи®ӨиҜҒпјҢиҝҷдәӢжҖӘдёҚеҲ°ејҖеҸ‘иҖ…еӨҙдёҠ**

еҫҲеӨҡдәәз¬¬дёҖеҸҚеә”жҳҜвҖқејҖеҸ‘иҖ…еӨӘзіҷвҖқгҖӮжҲ‘дёҚе®Ңе…ЁеҗҢж„ҸгҖӮ

MCP жң¬жқҘе°ұжҳҜд»ҺвҖқе…Ҳи·‘йҖҡеҶҚиҜҙвҖқй•ҝеҮәжқҘзҡ„гҖӮModel Context ProtocolпјҢAnthropic жҸҗзҡ„ејҖж”ҫеҚҸи®®пјҢжҠҠ AI еҠ©жүӢжҺҘеҲ°еӨ–йғЁе·Ҙе…·дёҠпјҢClaude DesktopгҖҒCursorгҖҒWindsurfгҖҒVS Code Copilot йғҪеңЁж”ҜжҢҒгҖӮиҝҷеҚҠе№ҙз”ҹжҖҒйҮҺиӣ®з”ҹй•ҝпјҢжҜ”зҡ„жҳҜвҖқжҺҘдәҶеӨҡе°‘е·Ҙе…·вҖқпјҢжІЎдәәжҜ”вҖқи®ӨиҜҒеҒҡеҫ—жҖҺд№Ҳж ·вҖқгҖӮиҝҷз¬”иҙҰзҺ°еңЁиҰҒиҝҳпјҢиҝҳеҫ—еңЁеҲ«дәәзҡ„ж—¶й—ҙиЎЁдёҠиҝҳгҖӮ

# **еӣӣгҖҒиҝһе·Ҙе…·иҝ”еӣһзҡ„дёңиҘҝйғҪдёҚиғҪеҪ“ж•°жҚ®зңӢ**

еҰӮжһңиҜҙжјҸжҙһжҳҜжҳҺйқўдёҠзҡ„з—…пјҢдёӢйқўиҝҷжқЎжӣҙеғҸж…ўжҖ§дёӯжҜ’гҖӮ

й’ҲеҜ№ 19 дёӘ MCP жңҚеҠЎеҷЁзҡ„зӣёе…із ”з©¶еҸ‘зҺ°пјҢ**е·Ҙе…·иҫ“еҮәдјҡдҫӢиЎҢеҗ‘ AI жҷәиғҪдҪ“зҡ„дёҠдёӢж–ҮйҮҢжіЁе…Ҙж„ҸеӨ–жҢҮд»Ө**гҖӮе…¶дёӯВ **Context7**В иў«жҠ«йңІеӯҳеңЁе…·дҪ“зҡ„жҸҗзӨәжіЁе…Ҙй—®йўҳгҖӮ9 жңҲ 2 ж—Ҙ Digital Applied зҡ„е®Ўи®Ўд№ҹжҢҮеҗ‘еҗҢдёҖд»¶дәӢгҖӮ

иҝҷжқЎз»“и®әеҸҚзӣҙи§үпјҢдҪҶжҜҸдёӘеҒҡе®үе…Ёзҡ„йғҪиҜҘи®°дҪҸпјҡ\*\*дҪ дёҚиғҪй»ҳи®Ө MCP жңҚеҠЎеҷЁзҡ„иҫ“еҮәжҳҜеҸҜдҝЎж•°жҚ®гҖӮ\*\*дј з»ҹжһ¶жһ„йҮҢпјҢж•°жҚ®е°ұжҳҜж•°жҚ®пјҢжҺҘеҸЈиҝ”еӣһд»Җд№ҲжҲ‘еҪ“еҖјеӨ„зҗҶпјӣеҲ°дәҶжҷәиғҪдҪ“жһ¶жһ„пјҢжҺҘеҸЈиҝ”еӣһзҡ„дёңиҘҝдјҡиў«жЁЎеһӢеҪ“жҢҮд»ӨиҜ»гҖӮдёҖдёӘиў«жұЎжҹ“зҡ„е·ҘеҚ•ж ҮйўҳгҖҒдёҖжқЎиў«жһ„йҖ зҡ„ж—Ҙеҝ—пјҢе°ұеҸҜиғҪеҸҳжҲҗз»ҷ AI дёӢзҡ„дёҖеј е‘Ҫд»ӨгҖӮ

еҶҚеҫҖдёӢдёҖеұӮжҳҜе®Ўи®Ўж—Ҙеҝ—гҖӮжҷәиғҪдҪ“иҜ»зҡ„жҳҜиў«дәәеЎһиҝҮзҡ„еҶ…е®№пјҢе®ғеҒҡзҡ„дәӢгҖҒи°ғзҡ„е·Ҙе…·е…Ёиў«и®°дёӢжқҘпјҢиҝҷд»Ҫж—Ҙеҝ—иҝҳиғҪдёҚиғҪеҪ“еҗҲи§„иҜҒжҚ®пјҹж•°жҚ®дҝқжҠӨиҝҷжқЎзәҝдёҠпјҢиҝҷжҳҜзӣҙжҺҘиё©зәҝгҖӮ

# **дә”гҖҒе®Ўжү№й—ЁзҰҒпјҢд№ҹеҸҜиғҪжҳҜзәёзіҠзҡ„**

9 жңҲ 4 ж—ҘжңүдёҖд»Ҫе…ій”®е…¬е‘ҠпјҢи®Іжҹҗ SSH MCP жңҚеҠЎеҷЁзҡ„е®һзҺ°жңү**е‘Ҫд»ӨеҲҶзұ»зјәйҷ·**пјҡдёҖжқЎе‘Ҫд»Өиў«еҪ’зұ»жҲҗвҖқе®үе…ЁвҖқпјҢдҪҶиҝңзЁӢ shell е®һйҷ…жү§иЎҢзҡ„пјҢжҳҜеҸҰдёҖжқЎжқғйҷҗжӣҙй«ҳзҡ„е‘Ҫд»ӨгҖӮ

иҝҷдёӘзјәйҷ·зҡ„еҸҜжҖ•д№ӢеӨ„дёҚеңЁжҠҖжңҜйҡҫеәҰпјҢеңЁдәҺе®ғ**зӣҙжҺҘжү“з©ҝдәҶдјҒдёҡе®Ўжү№й—ЁзҰҒжүҖдҫқиө–зҡ„еҸӘиҜ»е·ҘдҪңжөҒеҒҮи®ҫ**гҖӮжҲ‘д»¬еҒҡе®Ўжү№зҡ„йҖ»иҫ‘жҳҜвҖқеҸӘиҜ»ж”ҫиЎҢгҖҒеҶҷж“ҚдҪңжӢҰдҪҸвҖқпјҢйқ зҡ„е°ұжҳҜеҲҶзұ»иҝҷдёҖеұӮгҖӮеҲҶзұ»дёҖж—ҰдёҚеҸҜдҝЎпјҢжүҖжңүе®Ўжү№йғҪжҳҜеҪўејҸдё»д№үгҖӮ

жүҖд»Ҙе‘Ҫд»ӨеҲҶзұ»гҖҒжңҚеҠЎеҷЁжқҘжәҗгҖҒе®Ўжү№жөҒзЁӢпјҢеҫ—еҪ“жҲҗ**дёүдёӘзӢ¬з«ӢйӘҢиҜҒзҡ„жҺ§еҲ¶зӮ№**пјҢдёҚиғҪдёІжҲҗдёҖжқЎй“ҫеӯҗзӣёдә’иғҢд№ҰгҖӮ

еҘҪж¶ҲжҒҜжҳҜиЎҢдёҡеҹәзәҝеңЁиЎҘгҖӮ9 жңҲ 10 ж—ҘпјҢдә‘е®үе…ЁиҒ”зӣҹпјҲCSAпјүжӣҙж–°жҢҮеҚ—пјҢжҳҺзЎ®жҠҠ MCP жңҚеҠЎеҷЁи®ӨиҜҒжөҒзЁӢзЎ®з«ӢдёәдјҒдёҡжҷәиғҪдҪ“йғЁзҪІдёӯзҡ„е®үе…Ёе…ій”®жҺ§еҲ¶зӮ№пјҡиҝңзЁӢжңҚеҠЎеҷЁиҝһжҺҘеҝ…йЎ»дҪҝз”ЁВ **OAuth 2.1 + PKCE**пјҢе№¶дё”еңЁд»»дҪ•и®ӨиҜҒеҠЁдҪңејҖе§Ӣд№ӢеүҚпјҢ**ејәеҲ¶еҒҡжңҚеҠЎеҷЁе…ғж•°жҚ®ж ЎйӘҢ**гҖӮжҢҮеҚ—зӮ№еҗҚжү№иҜ„зҡ„пјҢе°ұжҳҜи–„ејұзҡ„жңҚеҠЎеҷЁеҸ‘зҺ°жңәеҲ¶пјҢе’ҢеҜ№жңҚеҠЎеҷЁжҸҗдҫӣз«ҜзӮ№зҡ„ж— жү№еҲӨдҝЎд»»пјҢиҝҷдёӨжқЎиў«и®Өе®ҡдёәе…ғж•°жҚ®ж“Қзәөе’ҢжңӘжҺҲжқғе·Ҙе…·дәӨдә’зҡ„дё»иҰҒж”»еҮ»е…ҘеҸЈгҖӮ

# **е…ӯгҖҒеҲ«зӯү CISA жҠҠдҪ еҶҷиҝӣ KEVпјҢд»ҠеӨ©е…Ҳе№Іиҝҷе…ӯд»¶дәӢ**

1. **зӣҳзӮ№**гҖӮжҠҠжүҖжңү MCP жңҚеҠЎеҷЁжҚһеҮәжқҘпјҢз¬¬дёүж–№е’ҢејҖжәҗзҡ„д№ҹз®—пјҢеЎһиҝӣиө„дә§еҸ°иҙҰгҖӮжҗһжё…жҘҡи°ҒеңЁз”ЁгҖҒиҝһдәҶд»Җд№ҲгҖҒиғҪдёҚиғҪеҮәзҪ‘гҖӮ
2. **жҢЁдёӘжҹҘйӮЈеӣӣзұ»жҙһ**гҖӮSQL жіЁе…ҘгҖҒSSRFгҖҒи·Ҝеҫ„йҒҚеҺҶгҖҒжҸҗзӨәжЁЎжқҝжіЁе…ҘпјҢеҜ№зқҖиҝҮдёҖйҒҚпјҢеҲ«жҠҪж ·гҖӮ
3. **зҪ‘з»ңеұӮйҡ”зҰ»**гҖӮжңҖдҫҝе®ңд№ҹжңҖи§Ғж•Ҳзҡ„дёҖжӯҘпјҡи®© MCP жңҚеҠЎеҷЁиҝӣзЁӢзў°дёҚеҲ°дә‘е…ғж•°жҚ®з«ҜзӮ№пјҢе…ҲжҠҠ SSRF иҝҷжқЎи·Ҝе өжӯ»гҖӮ
4. **ж”№е°Ҫи°ғй—®еҚ·**гҖӮи®ӨиҜҒжңәеҲ¶гҖҒиҫ“е…Ҙж ЎйӘҢгҖҒиЎҘдёҒиҠӮеҘҸпјҢйғҪеҠ иҝӣ AI дҫӣеә”е•ҶйЈҺйҷ©иҜ„дј°гҖӮжЁЎеһӢе’Ңе№іеҸ°дҪ йғҪиҜ„дәҶпјҢдёҚеӨҡиҝҷдёҖйЎөзәёгҖӮ
5. **жҺҘиҝӣе·Іжңүзҡ„зӣ‘жөӢжөҒзЁӢ**гҖӮи®©е®ғи·ҹзқҖзҺ°жңү CVE и·ҹиёӘдёҖиө·иө°пјҢеҲ«йЈҳеңЁжөҒзЁӢеӨ–гҖӮйЎәдҫҝзӣҜиҝҷдәӣ CVE дјҡдёҚдјҡиў« CISA еҲ—иҝӣе·ІзҹҘиў«еҲ©з”ЁжјҸжҙһпјҲKEVпјүзӣ®еҪ•пјҢдёҖж—ҰиҝӣдәҶпјҢиҒ”йӮҰеҗҲеҗҢзӣёе…із»„з»Үе°ұеҫ—жҢүејәеҲ¶ж—¶йҷҗдҝ®гҖӮ
6. **еҜ№еҹәзәҝ**гҖӮжӢҝ OWASP GenAI зҡ„ MCP е®үе…Ёеҹәзәҝе’Ң MCP жІҷз®ұеҹәзәҝеҪ“е°әеӯҗпјҢйҮҸеҮәиҮӘе·ұзҡ„е·®и·қжё…еҚ•гҖӮзӣ‘з®Ўж–№е’Ңе®Ўи®Ўж–№е·Із»ҸејҖе§Ӣеј•з”Ёе®ғд»¬еҪ“жңҖдҪҺж ҮеҮҶдәҶгҖӮ
