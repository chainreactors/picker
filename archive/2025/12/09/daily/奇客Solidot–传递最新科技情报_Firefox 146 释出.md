## Firefox 146 释出

[![Firefox](https://icon.solidot.org/images/topics/topicfirefox.png?123)](/search?tid=39 "Firefox")

[Edwards](/~Edwards) (42866)发表于 2025年12月09日 14时29分 星期二 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83000&appkey=1370085986&title=Firefox%20146%20%E9%87%8A%E5%87%BA "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自黑珍珠魔咒**

Mozilla 释出了 Firefox 146。主要新特性包括：对所有用户开放 Firefox Labs；macOS 版本将有一个专门的 GPU 进程，图形代码中的致命错误将不会导致浏览器崩溃，而是重启 GPU 进程；Linux 版本原生支持 Wayland 分数缩放显示，提升渲染效率；Windows 版本停止支持 Direct2D，需要 Direct2D 的用户建议用 140ESR 版本；WebCrypto 支持压缩椭圆曲线点；更新 Skia 图形库；支持 CSS text-decoration-inset 属性、支持 @scope 规则，等等。
https://www.firefox.com/en-US/firefox/146.0/releasenotes/
