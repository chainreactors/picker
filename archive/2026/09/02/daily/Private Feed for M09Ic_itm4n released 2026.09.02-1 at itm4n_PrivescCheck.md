### Modified

* Set output file encoding to "unicode" explicitly rather than relying on the OS decision.
* Modify build script to add an option for reusing the encryption key across runs.

## 2026-09-01

### Added

* Add a check to enumerate known vulnerable drivers that are not blocked.

## 2026-08-29

### Modified

* Refactor Main.ps1 completely, clean up things, and allow checks to be run fully standalone (for easier testing during development).
* Improve performance of the known vulnerable driver check by caching the known vulnerable driver sample list in memory.
* Refactor and clean up Main.ps1 completely.

### Fixed

* Fix an issue in the "exploitable leaked handle" check where NtQueryObject would hang when querying certain device file objects.

### Added

* Add information about signing certificates to the LOL driver list embedded into the script.
