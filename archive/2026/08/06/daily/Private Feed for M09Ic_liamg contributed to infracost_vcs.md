Fixes FIX-549 (residual of FIX-324).

The link branches in `formatFinopsResourceLocation`/`formatTagResourceLocation` interpolated the resource address and URL raw into `[text](url)` markdown, so a crafted resource name or module source URL from an untrusted PR could inject misleading links/markdown into the posted comment.

* Link text now gets the same code-span escaping as the non-link branches.
* URLs must be http(s) and get breakout chars percent-encoded; unsafe URLs drop the link and fall back to the escaped address.
