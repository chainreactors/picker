## Chrome 148 将延迟加载视频和音频以改进性能

[![Chrome](https://icon.solidot.org/images/topics/topicchrome.png?123)](/search?tid=154 "Chrome")

[Edwards](/~Edwards) (42866)发表于 2026年04月06日 22时22分 星期一 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83969&appkey=1370085986&title=Chrome%20148%20%E5%B0%86%E5%BB%B6%E8%BF%9F%E5%8A%A0%E8%BD%BD%E8%A7%86%E9%A2%91%E5%92%8C%E9%9F%B3%E9%A2%91%E4%BB%A5%E6%94%B9%E8%BF%9B%E6%80%A7%E8%83%BD "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自魔法生活**

Chrome 和 Firefox 等浏览器都支持延迟加载。延迟加载又名懒加载，顾名思义，为了加快页面加载速度而推迟加载特定对象，这些对象直到要使用时才会开始加载，如 Chrome 从 2019 年起就延迟加载图像和 iframe。现在它正在 Chrome 148 上测试延迟加载视频和音频以改进浏览器性能。今天很多网站尤其是新闻网站都会在页面中嵌入视频和音频，影响了页面加载速度。
https://slashdot.org/story/26/04/05/0031201/chrome-148-will-start-lazy-loading-video-and-audio-to-improve-performance
