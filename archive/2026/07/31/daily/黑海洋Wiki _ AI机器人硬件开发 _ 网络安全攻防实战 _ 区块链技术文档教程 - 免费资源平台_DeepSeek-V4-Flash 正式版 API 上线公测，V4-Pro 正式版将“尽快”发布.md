# DeepSeek-V4-Flash 正式版 API 上线公测，V4-Pro 正式版将“尽快”发布

发布时间:
2026-07-31 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
4371

7 月 31 日，DeepSeek 通过 API 文档发布日志，宣布 DeepSeek-V4-Flash 正式版 API 上线公测。据悉，正式版 V4-Flash 原生支持 Responses API 格式并针对性适配 Codex。

官方还表示，本次仅升级了 DeepSeek-V4-Flash 的 API 接口，DeepSeek-V4-Pro API 及 APP / WEB 端模型未做更改，DeepSeek-V4-Pro 正式版将会尽快发布。
