1. **Aurora勒索软件运营者在对10个目标的攻击中使用CursorAI**

发布时间：2026.09.01

新闻来源：Hacker News

根据 CloudSEK 和 Gambit Security 的发现，与 Aurora（又名 Aur0ra）勒索软件相关的威胁行为者被观察到使用 SpaceX 的人工智能（AI）驱动的编程助手 Cursor 入侵目标网络。Aurora（Aur0ra）勒索软件团伙利用 AI 编程助手实施网络攻击

根据 CloudSEK 和 Gambit Security 的分析，与 Aurora 相关的俄语系网络犯罪团伙被发现使用 SpaceX 旗下 AI 编程助手 Cursor 策划和执行网络入侵。该团伙的暴露基础设施泄露了2026年4月至7月间针对9个国家20多个组织的活动记录，其中4名受害者已被公开列于其数据泄露网站。

攻击手法： 该团伙以 Windows 为目标，初始访问通过电子邮件轰炸结合冒充 IT 支持人员的电话诈骗实现，使用 Xray-core 工具建立远程访问。随后通过 SMB、LDAP、WinRM、RDP、RPC 进行横向移动，获取高权限账户后清除日志、禁用 Microsoft Defender，最终收集并外泄数据、部署加密器。运营者使用 Cursor 以俄语规划攻击，并刻意排除 CIS（独联体）IP 段和国家域名。

加密器技术： CloudSEK 识别出用 Zig 编写的 Windows（sap.exe）和 Linux/ESXi（encrypt.out）两个版本的加密器，二者源自同一代码库的静态构建。Windows 版本可删除卷影副本并禁用系统还原；Linux/ESXi 版本则在加密前强制终止虚拟机。Gambit Security 进一步发现，运营者使用运行 Anthropic Claude Sonnet 的 Cursor Agent 对10个目标执行实际入侵，任务涵盖网络扫描、域枚举、NTLM 中继攻击和证书攻击等，但多数命令首次尝试即失败，需多次迭代修改。Linux 版本攻击还利用 Python 脚本扫描 VMware ESXi 环境。

附属模式： 从加密器中恢复的密钥使研究人员得以访问勒索谈判记录和4个加密货币钱包集群，附属成员分成比例在54%至79%之间浮动，根据赎金金额和受害者营收情况逐案确定，非法资金随后被清洗套现。

受害者： 据路透社报道，受影响企业包括 Christeyns、Teckentrup、Helideck Certification Agency、Bayou Title、一家阿根廷制药分销商和一家意大利制造商（具体名称未披露）。

2.Gryxa：首款 AI 全链条辅助攻击工具包

发布时间：2026.09.01

新闻来源：Hacker News

ReliaQuest 发现了一种名为 Gryxa 的新型 AI 辅助工具包，被用于针对324台主机的初始访问行动，是其观察到的首例 AI 参与构建完整攻击行动（从工具包到控制台）的案例。

Gryxa 将合法的远程监控和管理（RMM）软件转化为隐蔽访问后门，通过多个重启机制维持持久化，并窃取基于 Chromium 的浏览器中保存的凭据（通过 Telegram 传输）。当与攻击者的连接中断时，Gryxa 会在10-13分钟内尝试禁用或卸载 Microsoft Defender 等端点保护代理，中继恢复后重新启用 Defender。

该工具包还具备绕过 Chromium 应用绑定加密（ABE）的能力，并在可见 RMM 植入被移除后，通过隐藏组件收集 Windows 日志和主机工件上传至攻击者基础设施。有证据表明，幕后行为者通过将开发过程包装为"授权内部部署"来越狱 AI 编程智能体，Gryxa 很可能通过钓鱼邮件投递。ReliaQuest 指出，Gryxa 包含现成的"collect-forensics"作业，日志轮换阈值设为200KB，表明这是常规能力而非针对单一事件的响应。

3.AI生成视频攻破人脸识别系统!微信/QQ/多地市监平台遭黑产规模化滥用

发布时间：2026.09.09

新闻来源：安全内参

江苏仪征近期破获一起特大新型网络犯罪案。犯罪团伙利用AI生成动态人脸视频，攻破人脸识别系统，进而实施多种犯罪。

犯罪团伙将AI生成的动态人脸视频存储于电脑中，并在电脑上下载带有篡改、替换系统摄像头功能的软件，在平台进行人脸识别认证时，将屏幕前的实时画面替换为事先存储在电脑中的动态人脸视频，以此攻破“刷脸”认证防线。

江苏仪征近期破获一起特大新型网络犯罪案。自2020年7月起，马某某团伙利用AI软件批量合成动态人脸视频，通过篡改系统摄像头画面替换实时视频，攻破QQ、微信及多地市场监管平台的人脸识别系统。柳某某等中介人员接单转包赚取差价，该团伙还长期收购含照片的身份证信息用于生成视频。

他们将AI生成的动态人脸视频存储于电脑中，在电脑上下载带有篡改、替换系统摄像头功能的软件，在平台进行人脸识别认证时，将屏幕前的实时画面替换为事先存储在电脑中的合成人脸视频，以此规避人脸核验，完成识别认证。

这些AI生成视频被用于实施多种犯罪：贺某某等人盗取QQ账号内游戏币等虚拟物品变现；宋某某等原工商代办人员非法变更企业工商登记数据。2023年11月田先生举报后，公安机关抓获多地犯罪嫌疑人。

侦查实验确认该行为符合非法控制计算机信息系统罪构成要件。案件已推动整改非法变更工商登记数据400余条，并督促相关平台升级动态人脸校验机制。

1. 韩国医美平台"江南姐姐"用户敏感数据泄露，近5000名中国人受影响

发布时间：2026.09.08

新闻来源：安全内参

韩国知名医美预约平台"江南姐姐"（Gangnam Unni）发生用户个人信息泄露事件。运营方Healing Paper表示，共计219665名海内外用户受影响，其中包括近5000名中国人受影响。

据韩国《中央日报》报道，"江南姐姐"是韩国知名医美资讯平台，主要协助用户与诊所对接咨询。

根据平台运营公司Healing Paper9月7日发布的个人信息泄露通知暨致歉声明，本月4 日，"江南姐姐"用于查询咨询记录的部分系统功能遭异常访问，导致部分用户个人信息泄露。

公司发现异常后，立即封锁相关访问通道，并对整体系统采取紧急安全措施。处置过程中，公司发现同一攻击者5日又试图通过另一通道再次访问系统，相关通道亦被立即封锁。

声明指出，受影响用户共219665人，其中韩国用户约16万人、日本约4.8 万人、泰国1591人、中国大陆481人、中国台湾地区4218人，其他国家5308人。

据《韩国先驱报》报道，此次泄露事件还涉及更多敏感的就诊细节，包括手术和医院名称、医生、首选预约时间、就诊原因、就诊状态和照片。

Healing Paper声明称，公司已主动向韩国互联网安全局（KISA）通报此次个人信息泄露事件，并已逐一通知受影响用户。

该公司提醒用户，泄露信息可能被不法分子利用，应警惕来源不明的短信、电话及电子邮件；如遇有人要求提供个人信息或金融信息，请勿回复，也不要提供任何信息。

2.超2.2亿条航班乘客数据公网暴露，涉及大量中国用户

发布时间：2026.09.09

新闻来源：安全内参

安全内参9月9日消息，一个存有超过2.2亿条旅客和机组人员记录（包括护照号码和航班详情）的空港旅客信息系统（APIS）数据库，因一系列安全配置错误而被暴露在互联网上。发现该数据库的研究人员表示，该系统疑似与一家越南机构有关。

APIS在全球广泛使用。旅客和机组人员抵达或离开一个国家之前，航空公司会通过该系统提交其身份、护照及航班信息。

此次暴露的数据时间跨度从2017年1月至2026年4月。涉及的旅客可能来自多个国家和地区，且曾在上述时间段内搭乘航班前往、离开或经由越南中转。

长达9年的旅客和机组数据，途经越南航班的乘客可能受到影响

Kinryū Labs在6月3日在调查勒索软件活动期间，对互联网暴露数据库进行排查时发现了这套Elasticsearch集群。

该集群名为“pax-info”，包含29个索引，数据总量约107 GB。其中两个主要索引分别存储了210318069条旅客记录和10465631条机组人员记录，合计220783700条。

Kinryū Labs称，该集群位于河内一段由该国运营商Viettel分配的IP地址空间内。不过，目前无法确认具体是哪家越南机构运营该系统。

泄露信息包括旅客和机组人员的姓名、出生日期、性别、国籍、护照或旅行证件号码、证件有效期以及签发国家。

与出行相关的数据还包括航班号和航班日期、航空公司、出发机场、目的地机场、中转机场、座位信息、行李信息，以及计划起飞和抵达时间、预计时间和实际时间等。这些信息通常由APIS及相关航空公司系统记录。

外媒BleepingComputer抽查的部分记录显示，其中包括韩国、中国、加拿大和新西兰等国籍的旅客。

研究人员无法提供完整的国籍分布统计，但确认数据涉及亚太、欧洲和中东地区的众多国际航空公司。因此，泄露记录可能涉及来自世界各地、在这9年间到访越南或经越南中转的人员。
