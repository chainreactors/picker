## Optimizely 遭入侵 BBC CNN 等知名网站传播恶意程序

[![安全](https://icon.solidot.org/images/topics/topicsecurity.png?123)](/search?tid=100 "安全")

[Edwards](/~Edwards) (42866)发表于 2026年11月18日 17时12分 星期三 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85920&appkey=1370085986&title=Optimizely%20%E9%81%AD%E5%85%A5%E4%BE%B5%20BBC%20CNN%20%E7%AD%89%E7%9F%A5%E5%90%8D%E7%BD%91%E7%AB%99%E4%BC%A0%E6%92%AD%E6%81%B6%E6%84%8F%E7%A8%8B%E5%BA%8F "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自基因突变**

被知名网站用于网页 A/B 测试的软件 Optimizely 遭到入侵，黑客纂改了这些网站加载的 JavaScript 代码，向访客的计算机植入恶意程序。有至少 178 个网站受到影响，其中包括 BBC、CNN、Zoom、宜家、Salesforce、汇丰银行和 TalkTalk 等知名网站。这些网站使用了 Optimizely 的 Web Experimentation，允许在不更改网站底层代码的情况下调整网页的内容和布局。黑客利用了被称为 OPTIMJACK 的漏洞向 Optimizely 客户的项目中植入恶意的 JavaScript 代码。Optimizely 表示它已经修复了漏洞，通知了受影响的客户。黑客释放了多个恶意负荷，其中包括篡改用户的加密货币钱包地址将其替换为攻击者控制的地址；窃取支付卡信息、Cookie 和屏幕截图；甚至还会利用 iPhone 和 iPad 运行的旧版本 iOS 系统漏洞。目前不清楚有多少设备被安装恶意程序。
