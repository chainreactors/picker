# New Release: Tor Browser 15.0.21

by [ma1](/author/ma1)
| September 1, 2026

![](/new-release-tor-browser-15021/lead.png)

Tor Browser 15.0.21 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.21/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.20 is:

* All Platforms
  + Updated NoScript to 13.6.32.1984
  + Updated OpenSSL to 3.5.8
  + [Bug tor-browser#45223](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45223): Backport tor-browser#45220 - about:torconnect doesn't show when launching the browser in non-PBM
  + [Bug tor-browser#45253](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45253): Rebase Tor Browser stable onto 140.15.0esr
  + [Bug tor-browser#45259](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45259): Backport Security Fixes from Firefox 155
* Windows + macOS + Linux
  + Updated Firefox to 140.15.0esr
  + [Bug tor-browser#44996](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44996): Change the 32-bit linux message to the expired version for the final 15.0 release
  + [Bug tor-browser#45264](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45264): Use parent process for TorConnect redirections
* Android
  + Updated GeckoView to 140.15.0esr
* Build System
  + Windows + Linux + Android
    - Updated Go to 1.25.14
