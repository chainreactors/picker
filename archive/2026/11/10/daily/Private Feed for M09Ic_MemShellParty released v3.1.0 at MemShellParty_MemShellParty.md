[`bdbf85d`](/MemShellParty/MemShellParty/commit/bdbf85dc5e9130a324a12e2f5ae3d23a25b25093)

### Added

1. 自定义 shelltool 支持远程下拉选项：`@ConfigField` 字段可再标注 `@RemoteOptions`，界面按远程接口返回的 JSON 提取选项，String 字段绑定选中 ID，`Map<String, Object>` 字段绑定完整对象；生成期不发起远程请求
2. 新增 `ShellToolConfig#validate()` 校验钩子：生成入口在参数绑定完成后、创建生成器前调用，插件可抛出 `InvalidInputException` 报告非法输入
3. 外置插件新增只读元信息列表：启动时解析 `META-INF/memshell-party-plugin.properties`（缺失时回退 MANIFEST 与 jar 文件名），通过 `GET /api/plugins` 暴露，Web 与桌面端「关于」均可查看已加载及加载失败的插件；描述符损坏不影响插件加载

### Fixed

1. 修复 Tomcat 冷 processor 场景下 Command upgrade 回调在 `CoyoteAdapter.service` 之前执行、note 1 中没有 Catalina Request/Response 导致无法取参：按 CoyoteAdapter 的方式补建并回写，兼容 Tomcat 8.5 ~ 11
2. 修复 Tomcat 5/6/7/8.0 BIO 模式下 RawWebSocket 空闲读取超时导致会话断开
3. 修复 Apusic / GlassFish RawWebSocket 并发关闭连接时 Selector 未释放造成的文件描述符泄漏
4. 修复 Docker 构建因 Gradle 发行版下载超时或失败而中断，改为从官方 Gradle 镜像复制对应版本

### Changed

1. Maven 发布重构（不兼容变更）：
   * 14 个 servlet 容器 provider 合并为 `memshell-party-server-servlet`；
   * 新增 `memshell-party-bom` 统一管理模块版本，模块改为独立基线发布；
   * `memshell-party-server-all` / `memshell-party-shelltool-all` 改为 POM-only 聚合 platform，Gradle 用 `platform(...)`、Maven 用 `<type>pom</type>` 引入；
   * `memshell-party-fileless` 并入 `memshell-party-packer`，运行时包名为 `com.reajason.javaweb.packer.jar.agent.fileless`；
2. (WEB) 工具下拉默认选中排序后的第一项

**Full Changelog:** [v3.0.0...v3.1.0](https://github.com/MemShellParty/MemShellParty/compare/v3.0.0...v3.1.0)
