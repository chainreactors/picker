# New Release: Tor Browser 15.0.2

by [ma1](/author/ma1)
| November 19, 2025

![](/new-release-tor-browser-1502/lead.png)

Tor Browser 15.0.2 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.2/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.1 is:

* All Platforms
  + Updated Tor to 0.4.8.20
* Build System
  + Android
    - [Bug tor-browser-build#41629](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41629): Bump JNA to 5.16.0
