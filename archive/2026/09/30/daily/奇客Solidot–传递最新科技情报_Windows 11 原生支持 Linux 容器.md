## Windows 11 原生支持 Linux 容器

[![Linux](https://icon.solidot.org/images/topics/topiclinux.png?123)](/search?tid=7 "Linux")
[![Windows](https://icon.solidot.org/images/topics/topicwindows.png?123)](/search?tid=33 "Windows")

[Edwards](/~Edwards) (42866)发表于 2026年09月30日 18时23分 星期三 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85515&appkey=1370085986&title=Windows%2011%20%E5%8E%9F%E7%94%9F%E6%94%AF%E6%8C%81%20Linux%20%E5%AE%B9%E5%99%A8 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自龙岛**

微软宣布 WSL Containers GA，该工具为 Windows 11 开发者提供了一种通过 Windows Subsystem for Linux 构建、运行和部署 Linux 容器的内置方案。微软同时提供了容器管理工具 wslc.exe，GPU 支持、网络改进、健康检查、存储挂载、与 Microsoft Defender for Endpoint 和 Intune 的集成。微软还声称，当 Linux 环境访问存储在 Windows 中的文件时，性能最多可提升一倍。
https://blogs.windows.com/windowsdeveloper/2026/09/29/wsl-containers-now-generally-available/
