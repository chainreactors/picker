*News Today*

3 月 2 日消息，据路透社报道，亚马逊旗下云计算部门 AWS 在周日表示，其位于阿拉伯联合酋长国的数据中心因撞击引发火灾，电力暂时中断。

![](https://mmbiz.qpic.cn/mmbiz_png/757fvrbk7oYOXGIStWMOxOFMQzIhRXo0dxnbHZTqGCibtqDiaqFbiaPjrUtgGo4MuU0dn5K18kEbAqApZnj4FZHUtDkpTHWPEfM7x5iaMbz0ic4I/640?wx_fmt=png&from=appmsg)

AWS 在声明中披露，太平洋标准时间凌晨 4:30 左右，其阿联酋区域的可用区（mec1-az2），因物体撞击数据中心设施产生火花并引发火灾。消防部门已切断涉事设施的供电，工作人员正在开展灭火作业。AWS 表示，受影响可用区的服务连接恢复需要数小时时间，位于阿联酋区域的其他可用区目前运行正常。

根据 AWS 官网信息，“可用区”由单个或多个互联的实体数据中心组成。这些区域是 AWS 区域内相互独立且隔离的物理位置。当被询问 AWS 此次数据中心事件是否与袭击有关时，公司既未予以确认，也未予以否认。

参考今日早些时候报道，苹果已暂时关闭其位于阿联酋的全部 5 家 Apple Store 零售店，涵盖阿布扎比 3 家门店和迪拜 2 家门店。5 家门店的关闭状态将至少持续至当地时间的周三（3 月 4 日）。

另外，三大航已发布关于部分中东航线非自愿退改规定的通知；同程旅行针对中东地区局势启动应急保障机制，酒店订单可申请免费取消；携程也宣布为受伊朗及中东局势影响的旅客提供行程保障。
