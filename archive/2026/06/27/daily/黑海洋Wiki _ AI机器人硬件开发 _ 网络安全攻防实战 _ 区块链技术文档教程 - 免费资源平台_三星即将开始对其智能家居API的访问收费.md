# 三星即将开始对其智能家居API的访问收费

发布时间:
2026-06-28 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
1559

从今年十月起，三星将推出多种新的付费层级，用于访问其 “SmartThings API” ，其中包括一项面向 “非商业性个人开发者” 的每月4.99美元套餐。一些更高级的智能家居用户如果直接访问SmartThings API以获得更灵活的智能家居控制，或使用同样做法的第三方工具，则很可能会触犯这一规则变更。开源智能家居平台 Home Assistant 的创始人保卢斯·舒特森在一篇博客文章中写道：“使用Home Assistant集成将受到他们变更的影响，并将归入他们新的‘个人套餐’之下。”三星表示，新的定价将使其能够大力投资于合作伙伴和用户一直要求的企业级功能。
