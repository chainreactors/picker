# New Release: Tor Browser 15.0.12

by [ma1](/author/ma1)
| May 7, 2026

![](/new-release-tor-browser-15012/lead.png)

Tor Browser 15.0.12 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.12/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.11 is:

* All Platforms
  + Updated tor to 0.4.9.7
  + [Bug tor-browser#44940](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44940): Rebase Tor Browser stable onto 140.10.2esr
* Windows + macOS + Linux
  + Updated Firefox to 140.10.2esr
  + [Bug tor-browser#44746](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44746): Funding the Commons Implementation (Desktop)
* Android
  + Updated GeckoView to 140.10.2esr
  + [Bug tor-browser#44747](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44747): Funding the Commons Implementation (Android)
* Build System
  + All Platforms
    - [Bug tor-browser-build#41781](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41781): Fix clean section in rbm.local.conf.example
