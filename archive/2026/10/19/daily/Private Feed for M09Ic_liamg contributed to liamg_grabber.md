Owner

Adds `WithoutAmbientCredentials()`. With it set, s3 and gcs fetches ignore env/profile/instance-role/ADC credentials.

* s3: anonymous requests unless `WithAWSCredentials` is set
* gcs: unauthenticated unless `WithGCPCredentials` is set
* Default behaviour is unchanged

Needed by infracost so user-supplied module sources cannot use the runner's role (TRK-1227).
