**1**

**直播分享内容**

Claude Code 是当前 AI 编程与智能研发领域中非常值得关注的工具之一。相比传统代码补全工具，它更强调面向真实工程项目的上下文理解、任务拆解、代码修改与持续迭代能力，能够帮助研发人员在复杂项目中更高效地完成代码阅读、问题定位和功能开发。

    本次分享将围绕 Claude Code 的基础使用与实战场景展开，内容包括：

1. **Claude Code 安装与环境配置**  带大家快速了解 Claude Code 的安装流程、基础配置方式，以及使用前需要注意的关键事项。
2. **Claude Code 核心功能介绍**  系统介绍 Claude Code 在代码理解、代码生成、文件修改、问题定位、项目协作等方面的能力，帮助大家建立完整使用认知。
3. **“90秒修Bug”实战演示**  通过现场演示，展示 Claude Code 如何在真实代码场景中快速理解问题、定位原因并完成修复，让大家直观感受 AI Native 研发工具带来的效率提升。

    本次直播适合所有希望将 AI 工具真正融入研发流程的技术团队参与。无论你负责开发、测试、安全，还是承担技术管理、产品规划和团队效率提升工作，都可以通过本次分享了解 Claude Code 在真实研发场景中的使用方法。

**2**

**AI Native知识普惠工程直播计划**

本次活动是 **AI Native知识普惠工程** 系列直播的第二期。该系列培训围绕“个人成长、团队落地、组织转型”三条主线展开，按照 **认知启蒙 → 技能实战 → 定制转型** 的成长路径，系统帮助个人开发者、技术负责人、研发管理者及泛技术领域从业者理解 AI Native 研发的核心方法，并探索 AI 工具在真实研发流程中的落地应用。

    课程内容将围绕 AI Native 研发的核心本质展开，深入拆解 AI 如何重构软件生产方式；同时从 **Claude Code** 的实际使用出发，延展到 **MCP、Agent 工作流、AI 编程方法论** 等前沿方向，帮助大家理解研发行业正在发生的趋势变化。

    在直播过程中，我们也将结合实景演示，展示单人如何借助 AI 工具调度“完整 AI 开发团队”，完成需求理解、代码生成、Bug 修复、测试验证等研发全流程，让大家直观感受 AI Native 研发带来的效率提升。
