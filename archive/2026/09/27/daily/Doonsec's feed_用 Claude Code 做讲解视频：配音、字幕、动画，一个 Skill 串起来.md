Claude Code、Codex 写出来的代码，也可以用来制作讲解视频。

GitHub 上的 anything2explainer 就是这样一个项目：给它一个主题，或者一篇写好的技术文章，它把解说词、配音、字幕和动画制作组织成流程，交给编程 Agent 执行。作者已经放出了《RAG 与知识库》的中文样片，时长 4 分 54 秒。

**如果你有技术内容想讲，又不熟悉动画制作，这个项目值得看看。** 它把从文案到成片的步骤装进了一个 Skill，连配套的模板工程和样例文件也一起提供了。

## 先看它怎么讲 RAG

RAG（检索增强生成）经常出现在知识库项目里。讲原理时，一张流程图能把步骤列出来；做成讲解视频，还要安排每一步什么时候出现，以及旁白怎么和画面配合。

作者公开的样例里，知识库构建从文档解析讲起。PDF、网页、表格和扫描件分别画成图标，通过箭头连到解析器。上方放着“解析、切块、向量化、建索引、更新”的流程，正在讲的环节用紫色突出。

这套表现方式，适合拿来解释有步骤、有关系的技术主题。比如一次向量检索如何完成，或者一个请求怎样经过系统里的不同模块。对象、箭头和说明文字都能对应到要讲的知识点。

平时写技术文章、做团队分享，可以从自己熟悉的一张架构图开始，把其中一段流程作为试做主题。

## 画面由代码绘制，制作过程也公开了

anything2explainer 的画面用 Remotion 绘制。这套工具允许用 React 和 TypeScript 编写视频画面，编程 Agent 负责把分镜变成镜头组件，再渲染为 MP4。

具体到讲解片，就是把“这个方框放哪里、箭头何时出现、哪句话说完切换画面”写进代码。项目提供了常用图形、字体、动效和版式规范，Agent 在这些基础上完成每个镜头。

制作时先写解说词，再生成配音和时间轴，随后安排分镜与动画。镜头里的文字、图形和动作，都要按配音的时间出现。

我觉得值得一起看的，还有它公开的制作文件。仓库的 `examples/rag/` 目录里，可以沿着同一个主题往下看：

* **解说词**

  ：看一篇技术内容如何拆成适合听的讲解。
* **分镜表**

  ：看每段话对应什么画面，什么时候切换。
* **镜头代码**

  ：看图形和动画怎样实现。
* **质检与交付说明**

  ：看成片出现过什么问题，又改了哪些地方。

作者记录过切换时出现空帧、入场元素穿过字幕区域等问题，也保留了修订说明。这些记录让你知道，自动渲染之后，还有字幕遮挡、画面衔接等问题需要检查。

这里要区分一下版本：过程文件对应较早的中文样片，首页 4 分 54 秒的演示是后续版本；文中配图取自作者公开的样例帧。

## 怎么把自己的文章交给它

这是给 Claude Code、Codex 使用的 Skill。需要先准备本地运行环境，再由编程 Agent 执行制作流程。

先获取仓库：

```
git clone https://github.com/Vincentwei1021/anything2explainer.git
```

中文说明 `README_ZH.md` 列出了 Skill 的安装方法，以及 Node、Python、FFmpeg 和配音依赖。按文档接入自己使用的 Agent 后，就可以给主题或文章。

比如，手头有一篇向量数据库的介绍，可以这样提需求：

> 把这篇文章做成一条约 3 分钟的中文讲解视频。
>
> 面向会用大模型、但还不了解向量检索的开发者。重点讲清向量数据库解决什么问题，以及一次检索如何完成。
>
> 先给我看解说词，确认后再继续配音和动画。

这里的读者和讲解重点，要按自己的内容改。相同主题，讲给第一次接触 RAG 的同事，和讲给准备搭知识库的开发者，应该保留的细节会不一样。

项目流程里有几个需要你参与的地方：确定时长和语言、确认解说词、选择配音，以及查看前 30 秒样片。你也可以提供已经录好的配音。

**最值得花时间的是解说词和前段预览。** 配音之后，镜头会依照时间轴安排，再改文案就可能需要重新对齐；先看前 30 秒，则能尽早发现字号、画风和语速是否合适。

## 适合什么内容，开始前看清什么

按项目文档，这套模板支持中文和英文，画面是 1280×720 横屏，采用黑底、白色线条和紫色重点。图形、字幕与章节进度条的样式都有现成规范。

它适合的内容比较明确：技术科普、知识库原理讲解，以及文章里的流程演示。真人口播、以实拍为主的视频，以及竖屏短视频，都超出了当前模板的适用范围。想换一套视觉风格，也需要调整样式和组件。

使用许可同样要看：仓库采用 PolyForm Noncommercial 许可，作者说明工具包非商业使用免费，商业使用需要事先授权；制作出的视频归创作者。仓库还提醒，Remotion 对公司用户另有授权要求，准备商用时需一并核对。

想开始的话，先看作者样片，再打开 `examples/rag/` 里的解说词和分镜表。拿自己熟悉的一个主题，照着写出一份需求，让 Agent 先交出解说词和前段预览。
