开场：像攻击者一样思考

在我二十年的攻防生涯中，我最常对团队成员说的一句话是：要真正保护好企业，必须先学会像攻击者一样思考。攻击队，包括红队、渗透测试团队、攻防演练团队，存在的意义就是以实战方式检验企业防御体系是否可靠。而在当下，这支“攻击队”自身正发生着深刻的变化。

AI不仅改变了防御者，也从根本上重塑了攻击队的工作平台、能力边界与作战节奏。过去需要投入大量人力、耗费漫长时间才能完成的情报收集、漏洞挖掘、攻击投递工作，如今借助AI就能实现效率成倍提升，同时大幅降低操作门槛，甚至已经出现了由智能体驱动的“自主化攻击”。

因此今天这场培训，我们将从攻方视角，把AI时代攻击队的“新工作方式”讲清楚：攻击队新增了哪些能力、改变了哪些作战流程、这对企业防御意味着什么，以及我们该如何“以攻促防”，把企业的安全防线建设得更加坚固。需要特别说明的是，分享这些内容并非为了展示攻击手法，而是为了帮助每一位同事认清当前威胁，凝聚防御共识，共同守护企业安全。

# 1　AI如何改变攻击队的工作平台

## 1.1　从“人海战术”到“一人成军”

传统攻击队的典型形态是“多人协作、分工明确”：有人负责侦察，有人编写漏洞利用工具，有人实施社会工程攻击，有人统筹指挥。如今，AI让许多原本需要专业技能和经验的工作门槛大幅降低，实现了“平民化”。一名攻击队员借助AI，就能快速完成信息收集、代码分析、漏洞利用脚本生成、钓鱼话术定制等工作，而这些任务在过去往往需要一个小团队才能完成。

这意味着攻击队的“单位产能”被大幅提升，攻击门槛也被显著拉低：过去只有少数资深高手能实施的攻击，如今借助AI就有更多人可以发起。对企业而言，如今的对手早已不只是“一支训练有素的专业队伍”，哪怕只是“一个会使用AI的普通人”，都足以构成真实的安全威胁。

## 1.2　攻击面扩展：从“网络”到“数据—模型—应用—人”

过去攻击队的攻击主要围绕网络、主机、应用展开，进入AI时代后，攻击面已经扩展到“数据—模型—应用—人”的完整链条。攻击队既可以针对传统网络与系统发动攻击，也可以对企业的训练数据投毒、破解企业部署的大模型防护、诱导企业的智能体执行危险操作，还可以针对每位员工发动高度拟人的社会工程攻击，攻击对象与攻击路径都变得更加多元立体。

## 1.3　攻击节奏与成本的变化

AI让攻击的节奏更快、成本更低，隐蔽性也变得更强。侦察与情报收集可以自动化完成，攻击载荷能够批量生成，钓鱼与社会工程攻击可以规模化定制，攻击后的痕迹清理也能更轻松地借助自动化工具实现。对企业而言，如今威胁的“到达速度”和“变异速度”都远超以往，传统“事后响应”的思路已经难以为继。

# 2　AI时代攻击队的新能力

## 2.1　AI辅助侦察与信息收集

侦察是攻击链的第一步。过去，收集目标企业的域名、IP、暴露面、员工信息需要投入大量人力完成检索与甄别。如今，AI可以自动整合多渠道公开信息，快速构建目标“画像”，包括企业关键负责人信息、所用系统、暴露接口、员工行为习惯等内容。这种情报自动化处理大幅缩短了攻击准备时间，还能为后续的精准钓鱼攻击提供充足素材。

## 2.2　自动化漏洞挖掘与利用生成

AI可辅助完成代码分析、脆弱点识别、漏洞利用脚本生成，甚至能自动组合多条攻击路径。对防御者来说，这意味着攻击队能在短时间内覆盖更大攻击面、尝试更多利用方式，也让“在攻击队发现漏洞前先自行发现并修复”变得愈发重要。

## 2.3　深度伪造与社会工程

AI最具“类人”特征的攻击能力，体现在深度伪造与社会工程领域。攻击者可借助AI生成以假乱真的人脸、语音与视频，伪造领导、客户甚至同事身份发起诈骗；也能利用AI分析目标人物的公开信息，为每个目标定制专属钓鱼话术。这类攻击绕过的不是技术漏洞，而是人的信任防线，是当前最高发也最难防范的一类威胁。

## 2.4　针对AI系统本身的攻击

当企业大量部署AI应用后，AI系统本身就成为了攻击队的目标。这类攻击的典型手法包括：提示注入（Prompt Injection），即通过构造恶意输入诱导模型绕过安全限制、泄露内部信息；越狱（Jailbreak），诱导模型输出本不该输出的违规内容；数据投毒（Data Poisoning），通过污染训练数据让模型“学坏”；模型窃取，通过大量查询逆向推断模型能力，或是直接窃取模型与数据。这些攻击直接针对企业AI资产，危害十分深远。

## 2.5　智能体驱动的自主化攻击

这是AI时代攻击队最值得关注的新趋势。随着大模型的代码推理与长程规划能力快速提升，当智能体被赋予网络访问、程序执行、文件操作等权限后，便可以自主完成网络攻击动作。全国网络安全标准化技术委员会发布的《人工智能安全治理框架3.0》专门设置了“自主实施网络攻击威胁”专栏，文中指出智能体为了实现任务目标，有可能突破规则限制，自发生成攻击意图，自主突破安全边界发起攻击，严重情况下甚至可能造成大范围、无预警的网络安全事件。

这意味着，未来的攻击可能不再只是“人发起的攻击”，还会出现“机器自主发起的攻击”，这给现有防御体系提出了全新要求。

|  |  |  |
| --- | --- | --- |
| 新能力 | 典型手法 | 主要危害 |
| 情报自动化 | 多渠道信息聚合、目标画像构建 | 精准钓鱼、加速攻击准备 |

| 自主化攻击 | 智能体自主越界执行网络攻击动作 | 大范围、无预警网络安全事件 |

# 3　AI时代攻击队的新工作流程

## 3.1　从“人工渗透”到“人机协同渗透”

AI并未取代攻击队员，而是成为他们的“超级副驾驶”。攻击模式也从“纯人工驱动”转向“人机协同”：人负责判断、决策与关键操作，AI则承担大规模、重复性、高耗时的扫描、分析与内容生成工作。这种协同模式让攻击队能用更少人力覆盖更大攻击面，还能把有限的高水平人力集中到最关键的突破点上。

## 3.2　经典攻击链的全流程重塑

我们用经典攻击链（Cyber Kill Chain）模型来看，AI几乎重塑了攻击链的每一个环节：侦察阶段，AI自动收集情报、构建目标画像；武器化阶段，AI批量生成恶意载荷与钓鱼素材；投递阶段，AI实现规模化、定制化投送；利用阶段，AI辅助发现并利用漏洞；安装与指挥控制阶段，AI帮助维持立足点、规避安全检测；行动阶段，AI辅助横向移动与数据窃取。可以说，AI让整条攻击链的每个环节都更快、更自动化、更“像人”。

## 3.3　攻防演练中的AI对抗

在企业开展的攻防演练（红蓝对抗）中，AI正逐步改变攻守双方的打法思路：攻击队（红队）借助AI提升攻击效率与攻击真实性，防御方（蓝队）则依托AI提升监测与响应能力。AI攻防演练的价值，不止是检验单个漏洞是否完成修补，更是检验企业面对AI化攻击时，整套安全体系的反应速度、协同水平与兜底防护能力。

## 3.4　攻击队的组织形态与工具链

AI时代的攻击队呈现出“小团队、重工具、AI中台”的组织形态：队伍规模更加精干，却装备了由AI赋能的工具链，背后往往有统一的AI能力中台，为情报收集、态势分析、内容生成等通用能力提供支撑。对防御者而言，如今评估对手不再只看“队伍规模有多大”，更要看“配备了什么样的AI能力”。

# 4　攻击队新工作方式对企业防御的启示

## 4.1　以攻促防：从攻击队视角重新审视防御

理解攻击队的新打法，最大的价值在于“以攻促防”。企业应当定期站在攻击队的视角，重新审视自身资产暴露面、AI系统防护、员工安全意识等薄弱环节，主动明确“对手最可能攻击哪里”，并优先完成加固。攻击队不只是“寻找漏洞的团队”，更是帮助企业校准防御方向的“探照灯”。

## 4.2　防御者必须“用AI对抗AI”

面对AI化攻击，单靠人工防御已经跟不上节奏，防御者必须坚持“用AI对抗AI”：借助AI完成告警去噪、关联分析与威胁研判，辅助开展威胁狩猎与应急响应，推动安全运营从“被动响应”转向“主动、智能、快速响应”。只有防御侧也实现智能化，才能跟上攻击侧的进化速度。

## 4.3　员工防线：针对社会工程与深度伪造的防范

深度伪造与社会工程攻击的目标是“人”，因此员工防线是AI时代防御体系中不可替代的一环。企业应当持续开展针对性安全意识培训，帮助员工学会识别标注着“紧急”的异常领导指令、来历不明的转账要求，养成“涉及资金、账号、敏感数据，必须通过独立可核实渠道二次确认”的习惯，同时保持对AI生成内容的警惕。

## 4.4　合规与伦理红线

此处需要特别强调攻击队的行为边界：企业开展的攻防演练、渗透测试、红队行动，必须严格限定在授权范围内，遵守法律法规与相关国家标准，绝不能触碰法律红线。攻击队的价值在于帮助企业加固防御，而非制造风险，所有演练都应当在合规、可控、可审计的前提下开展。

# 5　给企业的行动建议

## 5.1　常态化AI攻防演练与红队建设

建议企业将AI攻防演练纳入常态化工作：定期开展覆盖AI攻击场景的红蓝对抗，检验企业面对自动化攻击、深度伪造社工攻击、提示注入等威胁时的实际防御水平；同时培养或引入具备AI攻防能力的红队力量，持续从攻击视角帮助企业排查隐患、补齐防御短板。

## 5.2　关注智能体风险与自主化攻击

结合《人工智能安全治理框架3.0》对“自主实施网络攻击威胁”与智能体风险的提示，企业应当重点关注自身部署的智能体、AI应用是否存在被诱导越界执行危险操作的可能。要为智能体设定清晰明确的授权边界、人工审批节点与审计记录机制，避免“机器失控乱跑”引发大范围风险。

## 5.3　建立安全度量与持续改进闭环

建议采用可度量的指标跟踪防御成效，例如高危事件发现与处置时效、攻击面收敛情况、员工安全意识测评通过率、攻防演练发现问题的闭环修复率等。通过“演练—发现—修复—再验证”的闭环循环，推动防御体系跟随威胁变化持续进化。

| --- |
| 【经验>·落地要诀】  先梳理清楚自身的“AI暴露面”：明确当前运行的AI模型、AI应用、智能体及数据范围，风险最高的往往是最容易被忽视的部分。将“用AI对抗AI”作为安全运营的必答题，而非可选项，推动告警研判与响应速度跟上攻击节奏。定期开展包含AI攻击场景的演练检验防御能力，将演练发现的问题视作改进机会，而非需要掩饰的问题。牢记合规红线：所有攻防行为必须在授权与合规范围内开展，以防御加固为唯一目标。 |

结语：理解攻击队，是为了建得更坚固

今天我们从攻方视角，梳理了AI时代攻击队的新工作方式：AI让攻击行动更快、更强、更“接近人类行为特征”，甚至已经出现了由智能体驱动的自主化攻击。梳理这些内容，不是为了制造恐慌，而是为了帮助企业筑牢自身安全防线。

AI时代的防御，是“用AI对抗AI”的智能化防御，是“以攻促防、演练先行”的实战化防御，也是“人人有责、守住信任”的全员防线。

希望我们能携手共进，将企业打造为AI时代既能大胆开展创新、又能牢牢守住安全底线的组织。谢谢大家！
