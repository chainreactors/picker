## Released from the curse of the update bork fairy

![](/design_picker/d2e337b97204af4aa34dda04c4e5d56d954b216f/graphics/icons/social_share_icon.svg)

Microsoft has finally fixed a Windows Recovery Environment (WinRE) bug it introduced in Windows 10's final update.

The October 14, 2025 update - released the same day Windows 10 reached end of support - broke WinRE on affected devices, preventing it from launching.

That same release also left [USB devices like keyboards and mice unavailable](https://www.theregister.com/2025/10/20/microsoft_bug_keyboard_mouse/) to some Windows 11 users in the recovery environment, prompting Microsoft to rush out an out-of-band patch. Yet for a subset of Windows 10 users, WinRE problems lingered.

[![](https://pubads.g.doubleclick.net/gampad/ad?co=1&iu=/6978/reg_software/oses&sz=300x50%7C300x100%7C300x250%7C300x251%7C300x252%7C300x600%7C300x601&tile=2&c=2aauiDxyHhgRq5bfwPVloPAAAABI&t=ct%3Dns%26unitnum%3D2%26raptor%3Dcondor%26pos%3Dtop%26test%3D0)](https://pubads.g.doubleclick.net/gampad/jump?co=1&iu=/6978/reg_software/oses&sz=300x50%7C300x100%7C300x250%7C300x251%7C300x252%7C300x600%7C300x601&tile=2&c=2aauiDxyHhgRq5bfwPVloPAAAABI&t=ct%3Dns%26unitnum%3D2%26raptor%3Dcondor%26pos%3Dtop%26test%3D0)

The Windows Recovery Environment is a critical last-resort tool when Windows repeatedly fails to boot. Users can also access it by interrupting the boot process... unless Microsoft has released an update that has broken it for a given device.
