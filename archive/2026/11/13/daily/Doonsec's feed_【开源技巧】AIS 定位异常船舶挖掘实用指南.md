# **AIS 定位异常船舶挖掘实用指南**

适用对象：海事态势感知分析员、合规与制裁筛查团队、海警/海关情报岗、航运风险尽调人员，以及搭建"暗船"检测流水线的数据工程师。

开源情报研究中心

![](https://mmbiz.qpic.cn/mmbiz_png/no8YFGgia2NGJ5ncwmBuvuTBfwWRoA2pCdLCdaBzhKILibByjpwYCBbnJ4xRWYdFOW5CvVKYjyUmbVymv4gNbpUSaKfHLsDt9gNmEN65eDRa0/640?wx_fmt=png&from=appmsg)

2026年11月13日不开船舶定位，或者盗用其他船舶的注册名称该怎么挖？一句话结论：**绝大多数"异常"是数据和覆盖造成的，不是船在作弊。指南的全部技巧，都是为了让"漏掉的船"和"无辜的船"同时变少。**

## **0. 一页速览：30 分钟上手流程**

|  |  |  |  |
| --- | --- | --- | --- |
| **步骤** | **做什么** | **产出** | **典型耗时** |
| ① 建底座 | 把 AIS 拆成"船舶静态表 / 动态报文表 / 航次表 / 事件表"，跑一遍字段质检 | 可信 MMSI 清单 + 脏数据黑名单 | 半天（一次性） |
| ② 硬规则筛 | 速度不可能、位置跳变、越陆、长度与船型矛盾 | L1 候选池（通常占全量 0.1%–2%） | 分钟级 |
| ③ 行为画像 | 静默缺口（gap）、绕行、长时间漂航、近距离并靠 | L2 候选池 | 小时级 |
| ④ 遥感复核 | 用 SAR/光学影像判断"当时那里到底有没有船" | 可见 / 不可见 / 无法判定 | 受卫星重访限制 |
| ⑤ 身份归因 | IMO 主键 → 注册、检验、所有权、制裁 | 证据卷宗 | 每船 10–30 分钟 |
| ⑥ 网络扩展 | 同港同窗、STS、共有公司、共有管理公司 | 关联船组 | 批量 |
| ⑦ 分级交付 | 按证据强度分 A/B/C 三档，附可复核的证据链 | 可行动清单 | 每轮 1 小时 |

记住一条铁律：**"某一次 SAR 过境没看到 AIS"不构成故意规避的证据**——可能是卫星没拍到、设备坏了、或船本来就小于 AIS 强制配备门槛。系统的定位是"生成待人工裁定的候选"，不是"下判决"。

## **1. 先搞清楚：你要找的是哪一类异常**

"定位信息异常"在实务中是四种完全不同的东西，混在一起分析必然误报泛滥：

|  |  |  |  |
| --- | --- | --- | --- |
| **类型** | **现象** | **常见成因** | **挖掘难点** |
| **A. 静默/断点**（gap） | 报文中断数十分钟到数天，之后在原处或远处"重新出现" | 关闭设备、遮挡、岸基/卫星覆盖空洞、设备故障 | 无法自证恶意；必须先排除覆盖问题 |
| **B. 位置伪造/跳变** | 位置瞬移、速度矢量不可能、多船同步偏移 | 篡改 AIS 报文、GPS 干扰/欺骗、身份冒用 | 区域性 GPS 干扰会让"整片海"一起异常 |
| **C. 身份伪装**（identity laundering） | 声称是渔船/游艇/Class B，但实际是大型货船 | 冒用他人 MMSI、错填船型、关闭 A 类改开 B 类 | 需要外部物理证据（长度、吃水、影像） |
| **D. 行为异常** | 绕行、禁区闯入、长时漂航、异常并靠 | 规避检查、走私转运、电缆/管道抵近、捕捞 | 阈值强依赖海域与时季 |

学术界常用的五种行为异常分类（Lane 等提出，被 *J. Mar. Sci. Eng.* 2022 综述沿用，该综述覆盖 44 篇 AIS 异常检测论文）可以直接作为你的"分析菜单"：

1.**偏离常规航线**（route deviation）

2.**异常 AIS 活动**（信号丢失 / 丢失后异常续接）

3.**异常到港**（unexpected port arrival，去了不该去的港）

4.**近距离接近**（close approach，长时间并靠）

5.**进入禁区**（zone entry，海洋保护区、专属经济区、制裁水域）

落到数据上，这五类都要转成可计算的代理指标，第 5 节给对照表。

### **一条重要的分流原则：单船异常 vs 区域同步异常**

|  |  |  |
| --- | --- | --- |
| **特征** | **更可能是** | **处置** |
| 只有个别船静默/跳变，同海域其他船正常 | 个体行为或个体设备问题 | 逐船画像 + 遥感复核 |
| 同一时段、同一片海域，**几十上百条船同时出现物理上不可能的位移** | 区域性 GPS 干扰/欺骗 | 判定为"环境受影响区"，**不要**把这些船当嫌疑人；标注为数据可信度屏蔽区 |

佐治亚理工学院对 2024 年 11 月—2025 年 2 月全球 36.7 万艘船的 AIS 测量发现：31 个持续性异常热点中至少 22 个有强 GPS 欺骗证据，且红海（MSC Antonia 搁浅事件前数月）与霍尔木兹海峡（2026 年伊朗战争前一年多）的欺骗活动长期存在。**结论：区域欺骗是常态，逐船定罪必须扣除这一层。**

## **2. 数据底座：把报文变成能查的四张表**

### **2.1 表结构**

|  |  |  |
| --- | --- | --- |
| **表** | **关键字段** | **用途** |
| 船舶静态表 | MMSI、IMO、呼号、船名、船旗、船型、总长/船宽、吃水 | 身份核对、物理一致性校验 |
| 动态报文表 | MMSI、时间戳(UTC)、经纬度、SOG、COG、艏向、旋回率、航行状态 | 一切轨迹分析 |
| 航次表 | 目的地、ETA、吃水、危险品标志 | 意图与实际对照（异常到港/异常目的地） |
| 事件表 | 进出港、锚泊、STS、禁区闯入、gap | 供人工复核的结构化线索 |

分区的关键建议：动态表按**MMSI + 时间** 建索引，并按月/海域分区；单月全球量级在十亿条报文上下（本地论文使用的商用聚合器 12 天语料即含 1.34 亿个位置快照、192 万 MMSI），单机 PostgreSQL/PostGIS + TimescaleDB 足够，不必上大数据栈。

### **2.2 质检：先杀掉会毁掉全部结论的脏数据**

|  |  |  |
| --- | --- | --- |
| **校验项** | **判定方式** | **不通过意味着** |
| MMSI 结构 | 9 位；前 3 位为 MID 国家码；无 MID 的号段（如 111/970/974）需单独规则 | 伪造号或测试设备 |
| MMSI 校验 | 同一 MMSI 出现多个 IMO/船名/呼号/尺寸 | 身份冒用、或静态信息被改写 |
| IMO 校验位 | 7 位，前 6 位加权求和取模 10 得第 7 位 | 假 IMO（本地论文样本中 IMO 校验位 100% 通过，说明**校验位是廉价而有效的过滤**） |
| 坐标合法性 | lat∈[-90,90]、lon∈[-180,180]；不等于 0/91/181；不在陆地上（用海陆栅格判定） | 解析错误、设备故障、故意投毒 |
| 速度合法性 | SOG ≤ 30 kn（本地论文取 v\_max=30 kn 作为水面船上限），且 > 102.3 kn 为保留值 | 传感器故障或伪造 |
| 时间一致性 | 报文时间单调、时区统一为 UTC、无跨年错误 | 聚合器处理错误（这类错误会伪造出"瞬移"） |
| 船型—尺寸一致性 | 声明"游艇/渔船/Class B"但总长 > 50 m | 身份伪装（本地论文据此定义 identity laundering 规则） |
| 覆盖可信度 | 与岸站/卫星覆盖栅格叠置，标注"低覆盖区" | 决定后续 gap 能否作为证据 |

**实操建议**：把"低覆盖区"图层做出来。同一片海，如果历史 AIS 密度本身很稀，那里的 gap 几乎没有任何证据价值——这是把误报砍掉一半的最省力手段。

## **3. L1 硬规则层：用物理与格式把人筛到几十条**

硬规则的价值不在"聪明"，而在**可解释、可复现、可写进报告**。建议全部实现为对单条报文或相邻报文的确定性判定。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **#** | **规则** | **判定式（示例阈值）** | **主要误报来源** | **处置** |
| R1 | 速度不可能 | 相邻两点位移 / 时间差 > 30 kn（或 > 45 kn 作为极端） | 时间戳错乱、聚合器补点 | 先修时间戳，再判 |
| R2 | 位置瞬移 | 位移 > 100 km 且 Δt < 10 min | 经纬度解析错误、MMSI 复用 | 标记为"疑似报文污染" |
| R3 | 越陆移动 | 相邻两点连线穿越海陆栅格的陆地 | 海岸线精度、内河/运河 | 用高精度海陆掩膜，排除运河 |
| R4 | 航迹—航向矛盾 | COG 与两点实际方位差 > 90° 且持续 > 3 个报文 | 强流、锚泊回转 | 结合 SOG 判定 |
| R5 | SOG 与位移不符 | SOG > 8 kn 但实际位移对应 < 1 kn，或反之 | 停泊时 GPS 抖动 | 用 10 分钟滑窗 |
| R6 | 报文间隔异常 | 单船报文中位间隔的 10 倍以上、且不在低覆盖区 | 卫星过境间隙 | 进入 L2 的 gap 分析 |
| R7 | 静态信息改写 | 同一 MMSI 的船名/呼号/尺寸在 30 天内变更 | 合法改名/换旗 | 与登记变更记录对照 |
| R8 | 身份伪装 | 船型∈ {游艇, 渔船, Class B} 且总长 > 50 m | 船型字段错填 | 用影像/登记长度交叉验证 |
| R9 | 禁区滞留 | 在禁区内连续 > 2 h 且 SOG < 3 kn | 边界精度、合法通行 | 叠加许可清单 |
| R10 | 异常到港 | 目的地字段与实际靠港不一致（连续 2 次以上） | 船员不改 ETA/目的地 | 仅作为弱证据 |

**阈值起点建议**：R1、R2 用"物理上限"（30 kn、100 km/10 min）而不是"统计学分位"，因为这层的目标是**零漏网的粗筛**；真正的排序交给 L3/L4。本地论文的配对实验也印证了"门限不能一味放大"——见第 5 节。

## **4. L2 行为层：把"异常"变成可比较的特征**

### **4.1 静默缺口（gap）的特征化——本指南的核心**

不要只记录"中断了 6 小时"，要把它拆成一组可比特征，否则无法区分"设备坏了"和"关掉了"：

|  |  |  |
| --- | --- | --- |
| **特征** | **计算方式** | **为什么有用** |
| gap 时长 | t\_end − t\_start | 与卫星重访周期、覆盖栅格对照才有意义 |
| gap 前 30 min 平均 SOG/COG | 滑窗统计 | 突然减速后关机 vs 高速中关机，含义不同 |
| gap 两端位移与方位 | 大圆距离 / 方位角 | 与"按最后 SOG 直线推算"的位置比对，偏差即证据 |
| gap 期间是否被 SAR/光学观测到 | 与影像检测结果求交 | **这是唯一能把"没报告"升级为"在但不报告"的证据** |
| gap 起点距最近港口/锚地距离 | 空间查询 | 一出港就关，和在大洋中间关，性质不同 |
| 同海域并发 gap 比例 | 时空邻域统计 | 高并发⇒ 区域干扰/覆盖问题，不是个体行为 |
| gap 后首次出现位置合理性 | 与可达半径比对 | 超出 v\_max·Δt 的"跳跃"是伪造的强信号 |

本地论文给了一个极其实用的数量级：一艘 30 kn 的船，**每静默 1 小时可以合法移动约 55.6 km**；因此任何"用固定 5 km 距离门去匹配 SAR 与 AIS"的做法，都会把正常的快速船误判成"位置伪造"。这正是论文里 legacy 静态门限产生 **105,549 条"疑似欺骗"告警**、把分析员彻底淹掉的原因。

### **4.2 停留、并靠与转运（STS）**

可复现的判据（本地论文部署规则，可直接借鉴）：

·**STS 转运候选**：两船 SOG < 3 kn（缺失按 0 处理），同一 5 分钟时间桶内位置相距 < 1 km，且共享时间桶的首末间隔 ≥ 0.5 h（不必连续）；排除平均位置距港口 < 2 n mile 的配对；且至少一方为货船/油轮，或双方船型未知。

·**到港**：至少 3 个 SOG < 1 kn 的位置落在某港口（有 UN/LOCODE）2 n mile（3704 m）内。

这两条规则的价值在于**把"漂航"从噪声里分离出来**：港口内的低速是常态，必须显式排除，否则告警里 90% 是锚地。

### **4.3 绕行与规避**

·建立"常规航路栅格"（把历史轨迹栅格化后取高频格），统计单船轨迹落在常规栅格内的比例；比例骤降且伴随航程变长 ⇒ 绕行。

·叠加敏感图层：海洋保护区、电缆/管道走廊、专属经济区边界、制裁相关水域。**绕行 + 禁区边缘擦边 + 目的地含糊**三者同时出现，才是高价值线索。

### **4.4 预测误差法（无需标签的通用手段）**

*Electronics* 2025 的做法值得直接照搬：用 LSTM 学习单船历史航迹，预测下一时刻的位置、COG、SOG，把"预测—实测"偏差与由航海惯例、AIS 精度、经验灵敏度共同标定的阈值比较，超阈即异常。优点是**不需要人工标注**，且能捕捉"莫名其妙改向/减速"这类软异常；缺点是阈值对海域敏感，必须逐海域标定（该文在北海南部—波罗的海验证）。

工程上更稳的组合是：

6.**逐船基线**（同一 MMSI 自身历史分位，如 P99）+ **同类型船基线**（同船型/同尺度/同海域）；

7.双基线都超阈才报警，可显著降低"特殊作业船"带来的长期误报；

8.把预测误差、gap 特征、STS 命中、禁区命中合成一个 0–100 的可解释分数，而不是训练一个黑箱分类器。

## **5. L3 遥感复核：把"没报告"变成"在但不报告"**

AIS 只能看见**愿意被看见的船**。要突破这个结构性盲区，必须引入非合作传感（SAR 全天时全天候、光学受云影响）。这一层的工程细节决定了整个流水线是否可用。

### **5.1 关联的核心：动态运动学门（DKG）**

把每个 AIS 船位按 SOG/COG 外推到卫星过境时刻，再与影像检测到的目标做二分图匹配。接受半径按下式放大（本地论文式 3）：

g\_j = min( g\_max , max( g\_0 , 2·CEP\_j , κ·√(1 + v\_j/v\_ref) ) + v\_max·Δt\_j )

|  |  |  |  |
| --- | --- | --- | --- |
| **参数** | **含义** | **部署取值** | **实务解读** |
| g\_0 | 门限下限 | 200 m | 约等于 Sentinel-1 的 20 像素，吸收几何定位与拼接误差 |
| κ | 速度不确定系数 | 50 m/kn | 吸收速度相关的抖动 |
| v\_max | 水面船速度上限 | 30 kn（15.43 m/s） | 静默 1 h ⇒ 半径 +55.6 km |
| g\_max | 门限硬上限 | 50 km | 超过约 0.9 h 静默后半径即封顶 |
| τ\_sparse | 时间稀疏阈值 | 3 h | 超过则降级为"低置信度"，不再计入欺骗告警 |

把静默时长与半径的关系记住一句话就够：**门限随静默时间线性膨胀，封顶后不再膨胀；超过 3 小时的静默交给"降级规则"处理，而不是继续放大半径。**

### **5.2 五种结果标签（也是你的告警分类）**

|  |  |  |
| --- | --- | --- |
| **标签** | **定义** | **处置** |
| **确认** Confirmed | 影像目标与 AIS 轨迹在门限内匹配 | 常规跟踪，不报警 |
| **暗船** Dark | 影像目标在门限内找不到任何 AIS | 高优先级，进入归因 |
| **疑似欺骗** Spoof candidate | AIS 广播在门限内找不到影像目标，且未触发降级 | 中优先级，需二次影像 |
| **身份伪装** Identity laundering | AIS 声明小艇但影像包围盒 > 50 m | 高优先级，物理证据最硬 |
| **低置信时间稀疏** | 静默 > 3 h，且存在影像目标落在 v\_max·Δt 可达半径内 | **不进入操作员队列**，仅存档 |
