Anthropic 正在为Claude Code 准备一项名为“安全中心（Security Center）”的重要功能更新。该功能前身为 AutoPatch，为用户提供**代码安全扫描的全局视图**，并支持针对特定仓库和分支的**手动扫描**。这一举措标志着 Anthropic 在 AI 开发安全上的进一步发力，意在对标行业日益增长的安全合规需求。

## 从 AutoPatch 到 Security Center

随着 AI 编程工具的普及，代码生成的安全性已成为企业和开发者最为关注的核心痛点。此前，社区曾流传 Anthropic 正在开发一项名为 "AutoPatch" 的功能，自动修复代码漏洞。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/aYef9qMYLnIu92fg9PUzL7lsatOCf5UtHs3vkiasvCamHHCTqibjuW0Fbiakspq0ynN4cyllkdVNUB0Q4HTkhoHvg/640?wx_fmt=png&from=appmsg)

而最新爆料的消息显示，这一功能已被重新命名并升级为 Security Center（安全中心），表明 Anthropic 正试图构建一个更全面、更可视化的安全管理体系，而非仅仅局限于自动修补。

## 让开发安全“可视”且“可控”

根据最新披露的信息，即将推出的 Security Center 将深度集成到 Claude Code，为开发者提供一个统一的界面。

主要功能包括：

1. 全局安全概览：用户可以在一个界面中查看最近的安全扫描记录，以及跨多个代码仓库（Repositories）检测到的问题目录。

   ![](https://mmbiz.qpic.cn/sz_mmbiz_png/aYef9qMYLnIu92fg9PUzL7lsatOCf5UtwhqnyJJl3rPAwpG1eTsnibyTtNWFq7muJxTWwTeJ7wcFFdWwDdcYprA/640?wx_fmt=png&from=appmsg)
2. 手动扫描控制：不同于之前被曝光的的自动检测，新功能允许用户手动选择特定的仓库和分支发起扫描。为开发者提供了更精细的控制权，特别是在合并关键代码或发布版本前进行针对性检查。 这一功能有望显著缩短从“发现漏洞”到“修复漏洞”的时间。

   ![](https://mmbiz.qpic.cn/sz_mmbiz_png/aYef9qMYLnIu92fg9PUzL7lsatOCf5UtELNMLVDib8lZfBASZxHN87Iy2S5uJ7RboM15vdEbgBxQ3ZtOiaXQvicsw/640?wx_fmt=png&from=appmsg)

虽然 Anthropic 尚未向所有用户开放此功能，但这被视为满足企业级开发需求的关键一步。值得注意的是，**OpenAI 奥特曼近期也多次强调了对网络安全的重新关注，且其竞品 Codex 也在酝酿相关的升级**。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/aYef9qMYLnIu92fg9PUzL7lsatOCf5UtZ6QquvR20m3c4cr7yg4x4PWDgFwaFCEk9A7geXqTlX6XgHqU5V7xiaw/640?wx_fmt=png&from=appmsg)

Anthropic 此举显然是为了在日益激烈的Vibe Coding市场中，通过提高代码安全来巩固其企业级AI地位。

## 点评

Anthropic 推出 Security Center 对开发行业是一个非常积极的信号。它将“安全”从一个幕后的黑盒流程，变成了一个开发人员可交互、可管理的显性功能。对于企业用户来说，这意味着不仅能利用 Claude 提高编码效率，还能通过集中化的面板管控合规风险。

但是对于传统应用安全团队而言，确实面临转型大考。
