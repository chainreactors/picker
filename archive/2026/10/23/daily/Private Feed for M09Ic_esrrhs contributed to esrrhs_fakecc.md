## Summary

* Fuzz workflow job `libFuzzer · fuzz_differential (macOS arm64)` crashed after the PR [chore: remove .trae specs; make bench README English-primary #98](https://github.com/esrrhs/fakecc/pull/98) merge (run [39774199904](https://github.com/esrrhs/fakecc/actions/runs/39774199904)) with UBSAN then ASan SEGV in `lower_expr` at `src/ir.c:6049` — load of poisoned `Expr*` (`0xbebebebebebebebe`).
* Root cause: `__sync_bool_compare_and_swap` / `__sync_val_compare_and_swap` IR lowering always read `args.data[1]` and `args.data[2]`, while sema only required `args.len >= 1`. A two-argument call (fuzz crash unit `crash-bf20718254bfb09cebe661bb46db280e01c37aa4`) therefore walked a missing/poisoned child.
* Fix: reject under-arity `__sync_*` builtins in sema (CAS needs 3; most others need 2; `lock_release` stays pointer-only), and add the same defensive `args.len` guards in IR that `__atomic_compare_exchange*` already had. Add `test_die_at` cases for the fuzz shape.
