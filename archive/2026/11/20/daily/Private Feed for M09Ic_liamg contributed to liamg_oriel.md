Fixes the failures on main's recent CI and scheduled race runs.

* **Data races (scheduled race run, ~30 tests):** tests set `Scene.Now` while work off the loop (the reviews poll, say) read it through the scene's clock. The clock is now read and set under a lock: `s.Now()` and `s.SetNow(t)`; every caller is updated, tagged files included.
* **`TestExplorerScrolls` (macOS):** the wheel came before the tree had loaded, so the frame showed an empty explorer. It waits for the tree first.
* **`TestSigningAsksForASecurityKeyTouch` (macOS, 10m timeout):** the key ask comes after `KeyWait` whatever git is doing, so the touch could come before the signing program opened its pipe; a non-blocking open then did nothing and the program waited forever. The test's touch now waits for the reader; the cleanup's stays non-blocking.

Checked: every build tag compiles; the failing packages pass under `-race`; the key-touch tests pass 20 times in a row; `./tools/...` passes.
