# New Release: Tor Browser 15.0.11

by [ma1](/author/ma1)
| April 28, 2026

![](/new-release-tor-browser-15011/lead.png)

Tor Browser 15.0.11 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.11/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.10 is:

* All Platforms
  + Updated NoScript to 13.6.18.1984
  + [Bug tor-browser#44907](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44907): Rebase Tor Browser onto 140.10.1esr
* Windows + macOS + Linux
  + Updated Firefox to 140.10.1esr
* Android
  + Updated GeckoView to 140.10.1esr
