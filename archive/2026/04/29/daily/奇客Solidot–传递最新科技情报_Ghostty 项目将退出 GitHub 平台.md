## Ghostty 项目将退出 GitHub 平台

[![开发者](https://icon.solidot.org/images/topics/topicdevelopers.png?123)](/search?tid=11 "开发者")

[Edwards](/~Edwards) (42866)发表于 2026年04月29日 14时52分 星期三 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=84179&appkey=1370085986&title=Ghostty%20%E9%A1%B9%E7%9B%AE%E5%B0%86%E9%80%80%E5%87%BA%20GitHub%20%E5%B9%B3%E5%8F%B0 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自诺比与错乱的时间线**

终端模拟器项目 Ghostty 宣布将退出 GitHub 平台，原因是在微软治理下 GitHub 越来越不稳定，严重扰乱开发者的工作。开发者称，过去一个月 GitHub 几乎天天宕机。GitHub 是工作的平台，如果每天都要宕机数小时那么它不再是一个可以工作的地方。Ghostty 项目将在未来几个月公布迁移细节，GitHub 上的项目将成为一个只读镜像。
https://github.com/ghostty-org/ghostty
https://mitchellh.com/writing/ghostty-leaving-github
