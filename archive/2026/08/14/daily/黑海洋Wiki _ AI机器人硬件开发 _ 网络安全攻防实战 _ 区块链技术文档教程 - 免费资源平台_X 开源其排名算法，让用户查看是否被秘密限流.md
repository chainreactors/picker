# X 开源其排名算法，让用户查看是否被秘密限流

发布时间:
2026-08-14 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
2468

X 正在大幅扩展其开源代码库，其中包括该应用的“为你推荐”算法及其核心排名引擎，并增加了一项功能，让用户查看其账户或帖子是否受到其排名系统的影响。公司正在 GitHub 上以 Apache v2 许可证提供“为你推荐”时间线的源代码。

此外，X 正在提供工具，让用户亲自查看其排名系统是否以及如何影响了他们的账户或帖子。一个新的透明度工具正在应用设置中的“Under the Hood”页面推出，让在过去一个月内发布了 10 次或更多内容的用户下载其汇总统计数据的 JSON 文件。该文件将显示在过去的一个日历月内，是否有某些标签应用于他们的账户或帖子。
