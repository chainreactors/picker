区块链情报公司 Chainalysis 表示，最近对其系统和内部工具的攻击导致所有客户的凭证和实时代币泄露。

Chainalysis 提供区块链分析工具，用于追踪加密货币交易并调查欺诈、勒索软件和洗钱等犯罪活动。其客户包括全球各地的执法机构、政府机构、金融机构、保险公司和加密货币企业。

此前，该公司上周五披露，攻击者使用人工智能工具，通过其所谓的“攻击性代理技术”获取了客户的姓名、电子邮件地址、用户 ID 和组织角色标签。

虽然最初表示影响有限，此次泄露仅影响了非敏感身份元数据，但后来的更新显示，所有客户的用户名和密码哈希值都在“路径攻击”（更常见的名称是中间人攻击或 MITM 攻击）中被泄露。

然而，该公司并未发现任何证据表明攻击者访问了调查图数据或篡改了其区块链归因存储库。

Chainalysis在周三发布的最新消息中表示： “周一，我们发现所有Chainalysis用户的某些客户信息，包括姓名、用户名、密码哈希值和实时令牌，已被恶意攻击者获取。 目前，我们仍未发现任何调查数据被访问或Chainalysis归因数据被篡改的证据。”

虽然该公司在发现一些客户的密码泄露后，出于谨慎起见锁定了 Chainalysis 帐户，并要求用户在重新登录之前重置密码，但在发现进一步的异常活动后，该公司已将登录门户网站以及 Reactor 和数据解决方案、了解你的交易 (KYT) 用户界面和 API 以及地址筛选产品下线。

为了确保攻击者无法访问受影响的帐户，Chainalysis 要求客户提供可信的 IP 地址，以便他们在登录门户恢复上线后能够重新获得访问权限并重置其凭据。

声明补充道：请联系 support@chainalysis.com 或您的 Chainalysis 客户团队，提供您信任的 IP 地址以添加到我们的允许列表中。之后，我们将允许用户重置密码并轮换 API 密钥以注册交易。我们正在夜以继日地加固系统，并尽快恢复 Reactor 和数据解决方案的在线运行。我们将要求用户采取额外的安全措施来访问账户，包括每个用户都必须根据需要重置密码并轮换 API 密钥。

该公司今天早些时候指出：“一旦获得访问权限，所有用户在注册交易之前，都必须重置密码并轮换 API 密钥（如适用）。”

Chainalysis的披露是继近几周其他几起影响加密货币公司的安全事件之后发生的。上个月，Ledger也要求亚洲的经销商和分销商将产品下架，并暂停钱包销售，同时该公司正在调查多起硬件植入事件。

最近，加密货币交易所币安透露，朝鲜黑客在一次虚假的求职面试中，通过向一名员工的笔记本电脑植入恶意软件，入侵了币安的钱包基础设施，窃取了价值约 63.4 亿美元的加密货币。
