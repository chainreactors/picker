## Summary

* Add a FakeCC port of the Genann neural network library under `test/app_ports/genann/`
* Add a unified app-ports runner (`test/app_ports/run_all.sh`) and wire it into CMake ctest + bootstrap CI (`misc` suite, `-O0`/`-O1`)
* Adapt Genann for FakeCC (`package`/`import runtime`, link `-lc -lm`); `genann_read` uses `strtod` because FakeCC lacks `fscanf %le`, with full-token validation

This lands the first app port and a foundation for more. The test suite is based on upstream Genann coverage (basic/xor/backprop/train/copy/persist/sigmoid) plus adapted relu/tanh training cases — not a verbatim copy of upstream `test.c`.
