## 微软 Copilot 在修改 PR 中的拼写错误时添加了广告

[![微软](https://icon.solidot.org/images/topics/topicMicrosoft.png?123)](/search?tid=150 "微软")

[Wilson](/~Wilson) (42865)发表于 2026年03月30日 20时15分 星期一 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83918&appkey=1370085986&title=%E5%BE%AE%E8%BD%AF%20Copilot%20%E5%9C%A8%E4%BF%AE%E6%94%B9%20PR%20%E4%B8%AD%E7%9A%84%E6%8B%BC%E5%86%99%E9%94%99%E8%AF%AF%E6%97%B6%E6%B7%BB%E5%8A%A0%E4%BA%86%E5%B9%BF%E5%91%8A "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自星火**

开发者发现，使用微软 AI 助手 Copilot 修改 PR 中的拼写错误时它主动添加了一则广告。对 GitHub 平台的搜索发现，已经有数以万计的 PR 包含了相同的广告——“Quickly spin up Copilot coding agent tasks from anywhere on your macOS or Windows machine with Raycast”。开发者认为微软此举无法让人接受。
https://notes.zachmanson.com/copilot-edited-an-ad-into-my-pr/
https://github.com/search?q=%22%E2%9A%A1+Quickly+spin+up+copilot+coding+tasks%22&type=pullrequests
