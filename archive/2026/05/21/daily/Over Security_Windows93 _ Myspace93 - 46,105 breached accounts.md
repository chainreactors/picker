# Windows93 / Myspace93 Data Breach

## What Happened

In January 2021, the parody site [Windows93 suffered a data breach of the Myspace93 sub-site](https://web.archive.org/web/20210704163048/https%3A//www.windows93.net/dearCommunity.txt) after a beta application was exploited to download server files. The compromised data was later leaked in June and included 46k Myspace93 accounts containing email and IP addresses, usernames and passwords stored in plain text.
