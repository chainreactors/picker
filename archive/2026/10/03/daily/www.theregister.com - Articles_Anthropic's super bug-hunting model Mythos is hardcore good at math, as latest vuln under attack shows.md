The second Anthropic-linked vulnerability known to have been exploited in the wild saw initial activity from an IP address in China targeting vulnerable hosts in the US and Japan.

The vuln is a critical authentication-bypass bug in Rejetto HTTP File Server (HFS) that can lead to full admin access and remote code execution. HFS is an open source web file server that previously appeared on the US Cybersecurity and Infrastructure Security Agency’s catalog of [Known Exploited Vulnerabilities](https://www.cisa.gov/known-exploited-vulnerabilities-catalog?search=rejetto&field_date_added_wrapper=all&field_cve=&sort_by=field_date_added&items_per_page=20&url=) in 2024.

On Wednesday, researcher Zach Hanley at AI pen-testing company Horizon3 said he used Mythos to [uncover a new flaw in the file server](https://horizon3.ai/attack-research/disclosures/anthropic-mythos-rejetto-hfs-rce/), now tracked as CVE-2026-61500. If you use Rejetto HFS, be sure to update to [v3.2.1](https://github.com/rejetto/hfs/releases/tag/v3.2.1) or later, which fixes this and other security flaws.

Hanley also [published a video](https://vimeo.com/1231352419?fl=pl&fe=vl) showing the steps to exploit HFS and remotely execute code on the server.

REG AD

By the next day, the CVE was under exploitation.

“We started detecting exploitation of CVE-2026-61500 in Rejetto HFS this evening,” VulnCheck security researcher Patrick Garrity [posted](https://www.linkedin.com/feed/update/urn%3Ali%3Aactivity%3A7511590230232256513/) on LinkedIn on Thursday, adding that Hanley and team reported the bug to VulnCheck for CVE assignment.

“Our canaries detected an actor in China targeting real vulnerable hosts in the US,” Garrity added.

Garrity has been[tracking CVEs](https://www.theregister.com/security/2026/04/15/anthropics-project-glasswing-cve-count-is-still-guesswork/5220505) attributed to Mythos and Project Glasswing, Anthropic’s initiative to give select partners access to the bug-hunting model, since shortly after [the program](https://www.theregister.com/security/2026/04/08/anthropic-mythos-model-can-find-and-exploit-0-days/5224393) was announced in April. Anthropic claims that Mythos is too powerful to release to the general public (insert evil laugh).

As of Friday, Mythos and Project Glasswing have [uncovered 286 CVEs](https://github.com/patrickmgarrity/Anthropic-Credited-CVEs), according to Garrity’s tracker, and up until Thursday [only one of these bugs](https://www.theregister.com/security/2026/09/21/anthropic-linked-cves-pile-up-attackers-mostly-shrug/5298018) had been exploited in real-world attacks.

The Thursday night activity originated from one IP address in China and targeted vulnerable servers in the US and Japan, Garrity told The Register.
