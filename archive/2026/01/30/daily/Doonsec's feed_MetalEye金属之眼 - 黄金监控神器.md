#### 固定价格提醒

* **价格大于**：突破关键阻力位
* **价格小于**：跌破重要支撑位

#### 相对涨跌幅提醒 🔥

* **上涨X%提醒**：捕捉上涨机会
* **下跌X%提醒**：及时止损预警
* 基准价格自动记录


## 🎛️ 控制面板

### 价格规则管理

![](https://mmbiz.qpic.cn/sz_mmbiz_png/YqguuzCS2ibvhUtZnMIhrX75ibp9Q1KoSSKxtBubcib00Br1jBaXRF7bryWkj2TF4pvZSW0fWo1tpOmOgKHBtrwLQ/640?wx_fmt=png&from=appmsg)

###

**4种规则类型**：

1. **价格大于** - 突破阻力位提醒

   ```
   例如：人民币黄金 > 1150.0000 时推送
   ```
2. **价格小于** - 跌破支撑位提醒

   ```
   例如：人民币黄金 < 1080.0000 时推送
   ```
3. **上涨百分比** - 捕捉上涨机会

   ```
   例如：相对于基准价上涨2%时推送
   基准价1100，目标1122，涨至1122时通知
   ```
4. **下跌百分比** - 及时止损预警

   ```
   例如：相对于基准价下跌2%时推送
   基准价1100，目标1078，跌至1078时通知
   ```

**智能防重复**：

* 触发一次后不重复推送
* 价格恢复后自动重置
* 可再次触发

### 定期提醒设置

**2种提醒模式**：

1. **每天固定时间**

   ```
   每天 9:00  → 早盘开市前查看
   每天 21:00 → 收盘后总结
   ```
2. **间隔时间提醒**

   ```
   每2小时  → 高频监控
   每4小时  → 常规监控
   每8小时  → 定期关注
   ```

**推送内容**：

* 所选金属的当天最高价
* 当天最低价
* 价格波动幅度
