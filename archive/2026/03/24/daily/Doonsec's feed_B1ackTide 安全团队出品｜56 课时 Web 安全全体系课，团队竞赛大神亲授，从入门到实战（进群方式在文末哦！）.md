## 56 课时全链路覆盖，一套课打通 Web 安全攻防全路径

这套课程全程共计 56 课时，分为 Web 基础与 Web 进阶两大阶段，完整覆盖网安人才成长的全流程，不管你是纯零基础的新人，还是有一定基础想突破瓶颈的从业者，都能找到适配的学习内容。

基础阶段，我们将从 Web 安全最核心的底层逻辑讲起，先带你完整拆解 Web 通信全流程、核心网络协议，深度剖析 HTTP 请求的每一个细节，掌握基础的绕过技巧与 cookie/session 机制；再完整覆盖 OWASP TOP10 全漏洞体系，从 SQL 注入、XSS&CSRF 跨站攻防，到文件操作漏洞、服务端漏洞、身份验证与访问控制、业务逻辑漏洞，每一个核心漏洞，我们都会从 “原理成因 - 利用方式 - 绕过技巧 - 防护策略” 全流程拆解，配套对应的实战演示，让你学完就能独立完成常规 Web 漏洞的挖掘、测试与利用。

进阶阶段，我们将直击行业实战核心需求，带你进入真正的攻防对抗世界。课程内容围绕护网行动、攻防演练、国家级赛事的核心能力要求设计，从内网渗透全攻击链搭建开始，手把手教你主机探测、信息收集、凭证获取、横向移动、权限提升、域环境利用，完整还原从外网打点到内网全域控制的全流程；同时覆盖云攻防基础、隐蔽免杀对抗、权限维持、代码审计等高阶技能，彻底解决你 “会挖漏洞却打不进内网、懂基础却冲不动赛事” 的成长瓶颈。
