# Thunderbird新增原生支持，实现对Microsoft Exchange账户的全面兼容

Thunderbird 145 版本已发布，通过 **Exchange Web Services (EWS) 协议** 提供对 Microsoft Exchange 邮件的 **完整原生支持**。

这意味着在 Microsoft Exchange 环境（如 Microsoft 365、Office 365）中的 Thunderbird 用户 **不再需要第三方插件**，并可受益于本地和服务器上的无缝消息同步与文件夹管理。

从 Outlook 迁移到 Thunderbird 也更加容易，因为 Mozilla 的邮件客户端会自动检测设置并使用 Microsoft 的 **OAuth2 授权协议**。

“在此之前，Exchange 托管环境中的 Thunderbird 用户通常依赖 IMAP/POP 协议或第三方扩展，” Thunderbird 的公告中写道。

“通过对邮件的完整原生 Exchange 支持，Thunderbird 现在在 Exchange 环境中工作更无缝，包括完整的文件夹列表、消息同步、本地和服务器上的文件夹管理、附件处理等。”

Thunderbird 是由 Mozilla 开发的免费开源邮件应用，而 Microsoft Exchange 是企业广泛使用的邮件和协作服务器，用于处理通信、日历和联系人。

通常，组织要么使用 Outlook 作为邮件客户端连接到 Exchange 服务器或 Microsoft 365 云服务。但是，任何支持 EWS 的应用（现在包括 Thunderbird）都可以连接到它。

要从 Outlook 迁移到 Thunderbird，用户必须在 145 或更高版本的邮件客户端中添加账户，前往 **账户中心 > Exchange/Exchange Web Services**，然后让应用程序引导完成其余过程。

![]()

### 目前支持的功能

1. Exchange 邮件设置和文件夹访问
2. 查看、发送、回复/转发、移动/复制/删除消息
3. 附件（保存、显示、分离/删除）
4. 搜索（主题、正文）和快速筛选
5. 使用标准 OAuth2 的 Microsoft 365 域
6. 具有基本密码身份验证的本地 Exchange

### 未来计划支持的功能

Thunderbird 开发团队还计划添加以下支持：

1. 日历同步
2. 地址簿/联系人
3. 需要完整消息内容的筛选器操作
4. 需要自定义 OAuth2 应用/租户 ID 的 Microsoft 365 域
5. 本地 NTLM 和 OAuth2 身份验证
6. Microsoft Graph 集成

目前尚未提供这些功能在 Thunderbird 上发布的具体时间线，各项功能的实施时间可能有所不同。

Mozilla 指出，EWS 仍被广泛使用，微软已承诺“在可预见的未来”继续支持它，尽管这家科技巨头正过渡到将 Microsoft Graph 接口作为连接到 Microsoft 365 服务的主要方法。

虽然计划支持 Microsoft Graph API，但 Thunderbird 团队认为 EWS 目前是满足更广泛用户群需求的优先事项。

有关 Thunderbird Exchange 支持的更多信息可在 维基页面 上获取，支持门户则提供了账户迁移指南。
