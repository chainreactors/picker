## Problem

A prompt containing `\r\n` renders with a large spurious indent before the typed input, but only when a prompt line is wider than the terminal.

Reproduced in [shiv](https://github.com/liamg/shiv), whose prompt uses CRLF throughout (`internal/shell/prompt/defaults.go`). With an 89-character cwd in an 80-column terminal, the renderer emitted:

```
ESC[0;36m❯ ESC[0mESC[JESC[13G
```

Column 13 on a row whose only content is `❯`  — 10 columns of dead space before the cursor.

## Cause

UAX #29 treats CR+LF as a single grapheme cluster, so `FromSpans` produced one cell with `Text == "\r\n"` and `Width == 0`:
