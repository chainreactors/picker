## Fedora Linux 45 释出

[![Redhat](https://icon.solidot.org/images/topics/topicredhat.png?123)](/search?tid=99 "Redhat")

[Edwards](/~Edwards) (42866)发表于 2026年11月04日 00时22分 星期三 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85786&appkey=1370085986&title=Fedora%20Linux%2045%20%E9%87%8A%E5%87%BA "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自诺比、龙和意识星云**

Fedora Linux 项目释出了 v45。Fedora Linux 项目同时释出了 Fedora Workstation、Fedora KDE Plasma Desktop、Fedora Server、Fedora Cloud、Fedora CoreOS 和 Fedora IoT，以及 Atomic Desktops 等众多衍生版本。Fedora Linux 45 的主要变化包括：支持通过 Anaconda 或 Kickstart 在 Stratis 存储上进行安装，移除 NetworkManager 不再维护的 VPN 插件，GNOME 和 KDE ​​Plasma 桌面环境的最新版本，完善 Wayland 支持，改进分数缩放，gcc 16.2、binutils 2.47、glibc 2.44、gdb 17.2、Fontconfig 2.18、LLVM 23 等开发工具的新版本。更多变化可浏览 ChangeSet。
https://fedoramagazine.org/announcing-fedora-linux-45/
https://fedoraproject.org/wiki/Releases/45/ChangeSet
