# HyperLoader

> Hypervisor isolated shellcode execution environment. Maps host process memory into a guest vCPU, intercepts DLL execute faults, and proxies API calls to the host, Stardust PIC shellcode compatible.

---

## Overview

HyperLoader executes position independent shellcode inside an isolated virtual CPU created with the **Windows Hypervisor Platform API (WHvP)**. The vCPU runs in its own address space.
