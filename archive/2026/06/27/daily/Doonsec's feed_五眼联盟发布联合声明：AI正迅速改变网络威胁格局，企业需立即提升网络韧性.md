###

澳大利亚、美国、英国、加拿大和新西兰组成的"五眼联盟"（Five Eyes）网络安全机构近日罕见发布联合声明，警告生成式人工智能正以前所未有的速度改变全球网络威胁形势，网络攻击能力的提升"不是几年后的问题，而是未来几个月内就将发生"。联盟呼吁企业管理层将网络安全视为核心经营风险，而非单纯的IT问题，并立即采取措施提升组织网络韧性。

声明指出，前沿AI模型正在显著提升漏洞挖掘、恶意代码生成、社会工程学攻击以及自动化攻击链构建能力，使原本需要高水平技术才能实施的攻击逐渐"平民化"。随着AI持续演进，攻击者发现、分析和利用漏洞的速度将不断加快，企业传统依赖边界防护和人工响应的安全策略将面临越来越大的挑战。

|  |
| --- |
| * 了解和评估风险、准备情况和责任 * 优先考虑基础网络安全实践和控制措施 * 赋予网络安全领导者权威和资源 * 随着威胁和指导方针的演变，保持积极参与。 |

五眼联盟建议各类组织尽快采取一系列基础安全措施，包括建立"安全默认（Secure by Design）"理念，加快漏洞修复和软件更新，淘汰缺乏安全支持的遗留系统，实施最小权限访问控制，减少互联网暴露面，并提前制定应急响应和业务连续性计划。声明强调，网络韧性已成为保障企业运营连续性、供应链安全及市场信任的重要组成部分。

|  |
| --- |
| 核心原则：   * 安全设计与安全默认必须成为标准做法，而不是一种愿望。 * 韧性不能依赖单一的解决方案或技术。纵深防御仍然至关重要。 * 随着人工智能系统的发展，新的、以前未知的漏洞将会出现，包括零日漏洞。   违规行为不可避免。做好准备有助于您快速控制违规行为，防止其升级为重大的运营和财务危机。 |

与此同时，联盟认为AI不仅是攻击者的新工具，也将成为网络防御的重要能力。各国网络安全机构鼓励企业积极利用AI辅助威胁检测、日志分析、漏洞管理和安全运营，以提高防御自动化水平和响应效率，在未来的人机攻防竞争中保持优势。

|  |
| --- |
| 实际行动 这些措施并非新举措，但现在迫在眉睫，不仅可以降低技术风险，还可以降低运营、财务和声誉风险：   1. **缩小攻击面：**限制不必要的系统访问和外部连接。仔细评估系统是否真的需要对外开放，并将不需要开放的系统隔离。 2. **加快补丁更新流程：**人工智能正在缩短漏洞发现到被利用之间的时间。补丁更新延迟会增加风险，尤其对于更新周期长的运营系统而言更是如此。因此，应根据风险控制情况，优先处理安全更新。 3. **解决遗留系统问题：**不受支持的系统很容易成为攻击目标。它们不仅是技术债务，更是战略隐患。 4. **审查并加强身份和访问控制：**限制关键系统的访问权限。强制执行强身份验证并定期审查权限。 5. **防患于未然：**测试应急预案，培训并做好准备团队，并假设安全漏洞将会发生。重点在于快速遏制和恢复。 |

这是五眼联盟首次以联合声明形式专门聚焦生成式AI带来的网络安全挑战。业内普遍认为，此举表明各国政府已将AI驱动的网络威胁提升至国家安全层面，并希望推动企业管理层尽快调整风险管理策略，以应对未来数月可能快速升级的AI网络攻击能力。
