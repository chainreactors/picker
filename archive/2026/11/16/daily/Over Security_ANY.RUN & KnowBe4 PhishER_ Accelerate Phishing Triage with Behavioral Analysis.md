ANY.RUN & KnowBe4 PhishER: Accelerate Phishing Triage with Behavioral Analysis

Every employee-reported suspicious email requires triage, but manually submitting messages for deeper analysis and transferring results between tools slows down SOC operations.

The new [**ANY.RUN integration for KnowBe4 PhishER**](https://support.knowbe4.com/hc/en-us/articles/55473471020691-Integrate-ANY-RUN-with-Your-PhishER-Console) automates the behavioral analysis stage of phishing triage by connecting PhishER with [ANY.RUN Interactive Sandbox](https://any.run/features/?utm_source=anyrunblog&utm_medium=article&utm_campaign=knowbe4-integration&utm_term=251126&utm_content=linktosblanding). Selected emails are automatically submitted for analysis, with verdicts returned directly to PhishER to reduce manual work and support faster, evidence-based decisions.

## About the ANY.RUN Sandbox Integration for KnowBe4 PhishER

KnowBe4 PhishER helps security teams manage suspicious emails reported by employees through configurable Rules, Actions, and automated classification workflows.

![](https://any.run/cybersecurity-blog/wp-content/uploads/2026/11/image-1024x505.jpg)

*Suspicious email in PhishER tagged with ANYRUN\_REQUEST for Sandbox analysis*

The new self-hosted ANY.RUN integration extends this process with behavioral analysis, allowing organizations to:

* **Automate Suspicious Email Analysis:** Automatically submit flagged emails from PhishER to ANY.RUN Sandbox, eliminating manual transfers and repetitive analysis setup.

* **Get Actionable Threat Verdicts:** Receive MALICIOUS, SUSPICIOUS, or CLEAN verdicts directly in PhishER to quickly determine which emails need further investigation.

* **Detect Hidden Phishing and Malware Threats:** Use behavioral analysis to uncover malicious activity in suspicious attachments and links that requires deeper validation.

* **Trigger Faster Phishing Response:** Use Sandbox verdicts in PhishER Rules and Actions to route malicious emails for response and suspicious cases for further review.

* **Investigate Complex Threats in Depth:** Open the linked Sandbox analysis to examine attack behavior, malicious infrastructure, and IOCs when a case requires deeper investigation or escalation.

For deployment and configuration instructions, see the [official KnowBe4 integration guide](https://support.knowbe4.com/hc/en-us/articles/55473471020691-Integrate-ANY-RUN-with-Your-PhishER-Console).

Streamline triage and cut response time inside your KnowBe4 environment.

Slash MTTR. Eliminate console switching. Reduce exposure.

[Integrate ANY.RUN](https://any.run/enterprise/?utm_source=anyrunblog&utm_medium=article&utm_campaign=knowbe4-integration&utm_term=251126&utm_content=linktoenterprise#contact-sales)

The integration checks PhishER for matching messages at a configurable interval, set to five minutes by default. It then queues selected emails for analysis and returns the results once the Sandbox task is completed.

![](https://any.run/cybersecurity-blog/wp-content/uploads/2026/11/image-4.png)

*Direct link to the ANY.RUN Sandbox analysis in the PhishER Discussion tab*

**Organizations can also integrate ANY.RUN into their existing PhishER workflows.** By default, the integration processes emails tagged ANYRUN\_REQUEST, but teams can configure it to recognize their existing tags or apply additional filtering criteria. This allows them to add automated Sandbox analysis to established phishing triage processes while keeping their current Rules and Actions.

![](https://any.run/cybersecurity-blog/wp-content/uploads/2026/11/image2.png)

*Malicious verdict automatically returned to PhishER through ANYRUN\_MALICIOUS and ANYRUN\_SCANNED tags*

This keeps phishing triage and workflow automation in PhishER, while ANY.RUN provides the behavioral evidence needed to evaluate suspicious messages.
