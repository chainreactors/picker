## Kimi 向科学家提供最高 2 万美元 API 免费额度

[Edwards](/~Edwards) (42866)发表于 2026年11月28日 00时14分 星期六 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=86015&appkey=1370085986&title=Kimi%20%E5%90%91%E7%A7%91%E5%AD%A6%E5%AE%B6%E6%8F%90%E4%BE%9B%E6%9C%80%E9%AB%98%202%20%E4%B8%87%E7%BE%8E%E5%85%83%20API%20%E5%85%8D%E8%B4%B9%E9%A2%9D%E5%BA%A6 "新浪微博分享")

**来自飞行村**

Kimi 大模型开发商月之暗面宣布了 Kimi for Science 项目，欢迎自然科学、工程学及相关交叉学科领域的研究人员加入。月之暗面表示，“科学始终源于人类的好奇心、严谨的探索精神，以及对未知世界的不懈追求。一个有价值的科学假设，往往需要经过大量的文献调研、数据分析和反复验证。而一次意料之外的发现，也可能成为下一项重大突破的起点。然而受限于时间、算力与人力资源，许多值得深入探索的想法，始终未能获得应有的关注与投入。我们相信 AI 能加速科学研究，拓展探索与发现的边界，帮助研究者突破时间、资源与研究方法的局限，让更多大胆而富有想象力的科学构想从可能走向现实。”月之暗面将向入选的研究人员提供最高 20,000 美元的 Kimi API 额度（约 70 亿 token），具体金额将根据研究需求及评估结果确定。
