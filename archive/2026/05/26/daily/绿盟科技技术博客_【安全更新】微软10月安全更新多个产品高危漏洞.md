| **版本：** | **1.0** |

### **1** **漏洞概述**

10月15日，绿盟科技CERT监测到微软发布10月安全更新补丁，修复了175个安全问题，涉及Windows、Microsoft Office、Azure、Apps、Microsoft Exchange Server、Microsoft Visual Studio等广泛使用的产品，其中包括权限提升、远程代码执行等高危漏洞类型。

本月微软月度更新修复的漏洞中，严重程度为关键（Critical）的漏洞有15个，重要（Important）漏洞有158个，中危（Moderate）漏洞有2个。其中包括3个0day漏洞：

Windows Agere Modem Driver权限提升漏洞（CVE-2025-24990）

Windows Remote Access Connection Manager权限提升漏洞（CVE-2025-59230）

Windows Agere Modem Driver权限提升漏洞（CVE-2025-24052）

请相关用户尽快更新补丁进行防护，完整漏洞列表请参考附录。

参考链接：

https://msrc.microsoft.com/update-guide/en-us/releaseNote/2025-Oct

### **2** **重点漏洞简述**

根据产品流行度和漏洞重要性筛选出此次更新中包含影响较大的漏洞，请相关用户重点进行关注：

**Windows Agere Modem Driver权限提升漏洞（CVE-2025-24052/CVE-2025-24990）：**

Windows Agere Modem Driver中存在缓冲区溢出漏洞，由于Agere调制解调器驱动程序（ltmdm64.sys）对用户态指针校验不足，经过身份验证的本地攻击者可在内核态操控内存从而提升为系统管理员权限。CVSS评分7.8，其中CVE-2025-24990已存在在野利用。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-24052

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-24990

**Windows Remote Access Connection Manager权限提升漏洞（CVE-2025-59230）:**

Windows Remote Access Connection Manager中存在权限提升漏洞，由于系统不正确的访问控制，经过身份验证的本地攻击者可将权限提升到 SYSTEM。该漏洞已存在在野利用，CVSS评分7.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-59230

**Windows Server Update Services远程代码执行漏洞（CVE-2025-59287）:**

Windows Server Update Services中存在远程代码执行漏洞，由于WSUS的反序列化问题，未经身份验证的攻击者可通过发送特制事件反序列化不受信任的数据，从而在目标服务器上执行任意代码。CVSS评分9.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-59287

**Microsoft Office远程代码执行漏洞（CVE-2025-59227）:**

Microsoft Office中存在远程代码执行漏洞，由于在处理特制文档时的释放后重用（use-after-free）问题，攻击者可通过制作恶意的文件诱使用户打开或预览窗格，从而在用户上下文中执行任意代码。CVSS评分7.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-59227

**Microsoft Excel远程代码执行漏洞（CVE-2025-59236）:**

Microsoft Excel中存在远程代码执行漏洞，由于Excel的释放后重用（use-after-free）缺陷，未经身份验证的攻击者可以通过制作恶意的文件诱使用户打开，从而在受害者主机上执行任意代码。CVSS评分8.4。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-59236

**Azure Entra ID权限提升漏洞（CVE-2025-59246）:**

Azure Entra ID中存在权限提升漏洞，由于Azure Entra ID在部分服务接口的身份验证缺陷，攻击者在特定条件下可在目标租户中获取高于分配的角色权限，从而执行创建/修改用户、变更应用或配置等敏感操作。CVSS评分9.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-59246

**Microsoft Exchange Server权限提升漏洞（CVE-2025-59249）:**

Microsoft Exchange Server中存在权限提升漏洞，由于Exchange Server的身份验证机制薄弱，具有普通用户权限的攻击者可以通过网络提升提升系统权限。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-59249

**Windows远程桌面客户端远程代码执行漏洞（CVE-2025-58718）:**

Windows远程桌面客户端中存在远程代码执行漏洞，由于远程桌面客户端的释放后重用（use-after-free）内存错误，未经身份验证的攻击者可通过特制网络请求触发远程代码执行。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-58718
