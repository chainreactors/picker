## 一、文档说明

本文档系统整理了当前主流 AI Agent 桌面版产品，按 **大厂办公智能体**、**编程开发智能体**、**开源/本地优先智能体** 三大类别划分，涵盖产品定位、核心功能、开发商及官方获取方式，便于选型与下载。

## 二、大厂办公智能体

此类产品面向日常办公场景，由国内互联网大厂推出，通常具备跨应用任务执行、本地文件操作、多 Agent 协作等能力。

### 2.1 WorkBuddy（腾讯）

**开发商**：腾讯
**产品定位**：AI 智能体桌面工作台，中文俗称“小龙虾”
**上线时间**：2026 年 3 月 9 日正式公测

**核心功能**：

* **人机双写**：用户可与 WorkBuddy 同时编辑同一份文档（Word、Excel、PowerPoint 或腾讯文档），选中内容后以自然语言说明修改要求，AI 直接在文件内完成修改，无需复制粘贴。-1
* **独立文件浏览器**：2026 年 10 月上线，用户在电脑中右键任意 Word、PDF、Markdown 等文件即可调用 WorkBuddy，文件在左、AI 在右，当前文件自动成为对话上下文。
* **跨应用连接**：通过内置连接器或 MCP 协议接入 Canva、GitHub、Notion、Morningstar 等服务，可跨工具汇总信息并完成任务。-1
* **技能生态**：内置超 20 种 Skills 技能包与 MCP，原生兼容 OpenClaw Skills 生态，支持多 Agents 并行执行。
* **安全审计**：具备企业级安全审计能力，从数据处理到任务执行全程保障信息安全。

**下载方式**：

* 官网：https://www.workbuddy.cn
* 团队官网（CodeBuddy 同底座）：https://www.codebuddy.cn

**系统要求**：Windows / macOS

### 2.2 百度搭子 DuMate（百度）

**开发商**：百度
**产品定位**：专业办公智能体平台，面向个人和企业办公场景
**核心定位**：跨应用、跨文件的复杂任务连续执行

**核心功能**：

* **文件智能管理**：将杂乱文件夹自动转化为有序知识库，支持智能分类归档、批量格式转换（Word/Excel/PPT ↔ PDF）、关键信息提取。-11
* **数据分析与报告**：自动数据清洗、多表关联分析、智能报告生成，从原始数据到精美报告一键完成。-11
* **自动化流程**：跨应用自动化、定时任务调度、操作录制回放，将重复操作流程化标准化。-11
* **Harness 智能引擎**：将需求理解、任务规划、工具调用、运行环境、记忆与执行反馈连成一条链路，确保长时任务执行路径不偏离。
* **场景套件**：内置自媒体、金融、教学、设计四套专业场景套件；企业版发布 15 个套件、96 个 Skills，覆盖金融财务、商务法务等领域。
* **远程控制**：支持移动端远程遥控 PC 下发任务，对话记录多端同步。

**下载方式**：

* 官网：https://www.dumate.cn
* 下载页：https://www.dumate.cn/download

**系统要求**：Windows / macOS / 移动端 App

**市场表现**：2026 年 7 月 AI 办公桌面端月活数据，WorkBuddy 与百度搭子合计约占整体市场的六成。

### 2.3 QoderWork（阿里巴巴）

**开发商**：阿里巴巴（阿里云 Qoder 团队）
**产品定位**：桌面端本地 AI 智能体，“AI 实习生”定位
**开放时间**：2026 年 3 月 3 日全面开放，提供 Mac 和 Windows 两个版本

**核心功能**：

* **四大核心优势**：本地沙箱执行、完整任务自动化、多 Agent 团队、岗位专家套件。
* **本地文件全自动化**：文件整理、数据清洗分析、文档批量生成、办公自动化，可直接在用户本地电脑环境执行。
* **多格式文档生成**：一句话指令即可生成文档、表格、图表与幻灯片，支持全格式专业文档一键生成。
* **照片管理**：按时间、地点、主题自动分类整理本地照片。
* **模型分级选择**：集成全球顶尖模型与 Agent 框架，提供模型分级选择器。
* **可视化监控**：自主任务规划与可视化监控，实时反馈任务进展。

**下载方式**：

* 官网：https://qoder.com.cn/qoderwork

**系统要求**：Windows / macOS

### 2.4 扣子 Coze（字节跳动）

**开发商**：字节跳动
**产品定位**：通用工作智能体，桌面端让 Agent 从网页走进电脑

* **本地文件处理**：桌面端可直接连接电脑，在获得授权后读取、整理和修改本地文件，执行本地 Shell 任务。
* **深度截图**：全局快捷键触发，自动将画面传入对话框并附带界面结构和文本信息，无需复制粘贴。
* **跨端同步与远程控制**：手机 App 可远程遥控处理本地电脑文件，跨端内容实时同步，持续推进项目。
* **多项目独立管理**：支持自定义 Agent 一键接入，精品模板快速创建专家 Agent。
* **技能与插件**：覆盖自媒体、编程、视频等行业的技能库，支持 OpenClaw、Claude Code 一键接入。

**下载方式**：

* 官网：https://www.coze.cn
* 文档：https://docs.coze.cn（含桌面端快速上手教程）

**系统要求**：Windows / macOS / 移动端 App

**开发商**：月之暗面（Moonshot AI）
**产品定位**：知识工作者桌面客户端，本地 AI Agent

* **300 Agent 集群**：支持 300 个 Agent 并行执行与多格式输出。
* **本地文件管理**：搜索、分析、摘要并整理 Windows 电脑上的文件，快速提取有用信息。
* **浏览器自动化**：由 Kimi WebBridge 支持的浏览器自动化与网络研究。
* **原生数据库对接**：原生对接金融与学术数据库。
* **自定义 Dashboard**：通过对话创建和调整个性化 Widget，固定到 AI Dashboard 或桌面。
* **定时任务自动化**：全天候定时任务自动化。

**下载方式**：

* 官网：https://www.kimi.com

**系统要求**：Windows / macOS

## 三、编程开发智能体

此类 Agent 专注于软件开发场景，能够读取代码库、自动修改代码、执行命令、管理多 Agent 协作等。

### 3.1 Codex App（OpenAI）

**开发商**：OpenAI
**产品定位**：专为管理多个编码智能体设计的“指挥中心”，非传统 IDE
**平台**：macOS（2026 年 2 月首发）、Windows（2026 年 3 月更新支持）

**核心功能**：

* **多 Agent 并行管理**：每个智能体在按项目整理的独立执行线程中运行，支持在不同任务间顺畅切换而不丢失上下文。
* **工作树隔离**：多个智能体可在同一代码库中同时工作，每个智能体在隔离的代码副本上运行，避免冲突。
* **技能库**：内置 OpenAI 内部广泛使用的工具与工作流程，包括从 Figma 提取设计情境、使用 GPT 图像生成技能、PDF/DOCX 文件读写等。
* **Record & Replay**：录制一次桌面操作，AI 自动整理为可检查、可编辑、可重复调用的 Skill（需 macOS 并启用 Computer Use）。
* **记忆功能**：记录用户偏好设置、历史修正内容及会话上下文，优化后续任务执行。
* **外部工具集成**：集成 Slack、Google Workspace 等，融入工作流程。
* **Mac 端 Appshots**：连续按下 Command 快捷键即可将当前应用窗口关联至 Codex 对话界面，同步截取画面与文本内容。
* **ChatGPT 整合**：桌面版更新后整合 Chat、ChatGPT Work 和 Codex 三个组成部分，保留现有 Codex 任务和项目。

**下载方式**：

* 官方入口：https://chatgpt.com/codex/get-started
* Windows 用户可通过 Microsoft Store 获取

**订阅要求**：ChatGPT 免费版及 Go 方案限时包含 Codex；Plus、Pro、Business、Enterprise 及 Edu 方案提供 2 倍速率限额。

### 3.2 Claude Code Desktop（Anthropic）

**开发商**：Anthropic
**产品定位**：具有图形界面的完整 Claude Code，专为同时运行多个会话设计
**平台**：macOS / Windows / Linux（Linux 通过 apt 安装）

**核心功能**：

* **三个选项卡**：Chat（无文件访问权限的常规对话）、Cowork（自主后台代理，独立处理任务）、Code（交互式编码助手，直接访问本地文件）。
* **并行会话与 Git 隔离**：通过自动生成的 Git Worktree 技术，在同一代码仓库中同时开启多个独立 Claude 会话，每个会话拥有隔离的分支工作区（默认存储于 `~/.claude-worktrees`）。
* **集成开发工具**：内置终端、文件编辑器、拖拽式布局、可视化 Diff 审阅、Live App 预览、GitHub PR 监控与自动合并、侧边聊天。
* **三种视图模式**：Verbose、Normal、Summary，用户可按需决定查看多少工具调用与内部活动信息。
* **云与远程支持**：完美集成 Web 版，可从桌面开启云端会话；支持 SSH 远程连接，桌面断开时任务可继续运行。
* **手机端发送会话**：支持从手机发送会话到桌面端。
* **独立核心**：内置独立稳定的 Claude Code 核心，不与系统已安装的其他版本冲突。

**下载方式**：

* 官方下载页：https://claude.com/download

**订阅要求**：需要 Pro、Max、Team 或 Enterprise 订阅。

### 3.3 Devin Desktop（Cognition）

**开发商**：Cognition
**产品定位**：Agentic Coding IDE，以 Agent Command Center 为默认界面
**发布时间**：2026 年 6 月 2 日

**核心功能**：

* **Agent Command Center**：默认界面为 Kanban 看板，按状态追踪所有本地和云端 Agent。
* **Spaces**：允许相关 Agent 共享上下文，有效协作处理任务。
* **自适应模型路由**：内置 Adaptive 智能模型路由器，自动为每个任务选择最佳 AI 模型（SWE-2、Claude、GPT 等）。
* **Computer Use 测试**：Devin 可测试自己的作品，自我验证并自动修复代码；拥有完整 Linux 桌面访问权限，可启动和测试桌面应用。
* **规划与调试**：支持 Ask 模式讨论需求、创建计划，擅长调试问题和处理重复性开发任务。
* **Windows 支持**：2026 年 5 月宣布支持 Windows 平台。

**下载方式**：

* 官方下载页：https://devin.ai/desktop
* 文档：https://docs.devin.ai/desktop

**定价**：Freemium（免费增值），约 $20/月。

### 3.4 ZCode（Z.ai / 智谱）

**开发商**：Z.ai（智谱 AI）
**产品定位**：AI 编程工作台，提供桌面、Web、终端三端统一体验
**开源时间**：2026 年 9 月 20 日正式开源

**核心功能**：

* **三端统一**：Electron 桌面应用、浏览器工作台、终端 TUI/CLI，共享同一 Agent 运行时。
* **GLM-5.2 集成**：将智谱自研 GLM-5.2 模型带入真实编程工作流，用自然语言完成编码、调试、测试、项目预览与变更审查。
* **目标模式**：用 `/goal` 设定可校验目标，Agent 自动迭代推进直至完成。
* **浏览器自动化**：Agent 可自主操控内置浏览器，点击、填表、截图，自动验证前端改动效果。
* **远程控制**：通过微信、飞书、Telegram 等即时通讯软件远程操控运行中的智能体。
* **子智能体与动态工作流**：支持 Subagents、动态工作流、闲时任务、内置浏览器与终端。
* **多模型接入**：支持接入第三方模型服务，包括 Claude Code、Codex、Gemini、OpenCode 等。

**下载方式**：

* 文档站点：https://zcode.z.ai
* 下载入口：https://zcode.z.ai/cn

**定价**：免费下载。

### 3.5 SuperCoder（开源）

**开发商**：TransformerOptimus（开源社区）
**产品定位**：本地优先的开源编码 Agent，桌面应用
**许可证**：开源

**核心功能**：

* **本地优先与完全开源**：源代码永不经过供应商后端，请求直接从用户机器发往用户配置的模型提供商，无中间服务。-47
* **自带模型**：原生支持 OpenAI Chat Completions 和 Anthropic Messages API，无翻译代理。-47
* **图感知代码理解**（可选）：Context Engine 将仓库索引为向量 + 调用图 + 词汇搜索，Agent 可按结构而非仅文本相似性定位代码。-47
* **三种模式**：Ask / Plan / Coding 模式，支持子 Agent、技能、工具审批、提示缓存。-47
* **核心功能集**：原地编辑、检查点与回滚、Diff 审阅、交互式终端、文件浏览器。-47
* **零后端要求**：添加 LLM Key 即可使用，Context Engine 通过 Docker Compose 本地运行。-47

**下载方式**：

* GitHub：https://github.com/TransformerOptimus/SuperCoder
* 当前需从源码构建，预编译二进制文件即将推出。-47

**系统要求**：Rust（stable）、Node.js 20+、Tauri 2 系统前置依赖；Context Engine 需 Docker。-47

## 四、开源 / 本地优先智能体

此类产品强调数据隐私和本地运行，适合对安全性要求高的用户或技术开发者。

### 4.1 Lexora（开源）

**开发商**：useLexora（开源社区）
**产品定位**：自我演化的独立桌面 AI Agent，不依附单一模型
**许可证**：AGPL-3.0-only

**核心功能**：

* **模型自由接入**：不绑定单一模型，用户连接自己的模型，支持通过 MCP 接入更多工具。
* **本地执行运行时与安全沙箱**：在用户授权的范围内调度工具、处理文件与自动化任务。
* **任务中心工作流**：将任务对话、本地上下文、沙箱工具执行与产物交付整合在同一套桌面工作流中。
* **定时任务与自动化**：让定时任务整理工作记录、生成周报，重复步骤交给自动化。
* **桌宠反馈**：桌面上的小桌宠呈现任务状态和反馈。
* **多 Agent 伙伴机制**：支持招募 NPC、探索者等，可委派已绑定的 NPC 参与对话。
* **技术架构**：Vue + Electron 承载桌面体验，独立的 TypeScript Runtime 承载本地 Agent，Pi 提供 Agent Loop，Rust 处理原生能力。

**下载方式**：

* GitHub Releases：https://github.com/useLexora/Lexora/releases/latest
* 官网：...
