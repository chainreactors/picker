## Important Changed

* The train module provided a unified API for agent training, supported training with VeRL, AReaL, Swift(WIP)
* Supported agent to the agent server, such as Google A2A and Anthropic MCP, so endorsed streaming task, and provided new streaming task API
* Claude's Skills ability is supported
* Context ability upgrade, supported context engineering
