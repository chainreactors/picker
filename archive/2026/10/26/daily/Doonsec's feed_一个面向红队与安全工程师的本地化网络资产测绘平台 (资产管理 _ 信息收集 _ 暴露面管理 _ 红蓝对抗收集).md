### 简介

**StarMap（星图）**，源StarMap 是一个面向红队与安全工程师的 本地化网络资产测绘平台 。 输入 公司名、域名、IP 、 ICP 备案号 ，自动识别输入类型，编排对应的任务流：ICP 备案查询 → 根域名提取 → 子域名枚举 → 空间测绘平台补充 → 端口扫描 → 存活探测 → Web 爬虫 → 敏感信息识别，全程无需人工干预，任务结束直接产出 XLSX / Word 双格式报告 。

从一次测绘，到一片星海；从资产打点，到长期盯防，攻防所需，尽收图中。

## 功能展示

### 多入口资产收集

* **五类输入**：公司名 / 域名 / IP / ICP 备案 / 企业资产，自动识别
* **自动编排**：9 种任务流，从一次输入，到一份报告
* **自动流转**：任务完成后，爬虫 / 端口扫描 / 监测 / AI 分析 / 报告一键接力

### 多源数据聚合

* **空间测绘**：FOFA / Hunter / Quake 并发查询，ICP 备案 + ENScan 企业资产同步聚合
* **结果治理**：自动去重合并，来源可追溯
* **子域收集**：Subfinder 被动枚举 + DNS 字典爆破，双保险

### 端口扫描与存活探测

* **双引擎**：Gogo / 原生 TCP，外部工具缺失自动回退
* **服务识别**：90+ 端口映射，高危端口自动评级
* **存活探测**：HTTPx 提取标题 / 技术栈 / Server / 最近存活时间

### Web 爬虫与敏感信息识别

* **双模式爬虫**：内嵌 Katana，标准 / 无头任选
* **深度提取**：API 端点 + 字典爆破 + 敏感信息识别
* **贴近实战**：代理池、自定义规则与字典，CDN 识别内置 100+ 指纹

### 统一资产库

* **全类型收纳**：域名 / IP / URL / APP / 小程序 / 公众号 / 微博 / 招聘 / 著作权
* **治理顺手**：星标、标签、备注、忽略，按公司 / 来源 / 类型聚合穿透

### 持续监测

* **全协议探测**：HTTP / TCP / ICMP / DNS + TLS 证书监控
* **变更检测**：宕机、恢复、篡改、到期等 15 种规则，分级告警
* **多渠道通知**：钉钉 / 飞书 / Webhook，变动第一时间发送

### AI 辅助分析

* **对话式研判**：任务、资产、爬虫结果随问随答
* **灵活接入**：OpenAI / Anthropic

### 报告交付

* **双格式**：XLSX + Word 文档
* **可定制**：主题与模板自定义，汇报归档一键输出

### 星图 · 企业数字宇宙

* **全景可视化**：中心企业是恒星，域名 / IP / 应用 / 证书等资产化作环绕行星，关联测绘
* **关联成网**：资产归属、资产间关联全部连线呈现，AI 挖掘的潜在关联资产经人工二次复核后并入图谱
* **大屏展示**：全屏沉浸、镜头飞行聚焦、自动旋转巡航，汇报演示与指挥大屏直接可用
* **实时同步**：与资产库联动，图谱随任务自动更新，态势常看常更新

### 企业银河 · 全局星空总览

* **态势纵览**：每家企业一颗发光星辰铺满银河，资产规模越大星光越亮，全局分布一眼纵览
* **多维定位**：企业名 / 备案号 / 域名 / 任务名模糊搜索
* **巡航模式**：随机轮播聚光企业，自动巡航海量资产，支持手动操作查看
* **主题适配**：浅色银河 / 深空夜景双主题适配不同大屏环境，点击星辰直达单企业星图

## 快速开始

### 最简使用

Release 中下载与操作系统对应的二进制文件，放到任意目录直接运行。

```
./starmap
```

浏览器访问：

```
http://localhost:8080
```

PS: 单文件即开即用。首次启动自动在同级目录生成 `configs/`、`data/`、`reports/`，并在终端打印管理员账号密码（默认用户名 `admin`，登录后请立即修改）。
