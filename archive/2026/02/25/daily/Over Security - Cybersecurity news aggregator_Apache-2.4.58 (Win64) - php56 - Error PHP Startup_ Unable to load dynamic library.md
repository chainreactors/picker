### Apache-2.4.58 (Win64) - php56 - Error PHP Startup: Unable to load dynamic library

[February 25, 2026](https://trueliarx.blogspot.com/2026/02/apache-2458-win64-php56-error-php.html "permanent link")

Error: PHP Startup: Unable to load dynamic library '../php56/ext\\gd2'

--

When using apache 2.4.\* the php extension php\_\*.dll seems to work only by renaming them without the "php\_" prefix
ex. php\_curl.dll to curl.dll

Inside the file php.ini keep php\_\*.dll naming (ex. php\_curl.dll).
