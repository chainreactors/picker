# LegionProxy Data Breach

## What Happened

In April 2026, the commercial residential and ISP proxy network [LegionProxy suffered a data breach](https://discord.com/channels/1236697205138788462/1239163077983735828/1500601065731653763). The incident exposed 10k email addresses, bcrypt password hashes, names and purchases.

## Compromised Data

Email addresses

Names

Passwords

Purchases

## Recommended Actions

##### Change Your Password

If you haven’t already changed the password affected by this breach, do
so immediately on every account where it was used.

##### Enable Two-Factor Authentication

Wherever 2FA is supported, add an extra layer of security to your
account.
