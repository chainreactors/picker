> 文末联系小编，获取项目源码

今天，小编给大家介绍一款开箱即用、源码交付的国产 AIoT 企业级物联网平台，提供设备连接、数据收集、分析可视化一站式功能服务，支持 MQTT、TCP、UDP、CoAP、HTTP等多协议接入，集成NodeRED，涵盖设备生命周期管理、规则引擎联动、告警、视频及报表管理，提供开放API，内置拖拽式低代码Web组态、数据看板、可视化大屏，零编码即可构建实时监控界面，同时具备SSL/DTLS安全链路保障，并支持国产信创软硬件环境部署，助力企业快速定制行业应用，缩短项目交付周期。

AIoT物联网平台在企业智能化架构中起到承上启下的核心枢纽作用，——向下连接、管理物联网设备端并完成感知数据的归集与存储，向上为应用开发商与系统集成商提供应用开发的统一数据接口及共性模块工具，是应用融合以及数据价值孵化的土壤，除提供基础设施服务支撑设备间的数据交换外，通过对平台数据的处理、分析和可视化，将数据赋能过程大幅前置，充分发挥规模效应，实现数据即生产即处理，便于数据快速应用落地，简化物联网解决方案的复杂度并降低方案成本，充当“加速层”，推进各层在应用场景的落地速度与进程。

![](https://mmbiz.qpic.cn/mmbiz_png/0VE9kDxicLUgGvWl1iazhYOCTmiapiaX7S6MCibMg9LCX3t5yJfp1xdEvpRahf3pSCxhP4EcUgWaqT4CxAkA9MSGC9eVrp1PpFTF9kKhiavlhaibdw/640?wx_fmt=png&from=appmsg)

* 轻量化交付：物联网平台的应用屏蔽了物联网的复杂特性，专注业务应用开发，缩短物联网项目的交付周期。
* 组态化展示：物联网设备协议众多，数据格式复杂，自建平台难以对设备实现统一管理。
* 低成本维护：系统支持远程访问局域网，可远程进行设备调试、拖拽式编程，维护无需下现场，减少维护成本。

🤖 物联网平台架构设计

![](https://mmbiz.qpic.cn/mmbiz_png/0VE9kDxicLUiajB1QibWHSK5ibhIfPibVayHLn3cmDkWJOz9YVMKPGrEk1ficlXIib4LZna0eudgZU1oWVfymJZB1QE9Q5HTB5iaKoMwBSEUapTnbH0/640?wx_fmt=png&from=appmsg)

* 多协议设备接入：支持MQTT、Modbus、HTTP、CoAP 等多种标准及私有协议。
* 设备全生命周期管理：涵盖设备注册、凭证鉴权（Access Tokens）、状态监控、远程控制（RPC命令）、子设备网关代理等功能，支持设备标签化分类与地理信息映射。
* 强大的实时数据处理：内置基于表达式的实时计算引擎，支持JavaScript语法，可在数据入库、告警前完成在线转换、计算与业务赋能。
* 可视化的规则引擎：提供拖拽式规则链设计，图形化场景联动、数据流转（至Kafka/MQTT/API等），支持条件触发（如设备数据阈值）、数据转换（JS脚本）、流转动作（MQ/HTTP推送至业务系统）等节点编排。
* 内置 Node-RED 模块：集成拖拽式大屏、组态和看板设计器，零代码即可快速构建专业SCADA界面、数据看板与监控大屏，支持实时数据绑定与控制。
* 深度摄像头视频集成：无缝接入GB/T28181、萤石云、海康、大华、宇视等视频源，支持流媒体配置、国标级联、录像计划与管理，实现视控一体化。
* 开放API与设备运维：提供完整的Open API接口、调用记录与统计、多租户管理体系、精细化权限控制（RBAC）、以及OTA远程升级能力。
* 智能告警与通知：具备统一告警管理中心，支持多维度告警查询与闭环处理，并能通过钉钉、微信、短信、邮件、语音等多渠道灵活推送消息。
* 高安全与可定制性：支持一机一密、证书认证、安全链路（SSL/DTLS），并提供平台菜单、logo、名称等自定义功能，满足国产化部署与等保要求。
* 国产信创适配 ：兼容银河麒麟V10、中科方德4.0、统信UOSV20操作系统、飞腾处理器、鲲鹏处理器、达梦数据库等信创生态。

规则引擎可配置设备解析后的数据和设备告警实时转发到HTTP、RabbitMQ、Kafka、RocketMQ，后续还会增加其他方式。

![](https://mmbiz.qpic.cn/mmbiz_png/0VE9kDxicLUjUcQjk2pOI7kBFYCgEojTxBL7yqdLdzzibhSnFoGBMHr0zxZUbtxkRUkzXAuIHE3reicUpxQUh7zlFibAFoYXfbzzp3e8aiaXlc4E/640?wx_fmt=png&from=appmsg)

Node-RED 流程以JSON文件形式存储，用户可以在流程完成后利用导出功能进行备份。同样，若需在新系统中部署现有流程，可使用导入功能。

![](https://mmbiz.qpic.cn/mmbiz_png/0VE9kDxicLUiauOT2SHiadZteAxD26q7NibPkact89TUnfk7YA2lagbicwQsJr9pQoq5Fs9lkpvUNTXBD5tr8gpVLgX89ohWiaicDy020mXbjqk4zY/640?wx_fmt=png&from=appmsg)

低代码Web可视化大屏是一种有效的可视化工具，可将收集到的数据以直观、生动的方式展示出来。通过创建交互式的数据大屏，决策者可以快速浏览关键指标，实时了解设备或业务运营状况。这有助于决策者更快地制定决策，并更好地理解数据驱动的洞察。

**🌳 物联网平台应用场景**

![](https://mmbiz.qpic.cn/mmbiz_png/0VE9kDxicLUjhzsvjdS0lXI29OzOGKQvIl2xf7nCibJED8RkWIz5aCCJoWBnqKhD1iaXlqAF7icKv7c3RTtibMDJnsC2ECJhVu79rU1wv7V6t91U/640?wx_fmt=png&from=appmsg)

AIoT物联网平台从最初提供“连接”这一层“毛细血管”，演进为构建覆盖“感知 - 连接 - 决策 - 控制”全链路的“智能神经元系统”，为帮助千行百业将物理世界复杂的运行规律转化为可优化、可自治的数据智能。

工业智造: 基于移动通信网路，实现所有供电点及受电点的电力电量信息、电流电压信息、供电质量信息及现场计量装置状态信息实时采集，以及用电负荷远程控制。

智慧农业: 将农业生产中最关键的温度、湿度、二氧化碳含量、土壤温度、土壤含水率等数据信息实时采集，实时掌握农业生产的各种数据。

智慧物流: 通过GPRS/4G网络提供的数据传输通路，实现物流车载终端与物流公司调度中心的通信，实现远程车辆调度，实现自动化货仓管理。
