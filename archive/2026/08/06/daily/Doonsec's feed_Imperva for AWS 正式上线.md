# Imperva for AWS 正式上线

行业领先的 Imperva WAF 以 SaaS 形式登陆 AWS Marketplace，原生部署于 Amazon CloudFront，零新增延迟

Thales 新闻稿 · 2026 年 8 月 3 日

为什么是现在？攻击者正绕过用户界面，以机器速度直奔 API 而来

53%

自动化流量已占全网请求的比例

27%

机器人攻击直接针对 API

750+

CloudFront 全球接入点原生防护

数据来源：2026 Thales Bad Bot Report

## 与传统 CDN WAF 的本质不同

传统 CDN WAF 需要把流量引出云厂商网络，而 Imperva WAF **直接部署在 Amazon CloudFront 之上**——所有流量始终留在 AWS 网络内部，零新增延迟，AWS Marketplace 按需付费、即买即用。

## 五大核心收益

1企业级防护

覆盖 Web 应用、API 与客户端代码

2极简部署

通过 Amazon CloudFront 一键启用

3集中管控

跨 AWS 与多云环境统一可视化与策略管理

4快速上线

更低运营复杂度，开箱即用

5随云扩展

一致的应用安全，匹配云业务增长

> “Imperva for AWS 让客户能够轻松获得开箱即用的企业级安全。借助 Amazon CloudFront 750+ 全球接入点的原生部署，所有流量都留在 AWS 网络内，以零新增延迟实现规模化防护。”
>
> Tim Chang · Thales 应用安全副总裁

## 为高合规要求行业而生

即使是对监管要求最严苛的组织，也能在不增加运营负担的前提下，同步强化应用、API 与 AI 安全，保持云端创新的敏捷性。
