* Ship three separately packaged agent skills: `open-knowledge-format` for authoring, reading, validation and migration; `okf-maintain` for repository knowledge upkeep; and `okf-backfill` for draft reconstruction from Git history. Package and dependency checks run in CI. Host-side skill activation has not been verified and is not claimed here.
