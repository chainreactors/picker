01

一个被公安部单拎出来的词

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Ah5NAr7MJFjK1OKyqvsHw9QRAlKdbhMgGGTl9JbiaXJt0mhxuBEf7IqV5dFwKanAoHBtIVEuwibPdlnOY0IZ5DQibJnroS0zwM0vbcyppoBBUw/640?from=appmsg)

「两部手机复制一张卡」——卡在你手里，卡的“替身”可以在别人手机里

先问你一个问题：你手机里的NFC开关，现在是开着还是关着？我猜九成人答不上来。它就躺在下拉快捷面板里，好多人从买手机那天起就没动过它。

今天要拆的这个词厉害到什么程度——**“NFC盗刷”，是公安部2026年6月前后专门发布的防诈关键词**，百科上甚至立了词条。一个技术缩写能进公安部的关键词表，只有一个解释：案子多到必须给它起个名了。

央视2025年7月曝光的画面更直接：一台手机贴住实体银行卡，另一台手机就能把这张卡“隔空”复制出来，取现、盗刷，全程不输密码。听着像科幻，对吧？今天周五，按惯例写技术拆解，我把这件事拆成三个环节。**拆完你会发现，恐慌和轻视，都是错的。**

02

先把谣言和事实分开

网上关于NFC盗刷的讨论基本分两派。一派贩卖恐慌：“地铁里被人贴一下，钱就没了”；另一派忙着辟谣：“都是骗流量的，NFC根本做不到”。**两派都只说对了一半。**

先看反诈中心的实测。央广网《法治在线》请信息通信行业反诈中心的专家做过一次“隔空刷卡”演示，注意一个关键细节：**模拟受害人的那台手机，已经下载安装了特定的App。**专家的结论也很清楚——这类犯罪的核心，还是设法骗取被害人的信任，诱导被害人在自己的手机上完成操作。

技术上讲，NFC通信距离只有几厘米，读卡能读到卡号这类信息，但读不到密码。所以“地铁贴一下钱就没了”确实是夸大。但下面这三种情况，每一种都有判决书和警方通报垫底——它们正好对应三个环节。

03

环节一 你的卡信息是怎么漏出去的

公安部刑侦局2026年6月的风险提示讲得很细：诈骗分子在闲鱼这类二手平台上伪装成买家或卖家，交易特别爽快，然后发来一张带二维码的“付款截图”。下一步就是**让你离开平台加好友，再“远程指导”你操作。**

![](https://mmbiz.qpic.cn/mmbiz_jpg/Ah5NAr7MJFgySN0eGibjic3dBP1LErUhibib3p544tOWh4T9gjtL9SxIu3OaljOXvzdjE7GkOic3WvppTsJRFiaenqezxiadv39RISIfZcA3w6nxps/640?from=appmsg)

「引流从一条付款截图开始」——离开平台、扫码、装软件，是同一条链上的三步

指导什么？屏幕共享开着，所谓“NFC数据读取软件”装上，银行卡绑上，支付密码、验证码一步步套走。到这一步，环节一就完成了：**你的卡信息不是被“隔空”偷走的，是你自己在屏幕共享里亲手交出去的。**

另一条路更黑市。江西九江警方破获的那起案子里，吕某、刘某手上的银行卡账号和密码根本不用钓——**境外聊天软件上的“上线”直接发给他们。**信息泄露的源头，可以是任何一个你填过卡号的假网站、假客服。这已经不是NFC的问题，是“料”的问题。

04

环节二 手机怎么变成一台虚拟POS机

拿到卡信息之后，才轮到NFC出场。公安部刑侦局2025年7月的公众号里给这个手法起过一个名字：**手机NFC，正在变成“虚拟POS机”。**

复制的原理不神秘：一部手机贴住实体卡片，把卡片信息读出来，写进另一部手机的支付钱包；或者干脆用套来的账号密码，把卡绑到骗子控制的支付工具上。九江那起案子里，警方反复看取款监控才发现不对——**取款人手里压根没有卡，只有两部手机，一部操作、一部贴卡。80多万元，就是这么被刷走的。**

复制完的手机就是一台POS机。2026年6月多地通报的案子里，骗子拿着手机对着商家的POS机一扫，输入密码，钱就被刷走，换成黄金、手机这类高价值商品。为什么是黄金？好变现、难追查、不走银行流水——跟“骗子不收转账改收黄金”那批案子，是同一个脑子想出来的。

05

环节三 那一下为什么不问你要密码

很多人卡在这个问题上：复制归复制，付款总要输密码吧？答案是：**那一档，真不用。**这就是环节三——银联闪付的小额免密。

![](https://mmbiz.qpic.cn/mmbiz_jpg/Ah5NAr7MJFjKCvG7bDz7ZmkDeCiaKBpJy3pbiabt74fHJOtNltR9xFlGkucAIzMhN9VnmJuewK2iby8ic4yZX2U8fVdXOia39iaiaZJoXsmz7W2Uhg/640?from=appmsg)

「手机变成虚拟POS机」——对着商家POS一扫，钱换成黄金和手机

你卡面上印着“闪付”标识的，基本都默认开了这个功能：**单笔限额以下（各行不同，常见300到1000元）不输密码、不签名，贴一下就走。**方便是真方便，漏洞也是真漏洞。

广州市荔湾区人民法院2025年3月判过一个案子：马某捡到一张信用卡，先在快餐店试了顿饭钱——免密支付成功，从此**连续盗刷三年**才被发现，判了刑。还有一起300余人银行卡被盗刷的案子，法院“以案说法”里写得明白：覃某专职负责取现，按三七分成抽走30%当“辛苦费”。

免密本来是为了快，在这条链上它成了“试探—放大”的放大器：先小额刷几笔试试卡活不活、有没有人盯账单，没人管，就成排往上刷。

06

这条链上坐着的不止一个人

把三个环节拼起来，这条产业链大概是四班人马：**料商**（境外聊天软件里发账号密码的“上线”）→ **引流组**（二手平台搭讪、发二维码截图）→ **操作组**（屏幕共享装软件、两部手机复制卡）→ **取现组**（POS刷黄金、三七分成）。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/Ah5NAr7MJFgsY6I39KQMbO7ArcMP4twaT2Bcediax8oTY9ibEJyewYBjIjqZ9L7WV9qnm17puXaFa1xxs9Ofibhl8WBIIPkOLpYkd2uAoXs5qk/640?from=appmsg)

「NFC风险链条拆解」——二手搭讪、扫码引流、屏幕共享、绑卡要密、贴卡变现，绿色框是断点

九江案里的吕某和刘某，只是链条最末端的“操作手”，真正发号施令的是那个连面都没见过的上线。这解释了为什么案子难打：**单看每一环好像都不算大案**——卖信息的、发二维码的、取现的各干各的，拼起来才是80万的盗刷。

但反过来看，这条链有个死穴：**环节一必须有你配合。**只要你不把手机交给“客服”远程指导、不装陌生人递过来的App、不离开平台交易，后面的复制和免密都无从谈起。断链点，就在你自己的手指上。

07

两个脚本 跑一遍就心里有数

老规矩，把判断做成能跑的脚本，本地运行、不联网、只做防御。第一个是“话术风险扫描”：把对方说的原话贴进去，按引流、套密、动钱、施压四类信号词打分。我拿二手平台那套“付款引导”的话术跑了一遍：

脚本一：nfc\_risk\_scan.py —— 交易话术风险自查，本地运行

#!/usr/bin/env python3

# -\*- coding: utf-8 -\*-

"""nfc\_risk\_scan.py —— 交易话术/短信风险自查（本地运行，不联网）

用法: python3 nfc\_risk\_scan.py          # 跑内置样例

　　　python3 nfc\_risk\_scan.py 文件.txt # 扫描自己的聊天记录/短信导出

命中 2 类以上信号词，建议直接中断操作。"""

import sys

RULES = {

　　"引流": ["离开平台", "加好友", "加微信", "加微", "扫二维码", "二维码", "点链接", "下载软件", "下载这个", "安装app", "远程指导"],

　　"套密": ["屏幕共享", "共享屏幕", "验证码", "支付密码", "银行卡号", "绑定银行卡", "身份证号", "nfc读取"],

　　"动钱": ["安全账户", "保证金", "解冻费", "刷流水", "验证账户", "买黄金", "取现", "关闭免密", "自动扣费"],

　　"施压": ["别告诉别人", "不要告诉", "立即处理", "否则起诉", "影响征信", "马上", "抓紧", "最后期限", "作废"],

}

def scan(text, name="样例"):

　　low = text.lower()

　　hits = {k: [w for w in ws if w in low] for k, ws in RULES.items()}

　　hits = {k: v for k, v in hits.items() if v}

　　score = len(hits) \* 25

　　level = "高危" if score >= 50 else ("可疑" if score >= 25 else "低危")

　　print(f"--- {name} ---")

　　print(f"风险分: {score}  等级: {level}")

　　for k, v in hits.items():

　　　　print(f"  [{k}] 命中: {'、'.join(v)}")

　　if not hits:

　　　　print("  未命中风险词")

　　print(f"判定: {'中断操作并官方渠道核实' if score >= 50 else ('提高警惕，先核实再操作' if score >= 25 else '未见明显话术风险')}\n")

　　return score

75分，高危，三类命中；对照组一条正常取件短信，0分。工具不下结论，只负责让你在手指点下去之前停三秒。**命中两类以上，直接中断操作**，去官方App里核实。

第二个是“账单试探自查”：把银行账单按“时间,金额,商户,渠道”整理成CSV喂进去，它专门盯三类异常——免密小额、凌晨时段、同额连续试探。我用一组还原账单跑出来的输出：

脚本二：bill\_audit.py —— 试探性盗刷账单自查，本地运行

#!/usr/bin/env python3

# -\*- coding: utf-8 -\*-

"""bill\_audit.py —— 银行账单“试探性盗刷”自查（本地运行，不联网）

用法: python3 bill\_audit.py            # 跑内置样例账单

　　　python3 bill\_audit.py 账单.csv   # 格式: 时间,金额,商户,渠道

重点盯三类异常: 免密小额、凌晨时段、同额连续试探。"""

import sys

from datetime import datetime

SAMPLE = """2026-10-18 02:13,198.00,某金店,闪付免密

2026-10-18 02:21,299.00,某数码商城,闪付免密

2026-10-18 02:40,288.00,某金店,闪付免密

2026-10-19 09:32,36.00,楼下咖啡店,密码支付

2026-10-19 12:05,58.00,外卖平台,免密支付

2026-10-20 20:11,129.00,超市,密码支付"""

def audit(rows):

　　prev = None

　　risk = 0

　　for row in rows:

　　　　t, amt, shop, ch = [x.strip() for x in row.split(",")]

　　　　dt = datetime.strptime(t, "%Y-%m-%d %H:%M")

　　　　amt = float(amt)

　　　　flags = []

　　　　if ("免密" in ch or "闪付" in ch) and amt <= 300:

　　　　　　flags.append("免密小额")

　　　　if 0 <= dt.hour < 5:

　　　　　　flags.append("凌晨时段")

　　　　if prev and abs(amt - prev) < 5 and ("免密" in ch or "闪付" in ch):

　　　　　　flags.append("同额连续")

　　　　if len(flags) >= 2:

　　　　　　risk += 1

　　　　　　print(f"[!] {t} {amt:>7.2f} {shop} {ch} -> {' + '.join(flags)} 可疑")

　　　　elif flags:

　　　　　　print(f"[~] {t} {amt:>7.2f} {shop} {ch} -> {' + '.join(flags)}（单信号，留意即可）")

　　　　else:

　　　　　　print(f"    {t} {amt:>7.2f} {shop} {ch}")

　　　　prev = amt

　　print(f"\n共 {len(rows)} 笔，可疑 {risk} 笔")

　　print("建议: 发现可疑笔立即挂失换卡，并到云闪付/手机银行关闭免密支付协议")

　　return risk

if \_\_name\_\_ == "\_\_main\_\_":

　　if len(sys.argv) > 1:

　　　　rows = [l for l in open(sys.argv[1], encoding="utf-8").read().splitlines() if l.strip()]

　　else:

　　　　rows = SAMPLE.splitlines()

　　audit(rows)

三笔凌晨的免密小额排成一列，就是教科书式的“试探—放大”。发现这种别犹豫：**先挂失换卡，再去云闪付或手机银行把免密支付协议关掉。**小提示：从公众号复制代码如果报“非法字符 U+00A0”，把行内空格重打一遍即可。

08

五分钟清单 把三个环节挨个堵死

清单来了，一条堵一个环节，今天就能做完。

**一、把NFC关了。**不用的时候，下拉快捷面板里点亮的那个图标熄掉。环球网2026年4月的提醒也是这句话：NFC功能不用时，请关闭。

**二、把免密限额压下来。**打开云闪付或手机银行，找“免密支付协议”或“闪付小额免密”，要么整个关掉，要么把单笔限额压到你能接受的最低档。这一步堵的是环节三。

**三、三条铁律贴墙上：**不离开平台交易、不开屏幕共享给“客服”、不装应用商店之外的App。卡号、验证码、支付密码，电话里一个字都不报。这一步堵的是环节一。

**四、开通每笔交易提醒**，每周花一分钟扫一眼账单，上面那个脚本就是干这个的。

说两句掏心窝的。干这行这些年，我最怕的从来不是多高明的技术，而是“这事跟我没关系”的心态。NFC盗刷恰恰是那种看着遥远、其实每部手机里都埋着的开关。**技术拆解拆到最后，拼的不是知识，是习惯**：关掉一个开关，压低一个限额，多问一句“凭什么”。

这篇转给那个总说“我卡里没钱不怕”的人，顺手把手机下拉面板拍给他看：**你的NFC，现在开着吗？**
