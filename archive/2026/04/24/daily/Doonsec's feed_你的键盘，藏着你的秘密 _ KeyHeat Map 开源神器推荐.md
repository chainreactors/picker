你有没有想过——
你一天到底按了多少次键盘？

是「Ctrl+C / Ctrl+V」重度依赖患者？还是「WASD」永动机？
你的空格键是不是已经被按出了包浆？

今天给大家安利一个超级酷的开源项目——
KeyHeat Map
它能把你的每一次按键都变成一张炫酷的热力图。

WHY YOU NEED IT

为什么你需要这个工具？

01 / 键盘热力图，炫到没朋友

SVG 矢量键盘布局，实时按键高亮，霓虹/暖色/冷色/单色四种配色方案。支持 60%/75%/全尺寸键盘布局。鼠标悬停还能看到每个按键的详细统计——按了多少次、占比多少，一目了然。

02 / 组合键排行榜，暴露你的真实身份

自动识别 Ctrl+C、Ctrl+V、Alt+Tab 等所有组合键，生成 TOP 15 排行榜。是复制粘贴工程师还是快捷键大师？数据不会说谎。

03 / 数据仪表盘，堪比 GitHub 贡献图

24 小时活跃度热力分布，仿 GitHub 贡献图样式。按键趋势折线图、鼠标点击趋势、按键分布饼图、详细按键排行榜……你的键盘使用数据，比你的朋友圈还丰富。

04 / 一键生成分享海报，社交属性拉满

电竞炫酷风、极简数据风、GitHub 贡献风三种海报模板，一键导出 PNG。发到朋友圈、发到技术群、发到社交媒体——让你的键盘数据成为你的社交名片。

TECH SPECS

技术党看这里

前端：React 18 + TypeScript + Vite
后端：Rust (Tauri v1) - 高性能低内存
数据库：SQLite - 零配置本地存储
动画：Framer Motion - 流畅 UI 动画
安装包：仅 ~7MB，内存占用 < 30MB
隐私：所有数据仅存储本地，不上传任何服务器

全平台支持

Windows (x64)  |
macOS (Intel + Apple Silicon)  |
Linux (deb + rpm)
