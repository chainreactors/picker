# **摘要**

黑熊学院（Kuma Academy）是2021年在台湾发起的“台独”性质明显的民间民防教育品牌。综合文档、官方网站留存资料、台湾公共部门文件及境内外报道，可以将其概括为一个由**收费课程公司、公益社团法人、专业授课合作方、学员与志工社群以及国际民防交流网络**共同构成的平台，依据具体课程、指挥关系和实际用途判断，虽不能推定其为武装民兵，但有明显逐渐“军事化”倾向，而非单一、边界清晰的“学校”。

本报告形成六项核心判断：

1.**组织已平台化。** 其发展路径大致是“五人志工团队—课程与演训机构—公司、协会双主体—民防交流与国际合作平台”。公司主要承接收费课程和商业运营，协会承担公益劝募、公共推广及论坛活动；两者不能混为同一法律主体。

2.**课程兼具一般民防与战时双用途属性。** 急救、家庭避难、资安、媒体识读具有普遍公共安全价值；OSINT、离线自组网通信、战术救护、隐蔽移动和无人机则可在灾害与冲突场景中使用，有军事化倾向。

3.**资金结构呈多元化，但公开信息不足以复原完整账目。** 可确认的收入或资源渠道包括课程收费、社会捐款、私人赞助和部分政府项目合作；美国在台协会（AIT）曾确认向包括黑熊学院在内的团体提供“小额奖助金”。“台独”顽固分子、联华电子前董事长曹兴诚公开承诺三年资助6亿元新台币，但承诺额不等于已全部到账。

4.**境外联系真实存在，但应区分资助、交流、合作与指挥。** 黑熊学院与美国、乌克兰及欧洲民防、安全研究和公民社会组织有公开往来，并引入部分课程、经验和认证资源。现有公开信源可以证明网络联系与早期资助，其受境外机构持续指挥尚需进一步核实。

5.**与台湾公共部门及政治网络联系较深，但并非已被正式纳入军方。** 其人员参与政策咨询和全社会防卫韧性相关机制，部分活动获得公共部门协办或项目支持；与此同时，台湾内政部门明确否认曾委托黑熊学院执行民防训练，境外媒体亦指出军方与民间团体整合仍有限。

6.**被大陆列为惩戒对象****。** 大陆官方已将黑熊学院及相关负责人列为惩戒对象，并对沈伯洋采取立案侦查等措施；这些是已发生的官方处置。坐实其“台独”标签。有关“间谍”“境外操控”等说法还需进一步获取证据。

# **一、研究方法与证据边界**

## **（一）资料来源**

本报告使用四类资料：

•**资料**：既有课程调研报告及其官网引文、台湾监察机构调查报告、地方政府活动文件、研讨会与培训议程、媒体报道PDF等；

•**机构自述**：黑熊学院官网、社团法人黑熊民防教育协会公开劝募页面、课程与活动说明；

•**第三方公开信源**：台湾内政部门、司法机构登记公告，AmCham Taiwan、ICRT、Defense News、ZMINA、NAKO、GTI等报道或活动资料；

•**大陆官方发布**：国务院台湾事务办公室、新华社等。

## **（二）证据分级**

|  |  |  |
| --- | --- | --- |
| 等级 | 资料类型 | 本报告使用方式 |
| A | 公共部门文件、法人登记、机构原始公告、可核验活动页 | 可用于确认主体、日期、职务、公开项目和政策表态 |
| B | 机构自述、可靠媒体采访、合作方活动记录 | 可用于描述运营、课程和往来；规模数字注明为自述或转述 |
| C | 政治人物指控、评论文章、匿名爆料、间接推算 | 仅用于说明争议存在，不直接作为事实结论 |

## **（三）重要限制**

1.黑熊学院官网内容主要依据既有报告在2026年10月18日前后的网页留存与引文，并以其他公开信源交叉核验。

2.协会劝募页可访问，并链接《2025年影响力报告》、捐款征信及113年劝募成果资料，但Calaméo和Google Drive本轮未能直连，故**未审阅完整财务明细、捐款人清单或审计报告**。

3.公开资料不能支持精确计算黑熊学院历年总收入、净资产、境外资金占比，也不能证明所有合作方之间存在资金往来。

4.本报告中的“境外联系”是中性的事实分类；“控制”“代理”“情报人员”等结论需要更高等级证据。

# **二、发展沿革与组织架构**

## **（一）发展沿革**

黑熊学院于2021年由沈伯洋、何澄辉等发起，机构自述早期仅有5名志工。2022年俄乌冲突及台海局势升温后，其课程需求和社会曝光度上升；同年“台独”顽固分子曹兴诚宣布大额资助计划，推动其扩张。

2022年5月，“黑熊社会企业有限公司”设立，逐步形成收费课程、线上内容和商业合作体系。2023年9月，“社团法人黑熊民防教育协会”完成法人登记，首任理事长为沈伯洋。2024年起，刘文以协会理事长身份频繁代表机构参与民防活动，朱福铭则以执行长或CEO身份负责运营。

2023年以来，其活动从基础课程拓展到“蓝鹊行动”综合演训、国际民防论坛、分众营队与民防年会。2026年，学院提出向“全方位民防平台”和民防媒体发展，显示其目标已不再局限于单次培训。

## **（二）“公司＋协会＋合作网络”的结构**

|  |  |  |
| --- | --- | --- |
| 组成 | 公开定位与职能 | 核验要点 |

| 黑熊社会企业有限公司 | 收费课程、线上课程、商业合作及网站运营 | 2022年设立；2024年后朱福铭以CEO/执行长身份对外 |
| 社团法人黑熊民防教育协会 | 公益推广、社会劝募、论坛及民防教育 | 2023年9月登记；现由刘文任理事长 |

协会公开劝募页列出的联系地址为台北市中正区武昌街一段18号3楼，与既有官网资料中的固定教学地点一致。

## **（三）治理特征**

这一结构具有三项特点：一是公司与协会并行，使商业收费和公益募资能够分轨运行；二是大量课程依赖外部讲师、认证机构、场地和设备伙伴，属于轻资产、网络化交付；三是通过年会、论坛、证书徽章和社群活动维系参与者，增强品牌的持续动员能力。

但公开资料尚未完整披露公司与协会之间的费用分摊、品牌授权、人员兼职、关联交易的制度安排。因此，不能仅凭同一品牌或人员交叉就断言财务混同；同样，也不能因法人不同而忽略其实际协同。

# **四、资金来源与财务核验**

## **（一）资金来源分层表**

|  |  |  |
| --- | --- | --- |
| 类别 | 可确认事实 | 不能据此推出的结论 |
| 课程与线上产品收入 | 基础营、专项课、线上课、少儿营等采取免费、保证金、中低价收费和高价营队并行的模式 | 不能以标价乘以估算人数，代替实际营收或审计数据 |
| 社会捐款与公益劝募 | 协会设有公开劝募页面，发布劝募许可、成果报告和捐款征信入口 | 未取得完整报告前，不能给出总捐款额、主要捐款人排名或境外占比 |
| 曹兴诚私人资助 | 2022年公开承诺三年资助黑熊学院6亿元新台币，支持民防训练 | **承诺6亿元不等于实际到账6亿元**；实际拨付总额和余额需财务资料验证 |
| AIT早期奖助 | AIT于2025年3月向ICRT确认，曾向包括黑熊学院在内的社会团体提供“小额奖助金”，目的为促进美台合作；未披露黑熊所得金额 | 不能推定资助持续至今，也不能仅凭资助推定境外指挥 |
| 台湾公共部门项目 | 2024年全球民防论坛中，外事部门提供100万元新台币用于外宾差旅等；黑熊方面承认该项目支持，论坛总支出超过200万元 | 项目补助不等于政府长期预算供养，也不代表所有活动均由官方委托 |
| 政府合作与资源链接 | 部分防灾活动、政策咨询、论坛协办和公共议程可见黑熊人员或机构 | 协办、咨询、师资参考均不自动等于委办收入 |

## **（二）三类****有争议收入**

1.**把关联机构经费算作黑熊学院收入。** 媒体有关开放社会基金会（OSF）向台湾民主实验室、台湾人权促进会、环境法律人协会等提供资金的报道，最多能说明相关人员所处的公民社会网络及其资金争议；在没有转账或共同项目文件时，暂不将这些款项并入黑熊学院。有关资金是否源自美国国际开发署（USAID）亦存在争议，未写成已确认事实。

2.**把预算、投标或师资名单算作实际收入。** 陆委会255万元项目属于黑熊参与投标但未中标；内政部门900万元亲子活动预算及警政相关预算曾遭质疑或删减，且内政部门明确称未委托黑熊执行训练。这些均未计为黑熊实际收入。

3.**把合作方项目资助算作黑熊收入。** 例如GTI有关台湾民防研讨和出版项目由台湾民主基金会支持，只能证明该项目背景，不能证明黑熊学院获得同一笔资金。

## **（三）财务结构的合理判断**

从公开业务模式看，黑熊学院可能同时依赖私人赞助、公众捐款、课程收入、企业合作和有限项目支持，形成“免费普及活动扩大受众—收费课程维持运营—协会劝募支持公益项目”的组合。免费大专营、公益演训与较高价格专项课并存，也说明不能仅以单门课程价格判断其整体性质。

不过，由于缺少完整审计报表、分主体收入表和跨境资金流文件，本报告不给出所谓“总资产”“境外资金总额”或“美国资助占比”等精确数字。

# **五、境外联系：资助、知识、组织与传播四层分析**

## **（一）美国：早期资助与安全研究网络**

AIT对“小额奖助金”的确认，是目前较明确的境外直接资助证据。公开报道还转述早期录音称，相关经费用于基础营，早期曾汇入沈伯洋个人账户，并有AIT人员提供指导。由于录音内容属于媒体转述，本报告将其作为待原始材料进一步核验的补充。

2025年9月，Aaron Huang以黑熊学院国际事务主任身份参加华盛顿GTI民防公开研讨会，显示其已进入台湾安全与美国智库交流网络。GTI出版物同时将黑熊描述为大型民防非政府组织，并讨论民间团体与泛绿政治人物的联系、军民协调不足及岛内政治极化问题。其“台独”标签显著。

## **（二）乌克兰：经验输入与共同办会**

2024年5月，黑熊民防教育协会在台北举办“全球民防与社会韧性领袖论坛”，台湾警政部门协办。ZMINA记录显示，论坛邀请近30名来自美国、乌克兰、波兰、捷克、爱沙尼亚等地的嘉宾，涉及ICUV、ZMINA、Mantis Analytics、欧洲价值观中心、大西洋理事会等机构或网络，主题包括乌克兰经验、区域安全、民防和军民合作。

2026年3月28日至29日，黑熊与乌克兰自由民主联盟（LDLU）合办台湾民防年会，议题涵盖反假信息、无人机与社会韧性。NAKO资料还显示，乌克兰代表团在台期间与外事、防务部门及DSET等交流。

这些材料可以支持“乌克兰经验是其课程与政策话语的重要来源”，其学习乌克兰军事斗争经验，“军事化”倾向显著。

## **（三）欧洲及其他国际联系：论坛、知识与人员往来**

欧洲联系主要体现为民防专家互访、国际论坛、智库和非政府组织交流，而非已证实的固定分支机构。沈伯洋曾公开表示拜访北美和欧洲民防专家；黑熊亦通过英文采访、国际会议和合作方报道进行对外传播。

课程层面还出现国际知识资源，例如TECC课程由台湾合作机构授课发证，并以美国相关委员会授权体系作为专业背书。

## **（四）综合判断**

黑熊学院的境外网络具有实质性：既有早期直接奖助，也有长期知识交流、国际论坛和共同议程设置。其功能主要是**引入国际经验、提高国际可见度、连接政策与公民社会**。是否存在统一境外指挥链、秘密情报任务或由单一外国机构持续控制需进一步收集证据。

## **（二）基础与普及课程**

一日基础营通常涵盖现代军事科普、资讯辨识与认知作战、基础救护、避难规划，是学院最具代表性的入门产品。官网留存资料显示，一般票约1200元新台币；线上基础课将同类内容转为近6小时课程。

“黑熊开讲”把资安、媒体识读、地缘政治等拆成短课；资安课程涉及密码管理、加密通信、数据保护和旅行安全。园游会、知识影片和《KUMA黑熊学院少年防卫课》等出版物，并把内容延伸到家庭和儿童。

## **（三）进阶技能课程**

•**OSINT**：包括地理位置判读、网络追查与网络架构，机构课程说明明确讨论战时信息搜集场景。

•**救护**：BLS教授基本救命术；TECC-FR面向不稳定环境下的出血处置、检伤和撤离，由专业机构授课发证。

•**防卫**：近身防卫与防身喷剂课程强调个人逃生和自卫。

•**避难与通信**：个人防空避难地图、Meshtastic离线通信分别对应空间规划和断网通信需求。

•**无人机**：2026年推出的体验课以基础操作和法规为主，使用小型设备；公开报道显示课程需求较高。

这些课程的技术门槛和潜在用途不同。课程组合正从一般风险管理向部分冲突情境技能延伸，有军事化倾向。

## **（四）“蓝鹊行动”综合演训**

“蓝鹊行动”自2023年起举办，以8至12人小队处理通信中断、OSINT任务、大量伤患、隐蔽移动和避难所交涉等随机事件。其价值在于团队协同与压力情境演练，而不是单纯课堂知识传授。

公开资料虽未足以证明该演训已经形成固定军事编制、武器训练或统一作战指挥链。本报告称其为**民防情境综合演训**，但部分科目的双用途性质明显，有向武装民兵训练演化倾向。
