The Ransomnews research team counted 484,142 publicly listable cloud storage buckets holding 18.05 billion files in October 2026, using data from [GrayhatWarfare](https://buckets.grayhatwarfare.com/), the search engine that indexes open cloud storage. Amazon S3 hosts 72% of them, but Azure Blob is 2.5 to 3.6 times over-represented among buckets named for backups, exports and payroll. Open buckets also list 321,058 credential and key files, and 67% of the exposed .env files were last written this year.

No file was opened for this index. Every number below comes from bucket names, file extensions, file counts and last-modified timestamps. That is a deliberate limit. It keeps the research on the right side of the line, and it turns out to be enough to see where the sensitive material concentrates. We are calling it the Ransomnews Cloud Exposure Index, and we will rerun it quarterly so the numbers can be compared over time.

## How many cloud buckets are publicly exposed in 2026?

484,142 buckets across five providers were publicly listable when we took the snapshot, with 18,054,411,545 indexed files between them. Amazon S3 accounts for 71.9% of the buckets, which is roughly its share of the market and not evidence that S3 is worse configured than the rest.

| Provider | Open buckets | Share |
| --- | --- | --- |
| Amazon S3 | 347,984 | 71.9% |
| Azure Blob | 68,532 | 14.2% |
| Google Cloud Storage | 53,131 | 11.0% |
| DigitalOcean Spaces | 11,069 | 2.3% |
| Alibaba OSS | 3,426 | 0.7% |
| **Total** | **484,142** | **100%** |

Publicly listable buckets by provider, index snapshot of 7 October 2026. Source: Ransomnews Cloud Exposure Index, built on GrayhatWarfare data.

A large share of these buckets are public on purpose: website assets, CDN mirrors, open datasets, podcast archives. The index is not 484,142 breaches. It is the population inside which the breaches sit, and the rest of this piece is about narrowing it down to the stores that should never have been listable.
