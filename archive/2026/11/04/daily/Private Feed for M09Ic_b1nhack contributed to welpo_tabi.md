Pushed a fix: the script now receives `external_links_no_follow` and `external_links_no_referrer` via data attributes and composes `rel` from all three settings, matching what Zola does for Markdown links (`noopener` still accompanies `target="_blank"`, same as the `rel_attributes` component).

I didn't route it through `rel_attributes` since that one deliberately skips `nofollow` for social links.

The minified file is generated with:

```
uglifyjs --compress --mangle -- "$file" > "${file}.tmp"
```
