Lets admin check a config template with the same code the runner uses, with no plugins.

* `WithDetectedProjects(projects, rootModules)`: uses the given projects, and skips plugin identify and autodetect
* `WithWriter(w)`: writes the compiled template, even when it fails part way
* `WithMaxRenderedBytes(n)`: stops a template once its output passes n bytes (`ErrRenderedTooLarge`)
* `TemplateError{Stage, TemplateLine, TemplateColumn, RenderedLine, Message}`: stage is `template_syntax`, `template_run`, `yaml` or `config`. `Message` has no location prefix. `errors.Is(err, ErrInvalidConfigTemplate)` still holds.
* `template.CompileError{Step, Err}` from `Compile` and `CompileFromFile`: `errors.Is` matches `ErrParse` or `ErrExecute`

No change for callers that don't use the new options: same error text, same wrapping.
