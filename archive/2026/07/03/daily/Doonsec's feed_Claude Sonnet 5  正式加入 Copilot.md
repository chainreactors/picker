# 2026 年 7 月 2 日，Microsoft 宣布 Anthropic 旗下 Claude Sonnet 5 正式接入 Microsoft 365 Copilot。作为新一代前沿模型，Claude Sonnet 5 将率先在 Copilot Cowork 和 PowerPoint 中逐步推出，面向日常办公中的多步骤、智能体式任务场景，覆盖文档处理、表格分析、演示文稿制作等常见工作流程。

![](https://mmbiz.qpic.cn/mmbiz_png/5BBJWJhb0eicr43ibWjq8xucbP4VsSDGKZp1kCJfwqNOyolEaCKouaJibmiatPxicM2sArNaHvhW6ibib67Pg9QjDWjtOKXwsodfBN3eicFtDhfoCl4/640?wx_fmt=png&from=appmsg)

按照 Anthropic 的介绍，Claude Sonnet 5 是一款能力更强的 Sonnet 系列模型，尤其适合需要连续推理、任务规划和上下文理解的复杂工作。其整体表现接近 Opus 4.8，同时具备更具竞争力的使用成本。这也意味着，在 Microsoft 365 Copilot 中，用户将拥有一个更适合处理复杂办公任务的新模型选择。

Claude Sonnet 5 的加入，进一步丰富了 Microsoft 365 Copilot 的前沿模型阵容。对于企业用户来说，这不仅是模型能力的扩展，也意味着可以根据不同任务需求选择更合适的 AI 模型。无论是内容生成、材料整理，还是复杂业务文档的构建，Copilot 都能够在安全、合规和隐私保护的基础上，为用户提供更加灵活的智能办公体验。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/5BBJWJhb0eic2XEBVkFDVwTjHliaAicMqI1MYY7rneIBEl4MQxzSzT0p0HTUxAyxoXan4Lg3DBQCwvXsibctrH3YibX0VDahlMn9RmRiaiceY4avAM/640?wx_fmt=png&from=appmsg)

当 Claude Sonnet 5 与 Microsoft 365 Copilot 的 Work IQ 能力结合后，Copilot 可以基于用户的工作文件、会议内容、聊天记录以及企业业务数据，更好地理解工作上下文，并进一步完成规划、构建和内容创作等任务。简单来说，Copilot 不只是回答问题，而是能够围绕真实工作场景，帮助用户生成更完整、更专业的业务成果。

总体来看，Claude Sonnet 5 的接入，代表 Microsoft 365 Copilot 正在从单一模型能力，进一步走向多模型协同与场景化选择。对于企业办公用户而言，这将带来更强的任务处理能力、更灵活的模型选择，以及更贴近实际业务流程的 AI 办公体验。

注意：在PPT中使用sonnet 5，国内网络就可以；但是在cowork中使用sonnet5，必须有其他手段。
