Typora 背后团队的新工具，已正式上线。

名字叫 Otty。

![CleanShot 2026-06-25 at 16.55.45@2x.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYApPs0iclibeibMXmtrkPU39GHvuYolsmbkTfvnsLGqq6OAIVQYDCtQMQgl0zodbs3ugRCHxcjAegu5Vt6m06jeEMaZj8ibo45QPaY4/640?wx_fmt=png&from=appmsg)

如果只看团队背景，很多人可能会以为它又是一款写作软件，但其实并不是。

Otty 是一个终端工具，目前主要面向 macOS 用户，其重点服务的是 AI Agent 编程工作流，而非普通命令行场景。

简单来说，如果你每天都在终端里跑 Claude Code、Codex、OpenCode 这类工具，Otty 会比传统终端更适合你。

![screenshot-9.png](https://mmbiz.qpic.cn/sz_mmbiz_png/ib4HLZ26hYAoqpKq7Dlgk9wGVCg18vFfekge0fkjBn8cbGSaZXhJ5LPtITkKToOlcVwC6t1RYExGxvkX5JiaAC0WmqPDTBcygSGcq7qny30Vg/640?wx_fmt=png&from=appmsg)

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0u4CHiaMhAdl8MT33E9ByxnhpYuMGja3h82BzeYpzJQ90iaTxpsibR2Qlg/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 作为终端工具

Otty 首先还是一个正常终端。

它支持标签页、分屏、文件 / 文件夹面板、命令面板、主题、自动补全、内联建议等丰富功能。

界面风格也很 Typora：干净、克制、好看，不像很多开发工具那样一打开就满屏按钮。

![CleanShot 2026-06-25 at 17.02.30@2x.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYApptYib11OpibnW3tQP6mEKWpgI5qCco6aCuGjSeU2SX8f8PCMlQg2GdHjMyFc7qtLqOUlnvKNprNQftLth8WKYYPwbfsao5wFaQ/640?wx_fmt=png&from=appmsg)

目前 Otty 可下载的是 macOS 版本，支持 Apple Silicon 和 Intel Mac，系统要求 macOS 14 Sonoma 或更高版本。Windows、Linux、iOS 版本还在开发中。

官网地址：https://otty.sh

![CleanShot 2026-06-25 at 16.59.51@2x.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYAoCZ0USUPVHeNFXzacvwiae3TVYz8tTRVFKAVqs1HKZNdmgQnZApBEOmn7S3DsISk8Qo0rlgia8Wic4QStJ1tjy65YIbeiaiaVAAwc0/640?wx_fmt=png&from=appmsg)

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0xU9Fvm3ILCw745js1LmpsibFNyvia4QsicUbKwqeibUyrYvx0N4CN2trBw/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) AI Agent 的好搭档

传统终端里跑 AI Agent，最麻烦的是你得一直盯着。

它是在思考？在改代码？在等你确认？还是已经跑完了？

Otty 对 Claude Code、Codex、OpenCode 做了专门支持。连接后，标签页上可以显示 Agent 状态；任务完成、等待输入或需要确认时，也能通过系统通知提醒你。

![](https://mmbiz.qpic.cn/mmbiz_gif/ib4HLZ26hYAo5T5wiaMrYyRibQ1uDMMeianjicXah637Vnicxd9JBboDFxPuIBCLBZ3faMoHRQ45ZLALXXicX0ZgalT9bicteBcQfcBCianK8JxSFILQ/640?wx_fmt=gif&from=appmsg)

这点很适合同时开多个任务的用户。

比如一个 Agent 在重构组件，另一个在补测试，旁边再开一个终端看日志。你不用在一堆窗口里来回找，也不用一直盯着屏幕等它跑完。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/ib4HLZ26hYAqRWeZshE31mjFc0CkfuTMhSHiaYpKurbibhk0jsiamCrXo20SRdUN2BzvmLjZN9U6F9J6OSe9UNfeD8LhmMKDmOpVAskzljFhmd8/640?wx_fmt=gif&from=appmsg)

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0WZZD2XSfTRL4qMsKuHfseqVcjBRM0E29GIiatsL7vdPItywyXqHibNEQ/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 轻松编辑 Prompt 长文

经常用终端 AI 工具的人，应该都踩过这个坑：

一句提示词还没写完，手滑按了回车，直接发出去了。

Otty 做了一个 Composer 输入面板，可以写多行 Prompt，支持撤销 / 重做，也能粘贴图片或富文本内容并转换成 Markdown。

![image.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYAokiciapMC3VNia3REyo3Y4rMeQRqQ1BxlxiafiaCeicLXyjWWEQ9d8eTAUP1umOTNZNAUiajWOzbWF50VcbdVtCMduclicibLuMibCu4B2U/640?wx_fmt=png&from=appmsg)

更实用的是，它还有 Prompt Queue。

Agent 还在处理当前任务时，你可以把下一步的指示先排个队。等当前任务结束，Otty 会按顺序把下一条发出去。

这就很适合那种已经想好接下来几步，但不想一直坐在电脑前盯进度的场景。

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0f9nmMMDAvNIxXBVYXiadGiar3ovYA7wm63icczibatTnaQbZAdPrIXfeSw/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 报错信息直接丢给 AI

以前终端里出现一段报错，通常要手动选中、复制、切到 Agent、粘贴、再解释一句「帮我看看这个错误」。

Otty 的 Send to Chat 可以把终端输出、文件面板选中的内容，直接发送给当前或新的 Agent 会话。

![CleanShot 2026-06-25 at 18.37.35@2x.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYAog75USLqNnicJmpJ4OZ63iaia5AxGW4Sct1y6253lDxddrhiaxiccnHPXZfwibG3okJefl8qIyLTv8ZLLKOo3S90zEo10ULEjgCzdt0/640?wx_fmt=png&from=appmsg)

比如测试失败、构建报错、命令输出异常，都可以直接带着上下文发过去。

这不是很花哨的功能，但每天用起来，会少很多复制粘贴和来回切窗口。

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0EG4nnJHvoicDYERdXImgoVQB5xeeVCGm52gQJWAGrbh3aAfdKicptPaw/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 会话恢复 & 分支

Otty 支持会话恢复。重新打开后，之前的窗口、标签页、分屏、工作目录和滚动历史可以恢复回来。

它还支持 Fork / Branch Session。

![screenshot-5.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYArLmzjotNtwDYuWmEVvDGIVf5GPqlMthHGDhzJfk14P4QEYRxicyIgia1KRRuZzaMImnUUFjLpiaEVO9koics56ic8gDzpkQaQPHQJw/640?wx_fmt=png&from=appmsg)

你可以把一段 AI 对话从某个节点分出去，开一个新标签或分屏，继续探索另一个方向。

比如同一个问题，方案 A 想重构，方案 B 想先补测试。以前只能复制上下文重新开聊，现在可以直接把会话分出去再实验。

![标题图标](https://mmbiz.qpic.cn/mmbiz_png/aFXaQ2oY6JBKwShvcSd8gIJqox7aK7I0TNuC2icdFOz26U0cNfDfbUMA7sLd7hwbnswWMYaZc98icWZIKXNiaqF2w/640?wx_fmt=png&tp=webp&wxfrom=5&wx_lazy=1) 本地功能免费

Otty 目前的离线功能免费，也不需要注册账号。

官方文档写得比较明确：终端、标签页、分屏、主题、Recipes、以及 Agent 相关的功能，都会保持免费。

官方文档：https://docs.otty.sh/

未来可能收费的，也是数据同步、远程控制、Otty AI 这类需要服务器支持的功能。

![CleanShot 2026-06-25 at 18.48.35@2x.png](https://mmbiz.qpic.cn/mmbiz_png/ib4HLZ26hYArwPXVX7lZ3JXF3gx78lV85f6XVdvS3UkbMszjgls2TljUH4FOiazcv6oU5uh5SFI6p1HhPID5Qht9apSQXofOWfibDRrWdAllLc/640?wx_fmt=png&from=appmsg)

如果你只是偶尔需要执行几条命令，系统终端、iTerm2、Ghostty 这些工具已经够用。

但如果你已经开始把 AI Agent 当成日常工作的一部分，不妨下载体验一下 Otty！

它不是一个普通的终端工具，而是一个更适合管理 AI 任务的工作台。

这可能也是这个时代，终端工具该有的新样子。
