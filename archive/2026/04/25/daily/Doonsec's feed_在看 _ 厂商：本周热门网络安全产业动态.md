****厂家发布****

**[1、赛力斯集团与奇安信集团达成战略安全合作](https://mp.weixin.qq.com/s?__biz=MzU0NDk0NTAwMw==&mid=2247631690&idx=1&sn=bac7c17dea65c084cb59758857e8008e&scene=21#wechat_redirect)**

4月17日，奇安信科技集团股份有限公司与赛力斯集团股份有限公司战略安全合作签约仪式圆满举行。双方合作关系全面升级，正式确立战略安全合作伙伴关系，并为“数据安全联合创新实验室”揭牌。

**[2、绿盟科技《DDoS攻击威胁报告》（2026版）正式发布](https://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650477069&idx=1&sn=2813ad7f9ef483b8fac228895d1ed418&scene=21#wechat_redirect)**

报告显示 DDoS 攻击从传统带宽对抗转向智能化、精准化对抗，AI 驱动的攻击平台已落地应用，大幅降低攻击门槛。高强度攻击数量与峰值带宽持续增长，攻击策略向高负载放大转变。攻击更趋靶向精准，瞄准关键业务节点与 API 接口。攻击生态由老牌家族主导，新兴僵尸网络快速崛起，攻击向应用层资源消耗转型，未来攻击将更智能，还可能成为地缘政治博弈工具。

****产品和迭代****

**[1、阿里云推出企业级智能体构建平台——JVS Crew](https://mp.weixin.qq.com/s?__biz=MzA4NjI4MzM4MQ==&mid=2660260224&idx=1&sn=8b2d945fc5ff4c5e9a779bf33b86fa38&scene=21#wechat_redirect)**

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8C1NLS8ickpfgp0XysDKxYVzyTHtkkicibbTlziaoaUc05BqJx7t1Q98U4hfZbQVwEoXSCs4vbov55ysXfQ29Ey8TGK0acVkOkBwljy8YDmYsVg/640?wx_fmt=png&from=appmsg)

**[2、360企业浏览器数据安全专版正式推出](https://mp.weixin.qq.com/s?__biz=MzA4MTg0MDQ4Nw==&mid=2247585767&idx=1&sn=d7936c12df11b67aec419aac11c852b0&scene=21#wechat_redirect)**

该版本搭载8大核心安全能力，覆盖应用访问准入、终端环境校验、账号权限管理、精细化行为管控与全流程安全审计，贯穿数字办公全场景，助力真正实现“数据不泄露、操作可追溯、风险可管控”。

**[3、魔方安全“AI+攻击面管理方案”重磅发布](https://mp.weixin.qq.com/s?__biz=MzU5ODgzNTExOQ==&mid=2247654297&idx=2&sn=ff4747e4573227510e0b2e5b2e975733&scene=21#wechat_redirect)**

魔方安全通过搭建“ASM × MCP”智能安全融合架构，全面赋能ASM系列产品，实现攻击面管理的自动化任务执行。简言之：魔方安全产品不仅拥有了"AI大脑"，更拥有了"AI手脚"——能够自动化完成复杂运维任务，实现数据查询、任务执行、漏洞管理的高度自动化和智能化，大幅提升安全运营效率。

**[4、全知科技2026重磅发布三大核心产品，重构全链路数据安全新范式](https://mp.weixin.qq.com/s?__biz=MzU0NDMxODY2Nw==&mid=2247526644&idx=1&sn=f1c6efd5a44d3ec18470f1cb56bf3c00&scene=21#wechat_redirect)**

全知科技春季数据安全产品发布会圆满落幕！全知科技重磅发布数据库风险监测系统、数据安全监测平台、AI数据分类分级系统三大核心产品，正式落地全通道数据安全监测体系，以AI技术与全链路防护能力，为企业数据安全打造“可见、可管、可控”的全新解决方案。

**[5、永信至诚发布「数字风洞」风电网络安全靶场](https://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454835391&idx=1&sn=29f14826ad77e61f538c7e15c360235c&scene=21#wechat_redirect)**

永信至诚基于「数字风洞」核心技术，推出风力发电网络安全靶场，融合工控协议仿真与攻防演练场景，构建高仿真、可对抗的风电安全验证环境，为风电企业、能源集团及科研机构提供覆盖安全研究、威胁复现、攻防演练、人才培养和装备测试的一体化能力平台。

**[6、派拉软件发布 MCP 网关× Ditto 双产品](https://mp.weixin.qq.com/s?__biz=Mzk0MjE5NzA3OA==&mid=2247511833&idx=1&sn=cba1a3d2408b08fe9a76e2f0ea13ae06&scene=21#wechat_redirect)**

一个面向“已有 API 的能力”，一个面向“没有接口的能力”；一个负责把已有能力快速接入 AI，一个负责把原本接不进来的能力先转出来，再纳入统一治理。
