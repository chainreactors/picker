# DeepSeek-V4-Pro API 宣布永久降价，调整为原定价的 1/4

发布时间:
2026-05-22 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
9527

DeepSeek 官方今日宣布，DeepSeek-V4-Pro 模型 API 价格将于 2026 年 5 月 31 日结束 2.5 折优惠活动后，正式调整为原定价的 1/4。
DeepSeek-V4-Pro 的 API **原价为**：
输入（缓存命中）：0.1 元 / 百万 Tokens
输入（缓存未命中）：12 元 / 百万 Tokens
输出：24 元 / 百万 Tokens

这一 API 截至 5 月 31 日拥有 2.5 折优惠活动，原本 6 月起恢复原价，但最新公告确认，DeepSeek-V4-Pro API 将永久降为原价的 1/4（相当于 2.5 折），相当于这个活动会一直保持下去。
