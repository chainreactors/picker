安装与设置Claude Code

Claude Code是一个需要安装的命令行工具（CLI），而不是一个独立的桌面应用。

安装：通常通过Node.js的包管理器npm安装，命令为

```
npm install -g @anthropic-ai/claude-code
```

启动：在终端进入你的项目目录后，运行 claude 命令即可启动交互会话

在本地通过 mkdir 等命令新建目录，使用claude命令进入

在指定位置新建并开发项目

#1.在你电脑的任意位置创建项目文件夹

```
mkdir ~/Desktop/my_new_projectcd ~/Desktop/my_new_project
```

#2.初始化Git仓库（可选但推荐，便于版本控制）

```
git init
```

#3.启动Claude Code开始开发

```
claude
```

![](https://mmbiz.qpic.cn/mmbiz_jpg/fnXiaEoiaI7TBmGKSLm6rDlJVqjFymAmJ5pnEYSpicZFFv9GImcOvicaHfWxCpILqXicP1rU6yrazQQEW8YkahyIDXiaiaSjn7x8JsqHloxU1DH0yE/640?wx_fmt=jpeg&from=appmsg)

启动后，你就可以在终端里用自然语言让Claude创建文件、编写代码、运行命令等。它会分析当前目录下的所有文件作为上下文

管理项目上下文：使用CLAUDE.md

为了让Claude更持久地“记住”你的项目结构、技术栈和编码规范，可以在项目根目录创建一个CLAUDE.md文件。你可以手动编写，或直接让Claude帮你分析生成

```
/init
```

执行这个命令，Claude会扫描项目并生成一个包含项目信息的 CLAUDE.md 文件，这能显著提升后续协作的准确度

Claude网页版（claude.ai）提供的“Projects”功能，其核心是一个云端知识库和上下文管理器，主要用于：

集中存储文档：上传API文档、设计稿、规范等到项目知识库，供所有相关对话调用。

设定项目级指令：为整个项目定义Claude的行为规范。

团队协作共享（付费团队版功能）。

它并非直接用于编辑本地文件，但可以作为你本地开发的知识后台。你可以在本地用Claude Code写代码，同时在网页版同一个“Project”里咨询关于项目背景的问题。
