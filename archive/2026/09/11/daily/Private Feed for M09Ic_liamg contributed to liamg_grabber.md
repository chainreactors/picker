go-git copies the whole body of a failed HTTP response into its transport error string (`plumbing/transport/http/common.go`). An HTML error page from a proxy or registry therefore becomes a multi-hundred-KB error.

Wraps the git HTTP transport in a RoundTripper that, on a non-2xx response, drops the body when it is HTML or over 1KB. Short plain bodies ("Repository not found.") are still kept.

Bodies are dropped, not truncated — a truncated page still carries timestamps and request IDs, so every error string stays unique and defeats deduplication downstream.

Measured on a 200KB HTML 502: error string goes from 204,964 bytes to 136.
