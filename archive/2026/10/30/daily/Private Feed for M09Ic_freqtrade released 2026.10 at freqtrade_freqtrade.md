# Highlighted changes

* Add Orderbook websocket support.
* Fully Decouple bot from RPC messaging for more reliable bot loop execution.
* Parameter values are now kept per strategy instance. Access them through `self.<param>.value`, not through the class.
* Armv7 (raspberry 32bit) image updated to python 3.13.
* Dropped support for python 3.11.
* Support changing strategy parameters from Backtesting UI (`webserver` mode only).
* FreqUI will now use the backtested strategy to plot in backtest mode (`webserver` mode only).
* `backtesting-show --export-params` now writes the parameters from a backtest back to the strategy.
* Improved efficiency for `AgeFilter` doing fewer calls for validated pairs.
