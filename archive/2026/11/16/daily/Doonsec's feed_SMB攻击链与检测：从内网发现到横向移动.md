SMB 主机发现 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) 攻击者可以针对内网网段探测 SMB 服务，并通过协议交互进一步收集目标主机的基础信息。 例如，使用 NetExec 进行 SMB 主机探测： nxc smb 192.168.4.0/24 这类操作不只是检测 TCP/445 端口是否开放，还可能进一步尝试 SMB 协议协商和主机信息收集，具体结果取决于目标服务及其配置。 确定目标主机后，攻击者通常还会查看其上开放了哪些共享，判断哪些目录可以访问： net view \\192.168.4.61 dir \\192.168.4.61\C$ net view 用于查看目标主机公开的共享列表；dir 则尝试访问指定共享路径并列出目录内容，结果取决于当前账号的权限及目标配置。 2. 检测思路 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) 内网 SMB 侦察通常表现为单一源主机在较短时间内向多个目标建立 TCP/445 连接。 因此，可以重点关注： * 单一源主机在短时间内访问大量 TCP/445 目标； * 目标地址呈顺序分布、访问间隔高度均匀，表现出批量探测特征； * SMB 探测范围明显超出该主机正常的业务访问范围。 单个 SMB 连接可能完全正常，但当访问目标数量、访问频率以及目标范围明显异常时，就可能呈现出内网侦察特征。 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8lvpAJHElQA6DiaJniaZb0daO3Kppz9ndV9Z2hHsjMuH61r2hu0jesGSg/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=hhvjiwep&tp=webp#imgIndex=3) 三、凭据访问：验证可用于横向移动的身份 完成内网主机发现后，攻击者通常还需要验证手上的账号口令能否访问其他主机。密码喷洒是一种常见的认证攻击方式——用少量密码尝试多个账号，以发现可用的身份，同时避免单个账号连续失败而触发锁定策略。 1. 密码喷洒：尝试验证 SMB 身份 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) 攻击者可以针对多个 Windows 主机尝试 SMB 身份认证，以判断哪些账号能够通过认证，并为后续访问其他主机提供条件。 例如，使用 NetExec 对指定 SMB 目标进行密码喷洒： nxc smb 192.168.4.0/24 -u users.txt -p 'Password' 其中，users.txt 为待测试的账号列表，-p 指定本轮尝试的密码。与针对单个账号尝试大量不同密码的暴力破解不同，密码喷洒的特点是失败分散在多个账号上，而不是集中在某一个账号。认证成功后，攻击者可能进一步利用这些身份访问其他 SMB 主机或管理资源。 2. 检测思路 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) 密码喷洒表现为同一源主机短时间内用多个账号反复认证，认证失败集中在多个账号而非单个账号，并可能在大量失败之后出现成功。可以重点关注： * 同一源主机短时间使用多个账号发起认证，失败分散且特征相似； * 大量失败之后出现认证成功； * 认证成功后随即访问此前较少访问的 SMB 主机或管理资源。 单次认证失败不足以定性。密码喷洒不一定表现为单个账号的大量失败记录，也不一定最终出现认证成功，因此需要从源主机、账号、目标主机和时间窗口等维度进行关联分析。 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8lvpAJHElQA6DiaJniaZb0daO3Kppz9ndV9Z2hHsjMuH61r2hu0jesGSg/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=hhvjiwep&tp=webp#imgIndex=3) 四、远程执行：SMB 如何成为远程执行通道 获得有效身份后，攻击者可以进一步利用 Windows 的远程管理能力，在其他主机上执行命令或启动程序。SMB 在这一过程中通常承担管理共享访问、文件传输及命名管道通信等作用，并与远程服务控制等机制结合形成远程执行链。 1. PsExec 类远程执行 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) PsExec 类工具通常结合 Windows 管理共享和服务控制接口，在目标主机上创建并启动服务，实现远程执行。 例如通过 PsExec 在远程主机上启动计算器： PsExec.exe \\192.168.4.61 -i -u user -p Password -accepteula "C:\Windows\System32\calc.exe" 该示例用于说明远程执行的基本方式，实际是否成功取决于账号权限、目标主机配置、服务管理权限和安全策略。 典型的 PsExec 远程执行过程涉及访问 ADMIN$ 等管理共享、向目标主机写入相关文件、通过 IPC$ 下的 \PIPE\svcctl 命名管道与服务控制接口交互，以及创建或启动远程服务。 2. 检测思路 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) 远程执行不是单一动作，而是一串前后关联的行为，可以从以下几类进行观察： * 管理资源访问——非常规源主机访问目标主机的 ADMIN$、IPC$ 等管理资源； * 文件与服务控制——管理共享访问后出现可疑文件写入，并伴随 svcctl 等服务控制接口相关通信； * 服务与进程活动——目标主机随后出现异常服务安装、启动或进程创建行为。 svcctl 是服务控制相关的 RPC 接口，通常通过 IPC$ 下的 \PIPE\svcctl 命名管道承载相关通信。典型行为链可以概括为： SMB 连接 → 管理共享访问 → 文件写入 → 服务控制通信 → 远程服务启动 → 目标进程活动 单独的管理共享访问、文件传输或服务控制通信都可能属于正常运维活动，但当多个行为在短时间内连续出现，并且源主机、目标主机和访问资源关系异常时，就可以作为识别疑似远程执行的重要依据。 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8lvpAJHElQA6DiaJniaZb0daO3Kppz9ndV9Z2hHsjMuH61r2hu0jesGSg/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=hhvjiwep&tp=webp#imgIndex=3) 五、横向移动：SMB 攻击的典型应用场景 在获得一台主机的控制权后，攻击者还可能尝试将控制范围扩大到更多主机。横向移动的技术分支较多，其中一种典型方式是 Pass-the-Hash（PTH）。 1. Pass-the-Hash ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) Pass-the-Hash 是一种利用 NTLM 认证机制的凭据滥用技术，不需要先还原出明文密码，也不依赖某个特定软件漏洞。攻击者在获取可用的 NTLM Hash 后，在支持相应 NTLM 认证流程的场景中，可以使用该 Hash 参与挑战—响应认证。 在 SMB 场景下，如果目标主机允许相应的 NTLM 认证，攻击者就可能利用该身份访问其他主机或管理资源，进而开展横向移动。 例如，用 NetExec 以指定用户名和 NTLM Hash 对目标 SMB 服务进行认证： nxc smb 192.168.4.61 -u User -H <NTLM\_HASH> 其中，-H 用于指定 NTLM Hash。该命令用于尝试 SMB 身份认证；认证成功并不意味着攻击者可以在目标主机上执行命令，后续是否发生远程执行还取决于账户权限和进一步使用的技术。 2. 检测思路 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8WFHRW8Evk0zcqAPJSmSRktqm69UXCNGtz8L1sz1g1Wg3sEYViamG90Q/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=ywon68xm&retryload=2&tp=webp#imgIndex=5) Pass-the-Hash 表现为使用已有 NTLM 身份访问新的 SMB 主机。由于认证过程与正常 NTLM 登录没有区别，单次认证无法直接判断。可以从两方面找线索： * 认证行为——同一账号在短时间内访问多台内部 SMB 服务器；认证源主机与该账号的日常访问模式明显不符；认证成功后进一步访问 IPC$、ADMIN$、C$ 等管理资源。 * 凭据来源——在上述认证涉及的源主机或目标主机上，出现凭据转储相关进程或文件，或对 lsass.exe 的异常访问与内存读取。 当认证行为偏离日常模式，且源主机或目标主机上存在对应的凭据转储痕迹时，可以进一步识别疑似 Pass-the-Hash 及其他基于凭据的横向移动行为。 ![图片](https://mmbiz.qpic.cn/mmbiz_png/NGIAw2Z6vnLSsTccx7j0fJVU0OOoqKA8lvpAJHElQA6DiaJniaZb0daO3Kppz9ndV9Z2hHsjMuH61r2hu0jesGSg/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1&randomid=hhvjiwep&tp=webp#imgIndex=3) 六、产品实践 SMB 攻击可能同时涉及网络通信、身份认证、文件操作和进程执行等多个环节。单一视角往往只能观察到攻击链的一部分，结合网络侧与终端侧的证据，能更完整地还原攻击过程。 山石智感（NDR）——聚焦网络侧检测。采用“特征匹配 + 行为基线”双路径检测：一方面结合已知攻击特征识别恶意活动；另一方面基于业务流量基线，从连接频率、访问对象与认证关系中识别异常。 ![](https://mmbiz.qpic.cn/sz_mmbiz_png/Zjic54DsBHbFJNL9GJ3dkL4N74BKXfs6RZ1F8vSibwKIuAzwQuObh4ibQxHcgoVDiaqWyAD69dic5RdDNFb8sDITIJibCXhIMZCzTpD173BvoxwbI/640?wx_fmt=png&from=appmsg) 图注：山石智感对 SMB 攻击链的检测 山石智铠（EDR）——聚焦终端侧检测。通过终端探针采集进程、文件、注册表、网络连接及管道等行为数据，结合静态特征分析与威胁情报识别可疑载荷，并对进程、文件和服务等活动进行行为分析与关联，逐步还原攻击在主机上的执行过程，定位攻击链中的关键环节。 ![](https://mmbiz.qpic.cn/mmbiz_png/Zjic54DsBHbEoh1kvCzWRGEl9xIAqeaNVetyANJJRBP7j5VmACydibicJfhic9VgESrIOgMafwT74OP1lAGSHyLK9PibAyKT...
