# iPhone未来图景：卫星通信将支持地图导航、照片传输及“自然交互”功能

据彭博社记者马克・古尔曼（Mark Gurman）在其最新《Power On》通讯中报道，苹果正积极开发一系列新的 iPhone 卫星连接功能，旨在将其能力从当前的 **“通过卫星发送紧急 SOS”** 显著扩展。

报告显示，苹果内部团队正在研发多项下一代功能，包括：

1. **苹果地图卫星导航（Apple Maps Satellite Navigation）**：即使在没有蜂窝网络或 Wi-Fi 覆盖的区域，也能通过卫星信号实现苹果地图导航——可能涉及地图数据的卫星传输。
2. **卫星照片消息（Satellite Photo Messaging）**：扩展当前的卫星消息功能，支持通过卫星发送照片，而非仅限于纯文本通信。
3. **自然使用模式（Natural Usage）**：旨在让卫星连接体验无缝且轻松——允许 iPhone 在室内、车内甚至放在口袋中时连接卫星，无需将设备指向天空。
4. **5G NTN 支持（5G NTN Support）**：2026 年的 iPhone 系列预计将更广泛地支持 **5G 非地面网络（NTN）**，使移动网络基站能够利用卫星基础设施扩展覆盖范围。
5. **第三方应用卫星 API 框架（Satellite API Framework for Third-Party Apps）**：苹果计划推出一套 API 框架，允许开发者选择性地将卫星连接集成到自己的应用中，不过并非所有服务都兼容。

报告还指出，苹果目前**无计划**通过卫星实现语音通话、视频通话或网页浏览。

目前，苹果的卫星服务免费提供——该公司最近将 iPhone 14 和 15 用户的免费使用期额外延长了一年。但古尔曼表示，对于更高级的功能，苹果最终可能要求用户直接向卫星运营商付费。

据报道，苹果曾讨论过运营自有卫星网络的可能性，但由于担心承担电信服务商角色而放弃了这一想法。

这些新功能的实现可能需要对 Globalstar 的基础设施进行升级，苹果已为此投资 11 亿美元。古尔曼推测，如果 SpaceX 收购 Globalstar，可能会加速必要基础设施升级的开发和部署。
