# 第一，中华民族共同体意识的文化认同

#

伏羲文化蕴含各民族人文共祖、共享文明本源的合和文化内核，形成了跨民族统一历史记忆与文化基因，是全体中华儿女共有的文化认同根基，为铸牢中华民族共同体意识提供共同的文化支撑。

也就是说，伏羲文化是中华民族共同体文化认同的文明源头、精神纽带、实践载体。因此，文化认同成为伏羲文化当代价值的最终落脚点。伏羲文化为“56个民族是一家”确立了血脉相通、文脉同源的文明起点。循着伏羲开创的华夏文脉，各族人民找到共有的精神根脉，在深度文化认同中牢固树立中华民族一家亲的集体共识。

一年一度举行的甘肃天水公祭伏羲大典等文化实践活动，已经成为凝聚跨民族集体文化认同的现实载体。

第二，全球华人聚力中华民族伟大复兴的文化源泉

伏羲文化承载着全体中华儿女同源共祖的文明记忆，是凝聚全球华人、同心共筑中华民族伟大复兴的核心文化源泉。依托这份共通文脉，海内外华人同心同德同向，凝聚起实现民族复兴的磅礴合力。

在全球华人心中，伏羲文化以独一无二的人文始祖标识，构筑起不分地域、世代相传的共同文化根基。深厚的根脉认同、共通的民族精神、传承的文化习俗，让伏羲文化成为团结海内外中华儿女、聚力推进中华民族伟大复兴不竭的文化源泉。

一年一度的天水公祭伏羲大典，都会邀请海外侨领、华侨代表、港澳台同胞共同参与。共祭人文始祖的庄重仪式，唤醒全球华人根脉意识、远古记忆和祖脉荣光，激发关心祖国发展、投身家乡建设的积极主动性，进而让伏羲文化传播更广、影响更大、认识更深、情结更重、血脉更浓。

# 第三，促进两岸统一的文化祖脉

#

伏羲文化是维系海峡两岸的万年文化祖脉，一年一度两岸共祭人文始祖活动，印证两岸同源一体、同根共祖。依托公祭伏羲大典，以共祖文脉凝聚两岸民心，就是为为推进祖国和平统一，注入持久深厚的文化力量。

今年，我遇到了台湾“小当归”壹壹参加伏羲大典，也看到她通过天水融媒发出的心声：海峡隔不断我们的血脉，我们台湾人也是炎黄子孙、华夏儿女，我们全部都是中国人。天水是我们所有中华儿女寻根的老家，伏羲是我们共同的祖先。“小当归”壹壹，用她稚嫩的童声，说出来两岸同胞应该有的共同心愿：台湾早日回家。

恰此时，我们尤其要铭记伏羲文化的“大一统”初始价值。正是有了伏羲文化的“一画开天”，才有了中华民族共同的文化源头。

正因为如此，伏羲“一画开天”，就是中华民族第一次大一统。天水这片神奇的土地上，从伏羲爷肇启文明，老秦人统一天下，再到唐宗宋祖安邦定国，都建立了中华民族“大一统”的历史性功勋。到了今天，两岸人民祝愿祖脉永昌，就必然拥有一个统一的中国，这个强烈的愿望，谁也无法阻挡，必将由这一代人变为现实。

# 第四，摒弃“丛林法则”的文化法宝

#

作为三皇之首，伏羲带领上古先民走出蒙昧、开启文明，他仰观天象、俯察地理，观万物变化而首创八卦，开启阴阳哲学，为《易经》奠定根基，让先民摆脱懵懂的神话思维，拥有了理性认知世界的智慧。他定嫁娶、分姓氏、禁同姓通婚，终结了混乱的原始群居生活，建立起最早的人伦礼教，让世间有秩序、族群有礼法。他斫桐为琴、练丝为弦，创制琴瑟、谱写乐章，让先民在温饱之外，拥有了丰盈的精神世界与艺术追求。

纵观伏羲文化的历史贡献，其实就是让人类社会从蒙昧状态进入文明时代。这非常类似当今的“丛林法则”进入“构建人类命运共同体”时代，都是打破旧世界的开创新历史功绩。

一个时代有一个时代的主题，一代人有一代人的使命，去年参加公祭伏羲大典之前，我主编出版了《中国故事到中国味道---天水麻辣烫和新质生产力》，明确断言共产党人就是“新时代的伏羲”，用“一带一路”实现新时代的“一画开天”，带领人类社会走出“丛林法则”的屠杀掠夺，崇尚合作共赢的“构建人类命运共同体”新时代文明。伏羲文化正在成为战胜“丛林法则”的文化法宝。

# 第五，实现高质量发展的文化典范

当前，中国式现代化进入高质量发展的新时代。不妨回溯万年之前，伏羲作为氏族首领脱颖而出，也正是基于“一画开天”的高质量。人类社会从荒蛮之中走来，正是伏羲文化这一次不同凡响的高质量跃进，才有了中华民族绵延不断的文明光芒，照耀东方、照耀世界，点亮人心，成为历史长河中靓丽的风景线。

作为文化典范，就要映射到参与公祭伏羲大典的每一个人，我们弘扬伏羲文化，首要的是敬仰、尊崇，切忌借着万民敬仰、华人尊重、两岸认同的伏羲大典，走偏、走歪、走邪，尤其是自媒体抱着不可告人的目的，将个人渲染成“国民偶像级文化使者” ，是极其幼稚的。这让我想起先赚“一个小目标”和“国民老公”的现代典故，最后必然是一个笑料。

公祭伏羲大典之后，天水市委、市政府在给全市人民的感谢信中说：礼乐虽止，文脉永昌；初心不改，砥砺前行。市委、市政府再次向所有倾情付出、鼎力支持大典举办的全市各界人士表示衷心感谢！愿全市上下接续传承千年文脉、厚植城市文明底蕴，凝心聚力、实干奋进，共同谱写天水经济社会高质量发展崭新篇章！

让我们携起手来，尊崇伏羲文化，两岸共情、世界共同，迈入高质量发展的新时代。

**一句话总结：兼顾国际国内两个大国，团结两岸和港澳同胞，聚焦高质量发展，充分发挥社会主义制度优势，不忘初心，让人民有更多的获得感、幸福感和安全感，实现祖国统一，这就是共产党人做“新时代”伏羲，对14亿多中国人民和全球华人郑重的承诺，让我们每一个人从自己做起，走出“丛林法则”，融入“构建人类命运共同体”的新时代文明。**

秦安，2026年6月23日，北京海淀。
