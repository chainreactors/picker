# 微软正致力于重建用户对Windows的信任

发布时间:
2026-01-30 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
1688

消息人士称，Windows工程师现在正集中精力在未来几个月内修复 Windows 11 的核心问题，这一过程被称为“swarming”。微软正在调派工程师紧急修复 Windows 11 的性能和可靠性问题，旨在阻止该操作系统因积弊过深而走向衰亡。微软还将在今年剩余时间里专注于解决所有 Windows 11的痛点。“我们从充满热情的客户和Windows预览体验成员社区收到的反馈非常明确。我们需要以对人们有意义的方式改进Windows，”Windows和设备部门总裁帕万·达武卢里在发表的一份声明中表示。“今年，你们将看到我们专注于解决从客户那里持续听到的痛点：提升系统性能、可靠性以及Windows的整体体验。”
