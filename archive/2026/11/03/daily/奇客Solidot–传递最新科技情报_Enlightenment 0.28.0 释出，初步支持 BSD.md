## Enlightenment 0.28.0 释出，初步支持 BSD

[![Linux](https://icon.solidot.org/images/topics/topiclinux.png?123)](/search?tid=7 "Linux")

[Edwards](/~Edwards) (42866)发表于 2026年11月03日 16时16分 星期二 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85783&appkey=1370085986&title=Enlightenment%200.28.0%20%E9%87%8A%E5%87%BA%EF%BC%8C%E5%88%9D%E6%AD%A5%E6%94%AF%E6%8C%81%20BSD "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自太阳系大乐透**

轻量级桌面环境 Enlightenment 项目释出了 v0.28.0。主要变化包括：初步支持 NetBSD，支持 Network Manager，原生支持 PipeWire，新的剪贴板管理器，电池管理、AC 轮询等相关代码进行重写，新增设置电池阈值和支持 ACPI 电源配置等等，以及大量 bug 修复和更改。
https://www.enlightenment.org/news/2026-10-31-enlightenment-0.28.0
