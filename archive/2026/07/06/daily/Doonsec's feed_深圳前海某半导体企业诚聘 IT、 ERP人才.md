**招聘计划**

Recruitment plan

01

IT工程师（薪资：面议）

**岗位职责：**

1、AD 域运维管理

负责企业 AD 域环境搭建、账号创建 / 注销 / 权限分配、组策略配置与批量下发；保障域控服务器稳定运行，处理域账号登录、权限、组策略等故障，配合完成终端统一管控。

2、数据防泄漏（DLP）管理

负责DLP系统日常运维、策略配置、规则优化、告警分析与事件处置；针对文件外发、外设拷贝、屏幕截屏、邮件传输等行为做审计管控，跟踪敏感数据泄露风险，输出安全审计报表。

3、网络边界安全（防火墙）

负责企业互联网出口防火墙日常运维、安全策略梳理、规则优化、端口与访问权限管理；监控边界流量、攻击告警，排查网络访问异常，配合完成网络安全加固。

4、终端与桌面运维

负责公司全部门办公终端（台式机、笔记本、外设）日常故障排查、系统安装、软件部署、补丁更新、病毒查杀；配合EDR、网络准入系统做终端安全基线加固，保障终端正常办公。

5、安全合规与体系落地

跟进网络安全等级保护、ISO27001、数据安全相关合规要求，完成日志留存、安全审计、漏洞整改、风险闭环；编制安全运维文档、巡检报告、应急处置预案。

6、其他工作

配合完成NAS存储、VPN、准入控制系统运维；开展员工安全培训，宣导终端安全规范；处理各类网络、信息安全突发事件，完成领导交办的其他工作。

**任职要求：**

1、本科及以上学历，计算机、网络、信息安全相关专业，3年以上企业信息安全、网络运维全职经验，有中大型企业安全体系建设经验优先。

2、熟练掌握Windows AD域部署、组策略、账号权限管理，具备大中型企业域环境运维经验优先。

3、熟练操作主流防火墙，具备策略优化、故障排查、攻防告警分析能力。

4、有完整DLP、EDR、网络准入项目落地及运维经验，熟悉数据防泄露管控逻辑。

5、精通Windows系统运维，具备扎实的桌面软硬件故障排查能力，能独立处理终端各类问题。

6、熟悉网络准入、备份存储、VPN等常用安全设备 / 系统，了解等保、数据安全相关合规要求。

7、具备良好的问题分析、应急处置能力，工作细心负责，沟通顺畅，能适应阶段性加班与现场支撑。

02

ERP工程师（薪资：面议）

**岗位职责：**

1、负责金蝶云星空企业版系统的日常二次开发工作，包括但不限于插件开发（C#/.NET）、表单扩展、报表开发及工作流配置。

2、基于金蝶BOS平台，根据业务部门需求进行功能定制，确保系统功能与业务流程的高度匹配。

3、负责ERP与MES的接口设计与开发，实现基础资料、生产订单、工单汇报、物料消耗、质量数据等关键业务数据的双向同步。

4、负责集成中间件的维护与监控，确保数据传输的准确性、及时性和一致性。

5、协同MES厂商及内部团队，排查并解决集成过程中的数据异常与接口报错问题。

6、负责金蝶云星空系统的日常运维管理，包括用户权限管理、账号配置、系统补丁更新及版本升级。

7、响应内部用户（财务、供应链、生产等部门）的技术支持请求，快速定位并解决系统故障。

8、编写系统操作手册、开发文档及运维知识库，定期对关键用户进行系统操作培训。

**任职要求：**

1、统招大专及以上学历，计算机、软件工程、信息管理或相关专业。

2、三年以上ERP系统开发或实施经验，其中至少两年金蝶云星空企业版实际开发与运维经验。

3、有制造业信息化背景，熟悉生产计划、供应链、财务等至少一个领域的业务流程。

4、精通C# / .NET 开发语言，熟悉SQL Server / Oracle数据库，能编写复杂的存储过程及SQL查询。

5、熟悉金蝶BOS开发平台，掌握金蝶云星空插件开发、Web API接口调用及单据转换规则。

6、熟悉HTTP/HTTPS、JSON、XML 等数据交互协议，有RESTful API 开发经验者优先。

7、必须具备MES、WMS或OA等外围系统与ERP的对接经验，熟悉异构系统集成的常见方案（如中间库、Web API、ESB等）。

8、具备良好的沟通协调能力，能够耐心与业务部门沟通，具备较强的服务意识。
