# BackBox Linux 10 released!

November 19, 2026/in [Releases](https://blog.backbox.org/category/releases/)

The BackBox Team is happy to announce the new major release of BackBox Linux, version 10 codename “Resolute Raccoon”.

As usual, this major release includes many updates. These include a new kernel, new and updated tools and some structural changes, with a focus on maintaining stability and compatibility with Ubuntu 26.04 LTS.

**What’s new**

* Updated Linux Kernel 7.0
* Updated desktop environment (Xfce 4.20)
* Updated hacking tools, including Metasploit Framework 6.5, Nmap 7.98, Wireshark 4.6, sqlmap 1.10, hashcat 7.1 and ZAP 2.17
* New tools: ffuf and gobuster for web content discovery, AFL++ for fuzzing, GDB, LLDB, ltrace and checksec for binary analysis, smbclient and the Kerberos and LDAP clients for Windows and Active Directory networks, plus hashID, mdk4, Firejail, apksigner and aapt
* Reworked anonymous mode: DNS queries now go through Tor as well, IPv6 is blocked while it is active, and `anonymous stop` restores the original network settings
* Better VMware support: open-vm-tools in the live session too, and the desktop follows the size of the VMware window
* Installer with normal and minimal installations, full disk encryption (LVM on LUKS) and ZFS support
* Updated ISO Hybrid with UEFI and Secure Boot support

**System requirements**

* 64-bit processor
* 2 GB of system memory (RAM)
* 30 GB of disk space for installation
* Graphics card capable of 800×600 resolution
* USB port and a USB drive of 8 GB or more

The ISO image for 64bit architecture can be downloaded, directly or via torrent, from the official web site download section:

<https://linux.backbox.org/download/>

We are also working to fully integrate agentic cyber operations into BackBox Linux through [BackBox AI](https://backbox.dev/en/backbox-ai.html), our new technology.

BackBox Linux remains a free, community-driven open source project. If you find it useful, please consider supporting it with a donation from the download page.
