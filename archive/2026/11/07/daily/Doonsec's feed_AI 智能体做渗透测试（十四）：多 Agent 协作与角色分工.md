## 1. 引言：单 Agent 的天花板

前十三篇，我们把一个单 Agent 从「会思考」一路打磨到「敢执行」：它能规划、能调工具、能记忆、能观测、能控成本、能在沙箱里安全执行。到这一步，一个单 Agent 的渗透测试闭环已经跑通了。

但只要真正拿它跑一次完整的授权测试，就会撞上三堵墙：

* • **上下文墙**：一次完整渗透涉及侦察、扫描、漏洞验证、利用、后渗透、报告，每一步都产生大量输出。全部塞进一个上下文窗口，要么爆掉，要么被压缩得面目全非，Agent 开始「忘事」。
* • **能力墙**：侦察需要广撒网、快速试错；漏洞验证需要严谨推理、反复确认；报告需要结构化归纳。这些能力对模型的要求差异很大，用一个 Agent 全包，往往哪一项都做不精。
* • **可靠性墙**：单 Agent 一旦在某一步「跑偏」（比如误判一个漏洞、陷入死循环），没有第二双眼睛纠正它，错误会一路传导到最终结论。
