该概念验证程序托管在名为 PrettyPrague 的 GitHub 存储库中，它将问题归因于 Avast Sandbox 组件中的一个缺陷。

根据存储库的 README，此漏洞允许具有本地执行权限的攻击者利用沙箱的提升权限来检索 SAM 数据库并获得完整的 SYSTEM 级命令 shell。

以 SYSTEM 身份运行程序可获得 Windows 系统上的最高本地权限。如果此漏洞得到验证，攻击者将能够绕过终端安全产品本应强制执行的权限边界。

这使得通常旨在保护操作系统的防病毒软件，变成了完全控制本地系统的潜在途径。

安全帐户管理器 (SAM) 数据库至关重要，因为它存储着敏感的本地帐户凭据，包括密码哈希值。获取 SAM 注册表单元的访问权限，可以方便地进行离线密码破解尝试、窃取凭据，并利用泄露的本地管理员凭据在组织内部进行横向移动。

MSNightmare 的 README 文档表明，该 PoC 与“任何版本的 Avast 防病毒软件”兼容，并且已使用 Avast 和 Windows 11 25H2 的补丁版本成功进行了测试。

该存储库上次更新于 8 月 30 日，包含 C 和 C++ 源代码、Visual Studio 项目文件、头文件、已编译的 x64 发布目录和 offreg.lib 库。

截至目前，GitHub 项目尚未列出正式版本、CVE 编号、厂商公告、受影响版本信息或补丁详情。研究人员还提到，该漏洞可能影响 GenDigital 的其他安全产品，例如 AVG 和 Norton。

然而，在 GenDigital 确认哪些软件受到影响以及在什么情况下受到影响之前，这些说法仍未经证实。

源代码和编译后的发布目录的公开，加剧了防御者的紧迫感。公开的概念验证（PoC）虽然可以加快研究人员的独立验证，但也降低了那些已经拥有本地Windows终端访问权限的威胁行为者的攻击门槛。

据报道，该漏洞似乎是本地权限提升问题，而非初始访问缺陷。攻击者需要拥有在目标机器上执行代码的权限，这可以通过网络钓鱼、恶意下载、窃取远程访问凭据、利用其他漏洞或滥用合法软件等方式实现。
