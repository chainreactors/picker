To address a vulnerability in Google's Brotli compression technology that could allow attackers to corrupt process memory, Microsoft is urging .NET users to update "as soon as possible" after releasing an out-of-band (OOB) security update.

It released new versions for .NET 8, 9, 10, and .NET 11 to patch against the Brotli bug, following similar updates from Node.js, Python, and other projects.

Senior program manager Rahul Bhandari said in [the October 25 release](https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/) that the buffer overflow vulnerability in Brotli, tracked as CVE-2026-111497 and rated 8.1 under CVSS v3.1 in Microsoft's advisory, could allow an unauthenticated attacker to read or corrupt process memory, potentially resulting in information disclosure, denial of service, or elevation of privilege.

REG AD

Microsoft’s own [advisory](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-111497) for the vulnerability, which some are referring to as [Broccoli2Shell](https://broccoli2shell.com/) or Node2Shell, confirms that while [experts have cobbled working exploits together](https://www.imperva.com/blog/node2shell-from-brotli-data-to-remote-code-execution/), there is nothing to suggest that criminals are using them in successful attacks.

REG AD

However, its exploitability assessment reads: “Exploitation More Likely.”

Broccoli2Shell was first disclosed on October 21 by the Node.js team, which released fixes for ten vulnerabilities, the most serious of which was CVE-2026-111497.

Node.js credited Khai Tran and Sylvie Mayer of OpenAI’s Codex Security with the discovery, but failed to mention why it was only recognized as a security flaw and disclosed properly in October, despite the underlying bug having been fixed in Brotli's source code in February.

OpenAI filled in the gap with a [Xeet](https://x.com/OpenAI/status/2113766354386084338): “This root cause issue was actually fixed in the Brotli source code in February, but it wasn’t known at the time that it gave rise to a security vulnerability, and there was no more recent release of Brotli.

“Since Brotli is built into other software, any software which includes this library needs to take the update too, followed by the users of that software.”

Attackers can exploit vulnerable systems by providing them with malicious Brotli-compressed data via a specially crafted request.

The vulnerability went slightly under the radar due to the disclosure timing closely aligning with that of [PHP2Shell](https://www.theregister.com/columnists/2026/10/26/php2shell-is-a-warning-shot-for-vulnerability-disclosure/5304918), although fixing the critical flaw should be a priority ...
