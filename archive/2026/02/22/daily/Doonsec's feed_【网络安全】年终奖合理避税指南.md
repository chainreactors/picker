## 年终奖计税方式

根据中国个人所得税法，年终奖有两种计税方式：

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe0UYyBbuzHUvkibjMqLdYRWpUzptw9A7kvEw8h7OjDgo8edz0LsQojSxZZia32w8W3ejKNb3uSqBvQA0GPcjAKDHVRlj1kxIkZfE/640?wx_fmt=png&from=appmsg)

### 单独计税

年终奖不并入当年综合所得，以全年一次性奖金收入除以12个月得到的数额，按照按月换算后的综合所得税率表，确定适用税率和速算扣除数，单独计算纳税。

**计算公式：**

```
应纳税额 = 全年一次性奖金收入 × 适用税率 - 速算扣除数
```

**适用税率表（按月换算）：**

| 级数 | 全月应纳税所得额 | 税率 | 速算扣除数 |
| --- | --- | --- | --- |
| 1 | 不超过3000元 | 3% | 0 |
| 2 | 超过3000元至12000元 | 10% | 210 |
| 3 | 超过12000元至25000元 | 20% | 1410 |
| 4 | 超过25000元至35000元 | 25% | 2660 |
| 5 | 超过35000元至55000元 | 30% | 4410 |
| 6 | 超过55000元至80000元 | 35% | 7160 |
| 7 | 超过80000元 | 45% | 15160 |

---

### 合并计税

年终奖并入当年综合所得，与工资薪金、劳务报酬、稿酬、特许权使用费等合并计算纳税。

**适用人群：**

* • 全年综合所得较低的人群
* • 专项附加扣除较多的人群
* • 需要通过合并计税减少税负的人群

---

## 典型案例分析

为了让大家更直观地理解年终奖计税方式，我们选取几个典型案例进行详细分析。

### 张三：年终奖8万元

**基本情况：**

* • 年终奖：80,000元
* • 假设全年工资薪金：200,000元
* • 专项扣除（三险一金）：40,000元
* • 专项附加扣除：36,000元（子女教育+赡养老人）

#### 方式一：单独计税

```
步骤1：计算月度应纳税所得额
80,000 ÷ 12 = 6,666.67元

步骤2：确定适用税率和速算扣除数
6,666.67元属于"超过3,000元至12,000元"区间
税率：10%
速算扣除数：210

步骤3：计算应纳税额
80,000 × 10% - 210 = 7,790元
```

**工资薪金个税（综合所得）：**

```
应纳税所得额 = 200,000 - 60,000（起征点） - 40,000 - 36,000 = 64,000元

综合所得个税 = 64,000 × 10% - 2,520 = 3,880元
```

**合计税额：** 7,790 + 3,880 = **11,670元**

#### 方式二：合并计税

```
全年综合所得 = 200,000 + 80,000 = 280,000元

应纳税所得额 = 280,000 - 60,000 - 40,000 - 36,000 = 144,000元

综合所得个税 = 144,000 × 10% - 2,520 = 11,880元
```

**合计税额：** **11,880元**

#### 结论对比

| 计税方式 | 税额 | 到手金额 |
| --- | --- | --- |
| 单独计税 | 11,670元 | 268,330元 |
| 合并计税 | 11,880元 | 268,120元 |
| **差异** | **少交210元** | **多拿210元** |

**张三选择：单独计税更划算**

---

### 李四：年终奖15万元

**基本情况：**

* • 年终奖：150,000元
* • 假设全年工资薪金：300,000元
* • 专项扣除（三险一金）：60,000元
* • 专项附加扣除：48,000元（子女教育×2+赡养老人）

#### 方式一：单独计税

```
步骤1：计算月度应纳税所得额
150,000 ÷ 12 = 12,500元

步骤2：确定适用税率和速算扣除数
12,500元属于"超过12,000元至25,000元"区间
税率：20%
速算扣除数：1,410

步骤3：计算应纳税额
150,000 × 20% - 1,410 = 28,590元
```

**工资薪金个税（综合所得）：**

```
应纳税所得额 = 300,000 - 60,000 - 60,000 - 48,000 = 132,000元

综合所得个税 = 132,000 × 10% - 2,520 = 10,680元
```

**合计税额：** 28,590 + 10,680 = **39,270元**

#### 方式二：合并计税

```
全年综合所得 = 300,000 + 150,000 = 450,000元

应纳税所得额 = 450,000 - 60,000 - 60,000 - 48,000 = 282,000元

综合所得个税 = 282,000 × 20% - 16,920 = 39,480元
```

**合计税额：** **39,480元**

#### 结论对比

| 计税方式 | 税额 | 到手金额 |
| --- | --- | --- |
| 单独计税 | 39,270元 | 410,730元 |
| 合并计税 | 39,480元 | 410,520元 |
| **差异** | **少交210元** | **多拿210元** |

**李四选择：单独计税更划算**

**特别提醒：** 李四的年终奖15万元正好落在"144,001元 - 160,500元"无效区间内！

如果企业愿意将年终奖调整为144,000元，节省更多：

* • 144,000元单独计税：144,000 × 10% - 210 = 14,190元
* • 比150,000元少交：28,590 - 14,190 = **14,400元**

### 王五：年终奖30万元

**基本情况：**

* • 年终奖：300,000元
* • 假设全年工资薪金：500,000元
* • 专项扣除（三险一金）：100,000元
* • 专项附加扣除：60,000元（子女教育×2+赡养老人+房贷）

#### 方式一：单独计税

```
步骤1：计算月度应纳税所得额
300,000 ÷ 12 = 25,000元

步骤2：确定适用税率和速算扣除数
25,000元正好是"超过25,000元"的临界值
税率：25%
速算扣除数：2,660

步骤3：计算应纳税额
300,000 × 25% - 2,660 = 72,340元
```

**工资薪金个税（综合所得）：**

```
应纳税所得额 = 500,000 - 60,000 - 100,000 - 60,000 = 280,000元

综合所得个税 = 280,000 × 20% - 16,920 = 39,080元
```

**合计税额：** 72,340 + 39,080 = **111,420元**

#### 方式二：合并计税

```
全年综合所得 = 500,000 + 300,000 = 800,000元

应纳税所得额 = 800,000 - 60,000 - 100,000 - 60,000 = 580,000元

综合所得个税 = 580,000 × 30% - 52,920 = 121,080元
```

**合计税额：** **121,080元**

#### 结论对比

| 计税方式 | 税额 | 到手金额 |
| --- | --- | --- |
| 单独计税 | 111,420元 | 688,580元 |
| 合并计税 | 121,080元 | 678,920元 |
| **差异** | **少交9,660元** | **多拿9,660元** |

**王五选择：单独计税更划算，节省近1万元！**

### 赵六：年终奖45万元（高收入案例）

**基本情况：**

* • 年终奖：450,000元
* • 假设全年工资薪金：800,000元
* • 专项扣除（三险一金）：160,000元
* • 专项附加扣除：72,000元（子女教育×2+赡养老人+房贷+继续教育）

#### 方式一：单独计税

```
步骤1：计算月度应纳税所得额
450,000 ÷ 12 = 37,500元

步骤2：确定适用税率和速算扣除数
37,500元属于"超过35,000元至55,000元"区间
税率：30%
速算扣除数：4,410

步骤3：计算应纳税额
450,000 × 30% - 4,410 = 130,590元
```

**工资薪金个税（综合所得）：**

```
应纳税所得额 = 800,000 - 60,000 - 160,000 - 72,000 = 508,000元

综合所得个税 = 508,000 × 30% - 52,920 = 99,480元
```

**合计税额：** 130,590 + 99,480 = **230,070元**

#### 方式二：合并计税

```
全年综合所得 = 800,000 + 450,000 = 1,250,000元

应纳税所得额 = 1,250,000 - 60,000 - 160,000 - 72,000 = 958,000元

综合所得个税 = 958,000 × 35% - 85,920 = 249,380元
```

**合计税额：** **249,380元**

#### 结论对比

| 计税方式 | 税额 | 到手金额 |
| --- | --- | --- |
| 单独计税 | 230,070元 | 1,019,930元 |
| 合并计税 | 249,380元 | 1,000,620元 |
| **差异** | **少交19,310元** | **多拿19,310元** |

**赵六选择：单独计税更划算，节省近2万元！**

### 低收入人群案例：年终奖并入更划算

**小明：低收入情况**

* • 年终奖：20,000元
* • 全年工资薪金：60,000元
* • 专项扣除：12,000元
* • 专项附加扣除：24,000元

#### 单独计税

* • 年终奖个税：20,000 × 3% = 600元
* • 工资个税：0（未达起征点）
* • **合计：600元**

#### 合并计税

* • 综合所得：80,000元
* • 应纳税所得额：80,000 - 60,000 - 12,000 - 24,000 = -16,000元
* • **合计：0元**

**结论：合并计税更划算，节省600元！**

## 合理避税策略

### 选择最优计税方式

**建议：**

1. 1. **分别计算两种方式的应纳税额**
2. 2. **选择税负较低的方式**
3. 3. **在年度汇算清缴时可以重新选择**

**一般规律：**

* • **高收入人群**：通常单独计税更划算
* • **中低收入人群**：可能合并计税更划算
* • **建议使用个税APP进行试算**

---

### 避开税率临界点

**"多发1元，多交几千甚至几万元税"的现象**

由于税率累进的特点，在某些临界点附近，多发1元可能导致税率跳档，税负大幅增加。

**典型临界点示例：**

| 年终奖金额 | 税率 | 税额 | 到手金额 |
| --- | --- | --- | --- |
| 36000元 | 3% | 1080元 | 34920元 |
| 36001元 | 10% | 3390.1元 | 32610.9元 |
| **差异** | - | **多交2310.1元** | **少拿2309.1元** |

**常见临界点区间：**

* • 36000元 - 38566.67元
* • 144000元 - 160500元
* • 300000元 - 318333.33元
* • 420000元 - 447500元
* • 660000元 - 706538.46元
* • 960000元 - 1120000元

**建议：**

* • 避开上述无效区间
* • 在临界点以下发放更划算
* • 超出部分可考虑其他方式发放

---

### 合理安排发放时间

**技巧：**

1. 1. **避开年初集中发放**：如果多人同时在年初发放，可能导致个税预扣预缴较高
2. 2. **分散到不同月份**：与企业协商，将部分奖金分散到不同月份
3. 3. **结合年度收入情况**：根据全年收入预测选择最优发放时间

---

### 利用专项附加扣除

**确保足额申报专项附加扣除：**

1. 1. **子女教育**：每个子女每月1000元
2. 2. **继续教育**：学历（学位）教育每月400元，职业资格教育当年3600元
3. 3. **大病医疗**：医保报销后个人负担超过15000元的部分，在80000元限额内据实扣除
4. 4. **住房贷款利息**：每月1000元，最长240个月
5. 5. **住房租金**：根据城市不同，每月800元、1100元或1500元
6. 6. **赡养老人**：独生子女每月2000元，非独生子女分摊每月2000元

**注意：**

* • 专项附加扣除在综合所得中扣除
* • 如果选择年终奖单独计税，不影响专项附加扣除的使用
* • 确保在年度汇算清缴时足额申报

---

### 企业福利替代

**合法的福利替代方式：**

1. 1. **实物福利**

* • 购物卡、礼品卡
* • 员工旅游
* • 健康体检
* • 商业保险

2. 2. **教育培训**

* • 职业培训
* • 学历教育补贴
* • 技能提升课程

3. 3. **长期激励**

* • 股权激励
* • 企业年金
* • 职业年金

**注意：**

* • 某些福利可能需要缴纳个税
* • 具体请咨询税务专业人士
* • 确保符合相关法律法规
