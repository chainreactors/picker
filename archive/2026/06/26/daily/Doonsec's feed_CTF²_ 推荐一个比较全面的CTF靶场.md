**背景分析**

![](https://mmbiz.qpic.cn/mmbiz_png/x2ibBTFXYHicKVzoiaRficiaiaNCL5h0m5FtwDffYIcYCia9AicYFPk8tOOnsdXO1tOTM4b600ukkEARF6VmLxpWULyOicNZfIgNzSmm74PWRKCs6HXY/640?wx_fmt=png&from=appmsg)

随着网络安全攻防对抗日益激烈，传统的安全人才培养与竞赛平台逐渐暴露出功能分散、赛制单一、学习资源碎片化等问题。`BUUCTF`作为国内知名的`CTF`训练平台已进入归档模式，亟需更具整合能力的新平台承接。`CTF`²由安恒信息数字人才创研院推出，是在`BUUCTF`基础上升级的新一代集成化网络安全实战平台，深度融合了竞赛运营、日常训练、课程教学和`Writeup`复盘等多种能力，统一支持`CTF`、`AWD`、`AWDP`、理论赛及`AI Agent`赛事等多种竞赛形式，并引入`AI`能力辅助选赛与智能分析，配套完整的自动判分、实时排行榜、赛后复看等全流程支撑机制，为网络安全学习者、参赛者和组织者提供了一个高效、统一、智能化的实战环境。

**安装介绍**

```
●●●

地址：https://ctf2.dasctf.com/
```

`CTF`²为基于`Web`浏览器的在线平台，无需下载安装任何客户端，直接在浏览器中访问即可使用，适配`Windows`、`Linux`、`macOS`等操作系统。

```
●●●

# 直接访问平台地址：
# 在浏览器中打开以下网址即可进入CTF²主界面
https://ctf2.dasctf.com/
```

平台注册与登录步骤：

```
●●●

# 1. 访问CTF²官网，点击页面右上角注册按钮
# 2. 填写用户名、密码、邮箱等基本信息完成账号注册
# 3. 注册成功后使用账号密码登录平台
# 4. 登录后即可进入个人中心，参与每日一练、公开练习场等内容
```

平台基于浏览器访问，无系统兼容性限制，注册并登录后即代表可正常使用。若页面加载异常，可尝试更换浏览器或检查网络环境。

功能介绍

![](https://mmbiz.qpic.cn/sz_mmbiz_png/x2ibBTFXYHicINaSxMAyHxh8h4BPKicAb8QcS3hTjPpicTue7EICtGzrFA0ZmXKMSkncCZYqibwUUV0F4QqAKvaXJ5JnudrvoNREC8whk4iacS58Q/640?wx_fmt=png&from=appmsg)

`CTF`²提供每日一练功能，系统每日自动推送精选题目，完成当前题目或经过一定时间后解锁下一题，帮助使用者保持持续学习的节奏与习惯，无明确对应使用代码。

平台设有公开练习场，涵盖六大类别模块，使用者可按类别浏览并报名参与对应训练项目，自由选择感兴趣的方向进行实战练习

![](https://mmbiz.qpic.cn/mmbiz_png/x2ibBTFXYHicLAMsttRwLBgPcsRYwN51QPbUZCGfGPE1adHD1jThrpXZsOcGOKUe8rkdFYehCAibiaAFwDmj1jJpxGXn4aANx3MvVEibh8F8d34Q/640?wx_fmt=png&from=appmsg)

平台支持创建与管理竞赛，涵盖`CTF`解题赛、`AWD`攻防对抗赛、`AWDP`混合赛、理论赛及`AI Agent`赛事等多种赛制，支持自定义多阶段赛程、晋级规则与评分规则，一键开赛、自动判分、实时排行榜展示：

```
●●●

# 创建新竞赛：
# 进入竞赛管理模块
# 选择赛制类型（CTF/AWD/AWDP/理论赛/AI Agent）
# 配置竞赛阶段、晋级规则与评分规则
# 发布竞赛后自动开启报名与参赛通道
```

平台内置`Writeup`复盘模块，支持提交、查看与评审历史题目的解题思路与源码，便于赛后总结与知识沉淀。同时平台还提供课程与班级功能，支持组织在线教学与学员管理，无明确对应使用代码。

![](https://mmbiz.qpic.cn/mmbiz_png/x2ibBTFXYHicICM1sH6SwFm7wc70F0qIlVoyuxWTcicOiaNxw5K0gNxiaTQWPfFzudeibx8CY7jdqOwN3xQ8pssG4mSuqqia993Ok10XU9nLODkgYQ/640?wx_fmt=png&from=appmsg)

`BUUCTF`旧平台已进入归档模式，其原有题目与练习资源已迁移至`CTF`²平台，使用者可在`CTF`²中继续访问`BUUCTF`历史题目，实现新旧平台的平滑过渡.
