资产管理系统新上线一个功能，可以查看 IP 历史关联域名以及反过来查询域名解析过的 IP 地址，主要应用场景：

1、寻找 CDN 背后的真实 IP，比如某个子域名存在 CDN 解析，可以通过查询主域名关联的所有 IP 地址，通过 host 碰撞来完成真实 IP 的发现

2、发现某个 IP 的某个端口存在漏洞，可以尝试查询关联来确定目标归属，还可以根据解析过的主域名来判断 IP 是 CDN 等云服务的还是目标的，方便定位 IP 归属

比如通过域名查询解析过的 IP 地址：

![截屏2026-06-28 17.48.17](https://mmbiz.qpic.cn/mmbiz_png/VnwOz8XYCTa4NUCuh5aziarmtWUrQN2N4cOgb4g5v11tn3KG2MVwZkLiaibwotzVkVseO8o9vt8FL3UnhU7m94N4rRZ6gxBR5fEP7s6QylarY8/640?wx_fmt=png&from=appmsg)

当查询主域名时，如果想知道与该主域名相关的 whois、dns、备案权重、子域名、关联资产等情况，可以通过按钮来跳转外站查询相关信息。

当你点击 IP 节点时，可以自动查询与该 IP 关联的主域名，如果想知道与该 IP 相关的地理位置、子域名、端口情况可以点击按钮直达外站查询：

![截屏2026-06-28 17.49.49](https://mmbiz.qpic.cn/mmbiz_png/VnwOz8XYCTZnrbGFZmccpD21GicJ4cd2PiaWNDeZRAtrZJ4dMoezG84DB7oGVPHgSZSL0XUelSWzCj9lZh097lPORGSveYTXXrAEJjicy3aM2w/640?wx_fmt=png&from=appmsg)

除此之外，我还在自定查询域名的备案权重、域名解析记录等信息，在平台会有部分标记，比如：

![image-20260628180145001](https://mmbiz.qpic.cn/mmbiz_png/VnwOz8XYCTbltIRYdGZDriccIHRZNKfIvDu2T4G1KEFGRPJm1np7UebtW0R1yWJqkU3ksMQjj1TULicUh5N5CCCckHqBy6E3vnIQveVTRKqDY/640?wx_fmt=png&from=appmsg)

后续还会对 IP 做标记，根据自己的规则来判断 IP 的归属，这个功能也只有激活用户可以使用，永久激活只需 10 元！
