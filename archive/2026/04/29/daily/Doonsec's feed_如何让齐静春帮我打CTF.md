手把手教你如何利用codex调用齐静春打ctf

第一步

### 安装 Codex CLI

使用 npm 安装：

```
sudo npm install -g @openai/codex

# 使用国内镜像安装更快
sudo npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

安装完成后运行：

```
codex
```

### 登录 Codex

首次运行需要登录。

有两种方式：

#### 方法一：ChatGPT 登录

```
codex
```

选择：

```
Sign in with ChatGPT
```

然后浏览器会打开登录页面。

登录完成即可使用

#### 方法二:使用sectoken.pro纯血版GPT5.5（推荐）
