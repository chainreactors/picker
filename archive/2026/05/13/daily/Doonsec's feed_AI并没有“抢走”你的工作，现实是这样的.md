# 焦虑蔓延，但真相可能和你想象的不太一样

关于“AI取代人类工作”的担忧，过去一年持续升温。

根据相关数据显示，AI已经连续第二个月成为企业裁员的头号原因。微软在最新发布的报告中直言：“职场中对AI的焦虑是真实存在的——从对失业的担忧，到跟上技术快速迭代的压力。”

但专家的观点却没那么非黑即白。

# AI在做什么？自动化“碎片”，而不是整份工作

麦肯锡指出，真正被现有AI和机器人技术完全取代的职位，少之又少。

麦肯锡的研究显示，AI技术上可以自动化57%的工作相关活动——但这些活动分散在各类职位和职责的“碎片”中，而不是整块切割。

换句话说，公司并不是用AI替换掉一个完整的岗位，而是让AI承担某个岗位中一部分重复性或可标准化的工作。

数字服务公司Incedo的联合创始人Seth举了一个很形象的例子：

“你不能把四个人的各四分之一工作拼成一个人。”

这也是为什么他的公司能通过AI帮客户提升20%-25%的生产力，却没有进行同等规模的裁员。

# 软件工程师的日常已经变了，但工作还在

技术行业是对AI感知最深的领域。

根据谷歌的研究显示，90%的技术从业者已经或计划在工作中使用AI。相关调查也发现，84%的开发者正在使用AI工具。

但这是否意味着软件工程岗位要消失了？

Anthropic Claude Code负责人Cherny的观点是：岗位名称可能会变。他认为，“构建者”这个称呼或许比“软件工程师”更贴切。写代码的行数在减少，但设计系统、排查问题、决定“要构建什么”这些核心能力，依然是人的工作。

某位拥有约十年软件工程经验也印证了这一点：

“工作依然需要解决问题和批判性思维。不同之处在于，执行方式变成了编写代码和提示AI的结合。”

关键问题变成了：你能否识别出什么样的代码质量是正确的？你能否解决复杂问题？

# 但AI的确在“动”一些岗位

我们不能忽视数据。今年以来，AI已经被列为超过49,000起裁员事件的原因之一。

Block公司（一家美国金融科技公司）今年就计划裁员40%，因为AI使得更小的团队就能完成原有工作。

他们认为，AI让工程师能在几天内完成过去需要数周的任务，在过去三个月AI使用量增长了600%以上，公司的运营方式已经彻底改变。

普华永道首席AI官Priest坦言，未来会出现“一些就业干扰”，但目前还没有哪个整类岗位真正面临被淘汰的风险。

# 企业还在摸索：AI到底需要什么样的人？

微软的报告揭示了一个有意思的现象：大多数公司还没有调整员工指标和激励措施来适应AI带来的变化。

换句话说，企业虽然开始在业务中使用AI，但还没有想清楚如何重新设计岗位、如何衡量人的价值。至少现在，很多人力资源层面的制度，是滞后的。

与此同时，AI的能力还在向上攀升。Anthropic最近就推出了专门针对金融工作的AI代理，可以制作推介手册、制作信用备忘录。

# 小结

AI确实在改变工作，也在触发裁员。但它目前做的，更多是重组工作内容，而不是直接消灭职位。对人的要求也在变化：从“执行具体任务”，转向“判断、整合、决策和批判性思考”。

焦虑是真实的，但或许不必恐慌。

真正值得思考的问题是：当AI承担了越来越多“可描述、可重复”的工作后，我们剩下那些无法被自动化替代的能力，到底是什么？
