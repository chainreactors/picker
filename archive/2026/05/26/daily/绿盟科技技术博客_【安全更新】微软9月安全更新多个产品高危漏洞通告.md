### **1** **漏洞概述**

9月10日，绿盟科技CERT监测到微软发布9月安全更新补丁，修复了86个安全问题，涉及Windows、Microsoft Office、Azure、Microsoft SQL Server等广泛使用的产品，其中包括权限提升、远程代码执行等高危漏洞类型。

本月微软月度更新修复的漏洞中，严重程度为关键（Critical）的漏洞有13个，重要（Important）漏洞有72个，中危（Moderate）漏洞有1个。

请相关用户尽快更新补丁进行防护，完整漏洞列表请参考附录。

参考链接：

https://msrc.microsoft.com/update-guide/releaseNote/2025-Sep

### **2** **重点漏洞简述**

根据产品流行度和漏洞重要性筛选出此次更新中包含影响较大的漏洞，请相关用户重点进行关注：

**Microsoft SharePoint远程代码执行漏洞（CVE-2025-54897）:**

Microsoft SharePoint存在远程代码执行漏洞，由于Microsoft Office SharePoint中不受信任数据的反序列化，经过身份验证的远程攻击者可以通过该漏洞执行任意代码。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-54897

**Microsoft高性能计算 (HPC) 包远程代码执行漏洞（CVE-2025-55232）:**

Microsoft 高性能计算包 (HPC)中存在远程代码执行漏洞，由于HPC中不受信任数据的反序列化，未经身份验证的攻击者可实现远程代码执行。CVSS评分9.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-55232

**Microsoft Office远程代码执行漏洞（CVE-2025-54910）:**

Microsoft Office中存在远程代码执行漏洞，由于Microsoft Office中基于堆的缓冲区溢出，未经身份验证的攻击者可以通过制作恶意的文件诱使用户打开或预览窗格，从而在用户上下文中执行任意代码。CVSS评分8.4。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-54910

**Windows路由和远程访问服务 (RRAS) 远程代码执行漏洞（CVE-2025-54106）：**

Windows路由和远程访问服务 (RRAS)中存在远程代码执行漏洞，由于Windows路由和RRAS中的整数溢出或环绕问题，未经身份验证的攻击者可通过诱骗用户向恶意服务器发送请求来利用此漏洞，从而在目标系统上执行任意代码。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-54106

**Windows NTLM权限提升漏洞（CVE-2025-54918）：**

Windows NTLM中存在权限提升漏洞，由于Windows NTLM中的身份验证不当，经过身份验证的本地攻击者可以利用此漏洞获取系统SYSTEM权限。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-54918

**Windows内核权限提升漏洞（CVE-2025-54110）：**

Windows内核存在权限提升漏洞，由于Windows内核中的整数溢出或环绕问题，攻击者可以通过从沙盒用户模式进程发送特制的输入来触发整数溢出，从而实现权限提升或沙盒逃逸。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-54110

**Windows SMB权限提升漏洞 （CVE-2025-55234）：**

Windows SMB存在权限提升漏洞，由于SMB服务器配置不当容易受到中继攻击，经过身份验证的攻击者可利用此漏洞获得目标用户的系统权限，从而实现权限提升。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-55234

**Microsoft SQL Server权限提升漏洞（CVE-2025-55227）:**

Microsoft SQL Server中存在权限提升漏洞，由于SQL Server命令中使用的特殊元素的不当中和，经过身份验证的攻击者可以在创建表时注入SQL代码并以提升的权限运行，从而获得系统管理员权限。CVSS评分8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2025-55227
