*前言*

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM7LicU65en3E7wx0VyalN0OrAVEEpeqIkqmCt0L5eVnDSkTLAY7uN0tWSmqUsWugjHTRA08tJjvATUmUx0M8HX36mJKu6KWdQgAoC7EpYl0zqA/640?wx_fmt=svg&from=appmsg)

如果你热爱网络安全、渴望真正进入国际顶级安全圈层，那么这可能是一次非常难得的机会。

近日，基于HackingClub 与海外合作伙伴 俄罗斯最大安全公司Positive Technologies 、国际道德黑客组织的深化合作：

原本已经截止招生的国际顶级网络安全训练营 —— Positive Hack Camp，特别为中国学生额外开放少量名额。

经过沟通，我们决定面向国内安全圈，HackingClub的粉丝用户，限量提供3个安全学习名额（本次中国3个特别推荐席位，培训费补贴后仅需0元）。

我们将面向对技术提升有持续追求、具备良好学习能力与英文基础的学员开放申请。希望你不仅关注技术能力的成长，更渴望进入更高层级的安全技术交流体系，在国际化的道德黑客社区中与全球安全研究者进行深入交流与碰撞，参与真实攻防思维与前沿安全理念的学习与实践。从而构建完整的攻防认知体系，实现从技术学习者向实战型安全能力者的进阶与跃迁。

*活动介绍*

![](https://mmbiz.qpic.cn/mmbiz_svg/Q3auHgzwzM6m3cevDvic204gECw7yS74x1h5tg1HV7d0rHlhFoChroBUImkmYVYfOpiaKTulILAvXo1vicyWw2bDcbBTMYvaHCexrT8BRG60BZSF0GugoVUGA/640?wx_fmt=svg&from=appmsg)

**Positive Hack Camp 是由国际知名网络安全企业 Positive Technologies 发起，并获得俄罗斯数字发展部支持的国际线下黑客训练营。**

Positive Technologies介绍：

Positive Technologies作为俄罗斯网络安全领域最具代表性的技术型安全企业，长期深耕漏洞研究、红蓝对抗、工业互联网安全与国家级攻防能力建设，在国际网络安全圈拥有极高影响力。

公司主办的 Positive Hack Days（PHDays），被誉为俄罗斯乃至东欧地区最具影响力的网络安全大会之一，汇聚全球顶尖白帽黑客、安全研究员、企业安全负责人及攻防专家。

训练营详情：

📍 地点：俄罗斯·莫斯科
📅 时间：2026年7月25日—8月9日
⏰ 为期14天

面向全球招募网络安全方向优秀学生与研究人员。

* 14天高强度实战学习
* 30位顶级网络安全专家授课
* 70位来自全球的安全研究员共同参与
* 全英文国际化交流环境
* 实战攻防 + 漏洞利用 + 红队技巧 + Active Directory 渗透等完整课程体系
* 掌握如何模拟对 IT 基础设施的攻击，并使用漏洞利用工具调查防御措施。
* 掌握常用工具，用于分析网络和协议流量以及调整客户端-服务器通信。
* 掌握提升信息系统、网站、操作系统和网络基础设施的权限技术。

课程大纲：

1.组织架构和伦理：准备本地和云环境，安装工具，并学习道德黑客原则，以进行安全、负责的实践。

2.侦察和扫描：外部环境探测、域和网络发现、主机和端口扫描，以绘制目标环境图。

3.初始访问和网络漏洞利用：主要访问控制技术和Web应用程序攻击，包括身份验证绕过、SQL注入、跨站脚本攻击（XSS）、扩展漏洞利用（XXE）和命令注入。

4.特权升级和横向移动：提升Linux和Windows系统的权限，入侵DMZ主机，转发流量，并在网络中移动。

5.规避、Active Directory 入侵和职业发展：规避检测、使用加密通道、利用 Active Directory 和域控制器漏洞，以及应对措施和道德规范。

**报名基础要求：**

1.英语水平为B1或以上，具备英文沟通能力（课程与交流以英文为主）

能够独立完成海外出行；

2.学生身份；

3.精通Linux或Windows 的高级用户操作，包括软件安装和基本配置。

4.了解互联网和局域网的工作原理；

5.对网络安全/黑客技术有浓厚兴趣；

6.有安全研究、CTF、漏洞挖掘经验（优先）；

7.具备良好的职业素养与安全意识，遵守国家法律法规，坚定爱国立场，理性参与国际技术交流，严禁参与任何违法违规活动或敏感信息泄露行为。

特别说明（重要）

本次活动属于国际技术交流项目。

我们鼓励中国安全人才积极参与全球技术学习与交流，但同时也希望所有参与者：

1.遵守国家法律法规

2.坚持正确网络安全价值观

3.保持良好职业伦理与保密意识

4.在海外期间注意个人及信息安全

5.不参与任何危害国家安全、利益及敏感信息泄露相关行为

真正优秀的白帽子，不仅需要技术能力，更需要责任感与底线意识。
