# дёҖгҖҒдәӢд»¶пјҡеҸІдёҠжңҖйҖҹвҖңејҖз®ұеҚіз ҙвҖқ

9жңҲ2ж—ҘпјҢAnthropic жӯЈејҸеҸ‘еёғдәҶж–°дёҖд»Јж——иҲ°жЁЎеһӢВ **Fable 5.1**пјҢеҗҢжӯҘжҺЁеҮәзҡ„иҝҳжңүйқўеҗ‘еҸ—е®Ўе®үе…Ёдё“е®¶дёҺз”ҹе‘Ҫз§‘еӯҰз ”з©¶иҖ…зҡ„В **Mythos 5.1**гҖӮ

иҝҷжң¬иҜҘжҳҜдёҖдёӘеұһдәҺи·‘еҲҶзҡ„ж—Ҙеӯҗпјҡ

* ARC-AGI-1пјҡ**97.5%**пјҢжҜҸд»»еҠЎ 1.40 зҫҺе…ғ
* е№іеқҮжҺЁзҗҶжҲҗжң¬жҜ”дёҠдёҖд»ЈйҷҚдҪҺзәҰВ **32%**

з„¶иҖҢпјҢеҸ‘еёғиҝҳдёҚеҲ°еҮ дёӘе°Ҹж—¶пјҢеү§жғ…е°ұжҖҘиҪ¬зӣҙдёӢвҖ”вҖ”зҹҘеҗҚи¶ҠзӢұз ”з©¶иҖ…В **Pliny the Liberator**В еңЁ GitHub дёҠз”©еҮәдёҖд»Ҫй“ҫжҺҘпјҡ**Fable 5.1 зҡ„е®Ңж•ҙзі»з»ҹжҸҗзӨәиҜҚпјҢи¶…иҝҮ 275,000 дёӘеӯ—з¬ҰпјҢе…ЁйғЁжӣқе…үгҖӮ**

е…ЁзҪ‘жІёи…ҫгҖӮ

и®ҪеҲәзҡ„жҳҜпјҢAnthropic е®ҳж–№еҪ“еӨ©е…¶е®һд№ҹе…¬еёғдәҶдёҖд»ҪвҖқзі»з»ҹжҸҗзӨәиҜҚжӣҙж–°вҖқпјҢзәҰ 2.7 дёҮеӯ—вҖ”вҖ”иҝҷе·Із»Ҹз®—жҳҜиЎҢдёҡйҮҢзҪ•и§Ғзҡ„вҖқйҖҸжҳҺвҖқдёҫеҠЁгҖӮдҪҶ Pliny жҜ«дёҚз•ҷжғ…ең°еҳІи®Ҫпјҡ

вҖңдҪ д»¬е°ұиҝҷд№ҲдҝЎдәҶпјҹд»ҺжҲ‘зҡ„и§’еәҰзңӢпјҢе®ҳж–№е…¬еёғзҡ„дёҚиҝҮжҳҜеҶ°еұұдёҖи§’пјҢеҸӘжңү 10% зҪўдәҶгҖӮвҖқ

дёҖдёӘжҳҜе®ҳж–№зІҫйҖүзҡ„вҖқз®ҖеҺҶзүҲвҖқпјҢдёҖдёӘжҳҜй»‘е®ўжҸҗеҸ–зҡ„вҖқдҪ“жЈҖжҠҘе‘ҠзүҲвҖқгҖӮдёӨиҖ…д№Ӣй—ҙзҡ„е·®и·қпјҢжҒ°жҒ°жҳҜиҝҷдёӘдәӢд»¶жңҖеҖјеҫ—зҺ©е‘ізҡ„ең°ж–№гҖӮ

# дәҢгҖҒ27дёҮеӯ—йҮҢеҲ°еә•и—ҸзқҖд»Җд№Ҳпјҹ

иҝҷж¬Ўжі„йңІзҡ„дёҚжҳҜеҮ иЎҢвҖқдҪ жҳҜ ClaudeпјҢз”ұ Anthropic еҲӣе»әвҖқзҡ„дәәи®ҫе®ЈиЁҖпјҢиҖҢжҳҜдёҖеҘ—**е®Ңж•ҙзҡ„иҝҗиЎҢж—¶з»„иЈ…жҢҮд»Ө**пјҢеҢ…жӢ¬ж ёеҝғиЎҢдёәйҖ»иҫ‘гҖҒи®°еҝҶзі»з»ҹгҖҒжҗңзҙўдёҺзүҲжқғи§„еҲҷгҖҒArtifacts е’Ңи®Ўз®—жңәдҪҝз”ЁжҢҮеҚ—гҖҒжҸ’д»¶и·Ҝз”ұпјҢд»ҘеҸҠе…ЁйғЁВ **46 дёӘеҶ…зҪ®е·Ҙе…·зҡ„ JSON жһ¶жһ„**гҖӮ

жҢ‘еҮ дёӘжңҖжңүж„ҸжҖқзҡ„иҜҙгҖӮ

**з¬¬дёҖпјҢзүҲжқғзәўзәҝз»ҶеҲ°вҖқзҰ»и°ұвҖқгҖӮ**

Fable 5.1 иў«дёҘзҰҒйҮҚзҺ°д»»дҪ•еҸ—зүҲжқғдҝқжҠӨзҡ„жӯҢжӣІгҖҒиҜ—жӯҢгҖҒд№ҰзұҚзүҮж®өпјҲ1929 е№ҙд№ӢеүҚзҡ„е…¬зүҲдҪңе“ҒйҷӨеӨ–пјүгҖӮи§Ҷи§үеҲӣдҪңдёҠжӣҙеӨёеј пјҡж— и®әз”Ё SVGгҖҒCSS иҝҳжҳҜ HTMLпјҢз»қдёҚе…Ғи®ёз”»еҮәд»»дҪ•е·ІзҹҘи§’иүІгҖҒLogoгҖҒдё“иҫ‘е°ҒйқўгҖӮжҸҗзӨәиҜҚйҮҢз”ҡиҮізҷҪзәёй»‘еӯ—зӮ№еҗҚпјҡ**вҖңдёҚе…Ғи®ёз”»еҲәзҢ¬зҙўе°је…ӢпјҢд№ҹдёҚе…Ғи®ёз”»гҖҠеҘҪйҘҝзҡ„жҜӣжҜӣиҷ«гҖӢгҖӮвҖқ**В е“ӘжҖ•з”ЁжҲ·иҰҒжұӮж”№е§ҝеҠҝгҖҒжҚўйўңиүІгҖҒеҸҳйЈҺж јпјҢд№ҹдёҚиЎҢгҖӮ

дҪ еҸҜд»ҘжғіиұЎпјҢиҝҷжҜҸдёҖжқЎвҖқиҺ«еҗҚе…¶еҰҷвҖқзҡ„и§„еҲҷиғҢеҗҺпјҢеӨ§жҰӮзҺҮйғҪиәәзқҖдёҖе°ҒеҫӢеёҲеҮҪпјҢжҲ–жҳҜдёҖеңәзңҹе®һзҡ„иҜүи®јгҖӮ

**з¬¬дәҢпјҢи®°еҝҶзі»з»ҹеҲ’еҮәвҖқиҮіжӯ»дёҚи®°вҖқзҡ„зҰҒеҢәгҖӮ**

Fable 5.1 зҡ„и®°еҝҶеҸҳжҲҗеҗҺеҸ°иҮӘеҠЁжү§иЎҢпјҢдҪҶйҷ„еёҰдёҘж јзҡ„йҡҗз§ҒеҲҶзұ»иҫ№з•ҢгҖӮд»ҘдёӢеҶ…е®№**ж°ёиҝңдёҚеӯҳеӮЁ**пјҡжңӘжҲҗе№ҙдәәзҡ„иә«д»ҪдҝЎжҒҜгҖҒз§Қе§“дёҺз§»ж°‘зҠ¶жҖҒгҖҒзҠҜзҪӘи®°еҪ•гҖҒеҝғзҗҶдёҺзІҫзҘһжҺЁж–ӯгҖҒжҖ§еҸІдёҺиҮӘж®ӢеҖҫеҗ‘гҖӮеҚідҪҝз”ЁжҲ·дё»еҠЁжҡҙйңІпјҢзі»з»ҹд№ҹдјҡеңЁеҗҺеҸ°ејәеҲ¶жё…з©әгҖӮ

**з¬¬дёүпјҢиғҪеҠӣиҶЁиғҖзҡ„е®һй”ӨгҖӮ**

еҶ…зҪ®е·Ҙе…·д»Һ 7 жңҲд»Ҫзҡ„ 30 дёӘжҡҙеўһеҲ°В **46 дёӘ**пјҡеӣҫиЎЁеұ•зӨәгҖҒиҪ®ж’ӯеӣҫгҖҒиЎҢзЁӢеҚЎзүҮгҖҒй“ҫжҺҘйў„и§ҲвҖҰвҖҰиҝҳжңүдёҖдёӘеҸ«В `read_conversation`В зҡ„е·Ҙе…·пјҢеҸҜд»Ҙзҝ»йҳ…дҪ иҝҮеҺ»зҡ„еҺҶеҸІеҜ№иҜқгҖӮClaude дёҚеҶҚжҳҜвҖқдёҖеҲ·ж–°е°ұеӨұеҝҶвҖқзҡ„иҒҠеӨ©жЎҶпјҢиҖҢжҳҜеңЁжӮ„жӮ„еҸҳжҲҗдёҖдёӘ**и¶…зә§е·ҘдҪңз«ҷ**гҖӮ

**з¬¬еӣӣпјҢиЎҢдёәзәҰжқҹеҜҶдёҚйҖҸйЈҺгҖӮ**

е®ғдёҚиғҪеҜ№з”ЁжҲ·зҡ„еҝғзҗҶзҠ¶жҖҒжҲ–еҠЁжңәдёӢж–ӯиЁҖпјҢдёҚиғҪжү®жј”еҢ»з”ҹпјҢдёҚиғҪж”ҫеӨ§з”ЁжҲ·зҡ„иҙҹйқўжғ…з»ӘпјӣеңЁжҜ’е“ҒиҜқйўҳдёҠйҮҮеҸ–вҖқеҮҸе°‘дјӨе®івҖқзӯ–з•ҘвҖ”вҖ”еҸҜд»Ҙи®ІиҝҮйҮҸзҡ„еҚұйҷ©е’ҢжҖҘж•‘ж–№жі•пјҢдҪҶз»қдёҚжҸҗдҫӣеүӮйҮҸгҖҒж—¶й—ҙе®үжҺ’жҲ–й…Қж–№гҖӮ

дёҖеҸҘиҜқжҖ»з»“пјҡ**иҝҷд»Ҫ 27 дёҮеӯ—зҡ„вҖқеӨ©д№ҰвҖқпјҢдёҺе…¶иҜҙжҳҜжҸҗзӨәиҜҚпјҢдёҚеҰӮиҜҙжҳҜдёҖд»Ҫ AI ж—¶д»Јзҡ„вҖқе‘ҳе·ҘиЎҢдёәжүӢеҶҢ + еҗҲи§„жүӢеҶҢ + е·Ҙе…·иҜҙжҳҺд№ҰвҖқдёүеҗҲдёҖеҘ—йӨҗгҖӮ**

# дёүгҖҒжҲ‘зҡ„и§ӮзӮ№пјҡжҸҗзӨәиҜҚд»ҺжқҘдёҚжҳҜжҠӨеҹҺжІіпјҢдҪҶиҝҷжҒ°жҒ°жҳҜжңҖеҚұйҷ©зҡ„ең°ж–№

еҫҲеӨҡдәәзңӢеҲ°иҝҷжқЎж–°й—»зҡ„з¬¬дёҖеҸҚеә”жҳҜпјҡвҖқAnthropic зҡ„жҠӨеҹҺжІіиў«жү’дәҶгҖӮвҖқ

жҲ‘зҡ„зңӢжі•жҒ°жҒ°зӣёеҸҚпјҢиҖҢдё”жҲ‘и®Өдёәиҝҷд»¶дәӢжҡҙйңІзҡ„й—®йўҳпјҢжҜ”вҖқжҠӨеҹҺжІівҖқиҰҒж·ұеҲ»еҫ—еӨҡгҖӮ

**и§ӮзӮ№дёҖпјҡжҸҗзӨәиҜҚд»ҺжқҘе°ұдёҚжҳҜжҠӨеҹҺжІіпјҢжқғйҮҚжүҚжҳҜгҖӮ**

е…ҲеҺҳжё…дёҖдёӘжҠҖжңҜдәӢе®һпјҡFable 5.1 е’Ң Mythos 5.1 жң¬иҙЁдёҠжҳҜ**еҗҢдёҖдёӘжЁЎеһӢпјҢе…ұдә«еҗҢдёҖеҘ—жқғйҮҚ**гҖӮеҢәеҲ«еҸӘеңЁдәҺеӨ–йқўеҘ—дәҶеӨҡе°‘еұӮжҠӨж ҸвҖ”вҖ”дёҖдёӘжҳҜйқўеҗ‘е…¬дј—зҡ„вҖқе®үе…ЁзүҲвҖқпјҢдёҖдёӘжҳҜйқўеҗ‘еҸ—е®Ўдё“е®¶зҡ„вҖқй«ҳжқғйҷҗзүҲвҖқгҖӮ

иҝҷж„Ҹе‘ізқҖд»Җд№Ҳпјҹж„Ҹе‘ізқҖзҺ°д»ЈеӨ§жЁЎеһӢзҡ„иғҪеҠӣж ёеҝғеңЁжқғйҮҚйҮҢпјҢиҖҢе®үе…Ёиҫ№з•ҢеңЁеҫҲеӨ§зЁӢеәҰдёҠжҳҜйқ жҸҗзӨәиҜҚе’ҢиҝҗиЎҢж—¶и§„еҲҷвҖқиҙҙдёҠеҺ»вҖқзҡ„гҖӮе°ұз®— Pliny жҠҠ 27 дёҮеӯ—е…Ёжү’еҮәжқҘпјҢдҪ д№ҹеӨҚеҲ¶дёҚеҮәдёҖдёӘ Fable 5.1вҖ”вҖ”дҪ жІЎжңүе®ғзҡ„жқғйҮҚпјҢжІЎжңүе®ғзҡ„и®ӯз»ғж•°жҚ®пјҢжІЎжңүе®ғиғҢеҗҺзҡ„з®—еҠӣгҖӮ

жүҖд»ҘеҲ«еҶҚиҜҙвҖқжҸҗзӨәиҜҚжі„йңІ = еә•зүҢе°ҪеӨұвҖқгҖӮзңҹжӯЈзҡ„еә•зүҢпјҢй»‘е®ўзў°дёҚеҲ°гҖӮ

**и§ӮзӮ№дәҢпјҡдҪҶиҝҷжҒ°жҒ°жҳҜеҚұйҷ©жүҖеңЁвҖ”вҖ”еҪ“вҖқе®үе…ЁвҖқдё»иҰҒйқ дёҖеұӮж–Үжң¬жҠӨж Ҹж—¶пјҢжҠӨж Ҹжң¬иә«е°ұжҲҗдәҶж”»еҮ»йқўгҖӮ**

жқғйҮҚеҒ·дёҚиө°пјҢдҪҶи§„еҲҷеҸҜд»Ҙиў«з ”з©¶гҖҒиў«з»•иҝҮгҖӮ

иҝҷж¬Ўжі„йңІзҡ„ж–Үд»¶йҮҢпјҢеҢ…еҗ«дәҶе…ЁйғЁ 46 дёӘе·Ҙе…·зҡ„ JSON жһ¶жһ„гҖҒи®°еҝҶзі»з»ҹзҡ„еҲҶзұ»иҫ№з•ҢгҖҒжҸ’д»¶и·Ҝз”ұйҖ»иҫ‘гҖӮеҜ№дёҖдёӘж”»еҮ»иҖ…жқҘиҜҙпјҢиҝҷдёҚжҳҜе…«еҚҰпјҢиҝҷжҳҜдёҖд»Ҫ**дҫҰеҜҹең°еӣҫ**пјҡзҹҘйҒ“дәҶйҳІеҫЎиҖ…еңЁе“ӘйҮҢи®ҫеҚЎпјҢе°ұзҹҘйҒ“иҜҘд»Һе“ӘйҮҢз»•иЎҢгҖӮзҹҘйҒ“жЁЎеһӢвҖқж°ёиҝңдёҚеӯҳеӮЁвҖқе“ӘдәӣдҝЎжҒҜпјҢе°ұзҹҘйҒ“е®ғзҡ„и®°еҝҶжңәеҲ¶еңЁе“Әдәӣж—¶еҲ»дјҡи§ҰеҸ‘жё…з©әвҖ”вҖ”жңәеҲ¶зҡ„йҖҸжҳҺпјҢеҫҖеҫҖе°ұжҳҜжјҸжҙһзҡ„ејҖз«ҜгҖӮ

жӣҙи®©дәәдёҚж”ҫеҝғзҡ„жҳҜ Fable/Mythos зҡ„еҸҢзүҲжң¬и®ҫи®ЎпјҡеҗҢдёҖеҘ—жқғйҮҚпјҢйқ еӨ–еӣҙи§„еҲҷеҢәеҲҶвҖқиғҪз»ҷи°ҒзңӢд»Җд№ҲвҖқгҖӮиҝҷжң¬иҙЁдёҠжҳҜеңЁз”ЁдёҖйҒ“иҪҜд»¶еӣҙж ҸпјҢзңӢз®ЎдёҖдёӘиғҪеҠӣи¶ід»ҘеӨ„зҗҶзҪ‘з»ңе®үе…Ёе’Ңз”ҹзү©еӯҰй«ҳйЈҺйҷ©д»»еҠЎзҡ„жЁЎеһӢгҖӮеӣҙж Ҹиў«е®Ңж•ҙжөӢз»ҳд№ӢеҗҺпјҢвҖқжҠҠ Fable й—®жҲҗ MythosвҖқдјҡдёҚдјҡжҲҗдёәдёӢдёҖдёӘи¶ҠзӢұз«һиөӣзҡ„зӣ®ж ҮпјҹиҝҷдёҚжҳҜжқһдәәеҝ§еӨ©пјҢиҖҢжҳҜи¶ҠзӢұзӨҫеҢәзҡ„ж—ҘеёёгҖӮ

**и§ӮзӮ№дёүпјҡ27дёҮеӯ— vs 2.7дёҮеӯ—вҖ”вҖ”вҖқе®ҳж–№йҖҸжҳҺвҖқдёҺвҖқзңҹе®һиҝҗиЎҢвҖқд№Ӣй—ҙзҡ„йёҝжІҹпјҢжүҚжҳҜиЎҢдёҡзңҹжӯЈзҡ„дҝЎд»»еҚұжңәгҖӮ**

Anthropic е·Із»ҸжҳҜеӨ§жЁЎеһӢеҺӮе•ҶйҮҢзӣёеҜ№еқҰиҜҡзҡ„дёҖдёӘдәҶпјҢдё»еҠЁе…¬еёғ 2.7 дёҮеӯ—зі»з»ҹжҸҗзӨәиҜҚпјҢиЎҢдёҡйҮҢжІЎеҮ е®¶иғҪеҒҡеҲ°гҖӮдҪҶй»‘е®ўз”Ё 27.5 дёҮеӯ—е‘ҠиҜүжҲ‘д»¬пјҡдҪ зңӢеҲ°зҡ„пјҢеҸӘжҳҜеҚҒеҲҶд№ӢдёҖгҖӮ

иҝҷдёҚжҳҜиҰҒиӢӣиҙЈ AnthropicпјҢиҖҢжҳҜиҰҒжҢҮеҮәдёҖдёӘз»“жһ„жҖ§зҹӣзӣҫпјҡ**AI е…¬еҸёдёҖиҫ№иҰҒжұӮе…¬дј—дҝЎд»»вҖқжЁЎеһӢжҳҜе®үе…Ёзҡ„вҖқпјҢдёҖиҫ№еҸҲжҠҠе®үе…ЁжңәеҲ¶и—ҸеңЁдёҖдёӘиҝһе®ҳж–№ж–ҮжЎЈйғҪдёҚе®Ңж•ҙжҠ«йңІзҡ„й»‘з®ұйҮҢгҖӮ**В еҪ“е…¬дј—еҜ№ AI е®үе…Ёзҡ„и®ӨзҹҘпјҢиҰҒйқ й»‘е®ўйҖҶеҗ‘е·ҘзЁӢжқҘиЎҘе…Ёж—¶пјҢиҝҷдёӘиЎҢдёҡзҡ„вҖқиҮӘжҲ‘зӣ‘з®ЎвҖқеҸҷдәӢе°ұе·Із»Ҹз ҙдә§дәҶдёҖеҚҠгҖӮ

**и§ӮзӮ№еӣӣпјҡеҜ№жҷ®йҖҡз”ЁжҲ·жқҘиҜҙпјҢжңҖиҜҘи®°дҪҸзҡ„жҳҜйӮЈеҮ жқЎвҖқиҮіжӯ»дёҚи®°вҖқгҖӮ**

еҲ«еҝҳдәҶпјҢиҝҷд»Ҫж–Үд»¶йҮҢзңҹжӯЈе’ҢдҪ жҲ‘жңүе…ізҡ„пјҢдёҚжҳҜе·Ҙе…·ж•°йҮҸпјҢдёҚжҳҜзүҲжқғи§„еҲҷпјҢиҖҢжҳҜйӮЈд»Ҫйҡҗз§ҒзҰҒеҢәжё…еҚ•гҖӮе®ғд№ӢжүҖд»ҘеӯҳеңЁпјҢжҳҜеӣ дёә**зңҹзҡ„жңүдәәдјҡеҜ№ AI еҖҫиҜүеҝғзҗҶй—®йўҳгҖҒжҡҙйңІиә«д»ҪдҝЎжҒҜгҖҒи®Іиҝ°йҡҫд»ҘеҗҜйҪҝзҡ„з»ҸеҺҶ**гҖӮ

зңӢеҲ°вҖқжңӘжҲҗе№ҙдәәзҡ„иә«д»ҪдҝЎжҒҜвҖқвҖқжҖ§еҸІдёҺиҮӘж®ӢеҖҫеҗ‘вҖқиҝҷдәӣжқЎзӣ®иў«зҷҪзәёй»‘еӯ—еҶҷиҝӣзі»з»ҹжҸҗзӨәиҜҚпјҢжҲ‘зҡ„ж„ҹеҸ—дёҚжҳҜзҢҺеҘҮпјҢиҖҢжҳҜеҝғй…ёвҖ”вҖ”жҜҸдёҖжқЎи§„еҲҷиғҢеҗҺпјҢйғҪжҳҜж— ж•°зңҹе®һз”ЁжҲ·иё©иҝҮзҡ„еқ‘гҖӮиҖҢиҝҷжүҚжҳҜиҝҷж¬Ўжі„йңІйҮҢжңҖеҖјеҫ—иў«и®ӨзңҹиҜ»е®Ңзҡ„йғЁеҲҶгҖӮ

# еӣӣгҖҒеҸҰдёҖйқўпјҡFable 5.1 зЎ®е®һејәеҫ—еҸҜжҖ•
