## 可编译的进攻工程载荷

为了弥合理论理解与二进制执行之间的鸿沟，本仓库在 `payloads/` 目录中提供了可直接编译的武器化代码库：

```
payloads/
|-- README.md                  # 载荷主索引、工具链与实验前置条件
|-- 01_dynamic_api_resolver/   # Windows PEB 遍历、内存内 API 导出哈希（C 语言，DJB2）
`-- 02_offensive_rust_loader/  # 内存保护翻转（RW -> RX）、Rust 原生 API 封装
```

**载荷 01：C 语言动态 API 解析器**：演示纯粹在内存中解析 Windows API 函数——遍历进程环境块（PEB）并对导出表字符串做哈希，击溃静态导入地址表（IAT）分析。

**载荷 02：进攻性 Rust 内存加载器**：演示在内存中分阶段部署加密 shellcode，规避直接 RWX 分配特征，并在线程派发前的最后一刻将内存权限翻转为可执行（PAGE\_EXECUTE\_READ）。

## 2025–2027 操盘手模块

本课程整合了击穿现代安全栈所需的最新进攻范式：

### 1. 现代 EDR 免杀与睡眠混淆

借助基于异步定时器的内存保护翻转，击败内存扫描器（Moneta、Hunt-Sleeping-Beacons、Pe-sieve）。

* • **Ekko、Foliage 与 Cronos 实现**：经由 NtContinue、CreateTimerQueueTimer 的 ROP 链加密，以及栈帧擦除。
* • **调用栈伪装（Call Stack Spoofing）**：合成栈帧生成（SilentMoonwalk、Unwinder），以通过返回地址校验。
* • **间接系统调用**：动态解析 SSN，并在合法的 ntdll.dll 内存空间内执行 syscall 指令，绕过用户态 Hook。

### 2. 企业级 Active Directory 与混合身份

* • **ADCS 漏洞利用**：滥用企业证书中心的错误配置，覆盖 ESC1 至 ESC15。
* • **认证强制（Authentication Coercion）**：经 PetitPotam（MS-EFSR）、DFSCoerce（MS-DFSNM）与影子凭据强制触发 NTLM 认证。
* • **Entra ID（Azure AD）**：主刷新令牌（PRT）提取、条件访问绕过、设备码钓鱼与 Azure Arc 横向移动。
