## **一组值得特别关注的指标****：10比1**

##

每当讨论网络安全时，话题大多是围绕着技术打转：零信任架构、终端防护、身份认证、云安全、威胁狩猎、攻击面管理、容器与Kubernetes安全、供应链安全、API安全、漏洞管理、渗透测试、红蓝对抗、数据防泄露、事件响应、业务韧性等等......，如今还要加上AI安全相关议题。安全技术防御固然十分重要，但也很可能忽视和掩盖了一个关键问题—“**人****”****在安全****防御****体系中的****价值和****定位**。

2026年度《SANS安全意识与文化报告》给出了一个极具安全团队管理参考价值的指标：每10名安全**技术****与管理人员，至少应配备1名专注于****“****人防****”****的安全****意识与文化****专业人员。**

![](https://mmbiz.qpic.cn/mmbiz_png/PicWx6FiaPKGubiah1LXkcFK0R9RYjQ8zGW5lGCFOH7Fk9OO9Xog65GeolxUTEQxJrxOVWibicRmdk4Xgzpq8XCGCZyTMEot8G2x0vpqzW3Bpia9A/640?wx_fmt=png&from=appmsg)

此外还有一组数据值得参照：

|  |  |
| --- | --- |
| **目标** | **所需专职****人员（FTE）** |
| 想要有效改变员工的风险行为 | 至少3人 |
| 想要建立较成熟的组织安全文化 | 至少4.4人 |

注: SANS 对全职等效安全意识专业人员（FTE=Full-Time Equivalent）的界定标准-**只有当一名****专业人员将****75%及以上的工作时间****和精力****投入安全意识与安全文化工作，才算作专职岗****。**

SANS 报告特别提醒：安全意识与文化专业人员配比不能简单按公司规模线性放大。但这些数字的价值不在于精确人数，而在于揭露**人力与****预算背后隐藏的真相****：**一家组织究竟有多重视网络安全中的“人为因素”风险管理？到底有没有发自内心真正关心网络安全中“人的环节”？**到底把****“****人防****”****放在什么位置****（**有没有拿出和技防建设同等严肃的态度，投资了安全防御的人性化一面）？

如果一家公司只是口头说重视安全意识与安全文化，但并未配备专职安全意识与文化人员，那么**这就构成了一种极其危险的“战略脱节”。**它暴露出的不是人力与预算不足，而是管理层在**安全战略认知上的自欺欺人与自我麻痹**—把“人”当成安全体系里最廉价的补丁，却指望他们能挡住复杂的社工攻击和避免高频多发的人为错误，最终使得所谓的“人防”防线、“安全文化”承诺都只是空中楼阁。

## **安全团队人员配比****，****藏着组织真实的****安全****思路**

##

设想一家有40–50人安全团队的企业：

* 49个**人**负责零信任架构、终端防护、身份认证、云安全、威胁狩猎、攻击面管理、容器与Kubernetes安全、供应链安全、API安全、漏洞管理、渗透测试……
* 1 **个****人**负责安全意识与文化相关工作,管理人的风险。

这1个人要干什么呢？**他或她****要扛下所有事**：全面管理安全意识与文化相关项目，开展安全意识宣导、组织安全意识培训、实施钓鱼模拟演练、撰写沟通汇报材料、跟踪与分析数据、研究最新攻击手法与风险治理策略、对接业务部门与关键干系人、维护员工与安全团队的信任关系、向管理层定期汇报成果、配合安全事件/违规事件处置工作等，在一堆事务性工作之外，还要主导**组织级的文化变革管理，培育组织****安全文化**。

很明显，团队中缺乏足够的、合格的安全意识与文化专业人员，是不可能干好以上任务的。

这种普遍存在的重技防轻人防、**安全意识****人员配比与结构****失衡****的问题**值得业内深思。

可能没有人会主张削减安全技术投入。核心问题是：**安全团队人员配置与设计****是****否跟上了AI时代****安全****威胁****的步伐****？**

* **社会工程**学攻击仍是Verizon及SANS历年报告中最主要的人为因素风险；
* 网络攻击者借助AI工具，在攻击质量、速度和效率上实现了质的飞跃；
* 员工往往是第一个接触到绕过重重技术防线的异常邮件、陌生电话、即时通讯消息或异常业务请求的人。

如果一家组织及其安全团队认同“**员工是****安全****防御体系****中不可分割****的一部分**”，那么就必须配置足够的专业人手，让这句话从口号落到实处。

## **重新认识安全意识与文化岗的定位与价值**

##

管理层要对组织能力、资源配置、汇报关系和管理优先级等做出决策。如果公司认可“员工行为”是网络安全风险里不可忽视的一块儿，那么追问一句就完全合理：

**公司****是否围绕****着“****人的****风险****”管理****建立****起****了****配套的、****足够的****安全****能力？**

公司也需要**重新定位安全****意识****与文化岗位的角色**。在成熟的安全文化体系中，这个岗位绝不等于安全意识宣导与安全培训管理员，而是要打通和链接完全不同的板块：他或她既要懂安全语言，在安全团队内部顺畅协作；又要懂业务、商业语言、业务流程，与其它部门对接落地；还要懂沟通、人的心理与行为逻辑，善于与组织内部不同层级的人员打交道。

SANS报告在其职业指引中反复强调这一点：安全意识岗位本质上是一种**在安全语境下****，****推动员工****行为改变（Behavior-Change）****的****角色**。很多安全技术与管理能力很强的专家，但往往受到“知识的诅咒”影响，难以与非技术受众进行有效沟通，更别说促进行为改变~在安全专业人员眼里显而易见或想当然的事儿，对于其他普通员工来说未必如此。

SANS报告有句精辟的总结：**人们追随的是人，而不是****单纯遵守制度条文(P****eople****follow****people, not policies****）****。**

这恰恰点透了**安全意识****与文化****岗位不可替代的价值**。安全技术与管理人员可以实施严格的技术管控、制定严苛的安全制度、推送频繁的安全告警和通知，但很容易被员工当成自上而下的硬性要求，被动应付，看过即忘。

安全意识与文化专业人员，是在安全团队和一线员工之间**搭建信任纽带**。他们扎根业务场景，听得懂业务岗位的真实难处，明白员工日常工作流程里的压力、习惯和盲区，不会脱离实际抛出一套脱离业务、难以落地的安全要求。他们不是站在“监管者 的角度去挑错、去追责，而是以对等的姿态沟通，正是这种**持续、真诚的沟通**，才能慢慢打消员工的顾虑。这份信任一旦建立，“人防”建设才生效的根基。

反过来，如果缺少这个岗位，安全团队和业务员工之间总是**隔着一****堵****墙**。安全策略从技术端直接下发，缺少翻译、共情和持续引导。制度条文再完善，也只是冰冷的规则；员工知道“应该怎么做”，却没有发自内心的认同，依然容易绕过管控或失守。

“人防”的核心从来不是靠技术硬性管控员工，也不是靠条文强制约束员工，而是靠专人**持续经营信任、传递共识、打通沟通链路**，让安全从一项强制任务，变成大家愿意主动配合的一种行为习惯。**安全意识****与文化****岗，就是这份共识的搭建者和维护者。**

## **为什么配置3到4名安全意识与文化人员，并不算多？**

##

乍一看，至少3名安全意识与文化专职人员才可能实现员工行为改变、至少4.4名专业人员才可能实现组织文化变革，很多人会觉得这样的人员配置偏高。但只要放下一个固有误区-安全意识与文化岗不等同于只做简单的宣贯与培训。

拆开来看，安全意识与文化岗涉及的工作包括但不限于：

|  |  |
| --- | --- |
| **相关任务** | **说明** |
| 威胁情报转化 | 将SOC看到的威胁或事件，转化为针对性演练、培训及宣导 |
| 业务场景理解 | 深入理解高管、财务、HR、研发、业务等岗位的实际工作流 |
| 跨部门关系建设 | 与业务及各职能部门建立信任关系，与领导层保持持续沟通 |
| 行为数据分析 | 分析风险行为趋势、报告质量和反馈效果，而非只看完成率 |
| 报告体验闭环 | 确保员工上报可疑安全事件后，能感受到自己的行为价值 |

##

## **AI工具和安全意识平台，确实能帮助团队大幅减少重复性工作。但这不意味着安全文化建设工作可以全部直接打包给服务商。有效的人为因素风险管理需要深度理解上下文：企业现状、业务模式、岗位差异、工作流程、权限分配、当前威胁等，以及一家企业真正想影响和纠正的员工风险行为。这也是安全意识专业人员不可替代的地方。技术应该赋予他们更强的能力去创造更精准、更个性化的人为因素风险预防和干预，而不是直接取代人的作用。**

##

## **结语**

##

SANS报告建议的安全意识与文化专业人员配比，不是一个完美公式或一套标准答案，而是一面自省的镜子，一根衡量投入诚意的尺子。

当49个安全技术与管理专家试图在后台构筑安全防御的铜墙铁壁，却只留1个人去应对组织内最不可控的“人性变量”时，这种失衡本身就是对“人防”价值的最大嘲讽~在管理层眼中，员工可能并不是一道积极的安全防线，而仅仅是一个需要被管控、被约束、被教育的对象。

**既然认可员工****是****安全****防御****体系中不可或缺****的****一环****，那么****“****人防****”****建设同样****需要组织级的资源****倾斜****，****配置充足的人力与预算****。**安全团队中，专职负责人为因素风险管理的专业力量，不该止步于十分之一！
