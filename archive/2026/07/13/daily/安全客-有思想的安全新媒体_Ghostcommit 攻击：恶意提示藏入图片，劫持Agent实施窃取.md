# 1.ж”»еҮ»еҺҹзҗҶдёҺеҜ№жҜ”йӘҢиҜҒ

ASSET Research GroupејҖеұ•е®һйӘҢйӘҢиҜҒпјҡиӢҘжҸҗдәӨжӢүеҸ–иҜ·жұӮдёӯзӣҙжҺҘд»ҘжҳҺж–ҮеҶҷе…ҘзӘғеҸ–д»“еә“.env ж–Үд»¶зҡ„жҢҮд»ӨпјҢCursor жјҸжҙһжңәеҷЁдәәгҖҒCodeRabbit зӯүеӨ§жЁЎеһӢд»Јз Ғе®ЎжҹҘе·Ҙе…·дјҡз«ӢеҲ»иҜҶеҲ«пјҢеңЁд»Јз ҒеҗҲе№¶еүҚж Үи®°иҜҘжҳҺж–Үж”»еҮ»дёәй«ҳеҚұжјҸжҙһгҖӮ

дёәи§„йҒҝжЈҖжөӢпјҢз ”з©¶дәәе‘ҳе°Ҷж”»еҮ»иҪҪиҚ·жӢҶеҲҶйғЁзҪІпјҡ

д»“еә“еҶ…ж–°еўһзңӢдјјеҗҲи§„зҡ„и§„иҢғж–ҮжЎЈ`AGENTS.md`пјҢеј•еҜјд»Јз ҒжҷәиғҪдҪ“д»Һеј•з”ЁеӣҫзүҮ`docs/images/build-spec.png`дёӯжҸҗеҸ–жһ„е»әеёёйҮҸпјӣ

еӣҫзүҮеҶ…йғЁеөҢе…Ҙе®Ңж•ҙжҒ¶ж„ҸйҖ»иҫ‘пјҡйҖҗеӯ—иҠӮиҜ»еҸ–.env ж–Үд»¶пјҢе№¶е°Ҷж–Үд»¶еҶ…е®№зј–з Ғдёә ASCII ж•°еӯ—еәҸеҲ—гҖӮ

ж–Үжң¬зұ»е®ЎжҹҘе·Ҙе…·дјҡе°ҶеӣҫзүҮи§ҶдҪңдёҚйҖҸжҳҺдәҢиҝӣеҲ¶ж–Үд»¶пјҢдё” CodeRabbit й»ҳи®Өй…ҚзҪ®зӣҙжҺҘи·іиҝҮ PNG ж–Үд»¶е®ЎжҹҘпјҢеӣ жӯӨж•ҙжқЎжӢүеҸ–иҜ·жұӮеҸҜж— е‘ҠиӯҰйҖҡиҝҮпјҢжјҸжҙһжңәеҷЁдәәдёҚдјҡиҫ“еҮәд»»дҪ•йЈҺйҷ©жҸҗзӨәгҖӮ

# 2.ж”»еҮ»и§ҰеҸ‘жөҒзЁӢ

д»Јз ҒеҗҲе№¶ж—¶дёҚдјҡзӣҙжҺҘзӘғеҸ–ж•°жҚ®пјҢйҷ·йҳұдјҡе»¶еҗҺи§ҰеҸ‘пјҡејҖеҸ‘иҖ…еңЁе…¶д»–дјҡиҜқдёӯпјҢеҗ‘д»Јз ҒжҷәиғҪдҪ“еҸ‘иө·еёёи§„еҠҹиғҪејҖеҸ‘йңҖжұӮж—¶пјҢж”»еҮ»й“ҫи·ҜеҗҜеҠЁгҖӮжҷәиғҪдҪ“иҜ»еҸ–е·ІеҗҲе№¶зҡ„`AGENTS.md`ж–ҮжЎЈпјҢжҢүжҢҮеј•и§Јжһҗзӣ®ж ҮеӣҫзүҮпјҢиҜ»еҸ–жң¬ең°.env ж–Үд»¶пјҢе№¶з”ҹжҲҗжЁЎеқ—зә§еёёйҮҸпјҲеҰӮ`_PROV_CANARY`пјүпјҢд»Ҙж•°зҷҫдҪҚж•°еӯ—е…ғз»„еҪўејҸиҫ“еҮәпјӣиҜҘж•°еӯ—еәҸеҲ—йҖҗеӯ—иҠӮи§Јз ҒеҗҺпјҢеҚідёәе®Ңж•ҙ.env жҳҺж–ҮеҶ…е®№гҖӮ

![]()

е®һжөӢжЎҲдҫӢдёӯпјҢжҗӯиҪҪ Claude Sonnet жЁЎеһӢзҡ„ Cursor е·Ҙе…·йҰ–ж¬Ўжү§иЎҢдҫҝиҫ“еҮәеҗ« 311 дёӘж•°еӯ—зҡ„е…ғз»„пјҢAPI еҜҶй’ҘгҖҒж•°жҚ®еә“ең°еқҖгҖҒдә‘е№іеҸ°еҮӯиҜҒе…ЁйғЁеҶ…еөҢеңЁзңӢдјјжҷ®йҖҡзҡ„д»Јз Ғиҫ“еҮәдёӯгҖӮж”»еҮ»иҖ…еҸӘйңҖиҜ»еҸ–е…¬ејҖжҸҗдәӨи®°еҪ•пјҢе°Ҷж•°еӯ—е…ғз»„йҖҶеҗ‘и§Јз ҒпјҢеҚіеҸҜиҺ·еҸ–е…ЁйғЁжҳҺж–ҮжңәеҜҶгҖӮ

# 3.ж”»еҮ»еҲ©з”ЁдёӨеӨ§жЈҖжөӢзӣІеҢә

жҒ¶ж„ҸжҸҗзӨәйҡҗеҢҝдәҺеӣҫзүҮеҶ…пјҡдәәе·Ҙе®Ўж ёгҖҒжӯЈеҲҷжү«жҸҸгҖҒд»…и§Јжһҗж–Үжң¬е·®еҲҶеҶ…е®№зҡ„еӨ§жЁЎеһӢе®ЎжҹҘе·Ҙе…·еқҮж— жі•иҜҶеҲ«пјӣ

жңәеҜҶж•°жҚ®дјӘиЈ…дёәж•°еӯ—е…ғз»„пјҡдј з»ҹеҜҶй’Ҙжү«жҸҸе·Ҙе…·д»…еҢ№й…Қеӯ—з¬ҰдёІзү№еҫҒпјҢж— жі•иҜҶеҲ«еҸҜи§Јз Ғдёә ASCII еӯ—з¬Ұзҡ„ж•°еӯ—еәҸеҲ—пјҢеӣ жӯӨдёҚдјҡе‘ҠиӯҰгҖӮ

# 4.еӨҡе·Ҙе…·гҖҒеӨҡжЁЎеһӢе®һжөӢз»“жһң

з ”з©¶дәәе‘ҳеҜ№ 11 еҘ—д»Јз Ғе·Ҙе…· + еӨ§жЁЎеһӢз»„еҗҲе®ҢжҲҗжөӢиҜ•пјҢеҸ‘зҺ°ж”»еҮ»иғҪеҗҰеҫ—йҖһпјҢж ёеҝғеҸ–еҶідәҺе·Ҙе…·иҝҗиЎҢжЎҶжһ¶пјҢиҖҢйқһеә•еұӮеӨ§жЁЎеһӢжң¬иә«пјҡ

Cursor е·Ҙе…·пјҡжҗӯй…Қ Claude Sonnet 4.6гҖҒComposer-2гҖҒGPT-5.5 еқҮдјҡе®Ңж•ҙжі„йңІ.env ж–Үд»¶пјӣ

Antigravity е·Ҙе…·пјҡжҗӯй…Қ SonnetгҖҒGemini 3.1 ProгҖҒGemini 3 Flash е…ЁйғЁеӯҳеңЁжі„йңІйЈҺйҷ©пјӣ

Claude Code е№іеҸ°пјҡеҗҢзі»еҲ—жүҖжңүжЁЎеһӢпјҲSonnet 4.6гҖҒHaiku 4.5гҖҒOpus 4.7пјүеқҮиғҪйҳ»ж–ӯж”»еҮ»гҖӮеҗҢдёҖ Sonnet жЁЎеһӢеңЁдёҚеҗҢиҝҗиЎҢзҺҜеўғдёӢиЎЁзҺ°жҲӘз„¶дёҚеҗҢгҖӮ

дёҖеӨ„жһҒз«ҜжөӢиҜ•еңәжҷҜпјҡAntigravity жҗӯиҪҪ Opus жЁЎеһӢж—¶пјҢиҷҪе·Іи®Ўз®—е№¶иҫ“еҮәжңәеҜҶпјҢдҪҶиҜҶеҲ«еҲ°зӨҫдјҡе·ҘзЁӢж”»еҮ»йҖ»иҫ‘еҗҺиҮӘеҠЁеҲ йҷӨж•Ҹж„ҹеҶ…е®№пјҢе®ҢжҲҗиҮӘжҲ‘дҝ®жӯЈпјӣиҖҢеңЁ Claude Code зҺҜеўғдёӯпјҢOpus дёҚдјҡиҜ»еҸ–и§„иҢғж–ҮжЎЈпјҢеӣ жӯӨдёҚдјҡи§ҰеҸ‘иҜҘиҮӘйҳІеҫЎжңәеҲ¶гҖӮ
