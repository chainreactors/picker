### eBook: Wi-Fi Security Sample Architectures

An unmodified excerpt from Wireless Security Architecture (Wiley) — a fast-reference cheat sheet for designing secure enterprise Wi-Fi.

High-, medium-, and low-security sample architectures for managed users, headless/IoT devices, contractors, BYOD, and guest networks — plus guidance on WPA2/WPA3 migration, when to separate SSIDs, and how long a WPA3-Personal passphrase should be.
