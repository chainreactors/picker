> 币安遭疑似史上最大黑客攻击：63亿美元受影响，加密市场单日爆仓超14亿美元

北京时间10月30日凌晨，全球最大加密货币交易所币安遭遇疑似史上规模最大的安全事件。币安官方随后确认，事件估计总影响约**63亿美元**，并承诺通过SAFU基金及公司自有资金承担全部损失。消息引发加密市场恐慌性抛售，比特币一度跌破77,000美元，全网24小时爆仓金额超过14亿美元。

### 事件确认：赵长鹏率先发声，币安随后官方定性

事件最早由币安创始人赵长鹏在X平台披露。北京时间10月30日上午，赵长鹏发文称“币安看起来确实遭到了黑客攻击”，同时强调“用户资金是安全的”。他特别感谢了Tether和Circle的快速冻结行动，并表示自己虽已不再管理币安，但“作为股东，预期所有用户资金将得到全额覆盖”。

随后币安官方发布正式通报，将事件定性为“安全事件”。币安在公告中给出了初步调查结论：事件可能涉及一名DevOps工程师的笔记本电脑被入侵，攻击者借此访问某个服务容器并提交了未经授权的提现交易。币安明确表示“未发现任何钱包私钥泄露的证据”，并承诺在调查完成后发布详细技术复盘报告。

### 数据口径：从17亿到63亿，各方估算差异显著

此次事件中，各方对损失规模的表述经历了多次修正，最终以币安官方口径为准：

| 数据来源 | 金额/内容 |
| --- | --- |
| 币安官方估计总影响 | 约**63亿美元** |
| 币安确认链上已冻结 | 约**30亿美元** |
| Chainalysis估计被盗 | 约59亿美元 |
| TRM Labs估计被盗 | 超过60亿美元 |
| Tether冻结 | 约15.6亿–16亿美元USDT |
| Circle冻结 | 逾8亿美元USDC |

赵长鹏最初提及Tether和Circle冻结约17亿美元资产，币安随后将链上冻结数字修正为约30亿美元。Tether首席执行官Paolo Ardoino确认冻结逾15.6亿美元相关资产，Circle首席执行官Jeremy Allaire则表示配合执法部门冻结逾8亿美元USDC。区块链安全组织SEAL 911的Taylor Monahan对媒体表示，攻击者实际获利“远超20亿美元”，可能高达55亿美元。

### 赔付承诺：赵长鹏“预期”与币安“承诺”的区分

关于“全赔”问题，需要区分两个层面：

**赵长鹏以股东身份表态**：他在X上表示“作为股东，我预期所有用户资金将得到全额覆盖”（“as a shareholder, I expect all user funds will be fully covered”）。措辞是“预期”，并非以运营方身份直接下达赔付指令。

**币安官方以运营方身份承诺**：币安在公告中明确表示“Binance will cover all losses from the SAFU fund and the company’s funds”（币安将通过SAFU基金和公司资金承担所有损失）。联合CEO何一亦公开确认将承担全部被盗损失。

简言之：赵长鹏给出的是股东层面的预期，币安官方做出的是具有执行效力的正式承诺。

### 市场反应：主流币集体跳水，24万人爆仓

币安事件成为加密市场短期情绪的引爆点。消息发酵后，主流加密资产同步下挫：

* **比特币**：一度跌破**77,000美元**，低见76,664美元，24小时跌幅约4.5%–5.45%
* **以太坊**：跌破**2,200美元**，跌幅约5%–7%
* **BNB**（币安平台币）：跌幅最深，一度超过**8%**，跌至约694–699美元

衍生品市场损失惨重。据CoinGlass统计，截至北京时间10月30日，过去24小时全网爆仓情况如下：

| 指标 | 数据 |
| --- | --- |
| 爆仓总人数 | 超**24万人** |
| 爆仓总金额 | 约**14.8亿–15.5亿美元** |
| 多单爆仓 | 约**12.8亿–13.4亿美元**（占比约86%） |
| 空单爆仓 | 约1.96亿美元 |
| 币安平台爆仓 | 约7.5亿美元（占全网50.8%） |

数据来源

多单爆仓占比超过八成，表明做多者在此轮下跌中损失最为惨重。Zeus Research分析师Dominick John对The Block表示，币安事件“加剧了全市场抛售，BNB面临的风险敞口最大”，约15亿美元的24小时清算（以多单为主）放大了BTC和ETH的下行压力。

### 兜底能力与市场评估

尽管金额巨大，多位分析师认为币安的损失在可控范围内。JPEG Trading联合创始人Kevin March指出，币安拥有约12亿美元的保险基金，加上Tether和Circle迅速冻结资产，预计损失可控。Laevitas市场主管Rick Maeda则表示，币安约1440亿美元的托管资产、此前无碍支付43亿美元美国罚款的记录，以及稳定币发行商的快速反应，共同避免了行业性恐慌。

不过，此次事件若最终确认，将打破2025年Bybit被盗15亿美元所创下的加密货币史上最大劫案纪录。TRM Labs全球政策主管Ari Redbord对媒体表示，这使得本案成为“人类历史上规模最大的银行劫案”。

币安已采取的即时措施包括：暂停充值提现、撤销受影响地址授权、联合执法机构与区块链情报伙伴追踪资金。币安表示将在修复完成后发布更新版储备金证明及完整技术报告。截至发稿，攻击者身份尚未确认，失窃资产的最终净损失数字仍有待完整调查报告的发布。
