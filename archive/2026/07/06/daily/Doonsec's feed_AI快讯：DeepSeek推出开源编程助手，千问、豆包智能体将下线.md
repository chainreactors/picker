→中央网信办深入开展“清朗·整治AI应用乱象”专项行动第一阶段工作

“清朗·整治AI应用乱象”专项行动自2026年4月启动以来，中央网信办聚焦未按规定履行大模型备案登记义务、AI平台安全和审核过滤能力不足、AI数据投毒、生成合成内容标识落实不到位等AI应用乱象，部署各地网信部门深入推进第一阶段重点整治任务，并开设“涉AI应用乱象举报专区”，专项受理公众举报。

在各方共同努力下，第一阶段累计处置违规网站、应用程序、智能体等AI产品1.4万余款，清理违法违规信息600余万条，处置账号2.6万余个，下架违规AI商品1300余个、违规开源数据集9个，各项工作取得积极进展。

→DeepSeek推出开源编程助手Deep Code

7月6日，DeepSeek官方API文档正式收录开源终端AI编程助手Deep Code。该工具专为DeepSeek-V4系列模型优化，支持深度推理、强度调控及Agent Skills。5月首发v0.1.20版，最新版为v0.1.31，提供CLI命令行与VS Code插件双形态。其核心特性包括项目级会话持久化、上下文感知、文件读写、命令执行等连续协作能力，兼容OpenAI接口模型。项目开源地址为https://github.com/lessweb/deepcode-cli。

→美团开源万亿参数大模型LongCat-2.0

7月6日，美团正式开源万亿参数大模型LongCat-2.0。该模型总参数达1.6万亿，平均激活约480亿，专为Agentic Coding任务设计。其创新采用LongCat稀疏注意力与N-gram Embedding架构，显著提升长上下文处理效率和token级表示能力，并通过动态激活机制增强代码理解、生成及执行性能。此举旨在推动AI编程基础设施发展，支持开发者高效构建智能编码代理应用。

→宇树科技陈立谈具身智能的“ChatGPT 时刻”

在亚布力中国企业家论坛第十二届创新年会，宇树科技股份有限公司联合创始人陈立表示，目前机器人其实没有大面积应用，主要原因还是具身智能大模型没有成熟。

陈立认为，未来2-5年，首先需要有一个统一的端到端的机器人大模型，这是最重要的。第二是，还有更低成本更高寿命的硬件以及超大批量规模生产制造，本体在超大批量规模生产制造之后，边际成本是非常低的。第三是低成本大规模的算力，算力可能是分布式的，因为端侧的算力可能会有比较大的续航、散热和成本问题，云端会有延时问题。

陈立认为，具身智能达成“ChatGPT时刻”的核心标志其实很简单，即两个80%：在80%的陌生场景中，机器人通过语音或文字指令，能够顺利完成约80%的任务。四年之后（2030年），具身智能机器人将引领全新消费浪潮，大幅推动社会生产力与劳动力升级。

→蚂蚁gPass与Rokid推AI眼镜智能体开发平台

7月4日，蚂蚁集团gPass与Rokid宣布合作推出面向AI眼镜的一站式智能体开发平台。该平台支持企业级Agent开发、编排及场景化落地，适配Rokid眼镜硬件特性，助力开发者快速构建、发布应用并上架至其应用商店。合作旨在降低AI眼镜应用开发门槛，加速从概念验证到商业化进程。

→谷歌地图将推AI点餐功能

7月4日，Android版谷歌地图v26.27.00.941319029测试版中出现多项点餐功能字符串，显示其正整合Gemini AI开发语音驱动的外卖服务。用户可通过Ask Maps语音描述需求（如‘想吃辣味披萨’），系统自动推荐餐厅并完成下单；车辆抵达时，可在得来速窗口直接取餐。该功能尚处内测阶段，具体技术实现路径（云端AI或端侧AI）及机型兼容性尚未公布。

→千问拟人化智能体及自建功能将于7月10日下线

7月4日，千问平台发布公告称，因功能升级与维护，拟人化互动类智能体及用户自建智能体功能将于2026年7月10日正式下线。届时，用户将无法继续访问相关智能体的配置信息及历史对话记录。

信息显示，此次调整涉及拟人化互动类智能体和用户自建智能体两类功能，平台将依照法律法规删除相关数据。用户需在7月10日前导出对话记录、备份人设配置。据介绍，千问智能体功能与服务将于7月15日全面停止服务，此次下线是继豆包之后，又一家平台对智能体功能进行调整。

→豆包智能体功能将于7月15日下线

7月5日，豆包平台发布通知称，由于产品功能调整，智能体功能将于2026年7月15日下线。功能下线后，用户仍可在一段时间内通过豆包查看并自行保存智能体信息及历史对话数据。

2026年10月15日后，豆包将根据《隐私政策》对智能体相关数据进行处理，后续将无法在豆包内查看或恢复。豆包建议用户，如有重要内容，可通过截图或分享导出文本的方式提前完成备份。

→GitHub Copilot宣布接入首个开源模型Kimi K2.7 Code

微软旗下AI编程助手GitHub Copilot今日宣布，正式接入Kimi K2.7 Code模型，这是GitHub Copilot自上线以来，首次接入开源模型。

GitHub Copilot是全球规模最大，使用最广泛的AI编程助手，由GitHub与OpenAI联合打造，拥有470万付费开发者及数万企业客户。此前GitHub Copilot仅支持OpenAI、Anthropic和Google等公司的顶尖闭源模型。此次接入Kimi，也是中国开源大模型在国际竞技场上获得的又一认可。

→高德AI专车升级支持自然语言下单

7月6日，高德地图宣布AI专车服务完成升级。用户可通过自然语言描述出行需求，如‘一家三口去首都机场，有老人，会晕车’，系统内置的‘AI专车管家’自动识别乘客结构、特殊需求等关键信息，匹配适配车辆（如油车、平稳驾驶车型）并提示司机执行相应服务。升级覆盖全国已开通高德专车服务城市，旨在提升个性化、无障碍出行体验。

→腾讯混元Hy3发布

腾讯混元Hy3正式发布，已在WorkBuddy/CodeBuddy、元宝、Marvis、ima等多个业务接入，API已在腾讯云TokenHub上线，多个海外API平台也将陆续接入。腾讯介绍，相较preview版本，Hy3展现出强于同尺寸模型且比肩旗舰开源模型的智能水平。

→售价99万元的机器人伴侣续航撑不过一晚，优必选回应

据新浪科技报道，近日，“99万机器人伴侣续航撑不过一晚”相关话题登上热搜榜单。对此人形机器人企业优必选作出回应。优必选方面称：“目前全尺寸人形机器人续航基本上都在2-4小时，这个是行业普遍情况。”

→欧莱雅等国际消费品巨头借AI提速产品研发

欧莱雅集团近日宣布，其借助AI筛选分子成分，将护肤成分复用于洗发水研发，使新品开发效率提升至原来的四倍。雀巢、赫力昂、亿滋国际等企业亦广泛应用AI加速原料测试、生成配方并优化供应链韧性。欧莱雅四年前已在实验室部署AI，预判分子对皮肤与发丝作用；亿滋则利用AI减少样品试制，60% AI生成配方在营养、可持续性及成本方面更优。此举旨在应对消费者偏好快速变化与降本增效压力。

→英伟达AI机架系统Kyber或推迟至2028年发布

据CNBC报道，因PCB中介板制造工艺难度过高，英伟达下一代AI机架系统Kyber预计推迟至2028年推出。该核心电路板需多层精密印刷以连接各模块，当前良率与产能无法满足量产要求。此次延期凸显其每年迭代AI硬件的节奏正受制于先进封装与板级制造能力。原计划的双系统拼接备用方案亦被放弃，主因云服务商认为其设计冗余、运维成本过高。事件发生于2026年7月，影响全球AI基础设施部署规划。

→千问大模型正式升级实时语音识别大模型Fun-ASR-Realtime

7月6日，千问大模型正式升级实时语音识别大模型Fun-ASR-Realtime，该模型为首字延迟控制在百毫秒级别、识别准确率接近离线模型的流式语音识别模型，支持16种方言和30种语言。

据介绍，Fun-ASR-Realtime在近期影视飓风“重返荒岛”100小时直播活动中全程提供实时字幕服务，累计识别字幕超过6万条，总计约132万字，通过上下文纠错显著提升识别准确率。

→阿里云全栈AI云服务市场份额达40.1%居首

7月6日，沙利文发布《2025中国全栈AI云服务市场报告》。报告显示，2025年中国IaaS、PaaS、MaaS总市场规模为595.9亿元，阿里云以239亿元收入占比40.1%，位居第一，其份额超过第二至第四名厂商之和。该数据覆盖全国范围，反映阿里云在提供开箱即用AI云服务方面的领先优势。报告指出，驱动增长的因素包括大模型基础设施、平台工具链及行业模型服务的全栈能力。

→Anthropic拟在澳大利亚布局1.4GW数据中心算力

人工智能公司Anthropic计划在澳大利亚采购至少1.4GW数据中心算力，对应建设成本约150亿美元（约216亿澳元），远高于市场此前预期。该公司目标是在2027年底前启用至少1GW算力，并已在澳大利亚设立办公室推进本地化基础设施布局。
