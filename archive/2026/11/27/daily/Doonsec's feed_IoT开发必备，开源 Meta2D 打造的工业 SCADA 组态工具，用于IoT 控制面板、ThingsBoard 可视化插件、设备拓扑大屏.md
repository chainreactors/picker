SceneV 是一款国产开源工业物联网低代码组态和数据可视化开发工具，兼容 ThingsBoard 物联网平台接口，基于 Meta2D 图形引擎构建，专为工业组态和数据可视化大屏设计而打造，让开发者能够通过直观的拖拽操作，零代码或低代码方式快速构建专业级的可视化应用。

🚀 最新技术栈：基于 TypeScript、Vue3、Canvas、WebGL 等最新技术栈，提供高性能的组态渲染能力。

🎨 丰富的组件：企业级组态可视化解决方案，提供丰富的图形组件和模板，满足各种业务场景需求。

🎭 主题定制：通过简单的配置，即可实现各种主题切换和样式定制，满足个性化需求。

🌐 数据驱动：内置数据绑定方案，支持Websocket、HTTP、MQTT等协议，并集成了ThingsBoard平台数据获取能力，支持实时数据更新，满足各种数据可视化需求。

🔒 交互丰富：内置丰富的交互能力，支持拖拽、点击、缩放、数据触发、条件触发等多种操作，交互自然流畅。

⚡ 高性能：现代化的渲染引擎，使用Canvas绘制，快速加载，流畅运行，支持大规模场景渲染。

🔥 ThingsBoard 插件：无缝集成 ThingsBoard 平台，可直接使用平台数据渲染到组态中，实现强大的物联网数据可视化与设备管理。

多端适配能力

🌐 跨浏览器支持：Chrome、Firefox、Edge、Safari 等主流浏览器

📲 移动端适配：完美支持移动端 webview 方式访问

🖥️ 全平台覆盖：手机、平板、PC、大屏等多端展示

开源版功能

![](https://mmbiz.qpic.cn/sz_mmbiz_png/0VE9kDxicLUiaOQXcrEChXqAcwYn07CslqQ1GUm0L5dv5PaTSgJjKmDh64UaGMgLUiaXciavRriaE2Qd5iaibsZicsHABCdoVnLF3Y430wJXYUnl8C8/640?wx_fmt=png&from=appmsg)

开箱即用：丰富的组件库和模板，快速搭建专业可视化界面

零代码开发：无需编写复杂代码，通过配置即可实现复杂交互效果

多数据源支持：无缝集成 ThingsBoard、HTTP、 MQTT、WebSocket 等多种数据源

实时数据展示：支持动态数据绑定和实时更新，满足监控大屏需求

响应式设计：自动适配不同屏幕尺寸，确保在各种设备上完美展示

高性能渲染：基于 Canvas 的高性能渲染引擎，支持万级数据点流畅展示

无缝对接 ThingsBoard：通过 websocket 实时接入 ThingsBoard 设备数据。

工业场景适配：内置多类型工业组态图形，适配 SCADA、MES、能源监控等典型工业场景。

动态效果：支持在地图上标注设备位置、连线表示通信关系，并可添加动态路径动画，模拟物流或数据流向。

技术栈

前端框架：采用主流的 Vite + Vue3 + Element Plus

底层技术：Canvas

消息通信：支持 WebSocket、MQTT、HTTP、ThingsBoard

浏览器支持：Chrome、Firefox、Edge 等现代浏览器

API 设计：遵循 RESTful API 设计规范

多端适配：支持浏览器和移动端访问

部署方式：支持离线部署，可在线/离线更新

SceneV 工业组态可视化开发工具广泛应用物联网数字可视化：实时展示物联网设备数据，实现设备状态监控与数据可视化分析；工业智能制造组态：工业控制系统的可视化监控，实现设备状态实时展示与远程控制，构建智能工厂的可视化控制系统，实现生产流程的数字化管理；智慧工厂：为工业触摸屏设备定制直观易用的操作界面，监控产线设备状态、能耗、良品率等；城市物联网：监控摄像头、环境传感器，利用热力图展示空气质量等；能源管理：显示电网负荷、光伏发电量，并设置报警阈值。
