CISP-PTE

CISP-PTE注册渗透测试工程师，自2017年推出后，凭借扎实的社会效应、正向的行业反馈与学员口碑，在业内形成了 “渗透之前必先考 PTE” 的普遍共识。

CISP-PTE培训以培养学员的「实际网络安全渗透测试能力」与「真实操作能力」为核心，注重所学知识的先进性、实战性，80%为手动实践操作。旨在进一步提升个人信息安全领域技术水平和专业能力。

5月班CISP-PTE，理论（随报随学），实操直播（5月14-17日）；考试（北京、成都）。针对高校学生、渗透、安服、运维等岗位量身定制！

CISP-TRE

这个新课终于即将迎来开班！**原 CISP‑IRE（注册应急响应工程师）全面升级更名为 CISP‑TRE（注册威胁响应工程师）**，认证体系、知识框架、合规效力全面迭代升级，聚焦 “威胁检测 — 分析研判 — 应急处置 — 溯源追踪” 全流程防守能力。

本次CISP-TRE开班是课程体系更新改版后的首次开课，**早报名、早取证、早锁定蓝队先发优势**！上课时间：5月23、24、29、30、31日。

无学历、无工作经验硬性要求，具备基础网络知识即可报考。该认证适用于企业安全运营中心、应急响应团队、威胁情报分析等岗位，网络安全相关专业学生及从业人员。‌报名人群包括但不限于：

* 各单位网络安全负责人员、网络安全管理人员、IT技术人员
* 网络安全服务支撑人员（运维顾问等）
* 各单位IT运维人员（网络、系统、机房等）
* 渗透测试人员、网络安全从业人员、应急响应工作人员
* 网络安全方向求职的高校学生

OSWE（WEB-300）

OSWE（WEB-300 ）学习高级 Web 应用程序攻击和漏洞利用，包括高级 SSRF、持久性 XSS 和盲 SQL 注入，以及 .NET 反序列化、源代码分析、会话劫持、模糊测试和身份验证绕过等技术。

谷安于2021年就邀请业内资深专家筹备设计了OffSec体系认证培训课程，以学会、练会、有思路，提高学员攻防能力为目标，复盘知识点，设计实操打靶练习环节。

本期OSWE**专家讲师刘隽良授课，基础+强化+靶机训练+考前辅导等多阶段培训安排，系统化课程按节奏学习，少走弯路、高效备考OSWE 认证，实现技术和资质同步进阶。**

**上课时间：5月16、17、23、24、30、31日**

DPO数据保护官

# EXIN认证的DPO数据保护官连年入选《北京市国际职业资格认可目录》、《杭州市国际职业资格认定职称认可目录》、是欧盟GDPR合规实施的核心能力证明‌。

# DPO（数据保护官）作为数据合规与安全的核心角色，其重要性早已渗透到政企、互联网、金融等全行业，无论是对个人职业发展，还是对企业合规运营，都有着不可替代的价值！

**持有(ISC)²的**CISSP**或ISACA的**CISM/CISA证书的学员，备考DPO（数据保护官）**可以在获得PDPF、PDPP认证后直接申请DPO证书。无技术证书的可以走常规路径（**PDPF+PDPP+ISO27001**）。**
