# Pirate Site Movix’s Source Code Survives Four Rounds of GitHub Takedowns

today by
[Ernesto Van der Sar](https://torrentfreak.com/author/ernesto/)

[Home](https://torrentfreak.com "Go to TorrentFreak.") > [Piracy](https://torrentfreak.com/category/piracy/ "Go to the Piracy category archives.") >

Earlier this year, the source code of pirate streaming site Movix was shared openly on GitHub. This was a thorn in the side of the French rightsholder group ALPA, which has had several copies removed since, including another 38 forks last week, citing a Paris court order. Meanwhile, a fresh copy remains online, with recent updates linked to a user that ALPA repeatedly asked GitHub to ban.

![movix logo](https://torrentfreak.com/images/movixlogo.png)
In March, a Paris court ordered French Internet providers Orange, SFR, Free and Bouygues Telecom to block Movix, together with 21 other pirate sites.

Like many pirate sites, the streaming portal simply moved on to [new domain names](https://torrentfreak.com/pirate-sites-domain-hopping-habit-undermines-belgiums-new-blocking-order/). However, Movix also stands out in another way. The code that powers the site is shared openly on [GitHub](https://github.com/), for anyone to copy and use.

The repository includes the site’s frontend and backend, as well as a browser extension and mobile apps. The README presents Movix as France’s first open source streaming site with an AI twist, adding that it was entirely vibe-coded.

## Takedown and Repeat

The shared code didn’t go unnoticed, of course. [ALPA](https://torrentfreak.com/?p=248283), the French anti-piracy group whose members include the local arms of major Hollywood studios, the [MPA](https://www.motionpictures.org/) and music rights group [SACEM](https://www.sacem.fr/), has been sending takedown notices to GitHub over the Movix code since March.

The first two notices were sent in March and April, targeting Movix repositories uploaded by the same GitHub account. GitHub blocked both repositories at the time. In the second notice ALPA also asked the platform to ban the uploader, but the account is still active today.

While the repositories were taken offline, the source code soon resurfaced. A new GitHub account was created two weeks after the April takedown, and archived copies show that it hosted a fresh copy of the code by early May. By late June, the repository had 94 stars and 21 forks.

ALPA eventually went after that repository too, sending a new takedown request in September, and GitHub blocked it the next day. That still left the forks online, however, which ALPA eventually targeted last week.

“We are now targeting forks which are exact copies,” ALPA writes in its notice, which lists 38 forks. The forks we checked were blocked by GitHub a day later.

*ALPA’s notice*

![ban this user](https://torrentfreak.com/images/ban-this-user.png)

The notice doesn’t mention any specific movies or TV shows either. ALPA writes that its members own the rights to the titles “listed below”, but there are none mentioned.

ALPA also repeats its request to ban the uploader of the September repository, linking it to the March and April copies. Its September notice made the same claim about that second GitHub account, using the exact same words.

“This is the third repost from this user […] please ban this user as well,” ALPA’s latest notice reads.

## A Paris Court Order

ALPA’s recent notices point to the blocking order from the Paris Judicial Court. This was issued following a request from several French film industry groups, ordering Internet providers to block 22 pirate sites for 18 months.

This order also shows how popular Movix was. According to the evidence presented to the court, the site offered 7,236 movies and 2,956 series without permission.

The same evidence, provided by ALPA’s sworn agents, shows that Movix drew more than 387,000 unique French visitors in a single month. That’s more than any of the other 21 sites in that blocking order.

## The Code Lives On

ALPA’s Github takedowns removed the targeted repositories, but now the code itself is leading a life of its own. A fresh copy is still online today, under yet another new GitHub account.

Data from GitHub shows that both the GitHub account and the repository were created on September 24, less than a day after GitHub blocked the previous version.

According to its commit messages, the repository mirrors the full Movix code excluding some private files. The most recent sync was on November 15, which is three days after ALPA’s latest notice. These updates are credited to the GitHub user that ALPA asked GitHub to ban in April.

In addition to the code, there is no shortage of full streaming sites using the Movix brand today. Whether ALPA will target these and the new GitHub copy, which already has 21 forks of its own, has yet to be seen.
