# 你是否也有过这样的经历？

刚入门电子取证时，面对全网零散的资料，不知道应该先学注册表、磁盘分析，还是内存取证。

为了找一道比赛题的配套检材，翻遍论坛、网盘和群文件，最后只看到一句：

“链接已失效。”

复盘比赛时，只能在博客、知乎、公众号和 QQ 群聊天记录里拼凑思路，却很难看到完整、清晰、可复现的分析过程。

收藏了上百个学习链接，过段时间再打开，一半已经 404，剩下的内容也可能早已过时。

在电子取证学习和竞赛训练中，很多人都遇到过同一个问题：

资料分散、题目分散、检材分散，学习路径不清晰。

真正应该用来学习和训练的时间，反而被大量搜索、整理和筛选工作消耗掉了。

为了解决这个问题，我们搭建了DigiForensics

# DigiForensics 是什么？

![](https://mmbiz.qpic.cn/sz_mmbiz_png/0c8wEXsuyARAogRoLSh03VIfsHV9AQx4NLjiaHhID9zI09gxzsc4ibYEJxfN9Ca7Fh46NR2XaBwmSicDdwj5Tz2SZVBxmOdeu4sG3iccGvbgcq0/640?wx_fmt=png&from=appmsg)

DigiForensics 是一个专注电子取证领域的一站式学习与训练平台。

我们没有做泛网安方向的大而全，而是把重点放在电子取证这一条赛道上，希望把原本分散在各个平台、论坛、网盘和个人博客里的资源，集中整理到一个更稳定、更清晰、更适合长期学习的地方。

我们希望通过 DigiForensics，打通：

学习 → 训练 → 分析 → 复盘

这一完整闭环。

对于初学者，它可以帮助你建立清晰的学习路线。

对于备赛选手，它可以提供集中题库和配套检材。

对于电子取证爱好者和从业者，它可以成为一个沉淀 WP、案例、工具经验和分析思路的技术阵地。

# 目前已开放的核心功能

# 01 比赛中心

收录平航杯、獬豸杯、警铮杯、FIC 等电子取证相关赛事题目，并按照基础、进阶、高级等难度进行整理。

平台支持在线刷题与实时判分，让训练过程更加集中、清晰、可复现。

# 02 检材柜

检材柜是我们重点打造的板块。

过去，很多检材散落在网盘、论坛和群文件中，经常出现链接失效、说明缺失等问题。

DigiForensics 会尽可能提供长期有效、稳定可用的检材资源，并标注难度、推荐工具和适用场景，帮助大家更快进入分析状态。

# 03 Wiki 文档库

从 Windows 注册表、磁盘分析、内存取证，到手机取证、数据库取证、浏览器痕迹分析，平台会持续整理电子取证相关基础知识和实战文档。

我们希望文档库做到：

新手看得懂，老手用得上。

# 04 学习路线图

很多人学习电子取证时，不是不努力，而是不知道该按什么顺序学。

学习路线图会针对不同阶段的学习者，整理对应的知识点、训练题目和参考资料，帮助大家少走弯路。

# 05 WP 复盘库

电子取证学习中，WP 不只是答案记录，更重要的是分析过程。

DigiForensics 提供统一的 WP 复盘库，方便大家阅读、上传和交流解题思路，让有价值的分析过程能够长期保存下来。

DigiForensics 想做的，就是一个长期维护、持续更新、专注电子取证的学习与训练入口。

我们希望它不只是一个刷题站，而是一个真正属于电子取证爱好者的技术社区。
