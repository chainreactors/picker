## 微软将默认收集 GitHub Copilot 交互数据训练 AI

[![隐私](https://icon.solidot.org/images/topics/topic隐私.png?123)](/search?tid=133 "隐私")

[Edwards](/~Edwards) (42866)发表于 2026年03月26日 21时54分 星期四 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83887&appkey=1370085986&title=%E5%BE%AE%E8%BD%AF%E5%B0%86%E9%BB%98%E8%AE%A4%E6%94%B6%E9%9B%86%20GitHub%20Copilot%20%E4%BA%A4%E4%BA%92%E6%95%B0%E6%8D%AE%E8%AE%AD%E7%BB%83%20AI "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自巴比伦Ⅰ：女人**

微软旗下的代码托管平台 GitHub 宣布更新 GitHub Copilot 交互数据使用政策。从 4 月 24 日起，除非用户主动选择退出，否则微软/GitHub 将使用 GitHub Copilot 交互数据训练 AI 模型。微软默认启用了数据收集，此举被认为违反了欧盟的通用数据保护法规 GDPR，GDPR 强制要求默认选择退出。
https://github.blog/news-insights/company-news/updates-to-github-copilot-interaction-data-usage-policy/
