OKF 0.3 is now the default document contract for undeclared bundles. Readers can still select OKF 0.1 or 0.2 explicitly. Existing version declarations continue to select their own contract.

## Changes

* Read, validate, search and export OKF 0.3 through the Go API, CLI, MCP, GitHub Action and offline Viewer. Support bundle metadata, dated provenance, trust and lifecycle, attested computations, and GFM tables in indexes.
* Migrate 0.2 bundles with a preview and a revision-checked apply. Edits preserve unknown YAML extension fields.
* Resolve claim citations through matching source IDs. Viewer links source-backed footnotes to their source rows and keeps authored Markdown footnotes and backlinks.
* Update the English and Russian guides, references and teaching demos, along with the three repository skills and plugin manifests.

## Install

```
go install github.com/skosovsky/okf/cmd/okf@v0.3.0
go install github.com/skosovsky/okf/cmd/okf-mcp@v0.3.0
```

Use [the migration guide](https://skosovsky.github.io/okf/migration/) to preview a 0.2 → 0.3 upgrade. See [English documentation](https://skosovsky.github.io/okf/) or [Русская документация](https://skosovsky.github.io/okf/ru/).

## Verification

All 14 interoperability bundles passed, covering 1,409 Markdown files and 1,289 concepts. Five public OKF 0.2 bundles migrated successfully. Viewer preserved all 1,498 authored footnotes and backlinks in the corpus. Chrome checks passed for Starter Vault, Acme Retail and Crossplane.
