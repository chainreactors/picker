**网络安全动态 — Cyber Daily**

2026.11.13

Microsoft 365大规模宕机，全球范围内的Outlook、Teams和Copilot瘫痪

关键词：服务中断

2026年11月12日报道。微软365近日遭遇全球性大规模宕机，导致Outlook、Teams、Copilot、Azure及OneDrive等核心服务中断。微软官方表示，事故起因并非流量激增，而是部分服务器意外离线，导致底层基础设施超负荷运转。目前微软已暂停所有部署并重启受影响服务器，各项服务正处于逐步恢复中。

Source:https://www.bleepingcomputer.com/news/microsoft/massive-microsoft-365-outage-disrupts-outlook-teams-copilot-worldwide/

关键的预授权MongoDB漏洞（CVE-2026-118383）在故障转移时可能导致滞后服务器崩溃

关键词：预认证漏洞    服务器崩溃

2026年11月12日报道。MongoDB 服务器中存在一个高危预认证漏洞（CVE-2026-118383，CVSS 评分 9.5）。攻击者可利用未授权的请求导致主节点崩溃。MongoDB 已发布修复版本，建议用户尽快升级或限制网络访问。

Source:https://cybersecuritynews.com/mongodb-database-crash-vulnerability/

Apache HTTP 服务器修补了关键的 HTTP/2 远程代码执行缺陷

关键词：远程代码执行

2026年11月12日报道。Apache HTTP Server 修复了一项存在于 mod\_http2 模块中的严重 HTTP/2 远程代码执行漏洞（CVE-2026-119618）。该漏洞由并发线程资源共享不当引发，攻击者可借此破坏堆内存并执行任意命令。官方已发布补丁，建议立即更新或暂时禁用 HTTP/2。

Source:https://www.bleepingcomputer.com/news/security/apache-http-server-patches-critical-http-2-remote-code-execution-flaw/

Palo Alto PAN-OS远程代码执行漏洞允许攻击者以root权限执行任意代码

关键词：远程代码执行

2026年11月12日报道。Palo Alto Networks 披露了 Panorama 系统中 PAN-OS 软件的远程代码执行漏洞（CVE-2026-0330，CWE-94）。该漏洞允许已认证管理员以 root 权限执行任意代码。目前官方已发布修复版本，并建议用户限制管理接口的外部网络访问以降低风险。

Source:https://cybersecuritynews.com/palo-alto-networks-pan-os-rce-vulnerability/
