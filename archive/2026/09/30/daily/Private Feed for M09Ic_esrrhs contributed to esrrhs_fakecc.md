## Summary

将原先会直接 `exit(1)` 的 `die_at` 改为**记录错误信息并返回 `FAKECC_ERR`**，编译管线各层检测并向上回传；`fakecc` CLI 仅在顶层检测到错误后退出进程。这样高层 C API（`fakecc_compile_*`）可以在不杀死宿主进程的情况下报告编译失败。

## Changes

* **`die_at`**：打印并保存首条错误（`fakecc_error_message` / `fakecc_error_loc`），返回 `FAKECC_ERR`；已出错后不再重复刷屏。
* **公共入口** `lex` / `parse` / `sema_check` / `ir_generate` 改为返回 `int`（`FAKECC_OK` / `FAKECC_ERR`）。
* **调用点**：错误路径早期返回；parser 在出错后让 `peek` 合成 EOF，并修正布尔型 helper（如 `parse_attribute`）在出错时返回 `0`，避免 `while (fn())` 死循环。
* **CLI / library**：`main.c` 与 `compiler.c` 检查返回码并 exit / 向上返回。
* **测试**：`test_die_at` 等改为基于错误码（fork 仅作隔离）；同步更新 `v0/` 翻译产物。
