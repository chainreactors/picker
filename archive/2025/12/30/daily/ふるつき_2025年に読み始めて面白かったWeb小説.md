# [2025年に読み始めて面白かったWeb小説](https://furutsuki.hatenablog.com/entry/2025/12/30/155702)

kotatsugameリスペクトです。もはや何をリスペクトしていたのか忘れているんですが、多分kotatsugameさんが週記や[twitter](https://d.hatena.ne.jp/keyword/twitter)で面白い作品を次々とシェアされている様子に感銘を受けて、一年に一度くらいやるか、と思って書き始めたのが最初なのではないか。

というわけで過去記事もあります。

* [2024年に読み始めて面白かったWeb小説 - ふるつき](https://furutsuki.hatenablog.com/entry/2024/12/28/190330)
* [2023年に読み始めて面白かったWeb小説 - ふるつき](https://furutsuki.hatenablog.com/entry/2023/12/29/104820)
* [2022年に読み始めて面白かったWeb小説 - ふるつき](https://furutsuki.hatenablog.com/entry/2022/12/30/105433)

2025年はあまりWeb小説読んでない。代わりにBaldur's Gate 3とELDENRING NIGHTREIGNをよくやっていました。
あと以前から読んでるやつで引き続きめっちゃ面白いやつとか展開がいい感じのやつとかも紹介したいけどレギュレーション違反になるので以前のエントリも読んでください。

* [「パン工場の手伝いをしている 錠前サオリだ」【完結】 - ハーメルン](https://syosetu.org/novel/343951/)
* [芸術的で文化的な異世界生活を目指して - ハーメルン](https://syosetu.org/novel/374270/)
  + とても好き
* [このまま僕らは大人になれないまま - ハーメルン](https://syosetu.org/novel/367863/)
* [魔術師クノンは見えている](https://ncode.syosetu.com/n1314hd/)
  + 漫画の1巻を読んで面白かったので全部読んだ。漫画も全部買った。好きな世界と好きな登場人物たちです
* [九つの塔。救世の勇者。おまけに悪役面おじさん。 - ハーメルン](https://syosetu.org/novel/362617/)
* [異世界転生周回プレイもの - ハーメルン](https://syosetu.org/novel/375522/)
  + これもかなり好き
* [ダブルスチール【完結】 - ハーメルン](https://syosetu.org/novel/352509/)
  + よくできてた。満足感のある作品
* [魔法使い♯ちゃんの世界最適化計画 - ハーメルン](https://syosetu.org/novel/375033/)
  + めっちゃ面白い。更新を楽しみにしています
* [塵埃の魔法少女【完結】 - ハーメルン](https://syosetu.org/novel/328562/)
* [墜星は暗路を行く - ハーメルン](https://syosetu.org/novel/383772/)
* [俺の切り札は光らない - ハーメルン](https://syosetu.org/novel/380950/)
* [わたしはあなたの耳鳴り（田村らさ） - カクヨム](https://kakuyomu.jp/works/822139836826258431)
  + **2025年で一番面白かった**。もっと読まれるべきだと思うのでみんな読みに行ってください
* [男娼マエストロと栄光の少女たち - ハーメルン](https://syosetu.org/novel/346520/)
  + 2024年から読んでるはずだが去年の一覧になかったので。最近また更新があってうれしい
* [【完結】うお……貞操逆転世界魔法少女物はちょっと盛りすぎ…… - ハーメルン](https://syosetu.org/novel/390359/)
* [異世界転生ダンジョンマスター　温泉ダンジョンを作る](https://ncode.syosetu.com/n0250js/)
* [晴嵐 - ハーメルン](https://syosetu.org/novel/340209/)
  + この人のバンドリの二次創作作品をずっと読んでる。はやく原作を履修するべきだが、二次創作だけでかなり満足できている
