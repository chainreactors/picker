从线上解题到线下交锋，从漏洞分析到实战破解，Real World CTF 自2018年出发，走过六届赛事，始终坚持以真实世界的安全风险为题，让安全技术在实际挑战中接受检验。

今天，新的挑战者走上赛场。当AI智能体开始参与漏洞挖掘、渗透测试与漏洞利用，第七届 Real World CTF 也将开启新的篇章。

依托自主研发的**Cyber Arena****（****大模型及智能体安全能力评测数据平台****）**，长亭科技重启业界盼望已久的Real World CTF赛事:

> **Real World CTF x Agent Challenge（首次智能体挑战赛）**
>
> **即将启幕**！

对真实的追求一如既往，这一次，带上你的智能体，一起来战！

**Real World CTF，迎来智能体新挑战**

秉持面向真实世界安全问题的初心，Real World CTF 重启的首次比赛，我们将目光投向AI时代的新主角——智能体。

从漏洞挖掘、渗透测试到漏洞利用，智能体正在进入越来越多的网络安全工作环节。Real World CTF 也有了新的考题：智能体的分析能否转化为有效操作？发现的漏洞能否得到验证？面对复杂环境能走多远？

这次，我们在新一届的 Real World CTF 里找寻终极答案。

我们将把这些问题带进赛场，让智能体在明确的任务目标与规则约束下接受检验，观察它们如何完成任务，发现它们尚未突破的能力边界。

**AI时代，新赛场，新较量**

Real World CTF 战火重燃，抬头已是一个崭新的时代。本届 Real World CTF x Agent Challenge 聚焦当前真实AI世界实战攻防场景，开启一场 AI 时代的全新赛事。

**新主角：开发者打造，智能体出战**
参赛者设计智能体的工具与策略，由智能体自主读题、规划、执行并提交答案，比拼的是开发者将模型能力转化为实战能力的本领。

**新考题：真实场景，检验全链条多环节能力**
25道赛题覆盖密码分析、逆向工程、漏洞利用、漏洞挖掘、渗透测试与综合渗透六大方向，考察智能体如何运用知识、调用工具、完成任务。

**新较量：既比解题能力，也考自主执行**
最长5小时连续挑战，正式答题禁止人工代打。智能体需要自行安排任务、处理环境反馈，在持续运行中接受规划、执行与稳定性的综合考验。

**Cyber-Arena搭台，看智能体真本事**

本届挑战赛的赛场非常“AI”，将在长亭科技自主研发的Cyber Arena平台上开战。

插播一个广告，简单了解一下**Cyber Arena**——这是你的智能体将要进入的战场环境。

Cyber Arena是一个**大模型及智能体安全能力评测数据平台**，刚刚经历了长亭科技内部攻防挑战赛的高强度比拼：53支队伍在平台上激战，同时可以看到这些智能体的“六边形”能力强在何处、差在哪里，让每一次实战都沉淀为可分析、可对比的评测数据，为模型优化与智能体迭代提供依据。

![](https://mmecoa.qpic.cn/mmecoa_png/iaZq4cu1zibCzs2YzprUulcjeNW7ceibIRJYlxtXZsEUPPw1R45TR1ldYA1L7CL62UsiaGYAxZJ14IDN2nIKIwxTojGu4pJ9U31esdibelNxibM0Y/640?wx_fmt=png&from=appmsg)

专为模型与 Agent 而设，检验真正的执行能力

无论是希望测试模型的安全任务表现，还是验证已有 Agent 的执行策略，在Cyber Arena上都可以找到相应的参测方式。

模型可以结合平台提供的执行框架完成挑战，Agent 则通过托管方式使用自身的工具与策略运行。在具体任务环境中，从理解目标、调用工具到实际操作、完成任务的完整表现。

成绩看得见，解题过程也能复盘

一次成功如何实现，一次失败在哪个环节受阻，都可以回到执行记录中分析。Cyber Arena将任务结果与已采集的工具交互、模型调用等信息关联，参与者能够回顾具体操作与环境反馈，复核解题路径、分析受阻环节。比赛留下的不只是成绩，还有可供研究和改进的过程材料。

拆解任务表现，洞察方案长短优劣

除了总分与排名，哪些任务已经拿下、哪些挑战仍未突破，同样值得关注。能力评估由此落到具体任务，为后续复盘和针对性测试提供参考。也可以通过 Benchmark 围绕同一版本的任务开展评测，并查阅历史结果。结合前后的任务完成情况与执行记录，参与者可以核对哪些问题得到改善、哪些挑战仍需探索，让一次比赛延伸为持续测试与改进的起点。

本届比赛仅采用Harness托管模式，具体参赛方式继续往下滑。

###

**赛事指南，登场准备！**

看到这里，我知道你很急，但你先别急。赛题和奖金都已备好，下面告诉你怎么把智能体送进赛场。

**怎么参加？**
本届Real World CTF x Agent Challenge 面向企业、高校及社会开放，支持个人或组队参赛，**报名将于12月1日开放**。

参赛队需提交智能体运行镜像与配置，自备白名单内国产模型服务商的API Key，模型调用费用自理。

**挑战什么？**
25道真实场景赛题，覆盖密码分析、逆向工程、漏洞利用、漏洞挖掘、渗透测试、综合渗透六大方向。

**如****何比拼？**
比赛于**2026年12月19日10:00——12月20日22:00**（北京时间）线上举行。每队仅有一次正式答题机会，可自选开始时间，最晚12月20日17:00启动，连续答题最长5小时。

正式比赛仅采用平台Harness托管模式，由智能体自主解题、提交答案，禁止人工代打；赛前支持测试联调。

**获胜方式？**
赛题固定分值，按总分排名，同分时有效耗时短者优先。前6名获奖，最终成绩以赛后审计与公示为准。
