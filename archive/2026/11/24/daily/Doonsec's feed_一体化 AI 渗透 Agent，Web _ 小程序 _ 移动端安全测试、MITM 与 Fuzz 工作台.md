全链哨兵（Full Chain Sentinel System）是一款 AI 渗透 Agent，基于 pi 二次开发，内置 Web 控制台。支持 Web、小程序、安卓及 iOS 移动端安全测试，集成 MITM 抓包、WebFuzz、Nuclei POC 订阅、资产测绘、开源代码情报监控。项目隔离容器环境，配备审批审计、执行监督、多角色模型调度、MCP 插件扩展，自动留存证据并导出 Markdown 报告，适配安全服务自动化交付，仅可用于已授权的安全测试场景。

### 报告中心

### 跟随全局项目，统一归档普通会话、自主目标、工程任务和工程总报告。Agent 完成实质测试任务时主动提交 Markdown 报告与证据图片，普通问答不生成报告；工程总报告归档成功后再结束工程。

支持搜索、来源筛选、Markdown 渲染与源文查看、图片放大、下载和删除。点击「编辑」后，左侧修改标题与 Markdown，右侧实时预览，支持保存、取消、草稿恢复和修改冲突提示。已有图片独立保存，容器停止、重建或删除后仍可查看；含图片的报告下载为包含正文与图片的 ZIP，无图片时下载 Markdown。

📦安装与使用指南

先安装并启动 Docker，再从 Releases 选择与你的系统和架构匹配的压缩包。

Linux x64 示例：

```
tar -xzf sentinel-web-linux-x64.tar.gzcd sentinel-webchmod +x sentinel-web./sentinel-web
```

Windows 解压 sentinel-web-windows-x64.zip 后，在 PowerShell 运行 .\sentinel-web.exe。请保留程序旁的 replayd/ 目录。

完成初始化

打开启动日志中的完整入口地址，设置账号密码并确认授权声明。在「设置 → 环境」准备工具镜像，在「设置 → 模型」添加端点并分配主模型，然后创建项目。

新项目包含工作容器与常驻网关，切换代理无需重建工作容器。

开始测试

在对话中描述授权范围和目标，默认使用审批模式。移动端测试需先接入设备，再启用当前会话的对应工具。
