## Firefox 147 将支持 XDG Base Directory Specification 目录标准

[![Linux](https://icon.solidot.org/images/topics/topiclinux.png?123)](/search?tid=7 "Linux")
[![Firefox](https://icon.solidot.org/images/topics/topicfirefox.png?123)](/search?tid=39 "Firefox")

[Edwards](/~Edwards) (42866)发表于 2025年11月23日 21时13分 星期日 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=82873&appkey=1370085986&title=Firefox%20147%20%E5%B0%86%E6%94%AF%E6%8C%81%20XDG%20Base%20Directory%20Specification%20%E7%9B%AE%E5%BD%95%E6%A0%87%E5%87%86 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自林中秘族**

在 Linux 操作系统上 Firefox 浏览器将所有文件都储存在 ~/.mozilla 目录下。2004 年 9 月递交的一份 bug 报告呼吁 Firefox 遵守 Freedesktop.org 的 XDG Base Directory Specification 目录标准：将配置文件、缓存数据、用户数据等储存在不同目录，如 ~/.config 和 ~/.local/share。21 年后，Firefox 终于解决了该 bug，从 Firefox 147 起它将支持 XDG Base Directory Specification 目录标准。
https://bugzilla.mozilla.org/show\_bug.cgi?id=259356
https://www.phoronix.com/news/Firefox-147-XDG-Base-Directory
