Attackers are currently exploiting a critical vulnerability tracked as CVE-2026-76466 in Cisco Expressway that allows them to remotely execute commands as root without any authentication, according to warnings from the US government and security researchers.

[CVE-2026-76466](https://nvd.nist.gov/vuln/detail/cve-2026-76466), which carries a 9.8 CVSS rating, affects Cisco Expressway-C and Cisco Expressway-E gateways configured in clusters, both virtual and physical appliances running vulnerable software. These provide firewall traversal, VPN-less remote access, and call routing for remote users connecting to voice, video, and messaging collaboration services.

The bug involves hard-coded authentication credentials and insufficient certificate validation in clustered Expressway deployments.

REG AD

“An attacker with possession of the cookies could exploit this vulnerability by connecting to the database service and invoking specific remote procedure call (RPC) commands,” Cisco [said](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-vcs-static-cred-hr7EWZ8t) in October, when it disclosed the bug and issued a software update that fixed the flaw. “A successful exploit could allow the attacker to execute arbitrary commands as root on the underlying operating system of an affected device.”

REG AD

At the time, the networking vendor said it wasn’t aware of any abuse of the vulnerability.

That all changed late last week, however, when Russian security firm F6 said it was investigating “the first observed case” of miscreants exploiting CVE-2026-76466, shortly after a [public proof-of-concept exploit](https://github.com/dinosn/cve-2026-76466) became available.

“The attackers initially compromised two Cisco Expressway internet-facing devices,” F6’s Cyber Defense Center [said](https://f6.security/media-center/press-releases/cisco-vulnerability-exploitation/) on Thursday. “Through one of them, they gained access to two additional cluster nodes located on the organization’s internal network. After obtaining root access, the attackers began preparing tooling for further lateral movement across the infrastructure.”

Specifically, the criminals prepared custom Python code to scan the victim’s network and identify files and folders shared over the Server Message Block (SMB) protocol. The scripts were also designed to interact with SQL Server and WinRM, and search GitLab repositories for credentials and other sensitive information.

The Python scripts used in the attack indicated that the operator used an AI assistant, according to F6.
