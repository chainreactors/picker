## GNU C Library 将从 Sourceware 迁移到 Linux Foundation 托管的 CTI

[![GNU](https://icon.solidot.org/images/topics/topicgnu.png?123)](/search?tid=44 "GNU")

[Edwards](/~Edwards) (42866)发表于 2026年01月29日 16时01分 星期四 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83425&appkey=1370085986&title=GNU%20C%20Library%20%E5%B0%86%E4%BB%8E%20Sourceware%20%E8%BF%81%E7%A7%BB%E5%88%B0%20Linux%20Foundation%20%E6%89%98%E7%AE%A1%E7%9A%84%20CTI "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自布兰尼肯夫人**

GNU C Library“glibc”维护者 Carlos O'Donell 宣布项目核心服务将从 Sourceware 迁移到 Linux Foundation 托管的 Core Toolchain Infrastructure“CTI”。此举旨在满足 glibc 和 GNU Toolchain 当前及未来的需求，拥有安全、稳固（robust）且可持续的基础设施，同时兼顾开发者和社区协作创新的需求，确保基础设施在长期内有可靠资金支持。
https://sourceware.org/pipermail/libc-alpha/2026-January/174457.html
