***前言***

**又到了一年一度的国家网络安全宣传周。**

2026 国家网络安全宣传周（9月14日—20日）主题为"网络安全为人民、网络安全靠人民——智能时代 网安护航"。今年官方专门设立个人信息保护日，并举办个人信息保护、汽车数据安全、政务数据安全等多场数据专题分论坛，由中央网信办网络数据管理局等指导；同时重点解读《数据安全法》《个人信息保护法》《网络数据安全管理条例》等法规。

在"数据要素化"加速奔跑的今天，一个扎心的问题摆在每个单位面前：我们天天喊数据安全，但自己的数据安全水平，到底处于什么段位？

是"裸奔"，是"及格"，还是"软考满分"？

大多数人，其实心里没底。

***01***

**数据，正在成为最贵的资产，也最脆弱的命门**

过去一年，数据泄露、违规收集、权限失控、内部人员泄密的案例层出不穷。

对企业来说，数据一旦"出事"，往往意味着：监管通报、巨额罚款、客户流失、品牌崩塌——一次事故，可能清零多年积累。

但现实是：

* 信息化分管领导，未必清楚全单位的数据安全责任有没有"压实"；
* 信息化负责人，未必说得清制度、流程、合规到底差在哪一环；
* 运维技术同学，未必意识到一次"随手权限"就是一处致命缺口。

**问题不是不重视，而是"不知道自己不知道"。**

***02***

**数据安全能力调查活动**

所以我们在网安周期间发起——数据安全能力调查活动

一份精心设计的数据安全能力评估问卷，让你发现在数据安全工作上存在什么问题

|  |  |
| --- | --- |
| **评估维度** | **你能看清什么** |
| 职责落实 | 数据安全责任是否到人、到岗 |
| 制度流程 | 分类分级、权限管理、审批是否闭环 |
| 安全防护 | 资产梳理、访问控制、日常操作隐患 |
| 合规管理 | 法规标准对照、整改盲区 |
| 应急能力 | 出事能不能"兜得住、查得清" |

3分钟作答，即时出分。

***03***

**适合什么人来测试**

👔 **信息化分管领导**：看清全单位数据安全责任地图与决策风险

🧭**信息化负责人**：梳理制度、流程、合规与统筹管理的短板

🔧 **运维技术人员**：排查数据资产、访问控制、日常操作隐患

**测完你能得到什么？**

✅ 一份数据安全能力评分——你的岗位段位，一目了然

✅ 一份个性化整改建议——不只告诉你"不及格"，更告诉你"怎么补"

✅ 一份数据安全资料包——法规 / 标准 / 案例 / 知识点 / 工具 / 模板 / 清单，一次打包

✅ 一次和专家对话的机会——报告背后，我们帮你解读改进路径
