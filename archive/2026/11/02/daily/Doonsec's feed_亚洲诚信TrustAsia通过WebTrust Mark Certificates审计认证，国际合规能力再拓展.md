近日，亚洲诚信TrustAsia 通过 **WebTrust Mark Certificates 审计认证**，在原有六项 WebTrust 审计认证的基础上，新增可信标志证书领域的专项认证，进一步拓展了公司在公开可信数字证书领域的合规覆盖范围，为面向企业邮件通信场景的品牌身份验证服务提供合规支撑。

![](https://mmecoa.qpic.cn/sz_mmecoa_png/PaAJmAASPibjuxhT8icxTVOAlRj6ZCKKJoOAAk9A1QGalL8xarpc0AQmz2K4TcfMxtSBAUQDYiahgYL581IGtuPKUQu06dmjvmwvZbrLRjGRyY/640?wx_fmt=png&from=appmsg)

WebTrust 是数字证书行业广泛采用的国际审计体系，由独立审计机构依据相应原则与准则，对电子认证机构的业务实践、运营管理和安全控制进行评估。各专项审计分别对接相应证书类型的行业规范，相关审计报告也是浏览器根证书计划评估 CA 合规性的重要依据之一。

此次新增 Mark Certificate 认证，是亚洲诚信TrustAsia 持续**推进国际合规建设、拓展数字证书应用场景、提升全球数字信任服务能力**的重要成果，进一步**彰显了公司在多类型数字证书领域的国际合规能力与专业服务实力**。

**新增可信标志证书审计认证**

**支持邮件中的品牌身份识别**

在企业与客户的邮件往来中，识别邮件来源、确认发件身份，是建立可信沟通的重要环节。Mark Certificates（标志证书）通过验证组织身份、域名控制权及品牌标识使用权等信息，将企业品牌标识与经过核验的组织及域名信息关联起来，为邮件中的品牌标识展示提供依据。

![](https://mmecoa.qpic.cn/sz_mmecoa_png/PaAJmAASPibhEbe8a0X3mUKuUSmbFkxqrkpQsEElqoawfYLk7lDXpDX9cKCUN21YElCYudUJCf2MeIZIfbib7bwMBqjTR3Te0jY9oNIXtOkjQ/640?wx_fmt=png&from=appmsg)

在满足 DMARC 等邮件身份验证要求的基础上，企业可结合 BIMI（邮件品牌标识）机制，在支持该机制且接受相关证书的邮箱服务中展示经过验证的品牌标识，帮助收件人更直观地识别发件品牌。具体展示方式遵循邮箱服务商的接受政策和展示规则。

WebTrust Mark Certificates 审计面向可信标志证书的签发与管理，重点关注组织身份核验、域名控制权验证、标识验证及证书生命周期管理等关键环节。通过该项审计认证，表明亚洲诚信TrustAsia **已具备依据相关国际标准开展品牌标识证书签发与管理的合规能力，进一步完善了公司在邮件身份认证与品牌可信验证领域的服务能力**。

**七项 WebTrust 审计认证**

**覆盖 CA 运营与多类证书服务**

不同类型的数字证书承担着不同的信任功能，也对应不同的身份核验、签发管理和安全控制要求。此次新增 Mark Certificates 审计认证，与亚洲诚信TrustAsia 此前已通过的六项 WebTrust 审计认证共同构成了覆盖基础运营、安全控制及多类证书应用的合规体系。

![](https://mmecoa.qpic.cn/mmecoa_jpg/PaAJmAASPibhwjoot43Xv1vut41IggaQamibvOmH3oWpyu2gzibHDY3J9XTVicCDck13xQakAYZEeDLJcoQK6UMcRfMhw4sNKPm4IaNOlQicHCok/640?wx_fmt=jpeg&from=appmsg)

**WebTrust for CA**

**夯实电子认证服务的运营基础 ——**

WebTrust for CA 是面向认证机构的基础审计，覆盖业务实践披露、密钥与证书生命周期管理，以及人员、物理环境、系统访问和业务连续性等控制。该项审计关注 CA 如何将公开承诺和管理制度落实到实际运营中，为亚洲诚信TrustAsia 各类证书业务的规范开展提供基础保障。

**WebTrust for TLS Baseline Requirements**

**规范网站证书的签发与管理——**

该项审计围绕公开可信 TLS/SSL 证书的基线要求，关注域名控制权验证、证书信息准确性，以及证书签发、吊销等关键环节。通过对相关业务控制的审查，为亚洲诚信TrustAsia 提供规范的网站证书服务建立合规依据，支持企业网站及在线服务开展身份认证、建立加密连接。

**WebTrust for Extended Validation TLS**

**强化网站运营主体的身份核验——**

Extended Validation（EV，扩展验证）审计针对 EV TLS/SSL 证书，重点关注申请组织的合法存在、实际经营地址、运营情况，以及域名控制权和申请授权等验证要求。严格的组织身份核验流程，为确认网站背后的运营主体提供更充分的依据，也体现了亚洲诚信TrustAsia 在企业身份验证方面的规范化管理能力。

**WebTrust for Code Signing****Baseline Requirements**

**支持软件发布者身份与代码完整性验证——**

该项审计面向代码签名证书，关注软件发布者身份验证、密钥保护、证书签发与吊销等要求。代码签名证书用于支持软件和代码的数字签名，帮助使用者核验发布者身份，并检测代码在签名后是否被篡改，为软件发布与分发提供信任依据。

**WebTrust for Network Security**

**加强证书服务基础设施的安全控制——**

Network Security 审计聚焦 CA 网络与证书系统的安全，涵盖访问控制、系统保护、安全监测和漏洞管理等方面。该项审计从基础设施层面检验证书服务运行环境的安全控制，为亚洲诚信TrustAsia 各类认证业务的安全运行提供支撑。

**WebTrust for S/MIME**

**为邮件签名与加密提供可信证书支持——**

S/MIME 审计面向邮件证书的签发与管理，关注邮箱控制权或使用授权验证，以及相应证书类型所要求的个人或组织身份验证。S/MIME 证书可用于邮件数字签名与加密，支持发件身份核验、邮件完整性验证和内容机密性保护，为企业邮件通信提供安全支持。

从 CA 基础运营、网络与系统安全，到网站身份认证、软件代码签名、邮件安全及品牌标识验证，七项 WebTrust 审计认证体现了亚洲诚信TrustAsia 在不同业务场景下持续推进合规建设的成果，也为客户评估相关证书服务提供了第三方审计依据。

**以国际标准为基础**

**持续深化数字信任服务能力**

从网站身份认证、软件代码签名，到邮件签名与加密、品牌标识验证，企业对数字信任的需求正贯穿更多业务环节。服务这些不同场景，需要电子认证机构准确理解各类证书的适用规范，并将要求落实到身份审核、证书签发、安全运维和异常处置等具体流程中。

**此次新增 Mark Certificates 审计认证，是亚洲诚信TrustAsia 将既有 CA 运营经验与合规管理能力延伸至品牌标识证书领域的重要进展。**公司将以此为基础，持续完善多场景数字证书服务能力，为企业建立可验证的数字身份、保护业务通信和维护品牌形象提供支持。

展望未来，亚洲诚信TrustAsia 将持续跟进国际标准与生态要求，推进合规审计和安全能力建设，完善身份验证、证书生命周期管理及安全运营机制，为企业数字化运营、软件发布与可信通信提供专业、可靠的数字信任产品与服务。
