上个月，我参加了 Offsec 的 Offensive Security Certified Professional (OSCP) 考试，顺利获得了证书。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/zVE7oia7FCW9ztgKlXDqxb3DrLOVQIc4UKhB5y0cJL5JkMmcEmImvNXbZPo6Kpa7fugr0z9wQxHfvX32ZI37rcc9JNsyfvbGzgOe1rrYmicHM/640?wx_fmt=png&from=appmsg)

最近在准备OSEP的考试了，想给大家分享一下我的OSCP备考经历，希望能对正在努力获得OSCP认证的人有所帮助。

━━━━━━━━━━━━━━━━━━━━

我是一名安全工程师。日常工作包括漏洞评估、渗透测试和安全审查。我参加 OSCP 考试的主要原因有以下三点：

* **知识和技能的提升：**
  虽然我在漏洞评估等领域有工作经验，但我学习获得 OSCP 认证的主要动机是进一步拓宽我的技术专长。

* **无限期认证：**
  OSCP证书没有有效期，且无需支付任何维持费用。一旦通过考试，认证终身有效。就是这么简单！现在考可以同时获得OSCP、OSCP+。需要说明的是，OSCP+有效期3年，后期需要的话你可以进行维持。

* **我想证明自己的能力：**
  作为一名渗透测试人员，我相信 OSCP 认证能够证明我的能力，也是我迈向成功之路的第一步。

━━━━━━━━━━━━━━━━━━━━

什么是OSCP？简单说就是：OSCP是由Offsec公司颁发的渗透测试人员认证。OSCP对应的培训课程是PEN-200，学习实用的渗透测试方法、工具和技术，主要侧重于 Kali Linux（一种基于 Debian 的 Linux 操作系统，专为安全测试而设计）。

如果你想报名参加 PEN-200 课程，OffSec鼓励学员根据自身方式选择备考，可以直接官网购买LAB自考、可以选择谷安培考，不得不说LAB以及培训这块，谷安折扣选项更多，非常友好。

我选择了培考模式，不想到处卡壳，工作的原因需要我集中时间高效备考，如果准备不足，我可能会遇到更多的问题从而中断学习。

如果你想先了解OSCP，不妨先免费试听学习再做规划！

━━━━━━━━━━━━━━━━━━━━

从 2023 年开始，OSCP 课程内容发生了变化。

关于缓冲区溢出的章节已被删除。取而代之的是，新增了针对 Active Directory (AD) 环境的攻击内容。这部分内容非常具有挑战性，我个人非常喜欢！

培训从5天精要课程直播（OSCP核心知识点）、打靶演示、作业实操、练习靶机，再到老师分享大量的靶机思路、打靶演示讲解，以及后期自己大量的实操打靶练习，很顺畅的学习节奏，如果你拖沓真的很容易放弃，在这里一定要反复的和自己强调，一定要拿下认证。

最重要的一点，在参加正式考试前，一定要找老师做模拟考试，完成 48 小时的（攻击 + 报告撰写），做到心中有数。

━━━━━━━━━━━━━━━━━━━━

通过**OSCP 课程（PEN-200）我学到的内容：**

• Web 相关入侵方法
• 绕过基本安全软件（杀毒软件）的技术
• Windows 和 Linux 系统中的初始入侵、横向移动、权限提升和持久化
• AD 环境中的横向移动、权限提升和持久化
• Metasploit 的使用方法

━━━━━━━━━━━━━━━━━━━━

简单说一下考试规则：考试时间47小时45分钟（实践考试：23小时45分钟 + 报告撰写：24小时）。

满分100，及格分70。

- 独立目标（不限于 Linux）：60 分（本地权限：10 分 + 高权限：10 分）
- AD 环境设置：40 分（2 个客户端 + 1 个域控制器）
-**不给部分分；必须渗透到域控制器。**

━━━━━━━━━━━━━━━━━━━━

考试的重要事项必须和大家分享一下：

* #### 记下攻击步骤：报告中必须包含获取访问权限的步骤，因此记录越详细越好。如果编辑了漏洞利用代码，请务必记下编辑的部分以及源代码。
* #### 保留比必要数量更多的证据：尽可能多地截取攻击过程的屏幕截图。如果报告中包含的证据存在疑问，可能会被扣分。
* #### 一定要睡觉：哪怕只是短暂地睡一会儿，也要睡一会儿。由于考试时长为23小时45分钟，尽可能的安排睡觉时间，让大脑更清醒。
* 关于考试分值：我不确定自己是否能够解决三个独立目标题。但是，如果能解决AD环境下的三个目标问题，就能得到40分。换句话说，如果你能在AD环境下拿到40分，离及格就不远了。首先，在 AD 环境中选择目标，然后释放独立目标。
* 关于报告：考试结束后，我吃了午饭，然后开始撰写报告。由于经常做漏洞评估和其他相关工作，所以已经很熟悉了，撰写报告并没有花费太多时间。
  我大约花了五个小时完成了报告并上传。至此，OSCP考试圆满结束。

━━━━━━━━━━━━━━━━━━━━

非常高兴的是，我在提交报告后的第二天就收到了通过考试的通知邮件，比官方说的10个工作日快太多了。

获得 OSCP 认证对我来说是一个小小的里程碑。OSEP的学习已经在进行中了，我希望自己在本年度结束前顺利拿到高阶的渗透测试证书，祝我好运！也希望正在备考或有计划备考OSCP的你们，顺利获证！
