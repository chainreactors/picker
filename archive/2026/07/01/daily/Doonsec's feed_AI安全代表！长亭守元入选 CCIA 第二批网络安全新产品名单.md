近日，中国网络安全产业联盟（CCIA）公示了第二批网络安全新技术新产品新服务遴选结果，**长亭科技大模型/智能体安全围栏“守元”成功入选新产品**名单。

![image.png](https://mmbiz.qpic.cn/sz_mmbiz_png/uX9TOlqibIRuL8CMiacD0FfcbaazWyYLylhboPiaicjnnbkwRqe8U3eTKIiatBJkQcVPVicyuJhFD2Wuztdhl6ys5IVGLvRic40E7hxKBJoRl7ErOI/640?from=appmsg)

此次遴选面向全行业征集网络安全领域的创新技术、产品和应用，守元作为大模型与 Agent安全方向的代表产品入选，体现出行业对AI自身安全这一新兴细分赛道的关注与认可。

当前，超七成央企和大型金融机构已启动大模型部署，但具备完善安全防护的比例不足三成。大模型向 Agent 自主决策演进的过程中，安全边界正从“内容合规”延伸到“行为可控”，这一变化对安全产品的实时性、覆盖面和智能化提出了更高要求。

**守元定位于企业大模型应用与 Agent 场景的安全防护**。在 LLM 安全维度，产品覆盖提示词注入、越狱、隐私泄露、违规内容合规等关键风险，以五层架构加三重防护机制实现检测延迟低于 50 毫秒、七大类攻击近乎全量拦截、误报率低于千分之三的性能表现。在 Agent 安全维度，守元提供 Skill 安全准入检测、Trace 全链路行为透视和 Agent 资产治理能力，帮助企业在引入第三方 Agent 组件时看清行为、管控风险。

长亭科技近年来围绕 AI 赋能安全、AI 自身安全和 AI 原生应用三大方向持续投入，守元是其 AI 安全产品矩阵中的核心组成部分。2025 年上市以来，守元已完成多个版本迭代，获得北京市 AI 创新大赛安全防护一等奖认可。

此次守元入选 CCIA 新产品名单，从行业层面印证了 AI 安全正从概念走向标配。守元在 LLM 安全与 Agent 安全双维度的技术积累，正在为企业大模型落地提供可验证的防护基线。
