# Upgrading How You Sign In to Your Sucuri Account

[![](https://blog.sucuri.net/wp-content/uploads/2026/01/avatar_user_116_1769198545-60x60.png)](https://blog.sucuri.net/author/sucuriblog)

[Sucuri](https://blog.sucuri.net/author/sucuriblog)

* August 7, 2026

![Featured Image - Upgrading How You Sign In to Your Sucuri Account](https://blog.sucuri.net/wp-content/uploads/2026/08/Featured-Image-Upgrading-How-You-Sign-In-to-Your-Sucuri-Account-820x385.png)

Starting August 10, 2026, Sucuri will begin moving customer account logins to a new authentication platform designed to provide a stronger, more modern sign-in experience.

The rollout will happen gradually over the following few weeks, so not every account will transition at the same time.

***For most users, there is nothing to do. Your password will remain the same, your current two-factor authentication setup will continue working, and existing bookmarks to the Sucuri dashboard login page will automatically redirect to the new sign-in page.***

Here is what is changing and what you can expect when the upgrade reaches your account.

## What is changing with Sucuri account login?

The main change is the URL you will use to sign in.

All Sucuri users will transition to:

```
sso.sucuri.net
```

This will replace the current login page at:

```
dashboard.sucuri.net/login
```

The change applies to all users and does not require you to opt in, update your account, or modify any settings.

If you already have the existing login URL saved in your browser bookmarks or password manager, you can continue using it. The old address will automatically redirect you to the new authentication page.

## When will the new Sucuri login begin rolling out?

The migration begins **August 10, 2026** and will roll out gradually over the following few weeks.

This phased approach means some users may see the new sign-in experience before others. If your account still uses the existing login page after August 10, that does not mean anything is wrong. Your account will move as the rollout progresses.

The migration is designed to happen without downtime, so you can continue using the Sucuri dashboard normally during the transition.

## Do I need to reset my Sucuri password?

No. **Your existing Sucuri password will continue to work.**

This authentication upgrade does not require a forced password reset.

When your account moves to the new sign-in platform, you can continue signing in with the same credentials you use today.

As always, we recommend using a unique password for your Sucuri account rather than reusing a password from another service. Additionally, we recommend resetting/refreshing your password regularly as a standard security practice.

## Will two-factor authentication change?

No. Your existing two-factor authentication, or 2FA, configuration will continue working as it does today.

You **do not** need to:

* Re-enroll in 2FA

* Change your current authentication method

* Reconfigure your account

* Generate a new setup as part of the migration

This upgrade changes the authentication platform behind the login process, not your existing 2FA configuration.

## What happens to existing SSO and SAML integrations?

Organizations already using SSO or SAML integrations with Sucuri should not need to make any changes.

Existing integrations will continue working as before and are not expected to be interrupted by this migration. This means for teams that centrally manage access to Sucuri through an identity provider, your established authentication workflow will remain in place while the platform is upgraded.

## Why is Sucuri upgrading its authentication platform?

Protecting a website also means protecting access to the systems used to manage it.

Account authentication is an important security control because access to a website security dashboard can include sensitive configuration, monitoring, and administrative functions.

The new platform gives Sucuri a more resilient and modern authentication foundation while keeping the login process familiar for customers.

The upgrade is also designed to improve the account recovery experience. If you are ever unable to access your account, the updated interface is intended to make the recovery process more straightforward.

No. The redirect is designed to make the transition as seamless as possible.

If you currently use **dashboard.sucuri.net/login**, you can continue using that address. It will automatically redirect to **sso.sucuri.net**.
