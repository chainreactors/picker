## What's New in v2.7.6

> **v2.7.6 fixes connection-failure skipping ([#366](https://github.com/x90skysn3k/brutespray/issues/366))**: `-skip-policy` and `-max-conn-fails` now actually stop brute force on unreachable or uncooperative hosts. Previously the skip counter was cleared by any reachable-host response — including credential rejections — so a live RDP server with mixed connection errors could never trip the threshold.

### Fixed: Circuit Breaker Never Tripped (`#366`)

* **Root cause** — `RunBrute` reset the circuit-breaker failure counter on `ConnectionSuccess=true` alone. Protocols return `ConnectionSuccess=true` for credential rejections (RDP `ErrKindAuth`, HTTP 401, FTP 5xx), so interleaved auth failures repeatedly zeroed the counter and `-skip-policy aggressive` / `-max-conn-fails n` never fired
* **Fix** — the counter now resets only when a credential is accepted. A reachable host that rejects credentials neither counts as a connection failure nor clears the counter
* **`-max-conn-fails` now implies enable** — outside spray mode, `-skip-policy auto` silently disabled the breaker, so an explicit `-max-conn-fails` did nothing unless `-spray` or an explicit policy was also set; it now enables skipping on its own
* **Fast skip after trip** — adaptive backoff no longer sleeps up to 30s per queued credential once the breaker has tripped; remaining credentials are skipped instantly
