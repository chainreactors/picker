# New Release (Android Only): Tor Browser 16.0.2

by [ma1](/author/ma1)
| November 10, 2026

![](/new-release-tor-browser-1602/lead.png)

Tor Browser 16.0.2 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/16.0.2/).

This is an Android-only release which fixes [a platform-specific breakage caused by a zlib update](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41919).

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-16.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 16.0.1 is:

* All Platforms
  + [Bug tor-browser-build#41919](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41919): Android 16.0.1's tor picked up the dynamic zlib
