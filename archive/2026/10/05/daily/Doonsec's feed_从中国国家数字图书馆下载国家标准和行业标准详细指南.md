# 从中国国家数字图书馆下载国家标准和行业标准详细指南

## 一、前言

中国国家数字图书馆（National Library of China）是国家图书馆的数字化平台，为注册读者提供了丰富的数字资源服务。通过该平台，用户可以免费访问中国标准在线服务网，下载国家标准和行业标准全文。本文将详细介绍从注册登录到下载标准的完整流程。

---

## 三、账号注册与登录

### 3.1 访问官网

打开浏览器，输入网址 `https://www.nlc.cn/web/index.shtml` 进入中国国家图书馆主页。

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe3P6icziaT27ibNn16s5aYfsfSFlf1azlEWzlyhztZKFKKWicbteZIMrjbQKFObl1ftPTwmSyrN4amnghEk2DNMUauibcp85djD7tk8/640?wx_fmt=png&from=appmsg)

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ZaibroIiatwe2KKY0MHs1MdWic8CMTibuXVW6DKn0h8zzQ9BzDBFlZCwXRrBFxImUZeuvVY6wv6nXQDs6vxqsufAFzZzgNUGicK3fjHsqyicicqtOo/640?wx_fmt=png&from=appmsg)

### 3.2 进入读者云门户登录页面

在主页找到"读者云门户"入口，点击进入登录页面：

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe2WM8TJ0CGSgACaJxKsAbqeLC3IW5szC8e3Gct5gRsibFrm70GwibnDhhia5deggnyuSr4MyKU2U7S1beSb6BHD8Z5X9lc9ljvxdI/640?wx_fmt=png&from=appmsg)

```
https://sso1.nlc.cn/sso/jsp/mylib-login.jsp?appId=90037&paramUrl=http%3A%2F%2Fread.nlc.cn%2Fuser%2Findex
```

### 3.3 选择登录方式

登录页面提供两种登录方式：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ZaibroIiatwe3KSyC4SqSticSL1mFyZ61wUVN5KAJbiaJqT1LibkDnyKwicB9RA3LWcxMGrG4vfSooTZyLbUqvs7dWe1nfwyxlh4ib7dib8E6APlGFI/640?wx_fmt=png&from=appmsg)

#### 方式一：账号登录

1. 1. 选择"账号登录"标签页
2. 2. 输入已注册的手机号或读者卡号
3. 3. 输入密码
4. 4. 点击登录按钮

#### 方式二：短信登录

1. 1. 选择"短信登录"标签页
2. 2. 输入手机号码
3. 3. 点击"获取验证码"
4. 4. 输入手机收到的验证码
5. 5. 点击登录按钮

> **重要提示**：登录页面显示有QQ、微信、微博第三方登录入口，但是通过这些入口登录后账号无权限下载标准文件，请务必选择"账号登录"或"短信登录"方式。

### 3.4 新用户注册

如果没有账号，点击登录页面下方的"立即注册"：

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe3wBNGeQIhCNlllibEy2NUs4eSyAvX0ibKkT9NC8Z6iaYBTea4rt0b4YmtXR25SbJ3icd4oBv80bj9O61icoKW5Qic3MqFbb237xrRc8/640?wx_fmt=png&from=appmsg)

1. 1. 输入手机号码
2. 2. 获取并输入验证码
3. 3. 设置登录密码（注意密码大小写）
4. 4. 设置昵称（可选）
5. 5. 阅读并同意用户协议
6. 6. 点击"提交注册"

> **注意**：登录账号是手机号，不是昵称。

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe1MBgjehlbGIskX6iaT6Cib9cEU21H0YdXgttianK3O4cZm0TesXZcB1zdDgwRc7CyzN6YoicJWVJpRW7pibJlqAFfazdFNY2XdlS4U/640?wx_fmt=png&from=appmsg)

在二次登录页面，再次使用账号登录或短信登录方式进行认证。

### 6.1 检索方式

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe3KOkBZG9LP4bKRPBMBiaMRdKRyjvojteEhic4FVvlzAAq4ibfzBDtyib6ArNrT7rAB1kgV3RwvV12QsYsk4Vu5MXy7XBiash678HXM/640?wx_fmt=png&from=appmsg)

#### 标准号检索

直接输入完整标准号，如：

* • `GB/T 43206-2023`
* • `GB 48001-2026`
* • `JJF 2374-2026`

#### 关键词检索

输入标准名称中的关键词，如：

* • "食品安全"
* • "质量管理"
* • "环境管理体系"

#### 高级检索

可组合多个条件进行精确检索：

* • 标准名称 + 发布日期
* • 标准类型 + 关键词
* • 标准状态 + 分类号

## 七、PDF文件处理

### 7.1 关于水印

从标准全文数据库下载的PDF文件默认带有水印。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ZaibroIiatwe2VBicRZX1dOLsNvhBpRc3S3AcxONWmEUDRxmdgSXrnTmAYbakDeFfAHytS8eoG3pRhGC0Picwbg3TujrnKa1NIMrDP04nMCibP8Y/640?wx_fmt=png&from=appmsg)

### 7.2 去除水印

可使用福昕PDF编辑器（Foxit PDF Editor）去除水印：

1. 1. 打开福昕PDF编辑器
2. 2. 打开带水印的PDF文件
3. 3. 点击"编辑"→"编辑文本"→"全部替换"
4. 替换水印文字为空
5. 4. 保存文件

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ZaibroIiatwe2zvWxibdpKsrVtYyFCMf7xgeicvrApctLKqgRiaS6kWeGVuwYPibhaBcibvyvU3tdkeTbN51Qq5sf1ct2L8cYfBhKoCtrfPBE2QQoo/640?wx_fmt=png&from=appmsg)

注意：文字替换以后可能存在部分页面未成功替换，需要手动检查。

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe1tJXINdq784soEVWSH2oKztWv1TRLab41LmPwq2o4yGdYEiciasTicr5fduTZGXmU2NOc9T3tdKK8XhWkPghX432f7CV7icvibzFEQ/640?wx_fmt=png&from=appmsg)
