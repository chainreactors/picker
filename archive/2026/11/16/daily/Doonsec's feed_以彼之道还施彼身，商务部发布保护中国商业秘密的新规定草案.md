作者：袁立志 陈书琦

2026年10月19日，美国国务院宣布依据《保护美国知识产权法》（PAIPA）对五家中国实体实施所谓的制裁，美方认定其参与或受益于美国科技企业商业秘密被窃取事件。同日，美国财政部外国资产控制办公室（OFAC）将这些实体列入“非SDN菜单式制裁名单”，启动资产冻结、金融交易限制和投资禁令等措施。

次日，中国商务部新闻发言人表示“将敦促美方尽快纠正错误做法，否则将采取必要措施予以回应，坚定维护中国企业正当合法权益”。

10月26日，中国商务部发布《保护中国商业秘密特别规定（征求意见稿）》（下称草案），向社会公开征求意见。

不同于2026年6月1日施行的市场监管总局《商业秘密保护规定》“加强商业秘密保护，维护公平竞争的市场秩序”的立法目的，草案着力于“国家主权、安全、发展利益，权利人的合法权益”，将国家利益置于首位，其定位已明显超出传统商业秘密民事保护的范畴。

从发布时间来看，草案可谓与美国的所谓制裁决定针锋相对。在科技竞争方面，中国越来越多地以彼之道还施彼身。

# **草案基于《对外贸易法》和《反不正当竞争法》制定，明确由商务部统筹有关部门开展涉外商业秘密保护工作。**

#

# **《对外贸易法》作为我国涉外经贸管理规则，明确授权对危害国家主权、安全、发展利益的境外个人、组织采取贸易限制措施，提供开展对外贸易调查的制度依据。**

#

# **《反不正当竞争法》则承担实体定性功能，为“商业秘密”及“侵害”行为提供定义来源，同时其第**40条域外适用条款为草案第2条“在国际经贸及相关活动中”侵害行为的管辖提供了连接点。

#

#

# 以下是草案要点梳理：

#

**1.草案的适用范围（双重门槛触发）**

草案第2条规定适用边界：外国实体在国际经贸及相关活动中侵害中国商业秘密的行为+危害国家主权、安全、发展利益或者构成现实威胁，这两个门槛需同时满足。单纯的商业秘密民事侵权，仍采取《反不正当竞争法》的民事救济路径，只有当“侵权行为”与“现实、紧迫的国家利益”相关联时，才触发草案规定。

第一道门槛需要以明确的商业秘密及侵害行为为基础。《反不正当竞争法》第10条明确了商业秘密的构成要件及侵害商业秘密的四类行为。同时，《商业秘密保护规定》对商业秘密的认定及侵害行为进行细化，补充了通过设置恶意程序、漏洞攻击等技术手段获取商业秘密等新型侵权手段。

第二道门槛则强调上述侵权行为危害国家主权、安全、发展利益，或者构成现实威胁。这是该规定区别于一般商业秘密保护规则的核心要件，这一表述不以实际损害发生为必要，存在现实威胁即可启动，启动门槛显著低于一般预期。

**2.草案的****适用对象（外国实体）**

草案第3条延续《不可靠实体清单规定》中的定义，将适用对象“外国实体”解释为“外国企业、其他组织或者个人”。同条界定“权利人”为商业秘密所有人和经所有人许可的使用人，后者同样享有启动救济的资格。

与美国PAIPA的适用对象相比，该规定的适用对象边界更窄。PAIPA的覆盖范围相当广泛：明知参与或受益于重大商业秘密窃取的外国主体、提供重要资金物资技术支持的主体、相关受控或代理实体及涉案实体的首席执行官和董事；而草案的规制对象限于直接实施侵害行为的外国主体，并未延伸至提供帮助、支持的境内外主体。

该条规定下的“个人”与该规定第5条第3项、第4项的入境限制、工作许可与居留资格措施相衔接，即外籍高管、外派员工自身即可能成为被采取措施的对象。

**3.限制****措施（六项限制）**

草案第5条针对落入适用范围的外国实体，授权商务部决定采取一项或者多项限制措施：

|  |  |  |  |
| --- | --- | --- | --- |
| **措施类型** | **内容** | **影响** | **关联规定** |
| 贸易限制 | 限制或禁止涉华货物、技术进出口及国际服务贸易，禁止向其出口相关物项 | 供应链与中国市场切断 | 《对外贸易法》第40条；  《实施〈中华人民共和国反外国制裁法〉的规定》第9条；  《不可靠实体清单规定》第10条第1项 |
| 投资限制 | 限制或禁止在华新增投资（不触及存量） | 限制集团在华扩张 | 《不可靠实体清单规定》第10条第2项 |
| 人员入境 | 限制或禁止相关人员、交通运输工具入境 | 高管、技术人员无法来华 | 《反外国制裁法》第6条；  《不可靠实体清单规定》第10条第3项 |
| 工作居留 | 限制或取消相关人员在华工作许可、停留或居留资格 | 已在华外籍员工受直接冲击 | 《实施〈中华人民共和国反外国制裁法〉的规定》第9条；  《不可靠实体清单规定》第10条第4项 |
| 罚款 | 根据情节轻重依法处以相应数额罚款 | 裁量标准待明确 | 《不可靠实体清单规定》第10条第5项 |
| 其他措施 | 其他必要措施 | 兜底条款，保留弹性 | 《反外国制裁法》第6条第4项 |

这一措施组合并非新设，而是对既有涉外经贸反制工具的系统性移植。

六项限制措施的目的并非矫正具体的侵权行为，而是通过褫夺贸易、投资、人员往来的准入资格等威慑，切断相关实体与中国市场的联系。这也意味着，措施的实际效力与外国实体的在华依存度正相关，即在华资产、人员、业务布局越深，受措施影响的可能性就越大。

**4.调查触发机制（依职权和权利人举报）**

第6条确立了启动调查的两种方式：一是商务部依职权主动启动，二是依权利人举报。鉴于该规定第3条已将“权利人”扩展至被许可使用人，被许可使用人不再需要依附于所有人的意愿或另行提起民事诉讼。不论以何种方式启动调查，被调查方均负有配合义务，但同时也享有陈述、申辩的权利。

**5.救济方式（变更、取消与交易豁免）**

草案第7条与第9条共同构成了该规定下的救济框架：前者是措施的变更与取消，后者是交易的豁免，但两者的适用主体与功能定位有所不同。第7条针对的是被采取措施的外国实体，可主动通过整改换取措施的变更或取消；第9条则面向具体交易。

第7条将“主动改正、停止侵害并消除危险、赔偿损失”设定为申请变更或取消措施的前提条件，改正与停止侵害是行为层面的要求，消除危险指向后果的阻断，赔偿损失则是对已发生损害的填补。这与第2条“现实威胁”即可启动的预防性逻辑形成对应，启动时不以实际损害为必要，退出时则要求损害已被实际处理。商务部可根据申请或者实际情况组织评估，决定维持、暂停、变更或者取消。草案未规定行政复议、行政诉讼等常规救济路径，外国实体对调查决定、措施决定存在异议的，目前只能按照第7条的要求递交申请。

第9条处理的是另一个层面的问题：第5条措施生效后，中国企业、组织或个人并非被绝对禁止与受措施约束的外国实体发生任何交易。条文设置了“特殊情况确需交易”的豁免，条件是向商务部提出申请并获得同意。这里需要注意的是，豁免的申请方是中国交易相对方，而非被采取措施的外国实体本身；豁免是由商务部逐案审批的，没有概括性许可。
