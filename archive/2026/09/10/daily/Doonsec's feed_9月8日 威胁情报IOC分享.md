## 01攻击者视角（情报通报，用于防守检测）

**1.1 定向攻击 IP（10 个）**
本期监测发现 10 个 IP 对 13 家重点单位存在攻击行为，攻击方式包括 SQL 注入、命令注入、组件漏洞攻击等。归属地以国内为主（上海 2 个、台北、新竹、北京 2 个、长沙 2 个、重庆、郑州），含德国、美国弗吉尼亚州阿什本共 2 个境外。完整列表见 05 完整附表 · 附件一。

**1.2 恶意样本（4 个）**
本期捕获 4 个恶意样本。值得警惕的是第 4 个 AweSun\_16.5.0.7.exe——直接用「向日葵」远控安装包的名字当马甲，普通用户一看是熟知的远程工具就放松警惕；另外 3 个文件名包括 \_所有人\_2026 第三季度违纪人员内部调查信息…exe（冒充内部通报文档）、20916879.exe、26756400.exe。完整 MD5 与文件名见 05 完整附表 · 附件二。

**1.3 银狐组织 IOC（14 条）**
银狐组织近期针对金融、教育、能源行业实施钓鱼攻击，窃取用户敏感信息。本期 IOC 含 7 个全端口恶意域名（889uuyp.com、okpp666888.com、hjgj3a.com、geco249.club、www.kazimmq1.com、www.antigonyrecords.com、mac-shijiebei.com）与 7 个恶意 IP 端口（1.14.160.200:8838、108.187.37.13:445、115.190.205.255:8888、134.122.187.74:6666、137.220.136.182:445、16.162.193.56:8443、18.162.176.172:8880）。本期域名套路升级（www.antigonyrecords.com 伪装音乐厂牌、mac-shijiebei.com 蹭世界杯热点），需逐个域名与端口拉黑。完整列表见 05 完整附表 · 附件三。

**1.4 高频漏洞和高危攻击 IP（30 个）**
安全监测团队本期收录 14 个高危漏洞，关联 30 个高危攻击 IP。与 9.7 不同，本期配比回归多元——禅道 env.bak 仅 9 例（30%），SP Page Builder 任意文件上传（CVE-2026-48908）6 例、金和 C6 SQL 注入 5 例、蓝凌 OA 远程代码执行 4 例成为主力。完整列表见 05 完整附表 · 附件四。

## 03老宋说

**技术本质：**9.7 那张满屏禅道 env.bak 的表不是常态，是个异常峰值，9.8 立刻回落到 9 例（30%），说明那波冲到 100% 更像是攻击者集中扫了一轮配置备份文件，扫完换靶子了。但别因此松劲——禅道 env.bak 仍是单一最大类（9 例），公网上的 .bak、env.bak 配置备份一直没撤干净，只是这周没被集中扫。

**行业观察：**这期真正该盯的新靶子是 SP Page Builder 任意文件上传（CVE-2026-48908），6 例冲到榜首，外加 Balbooa Forms 上传漏洞（CVE-2026-56291）、Agent Zero 任意文件读取，Joomla 系组件和 AI Agent 框架成了新重灾区。攻击者换靶子比咱们打补丁快，漏洞窗口一开就被批量利用，金和 C6、蓝凌 OA 这些老面孔反而还在榜上，说明老漏洞的补丁也没全打上。

**对读者的建议：**今天先做三件事：把文末 14 条银狐 IOC（7 个域名 + 7 个 IP 端口）拉进 WAF / 威胁情报拦截，逐个域名与端口拉黑，别指望封一个根域；核一遍 30 个攻击 IP 涉及的资产，重点看 SP Page Builder / Balbooa Forms 这两个 Joomla 组件和禅道有没有公网暴露、补丁到没到位；最后给全员发个提醒：带「向日葵」「内部通报」字样的 exe 一律先沙箱，AweSun\_16.5.0.7.exe 这种冒名远控包，看到就当木马处理。

以下均为防守动作，按优先级排序，今天即可执行。

|  |  |
| --- | --- |

| R4 | **核查并修补漏洞涉及资产**对照本期 30 个攻击 IP 关联的 14 个漏洞核查资产：重点处置 SP Page Builder 任意文件上传（CVE-2026-48908，6 例）、Balbooa Forms 上传漏洞（CVE-2026-56291）、Agent Zero 任意文件读取；同时关注金和 C6、蓝凌 OA、泛微 e-cology、亿赛通 DLP、美特 CRM、SonicWall GMS、禅道 env.bak 等是否已修复或防护。 |
| R5 | **钓鱼邮件与冒名远控专项**针对银狐组织样本与 AweSun 冒名包，向全员推送预警；邮件网关开启附件沙箱，对可疑 exe / zip 先核验后打开；明确告知：带「向日葵」「内部通报」字样的 exe 一律按木马处理，不双击、先上报。 |
| R6 | **资产暴露面复盘**继续盘点禅道等系统的公网地址，移除 .bak / env.bak / \_bak 等配置备份文件，禁止敏感配置直接暴露公网；本期禅道 env.bak 9 例（30%）虽较 9.7 的 25 例（100%）回落，但仍是单一最大类，清理没常态化就会反复，别等攻击者把你的配置文件当公开资源翻。 |
