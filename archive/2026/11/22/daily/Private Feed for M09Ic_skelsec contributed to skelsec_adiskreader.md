## What is in here

New formats

* VHDX log replay; VHD / VHDX differencing chains, fixed VHD reads
* VMDK rewrite: text descriptors, multiple extents, snapshot chains, ESXi sparse formats
* WIM (XPRESS, LZX, split files) and ESD (LZMS, solid resources)
* ISO9660 (Joliet, Rock Ridge) and UDF
* QCOW2 and VDI, disk types are detected by signature
* Veeam VBK / VIB / VBM backups (LZ4, RLE, zstd blocks, incremental chains); encrypted backups are detected and their password verifier can be exported, the data itself is not decrypted

Fixes

* NTFS: sparse runs, files with several `$DATA` extents, reads limited to the file size, resident index parsing
* FAT: lower case 8.3 names, case insensitive lookup
* VHDX / SMB read bugs; `open_sibling` on datasources, SSH host key options

Other

* optional native (Rust) module with the decompressors and CRC32C, the pure Python ones are used without it
* `zstandard` is now a requirement

## Tests

* the tests run without mounting anything
* the large test files are not in git: the tests download them from the releases of [adiskreader-testfiles](https://github.com/skelsec/adiskreader-testfiles) and check their SHA-256 (`tests/config.py`); `ADISKREADER_TEST_OFFLINE=1` skips those tests instead
* new workflow `.github/workflows/tests.yaml` runs the tests ...
