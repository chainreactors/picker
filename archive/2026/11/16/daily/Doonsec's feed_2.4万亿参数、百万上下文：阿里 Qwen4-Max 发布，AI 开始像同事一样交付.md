Qwen4-Max
阿里把 AI 变成「新同事」

2026 年 11 月 16 日，阿里 Qwen 团队发布 Qwen4-Max：2.4 万亿参数、百万 token 上下文、原生视觉，主打长程任务与真实交付。API 同步降价，单任务平均费用降 58%。

· 模型发布　· 来源：Qwen 官方博客　· 2026-11-16

官方给它的定位不是“更强的聊天模型”，而是“与你并肩工作、创作和探索的全天候 AI 新同事”。这个说法听起来像宣传语，但看完发布内容会发现，它指向一个很具体的变化：模型不再只负责回答问题，而是被要求把一个复杂目标从头跟到尾，最后交出能用的东西。

01参数更大，推理更省

Qwen4-Max 基于 Qwen4 系列全新架构，主干参数 **2.4 万亿**，每个 token 激活 71B 参数，另有 328B 的 N-gram Embedding 参数；具备原生视觉能力，支持**百万 token 上下文窗口**。这意味着它可以一次性读入极长的文档、成批的图纸和多份病历影像。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/PUTQGRQ4GO8CYJmLKB3FeETqaibWotQxaJqmR9IoIkvvficibzA2EibbwN7hziau3TUSicKTGdEpO7vmelFcmqN4dJE5jZnKib5ZZe1Ux73l3dSFiao/640?wx_fmt=png&from=appmsg)

图1 | 关键评测与成本——Work360 从 47.74 升到 52.69，单任务费用从 26.58 元降到 11.16 元。（数据：Qwen 官方博客；信息图为本文重绘）

官方给出的对比基准是上一代 Qwen3.8-Max。参数更大，但推理更省：在 Work360 上，Xhigh、High 两档推理强度的 token 消耗分别减少约 24% 和 35%；在 Terminal-Bench 4.0 上分别减少约 48% 和 49%。

1**GDN + QSA**——每四层中，三层用 Gated DeltaNet 将历史信息压缩为固定大小的状态，另一层 QSA 通过轻量级 Indexer，以 block 为粒度选择相关上下文，降低长序列的 Attention 计算与索引开销。

2**Gated Residual**——将 Residual Stream 扩展为四条并行分支，通过动态读写门控增强跨层信息传递，提升训练稳定性。

3**N-gram Embedding**——根据局部上下文查表，在第二层提供局部 token 模式的表示，以较低的额外计算扩展模型容量。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/PUTQGRQ4GO9NdHhbhM4na2yG85xMZwPr0X4aunHqoI8rXic9EmyffiaEFFxkckic7BhiaJbr571ZnrAZ6yaxibCKYDO3xiaV0IAAwRURicTeOXnR3E/640?wx_fmt=jpeg&from=appmsg)

图2 | Qwen4-Max 模型结构——GDN+QSA、四条 Gated Residual 分支与 N-gram Embedding。（图源：Qwen 官方博客）

官方称，2.4T 规模下预训练全程未出现 loss spike；Qwen4-Max-Base 在知识、代码、问答、STEM 四类内部评测中的 BPB 均为参评模型最低，相比上一代下降约 5%–13%，同时每个 token 的激活参数减少约 25%。

翻成大白话：同样是干活，它的“脑容量”更大，但每次动用的“脑力”更少。

02从“会聊”到“能交付”

发布内容里，最有信息量的不是跑分，而是一批具体场景。

**三维与游戏。** Qwen4-Max 能调用 Blender，把建模、场景搭建、材质、灯光和渲染串起来；也能在 Unity、Unreal Engine、Godot 里独立完成场景、玩法逻辑、资产整合、HUD 和特效，并实际运行游戏，根据画面与交互反馈调整镜头、动作与打击感。

![](https://mmbiz.qpic.cn/mmbiz_jpg/PUTQGRQ4GOicWK1PCApmjnXDvfOoY0TTLicjJLZX1x2EiaXvdPHu9XOCpHpicUZmaMCDGtpVOYCZq4tq4ibhdRMic2zgoc8prAe6gDicS1kzkpVw68/640?wx_fmt=jpeg&from=appmsg)

图3 | 游戏开发演示——Qwen4-Max 在 Unreal Engine 中搭建的猫咪法师冒险场景。（图源：Qwen 官方博客）

**工业制造。** 在三丰智能装备、统联精密的真实生产场景中，它根据二维布局图和工艺参数构建三维产线，做节拍仿真和 PLC 虚拟调试；也能完成车门总成、摩擦轮等零件的建模、工艺规划、刀路生成与仿真核验。官方案例中，单个工件加工编程的人工投入从约 475 分钟降到 24 分钟，减少约 95%。

**金融投研。** 它能调用 90 个 MCP 工具，获取 A 股、港美股、债券、基金及衍生品数据，结合搜索交叉核验，最后交付 Excel 底稿和可编辑 PPT。每个数字能点回原始出处，图表与底稿对齐。

**法律尽调。** 面对 198 份格式混乱、命名不一的底稿，它按实质内容重命名并归入 14 个目录，主动检索工商、知识产权、司法和信用信息做交叉核验，最终交付 86 页、6 万余字的尽调报告，覆盖 12 个模块、14 项法律问题，结论附底稿引用。

**临床医疗。** 在一份包含几十份检验单、上万字病程记录、多份医嘱和 1,433 张原始影像的复杂病例中，它单次对话通读全部资料：跨日期定位指标、把六天病程对齐成时间线、并行读取数百张胸部 CT，识别出“双肺背侧实变”，与主管医生诊断一致，并给出四条与当日医嘱逐条对应的处置建议。

这些案例都来自厂商和合作方，不能当成独立的第三方验证。但它们至少说明，模型厂商竞争的焦点，正在从“考试分数”转向**“能不能把活干完”**。

0324/7 长程 Agent：边做边交付

长任务最怕两件事：模型闷头做很久，方向错了也不知道；以及最后交出一个“看起来完整、其实没法用”的结果。

Qwen4-Max 的解法叫 **Live Delivery**：先交一个可用首版，再持续交付更新版本，逐版扩展内容、提升质量。用户可以按每一版评估进展、校准方向，模型再根据反馈调整计划。官方同步开源了 Qwen-Live-Delivery-Plugin。

**云资源调度。** Qwen4-Max 围绕目标与约束做运筹建模、求解和验证，在阿里云真实业务中优化数据标注的多模型调用、GPU 在线分配和 CPU 离线重调度。官方数据是：标注调度费用平均降低 10.42%，GPU 在线分配的整机空闲容量时长提升 4.62%，CPU 离线重调度求解速度提升超过 14.61 倍。

说得直白些：它开始参与优化**“支撑自己运行的系统”**。

04科研：从屏幕走到实验台

发布里最“科幻”的一段，是材料与药物发现。

**冷却液材料。** Qwen4 连续自主运行 48 小时，完成路线调研，构建包含 270 万个分子的候选空间，做结构筛选、性质预测、第一性原理计算、逆合成设计和实验规划，再调度自动化湿实验室完成配制、合成、分离纯化和测试。经过 4 轮“设计—合成测试—主动学习”的闭环，最终拿到经实验验证的新型冷却液分子。

**药物发现。** 在阿尔茨海默病相关靶点的任务中，Qwen4-Max 在深势科技平台上累计调用工具 454 次，完成 3,239 项计算指标评估，设计优化 24 个候选分子。相比专利起点，最终优选分子的 RBFE 计算显示，与目标靶点的名义结合亲和力约为起点的 3.6 倍。

这不等于“AI 独立做出了新药”，但确实是 AI 在科研流程里承担了越来越长的链条。

05价格、接入与冷静提醒

Qwen4-Max 已上线千问 AI 平台，开发者可通过 Token Plan 或 API 接入；也能在千问办公、Qoder CN、千问 App、Qwen Studio 中使用。

价格方面，官方称相比 Qwen3.8-Max 全面下调 API 定价，尤其大幅降低缓存命中价格。结合单任务成本降 58% 的数据，这次发布不只是“能力更强”，也在主动压低重度使用的门槛。

还有一个容易被忽略的信息：Max 只是 Qwen4 系列的第一款模型，系列中的小尺寸模型将陆续开源。大模型冲上限，小模型走开源和落地，两条线会同时推进。

当然，发布材料终究是厂商视角。Work360、JobBench 等基准的分数、案例里的效率提升，都需要在真实业务里复现；百万上下文能不能稳定用、长程任务会不会中途跑偏、专业场景的错误由谁兜底，也都要等更多独立测试和实际使用。

06写在最后

但方向已经很清楚了：下一阶段的 AI 竞争，不只是比谁更会回答，而是比谁能把一件复杂的事，稳稳当当地做完。
