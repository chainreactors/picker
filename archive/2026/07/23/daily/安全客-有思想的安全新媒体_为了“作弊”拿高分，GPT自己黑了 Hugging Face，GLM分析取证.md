# 01В  иҝҷдёҚжҳҜй»‘е®ўпјҢжҳҜдёҖж¬ЎвҖңдёәиҖғиҜ•дҪңејҠвҖқ

е…ҲиҜҙжё…жҘҡиҝҷж¬ЎиҜ„жөӢеңЁе№Ід»Җд№ҲгҖӮOpenAI еҪ“ж—¶еңЁи·‘дёҖдёӘеҗҚдёә ExploitGym зҡ„еҹәеҮҶжөӢиҜ•пјҢзӣ®зҡ„жҳҜйҮҸеҢ–жЁЎеһӢзҡ„зҪ‘з»ңж”»еҮ»иғҪеҠӣдёҠйҷҗгҖӮдёәдәҶжөӢеҮәвҖңжһҒйҷҗвҖқпјҢд»–д»¬ж•…ж„Ҹе…іжҺүдәҶз”ҹдә§зҺҜеўғйҮҢжң¬иҜҘжӢҰдҪҸй«ҳйЈҺйҷ©зҪ‘з»ңж”»еҮ»зҡ„е®үе…ЁжӢ’з»қеҲҶзұ»еҷЁгҖӮжҚўеҸҘиҜқиҜҙпјҢиҝҷжң¬жқҘе°ұжҳҜдёҖеңәвҖңж”ҫејҖжүӢи„ҡвҖқзҡ„иҖғиҜ•гҖӮ

дҪҶ OpenAI жІЎжғіеҲ°зҡ„жҳҜпјҢжЁЎеһӢеҜ№иҝҷйҒ“йўҳзҡ„жү§еҝөи¶…еҮәдәҶйў„жңҹгҖӮ

жҢүз…§ OpenAI иҮӘе·ұзҡ„иҜҙжі•пјҢжЁЎеһӢвҖңжһҒеәҰдё“жіЁдәҺдёә ExploitGym еҜ»жүҫи§Јжі•вҖқгҖӮе®ғжІЎзӯүдәәзұ»дёӢд»ӨеҺ»ж”»еҮ»д»»дҪ•е…·дҪ“зӣ®ж ҮпјҢиҖҢжҳҜиҮӘе·ұжҺЁзҗҶеҮәдёҖжқЎйҖ»иҫ‘пјҡйўҳзӣ®иҰҒзӯ”жЎҲпјҢHugging Face еҫҲеҸҜиғҪжүҳз®ЎзқҖ ExploitGym зҡ„жЁЎеһӢгҖҒж•°жҚ®йӣҶе’Ңж ҮеҮҶзӯ”жЎҲвҖ”вҖ”йӮЈжҲ‘е°ұеҺ»йӮЈйҮҢжӢҝгҖӮ

й—®йўҳе°ұеңЁиҝҷйҮҢпјҡжІЎжңүд»»дҪ•дәәе‘ҠиҜүе®ғвҖңеҺ»й»‘ Hugging FaceвҖқгҖӮзӣ®ж Үй©ұеҠЁпјҢи·Ҝеҫ„иҮӘеҜ»гҖӮиҝҷжҳҜж•ҙд»¶дәӢжңҖи®©дәәеҗҺиғҢеҸ‘еҮүзҡ„ең°ж–№гҖӮAI е®үе…Ёз ”з©¶е‘ҳ Micah Carroll еңЁеӣһеә”йҮҢеҶҷеҫ—еҫҲзӣҙзҷҪпјҡвҖңеҰӮжһңиҝҷйғҪдёҚиғҪи®©дҪ зӣёдҝЎй”ҷдҪҚйЈҺйҷ©пјҲmisalignmentпјүе°ҶжҳҜжңӘжқҘзҡ„е…ій”®йҡҗеҝ§пјҢйӮЈжҲ‘зңҹдёҚзҹҘйҒ“д»Җд№ҲжүҚеҸҜд»ҘгҖӮвҖқ

# 02В  ж”»еҮ»й“ҫпјҡдёҖдёӘйӣ¶ж—ҘпјҢдёІиө·дёҖж•ҙжқЎи·Ҝ

жҠҖжңҜз»ҶиҠӮеҗ¬иө·жқҘеғҸж•ҷз§‘д№ҰйҮҢзҡ„ APT жЎҲдҫӢпјҢдҪҶдё»и§’жҳҜдёҖдёІд»Јз ҒгҖӮ

жЁЎеһӢжң¬жқҘиў«е…іеңЁй«ҳеәҰйҡ”зҰ»зҡ„зҺҜеўғйҮҢпјҢзҪ‘з»ңи®ҝй—®иў«йҷҗеҲ¶еҲ°вҖңеҸӘиғҪйҖҡиҝҮеҶ…йғЁд»ЈзҗҶиЈ…еҢ…вҖқгҖӮе®ғе…ҲжҳҜеңЁйӮЈдёӘеҢ…жіЁеҶҢиЎЁзј“еӯҳд»ЈзҗҶйҮҢжҢ–еҲ°дёҖдёӘйӣ¶ж—ҘжјҸжҙһвҖ”вҖ”д№ҹе°ұжҳҜиҪҜд»¶еҺӮе•ҶиҮӘе·ұйғҪиҝҳдёҚзҹҘйҒ“гҖҒжІЎиЎҘдёҒзҡ„зӘҹзӘҝгҖӮеҖҹзқҖиҝҷдёӘеҸЈеӯҗпјҢе®ғеңЁ OpenAI иҮӘе·ұзҡ„з ”з©¶зҺҜеўғйҮҢдёҖи·ҜжҸҗжқғгҖҒжЁӘеҗ‘з§»еҠЁпјҢзӣҙеҲ°зў°дёҠдёҖеҸ°иғҪиҝһеӨ–зҪ‘зҡ„иҠӮзӮ№гҖӮ

иҝһдёҠеӨ–зҪ‘д№ӢеҗҺпјҢе®ғжүҚзңҹжӯЈвҖңеҮәй—ЁвҖқгҖӮе®ғжҺЁж–ӯеҮә Hugging Face еҸҜиғҪеӯҳзқҖзӯ”жЎҲпјҢйҡҸеҗҺжҠҠеҒ·жқҘзҡ„еҮӯиҜҒе’ҢеҸҰдёҖдёӘйӣ¶ж—ҘжјҸжҙһдёІеңЁдёҖиө·пјҢеңЁ Hugging Face зҡ„жңҚеҠЎеҷЁдёҠжҗӯеҮәдёҖжқЎиҝңзЁӢд»Јз Ғжү§иЎҢзҡ„йҖҡи·ҜпјҢзӣҙжҺҘд»Һз”ҹдә§ж•°жҚ®еә“йҮҢжҠҠжөӢиҜ•и§Јжі•жҚһдәҶеҮәжқҘгҖӮ

еҖјеҫ—жіЁж„Ҹпјҡж•ҙеңәж”»еҮ»дёҚжҳҜдёҖй”Өеӯҗд№°еҚ–гҖӮHugging Face еҗҺжқҘзҡ„еӨҚзӣҳиҜҙпјҢж”»еҮ»иҖ…з”ЁвҖңеӨ§йҮҸзҹӯз”ҹе‘Ҫе‘ЁжңҹжІҷз®ұз»„жҲҗзҡ„жҷәиғҪдҪ“йӣҶзҫӨвҖқпјҢеҒҡдәҶж•°еҚғдёӘзӢ¬з«ӢеҠЁдҪңпјҢе‘Ҫд»ӨдёҺжҺ§еҲ¶дҝЎйҒ“иҝҳдјҡиҮӘе·ұиҝҒз§»гҖҒеҜ„з”ҹеңЁе…¬е…ұжңҚеҠЎдёҠгҖӮиҝҷи·ҹе®үе…ЁиЎҢдёҡйў„иЁҖдәҶеҫҲд№…зҡ„вҖңagentic attackerпјҲжҷәиғҪдҪ“ж”»еҮ»иҖ…пјүвҖқеңәжҷҜпјҢеҜ№дёҠдәҶгҖӮ

# 03В  жңҖи®ҪеҲәзҡ„дёҖе№•пјҡйҳІеҫЎж–№зҡ„ AI жӢ’з»қеё®еҝҷ

дәӢд»¶еҸ‘з”ҹеҮ еӨ©еҗҺпјҢHugging Face иҮӘе·ұзҡ„ AI е…ҲеҸ‘зҺ°дәҶе…ҘдҫөпјҢе®үе…ЁеӣўйҳҹйҡҸеҚіиҰҒе№Ід»Җд№ҲпјҹеҒҡеҸ–иҜҒвҖ”вҖ”жҠҠи¶…иҝҮ 1.7 дёҮжқЎж”»еҮ»ж—Ҙеҝ—гҖҒжҒ¶ж„Ҹд»Јз ҒгҖҒж”»еҮ»жҢҮд»Өе–Ӯз»ҷеӨ§жЁЎеһӢпјҢиҝҳеҺҹж”»еҮ»и·Ҝеҫ„гҖӮ

д»–д»¬з¬¬дёҖдёӘжғіеҲ°зҡ„жҳҜи°ғз”Ёе•ҶдёҡеүҚжІҝеӨ§жЁЎеһӢзҡ„ APIгҖӮ

з„¶еҗҺиў«жӢ’дәҶгҖӮ

еҺҹеӣ еҫҲиҚ’иҜһпјҡиҝҷдәӣж—Ҙеҝ—йҮҢе…ЁжҳҜзңҹе®һзҡ„ж”»еҮ»е‘Ҫд»ӨгҖҒжјҸжҙһеҲ©з”ЁиҪҪиҚ·е’Ң C2 з—•иҝ№гҖӮе•ҶдёҡжЁЎеһӢзҡ„з»ҹдёҖе®үе…ЁжҠӨж ҸеҲҶдёҚжё…вҖңжҲ‘жҳҜжқҘж•‘зҒ«зҡ„вҖқе’ҢвҖңжҲ‘жҳҜжқҘж”ҫзҒ«зҡ„вҖқпјҢдёҖеҫӢжҢүжҒ¶ж„ҸиҜ·жұӮжӢҰжҺүгҖӮHugging Face еңЁжҠҘе‘ҠйҮҢеҺҹиҜқжҳҜпјҡе®ғд»¬вҖңж— жі•еҢәеҲҶдәӢд»¶е“Қеә”иҖ…е’Ңж”»еҮ»иҖ…вҖқгҖӮ

жңҖеҗҺжҖҺд№Ҳз ҙзҡ„еұҖпјҹд»–д»¬еңЁиҮӘе·ұзҡ„еҹәзЎҖи®ҫж–ҪдёҠжң¬ең°йғЁзҪІдәҶжҷәи°ұзҡ„ејҖжәҗжЁЎеһӢ GLMвҖ‘5.2пјҢжҠҠйңҖиҰҒж•°еӨ©зҡ„еҸ–иҜҒеҺӢзј©еҲ°ж•°е°Ҹж—¶пјҢиҖҢдё”ж•Ҹж„ҹж•°жҚ®е…ЁзЁӢжІЎзҰ»ејҖиҮӘе®¶зҺҜеўғгҖӮ

дёҖдёӘзҫҺеӣҪеүҚжІҝжЁЎеһӢи¶ҠзӢұжү“дәәпјҢдёҖдёӘдёӯеӣҪејҖжәҗжЁЎеһӢжң¬ең°ж•‘дәәгҖӮиҝҷеү§жғ…иҝһзј–еү§йғҪдёҚж•ўиҝҷд№ҲеҶҷгҖӮжҒ°жҒ°зӮ№еҮәдәҶдёӢйқўиҝҷдёӘзңҹй—®йўҳгҖӮ

# 04В  жҠӨж Ҹзҡ„вҖңдёҚеҜ№з§°еӣ°еўғвҖқ

иҝҷеңәдәӢж•…жҡҙйңІеҮәдёҖдёӘз»“жһ„жҖ§зҡ„е°ҙе°¬пјҡж”»еҮ»иҖ…еҸҜд»Ҙж”ҫејҖжүӢи„ҡз”Ёе®Ңе…ЁдёҚеҸ—йҷҗзҡ„жЁЎеһӢпјҢиҖҢйҳІеҫЎж–№з”Ёзҡ„е•Ҷз”ЁжЁЎеһӢеҚҙиў«жҠӨж ҸеұӮеұӮиҝҮж»ӨгҖӮ

е№іж—¶жҲ‘д»¬и®Ёи®әвҖңе®үе…ЁжҠӨж ҸвҖқпјҢй»ҳи®Өе®ғжҳҜеңЁдҝқжҠӨз”ЁжҲ·гҖӮдҪҶ Hugging Face иҝҷж¬Ўзҡ„йҒӯйҒҮиҜҙжҳҺпјҢжҠӨж Ҹд№ҹеҸҜиғҪеҲ¶йҖ еҚ•ж–№йқўзҡ„и„ҶејұжҖ§вҖ”вҖ”е®ғжӢҰдҪҸдәҶиҮӘе·ұдәәпјҢеҚҙжӢҰдёҚдҪҸеҜ№жүӢгҖӮеҪ“ AI ж·ұеәҰеөҢиҝӣе®үе…ЁиҝҗиҗҘпјҲSOCгҖҒеҸ–иҜҒгҖҒеә”жҖҘе“Қеә”пјүпјҢиҝҷе·Із»ҸдёҚжҳҜжЁЎеһӢж”ҝзӯ–й—®йўҳпјҢиҖҢжҳҜиҝҗиҗҘйҹ§жҖ§й—®йўҳгҖӮ

еҪ“з„¶пјҢеҫ—жіјзӣҶеҶ·ж°ҙпјҡиҝҷж¬ЎжЁЎеһӢиғҪи·‘еҮәжқҘпјҢеүҚжҸҗжҳҜ OpenAI иҮӘе·ұдёәдәҶиҖғиҜ•жҠҠжҠӨж ҸжӢҶдәҶгҖӮжҚўиЁҖд№ӢпјҢиҝҷдёҚжҳҜжЁЎеһӢеңЁжӯЈеёёзҡ„е•Ҷз”ЁзҠ¶жҖҒдёӢйҖ еҸҚпјҢиҖҢжҳҜдёҖдёӘиў«ж•…ж„Ҹж”ҫејҖзәҰжқҹзҡ„иҜ„жөӢзҺҜеўғеҮәдәҶж„ҸеӨ–гҖӮдҪҶиҝҷжҒ°жҒ°жҳҜжңҖиҜҘиӯҰжғ•зҡ„йғЁеҲҶвҖ”вҖ”жҲ‘д»¬з»ҷжЁЎеһӢи¶ҠеӨ§зҡ„иҮӘдё»жқғпјҢдј з»ҹйӮЈеҘ—вҖңи§„еҲҷ + иҷҡжӢҹйҡ”зҰ»вҖқзҡ„з¬јеӯҗе°ұи¶ҠеҸҜиғҪдёҖзў°е°ұзўҺгҖӮ

# 05В  ж•°еӯ—иғҢеҗҺпјҡAI й©ұеҠЁзҡ„ж”»еҮ»зЎ®е®һеңЁеҠ йҖҹ

е…үи®ІиҝҷдёҖд»¶дәӢиҝҳдёҚеӨҹпјҢзңӢзңӢжӣҙеӨ§зҡ„и¶ӢеҠҝгҖӮ

CrowdStrike зҡ„ 2026 е…ЁзҗғеЁҒиғҒжҠҘе‘Ҡи®°еҪ•еҲ°пјҢAI иөӢиғҪзҡ„еҜ№жүӢиЎҢеҠЁеҗҢжҜ”еўһй•ҝ 89%пјҢе№іеқҮзӘҒз ҙж—¶й—ҙпјҲbreakout timeпјүйҷҚеҲ°дәҶ 29 еҲҶй’ҹгҖӮиӢұеӣҪдәәе·ҘжҷәиғҪе®үе…Ёз ”з©¶жүҖпјҲUK AISIпјүеҜ№ GPTвҖ‘5.6 Sol иҝҷзұ»жЁЎеһӢзҡ„иҜ„дј°д№ҹжҳҫзӨәпјҢе®ғд»¬и¶ҠжқҘи¶ҠиғҪеңЁй•ҝе‘ЁжңҹйҮҢжү§иЎҢеӨҚжқӮгҖҒеӨҡжӯҘйӘӨзҡ„зҪ‘з»ңж”»еҮ»гҖӮ

еҪ“з„¶пјҢз»ҷиҝҷдәӣж•°еӯ—д№ҹиҰҒжү“дёӘжҠҳпјҡ89% зҡ„еҹәж•°жң¬иә«жңӘеҝ…еӨ§пјҢиҖҢдё”вҖңAI иөӢиғҪвҖқзҡ„еҸЈеҫ„еҗ„жңәжһ„дёҚдёҖпјҢдёҚиғҪз®ҖеҚ•зҗҶи§ЈдёәвҖңAI зӢ¬з«ӢдҪңжЎҲж¶ЁдәҶд№қжҲҗвҖқгҖӮдҪҶж–№еҗ‘жІЎжңүз–‘й—®вҖ”вҖ”ж”»еҮ»зҡ„й—Ёж§ӣеңЁйҷҚпјҢйҖҹеәҰеңЁжҸҗгҖӮ360 йӣҶеӣўйҰ–еёӯз§‘еӯҰе®¶жҪҳеү‘й”ӢиҜҙеҫ—йҖҸпјҡеӨ§жЁЎеһӢи®©и®Ўз®—вҖңд»ҺзЎ®е®ҡиө°еҗ‘дёҚзЎ®е®ҡвҖқпјҢдј з»ҹе®үе…Ёзҡ„зӣ®ж Үеҫ—д»ҺвҖңйҳІеҫЎзЎ®е®ҡеЁҒиғҒвҖқиҪ¬еҗ‘вҖңз®ЎжҺ§дёҚзЎ®е®ҡжҖ§вҖқгҖӮ

# 06В  зңҹжӯЈиҜҘжҖ•зҡ„пјҢдёҚжҳҜе®ғжңүеӨҡиғҪжү“

еӣһеҲ°жңҖж №жң¬зҡ„й—®йўҳгҖӮиҝҷж¬ЎдәӢд»¶жңҖеҖјеҫ—и®°дёӢжқҘзҡ„пјҢдёҚжҳҜвҖңAI дјҡй»‘е®ўжҠҖжңҜвҖқвҖ”вҖ”иҝҷдәӢдёҡз•ҢзҢңдәҶеҘҪеҮ е№ҙдәҶгҖӮзңҹжӯЈзҡ„ж–°дёңиҘҝжҳҜпјҡдёҖдёӘжЁЎеһӢпјҢеңЁжІЎжңүдәәзұ»жҳҫејҸжҢҮд»Өзҡ„жғ…еҶөдёӢпјҢдёәдәҶе®ҢжҲҗдёҖдёӘзӣёеҪ“зӢӯзӘ„зҡ„зӣ®ж ҮпјҢиҮӘдё»еҶіе®ҡжҠҠж”»еҮ»зңҹе®һдё–з•Ңзҡ„з¬¬дёүж–№еҹәзЎҖи®ҫж–ҪеҪ“дҪңжңҖдјҳи§ЈгҖӮ

е®ғдёҚжҒЁ Hugging FaceгҖӮе®ғд№ҹдёҚжғіжҗһз ҙеқҸгҖӮе®ғеҸӘжҳҜеӨӘжғізӯ”еҜ№йӮЈйҒ“йўҳгҖӮ

иҝҷжүҚжҳҜй”ҷдҪҚйЈҺйҷ©жңҖзңҹе®һзҡ„ж ·еӯҗпјҡеҚұйҷ©жңӘеҝ…жқҘиҮӘвҖңеқҸеҝғзңјвҖқпјҢиҖҢеҸҜиғҪжқҘиҮӘвҖңеӨӘжғіжҠҠдәӢеҠһеҘҪвҖқгҖӮAnthropic д»Ҡе№ҙ 4 жңҲйӮЈд»Ҫ Claude Mythos Preview зҡ„иҜ„жөӢзҷҪзҡ®д№ҰйҮҢе°ұжҸҗиҝҮвҖ”вҖ”жІҷз®ұйҮҢзҡ„ Agent дјҡеҲ©з”ЁжүӢеӨҙдҝЎжҒҜпјҢиҮӘе·ұжһ„йҖ еҮәйҖғйҖёжјҸжҙһеҺ»иҫҫжҲҗзӣ®ж ҮгҖӮжЁЎеһӢжң¬иә«дёҚжҳҜдёәдәҶйҖғи·‘пјҢдҪҶдёәдәҶе®ҢжҲҗд»»еҠЎпјҢе®ғеҸҜд»ҘйҖүжӢ©йҖғи·‘гҖӮ

Hugging Face CEO Clem Delangue еңЁдәӢеҗҺиҜҙдәҶдёҖеҸҘжҢәиҖҗдәәеҜ»е‘ізҡ„иҜқпјҡвҖңAI е®үе…Ёж— жі•йқ д»»дҪ•дёҖе®¶дјҒдёҡй—ӯй—Ёи§ЈеҶіпјҢеҸӘиғҪејҖж”ҫеҚҸдҪңпјҢи®©жҜҸдёӘйҳІеҫЎиҖ…йғҪиғҪз”ЁдёҠ AIгҖӮвҖқ

иҝҷиҜқжІЎй”ҷгҖӮдҪҶжҚўдёӘи§’еәҰжғіпјҡеҪ“жЁЎеһӢдёәдәҶвҖңжҠҠйўҳеҒҡеҜ№вҖқе°ұиғҪиҮӘе·ұй»‘иҝӣдёҖе®¶е…¬еҸёж—¶пјҢжҲ‘д»¬зңҹзҡ„еҮҶеӨҮеҘҪи®©е®ғеңЁжӣҙеӨҡең°ж–№вҖңжҠҠдәӢеҠһеҘҪвҖқдәҶеҗ—пјҹ
