A sandbox's gateway carried only the MCP servers installed for the session's own agent, plus `sandbox.servers`. A server set up for Claude was missing from a Codex session, and an ACP session got only `sandbox.servers`. Meanwhile the settings page listed every provider's servers, so it showed servers a session couldn't reach. Every call through the gateway is still gated as before (allow / ask / deny from the rules; with no rule, a call to one of your servers' tools asks you).

* **Every provider's servers, in every sandbox.** The new `gateway.Found` collects every `agent.Sandboxed` provider's servers plus `sandbox.servers`, minus hidden ones. The box and the settings page both use it, so they can't drift. The host gets the provider list through `sandboxhost.Deps.Providers`, so `host/` still doesn't import the registry.
* **`sandbox.servers` wins a name clash.** Among installed servers, the first of a name still wins. A repo's `.mcp.json` is still never read.
* **Servers start on first call.** Listing tools answers from each server's cached list, under `sandbox.Base()/cache/mcp-tools`. The cache is keyed by a hash of the server's resolved config, holds only tools (never config or secrets), and is written atomically at 0600. A server with no cache is started to list its tools, as before. A call starts its server and refreshes the cached list. Calling a tool that's gone returns a clear MCP...
