军委后勤保障部采购服务中心违规处理信息公示

网安圈炸了。

看到这份公告的时候，我愣了一下。

**北京天融信——国内老牌网安厂商，被全军永久禁入采购。**

不是罚钱，不是暂停，是**永久**。全军、全品种。

这个处罚的分量，圈外人可能没概念。我来拆开说说。

01

三个关键词，读懂这份处罚

先把公告里的关键信息拎出来：

|  |  |
| --- | --- |
| 项目 | 内容 |
| 被处理公司 | 北京天融信网络安全技术有限公司 |
| 处理结果 | 终身禁止参加全军物资工程服务采购活动 |
| 处罚范围（单位） | 全军 |
| 处罚范围（品种） | 全品种 |
| 处罚时间 | 永久 |
| 处理部门 | 军委后勤保障部采购服务中心 |
| 违规情形 | 其他、无 |

三个关键词，一个比一个重。

**全军。**不是某个战区、某个军种，是全军。意思是解放军系统的采购项目，天融信都不能碰了。

**全品种。**不是某一类产品，是所有品类。防火墙不能卖，入侵检测不能卖，安全服务也不能提供。只要是军队的采购，跟网安沾边不沾边的，都不行。

**永久。**这个最狠。一般的违规处罚是暂停6个月、1年、3年。永久禁入，基本等于从军队采购体系里彻底除名了。

说直白点：天融信在军队这一块的生意，没了。而且是永久性的。

02

天融信是什么来头？

圈外的朋友可能没听过这个名字。简单介绍一下。

天融信，1995年成立，国内最早做网络安全的公司之一。有多早呢？很多人可能还没出生，它已经在做防火墙了。

国内第一台自研防火墙，就是天融信做出来的。这句话在网安行业的分量，相当于"中国第一台国产计算机"那种感觉。

2016年借壳南洋股份上市，股票代码002212。市值最高的时候冲到过300多亿。

行业地位方面，天融信长期是国内网安厂商第一梯队的。跟深信服、奇安信、启明星辰这些名字经常放在一起比。政企、金融、运营商，都是它的大客户。

军队客户，更是天融信的传统优势领域。做了多少年了，关系一直很深。

正因为是老兵、正因为军队是它的传统市场，这次被永久禁入才显得格外刺眼。

03

到底犯了什么事？

公告里写的违规情形是"其他、无"。等于没说。

具体什么原因，官方没明说。外面各种猜测都有，我就不瞎传了。

但有几件事是确定的：

第一，能被军委后勤保障部采购服务中心下"永久禁入"的处罚，事情小不了。一般的小违规、标书造假什么的，罚个一年半年顶天了。永久，说明问题很严重。

第二，被处理人员那栏写的是"无"。没有个人担责，是公司层面的处罚。这个信息其实也很耐人寻味。

第三，处罚从2025年10月30日就开始了。快一年了，现在才慢慢被更多人知道。

具体原因，等官方通报或者公司公告吧。在那之前，别瞎猜，也别传谣。

04

这件事对行业意味着什么？

有人问我，天融信被军队踢出去，是不是奇安信、深信服的机会来了？

别那么急着分蛋糕。这件事的影响，远不止"少了一个竞争对手"那么简单。

我看到的信号是——

**军队采购的合规门槛，正在快速拉高。**

以前做军队项目，大家都懂的——关系很重要。产品好不好是一回事，关系到不到位是另一回事。

但这两年不一样了。军队采购的审查越来越严，从资质到招投标过程，再到履约交付，每一步都在收紧。

天融信不是第一个被罚的。之前也有其他行业的公司被军队列入黑名单。但天融信是网安行业里，目前被处罚最重的头部厂商。

对网安行业来说，这件事有几个值得关注的点：

**军工资质会越来越值钱。**以前很多公司觉得"能拿到项目就行"，资质能拖就拖。现在不行了——没有正规的军工资质，项目根本拿不到。有资质的公司，议价权会越来越强。

**合规成本会大幅上升。**招投标流程、供应链管理、数据安全、保密管理……每一项都要投入大量人力物力。小公司根本扛不住，头部公司的优势会进一步拉大。

**信创和网安的绑定会更深。**军队的安全产品，必须是国产的、可控的。纯外资或者有外资背景的公司，基本进不去这个市场。国产替代在军队系统会加速推进。

**行业集中度可能会提升。**头部的几家合规做得好的厂商（奇安信、深信服、启明星辰、安恒信息等），有机会吃下更多的军队市场份额。但前提是——自己别出事。

**一句话总结**
天融信的事不是个例，而是一个信号。
军队网安采购的游戏规则，正在重写。

05

最后说几句

天融信是国内网安行业的老兵了。从1995年到现在，快三十年了。

它培养了一大批网安人才，业内很多公司的技术骨干，都有天融信的背景。说一句"网安黄埔军校"，不算夸张。

这次被军队永久禁入，对公司的打击肯定不小。军队订单占比多少，只有他们自己知道。但不管占多少，"被全军永久禁入"这个标签，对品牌的伤害是实打实的。

其他网安厂商也别幸灾乐祸。今天被罚的是别人，明天说不定就轮到自己。合规这根弦，松不得。

至于我们这些做技术的，这件事提醒了我们一件事——

网络安全这个行业，技术只是一面。合规、资质、关系、政策，每一面都能决定一家公司的生死。
