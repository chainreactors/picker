由中国人工智能学会（CAAI）主办，CAAI具身智能专委会、安徽大学、深圳市越疆科技股份有限公司（以下简称越疆科技）联合承办的全国具身智能大赛——2026 Dobot具身智能挑战赛（以下简称大赛）于今日正式发布。本届大赛围绕工业制造、医疗科研、日常生活中的典型场景，设立从仿真环境到实机操作的多个赛题，探索具身智能机器人在目标检索、精细操作、协同控制等领域的泛化能力。

**0****1**

PART

**基本信息**

大赛名称：2026 Dobot具身智能挑战赛

主办单位：中国人工智能学会

承办单位：CAAI具身智能专委会、安徽大学、深圳市越疆科技股份有限公司比赛时间：2026年2月12日-2026年4月12日

比赛地点（决赛）：中国安徽省合肥市

**0****2**

PART

**竞赛内容**

本届大赛设立线上仿真赛（初赛）和线下实战赛（决赛）两个阶段，总共设立3个赛题，各赛题独立评分排名，参赛队伍可根据自身擅长领域选择单一或多个赛题完成。在决赛阶段，为确保公平竞争及专注算法创新，所有团队都将使用指定的具身智能设备及配套组件，设备及配套组件由大赛组委会提供。

**比赛题目**

**1.料品分拣：根据要求进行壳料检测与分类放置**

**0****3**

PART

**赛制赛程**

本届大赛面向全国具身智能领域研究者及从业者开放，特别鼓励优秀的高校、企业及科研机构组织参赛。赛事日程安排如下：

|  |  |  |
| --- | --- | --- |
| 参赛流程 | | |
| 事项 | 时间 | 内容 |
| 注册报名 | 2026.2.12—3.31 | 在大赛官方网站进行注册登记，提交完整队伍信息 （推荐注册后加入赛事交流群，获取最新资源信息及大赛通知） |
| 模型训练 | 2026.2.12—3.31 | 基于Baseline修改或自定义模型框架，不断优化调试 |
| 培训答疑 | 2026.2.12—3.31 | 可参与大赛官方组织的各类培训活动，深入了解赛题要求及问题答疑 |
| 线上仿真赛  （初赛） | 2026.2.12—3.31 | 开放Hugging Face评测入口，可上传模型进行自动化评分，依据参赛队伍初赛期间有效提交作品的最高评分计算成绩 |
| 线下实战赛  （决赛） | 2026.4.7—4.12 | 根据大赛组委会要求参与线下实战赛，同期参与第三届中国具身智能大会 |
| 比赛结果公示 | 2026.4.12—4.19 | 公布比赛结果，并设置一周公示期以接收问询 |

**0****4**

PART

**奖项设置**

大赛共设立3万元奖金，在决赛阶段根据各赛题成绩排名决定最终奖项，具体如下：

一等奖，3名，奖金5000元，荣誉证书；

二等奖，3名，奖金3000元，荣誉证书；

三等奖，3名，奖金2000元，荣誉证书。

除以上奖励外，获奖队伍有机会获得由越疆机器人组织举办的其它具身智能相关赛事的决赛直通资格。

**0****5**

PART

**赛会联动**

本届大赛为2026中国具身智能大会（CEAI2026）官方唯一指定赛事。CEAI2026以“体驱万物，智汇江淮”为主题，将围绕具身认知、端到端模型、机器人系统、产业落地等议题开展交流。会议设有主旨报告、专题研讨、青年论坛及技术展览等环节，旨在促进学术、产业与生态的深度对接（进入决赛的选手不收取会议注册费）。

**0****6**

PART

**报名启动**

本届大赛已正式开放报名，欢迎登录大赛官网了解详细信息。

官网地址：https://challenge.dobot-robots.com/

如有相关疑问，可加入钉钉群（群号170895003131）或发送邮件至challenge@dobot-robots.com进行咨询。
