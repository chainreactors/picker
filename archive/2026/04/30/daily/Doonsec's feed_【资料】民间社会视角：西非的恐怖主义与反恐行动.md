联合国反恐委员会执行局（CTED）发布的《民间社会视角：西非的恐怖主义与反恐行动》报告。

一、文件基本信息

|  |  |
| --- | --- |
| 项目 | 内容 |
| 发布机构 | 联合国安理会反恐委员会执行局（CTED） |
| 发布时间 | 2026年4月 |
| 核心内容 | 2025年8月与西非民间社会组织（CSOs）举行的两轮虚拟圆桌会议及书面调查的发现摘要 |
| 关注区域 | 乍得湖盆地（Lake Chad   basin）和几内亚湾（Gulf of Guinea） |
| 参与情况 | 50多名CSO代表、CTED全球研究网络伙伴、技术专家和从业人员；性别比例均衡（女性46%，男性54%） |

二、核心发现与详细解读

（一）安全形势演变——威胁日益复杂严峻

1. 恐怖组织扩张与活动升级

主要威胁体：伊斯兰国西非省（ISWAP）、伊斯兰与穆斯林支持组织（JNIM）、博科圣地（Boko Haram）

扩张趋势：JNIM的行动范围已超越中部萨赫勒国家；ISWAP在尼日利亚和喀麦隆频繁袭击军事哨所，使用侦察无人机和重型武器

新兴派系：尼日利亚出现Lakurawa和Mahmuda等新派系，使威胁格局更加复杂

外溢效应：暴力已扩散至莫桑比克、肯尼亚等国；加纳北部因布基纳法索溢出效应而日益脆弱

2. 恐怖主义与有组织犯罪的深度融合（"犯罪-恐怖关联体"）

恐怖组织已深度嵌入犯罪活动，形成"以恐养恐、以黑助恐"的恶性循环：

|  |  |
| --- | --- |
| 犯罪类型 | 具体表现 |
| 武器走私 | 利用 porous borders（   porous 边境）和复杂地形进行跨境武器流转 |
| 人口贩运 | 绑架勒索成为重要收入来源，每月报告数十起案件 |
| 毒品贩运 | 从几内亚比绍经塞内加尔、冈比亚到毛里塔尼亚的毒品网络 |
| 非法采矿 | 科特迪瓦的金矿开采区成为犯罪活动中心，吸引外国武装分子 |
| 自然资源掠夺 | 牲畜盗窃、燃料走私、日用消费品走私 |
| 非法征税 | ISWAP对渔民征收每日税费，对牧民征收牲畜通行费 |

关键洞察：这种关联体兼具意识形态驱动和利润驱动特征，不仅资助恐怖活动，还加深地方不安全、侵蚀国家信任、为招募提供土壤。

3. 技术赋能恐怖主义——新维度威胁

无人机系统（UAS）：用于侦察军事情报、测试扩张地形，实施更精确的协调攻击

人工智能：用于生成宣传内容、规避监控

社交媒体滥用：超越传统招募，发展到直播宣传、内容变现（如ISWAP在尼日利亚使用TikTok变现账户）

加密通讯：利用算法驱动内容、情感化图像、互动游戏格式进行精准洗脑

（二）恐怖主义滋生的条件（Conditions Conducive to Terrorism）

1. 结构性治理缺陷

国家服务缺位：边境地区缺乏政府机构和发展项目，形成恐怖组织利用的真空

资源错配：政府不得不在安全支出与社会经济发展之间权衡，往往优先安全而忽视预防

政治动荡：萨赫勒地区的违宪政府更迭破坏了国家安全，国际孤立（如退出西非国家经济共同体ECOWAS）减少了情报共享

区域合作断裂：原有区域合作机制中断，直接增加边境社区脆弱性

2. 社会经济驱动因素

|  |  |
| --- | --- |
| 因素 | 具体表现 |
| 极端贫困 | 青年失业率高、贫困和文盲率居高不下 |
| 系统性歧视 | 少数民族（如富拉尼人）面临持续人权侵犯，难以获得医疗、教育、就业 |
| 教育缺失 | 冲突地区大规模学校关闭，儿童被剥夺教育权 |
| 流离失所 | 不安全导致的被迫流离失所和大规模青年移民反映绝望和机会匮乏 |

3. 环境退化——"威胁倍增器"

气候变化加剧了不安全感和激进化：

典型案例：

毛里塔尼亚：饮用水资源匮乏、雨季洪水导致紧张；干旱导致牲畜死亡、贫困加深，促使青年加入暴力极端组织

科特迪瓦：干旱、土地退化、水资源稀缺导致农业生产力下降，农民、牧民和渔民之间紧张关系升级

喀麦隆和尼日利亚：荒漠化和降雨减少迫使传统游牧民定居，与农耕社区发生土地和作物冲突

乍得湖盆地：湖面面积减少90%以上，加剧土地和水资源竞争，助长社区间冲突

恐怖组织的策略性嵌入：恐怖组织将自己定位为"服务提供者"和"资源争端仲裁者"，在脆弱环境中建立影响力。

4. 性别与代际维度

妇女和女童：面临性暴力和性别暴力（SGBV）、强迫婚姻、绑架、剥削；在流离失所环境中面临更高贩运风险；重返社会时面临污名、心理创伤和经济边缘化

儿童：学校关闭导致教育剥夺、武装团体招募、童婚；在囚禁中出生或被招募的儿童面临排斥和教育机会有限

青年：被系统性排斥，恐怖组织利用其有限机会提供经济激励和归属感

（三）反恐措施中的问题与人权关切

1. 过度安全化与法律滥用

扩大化适用：反恐法律被滥用于处理与恐怖主义无关的长期国内问题，压制异见，将人权倡导工作刑事化

少数群体 targeting：少数民族（如富拉尼人）被贴上恐怖分子标签或被指控协助恐怖活动

侵权现象：任意逮捕、法外处决、少数群体画像分析（profiling）

公民空间萎缩：反恐话语被武器化，针对人道主义行为者和人权捍卫者

2. 民间社会边缘化

参与缺失：CSOs在国家反恐战略的发展和实施中被边缘化，包括政治变革和政府更迭背景下

信任赤字：社区与政府之间缺乏信任是重大障碍

信息断层：中央政府与地方民众之间缺乏安全形势的透明沟通，导致错误信息传播

（四）经验教训与良好实践

1. 社区为本的预防方法

|  |  |  |
| --- | --- | --- |
| 国家/地区 | 创新实践 | 核心机制 |
| 科特迪瓦 | 全国跨宗教对话平台反对暴力极端主义 | 培训伊玛目和牧师在礼拜期间传递替代信息，促进宽容 |
| 毛里塔尼亚 | 古兰经学校毕业生职业融合 | 建立职业学校，将毕业生融入劳动力市场，解决失业和激进化脆弱性 |
| 毛里塔尼亚 | 创造性参与策略 | 论坛剧场、足球比赛期间的代际对话，结合暴力极端主义教育 |
| 科特迪瓦和尼日利亚 | 经济赋权倡议 | 支持农业合作社和市场园艺项目，经济赋权妇女和青年 |
| 喀麦隆和乍得 | 社区广播促进重返社会 | FM   Sava和Narasen等电台用当地语言广播和平与投降信息 |
| 尼日利亚 | 广播剧和讲故事项目 | 制作广播剧培养同理心、和解，支持博科圣地返回者和暴力幸存者 |
| 喀麦隆 | 传统领导层在和平建设中的作用 | 传统首领在正式解除武装、复员和重返社会方案建立前促进叛乱分子投降 |
| 加纳 | 整合女性传统领导人 | 动员"女王母亲"协会等女性传统领导人，促进社会凝聚力和冲突预防 |

2. 妇女领导力的关键作用

"女王母亲"（Queen Mothers）：在加纳，这些深入社区的女性领导人在预防工作和预警系统中发挥关键作用

富拉尼妇女赋权：作为社区教育者和倡导者，通过意识和参与防止青年暴力激进化

跨社区信息网络：妇女领导人利用与妇女团体的跨社区联系，有效传播信息、促进危机期间快速响应

3. 宗教间对话

一些国家将宗教领袖参与制度化，培训其推广拒绝暴力的替代叙事和宗教话语

宗教领袖还参与与狱中恐怖罪犯和拘留者的对话

重要原则：必须在充分尊重宗教或信仰自由的情况下实施，确保符合国际人权标准

（五）民间社会提出的详细建议

对政府和有关当局：

1. 改进国家反恐战略制定与实施

确保CSOs有意义地参与国家和区域反恐战略的制定与实施

确保战略不仅起草，而且有效实施和监测，建立问责和基于实地现实的调整机制

将CSOs收集的实地洞察和数据整合到政策制定中

优先为前恐怖战斗人员制定量身定制的、性别敏感的、基于社区的康复和重返社会方案

2. 在反恐措施中促进和保护人权

审查法律框架，确保符合国际人权法、国际人道法和国际难民法

保护公民空间，反对将反恐立法和话语武器化以压制异见

避免将内部冲突安全化，避免滥用反恐法律将少数群体标记为恐怖分子

保障所有儿童的受教育权作为基本人权

解决冲突地区大规模失学问题，优先为女孩提供安全、包容和优质教育

3. 应对激进化的条件和新兴威胁

将人权诉求作为优先事项，重建社区与国家之间的信任

向有需要的社区提供人道主义援助，特别关注流离失所者和受不安全影响者

投资当地驱动的媒体和宗教教育运动，提供可信的替代叙事

加强数字素养和网络安全倡议，应对恐怖分子使用无人机、AI生成宣传和社交媒体变现

确保对恐怖主义受害者和反恐措施受害者的人权侵犯进行问责

4. 采取全面司法改革

加强司法独立，确保公正审判保障，减少任意拘留

建设法官和法律从业者能力，维护国际人权标准

确保筛查、起诉、康复和重返社会工作获得充足资源，涉及CSOs和传统领导人

5. 改善边境安全与协调

加强边境管理，防止恐怖分子流动，遏制跨国有组织犯罪与恐怖主义关联

补充以人为中心的执法和边境控制措施，积极侦测和打击恐怖主义融资

与边境社区加强信息共享，促进社区准备

在保护寻求庇护者、流离失所者和难民权利的同时，建立适当措施打击恐怖分子的跨境流动

6. 加强包容性治理和服务提供

增加对边缘化和边境地区基本服务（教育、卫生、司法）的投资

促进妇女平等和有意义地参与和平建设、安全部门改革和反恐政策制定

7. 增强透明度和沟通

与社区及时分享准确安全信息，建立信任和准备

解决错误信息，改善公众对政府人道主义援助和反恐努力的理解

8. 加强社区为本的预防

投资地方结构作为预警、对话和反叙事工作的关键行为体

培训宗教领袖开展反激进化工作，建立信任、韧性和包容性

对国际社会、能力建设和捐助国：

1. 维持和多元化资金

继续支持社区反恐和预防项目，减轻资金削减的影响

更新投资和战略伙伴关系，确保成果不因资金短缺而逆转

2. 支持社区为本的方法

投资当地主导的社会凝聚力、早期预警系统和反叙事倡议

资助赋权妇女、青年和边缘群体作为社区和平建设者和教育者的项目

3. 应对非传统威胁和相关脆弱性

承认环境退化是不安全和激进化的驱动因素，资助气候适应和可持续发展项目

建设能力，加强公私伙伴关系，应对新技术被滥用于恐怖目的

4. 促进区域稳定与合作

鼓励成员国之间的接触与合作，特别是在乍得湖盆地和几内亚湾地区

支持区域反恐中心和联合行动，同时确保人权合规

三、关键洞察与战略意义

1. "全社会方法"（Whole-of-Society Approach）的必要性

报告反复强调，有效的反恐不能仅依靠军事和安全手段，必须整合：

政府各部门协调（Whole-of-government）

民间社会深度参与（CSOs从战略制定到监测评估的全过程参与）

社区韧性建设（经济赋权、社会凝聚力、替代叙事）

2. 从"硬安全"到"预防为主"的范式转变

过度安全化的悖论：过度依赖军事手段、滥用反恐法律反而可能疏远社区、加深不信任、为恐怖组织提供招募叙事

预防的投资逻辑：投资教育、就业、气候适应、包容性治理的成本远低于军事干预和应对袭击的成本

3. 性别敏感的反恐框架

妇女不仅是受害者，更是关键的预防行为体（如"女王母亲"、富拉尼妇女教育者）

必须关注妇女和儿童在重返社会中的独特需求（心理创伤、经济边缘化、性暴力后果）

4. 气候-安全关联的新前沿

环境退化不再是"背景因素"，而是直接的安全威胁倍增器。反恐战略必须与气候适应、自然资源管理、农牧民冲突调解相结合。

5. 技术治理的紧迫性

无人机、AI、社交媒体变现等技术被恐怖组织快速武器化，而国家能力和监管框架严重滞后，需要公私合作和国际协作。
