关于LYSRC暂停接收漏洞公告

尊敬的各位白帽师傅、安全研究者：

       为进一步提升平台服务能力与用户体验，经LYSRC团队评估，将暂停接收新增漏洞，并公告如下：

一、暂停安排

       自该公告发布起立即生效，LYSRC平台暂停接收新增漏洞，恢复时间将另行通知。请及时关注平台公告获取最新动态。

二、暂停期间相关说明

|  |  |
| --- | --- |
| 事项 | 处理方式 |
| 已提交漏洞 | 继续按照现有流程正常审核与处理，不受本次调整影响 |
| 新漏洞提交 | 暂停接收 |
| 积分兑换与奖励发放 | LYSRC平台积分正常兑换，奖励将按照积分兑换顺序分批采购发放，请提前在个人中心确认实名信息并填写正确的地址信息，避免影响正常奖励发放 |
| 安全测试授权 | 暂停期间请勿对同程旅行及其关联业务进行任何形式的安全测试，未经授权的测试行为将依据相关法律法规处理 |

三、联系方式

官方邮箱：sec@ly.com

官方微信公众号：同程旅行安全应急响应中心
