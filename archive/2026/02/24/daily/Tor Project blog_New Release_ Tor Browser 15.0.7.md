# New Release: Tor Browser 15.0.7

by [ma1](/author/ma1)
| February 24, 2026

![](/new-release-tor-browser-1507/lead.png)

Tor Browser 15.0.7 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/15.0.7/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-15.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 15.0.6 is:

* All Platforms
  + Updated NoScript to 13.5.14.1984
  + Updated zlib to 1.3.2
  + [Bug tor-browser#44656](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44656): Rebase Tor Browser release onto 140.8.0esr
  + [Bug tor-browser#44681](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44681): Backport Security Fixes from Firefox 148
* Windows + macOS + Linux
  + Updated Firefox to 140.8.0esr
* Android
  + Updated GeckoView to 140.8.0esr
  + [Bug tor-browser#44620](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/44620): Move the Android IPC directory
