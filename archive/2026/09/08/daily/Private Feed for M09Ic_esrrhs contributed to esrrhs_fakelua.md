Replace the hand-rolled non-blocking IO implementation (raw sockets + epoll/select + CircularBuffer + manual HTTP/WS parser dispatch) with a Boost.Asio-based engine while preserving the existing Lua API surface, framer types, WebSocket support, and deferred-close semantics.

## Changes

**New files:**

* `src/native/net/net_asio.h` / `.cpp` — Boost.Asio-based engine (`TcpServer`/`TcpClient`/`AsioConn`)
  + Per-engine `io_context` + background worker thread
  + Event queue (engine thread produces, tick thread consumes)
  + `drain_events_with(dispatcher)` for synchronous dispatch
  + `tick()` member fn as backwards-compatible wrapper
