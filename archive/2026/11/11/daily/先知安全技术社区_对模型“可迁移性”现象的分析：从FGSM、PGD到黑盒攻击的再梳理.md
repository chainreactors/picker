# 引言

我最初接触对抗样本时，注意力主要放在FGSM、PGD这类白盒攻击上，觉得只要理解了梯度怎么被利用、扰动怎么让模型出错，就对这个问题有了比较完整的认识。后来把迁移攻击和经典黑盒攻击放在同一条线索上重新梳理，我才发现之前的理解偏窄：现实中的攻击者往往看不到模型内部，查询也受限，此时对抗样本能否迁移、查询成本高不高、一些正常功能会不会被组合成新的传递或攻击路径，都会影响风险评估。

基于这个发现，本文尝试从威胁模型、攻击目标和算法选择入手，把白盒攻击、迁移攻击和黑盒攻击串起来，帮助读者建立“威胁模型—攻击目标—算法选择—防御评估”的整体认识，而不是只盯着攻击成功率。这次研究让我意识到，对抗样本的意义在于更真实地评估模型鲁棒性和安全部署风险：白盒攻击暴露脆弱点，迁移和黑盒攻击提醒我们现实攻击可能性不能低估。

# **一、对抗样本与基本概念**

## 1.1 什么是对抗样本

**什么是人工智能模型**

假设我们训练了一个图像分类模型，能够识别猫、狗等不同物体，模型的工作流程可以简化为：

```
输入照片 → 神经网络提取特征 → 输出各类别得分 → 选择预测类别
```

在正常情况下可以正确识别，但是如果对输入图片添加一些**人类几乎无法察觉**的微小扰动，模型可能就会产生完全不同的预测结果。

这就是对抗样本攻击的基本思想。

**什么是对抗样本**

英文名称：Adversarial Examples。

对抗样本是指：

> 通过对正常输入数据添加经过特殊构造的扰动，使机器学习模型产生错误预测或攻击者期望的预测结果，同时尽可能保持原始输入的语义不变。

用一个公式表示：

![](https://xzfile.aliyuncs.com/2026/11/09/1707/17ff0328-a01.png)

其中：

| 符号 | 含义 |
| --- | --- |
| $x$ | 原始输入样本 |
| $\delta$ | 对抗扰动（Adversarial Perturbation） |
| $x'$ | 对抗样本 |
| $f(x)$ | 模型对原始样本的输出 |
| $f(x')$ | 模型对对抗样本的输出 |

攻击的核心目标：

![](https://xzfile.aliyuncs.com/2026/11/09/1707/ec2f6963-820.png)

也就是说，原始输入和对抗样本在语义上基本相同，但是模型预测结果发生了变化。

这里需要了解：**对抗样本不是简单地给图片添加随机噪声，而是根据模型的弱点，有目的地构造扰动。**

随机噪声不一定能让模型分类错误，而对抗扰动会利用模型的决策机制，尽可能高效地改变模型预测结果。

**为什么会出现对抗样本攻击**

涉及机器学习模型的一个核心问题：模型学习到的特征不一定与人类理解的语义完全一致。

例如： 人类识别一只猫，可能会关注：

* 耳朵形状。
* 眼睛。
* 胡须。
* 身体轮廓。

我进一步意识到，神经网络并不一定像人那样“理解”输入，它可能学到大量人类难以直观解释的统计特征。这些特征在正常数据分布下确实能帮助模型分类，但我也认识到，它们可能让模型对某些特定方向上的微小扰动格外敏感。

早期研究中一个很重要的解释是：模型在高维空间中可能表现出局部线性行为，大量微小扰动经过特征和权重的累积，最后可能足以改变分类结果。

不过我在研究时也提醒自己，不能把这种解释当成所有对抗样本现象的唯一答案；模型结构、训练数据、决策边界和输入分布等因素，都会影响模型的对抗脆弱性。

**安全意义：** 模型在正常测试集上准确率很高，并不意味着它能够抵抗攻击者精心构造的输入。

#### 机器学习模型的分类过程

* 类别 1：狗

* $p\_0$：预测为猫的概率。
* $p\_1$：预测为狗的概率。

即选择概率最大的类别。下文用 $f(x)$ 表示模型输出，用 $\hat{y}(x)$ 表示最终预测类别；实验代码中的网络输出是 logits，交叉熵函数会在内部处理，不需要提前调用 softmax。

#### 什么是损失函数

损失函数用于衡量模型预测结果与真实标签之间的差距。

机器学习训练的目的，就是不断调整模型内部的参数，使得这个**“损失值”降到最低**。对于当前样本，真实类别的预测概率越高，交叉熵损失通常越小。

假设：

假设真实类别为 1，也就是狗：

![](https://xzfile.aliyuncs.com/2026/11/09/1909/a74f3987-b5e.png)

* 模型预测：

![](https://xzfile.aliyuncs.com/2026/11/09/1910/3539bf4c-f28.png)

模型给真实类别的概率为 0.9，预测正确，损失较小。

* 模型预测：

![](https://xzfile.aliyuncs.com/2026/11/09/1910/820bf591-329.png)

真实类别的预测概率只有 0.1，模型预测错误，损失也更大。

分类问题常用交叉熵损失作为损失函数：

![](https://xzfile.aliyuncs.com/2026/11/09/1910/197017c6-dd3.png)

其中：

* $C$：类别数量。
* $y\_i$：真实标签的独热编码（通常是 One-hot 编码，正确类别为1，其余为0），从而**损失 = $-\log(\text{预测正确的概率})$**。
* $p\_i$：模型预测概率。

解释一下原理：

在信息论中，一件越不可能发生的事情发生了，它包含的信息量就越大。公式定义为：$I(p)=-\log(p)$

**交叉熵（Cross-Entropy）**：衡量**“我们用预测的概率分布去表达真实概率分布时，所需的平均信息量”**

对抗攻击者希望利用这个损失函数，找到一个扰动，使模型的损失增加。

#### 什么是梯度（Gradient）

**梯度是一个向量，它指出了函数值（比如损失）上升最快的方向。**

对于神经网络：

![](https://xzfile.aliyuncs.com/2026/11/09/1911/850bb2eb-3e6.png)

表示损失函数关于输入数据 $x$ 的梯度。

注意，这里不是对模型参数求梯度，而是对输入数据求梯度。

训练时，我们通常对模型参数求梯度，让损失下降；这里则固定模型参数，修改输入，让损失上升。两者使用的都是梯度，但求导对象和更新方向不同。

#### 为什么梯度可以用于攻击

假设我们想让模型分类错误。

我们可以：

1. 输入一张正常图片。
2. 计算模型预测结果。
3. 计算损失函数。
4. 求损失函数对输入图片的梯度。
5. 根据梯度方向修改图片。
6. 再次输入模型，观察预测结果。

数学表达：

![](https://xzfile.aliyuncs.com/2026/11/09/1911/a06e784b-276.png)

我们希望：

![](https://xzfile.aliyuncs.com/2026/11/09/1911/709fd6d5-705.png)

同时限制扰动的大小：

![](https://xzfile.aliyuncs.com/2026/11/11/1626/06283d51-21f.png)

其中：

* $\epsilon$：扰动预算。
* $p$：使用的范数类型。
* $L$：模型损失函数。

这就是经典的非定向对抗攻击优化目标。

简单来说，训练时希望模型少犯错，非定向攻击则故意让模型更容易犯错。

特别注意： 扰动预算越大，通常越容易改变模型预测，但也可能让输入变化更加明显，所以要限制扰动的大小在预算之内。

这类只要求预测错误、不指定错误类别的方式，叫作非定向攻击。

## 1.3 攻击方式的分类

#### 按攻击者掌握的信息分类

`白盒攻击（White-box Attack）`

掌握模型内部信息

攻击者可以获取模型结构、参数，通常还可以计算梯度。

例如：知道模型使用 ResNet，并可以访问模型权重。

`黑盒攻击（Black-box Attack）`

无法直接访问模型内部

攻击者无法直接获得模型参数和梯度，可能只能提交输入并观察输出。

例如：只能通过在线图像识别 API 获取分类结果。

`灰盒攻击（Gray-box Attack）`

掌握部分信息

攻击者了解模型部分结构、接口或训练信息，但无法完全访问模型内部。

这里需要特别注意：

白盒、黑盒和灰盒描述的是攻击者的信息与访问能力，而不是攻击算法本身。

#### 按攻击目标分类

**（1）非定向攻击（Untargeted Attack）**

攻击者只要求模型预测错误，不关心错误预测成什么类别。

例如：

* 原始图片：猫。
* 模型原本预测：猫。
* 攻击后预测：狗、兔子、狐狸都可以。

目标：

![](https://xzfile.aliyuncs.com/2026/11/11/1626/12008bd2-f85.png)

优化目标：

![](https://xzfile.aliyuncs.com/2026/11/11/1626/dab60559-c0c.png)

**（2）定向攻击（Targeted Attack）**

攻击者希望模型预测成指定类别。

例如：

* 原始图片：猫。
* 攻击目标：狗。
* 攻击后必须预测成狗。

目标：

![](https://xzfile.aliyuncs.com/2026/11/09/1711/5dfd20d6-9dd.png)

其中 $y\_t$ 是攻击者指定的目标类别。

定向攻击通常通过最小化目标类别对应的损失来实现：

![](https://xzfile.aliyuncs.com/2026/11/09/1711/f58d0b13-294.png)

#### 按扰动范围分类

常见的范数约束：

| 范数 | 含义 | 特点 |
| --- | --- | --- |
| $L\_0$ | 发生变化的像素数量 | 控制修改位置数量 |
| $L\_1$ | 扰动绝对值之和 | 控制总体扰动量 |
| $L\_2$ | 扰动平方和开根号 | 控制整体欧氏距离 |
| $L\_\infty$ | 最大单个元素扰动 | 控制每个像素的最大变化 |

其中，FGSM 和 PGD 常使用 $L\_\infty$ 约束。

例如：

![](https://xzfile.aliyuncs.com/2026/11/09/1711/823c75c6-cbe.png)

表示每个归一化像素的扰动绝对值不能超过 $8/255$。

# **二、FGSM：沿梯度方向修改一次图片**

**（Fast Gradient Sign Method）**

快速梯度符号法，它是一种经典的白盒攻击（White-box Attack）方法，旨在通过利用神经网络的梯度信息，以极低的计算成本生成对抗样本，使模型产生分类错误。

## 2.1 原理

FGSM 的核心思想不是通过复杂的迭代优化来寻找对抗扰动，而是**沿着损失函数梯度上升的方向，单步推入一个固定大小的扰动**。

数学表达式为：

![](https://xzfile.aliyuncs.com/2026/11/09/1710/c9d96304-f47.png)

公式中：

* $x$：原始图片。
* $x\_{\mathrm{adv}}$：对抗样本。
* $\epsilon$：扰动幅度。
* $L$：损失函数。
* $\nabla\_x L$：损失函数对输入图片的梯度。
* $\operatorname{sign}$：符号函数。

符号函数的规则：

![](https://xzfile.aliyuncs.com/2026/11/09/1709/e8c15a97-5f7.png)

例如，计算得到梯度：

![](https://xzfile.aliyuncs.com/2026/11/09/1709/46d81a98-7dc.png)

经过符号函数：

![](https://xzfile.aliyuncs.com/2026/11/09/1709/c6f670e7-5be.png)

假设扰动幅度为：

![](https://xzfile.aliyuncs.com/2026/11/09/1709/2d88b9ef-91b.png)

那么添加的扰动为：

![](https://xzfile.aliyuncs.com/2026/11/09/1708/bff0bfe7-df9.png)

这意味着每个像素按照梯度的正负方向进行修改。

这里有一个细节：

为什么使用 `sign(gradient)`，而不是直接使用梯度？

因为 FGSM 的目标是在 $L\_\infty$ 约束下，通过一次梯度计算最大化局部线性近似的损失。

下面把损失简写为 $L(x)$，表示固定模型与真实标签后，损失随输入的变化。对于线性近似：

![](https://xzfile.aliyuncs.com/2026/11/11/1627/1c93cbb3-fd0.png)

在满足：

![](https://xzfile.aliyuncs.com/2026/11/11/1627/853a9b16-07a.png)

的情况下，选择梯度符号方向可以最大化这个一阶近似目标。

这就是 FGSM 的数学基础。

**FGSM 的特点**

优点：

* 实现简单。
* 计算成本低。
* 只需要一次反向传播。
* 适合快速测试模型的对抗脆弱性。

缺点：

* 只进行一次扰动。
* 不一定能找到最强的对抗样本。
* 攻击效果依赖扰动幅度。
* 可能存在攻击失败的情况。

## 2.3 定义模型

其中 `model.py`：

```
import torch
import torch.nn as nn
import torch.nn.functional as F
​
class MNISTModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 16, 3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, 3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(32 * 7 * 7, 128)
        self.fc2 = nn.Linear(128, 10)
    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(x.size(0), -1)
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x
```

解释一下代码：

先看导入的包

* `torch`：PyTorch 的核心库，用于张量（Tensor）计算。
* `torch.nn`：包含了构建神经网络所需的各种层（如卷积层、全连接层）。
* `torch.nn.functional`：包含了各种激活函数（如 ReLU）和不需要学习参数的操作（如池化）。

这里使用了 CNN（卷积神经网络）。因为 MNIST 是图像分类数据集，CNN 能够通过卷积操作提取图像中的局部特征。

之后定义了模型类进行初始化

* 所有的 PyTorch 模型都必须继承 `...
