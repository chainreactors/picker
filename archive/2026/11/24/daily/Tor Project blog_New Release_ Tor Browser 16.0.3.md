# New Release: Tor Browser 16.0.3

by [boklm](/author/boklm)
| November 24, 2026

![](/new-release-tor-browser-1603/lead.png)

Tor Browser 16.0.3 is now available from the [Tor Browser download page](https://www.torproject.org/download/) and also from our [distribution directory](https://www.torproject.org/dist/torbrowser/16.0.3/).

This version includes important [security updates](https://www.mozilla.org/en-US/security/advisories/) to Firefox.

## Send us your feedback

If you find a bug or have a suggestion for how we could improve this release, [please let us know](https://support.torproject.org/misc/bug-or-feedback/).

## Full changelog

The [full changelog](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/maint-16.0/projects/browser/Bundle-Data/Docs-TBB/ChangeLog.txt) since Tor Browser 16.0.2 is:

* All Platforms
  + Updated NoScript to 13.6.39.1984
  + Updated Tor to 0.4.9.17
  + [Bug tor-browser#45428](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45428): Apply worker patches before static imports
  + [Bug tor-browser#45429](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45429): (H1) Track SharedWorker load redirections
  + [Bug tor-browser#45432](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45432): (H1) Remote nested worker propagation issue from blob: parent context
  + [Bug tor-browser#45472](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45472): Protect against malicious environment tampering beyond xray wrappers
  + [Bug tor-browser#45494](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45494): Rebase Tor Browser Stable on 153.8
  + [Bug tor-browser#45499](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45499): Backport Security Fixes from Firefox 161
* Windows + macOS + Linux
  + Updated Firefox to 153.8.0esr
  + [Bug tor-browser#45455](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45455): Remove console noise on some static imports.
* Windows
  + [Bug tor-browser#45473](https://gitlab.torproject.org/tpo/applications/tor-browser/-/issues/45473): Windows paths can bypass local file event-based oracles protection
* Android
  + Updated GeckoView to 153.8.0esr
* Build System
  + All Platforms
    - [Bug tor-browser-build#41910](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41910): Update apt for security update (CVE-2026-109518)
  + Windows + Linux + Android
    - Updated Go to 1.26.11
  + Windows + Android
    - [Bug tor-browser-build#41916](https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/issues/41916): zlib updates should be listed in the relevant platforms in changelogs
