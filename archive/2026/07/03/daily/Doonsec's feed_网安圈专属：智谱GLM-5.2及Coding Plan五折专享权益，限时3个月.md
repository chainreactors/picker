即日起，**中关村自主大模型产业联盟正式发起“网络安全人员开放计划”**。

本计划面向网络安全企业、安全研究机构、重点实验室、高校安全团队、基础设施安全团队，以及经联盟审核通过的安全研究人员和开源基础设施维护者，**受邀、受控开放智谱 GLM-5.2 系列模型在网络安全场景中的能力**。

通过本计划，联盟希望帮助可信安全伙伴在**合法授权、防御优先、过程可审计**的前提下，提升漏洞挖掘、代码审计、补丁验证、安全测试、代码修复和安全研发效率，让先进大模型能力真正服务于网络安全防御体系建设。

本计划**不面向公众开放**，而是面向可信防御者提供受控访问机制。模型能力应优先用于伙伴自身产品、服务、授权系统、开源基础设施和防御性安全研究。

智谱将提供模型能力与技术支持；联盟伙伴负责使用场景合规、目标授权、结果复核与漏洞处置，共同构建安全、可信、可治理的大模型网络安全应用机制。

**一、开放对象**

本计划优先面向以下对象开放：

1. **有关网络安全部门及相关支撑单位**
2. **安全研究机构、重点实验室和高校安全团队**
3. **网络安全企业、软件安全服务商和基础设施安全团队**
4. **经联盟审核通过的安全研究人员和开源基础设施维护者**

如果你或你的团队长期关注漏洞挖掘、代码审计、安全测试、补丁验证、安全研发、开源基础设施维护或国产软件安全提升，本计划将为你提供更高效的大模型能力支持。

**二、伙伴权益**

1. **Coding Plan 网络安全特供名额：**面向通过审核的联盟伙伴，开放智谱**Coding Plan 团队版 5 折特供名额。**Coding Plan 名额有限，优先支持安全研发、代码审计、漏洞分析、补丁验证、测试用例生成和代码修复等高价值场景（Coding Plan 是智谱面向开发者编程场景的 AI 编程套餐）。
2. **GLM-5.2 API 特供 5 折权益**：面向具备持续使用需求的企业、机构和安全团队，**开放 GLM-5.2 API 5 折特供权益，**支持在合法授权、防御优先的前提下，用于漏洞挖掘、代码审计、安全测试和产品集成。
3. **企业级技术接入与治理支持：**对于重点伙伴，联盟将优先提供额度及并发保障、接入支持和场景适配，帮助其将 GLM-5.2 能力稳定接入自身产品、服务和安全研发流程。
4. **联盟生态协同机会：**优秀伙伴可优先参与联盟闭门交流、联合评测、场景共创和国产软件安全提升专项，共同推动大模型能力服务网络安全防御体系建设。

折扣政策为限时折扣，折扣享受期为7月1日–10月1日。

**三、准入原则**

1. **受邀与验证**：有意参与的企业、机构或个人可向中关村自主大模型产业联盟提交申请，并提交防御性使用场景说明，联盟审核通过之后即可开放。
2. **合法授权、防御优先：**联盟伙伴仅限用于授权场景，对异常调用与疑似违规场景，将通过审计和访问控制进行治理。
3. 模型输出为专家辅助而非最终结论，须经人工复核与工程验证后，方可用于生产处置或对外披露；漏洞遵循负责任披露流程。

**四、填写申请表**

线上申请表：《中关村自主大模型产业联盟 · 网络安全人员开放计划》
