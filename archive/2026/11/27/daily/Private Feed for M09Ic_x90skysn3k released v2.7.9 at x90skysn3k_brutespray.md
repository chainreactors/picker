## What's New in v2.7.9

> **v2.7.9 makes big scans trustworthy at scale**: one driver per target, host slots that survive runtime resizing, SSH misses under server load are retried instead of silently scored wrong, and a cross-host `round-robin` schedule for sprays.

### Fixed: hosts kept starting work after being skipped/finished; duplicate targets double-bruted (`#378`, PR [#380](https://github.com/x90skysn3k/brutespray/pull/380))

* **Root cause 1 — duplicate targets drove one pool twice.** The same target arriving from repeated `-H` args or overlapping `-f`/`-H` inputs launched two processing goroutines against one host pool: reproduced `panic: send on closed channel` (double queue close) plus every credential brute-forced twice. **Fix** — exact duplicate targets are collapsed at config time (`dedupeHosts`) and each target is claimed exactly once per run (`processedTargets` claim at the top of `ProcessHost`). **Regression** — `TestProcessHostConcurrentDuplicatesDoNotShareQueue` (red on the pre-fix implementation with the queue panic), `TestProcessHostSequentialDuplicateDoesNotRebrute`
* **Root cause 2 — two services on the same `host:port` shared one job queue.** The second service fed and closed the first one's queue; one service's attempts were silently dropped or crashed the pool. **Fix** — host pools are keyed `host:port/service`. **Regression** — `TestProcessHostSameHostPortDifferentServicesBothRun...
