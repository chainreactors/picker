# Cloudflare 控制面板和 Cloudflare API 服务出现问题

发布时间:

热度:

May 22, 2026 - 15:36 UTC — Cloudflare 正在调查 Cloudflare 控制面板及其相关 API 的问题。这些问题不会影响通过 Cloudflare CDN 提供的缓存文件服务，也不会影响 Cloudflare Edge 上的其他安全功能。使用控制面板/Cloudflare API 的客户会受到影响，因为请求可能会失败和/或显示错误。

May 22, 2026 - 15:41 UTC — 问题已查明，目前正在实施修复。
