еҫ®иҪҜ Windows еӣҫеҪўз»„д»¶дёӯеӯҳеңЁдёҖдёӘВ **дёҘйҮҚзҡ„иҝңзЁӢд»Јз Ғжү§иЎҢжјҸжҙһ**пјҢж”»еҮ»иҖ…еҸҜеҲ©з”Ёзү№еҲ¶ JPEG еӣҫеғҸеӨәеҸ–зі»з»ҹжҺ§еҲ¶жқғгҖӮ

иҜҘжјҸжҙһзҡ„ CVSS иҜ„еҲҶдёәВ **9.8**пјҢеҜ№е…Ёзҗғ Windows з”ЁжҲ·жһ„жҲҗдёҘйҮҚеЁҒиғҒпјҢеӣ е…¶В **ж— йңҖз”ЁжҲ·дәӨдә’еҚіеҸҜиў«еҲ©з”Ё**гҖӮ

иҜҘжјҸжҙһдәҺ2025е№ҙ5жңҲиў«еҸ‘зҺ°пјҢеҫ®иҪҜдәҺ2025е№ҙ8жңҲ12ж—ҘеҸ‘еёғиЎҘдёҒдҝ®еӨҚгҖӮй—®йўҳжәҗдәҺВ **windowscodecs.dll еә“дёӯзҡ„дёҚеҸҜдҝЎжҢҮй’Ҳи§Јеј•з”Ё**пјҢеҪұе“Қж ёеҝғеӣҫеғҸеӨ„зҗҶеҠҹиғҪгҖӮ

ж”»еҮ»иҖ…еҸҜе°ҶжҒ¶ж„Ҹ JPEG еөҢе…Ҙ Microsoft Office ж–ҮжЎЈзӯүж—Ҙеёёж–Үд»¶дёӯпјҢеҪ“ж–Үд»¶иў«жү“ејҖжҲ–йў„и§Ҳж—¶еҚіеҸҜВ **йқҷй»ҳж”»йҷ·зі»з»ҹ**гҖӮ

жӯӨжјҸжҙһеҮёжҳҫдәҶдј з»ҹеӣҫеҪўеӨ„зҗҶдёӯзҡ„жҢҒз»ӯйЈҺйҷ©пјҡзңӢдјјж— е®ізҡ„еӣҫеғҸи§Јз Ғж“ҚдҪңеҸҜиғҪеҜјиҮҙВ **е®Ңе…Ёзҡ„зі»з»ҹжҺҘз®Ў**гҖӮз”ұдәҺ Windows й©ұеҠЁзқҖж•°еҚҒдәҝи®ҫеӨҮпјҢжңӘжү“иЎҘдёҒзҡ„зі»з»ҹд»ҚжһҒжҳ“йҒӯеҸ—й’“йұјж”»еҮ»жҲ–ж— дәӨдә’дёӢиҪҪж”»еҮ»гҖӮ

### жјҸжҙһеҸ‘зҺ°дёҺжҠҖжңҜз»ҶиҠӮ

Zscaler ThreatLabz йҖҡиҝҮеҜ№ Windows жҲҗеғҸз»„д»¶зҡ„е®ҡеҗ‘жЁЎзіҠжөӢиҜ•еҸ‘зҺ°дәҶиҜҘжјҸжҙһпјҢйҮҚзӮ№е…іжіЁ windowscodecs.dll дёӯзҡ„ JPEG зј–з Ғе’Ңи§Јз Ғи·Ҝеҫ„гҖӮ

жјҸжҙһеҲ©з”Ёзҡ„е…ҘеҸЈзӮ№дҪҚдәҺВ `GpReadOnlyMemoryStream::InitFile`В еҮҪж•°пјҢж”»еҮ»иҖ…еҸҜйҖҡиҝҮж“Қзәөзј“еҶІеҢәеӨ§е°ҸжҺ§еҲ¶ж–Үд»¶жҳ е°„жңҹй—ҙзҡ„еҶ…еӯҳеҝ«з…§гҖӮ

жЁЎзіҠжөӢиҜ•жҳҫзӨәпјҢеңЁВ `jpeg_finish_compress+0xcc`В еӨ„и§Јеј•з”ЁжңӘеҲқе§ӢеҢ–жҢҮй’Ҳдјҡи§ҰеҸ‘еҙ©жәғпјҢйҖҡиҝҮе Ҷе–·е°„еҸҜжҡҙйңІз”ЁжҲ·еҸҜжҺ§ж•°жҚ®гҖӮ

WinDbg еҲҶжһҗзҡ„е Ҷж Ҳи·ҹиёӘжҢҮеҗ‘В `CJpegTurboFrameEncode::HrWriteSource`В е’ҢВ `CFrameEncodeBase::WriteSource`В зӯүе…ій”®еҮҪж•°пјҢиҜҒе®һ JPEG е…ғж•°жҚ®зј–з ҒиҝҮзЁӢдёӯеӯҳеңЁзјәйҷ·гҖӮ

иҝҷз§ҚжңӘеҲқе§ӢеҢ–иө„жәҗй—®йўҳе…Ғи®ёВ **ж— зү№жқғжү§иЎҢд»»ж„Ҹд»Јз Ғ**пјҢдҪҝе…¶еҸҜйҖҡиҝҮзҪ‘з»ңеҲ©з”ЁгҖӮеҫ®иҪҜзЎ®и®ӨиҜҘжјҸжҙһеҪұе“Қдҫқиө–еӣҫеҪўз»„д»¶иҮӘеҠЁжёІжҹ“еӣҫеғҸзҡ„еә”з”ЁзЁӢеәҸгҖӮ

### еҸ—еҪұе“ҚзүҲжң¬дёҺиЎҘдёҒ

иҜҘжјҸжҙһеҪұе“Қиҫғж–°зҡ„ Windows зүҲжң¬пјҢе°Өе…¶жҳҜдҪҝз”Ёжҳ“еҸ—ж”»еҮ»зҡ„ windowscodecs.dll жһ„е»әзүҲжң¬зҡ„зі»з»ҹгҖӮз»„з»Үеҝ…йЎ»дјҳе…Ҳжӣҙж–°д»ҘйҷҚдҪҺйЈҺйҷ©пјҢеӣ дёәжјҸжҙһеҲ©з”ЁеҸҜиғҪдёҺе…¶д»–ж”»еҮ»й“ҫз»“еҗҲпјҢе®һзҺ°зҪ‘з»ңжЁӘеҗ‘з§»еҠЁгҖӮ

![]()

### еҲ©з”ЁжңәеҲ¶дёҺжҰӮеҝөйӘҢиҜҒ

еҲ©з”ЁВ **CVE-2025-50165**В йңҖиҰҒжһ„йҖ еңЁи§Јз Ғж—¶и§ҰеҸ‘жҢҮй’Ҳи§Јеј•з”Ёзҡ„ JPEGпјҢйҖҡеёёйҖҡиҝҮ Office жҲ–з¬¬дёүж–№еә”з”Ёдёӯзҡ„еөҢе…Ҙж–Үд»¶е®һзҺ°гҖӮ

еҜ№дәҺ 64 дҪҚзі»з»ҹпјҢж”»еҮ»иҖ…йҖҡиҝҮеңЁеӨ§е°ҸдёәВ **0x3ef7 зҡ„е Ҷеқ—дёӯжһ„е»әйқўеҗ‘иҝ”еӣһзҡ„зј–зЁӢпјҲROPпјүй“ҫ**В з»•иҝҮжҺ§еҲ¶жөҒдҝқжҠӨпјҲCFGпјүгҖӮиҝҷйҖҡиҝҮВ `VirtualAlloc`В еҲӣе»әиҜ»-еҶҷ-жү§иЎҢеҶ…еӯҳе№¶еҠ иҪҪ shellcodeпјҢе®һзҺ°жҢҒд№…еҢ–и®ҝй—®гҖӮ

![]()

Zscaler зҡ„жҰӮеҝөйӘҢиҜҒйҖҡиҝҮзӨәдҫӢеә”з”Ёжј”зӨәе Ҷж“ҚзәөпјҡеҲҶй…ҚгҖҒйҮҠж”ҫе’ҢеӨ„зҗҶ Base64 зј–з Ғзҡ„ JPEGпјҢжңҖз»Ҳе®һзҺ° RIP жҺ§еҲ¶гҖӮ

е°Ҫз®Ўе°ҡжңӘжҠҘе‘ҠйҮҺеӨ–еҲ©з”ЁжЎҲдҫӢпјҢдҪҶВ **дҪҺеӨҚжқӮеәҰе’Ңе№ҝжіӣзҪ‘з»ңиҰҶзӣ–**В дҪҝе…¶жҲҗдёәеӢ’зҙўиҪҜд»¶жҲ–й—ҙи°Қжҙ»еҠЁзҡ„дё»иҰҒзӣ®ж ҮгҖӮ32 дҪҚзүҲжң¬й»ҳи®ӨзҰҒз”Ё CFGпјҢйҷҚдҪҺдәҶеҜ№ж—§зі»з»ҹзҡ„ж”»еҮ»йҡҫеәҰгҖӮ

з”ЁжҲ·еә”з«ӢеҚійҖҡиҝҮ Windows Update еә”з”ЁВ **2025е№ҙ8жңҲиЎҘдёҒжҳҹжңҹдәҢжӣҙж–°**пјҢдјҳе…Ҳй’ҲеҜ№й«ҳд»·еҖјиө„дә§гҖӮзҰҒз”ЁйӮ®д»¶е®ўжҲ·з«Ҝдёӯзҡ„иҮӘеҠЁеӣҫеғҸйў„и§ҲпјҢе№¶еҜ№дёҚеҸҜдҝЎж–Үд»¶е®һж–ҪжІҷз®ұйҡ”зҰ»гҖӮZscaler е·ІйғЁзҪІеҹәдәҺдә‘зҡ„йҳІжҠӨжҺӘж–Ҫд»Ҙйҳ»жӯўжјҸжҙһеҲ©з”Ёе°қиҜ•гҖӮ

жӯӨдәӢд»¶еҮёжҳҫдәҶдјҒдёҡзҺҜеўғдёӯжңӘжү“иЎҘдёҒеӣҫеҪўеә“зҡ„еҚұйҷ©вҖ”вҖ”JPEG еңЁе·ҘдҪңжөҒдёӯж— еӨ„дёҚеңЁгҖӮ

йҡҸзқҖеЁҒиғҒиЎҢдёәиҖ…дёҚж–ӯжј”еҸҳжҲҳжңҜпјҢ**еҸҠж—¶жү“иЎҘдёҒд»ҚжҳҜжҠөеҫЎжӯӨзұ»вҖңеғҸзҙ зә§жҜ’иҚҜвҖқзҡ„жңҖејәйҳІеҫЎ**гҖӮзӣ®еүҚе°ҡжңӘи§ӮеҜҹеҲ°дё»еҠЁеҲ©з”ЁпјҢдё»еҠЁжҺӘж–ҪеҸҜйҳІжӯўеӨ§и§„жЁЎжҚҹе®ігҖӮ
