2026年7月29日，Anthropic 旗下的 Claude AI 服务出现全球性中断。大量用户报告无法正常使用 Claude，请求失败并返回“529 Overloaded”错误信息。Anthropic 已正式确认多个 AI 模型出现高错误率，并正在积极修复。

![](https://mmbiz.qpic.cn/mmbiz_png/ft6csZH0gNWfWrh7uiav4FcnxfsqVTtJmsLqZ2QiaeebERZadHrNE1ty0kEicDnMWDu1COmCWMxa6pXEcwO4GuaIxyyic94nq4Z0Mw5wHBVsgMA/640?wx_fmt=png&from=appmsg)

据 BleepingComputer 报道，Anthropic 于 UTC 时间 7月29日晚上7:49开始调查此次故障。到晚上8:33，公司表示已定位问题，正在着手解决，但未公开具体原因，也没有给出明确的恢复时间表。

故障期间，用户反复看到类似提示：“API Error: 529 Overloaded. This is a server-side issue, usually temporary — try again in a moment.” 529 错误通常意味着服务器无法应对当前请求量，属于服务端过载问题。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/ft6csZH0gNVnWIHbtGz8jO5OVUCRs1aBD26yWVfpQqEkxNtLic1qb1iaVAMCgyqoaQ8Jxj5MEJmUKUBpnww1tjP1kOibiagyC5YBJIPBZ8r67QI/640?wx_fmt=png&from=appmsg)

之后 Anthropic 发布更新：截至美东时间 17:30，公司仍在全力解决导致 Claude 模型请求量和延迟升高的问题。目前大部分模型已开始恢复，但仍有部分用户可能继续遇到错误。

此次中断影响了直接使用 Claude 网页版、应用以及依赖其 API 的第三方工具。不少开发者和日常用户表示工作与学习受到影响，有人调侃“现在怎么写代码”。

目前 Anthropic 尚未公布故障的根本原因。AI 服务近年来频繁出现大规模中断，反映出高并发场景下基础设施压力仍较大。用户可关注 Anthropic 官方状态页面或社交媒体，获取最新恢复进展。
