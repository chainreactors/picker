* Send stored response, item, conversation and container IDs back only to the endpoint that created them, via `Model.accepts_server_state` by [@DouweM](https://github.com/DouweM) in [#11774](https://github.com/pydantic/pydantic-ai/pull/11774)

* Turn off strict tool schemas for `Coder`'s tools by default, with `Coder(strict=True)` to opt in by [@mpfaffenberger](https://github.com/mpfaffenberger) in [#11743](https://github.com/pydantic/pydantic-ai/pull/11743)
* Surface every nested `RepoContext` instruction file between a traversed path and the working directory, without repeating the root file by [@DouweM](https://github.com/DouweM) in [#11687](https://github.com/pydantic/pydantic-ai/pull/11687)
* Add `output_speech_timestamps` to report word timing of realtime speech, on Azure AI Voice Live by [@DouweM](https://github.com/DouweM) in [#11685](https://github.com/pydantic/pydantic-ai/pull/11685)
