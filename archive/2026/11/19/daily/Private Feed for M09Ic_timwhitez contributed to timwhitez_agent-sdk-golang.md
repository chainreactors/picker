## Summary

Fixes `jobObjectExtendedLimitInfo` ABI mismatch on `windows/386` so `SetInformationJobObject(JobObjectExtendedLimitInformation)` receives the exact 112-byte Win32 layout rather than 108 bytes.

* **`sdk/tools/execrunner/process_group_windows_386.go`**: adds explicit 4-byte tail padding to `jobObjectBasicLimitInformation` on `windows/386` (matching MSVC x86's 8-byte `LARGE_INTEGER` alignment: basic header `48`, `IOInfo` `@ 48`, `ProcessMemoryLimit` `@ 96`, total `112`) with compile-time layout assertions.
* **`sdk/tools/execrunner/process_group_windows_64bit.go`**: preserves the 64-bit layout on `windows/amd64` and `windows/arm64` (basic header `64`, `IOInfo` `@ 64`, `ProcessMemoryLimit` `@ 112`, total `144`) with compile-time layout assertions.
