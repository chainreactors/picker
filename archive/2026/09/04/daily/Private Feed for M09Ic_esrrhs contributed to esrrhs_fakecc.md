## Summary

Enable the `sizeof-macros-1.c` test by adding support for the missing GCC predefined size/type macros and the `__WINT_TYPE__` typedef.

## Changes

* **`src/lexer.c`**: Added 5 missing `__SIZEOF_*` predefined macros:
  + `__SIZEOF_SHORT__` → `2`
  + `__SIZEOF_SIZE_T__` → `8`
  + `__SIZEOF_WCHAR_T__` → `4`
  + `__SIZEOF_WINT_T__` → `4`
  + `__SIZEOF_PTRDIFF_T__` → `8`
* **`src/ast.c`**: Added `__WINT_TYPE__` typedef (4-byte signed int, matching `__WCHAR_TYPE__`)
* **`test/compile/SKIPPED.txt`**: Removed `sizeof-macros-1.c` from the skip list
* **`test/compile/sizeof-macros-1.c`**: Added compile-only test (GCC torture, sizes verified at compile time)
* **`test/e2e/cases/types/sizeof_macros.c`**: Added e2e runtime test that difftests fakecc vs gcc (exit 0 when all sizes match)
