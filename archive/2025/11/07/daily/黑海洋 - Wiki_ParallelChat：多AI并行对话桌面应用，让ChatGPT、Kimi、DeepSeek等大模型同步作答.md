## 一次提问，多个AI同时作答

ParallelChat是一款开源的多AI协作桌面应用，让你在同一个界面中并行使用多个主流大模型，包括ChatGPT、DeepSeek、Qwen、GLM、Kimi、Doubao、Yuanbao、Grok等。无需API Key或Token，直接使用各AI官网的原生能力，保持最纯净、无广告的体验。

![](https://cdn.skyimg.net/up/2025/11/7/d5b7b367.webp)

### 让对话更高效、更全面

ParallelChat专为创作者、研究者与开发者设计，通过多模型同步回答，你能快速对比不同AI的理解方式与内容质量，从而取长补短，生成更精准的思路或输出。

* **高效比较**：在同一窗口对比多个AI的回答
* **快速决策**：让不同AI的观点成为你的参考面
* **提升质量**：融合多源智能，获得更完整的输出

### 核心特性

* **完全免费**：无需API Key或额外付费，直接连接各AI官网
* **主流模型齐全**：覆盖ChatGPT、DeepSeek、Qwen、GLM、Kimi、Doubao、Yuanbao、Grok等
* **两种使用模式**：
  + *标签模式*：每个AI独立页面，适合专注阅读
  + *分组模式*：多个AI并列展示，便于对比与分析

* **数据安全**：所有对话与缓存存储于本地，用户可随时清理，无上传风险

* **快捷操作**：支持键盘Tab切换与分组自定义，让交互更流畅

### 使用指南

1. 前往官网 [parallelchat.top](https://blog.upx8.com/go/aHR0cHM6Ly9wYXJhbGxlbGNoYXQudG9wLw "ParallelChat") 下载并安装（下载地址：[网盘下载](https://blog.upx8.com/go/aHR0cHM6Ly9wYW4ucXVhcmsuY24vcy8zMTczMzA0NmM1Y2Y "ParallelChat：多AI并行对话桌面应用")）
2. 打开模型管理，启用你需要的AI
3. 登录对应AI账号
4. 选择“标签模式”或“分组模式”开始使用
5. 可在顶部标签间使用快捷键Tab自由切换

npm install
npm start
