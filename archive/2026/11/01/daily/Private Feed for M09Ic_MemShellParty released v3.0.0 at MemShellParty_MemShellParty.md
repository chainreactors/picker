### Added

1. 新增内存马与探测马字节码混淆，支持混淆范围（内存马 / 注入器 / 辅助类）与 `key=value` 选项（[#13](https://github.com/MemShellParty/MemShellParty/issues/13) Thanks [@4ra1n](https://github.com/4ra1n) and [https://github.com/jar-analyzer/class-obf）](https://github.com/jar-analyzer/class-obf%EF%BC%89)
2. 新增 RawWebSocket 内存马类型，覆盖 Tomcat / Jetty / GlassFish / WebSphere / WebLogic / Undertow / Apusic / Resin（[#25](https://github.com/MemShellParty/MemShellParty/issues/25)）
3. 新增无文件 Agent：Linux amd64/arm64（HotSpot、OpenJ9）与 Windows x64，无需落地 Agent JAR 即可获取 `Instrumentation` 并完成注入（[#56](https://github.com/MemShellParty/MemShellParty/issues/56)）
4. Agent 内存马支持持久化注入（`persist=true`）与复原 `restore=true`；
5. boot 内置 MCP Server（Streamable HTTP，端点 `/mcp`），提供 `memshell_capabilities`、`generate_memshell`、`generate_probe_shell` 三个工具
6. (UI) 新增 Java Swing 桌面端：完整发行版内置全部 server 与 shelltool，提供内存马 / 探测马 / CFR 反编译界面；另发布 `memshell-party-gui-sdk`，可只引入生成器与反编译 frame，通过 `GuiExtension` 接入自己的客户端（[#84](https://github.com/MemShellParty/MemShellParty/issues/84) By [@ReaJason](https://github.com/ReaJason)）
7. 新增 Woodpecker 插件（Helper 页签内直接生成内存马 / 探测马）
8. 新增字节码工具（Web / API）：Base64 / GzipBase64 与 class 互转、改父类与包名前缀、添加 main / 入口方法、随机类名与缩小字节码、模块限制绕过、静态初始化触发（[#79](https://github.com/MemShellParty/MemShellParty/issues/79)）
9. 探测马新增 ResponseHeader 探测方式；未知中间件可先探测服务类型，Spring WebMVC / Struts2 场景会拼接容器类型（[#161](https://github.com/MemShellParty/MemShellParty/issues/161) Thanks [@ViCrack](https://github.com/ViCrack)）
10. 新增内置 GodzillaSession 工具（每个会话独立注入并随会话释放）；哥斯拉 4.15 内置 WebSocket 通道可与 GzWebsocket 插件共用同一内存马（[#159](https://...
