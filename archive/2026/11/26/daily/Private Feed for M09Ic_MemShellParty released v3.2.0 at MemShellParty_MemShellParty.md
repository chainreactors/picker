[`61d7289`](/MemShellParty/MemShellParty/commit/61d72897f465087f812ef1d280a420a6b90095a8)

### Added

1. `AbstractServer` 新增插件扩展钩子，支持自定义模板类加载器、最低目标 JDK、shell 包名/类名、注入器字节码后处理及工具模板映射覆盖（`getToolMappingOverrides()`）
2. 新增 `PluginBootstrap.validate(Path)` 只读校验插件目录（SPI 实现、注入器与工具模板、映射覆盖及 packer 元数据）
3. REST `GET /api/config/servers` 暴露各 server 的最低目标 JDK
4. 自定义 shelltool 远程选项改为服务端数据源，新增 REST 选项接口与 MCP `list_remote_options`，支持按 `keyPath` 解析对象字段并按通道转发 `PLATFORM` 凭据
5. boot 服务新增可配置认证模式（`memshell-party.auth.mode`：`OFF` / `ADMIN` / `PLATFORM`），覆盖 UI、REST 与 MCP；`ADMIN` 使用启动随机密码 Basic 认证，`PLATFORM` 支持按 REST/MCP 通道转发凭据至平台校验（兼容自签名 HTTPS）

### Fixed

1. 注入器模板缺少 `getClassName()` / `getBase64String()` 或开启 `staticInitialize` 却缺少无参构造时，改为生成前校验报错
2. 修复注入器映射中模板类名错误时仍暴露该 shell 类型的问题，`getSupportedShellTypes` 改为按模板字节是否存在过滤
3. 修复 `ViewController` UI 视图路径校验，白名单限制路径以防止路径穿越与表达式注入
4. (UI) 修复窄屏下标签页与混淆选项工具栏溢出，优化代码高亮、搜索、反编译面板与文档图片的按需加载

### Changed

1. 目标 JDK 下限改为由各 server 声明（SpringWebFlux、XxlJob 设为 Java 8），生成入口与 Web/桌面端同步生效，不再硬编码
2. Dubbo 支持拆分至独立仓库 [memshell-party-dubbo](https://github.com/MemShellParty/memshell-party-dubbo)，降低主仓库复杂度
3. Docker 基础镜像升级至 Temurin `21.0.13+9` 与 Bun `1.4.4`

**Full Changelog:** [v3.1.0...v3.2.0](https://github.com/MemShellParty/MemShellParty/compare/v3.1.0...v3.2.0)

Web 端内置 Web 界面、REST API 与 MCP Server（<http://127.0.0.1:8080/mcp>），需 JDK 17 及以上。

Docker 部署：

```
docker rm -f memshell-party

docker run --pull=always --rm -it -d -p 8080:8080 --name memshell-party reajason/memshell-party:latest
```
