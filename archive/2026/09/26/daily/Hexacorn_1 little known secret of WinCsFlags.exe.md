# 1 little known secret of WinCsFlags.exe

Posted on [2026-09-26](https://www.hexacorn.com/blog/2026/09/26/1-little-known-secret-of-wincsflags-exe/ "10:40 pm")  by  [adam](https://www.hexacorn.com/blog/author/adam/ "View all posts by adam")

The *WinCsFlags.exe* program accepts an undocumented command line argument “-w”.

When you invoke it like this:

```
WinCsFlags.exe -w
```

it will go into a never-ending loop waiting for the debugger to be attached.
