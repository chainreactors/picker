数据安全风险评估系统已可部署到测评师本地，安装包和key请请微信联系飞度小二（th0987667891）。

**01**

**产品简介**

数据安全风险评估系统是一款面向企业数据安全合规场景的专业评估工具，覆盖 通用、网信、工业、电信四大领域评估模块，内置标准化评估流程与报告模板，支持从资产梳理、数据处理活动分析、风险识别、风险评价到报告导出的全流程线上化管理，帮助企业快速完成数据安全风险评估并一键生成规范评估报告。

本版本核心亮点：

- 硬件授权升级：全面启用USB授权Key（加密狗）强制校验，一机一钥，杜绝未授权使用。

- 报告导出优化：导出全程页面内提示，自动清理同名旧报告，只保留最新版本。

- 稳定性增强：数据库结构自动升级，存量数据零丢失平滑迁移。

**02**

**运行环境**

|  |  |
| --- | --- |
| 项目 | 要求 |
| 操作系统 | Windows10/11/Server2016及以上（64 位） |
| 硬件 | 授权Key一枚（部署时插入服务器USB口并长期保持插入） |
| 网络 | 单机部署即可运行，局域网内可多终端浏览器访问 |
| 浏览器 | Chrome/Edge等现代浏览器 |

免安装、免依赖：系统为单文件绿色版，无需安装 Python或数据库，解压即用。

**03**

**全新部署**

1. 解压安装包：将`数据安全风险评估系统\_客户版.zip` 解压至目标目录（如`D:\风险评估系统\` ），解压后目录包含`run.exe` 等。

2. 插入授权 Key ：将随货USB Key插入本机 USB 接口。

3. 启动系统 ：双击`run.exe` ，出现服务启动日志即表示运行成功（系统监听 15999 端口）。

4. 访问系统 ：浏览器打开`http://127.0.0.1:15999` ，登录后请立即修改密码 ，局域网访问：将 127.0.0.1 替换为服务器 IP 即可，如`http://192.168.x.x:15999`。

**04**

**日常使用流程**

登录系统→创建评估项目（选择领域）→填写评估对象与范围→录入数据处理活动情况→风险识别→风险分析与评价→整改建议 →一键导出评估报告（Word）。

- 各页面表格均支持 页面内直接编辑，填写即保存

- 项目列表操作按钮全部在当前窗口完成，导出时按钮下方显示进度提示。

- 拔出Key后系统将自动拦截登录与报告导出，插回即可恢复。

**05**

**日常升级指引**

已有数据的客户请使用升级补丁包，切勿用全新安装包覆盖：

1. 退出正在运行的系统。

2. 备份整个安装目录。

3. 将补丁包中的文件夹覆盖到安装目录。

4. 以下三个目录保持原样不动 ：

   - `data\data\_security\_risk.db` （业务数据）

   - `app\static\uploads\` （上传附件）

   - `reports\` （已生成报告）

5. 插入授权Key，双击`run.exe` 启动——数据库结构将自动完成升级 ，存量项目与数据完整保留。

**06**

**注意事项**

- 授权 Key 为系统运行凭证，请妥善保管、长期插入；登录、导出报告均需 Key 在线。

- 更换服务器时，整体拷贝安装目录并携带 Key 即可迁移。

- 建议定期备份`data\` 目录。
