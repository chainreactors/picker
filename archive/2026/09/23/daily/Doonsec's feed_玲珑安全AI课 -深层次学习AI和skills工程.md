玲珑安全AI课秉承授人以鱼不如授人以渔的原则进行，不是直接卖skills，而是教你理解、沉淀自己的skills。

AI 正在改变安全研究的方式。这套 17 节直播课（每节 60 分钟），不是编程课，而是"AI 驱动安全"的实战指南。

* 从 0 搭 AI 助手： 讲清大模型和 AI 工具基础，教你用 AI 做 Web 漏洞挖掘。
* Agent 原理与开发： 搞懂 Agent 运行机制，学 Prompt 进阶、多 Agent 协同。
* 核心实战： 覆盖 AI 漏洞挖掘、报告撰写、自动化测试，以及实战技巧 + Agent 行为可视化 + 红线标准。
* 攻防兼顾： 不只教你用，还教你防，了解提示词注入等 AI 自身风险，研究 AI 红队攻防。
