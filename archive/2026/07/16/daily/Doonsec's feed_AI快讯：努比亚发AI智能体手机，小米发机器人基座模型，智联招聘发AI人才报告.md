→DeepSeek首轮融资落地

7月15日，企查查信息显示，DeepSeek关联公司完成融资相关的股权变更及工商登记调整。杭州深度求索人工智能基础技术研究有限公司新增杭州程砺企业管理咨询合伙企业、国家人工智能产业投资基金合伙企业为股东，注册资本增加至1644.75万元。

同时，DeepSeek创始人梁文锋退出杭州程砺企业管理咨询合伙企业股东，该合伙企业新增腾讯、宁德时代、京东等关联公司为股东，注册资本也由0.4万元增至14.02亿元。

→努比亚发布首款AI智能体手机NaviX Ultra

7月16日，努比亚在北京正式发布全球首款AI智能体手机NaviX Ultra。该机搭载豆包手机助手，配备专属橙色AI键及横向后置摄像模组，提供黑、粉、银、紫四色选择。努比亚技术有限公司总裁倪飞此前宣布公司已完成智能体大模型备案。该机型获2026世界人工智能大会SAIL卓越人工智能引领者奖。大会将于7月17日至20日在上海举行，NaviX Ultra为首批全球首发新品之一。

→MiniMax Code将上线远程控制、浏览器操控等功能

7月16日消息，MiniMax宣布更新MiniMax Code 2.0桌面端。MiniMax Code 2.0桌面端现已开放下载，重点改善长任务执行过程中的等待、中断与上下文衔接问题。此外，MiniMax Code将在本月上线远程控制、浏览器操控，目标模式、计划模式等功能，进一步扩展处理复杂任务和跨环境协作的能力。

→汇丰英国联合Visa落地首笔端到端AI智能体支付交易

汇丰英国与Visa展开合作，共同研发AI驱动的购物支付方案，搭建安全支付技术体系，支撑银行卡在AI智能体商业场景中合规、可控完成支付。AI智能体购物可简化出行预订、日用采购、商品筛选等日常消费流程，节省用户操作时间；整套流程设置清晰权限管控与安全防护机制，用户全程掌握交易决策权。

→混元大模型Hy3上线一周，总调用量增长超68倍

7月15日，腾讯混元大模型Hy3总调用量较上一代模型（Hy2）增长超68倍。延续Hy3 preview版本的增长态势，Hy3展现出更高的增长斜率。发布一周后，Hy3在OpenRouter全球大模型调用量总榜排名第一。在Agent产品中，Hy3也展现出更强的竞争力，WorkBuddy自选模型的用户中，选择Hy3的占比达到60%。

→摩根大通CEO戴蒙警告Mythos不宜广泛开放

摩根大通首席执行官杰米·戴蒙表示，Anthropic PBC的Mythos人工智能(AI)模型带来的风险是一个“现实问题”，美国政府目前已高度关注。近几个月来，AI模型的快速发展促使业界和政府评估潜在威胁。

此前，Anthropic称其Mythos模型在发现软件漏洞方面非常出色，以至于不能向公众发布，这使得该问题变得更加紧迫。戴蒙周三在参议员Dave McCormick的宾夕法尼亚防务与创新峰会上警告称，将一个先进的系统开放给广大人群使用存在风险。“让个人使用Mythos，基本上相当于把弹道导弹交到他们手里，”他说。

→小米发布机器人基座模型Xiaomi-Robotics-1

小米机器人事业部发布Xiaomi-Robotics-1，一个面向真实移动操作任务的具身基座模型。模型基于10万小时真实世界数据进行预训练，并结合跨本体数据完成后训练。完成后训练后，Xiaomi-Robotics-1即可在真实环境中，根据自然语言指令直接执行多类移动操作任务。

→英伟达与日本企业扩大机器人合作

英伟达与日本四家工业自动化企业宣布，将扩大机器人开发领域的合作。富士通、发那科、川崎重工业和安川电机将加入由英伟达主导的Cosmos联盟。该联盟旨在加快采用英伟达平台发展业内所谓“物理AI”。物理AI涵盖广泛的硬件应用，包括人形机器人、工厂自动化、自动驾驶汽车，以及智能建筑和轨道交通系统等。日立制作所、日本电气、小松制作所和久保田也将加入该联盟。

→马斯克旗下SpaceXAI宣布开源Grok Build

马斯克旗下SpaceXAI宣布开源Grok Build，并重置所有用户的使用限制。针对用户关于隐私的问题，公司表示，自上线以来，Grok Build完全尊重零数据保留（ZDR）原则。所有用户始终能够在命令行界面中禁用数据上传。在早期测试版中，非ZDR用户默认启用了数据保留。自7月12日起，公司已为所有GrokBuild用户禁用默认数据保留，此外正在删除之前保留的所有编码数据，确保每位用户的偏好得到尊重。

→Anthropic最快或10月挂牌

据报道，AI初创公司Anthropic已开始安排管理层与潜在投资者会面，为首次公开募股做准备。报道称，高盛、摩根士丹利和摩根大通担任承销商，公司最快或于今年10月登陆美股。Anthropic已于6月向美国证券交易委员会秘密递交IPO申请文件，今年5月完成一轮融资后估值达965亿美元，高于OpenAI当时约852亿美元的估值。

→美联储主席沃什：寻求获取一系列新型AI模型权限

7月15日，美联储主席沃什表示，正在寻求获得一系列新型人工智能模型的权限。他指出，目前看到人工智能对需求的影响比对供给的影响更快。据介绍，沃什在参议院听证会上称，人工智能基础设施建设带来的价格上涨并不一定会刺激通货膨胀。他强调相关投资虽推高了芯片价格，但一次性价格变动未必引发通胀，因供给侧会作出回应，并预计AI将提高生产率和薪资。

在就业影响方面，沃什相信长期来看AI能创造就业，但过程可能带来扰动。他主张为AI发展营造宽松的监管环境以保持美国的国际领先地位，强调美联储政策将基于数据判断AI对通胀的最终影响。

→豆包正式下线自建拟人化智能体功能

7月15日，字节跳动旗下AI产品豆包正式下线用户自建的拟人化智能体功能。该调整与《人工智能拟人化互动服务管理暂行办法》同步施行。此次功能调整严格限定于用户自行创建的虚拟角色扮演、情感陪伴对话等带有拟人化交互特征的功能。目前用户无法新建智能体，也无法调取已有智能体进行对话。

不过，问答、文案生成、AI绘画等基础工具型能力仍可正常使用。针对已创建智能体的用户，字节跳动预留了从7月15日至10月15日的三个月数据备份缓冲期。

→天津：加强人工智能生成内容（AIGC）在广告领域研发应用

天津市人民政府办公厅印发《天津市推动广告产业高质量发展行动方案（2026—2028年）》。方案提出，壮大数字广告新业态。加快海河传媒等传统媒体广告数字化转型，推动传统媒体与新媒体有机融合，提升广告传播效果和营销水平。开展“人工智能＋数字广告”推广行动，着力以大数据、云计算等技术赋能广告产业，支持广告设计制作、效果监测等软硬件研发应用，加强人工智能生成内容（AIGC）在广告领域的研发应用；支持广告企业租用智能算力或超级算力资源，开展本领域人工智能垂类大模型训练推理、数据标注、数据分析等算力应用。

→IDC报告：阿里位居中国AI编程市场份额第一

国际咨询机构IDC发布2025年中国AI编程市场份额报告，报告显示，阿里以47.6%的营收市场份额位居第一，超第二名至第五名总和。

→京东京麦AI经营中心上线，开放22款AI工具

7月16日，京东在京麦平台正式上线AI经营中心，面向全体商家全量开放22款核心AI工具。该中心集工具赋能、专家智囊与智能托管于一体，覆盖超百项日常经营场景，可解决50余项高频痛点，贯穿智能诊断、策略执行到全店托管全流程。此举旨在提升商家运营效率与决策智能化水平，助力中小商家降本增效。

→英伟达发布多款物理AI产品 推出两款机器人计算模组

7月16日，英伟达宣布推出Thor架构的机器人计算模组Jetson T2000和T3000，以推动硬件进入更多机器人细分市场。Jetson T2000在40瓦功耗下算力为400TFLOPS，T3000在70瓦功耗下算力为865TFLOPS。

这两款计算机算力低于Jetson T5000的2000TFLOPS，但高于Jetson AGX Orin的算力。 据介绍，两款新计算模组将于明年第一季度上市，上市后英伟达的Jetson计算模组将覆盖从70TOPS到2000TFLOPS算力范围，补齐在视觉AI代理、自主移动机器人及工业机械臂等入门级市场的布局。

→金山办公发布两款AI办公智能体

7月15日，金山办公在2026 AI生产力大会上发布两款AI办公智能体，包括面向个人的“灵犀专业版”与面向组织的“WPS Comate”。灵犀专业版可理解用户工作上下文，联动WPS文档内核及外部工具，将自然语言指令转化为可编辑、可追溯、支持多人协作的办公成果。

WPS Comate则支持Skill技能生态与自动化任务。WPS Comate可连接组织数据、系统与流程，让AI融入组织工作流并交付业务结果，提供覆盖全工作场景的六大模块，推动办公范式从人操作软件转向人提目标、AI完成。

→智联招聘发布AI人才报告

7月16日，基于平台2026年上半年数据，智联招聘发布《2026年人工智能产业人才发展报告》。数据显示，人工智能行业招聘企业数同比增长24.8%，职位数同比增长10.6%。

据介绍，地域分布上，一线与新一线城市合计贡献AI行业65%招聘需求。一线城市中，北京人工智能行业体量最大，上海职位数增速最快。长沙、武汉、成都等新一线城市人工智能行业招聘增速领跑。

具体领域上，人工智能工程师需供比达2.62，AI产品经理以87.7%职位数增速领跑。AI智能体开发人才需求同比增长244%，AI正从“辅助工具”走向“自主执行”。汽车研发/制造行业的人工智能工程师人才缺口较大，需供比达8.2。

→日本拟采购2.75万颗英伟达Rubin芯片，开发本土机器人AI模型

据相关报道，日本计划采购2.75万颗英伟达(NVDA.O)下一代Rubin芯片，用于开发本土基础机器人AI模型。 新成立的Noetra公司已从政府财政中获得3873亿日元拨款，公司表示将负责统筹该项目并建设一座大型数据中心。这一计划是日本政府降低对外国技术依赖、加强国家安全一系列举措的一部分。Noetra计划于明年3月前发布首个AI模型，并持续进行更新。Noetra总裁Hironobu Tamba表示，长期目标是在未来几年推出专门面向机器人应用的AI模型。开发本土物理人工智能模型是日本打造全球领先人工智能和机器人产业中心总体战略的重要组成部分。日本政府的目标是，到2040年占据全球约60万亿日元机器人市场30%以上的份额。
