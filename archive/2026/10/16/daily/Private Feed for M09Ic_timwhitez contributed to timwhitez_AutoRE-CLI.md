The verifier now validates the entire generated wrapper with the reader's structure policy inside the existing recovery block before exclusive creation. If owned-root cleanup fails, its diagnostic retains the first error and exact recovery path.

Tests cover 1024/1025 entries, whole-wrapper 4096/+1 values, depth and encoded-byte boundaries, Unicode/JSON escaping, real writer-reader-cleanup, failure recovery and ownership protections. The read-only test receipt is made writable only before fixture deletion on Windows. Only the three affected checksum rows change. Release binaries, versions, provenance and release archives are unchanged.
