Two fields on `GetParserConfigResponse` so plugins declare when their projects should be dropped, instead of config hardcoding it per format:

* `exclude_if_repo_contains` — drop my projects if these types exist anywhere in the repo. terraform sets `["terragrunt"]`.
* `exclude_if_inside` — drop my projects if these types own a parent dir. cloudformation sets `["terraform", "terragrunt"]`.

Additive, empty by default, nothing reads them yet. Unblocks FIX-592, where the hardcoded version of the second rule dropped ~2.9k projects with no diagnostic.
