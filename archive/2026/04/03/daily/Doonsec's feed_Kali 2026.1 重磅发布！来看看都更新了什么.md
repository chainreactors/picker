Kali Linux 作为全球网络安全从业者、渗透测试工程师首选的专业 Linux 发行版，正式推出 2026 年首个重大版本更新 ——Kali Linux 2026.1。本次更新承接 2025 年年底 2025.4 版本的迭代优化，既延续了发行版一贯的年度主题焕新传统，也带来了致敬行业经典的怀旧功能、多款重磅安全工具、内核版本升级，同时在移动端 NetHunter 生态实现了多项里程碑式突破，为全球安全爱好者与从业者带来了诚意满满的全维度升级。

## 一、2026 全新主题全面焕新

和历年的 xx.1 版本一致，Kali 2026.1 带来了一年一度的全链路主题焕新，这一长期坚持的传统，让 Kali Linux 的界面始终保持现代化的设计与创新的交互体验。本次主题更新覆盖了系统从启动到使用的全流程，从开机的第一秒就能感受到全新的视觉体验。

* **启动动画优化**：本次更新对启动动画进行了细节打磨，修复了 Live 镜像启动时动画卡在开头、仅显示尾部的问题；同时新增了长启动流程下的动画循环重启机制，让整个开机过程的动画表现更加流畅丝滑。
* **全场景界面焕新**：从 Grub 启动菜单、图形化安装向导，到系统登录界面，均采用了 2026 年度全新设计语言，同时为默认桌面与 Kali Purple 桌面分别定制了专属的主题样式，兼顾了渗透测试与防御安全双场景的视觉需求。

## 二、BackTrack 模式上线，致敬 20 周年里程碑

2026 年是 BackTrack Linux 的 20 周年诞辰，作为 Kali Linux 的前身，BackTrack 是无数网络安全从业者的启蒙发行版，早已成为行业内的传奇符号。为了纪念这一里程碑时刻，Kali 团队在 kali-undercover 工具中新增了**BackTrack 模式**，为老用户带来了满满的情怀与回忆。

该模式可以一键将 Kali 桌面完全还原为 BackTrack 5 的视觉风格，包括经典的壁纸、配色方案、窗口主题与交互细节，完美复刻了当年的使用体验。用户可以直接从系统菜单启动该模式，也可以在终端执行`kali-undercover --backtrack`命令一键开启，再次执行相同命令即可切换回默认的 Kali 桌面，切换便捷且不影响系统原有功能。

## 三、Kali 13 周年社区活动与贡献致谢

本次更新同期，Kali Linux 迎来了自己的 13 岁生日。为了回馈社区长期以来的支持，官方在 Discord 社区举办了专属解谜活动与奖品抽奖，目前活动前三名已决出，但仍会持续开放一段时间供社区用户参与挑战。

同时，官方也对本次版本迭代中做出贡献的社区成员进行了公开致谢，涵盖了软件打包、文档维护、社区共建等多个维度。来自社区的 Tristram 也发表了寄语，强调了网络安全领域红蓝队协同的重要性，呼吁攻防两端的从业者通过知识共享与协作，共同推动整个安全生态的韧性提升，也让 Kali 社区的开源共建精神得到了进一步的传递。

## 四、8 款全新安全工具上线，内核升至 6.18

每一次 Kali 版本更新，新增的安全工具都是从业者最关注的核心内容。本次 Kali 2026.1 在官方软件源中新增了 8 款重磅安全工具，覆盖了后渗透、攻防演练、漏洞检测、调试审计等多个核心场景，完整工具列表如下：

1. **AdaptixC2**：可扩展的后渗透与对抗模拟框架
2. **Atomic-Operator**：支持跨多操作系统环境执行 Atomic Red Team 测试的工具
3. **Fluxion**：专注于安全审计与社会工程学研究的专业工具
4. **GEF**：为 GDB 调试器打造的现代化增强工具，提供高级调试能力
5. **MetasploitMCP**：面向 Metasploit 的 MCP 服务组件
6. **SSTImap**：带交互式界面的自动化 SSTI（服务端模板注入）漏洞检测工具
7. **WPProbe**：高性能 WordPress 插件枚举工具
8. **XSStrike**：高级 XSS 漏洞扫描器

除了新增工具外，本次版本累计完成 25 个新软件包引入、9 个软件包移除与 183 个核心软件包的版本更新；同时将系统内核升级至**6.18 版本**，进一步提升了硬件兼容性、系统稳定性与安全防护能力。

### 已知问题提示

本次版本中，kali-tools-sdr（软件定义无线电）元软件包相关生态存在兼容问题，GNU Radio 相关组件状态不佳，已知 gr-air-modes、gqrx-sdr 等工具出现功能故障，可能影响同生态下的其他相关工具。官方已明确该问题将在下一个版本中修复，相关用户可暂缓升级，或临时规避相关工具的使用。

## 五、Kali NetHunter 多项重磅更新

作为 Kali 面向移动端的专属渗透测试平台，Kali NetHunter 在本次更新中完成了大量优化与突破，进一步释放了移动设备的安全审计能力：

1. **核心 App 优化**：完成了 App 底层代码清理，修复了 WPS 扫描 bug、HID 权限检测异常、返回键逻辑错误等多个长期存在的问题，提升了 App 的稳定性与易用性。
2. **设备适配升级**：为 Redmi Note 8（Ginkgo）适配了 Android 16 的全新内核；修复了三星 S10 系列的内部无线固件兼容问题，完美支持 reaver、bully、kismet 等工具的正常运行，大幅提升了该系列设备的 wardriving 能力。
3. **无线注入里程碑突破**：时隔数年，首个可正常工作的 QCACLD v3.0 无线注入补丁正式上线，该补丁有望适配绝大多数搭载高通芯片的手机设备，极大拓展了 NetHunter 的硬件支持范围。
4. **社区生态拓展**：官方上线了与 Nexmon 团队的专属播客内容，揭秘了移动端无线注入技术的研发历程；同时分享了社区爱好者基于 NetHunter 无根模式，将本田 Civic Type-R 改装为车载渗透测试平台的创意案例，展现了 NetHunter 极强的场景适配能力。

## 六、新增齐鲁工业大学官方镜像站

本次更新周期内，Kali 官方新增了 4 个全球镜像站，进一步提升了全球用户的下载与更新速度，其中就包括**中国齐鲁工业大学镜像站（mirrors.qlu.edu.cn）**，为国内用户提供了更稳定、更快速的软件源访问渠道。其余新增镜像分别来自阿塞拜疆、韩国与西班牙，官方也持续欢迎有充足磁盘空间与带宽资源的机构与个人参与镜像站共建。

## 七、一键升级至 Kali 2026.1

### 全新安装

用户可直接前往 Kali 官方下载页面，获取 2026.1 正式版镜像进行全新安装；若想提前获取最新的 bug 修复与软件更新，也可选择官方每周构建的自动化镜像（注：每周镜像无正式版同等的 QA 测试，可提前向官方反馈相关 bug）。

### 现有安装在线升级

若你已安装 Kali Linux，可通过以下命令一键完成全量升级，无需重装系统：

首先配置官方软件源：

```
echo "deb http://http.kali.org/kali kali-rolling main contrib non-free non-free-firmware" | sudo tee /etc/apt/sources.list
```

```
# 临时禁用 IPv6（重启后恢复）

# 重新尝试升级，加上 --fix-missing 修复缺失包
sudo apt update && sudo apt -y full-upgrade --fix-missing
```

同步系统配置文件：

```
cp -vrbi /etc/skel/. ~/
```

若有内核更新等需要重启的变更，执行重启命令：

```
sudo -i
[ -f /var/run/reboot-required ] && sudo reboot -f
```

### 版本验证

重启完成后，可通过以下命令验证是否成功升级至 Kali 2026.1：

```
# 查看系统版本
grep VERSION /etc/os-release
# 查看内核版本
uname -r
uname -v
```
