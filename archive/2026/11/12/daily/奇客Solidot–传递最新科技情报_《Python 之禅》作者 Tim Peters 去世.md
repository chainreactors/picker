## 《Python 之禅》作者 Tim Peters 去世

[![Python](https://icon.solidot.org/images/topics/topicPython.png?123)](/search?tid=114 "Python")

[Edwards](/~Edwards) (42866)发表于 2026年11月12日 16时30分 星期四 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85867&appkey=1370085986&title=%E3%80%8APython%20%E4%B9%8B%E7%A6%85%E3%80%8B%E4%BD%9C%E8%80%85%20Tim%20Peters%20%E5%8E%BB%E4%B8%96 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自十二魔**

Python 语言作者 Guido van Rossum 发表文章悼念了 2026 年 7 月 15 日去世的 Tim Peters（享年 74 岁）。他写道：Tim Peters 最为人熟知的贡献是撰写了《Python 之禅》，“但对我而言他是我的良师益友，也是这门语言的共同设计者之一。”Tim Peters 很早就接触了 Python 语言，说服 Guido 让 Pytho 支持整数（int）与浮点数（float）之间的混合运算，他在邮件列表上非常活跃，总是细致耐心回答用户的各种问题，以至于获得了 Timbot 这一绰号。他在 2002 年带来 一种全新的排序算法 Timsort，它后来被 Java 和 Android 采用。如果没有 Tim Peters，Python 绝不会有今天的模样。
