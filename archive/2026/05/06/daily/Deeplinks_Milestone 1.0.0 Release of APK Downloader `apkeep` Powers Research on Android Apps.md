Last week, we released [apkeep](https://github.com/EFForg/apkeep) version [1.0.0](https://github.com/EFForg/apkeep/releases/tag/1.0.0), the latest edition of our command-line Android package downloading software. Rather than indicating major changes for the project, this milestone instead signifies arriving at a relatively stable and mature place after gradual iteration on the project over the course of over four years.

**What’s New in** [**1.0.0**](https://github.com/EFForg/apkeep/releases/tag/1.0.0)

We do have a few fresh features we’ve packed into this latest release, though—all focused on the Google Play Store:

* You [can now download](https://github.com/EFForg/apkeep/pull/221) a [dex metadata](https://source.android.com/docs/core/runtime/configure) file associated with an app containing a [Cloud Profile](https://docs.cloud.google.com/profiler/docs), which provides information on app performance based on real usage.
