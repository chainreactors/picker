《防卫白皮书》是日本政府每年向内阁会议报告、由防卫省编纂并发布的年度安保政策文件，系统阐述其对周边安全环境的判断、防卫力量现状与政策走向，是日本安保战略取向的官方风向标。

2026年版（令和8年版，8月4日公布）是高市早苗内阁上台后首份完整版本，正文约598页。该版延续将中国定位为"前所未有的最大战略挑战"的基调，渲染"中国威胁"，并将俄乌危机经验包装为"新型作战方式"，首设独立章节；大幅扩容军工产业篇幅，新增强化防卫生产与技术基础、主要国家防卫费比较等内容；制度层面补入联合作战司令部、航空宇宙自卫队、通信防护与电子计算机警护、防卫装备转让三原则修订（实质放开杀伤性武器出口）等一揽子事项。

整体看，该白皮书以周边威胁叙事为铺垫，持续突破"专守防卫"与和平宪法约束，加速扩军备武，并为年内修订"安保三文件"、将军工与作战域向太空、网络、认知域、北极等方向拓展制造舆论，势必对地区战略稳定产生负面影响。

一、新型作战方式

1. “新型作战方式” 与相关课题

在乌克兰战场上，大量、廉价、多种多样的无人装备被投入使用，用于攻击高价值装备及生活基础设施，同时与传统炮弹和导弹相结合，实施大规模复合攻击。

在推进基于人工智能、网络的决策迅速化的同时，太空、网络、电磁波领域的作战与信息战被高度融合，形成综合性作战。此外，与以往相比，装备和战术在极短的周期内得到更新的情况也有所显现。

俄罗斯与乌克兰双方均被认为将装备、弹药的稳定采购视为一项课题。平时的储备以及确保持续性应对能力的重要性。

由此愈发凸显。与此同时，从同盟国·志同道合国家等处获取有效支援，也成为一项重要因素。

2.支撑“新型作战方式”的各类领域与前沿技术动向

太空·网络·电磁波领域及前沿技术，是“新型作战方式”中的重要因素。

在太空领域，人造卫星被用于强化指挥控制、通信、情报收集、警戒监视、侦察等能力，而反卫星武器等对太空装备构成的威胁正不断增大。在网络领域，包括对重要基础设施侵害在内的网络攻击已成为安全保障上的威胁；在电磁波领域，包含电子攻击在内的电子战及电磁波管理在现代作战中愈发重要。

支撑上述领域的人工智能技术、量子技术等前沿技术是技术开发快速推进的领域，此外，在信息战中，利用深度伪造及生成式人工智能制作的视频、图像等也正成为愈发严重的威胁。

3. 防卫生产技术基础相关动态

在美国，通过国防高等研究计划局及国防创新单元等机构，对前沿技术积极开展投资。

中国在题为《新时代的中国国家安全》的白皮书中，将新兴领域（网络、数据、人工智能等）的发展定位为国家安全保障的新领域，并指出前沿技术的发展对安全保障环境产生深刻影响。

北约为将高端新技术引入安全保障领域，设立了北大西洋防卫创新加速器。在2026年挑战计划中，DIANA将遴选150家企业，开发用以应对防卫·安全保障方面的课题（能源、太空作战、无人系统等）的两用技术。

各国正积极推进将AI、量子、半导体等先进技术应用于安全保障领域及对其实施管理。此外，各国将本国防卫生产技术基础视为国防所需的重要因素，正在推进支持国内企业参与、促进出口等各项举措。尤其是装备品的出口，不仅有助于强化防卫生产技术基础，还有助于加强与出口对方国之间的关系，因此各国正战略性地推进相关工作。

二、强化防卫生产与技术基础

1. 防卫生产基础强化法与基本方针

日本防卫产业承担装备品全寿命周期各阶段（研究、开发、生产、维持整备、补给、废止使用等），装备品与防卫产业密不可分。为维持和强化生产高端装备品并确保较高可动率的能力，防卫生产基础强化法于2023年施行。该法律规定防卫大臣须制定基本方针并于同年10月公布，取代2014年制定的"防卫生产·技术基础战略"，重新指明今后维持和强化防卫生产·技术基础的方向。

2. 防卫科学技术委员会的设置

作为就科学技术与安全保障相关课题向防卫大臣提供建议与提案的常设会议机构，防卫科学技术委员会于2025年6月设立，由精通人工智能、太空、网络等领域的学识与实务经验人士组成，截至2026年3月共召开6次会议。其设立动机在于扭转"仅以装备品功能与性能等自卫队内部需求为基础进行研究论证"的倾向，转而构建"通过防卫力整备提升科学技术实力、进而有助于国家整体国力提升"的结构，使防卫力整备同时服务于国家整体科技实力。

3. 防卫装备转移三原则及"5类型"废除

这是2026年4月修订的核心内容。修订后，在制度上原则上所有成品、零部件、技术及维修等劳务的提供均可转让，此举被其定位为提升地区威慑力、贡献地区和平稳定的举措，并拓展日本与各国开展新防卫装备·技术合作的可能性。通过修订，日本所有防卫装备原则上均可转让，由此通过转让强化同盟国及"志同道合国家"的威慑力与应对力，并与这些国家共同持有相同装备品、共享生产·维持整备基础，构建相互支援环境。

原有的"5类型"（救难、运输、警戒、监视、扫雷）限制框架被废除。白皮书给出的理由是，近年来人工智能、网络、太空等新领域与常规武器相融合，装备品与作战方式在极短周期内不断变化，将装备品套用"类型"已比以往更加困难。

三、制度性/法律性新增事项

1. 联合作战司令部（常设）的设立与职能

|  |  |
| --- | --- |
| 项目 | 内容 |
| 设立时间 | 2025年3月 |
| 所在地 | 市谷 |
| 首长 | 联合作战司令官 |
| 性质 | 常设联合司令部，是"部队"而非幕僚机关；系自卫队历来首次常设此前不具备的职能 |
| 核心职能 | 平时起对陆·海·航空自卫队实施一元化指挥；与美军在作战层面更紧密协调 |

在国家防卫战略及防卫力整备计划中，日本决定创设可对陆·海·航空自卫队部队实施统一指挥的常设联合司令部；据此，2025年3月以联合作战司令官为首的联合作战司令部在市谷正式设立。新设该司令部后，从平时起即将陆·海·航空自卫队统合作战的指挥事项统一归口其负责；由于平时即可培育跨领域作战能力，联合运用的实效性得到提升，能够持续进行迅速的事态应对与决策。该司令部是以平时起对全国陆·海·航空自卫队部队实施一元化指挥为出发点新设的"部队"，与以统幕长为首的统幕明确分担职责，其新设不改变统幕后者的职能。

2. 航空自卫队改编为航空宇宙自卫队

白皮书提出，要整备能够确保太空利用优势的体制，将航空自卫队升格为航空宇宙自卫队。为强化太空作战能力，稳步推进宇宙领域掌握（SDA）态势整备，新编以将官为指挥官的宇宙领域专业部队，同时将航空自卫队改编为航空宇宙自卫队。在第221届特别国会上，涉及将防卫副大臣由1人体制强化为2人体制、将航空自卫队改编为航空宇宙自卫队的防卫省设置法等部分修正法律案经表决通过，正式成立。文件在跨领域作战部分解释动机称，鉴于宇宙领域已不再是仅作监视的对象，而是实施作战行动的领域，因而将航空自卫队改编为"航空宇宙自卫队"，并明确2026年将通过发射宇宙领域把握卫星等方式强化宇宙领域把握能力，新编"太空作战集群"。

3. 通信防护措施与自卫队等电子计算机警护

两项均以"（2026年10月1日起施行）"标注施行日，分列于第二部第四章"自卫队的任务"项下（"通信防护措施"与"自卫队等电子计算机警护"），显示其为新近立法、尚未施行即写入白皮书的新制度内容。前者属自卫队为应对通信领域侵害而新设的任务框架，后者针对自卫队等所使用电子计算机遭受网络攻击的风险，将"电子计算机警护"纳入法定任务。两项均定于2026年10月1日方才施行，却已作为既有任务体系的新增项写入白皮书，反映出日本借立法固化网络/电磁领域应对职能的节奏明显加快。

4. 防卫装备转让三原则修订

白皮书称，如今任何国家都无法仅凭一己之力守护本国和平与安全，基于此，日本在坚持和平国家基本理念前提下进一步推进防卫装备转让，为确保日本安全及地区与国际社会和平稳定，于2026年4月对防卫装备转让三原则及运用方针进行修订。该修订与第二部分第3点"5类型"废除一体，构成白皮书所谓"强化防卫生产与技术基础"的重要一环，被外界解读为事实上放开杀伤性武器出口。

四、新增/强化的具体作战域与技术条目

1. 高功率能量武器（激光、微波等反无人装备）

|  |  |  |
| --- | --- | --- |
| 类别 | 原理/特点 | 运用动向 |
| 电磁轨道炮 | 利用电气能量产生的磁场发射子弹，无推进装置；体积小、成本低，可节省空间储备，并能高效应对大量导弹攻击 | 美、中等国推进研发 |
| 高功率激光武器 | 通过高功率激光能量摧毁目标；针对大量小型无人机/船舶的低成本有效拦截手段 | 美、中、俄、以、英研发/部署（以"铁束""龙火"为代表） |
| 高功率微波武器 | 损坏或导致无人航空器、导弹等所搭载电子设备误动作 | 美空军"THOR"使蜂群无人机失效 |

各国动向方面：美国2025年6月以无人航空器群为目标，对50kW级车载型激光武器"DEM-SHORAD"实施实弹射击并成功使其丧失战斗力；以色列输出功率达100kW级的车载型防空激光武器"铁束"已完成开发，同年12月首套系统移交部队；英国"龙火"高功率激光武器每发仅需10英镑，精度可在1公里外击中1英镑硬币。高功率微波方面，美国空军针对模拟蜂群飞行的大量无人航空器，使用高功率微波武器"THOR"，据称有效使多数无人航空器失效。

2. 认知域相关动态

认知域与太空、网络、电磁并列列为关键作战域。国际社会从冲突前阶段起便通过虚假信息及战略性信息发布对人的认知施加影响，进而影响他国舆论与决策，此类信息战持续进行。在专门专栏中，俄罗斯被描绘为利用西方社会自由开放的政治、社会体制特性、对其实施以虚假信息为手段的信息操控与渗透行动的一方。文件还称，防卫省·自卫队以作为信息战应对核心的情报本部为首，政策部门与运用部门正携手一体、加速推进相关工作。

3. 海底基础设施相关动向

近年来波罗的海及台湾地区周边海域发生多起海底电缆受损事案，已成为海洋领域新课题；围绕上述事案，指出蓄意破坏行为有可能使其成为混合战的组成要素之一。具体案例包括：2025年1月台湾地区北部海域国际通信用海底电缆受损，同年2月连接台湾本岛与澎湖列岛的海底电缆遭切断；波罗的海自2024年11月后重要海底电缆损毁事件接连发生，北约据此于2025年1月启动"波罗的海哨兵"行动，欧盟亦发布《海底电缆安全保障行动计划》。

4. 北冰洋·北极圈相关动向

随着北冰洋海冰减少，围绕北冰洋航线利用及资源开发的动向日趋活跃；从安全保障角度看，北冰洋传统上是战略核力量部署或通过的海域，近年来随着海冰减少，舰艇可航行时间与海域不断扩大，预计将来可能被用于海上战力部署。文件述及俄罗斯在北极圈沿岸推进雷达监视网整备，并推进飞行场重建及地对空、地对舰导弹部署；美国发布《北极圈战略2024》，丹麦、法国、德国等北约成员国启动"北极耐力演习""北极哨兵"等计划，并重点渲染中国与俄罗斯在北冰洋领域的合作不断增加、中俄军事合作正不断增加。

五、主要国家防卫费动向图表

2026年版刻意新增"主要国家防卫费比较"图表，以购买力平价折算并对比各国国防费占GDP比，凸显日本相对"落后"的水平，为扩军舆论铺垫。

1. 与各国的比较

由于国防费在国际上没有统一定义，文件将日本防卫相关经费与各国公布的国防费，通过经济合作与发展组织公布的购买力平价换算成美元，并对国防费占国内生产总值的比率进行比较。根据斯德哥尔摩国际和平研究所实况报告（2026年4月公布），2025年世界国防费占世界GDP比例为2.5%，日本防卫相关经费占日本GDP比例为1.4%。文件称在《国家安全保障战略》中已决定采取必要措施，使2027年防卫力根本性加强及补充举措所需预算水平达到2022年GDP的2%；鉴于安全保障环境严峻程度急剧加深，政府决定在2025年内将年初预算与补正预算合并提前安排落实。

2. 主要图表与换算基准

白皮书列出图表Ⅱ-2-4-5“主要国国防费比较（2025年）”与图表Ⅱ-2-4-6“主要国家国防费的变化趋势”，其购买力平价折算基准如下：
