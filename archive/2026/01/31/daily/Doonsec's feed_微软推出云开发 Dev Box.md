随着 AI 代理、模型上下文协议（MCP）以及新兴 AI 工作流的兴起，软件开发范式正在发生根本性转变。为了帮助开发者跟上这一创新步伐，微软在 Microsoft Dev Box 中推出了一系列新能力，旨在提供零配置的云端开发环境。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/BuagpZZ9F9qpAT6uMtEJGldQib6GO6pZtcgicOBROMYiaDmxuWgvsEpp3oPTQtp4ZDVqEntvWamvzxasyvLwD0KCw/640?wx_fmt=png&from=appmsg)

此次更新主要包含以下关键信息：

* **简化 Dev Box 配置**：平台工程师和项目管理员现在可以直接在配置 Dev Box 池时指定镜像和 SKU，无需在 Dev Center 层面预先创建 Dev Box 定义。
* **自助创建 Dev Box**：管理员现在可以代表开发者创建 Dev Box，这一此前呼声最高的功能现已进入公共预览阶段。无论是新员工入职、黑客马拉松还是客户演示，都能快速为开发者搭建好环境。
* **自动删除功能**：针对闲置时间过长的 Dev Box，微软推出了自动删除预览功能。管理员可以设置规则，在特定条件满足时自动清理资源，有助于控制成本并保持环境整洁。
* **项目级策略**：在 Build 2025 上宣布的项目策略现已正式发布，允许平台工程师在项目层面设置边界，确保每个项目仅访问必要的资源，从而在保障治理的同时提升安全性。
* **休眠功能**：针对云原生部署中的成本控制，Dev Box 的休眠功能现已正式可用。通过自动停止、断开连接休眠或无连接休眠等机制，系统能够在开发者需要时唤醒资源，闲置时自动节省开支。
* **AI 开发优化**：Dev Box 现已针对 AI 应用开发进行了优化，提供预配置的模型和工具，帮助开发者快速启动云端开发环境。

  ![](https://mmbiz.qpic.cn/sz_mmbiz_png/BuagpZZ9F9qpAT6uMtEJGldQib6GO6pZtgW3wicdEgFnXAdJw0Bf82sa9utZtJQbCn0MYbD97cB4yeh5zm0CoR5w/640?wx_fmt=png&from=appmsg)

在 Azure DevTest Labs 的“我的虚拟机”视图中，微软也进行了多项体验升级。用户现在支持多选虚拟机进行批量操作（如启动、停止、重启或删除），并能按类型、状态、大小等属性对虚拟机进行排序和分组。此外，该视图还支持查看虚拟机的网络配置，进一步简化了 VM 的管理流程。

对于平台工程师而言，在开发和测试环境中安全地管理敏感信息至关重要。从虚拟机配置到自动化环境搭建，整个流程往往涉及凭证、SSH 密钥和 API 令牌。微软此前收到大量反馈，指出在缺乏集中化解决方案的情况下，这些机密信息容易分散在邮件、聊天记录和脚本中，从而增加安全风险。此次更新通过集中化的管理工具，旨在解决这一痛点。
