иҜҘжјҸжҙһз”ұе®үе…Ёз ”з©¶е‘ҳ **Arkmarta** еҸ‘зҺ°пјҢ**д»…еҪұе“Қ AVideo 6.0 зүҲжң¬**пјҢзӣ®еүҚе·ІеңЁ **7.0 еҸҠжӣҙй«ҳзүҲжң¬**дёӯе®ҢжҲҗе®ҳж–№дҝ®еӨҚгҖӮ

жӯӨжјҸжҙһеҪ’зұ»дәҺ **CWE-78пјҲж“ҚдҪңзі»з»ҹе‘Ҫд»Өдёӯзү№ж®Ҡе…ғзҙ еӨ„зҗҶдёҚеҪ“пјү**пјҢеұһдәҺ**ж— йңҖжқғйҷҗгҖҒж— йңҖз”ЁжҲ·дәӨдә’**зҡ„иҝңзЁӢзҪ‘з»ңж”»еҮ»гҖӮ

дёҖж—Ұиў«жҲҗеҠҹеҲ©з”ЁпјҢж”»еҮ»иҖ…еҸҜ**е®Ңе…ЁжҺ§еҲ¶жңҚеҠЎеҷЁ**гҖҒзӘғеҸ–ж•Ҹж„ҹй…ҚзҪ®еҜҶй’ҘпјҢе№¶**еҪ»еә•еҠ«жҢҒзӣҙж’ӯи§Ҷйў‘жөҒ**гҖӮ

### AVideo е№іеҸ°жјҸжҙһиҜҰжғ…

иҝҷдёҖй«ҳеҚұжјҸжҙһзҡ„**ж №жәҗ**дҪҚдәҺ AVideo е№іеҸ°зҡ„ **objects/getImage.php** з»„д»¶гҖӮ

еҪ“еә”з”ЁеӨ„зҗҶеҢ…еҗ« **base64Url** еҸӮж•°зҡ„зҪ‘з»ңиҜ·жұӮж—¶пјҢе№іеҸ°дјҡеҜ№з”ЁжҲ·иҫ“е…ҘиҝӣиЎҢ Base64 и§Јз ҒпјҢ**е№¶зӣҙжҺҘжӢјжҺҘеҲ°еҸҢеј•еҸ·еҢ…иЈ№зҡ„ ffmpeg зі»з»ҹе‘Ҫд»Өдёӯ**гҖӮ

е°Ҫз®ЎзЁӢеәҸе°қиҜ•йҖҡиҝҮж ҮеҮҶ URL иҝҮж»ӨеҷЁеҜ№иҫ“е…ҘиҝӣиЎҢж ЎйӘҢпјҢдҪҶиҜҘеҮҪж•°**д»…жЈҖжҹҘеҹәзЎҖ URL иҜӯжі•ж јејҸ**гҖӮ

е®ғ**е®Ңе…ЁжІЎжңүеҜ№еҚұйҷ©зҡ„ Shell е…ғеӯ—з¬ҰжҲ–е‘Ҫд»ӨжӣҝжҚўеәҸеҲ—иҝӣиЎҢиҝҮж»Ө**гҖӮ

з”ұдәҺеә”з”ЁеңЁжү§иЎҢе‘Ҫд»ӨеүҚ**жңӘеҜ№дёҚеҸҜдҝЎж•°жҚ®иҝӣиЎҢжӯЈзЎ®иҪ¬д№ү**пјҢиҝңзЁӢж”»еҮ»иҖ…еҸҜиҪ»жқҫиҝҪеҠ жҒ¶ж„ҸжҢҮд»ӨгҖӮ

иҝҷдёҖзјәйҷ·дҪҝеҫ—жңӘжҺҲжқғз”ЁжҲ·иғҪеӨҹ**жү§иЎҢд»»ж„Ҹд»Јз Ғ**гҖҒзӘғеҸ–еҶ…йғЁеҮӯиҜҒпјҢжҲ–ж•…ж„Ҹз ҙеқҸжңҚеҠЎеҷЁзҡ„жөҒеӘ’дҪ“жңҚеҠЎгҖӮ

### дҝ®еӨҚдёҺйҳІжҠӨе»әи®®

ж №жҚ® GitHub еҸ‘еёғзҡ„е®үе…Ёе…¬е‘ҠпјҢиҝҗиЎҢ **AVideo-Encoder 6.0** зҡ„з®ЎзҗҶе‘ҳеә”**з«ӢеҚіеҚҮзә§еҲ° 7.0 жҲ–жӣҙй«ҳзүҲжң¬**д»ҘдҝқйҡңзҺҜеўғе®үе…ЁгҖӮ

е®ҳж–№дҝ®еӨҚзүҲжң¬йҖҡиҝҮдҪҝз”Ё **escapeshellarg()** зӯүеҮҪж•°еҜ№ Shell еҸӮж•°жү§иЎҢ**дёҘж јиҪ¬д№ү**пјҢд»Һж №жәҗдёҠи§ЈеҶідәҶиҜҘжјҸжҙһгҖӮ

иҝҷдёҖе…ій”®дҝ®еӨҚзЎ®дҝқ**жүҖжңүз”ЁжҲ·иҫ“е…ҘеңЁдј е…Ҙе‘Ҫд»ӨиЎҢеүҚйғҪдјҡиў«еҪ»еә•еҮҖеҢ–**пјҢжңүж•Ҳйҳ»жӯўж”»еҮ»иҖ…зӘҒз ҙйў„и®ҫзҡ„е‘Ҫд»Өз»“жһ„гҖӮ

иӢҘж— жі•з«ӢеҚіе®ҢжҲҗиҪҜд»¶еҚҮзә§пјҢе®үе…Ёеӣўйҳҹеҝ…йЎ»йғЁзҪІ**дёҙж—¶зј“и§ЈжҺӘж–Ҫ**дҝқжҠӨжөҒеӘ’дҪ“еҹәзЎҖи®ҫж–Ҫпјҡ

* з®ЎзҗҶе‘ҳеә”еңЁ Web жңҚеҠЎеҷЁжҲ–еҸҚеҗ‘д»ЈзҗҶеұӮпјҢйҖҡиҝҮ**дёҘж јзҡ„ IP зҷҪеҗҚеҚ•**йҷҗеҲ¶еҜ№и„Ҷејұз«ҜзӮ№ **objects/getImage.php** зҡ„и®ҝй—®гҖӮ
* жңәжһ„еҸҜй…ҚзҪ®**Web еә”з”ЁйҳІзҒ«еўҷпјҲWAFпјү** и§„еҲҷпјҢжЈҖжөӢе№¶дё»еҠЁжӢҰжҲӘеҸҜз–‘зҡ„ Base64 зј–з Ғ Shell е‘Ҫд»Өзү№еҫҒгҖӮ
* иӢҘе№іеҸ°ж—ҘеёёиҝҗиЎҢж— йңҖдҫқиө–еӣҫзүҮиҺ·еҸ–еҠҹиғҪпјҢз®ЎзҗҶе‘ҳеҸҜ**зӣҙжҺҘе…ій—ӯиҜҘз»„д»¶**дҪңдёәжңҖз»ҲйҳІжҠӨжүӢж®өгҖӮ
