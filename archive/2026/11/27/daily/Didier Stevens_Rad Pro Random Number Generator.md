# Rad Pro Random Number Generator

# [Didier Stevens](https://blog.didierstevens.com/)

## Friday 27 November 2026

### Rad Pro Random Number Generator

Filed under: [Hardware](https://blog.didierstevens.com/category/hardware/) — Didier Stevens @ 13:05

Rad Pro, a [custom firmware for Geiger counters/radiation meters](https://github.com/Gissio/radpro), has a random number generator. It is a [Hardware Random Number Generator](https://en.wikipedia.org/wiki/Hardware_random_number_generator), it generates random numbers from a physical process (radiation).

From the main screen:

![](https://blog.didierstevens.com/wp-content/uploads/2026/11/image-8.png)

You go into the settings menu to Random generator:

![](https://blog.didierstevens.com/wp-content/uploads/2026/11/image-9.png)

And there you have many options:

![](https://blog.didierstevens.com/wp-content/uploads/2026/11/image-10.png)

I select Alphanumeric, and this gives me a random string:

![](https://blog.didierstevens.com/wp-content/uploads/2026/11/image-11.png)

You can see the string grow while radiation is detected. It’s slow with normal background radiation, it takes several seconds for a new character to appear. It’s not practical if you need a lot of random data.
