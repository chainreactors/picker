第十四届云计算与大数据国际会议（**The Fourteenth International Conference on Advanced Cloud and Big Data, CBD 2026**）将于 `2026年11月21日至23日` 在美丽的春城 `昆明`举办。

CBD会议长期聚焦云计算、大数据、人工智能、物联网、网络与系统安全等前沿方向，为国内外学者和产业界专家提供高水平学术交流平台。诚邀相关领域研究人员、工程技术人员及研究生踊跃投稿和参会交流。

## 📌 会议主题（包括但不限于）

### Research Track

* Cloud Security and Privacy
* Cloud-Native Theories and Algorithms
* Cloud Resource Management
* Multi/Hybrid/Inter Cloud
* Big Data Processing, Mining and Analytics
* Big Data Protection and Privacy
* Edge Computing Architecture and Algorithms
* Communication and Networking for Big Data
* Energy-Efficient Computing for Big Data
* Cloud and Big Data Intelligence

### Application Track

* AI for Cloud and Big Data
* Blockchain for Cloud and Big Data
* IoT, Smart City and Healthcare
* Cloud Applications and Services
* Big Data Applications and Services

### Industry Track

* Cloud Computing Solutions
* Big Data Solutions
* Cloud and Big Data Standards
* Industry Practices

## 🏆 出版与推荐

录用论文将由会议论文集出版，并提交 **EI Compendex** 检索（待批准）。

优秀论文将有机会推荐至多个国际高水平期刊扩展发表，包括：

* *Frontiers of Computer Science (FCS)*
* *Sustainable Computing: Informatics and Systems*
* *Big Data Mining and Analytics*
* 等国际知名期刊

## 📅 重要日期

* **论文投稿截止**：2026年7月30日
* **录用通知**：2026年8月30日
* **终稿提交**：2026年9月20日
* **注册截止**：2026年9月20日

## 🔗 投稿与会议信息

* 投稿系统：`https://easychair.org/conferences/?conf=cbd2026`
* 会议主页：`https://cbd-conference.net/2026`

欢迎各位老师、同学及相关领域研究人员投稿交流，也欢迎转发给感兴趣的同行！ 期待今年11月与大家相聚昆明，共同探讨云计算、大数据与人工智能领域的最新进展。
