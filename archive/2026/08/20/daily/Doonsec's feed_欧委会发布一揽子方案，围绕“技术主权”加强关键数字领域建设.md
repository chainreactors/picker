**2026年6月，欧委会发布“欧洲技术主权一揽子方案”，提出“技术主权”概念，即面对AI等数字化革命，为支撑经济、社会与安全发展，减少对外战略依赖，增强发展关键技术、基础设施、数据、服务等关键要素的能力。围绕“技术主权”，欧委会提出一系列加强关键数字领域能力的举措，包括：通过《芯片法案2.0》加强面向AI需求的半导体供应链建设；通过《云与AI发展法案》减少对外国云服务等计算基础设施的依赖；通过《开源战略》发挥欧盟优势，实现技术自主替代。**

/

**一**

/

**相关背景**

关键技术、基础设施、数据和服务是支撑欧盟经济、社会与安全的关键要素，“技术主权”是指欧盟为减少战略依赖和外国干预，推动上述要素规模化发展、降低供应链技术敞口风险、推动供应链多样化的能力。随着AI革命等数字技术加速发展，数字生态系统各关键要素能力越发重要；欧盟地区超过80%的数字产品、服务、基础设施和知识产权结构性依赖外国供应商。随着地缘政治分裂加剧，上述战略性依赖可能会被别国“武器化”利用，威胁欧盟技术主权和经济安全。在此背景下，“技术主权一揽子方案”将优化欧盟政策布局，从被动关注韧性和风险缓解转向基于技术主权的积极主动行动，并选定关键领域作为政策干预的起点（详见表1）。

表1 “技术主权一揽子方案”选定关键领域的共同特点与发展目标

|  |  |  |  |
| --- | --- | --- | --- |
| **共同特点** | **半导体** | **云与AI** | **开源技术解决方案** |
| AI等数字革命发展使该领域重要性不断上升 | 支撑AI发展的数据中心需要大量半导体：预计到2030年，AI相关组件将占据半导体市场70%以上份额。 | AI发展推动计算能力需求持续增长，云服务、数据中心等基础设施已成为关键战略资源。 | 开源技术支撑政府服务、科学研究等关键领域，对维护技术主权至关重要。作为Linux等开源方案的发源地，欧盟在该领域具备优势。 |
| 地缘政治局势紧张与对外依赖加剧 | 中美紧张局势加剧，进一步凸显半导体的战略重要性；欧盟此前《芯片法案》提出的“到2030年欧盟全球市场份额翻番”目标难以实现。 | 三家美国服务商控制70%以上欧盟云市场，技术主权受到美国法律“长臂管辖”威胁。 | 美中在全球开源生态系统中影响力不断扩大，欧盟技术主权与竞争力受到威胁。 |
| 发展目标 | 重点解决《芯片法案》两大遗留问题：（1）半导体设计和制造过度依赖第三国；（2）危机应对与准备能力不足。 | （1）提升欧盟云与AI生态系统竞争力和创新能力，建立韧性与战略自主的法律框架；（2）未来5~7年内将欧洲地区数据中心容量提升至现有水平的3倍。 | （1）利用开源维护技术主权；（2）强化活跃的开源生态；（3）推动公共部门使用开放、互操作的数字生态系统；（4）与伙伴国合作，引领国际标准制定。 |

/

**二**

/

**《芯片法案2.0》：升级《芯片法案》，从聚焦制造领域拓展至面向AI的全供应链安全建设**

**（一）资助研究创新，建设覆盖半导体产业全价值链的技术能力**

《芯片法案》曾提出“欧洲芯片倡议”，《芯片法案2.0》进一步提出**“欧洲芯片倡议2.0”，聚焦七大行动领域**（详见表2）**进行半导体产业的全价值链技术能力建设**，尤其关注研发与创新。针对欧盟半导体技术与产业面临的跨部门重大挑战，“欧洲芯片倡议2.0”还引入**“重大挑战”机制，资助对欧盟不可或缺或具备良好前景的关键半导体技术发展**，覆盖技术开发、产业部署等多价值链环节。

表2 “欧洲芯片倡议2.0”七大行动领域及主要内容

|  |  |
| --- | --- |
| **行动领域** | **主要内容** |
| 集成半导体技术  设计能力 | 打造基于云服务的一站式创新设计平台，整合全欧盟资源，推动新一代无晶圆厂初创企业发展。 |
| 服务于创新性生产、测试和验证的试点生产线 | 资助试点生产线建设，覆盖多个先进半导体技术路线（如功率电子、神经形态、嵌入式AI芯片、集成光子学、石墨烯），推动企业跨越从实验室到工厂的创新鸿沟。 |
| 量子芯片先进技术与工程能力 | 资助量子芯片及相关技术开发，提供可信赖生产与验证平台。已建立覆盖六大技术路线（超导、自旋、光子、金刚石、中性原子和离子阱）的量子芯片试点生产线，未来将继续发展电子学、低温学、封装等使能技术。 |
| 能力中心网络与技能发展 | 构建能力中心网络，为企业提供技术测试、咨询等服务。 |
| 光子集成电路技术先进设计、原型制造与产业化能力 | 支持光子集成电路相关技术发展：已覆盖硅、氮化硅、磷化铟等多种光子材料平台；未来计划进行多项技术路线验证（如服务于AI数据中心的共封装光学、用于增强现实或虚拟现实的可见光引擎、可编程光子处理器等）。 |
| 通过“芯片基金”为企业融资 | 通过“芯片基金”为初创企业、成长期企业和中小企业提供风险投资，帮助其发展业务和扩大市场。 |
| **重大挑战** | **未来四大潜在行动方向** |
| 能够大幅降低能耗的计算技术 | 开发能效提高1000倍的新计算技术，服务高能效、安全、分布式AI基础设施（包括高带宽内存、堆叠逻辑、光互联/射频互连等）。 |
| 欧盟自主可控的AI处理器和加速器 | 开发能够在欧盟地区设计和制造的处理器和加速器，构成欧盟云和AI全技术栈的组成部分。 |
| 物理AI | 面向从人形机器人到工业机器人的广泛领域夯实技术基础，推动多种主流技术研发（如功率半导体、微控制器、模拟/混合信号、传感器技术）。 |
| 智能眼镜与虚拟  世界 | 集成超低功耗组件（如功率电子学、激光器、神经形态芯片、AI芯片等），开发应用于虚拟世界的原型。 |

**（二）通过日常建设和紧急措施，维护半导体供应链生态与韧性**

**一是加强供应链关键环节日常建设。**“欧洲半导体技术倡议”是通过资助制造业项目降低欧盟半导体供应链对外依赖的机制。其中，“首创项目”主要资助由单一成员国企业开展的项目；“战略项目”主要资助成员国间企业开展重大合作项目，重点聚焦六大优先领域（详见表3）。

表3 “战略项目”六大优先领域

|  |  |
| --- | --- |
| **领域** | **主要内容** |
| 欧洲先进半导体  制造 | 建成欧盟地区首家先进半导体制造工厂，集领先节点芯片制造、小芯片集成和2.5D/3D先进封装能力于一身。 |
| 欧盟计算基础设施所需AI芯片与系统 | 基于欧洲先进技术设计和开发AI芯片和计算系统，并实现原型制造和流片。 |
| 服务于自动驾驶的汽车应用处理器 | 基于第五代精简指令集（RISC-V）架构，设计和开发高性能汽车应用处理器并实现原型制造和流片，最终为企业提供经过车规认证的能够直接应用的器件。 |
| 欧洲本土存储器  制造设施 | 建立欧洲本土存储器制造厂，生产新兴非易失性存储器（如DRAM、NAND）。 |
| 前沿芯片设计 | 聚焦知识产权、架构和验证，建立欧盟自主的世界级领先逻辑芯片设计能力。 |
| 价值链关键环节  强化 | 针对半导体价值链中的战略脆弱环节采取专门行动，包括最先进领域以及主流芯片生产、后端工艺、空白印刷电路板组装、材料和设备等环节。 |

**二是加强供应链危机时紧急应对。**包括：（1）通过供应链风险监测，及时发现危机。风险监测和危机应对被严格限定在13个关键部门（如能源、交通、银行业、金融市场基础设施、健康、数字基础设施、太空等）和10个使用半导体的工业部门（如汽车，数据中心、云与AI，工业自动化与机器人，电子通信基础设施，工业级计算与物联网等），旨在聚焦关键领域以避免政府过度干预。（2）及时启动危机应对。一旦被认定为供应链危机，欧委会与成员国有权采取如下紧急措施，例如，要求供应链企业优先处理相关订单，通过公共采购弥补供应链短缺；要求企业提供生产情况和供应链扰动信息等。

/

**三**

/

**《云与AI发展法案》：聚焦云与AI能力建设，构建“主权云”监管框架**

**（一）推动尖端技术研发与部署，确保AI发展的同时履行气候减排承诺**

《云与AI发展法案》提出“云与AI领导地位倡议”，目标为资助前沿与可持续发展技术的研发和部署，以维护欧盟在云与AI领域的领导地位。该倡议主要支持八大技术与转型领域（详见表4）。

表4 “云与AI领导地位倡议”八大目标

|  |  |
| --- | --- |
| **目标** | **主要内容** |
| 推动欧盟先进数据中心技术开发部署 | 提升数据中心环境可持续性、性能与安全。 |
| 发展云计算技术 | 建设云技术栈（包括完整的端到端硬件云栈与软件云栈），填补欧盟关键能力缺口。 |
| 提升欧盟前沿AI领域能力 | 开发下一代多模态前沿AI模型和系统，拓展全新能力。 |
| 提升物理AI能力并促进其在战略领域部署 | 开发前沿物理AI模型与系统，确保其能够在非结构化环境中自主安全运行。 |
| 加速工业AI在欧盟战略行业的开发与应用 | 战略领域包括自动驾驶、制造、医疗、能源、农业食品、国防等。 |
| 支持构建高级AI智能体大规模部署平台 | 该平台应能推动欧洲AI智能体的协作，并提供服务于大规模安全部署的中间件。 |
| 加强AI模型和系统在欧盟公共部门的开发与应用 | 基于公共部门高质量数据，为关键领域（医疗、公共管理、法律、危机管理、公共服务）开发AI模型与系统。 |
| 推动区域AI应用，推广欧洲云服务 | 开发欧洲合作性工业模型，能够在保护商业敏感数据的同时，实现欧洲工业界内部的AI模型协同开发。 |

**（二）通过公共采购构建欧洲“主权云”，提升政府数据安全保障级别**

欧盟及成员国政府须将关键敏感数据存储于自主可控的云服务上（即“主权云”）。对此，欧盟计划发布“云计算主权框架”，将主权安全水平分为四大“保障级别”。欧盟及其成员国政府部门将开展风险自评，根据主管领域数据敏感程度确定对应级别，在公共采购中严格遵守“云计算主权框架”要求选择供应商，其中至少25%采购份额应分配给创新型中小企业。

/

**四**

/

**《开源战略》：推动自主技术替代，与伙伴国合作引领国际标准制定**

**（一）推动开源技术重点领域研发与创新，减少对外技术依赖**

在云、AI、互联网技术、网络安全和半导体等优先领域，推动使用开源技术作为替代性解决方案，相关研发和创新项目将重点聚焦“关键技术示例”明确的七大方向（详见表5）。

表5 “关键技术示例”明确的开源技术研发创新方向

|  |  |
| --- | --- |
| **关键技术** | **主要内容** |
| 半导体 | 开发基于第五代精简指令集（RISC-V）的开源硬件，投资开源电子设计自动化工具（EDA）。 |
| 操作系统 | 包括计算机、移动端、物联网、机器人、无人机等领域操作系统。 |
| 未来互联网架构 | 包括软件开发、交付基础设施、Web 4.0开源构建块和虚拟世界架构框架。 |
| 云栈 | 支持欧洲云连接到边缘的软件栈发展，确保其能够拓展至计算层、连接层、数据层和AI服务层。 |
| 软件开发基础设施 | 加速软件交付、增强安全性或提高代码质量，为法律合规、依赖项识别和漏洞管理提供统一工具。 |
| AI栈 | 开发开源AI模型，优先服务于欧盟AI工厂并配备必要安全保障措施。 |
| 网络安全 | 开发能够增强开源组件及其组合安全性的开源网络威胁情报框架、漏洞披露工具和保障验证工具。 |

**（二）加强技术标准制定与国际推广**

与具有共同价值观的国家开展合作，推广欧盟成熟、可重用、可适配的开源方案，如开放互联网栈、AI软件、数字身份和商业钱包，并将开源流程融入标准制定过程中，特别是在网络安全、AI、互联网技术等关键领域。
