tuios 0.9.1 is a fix release. It fixes a daemon crash on agent transcripts, races in the daemon's client state, a scrollback line that broke after a reattach, and a theme from a config file that missed the panes.
It also moves tuios-web to sip v0.8.5, which blocks DNS rebinding and caps the size of a browser window.

The full list is at [tuios.dev/releases](https://tuios.dev/releases).
