## 抖音推荐影响器（Douyin Smart Feed Assistant）

想把抖音推荐流调成更合你口味的样子？这款基于 AI 的自动化工具，会读取视频标题、作者与标签，根据你的偏好规则，自动做出“点赞、忽略或不感兴趣”的反馈，让系统更快理解你的真实需求，减少无效刷屏。

![](https://cdn.skyimg.net/up/2025/11/6/fb5abd91.webp)

## 适用场景

* **内容监管与引导**：家长为未成年人或长辈把关推荐内容，降低不适宜与诱导性信息曝光。
* **打破信息茧房**：主动扩展内容圈层，获得更丰富的知识与视角。
* **聚焦特定兴趣**：科普、健身、艺术创作等垂直方向更快建立高质量内容池。

## 工作原理（通俗解释）

推荐系统依赖用户行为信号进行个性化分发。本工具将这类信号自动化并结构化，让“喜欢/跳过/不感兴趣”等反馈更精准、更持续，促使推荐方向向你的偏好收敛。

## 核心特性

* **AI 智能分析**：接入 DeepSeek、Kimi、通义千问、智谱 GLM 等主流大模型，亦可使用 OpenAI 兼容 API。
* **自动化规则**：按自定义规则执行“点赞/忽略/不感兴趣”，持续向系统传达偏好。
* **人机交互策略**：模拟合理观看时长与随机跳过，避免机械化操作带来的异常行为。
* **灵活配置**：内置青少年引导、效率知识、艺术审美等模板，也可完全自定义。
* **隐私与透明**：配置与 API Key 本地存储，开源代码可审查。
* **使用成本可控**：多家 API 提供试用额度；按调用计费时单次判断成本较低，足以支撑日常优化。

## 安装与获取

* **运行环境**：仅支持 **抖音网页版**
* **脚本管理器**：选择 **Tampermonkey** 或 **Violentmonkey**。
* **获取方式**：在 **GreasyFork / GitHub** 安装用户脚本，扩展将自动弹出安装确认页。

> 安装完成后，访问抖音网页版即可看到侧边悬浮的机器人图标。

## 常见疑问

* **费用**：视模型与调用频率而定。常见平台提供新用户试用额度；常用判断量的总体成本较低。
* **模型选择**：建议使用标准对话模型（如 deepseek-chat、gpt-4o-mini、claude-3.5-sonnet）。推理型模型可能响应慢、费用高且不便解析。
* **运行形态**：需保持抖音标签页处于激活与可见状态；最小化窗口或切换标签可能影响稳定性。
* **数据安全**：配置与密钥保存在本地，不上传第三方服务器；可在服务商控制台查看与管理密钥。
* **页面更新**：如遇“无法定位当前视频”等异常，可能是网页结构更新，建议刷新、清缓存，并关注脚本版本更新。
* **多设备差异**：Web、平板与手机端的推荐形态不同，内容同步可能存在差异。

## 合规与风险提示

* 请遵守抖音平台规则与相关法律法规，本工具面向内容偏好管理、家长引导与信息效率提升等正当用途。
* 任何自动化手段都存在不确定性与平台风控可能，建议先在非主力账号进行小规模验证。
* 使用造成的账号或内容风控等后果，由用户自行承担。
