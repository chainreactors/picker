WinHex：硬盘里的“显微镜”，能看见被删掉的文件

你有没有这种经历：

回收站清空了，才发现删错了文件。

硬盘打不开了，里面存着五年的工作资料。

怀疑电脑被人动过，想知道他看了什么。

这时候你需要一个工具——WinHex。

它不是黑客的武器，是每个人电脑里都应该有的“数据急救箱”。

一、WinHex是什么？

WinHex是一个十六进制编辑器，但这么说太专业了。

简单说：它能直接看硬盘里存的“原始数据”。

你平时看到的文件，是Windows整理好给你看的。WinHex跳过Windows，直接看硬盘底层——被删掉的文件、隐藏的分区、格式化前的数据，全都能看见。

二、WinHex能干什么？

1. 恢复误删的文件

清空回收站不代表文件没了，只是Windows告诉硬盘“这块地方可以写新数据了”。在真正被覆盖之前，文件还在。

WinHex能把它们找回来。

2. 克隆整个硬盘

硬盘要坏了，趁还能读出来，用WinHex全盘克隆到新硬盘。包括系统、文件、隐藏分区——一模一样。

3. 查USB使用记录

怀疑有人用U盘拷走你的文件？WinHex能看注册表里的USB记录：什么时候插过什么U盘。

4. 看文件到底删没删

“我删干净了”这句话，用WinHex一照就知道真假。数据还在不在，一目了然。

三、怎么用？手把手教程

第一步：下载安装

去官网 x-ways.net 下载WinHex。有30天免费试用，够用了。

安装时选中文语言。

第二步：打开硬盘

打开WinHex，点“工具”→“打开磁盘”。

选你的C盘或D盘，点确定。

你会看到满屏的十六进制数字——别慌，这是硬盘的“原样”。

第三步：恢复误删文件

假设你刚清空了回收站，发现里面有重要文件。

1. 点“工具”→“磁盘工具”→“按类型恢复”

2. 选你想恢复的文件类型（Word、Excel、图片等）

3. 选保存位置（别选同一个盘，防止覆盖）

4. 点确定

WinHex会扫描整个磁盘，把所有能恢复的同类型文件找出来。扫描完去保存的文件夹里找。

第四步：按关键字搜索

如果你记得文件里有什么关键词：

1. 点“搜索”→“查找文本”

2. 输入关键词

3. 选“所有块”

4. 点确定

WinHex会标出所有包含这个词的位置。双击就能看到原始数据。

四、进阶功能：克隆坏硬盘

硬盘咔咔响，快坏了。趁还能读，赶紧克隆：

1. 准备一个新硬盘，容量要比旧的大

2. 点“工具”→“磁盘工具”→“克隆磁盘”

3. 源盘选旧硬盘，目标盘选新硬盘

4. 勾选“忽略读取错误”（坏道多的时候用）

5. 点确定

等几个小时，新硬盘就是旧硬盘的完美复制品。包括分区、系统、隐藏文件。

然后把旧硬盘拆了扔掉，新硬盘装上去——电脑复活。

五、查USB使用记录

怀疑有人用U盘拷走你的文件：

1. 点“工具”→“解释注册表文件”

2. 找到 SYSTEM 文件（在 C:\Windows\System32\config 里）

3. 点开“ControlSet001”→“Enum”→“USBSTOR”

这里会列出所有在这台电脑上插过的U盘，包括时间、序列号、品牌。

和你自己的U盘对一下，多出来的就是别人插过的。

六、真实场景

场景1：毕业论文被删

学生写了一个月论文，误删了Word文档，回收站清空。

用WinHex“按类型恢复”，找到所有docx文件。按修改时间排序，最新的那个就是论文。恢复成功。

场景2：硬盘打不开

移动硬盘插上提示“未格式化”，里面是几年照片。

用WinHex打开磁盘，发现分区表坏了。直接按文件类型恢复，把照片全捞出来。

场景3：怀疑公司电脑被拷贝

员工离职，怀疑他拷走了客户资料。

用WinHex查USB记录，发现一个没见过的U盘，插拔时间正好在他离职前一天。

七、重要提醒

1. 恢复的文件别存同一个盘

想恢复C盘的文件，别存到C盘。新数据会把旧数据覆盖，再也找不回来。

2. 发现删错了，马上关机

越早动手，恢复概率越高。别继续用电脑，别存新文件。

3. 不能恢复被覆盖的文件

如果删掉后往硬盘里写了很多新数据，原来的文件可能已经被覆盖了。WinHex也救不回来。

八、最后一句

WinHex不是什么神秘的黑客工具，它是每个电脑用户都应该有的“数据急救箱”。

误删文件？用它找。

硬盘要坏？用它克隆。

怀疑被人动过？用它查。
