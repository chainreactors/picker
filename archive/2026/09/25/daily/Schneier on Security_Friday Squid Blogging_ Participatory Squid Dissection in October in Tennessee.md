Not all squid are either edible or palatable.

In fact quite a few “smell of ammonia” / urine and last weeks Friday Squid gave me pause to think about it.

Ammonia is a natural by product of a carnivorous diet… And some “ammoniacal” squid species have a sufficient quantity to make them not just smell of pee but made inedible by the ammonia ions in their body.

Interestingly ammonia ions are slightly lighter than sodium ions thus the resulting solution is lighter than seawater thus if stored in an internal sac gives buoyancy in a dozen or so squid species for little or no energy input.

Admittedly these dozen or so squid species are of the deep-sea or even Giant-squid so would not be considered for the dinner table anyway. Also as they are rarely caught and sufficiently rare that they are considered for either chucking back or made available for science / research.

The code is trivial and safe, makes no requests, and doesn’t require javascript to be enabled, it only uses css features.
Use it with Greasemonkey/Firemonkey in Firefox, or Violentmonkey in Chromium-based (I recommend against Tampermonkey).
I think there’s no need to remind to users of this blog that you shouldn’t install directly but should save the file first and look through the code, to be sure it’s safe.
Also, you can set some of four variables in the top of the script, so that comments are folded or unfolded by default. If folded, you can use whitelist so that whitelisted commenters are unfolded by default. Similarly, if unfolded (open) by default, you can use blacklist to fold ones who you still want folded, or hide (“delete”) blacklisted comments completely.
The whitelist includes some old-timers, but I removed really old ones like NickP, who would barely show up. Adapt to your needs.
