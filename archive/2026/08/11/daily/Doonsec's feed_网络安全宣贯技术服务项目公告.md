# **中国出口信用保险公司****网络安全宣贯技术服务****项目**

# **竞争性磋商公告**

中信国际招标有限公司（以下简称“代理机构”）受中国出口信用保险公司（以下简称“采购人”）的委托，代理组织中国出口信用保险公司网络安全宣贯技术服务项目的竞争性磋商采购工作。

**一、项目名称及编号**

中国出口信用保险公司网络安全宣贯技术服务项目

（采购编号：0733-26102724）

**二、项目简介**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 服务类别 | 服务内容 | 预计数量 | 备注 | 预算金额（万元） |
| 网络安全宣贯技术服务 | 网络安全宣传周互动展服务：结合国家网络安全宣传周活动，组织开展网络安全宣传周互动展，包含宣贯互动活动策划、宣贯培训课程、宣贯培训物料等。 | 2年期（自合同签订之日起两年。） | / | 80 |
| 网络安全劳动竞赛服务：结合国家网络安全宣传周活动，组织开展网络安全劳动竞赛，包含劳动竞赛平台、竞赛题库等。 |
| 网络安全意识宣贯服务：结合采购人开展宣贯培训需要，不定期开展网络安全意识宣贯培训，包含网络安全宣贯专栏、宣贯培训素材等。 |
| 自动化钓鱼邮件和社工攻击演练平台 | 自动化钓鱼邮件和社工攻击演练平台 | 1套 | ★含三年免费原厂维保服务。 | 80 |

项目预算：160万元。

资金来源：自筹。

服务期限及交付期限：
（1）网络安全宣贯技术服务期限：自合同签订之日起2年。

（2）自动化钓鱼邮件和社工攻击演练平台交付期限：合同签订后15个工作日内完成产品交付（完成部署和调试，并开始提供技术服务）。

**三、合格供应商的基本资质要求**

3.1 中华人民共和国境内合法注册的独立法人，具有良好的商业信誉和健全的财务会计制度；

3.2供应商如为代理商，须提供原厂商针对本项目的授权书盖章件复印件，并提供产品原厂商售后服务承诺函，加盖原厂商公章；

3.3供应商具有至少1个金融行业自动化钓鱼邮件、社工攻击演练平台等产品的服务业绩或网络安全宣贯相关服务业绩；

3.4供应商不得为“信用中国”网站（www.creditchina.gov.cn）中列入失信惩戒对象和重大税收违法案件当事人名单的供应商。（查询时间范围应为本项目公告发出之日至响应文件递交截止日之间）；

3.5法定代表人为同一个人的两个及两个以上法人，母公司、全资子公司及其控股公司，都不得在本项目中同时参与；

3.6本项目不接受联合体，不允许分包、转包；

3.7供应商未被列入采购人供应商禁用名单。

★**以上要求供应商必须同时满足，所提供的所有资质文件必须真实，且与供应商主体一致，如果需要供应商提供的相关证件需要年检的，请确保提供的文件复印件已年检合格，否则在评审时将予以否决****。**

**四、****磋商****文件的发售**

发售时间：自2026年8月11日至2026年8月17日，每日上午9：00-12:00，下午13:00-17:00（北京时间）。未购买磋商文件的供应商不得参加本项目的响应。

发售方式：

**第一步，注册。**

1.注册。在中国出口信用保险公司投标人服务中心注册（https://xbsc.sinosure.com.cn/gysfw/#/login/register）。技术支持电话：冯经理，（电话：010-66580499、15234958320），仅受理注册登录问题。

2.截图。注册审核通过后，重新登录网站并保留登录截图（加盖供应商公章）。

**第二步，购买文件。**

1.供应商在报名购买磋商文件前，请先将上述步骤中的“截图”发送给中信国际招标有限公司。

2.购买磋商文件

请供应商将以下全部报名所需资料的扫描件，发送至代理机构电子邮箱中(huanghus@ck.citic.com)，发送后请及时联系代理机构(联系方式: 010-87945198-531，联系人:黄经理)，获取磋商文件：

1)供应商营业执照副本复印件加盖供应商公章；

2)法人代表授权委托书原件(注明本项目名称及项目编号)；

3)被授权人身份证原件和复印件加盖供应商公章；

4)磋商文件费(人民币200元整，售后不退)的银行汇款凭证；

账户名称：中信国际招标有限公司

开户行：中信银行北京三元桥支行

账户：8110701013102383606

5)磋商文件购买记录(可编辑的WORD版及扫描版)；

6)中国出口信用保险公司集中采购门户的登录截图加盖供应商公章。

**特别提醒：只有从采购代理机构处购买****磋商****文件，并完成报名手续的潜在供应商才有资格参与本项目。**

**第三步，确认报名。**

购买完磋商文件的供应商，应保留购买凭证，并登录供应商服务中心（https://xbsc.sinosure.com.cn/gysfw/#/login）。登录成功后，点击“集采系统”菜单，进入后，点击左侧“投标管理”——“在线报名”——“选择本次报名的项目”，点击右侧“报名”，按提示补充相关资料后，点击下方“提交”按钮。

**五、响应文件的递交**

递交响应文件截止时间：北京时间2026年8月24日14:30时整。逾期收到或不符合规定的响应文件恕不接受。

递交响应文件地点： 北京市朝阳区东三环中路59号楼16层1611会议室。

**六、联系方式**

代理机构名称：中信国际招标有限公司

代理机构地址：北京市朝阳区东三环中路59号楼18层1821室

代理机构联系方式：黄经理，010-87945198-531，huanghus@ck.citic.com

苏经理，010-87945198-530，suxu@ck.citic.com

采购人名称：中国出口信用保险公司

采购人地址：北京市西城区丰汇时代大厦北楼

本公告同时在中国金融集中采购网（http://www.cfcpn.com）、中国出口信用保险公司集中采购门户网站（http://eps.sinosure.com.cn）发布。
