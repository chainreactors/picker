最近刷到 B站 @陈小黑数学 老师的一条短视频，标题只有一句话，却挺扎心：

中学阶段的考试，考的不是创造。

这句话我同意，但更想把后半句补上：既然不考创造，那考什么？

我的答案是两个字：检索。

有个场景，几乎每个高中生都经历过。考场上，一道题盯了五分钟，脑子一片空白；交卷后翻开笔记本，或者老师讲评到第三行，突然一拍大腿：这题我做过啊，就上周那道，连数字都差不多。

不是不会，是「没想起来」。

而班里那个数学总在前面的同学，往往看一眼题就说："哦，这题跟上次那道一样。"三分钟写完。

两个人的差别，常常不在谁更聪明，也不在谁刷的题更多，而在一个很朴素的动作：一个人现场重新想，一个人从记忆里调取。

# 一、不考创造，那考什么：调取

翻开任何一张高一到高三的正规试卷，真正「从没见过」的题非常少。命题人做的事，主要是给母题「换装」：

把数字换成字母，把具体函数换成抽象的 f(x)；

把条件藏进定义域、藏进「对任意 x 都成立」；

把问法从「求值」改成「求范围」，从「证明」改成「是否存在」；

把两个熟悉的模块拼在一起。

题目变了装，但骨架没变。考生要做的事，是把妆卸掉，认出它是谁，然后调用当初解它的那套动作。

这跟用搜索引擎几乎一模一样：你输入的是题面里的特征（关键词），系统在你脑子里那个「做过的题库」里召回相似样本，你挑出最像的一个，检查一下条件对不对得上，最后输出解题步骤。

题面是 query，题型是索引，母题是库，第一动作是结果。

医生看病也是这个逻辑：不是每次重新研究病理，而是「症状 → 匹配疾病谱 → 调用治疗方案」。老手和新手的差别，很大程度在于见过的病例有没有被整理成「可检索的样子」。

所以「考的不是创造」并不是一句泄气的话，它其实是个好消息：创造没法教，检索可以练。

# 二、为什么「听懂了却做不出」：你存的是答案，不是入口

如果考试是检索，那么「听懂了却做不出」就有一句现成的解释：你存进去的东西，没有检索入口。

大多数人的笔记和错题本，记的是「这道题的完整解答」。但解答是结果，不是入口。考场上题面给你的不是解答，是几个特征词。你需要的映射是：

看到什么 → 想到哪一类 → 第一步做什么

而不是：

这道题 → 答案

举个例子。看到 f(x+1)=x²，求 f(x)。

会检索的人，脑子里的 query 是「括号里不是单独的 x」，命中的索引是「复合形式求解析式」，第一动作是「换元：令 t=x+1」，然后顺手校验一句「t 的范围要不要传给 f 的定义域」。

这三步里，真正值钱的是第一步——那个「括号里不是单独的 x」。它明明白白写在题面上，谁都看得见，但只有把它当成检索关键词记下来的人，下次才能召回。

再看一个更能说明问题的：

「对任意 x∈[1,2]，x²-2ax+1≥0 恒成立，求 a 的范围」

「存在 x∈[1,2]，使 x²-2ax+1≥0 成立，求 a 的范围」

题面只差「任意」和「存在」两个字，动作却正好反过来：一个取最小值，一个取最大值。检索的精度，就抠在这种字上。如果你的笔记里只写了「二次函数含参求范围」，这两个字没被标成信号，考场上就必然召回错误。

还有一个更隐蔽的坑：「看答案都懂」是「再认」，考试要的是「回忆」。再认是给你选项你能认出来，回忆是给你题面你要自己把方法调出来。刷题和看解析训练的大多是前者，试卷考的却是后者。所以「看解析两小时」，往往不如「合上书，把第一动作默写一遍」。

# 三、还有一层：找得到，还得「调得快」

「考的不是创造」这句话，还有个常被忽略的后半截：既然不靠临场发明，那靠的就是速度。

那位老师在同主题的专栏里给过一个通俗解释：大脑完成一个复杂动作，要靠一组神经元协同放电；同一条回路反复被使用，外面会裹上一层叫「髓鞘质」的绝缘层，越厚，信号跑得越快。所以熟练的本质，不只是「记得更牢」，更是那条通路被走得更快。他也直说：高中数学考试绝大部分内容，要的是反应快速，不是创造新的数学知识。

这跟「检索」是同一件事的两面：

建库、建索引，解决的是「能不能找到」；

有效重复，解决的是「多久能调出来」。

考场上两者缺一不可。120 分钟，一道题想五分钟才想起来，和不会做，在卷面上常常是同一个结果。

于是「刷题」这件事就被重新解释了：

无效的重复，是重复「看答案」——练的是再认，通路根本没被完整走一遍；

有效的重复，是重复「信号 → 第一动作」——每走一次，通路就快一点。

这也解释了老师为什么总让「重做例题、复习笔记」：那不是罚抄，是在给检索通路加速。但有个前提——重做时必须合上答案，从题面重新走一遍识别。对着解析抄一遍，速度一点都不会变快。

所以「题海低效」和「重复有用」并不矛盾：一个只堆样本、不建索引、也不练召回；一个反复走同一条已经建好索引的通路。差别不在题量，在重复的到底是哪一个动作。

# 四、把学法改成三件事：建库、建索引、练检索

如果这个观点成立，「学数学」就该被重排成三个动作。刷题只是第一件事里的一小部分。

## 1. 建库：一题一卡，只存三样东西

不是抄题，不是抄解答。每张卡只写：

触发信号：题面上看得见的那个词或结构（如「f(x+1)」「任意 x 恒成立」）；

标准第一动作：换元、分离参数、作图、分类讨论……只写第一步；

边界与易错：什么情况下这招不能用（定义域、参数正负、等号能否取到）。

按题型归类，不按章节归类。因为考卷不按章节出题。「求解析式」「恒成立与存在性」「奇偶性的应用」「单调性证明」「含参二次函数最值」——这样的抽屉才方便检索。一张卡 = 一个母题 + 2~3 个变装；一个学期 30~50 张，基本能覆盖大部分常规考题。高一函数尤其值得这么做，它是后面所有内容的母题库。

## 2. 建索引：把笔记写成「如果…就…」

记笔记时，把「这题的关键特征」写在最上面，解答放在下面。用这个句式：

如果看到 f(□) 里不是单个 x → 就先换元或配凑

如果看到「任意 / 恒成立」→ 就先想最值或分离参数

如果看到「存在 / 能成立」→ 最值方向反过来

如果看到求定义域 → 就列不等式组取交集，别先化简

有个硬要求：信号必须写成题面上看得见的字，别写成「数形结合思想」「函数与方程思想」这类抽象词。抽象词没法当搜索词用，检索系统读不懂。

## 3. 练检索：练「认」，而不只是练「算」

最被忽略、性价比最高的一个训练，叫限时识别：拿 10 道题，每题只给 30 秒，不求解、不算数，只写两行——「这是哪一类」「第一动作是什么」。写完对答案，看识别对了几个。这个训练练的正是考场上最卡人的那一环。很多孩子计算没问题，是卡在「这题到底是哪一类」上卡掉五分钟，后面全盘崩。

错题也别只改答案，要在旁边标一个检索失败原因，四类：

第一类，库里没有：这个母题根本没见过 → 补一张题型卡。

第二类，没认出变装：见过，但题面换了衣服 → 补信号标签。

第三类，动作生疏：认出来了，第一步之后卡住 → 单独练这一型 3 道。

第四类，召回错了：把「存在」当成「任意」 → 把易混信号摆在一起对比。

四种原因，四种完全不同的补救。不分类，错题本就只是「抄一遍正确过程」，下次照错。

最后是复做：错题在 3 天后、7 天后各做一次，且必须合上笔记。练的不是会不会，是「再次召回要多久」——也就是上一节说的那条通路，有没有变快。

# 五、考场上，按这五步走

1. 读题先圈信号词：定义域、任意 / 存在、奇偶、单调、最值、参数范围、括号里的复合结构……圈出来，检索才有 query；
2. 用 30 秒召回母题，写出第一动作；
3. 先校验，再动笔：这题和母题比多了什么限制？定义域变没变？等号能不能取？是「任意」还是「存在」？这一步能挡掉大半「会做但做错」；
4. 30 秒还没召回，立刻标记跳过，别在原地「现场发明」。先把能稳定检索到的分拿满，回头再攻；
5. 交卷前，对召回过的题只查边界条件，不重算全题。

# 六、说句公道话

我并不是说数学等于背题型、套模板。

恰恰相反，近年命题一直在「反套路、反刷题」。

所以检索的索引要建在结构特征上（括号里是不是 x、条件是全称还是存在、定义域有没有被藏起来），而不是建在「这题长得像哪道模拟题」上。

前者能迁移，后者一换包装就失效——这正是很多人「题型背了不少，一变还是不会」的原因。

检索到母题之后，剩下的推理、变形、运算，仍然要靠真功夫；每张卷子最后那 10%~15% 的新情境题，也确实需要现场构造，那部分比的是思维的深度。

但那是有余力之后的事。对大多数卡在 90~120 分的孩子来说，丢分的原因几乎从来不是「不够聪明」，而是三件很具体的事：库里没货、索引混乱、召回太慢。

还有一句想对家长说：「中学阶段不考创造」，说的是考试这件事的规则，不是数学这门学科的边界，更不是孩子不该有好奇心。别用这句话去否定他「为什么一定要这样」的追问——那种追问，是将来真正做数学的本钱。我们只是在说：先把卷子上那 85% 的分，用可训练的方式稳稳拿住。

好消息是，这三件事都能练，而且投入产出比最高。它不需要更聪明，只需要换一种整理方式，加上一点有效的重复。

如果今天只做一件事，我建议这个：

拿出最近一张数学卷子，别改错，别重算。每道题旁边只写两行——「它属于哪一类」和「第一步该干什么」。写不出来的那几道，就是你的库里真正缺的东西；写得慢的那几道，就是需要重复走几遍的通路。

写完你会发现，数学忽然从「每次都要重新面对的一堆新题」，变成了一个可以慢慢填满、越用越顺手的检索系统。

考试那天，你要做的不是灵光一闪，是把那一道题，稳稳地、快地找出来。
