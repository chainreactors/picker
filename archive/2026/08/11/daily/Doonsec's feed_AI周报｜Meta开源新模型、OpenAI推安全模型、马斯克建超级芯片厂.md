| 01 | Meta发布Muse Glimmer：单卡可跑的开源模型 |

|  |
| --- |
| 模型发布 8月10日 |

Muse Glimmer：让AI跑在一张显卡上

**核心特点：**开源权重（open-weight），专为小型Agent任务设计，**单张显卡即可运行**，大幅降低开发者硬件门槛

**定位：**降低推理成本、支持本地部署、保护隐私、离线可用

**扎克伯格宣言：**同步发表AI愿景长文，主张AI能力不应集中在少数公司手中，呼吁美国重新审视可能不利于开源模型开发者的政策

**下一步：**Meta同时准备**Muse Spark 1.2**，号称其最先进的前沿模型，形成"小模型打本地 + 大模型打前沿"的双线策略

AI能力不应成为少数公司的特权。 ——马克·扎克伯格

| 02 | OpenAI推出GPT-5.6-Cyber：网络安全专用模型 |

|  |
| --- |
| 安全模型 8月10日 |

GPT-5.6-Cyber：95%高级安全任务完成率

**Daybreak计划：**分为**Blue**和**Red**两级。Blue提供GPT-5.6 Sol访问（含安全防护），Red提供GPT-5.6-Cyber（专用于漏洞研究和渗透测试）

**能力对比：**GPT-5.6-Cyber在内部高级网络安全测试集中完成率**95.0%**，而标准GPT-5.6 Sol仅1.5%

**使用限制：**仅向获批的防御人员开放，合作方包括Accenture、IBM、PwC、CrowdStrike、Palo Alto Networks等

**战略意图：**在攻击者大规模部署自主网络攻击之前，将前沿AI能力交付可信防御人员

OpenAI同时透露，其即将推出的**Astra**模型存在潜在的关键网络安全风险，已收紧开发管控。
