## 修复内容

### 1. CheckIntegerArg / CVarToInteger float→int64 UB

* `static_cast<int64_t>(float)` 在值超 int64 范围时是 UB
* 改为范围检查，越界时报 "number has no integer representation"（对齐 Lua 5.4）

### 2. math.abs(INT64\_MIN) UB

* `llabs(INT64_MIN)` / `std::abs(INT64_MIN)` 是 UB
* JIT 内联和 native 双路径都改为检测 INT64\_MIN 时返回 float 9.22e18

### 3. math.random 多 bug

* `random(0)` 返回全范围随机整数（Lua 5.4 特殊语义）
* `random(负数)` / `random(l>u)` 报 "interval is empty"
* 宽范围用无符号运算避免有符号溢出 UB
* JIT 内联和 native 双路径都修复

### 4. string.byte 对齐

* 改用 CheckIntegerArg 保持与 string.sub 一致

## 验证

* 所有边界条件与 Lua 5.4.1 实测对齐
* 新增 test\_math\_critical\_boundary.lua 覆盖全部边界
