## CachyOS 支持 Easy Anti-Cheat v2

[![游戏](https://icon.solidot.org/images/topics/topicgames.png?123)](/search?tid=13 "游戏")

[Edwards](/~Edwards) (42866)发表于 2026年11月23日 23时37分 星期一 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85971&appkey=1370085986&title=CachyOS%20%E6%94%AF%E6%8C%81%20Easy%20Anti-Cheat%20v2 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自夏日永别**

基于 Arch Linux、专注于高性能优化的发行版 CachyOS 释出了最新版本 CachyOS November 2026，主要变化是为需要运行反作弊工具的 Linux 多人游戏提供了 Easy Anti-Cheat v2 支持。其它变化包括：用于回滚受损系统的新恢复环境 cachyos-recovery；引入新 UI 的 CachyOS Package Installer v2；取代 KMS 和 nvidia-module-loader 的 cachyos-drm-awaiter，确保在显示管理器启动前已完成加载 GPU 驱动；等等。
https://cachyos.org/blog/2611-november-release/
