# Highlighted changes

* Add time offset check against exchange clock.
* Add support for open interest data as informative pair (for exchanges that support this).
* Startup now fails if the strategy requests informative candle types the exchange doesn't support (e.g. `open_interest`).
* freqUI: Show available free balance in force-entry form.
* Add configurable liquidation warning messages in futures mode.
* Add `delete_custom_data()` support to allow removing data from trades again.
* Improved refresh logic for pairs with little activity.
* Security hardening in several places (config output redaction, freqAI identifier path traversal).
* Fixed funding fees being reset to 0 when a filled order...
