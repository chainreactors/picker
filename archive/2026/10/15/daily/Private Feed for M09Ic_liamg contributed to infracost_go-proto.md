Follow-up to [#108](https://github.com/infracost/go-proto/pull/108), from review of the parser PR.

* `MarkerLen(kind, id, n)` writes `%ic:<kind>:<id>:<n>%`, for a value whose length is known, e.g. `random_string` with `length = 6`.
* `Markers(s)` returns each marker's position and length. The parser uses it to keep markers intact through string functions.
* Markers now match in any case, so `upper("data-${random_pet.p.id}")` still becomes `DATA-*`.
