上周五快下班，同事小A探头盯着我屏幕："你录屏用的啥？Bandicam？OBS？"

我说都没装。

他愣了几秒。我当他面演示了一遍，他憋出一句：

"Windows就有？？"

我估计不止是他，很多人都不知道你电脑里装的软件，大概有一半系统自带功能就能平替。问题是从来没人告诉你。

今天我挑了3个自己天天在用的。不装软件、不花钱、打开就有。

---

## 一、录屏。不是截图，是录屏。Windows自己能干

一提录屏，脑子里蹦出来的不是OBS就是某款带水印的免费工具。

但Windows自己就带。藏在一个你大概从来没点开过的地方。

**Win+G。现在就按。**

弹出来那个叫 Xbox Game Bar。名字里带「游戏」，99% 的人瞟一眼就觉得跟自己没关系。

错了。它的录屏跟游戏半毛钱关系没有。

打开任意一个窗口，Win+G，屏幕上方出来一排工具栏。点那个小圆点，开始录。再点，停。视频自动存到「此电脑 → 视频 → 捕获」。

没码率选项，没编码器，没分辨率。就一个按钮。打开，点，录。

你说我只截个图？同一个面板里有个照相机，截图比你打开微信截图还快。

还有一手：**Win+Alt+R**。这个快捷键连 Win+G 界面都不用弹，直接开录。再按一次停。你给同事远程演示东西的时候，比掏手机拍屏幕强一百倍。这是给我妈演示怎么用打印机之后发现的。

Win10、Win11 通吃。按了没反应的话，去「设置 → 游戏 → Game Bar」把开关打开。

## 二、你电脑可以有好几个桌面，但你从来没切过

上班打开一堆文档、网页、微信，任务栏密密麻麻。点个东西找半天。桌面上临时文件摞了一堆，想清不敢清——万一哪个还有用。

然后你看到同事的 Mac，手指在触控板上一滑，换到一个干干净净的桌面，上面就一个浏览器和一个 PPT。你说："Mac 真好。"

**Windows 也有，比 Mac 出来得还早。**

按 `Win+Tab`。

屏幕上方出现一排缩略图，右下角有个「新建桌面」。点一下，第二个桌面就有了。

桌面1扔你的微信、邮件、杂七杂八的窗口。切到桌面2，干干净净，只放你真正要干的东西：一篇文档、一个浏览器、一个笔记。

**Ctrl+Win+← / Ctrl+Win+→ 来回切。**

左右一滑，聊天模式和干活模式秒切。老板走过来切桌面1，走远了切回桌面2。这不是摸鱼，这是工作流——我认真的。

还有个骚操作：你在桌面1的微信收到一条消息，想把整个微信窗口搬到桌面2？拖住窗口到屏幕顶，Win+Tab 打开，把窗口丢到桌面2缩略图上，松手。搬家完成。

这功能 Win10 起就有了。我用了三年。最大的变化不是什么效率翻倍，就是那个感觉——**开了 20 个窗口，但眼前只有 3 个。** 心理负担少了一大截。

## 三、打字打到手酸？Win+H，说完就打完

一个做自媒体的同学，每天几千字，去年手关节开始疼，腱鞘炎。咬牙买了个大几百的语音输入软件。

我问他："你为什么不用 Win+H？"

他很好奇的看着我说，这是干啥的？

其实微软从Win10 开始就内置了语音输入。随便哪个能打字的地方——Word、微信对话框、浏览器搜索框、记事本——按 `Win+H`，弹出一个麦克风条，说话，字自动打在光标位置。

我专门测过。正常语速、普通话，准确率 95% 往上。标点它自己加。你说「句号」它打句号，说「换行」它换行。比有些收费的还准。

前提是去「设置 → 隐私和安全性 → 语音」把「在线语音识别」打开。第一次用要下载一个几十兆的语言包，一分钟的事。

我有个习惯：有时候脑子里蹦出一个想法，来不及翻手机备忘录。直接按 Win+H，嘟囔几句，字已经在屏幕上了。比自己打字快三倍，而且想说什么就说什么，不会因为打字慢把话忘掉。

## 这三个，再串一遍

| 功能 | 快捷键 | 替你省了什么 |
| --- | --- | --- |
| 录屏 | Win+G / Win+Alt+R | OBS、Bandicam、录屏软件 |
| 虚拟桌面 | Win+Tab / Ctrl+Win+←→ | 多一台显示器、窗口管理软件 |
| 语音输入 | Win+H | 第三方语音输入软件 |

三个人加起来，不用装任何东西。不花钱，打开就有。
