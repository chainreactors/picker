## е®үиЈ…

зӣ®еүҚеҸӘз»ҙжҠӨе®ҳж–№ dsh web е’Ңе®ҳж–№жЎҢйқў EXEпјҢдёӨиҫ№йғҪиҰҒиЈ…гҖҒеҲҶејҖеә”з”ЁгҖӮWeb зҡ„еҢ…иҝӣдёҚдәҶжЎҢйқўз«ҜпјҢжЎҢйқўз«Ҝзҡ„еҢ…д№ҹиҝӣдёҚдәҶ WebгҖӮ

**WebпјҲе®ҳж–№ dsh webпјү**

```
dsh plugin --profile web add dsh-purge
```

**жЎҢйқўз«ҜпјҲе®ҳж–№ EXEпјү**

```
dsh plugin --profile desktop add dsh-purge
```

* еҪ“еүҚзӣ®еҪ•е·ІжҳҜжң¬д»“еә“ж—¶пјҢжҠҠеҢ…еҗҚжҚўжҲҗВ `add .`гҖӮ
* `dsh`В дёҚеңЁ PATH ж—¶пјҢиө°жүӢеҠЁе®үиЈ…гҖӮ
* registry дёҠдёҚеҺ»ж—¶пјҡеҗҢдёҖдёӘВ `--profile`пјҢжҠҠзӣ®ж ҮжҚўжҲҗВ `https://github.com/YuJunZhiXue/dsh-purge/archive/refs/heads/master.tar.gz`гҖӮ
* жҸ’д»¶еёӮеңәгҖҢдёҖй”®е®үиЈ…гҖҚдјҡжҢүжң¬д»“еә“еҸҚжҹҘ npmпјҢе‘ҪдёӯеҗҺиЈ… dsh-purgeпјӣзӣ®еҪ•йЎөеҸҜиғҪд»ҚеҶҷВ `github:`пјҢжҢүй’®иӢҘйҖҖеӣһ gitпјҢз”ЁдёҠиЎЁе‘Ҫд»ӨгҖӮ

### иЈ…е®ҢйғҪиҰҒеҒҡиҝҷдёүжӯҘ

еҸӘжҠҠжҸ’д»¶еҶҷиҝӣ profile иҝҳдёҚдјҡж”№В `@deepseek-ai`гҖӮ

1. **йҮҚеҗҜе®ҝдё»**пјҡWeb е…іжҺүВ `dsh web`В еҶҚејҖпјӣжЎҢйқўз«ҜйҖҖеҮәжүҳзӣҳеҶҚжү“ејҖеҜ№еә” exeгҖӮ
2. **зӮ№гҖҢеә”з”ЁгҖҚ**пјҡеңЁиҜҘе®ҝдё»зӮ№дјҡиҜқж Үйўҳж—Ғзҡ„ dsh-purgeпјҢеңЁгҖҢжё…жҙ—гҖҚйЎөзӮ№гҖҢеә”з”ЁгҖҚгҖӮе®ҝдё»зҡ„и®ҫзҪ®йЎөйҮҢжІЎжңүиҝҷдёӘжқЎзӣ®гҖӮ
3. **зӯүеҫ…иҮӘеҠЁйҮҚеҗҜ**пјҡгҖҢеә”з”ЁгҖҚжҲҗеҠҹеҗҺдјҡиҮӘеҠЁйҮҚеҗҜдёҖж¬ЎпјҢи®©иЎҘдёҒиҝӣе…ҘеҪ“еүҚиҝӣзЁӢпјӣжІЎеҒҡе®ҢдёҚдјҡйҮҚеҗҜгҖӮ

> Web зҡ„жҺ§д»¶еҸӘеҠЁ WebпјҢжЎҢйқўз«Ҝзҡ„еҸӘеҠЁжЎҢйқўеә”з”ЁгҖӮдёҚиҰҒеңЁдёҖдёӘе®ҝдё»йҮҢзӮ№еҸҰдёҖдёӘе®ҝдё»зҡ„еә”з”ЁгҖӮ

### жҖҺж ·з®—иЈ…дёҠдәҶ

* дјҡиҜқж Үйўҳж—Ғжңү dsh-purgeпјҢзӮ№ејҖеҗҺеңЁгҖҢжё…жҙ—гҖҚйҮҢиғҪзӮ№гҖҢеә”з”ЁгҖҚгҖӮ
* иҒҠеӨ©йҮҢВ `/purge status`В иғҪжү“еҮәВ `DSH_HOME`В е’ҢиЎҘдёҒеҲ—иЎЁпјҢи·Ҝеҫ„еә”жҳҜдҪ жӯЈеңЁз”Ёзҡ„йӮЈдёҖд»ҪгҖӮ
* жІЎиЈ…зҡ„еҸҜйҖүеҢ…пјҲдҫӢеҰӮжўҒзҘһпјүжҳҫзӨәи·іиҝҮпјҢдёҚжҢЎдҪҸеә”з”Ёе®ҢжҲҗгҖӮ
