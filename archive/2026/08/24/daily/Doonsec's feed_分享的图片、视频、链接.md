（1）prompts.chat

产品具有Web界面和API端点，可独立部署，漏洞描述涉及路径遍历和SSRF，属于Web应用

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokBXJgTkBn6HW7EDmFwGvBXvpAXVKOib7dShDwCwz3thPEgMoo0f1EPibakOhtzyaJ0iclwROcL3GPhkLfLKHZ0bAkMaSsQgZF4ibh4/640?wx_fmt=jpeg&from=appmsg)

（2）Citizen

Citizen 是 MediaWiki 的一款主题（Skin），通过 Web 界面呈现内容并深度集成于 MediaWiki 系统中，具备 Web 应用特征

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2vWkqc6FokDHoic91Z3G8osEiaKRI0EvrXGejwgRy1HMhdqDicnElQXsLlIu3IlHDvUAJIWxakCSb8N7VicECa4BH5urIPu5JkwxYOQ6R7mH9yk/640?wx_fmt=jpeg&from=appmsg)

(3)Bacula-web

Bacula-web 是一个基于 Web 的 Bacula 备份系统监控和管理界面，提供 Web 界面且可独立部署，符合 Web 应用产品定义。CPE 标注的 GitHub 仓库和官网均为官方来源，漏洞描述也指向该 Web 应用。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokBaVNaqgrib6OZtQyPGfU6hgx6UZEx52ibPb52qicHG5S5khiaN9FGDEmMHPTSed14GhactzT0Ho9S5ulJQDPcRlWcuyUkbHcGmPdU/640?wx_fmt=png&from=appmsg)

(4)Rebuild

该产品具有Web界面和Web服务特征（漏洞描述涉及WebInterceptor和/user/login API），属于可独立部署的Web应用系统。GitHub仓库存在且与CPE厂商名匹配，确认为开源项目。源码仓库首选GitHub（国际主流开源平台），官网首选getrebuild.com（厂商地址域名）。产品为低代码开发平台，属于Application类型。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokBCED51vBolOthpX4yYXnZIHxrgEnQjrjWO4p4Ob6yyyNH63krAibCyOp5CDSjA7oHP3bX344xrkIQgPhoK2FqzCeGpicrnUGjXU/640?wx_fmt=png&from=appmsg)

(5)Simple Admin

Simple Admin 是一个基于 Go 的后台管理系统框架/应用，具有 Web 管理界面（/sys-api/role/update 接口表明存在角色管理功能），符合 Web 应用产品定义。从 CPE 厂商名 ryansu 和 GitHub 仓库 suyuan32/simple-admin-core 的命名一致性、NVD 引用来源，以及文档站点 doc.ryansu.tech 的域名匹配来看，这是一个开源的后台权限管理系统项目。产品类型为 Application，因其提供完整的后台管理功能；领域分类涉及 Developer Tools（开发工具）和 Identity & Access（身份与访问管理，含角色权限管理）。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokBPEHeysLExvWibzI1JibEoXnNjPQDfU55eP3dbuOKrb4ibbnfglPC9gzAEdLOaDx4dsJAhPn4k8Uib2Q3W0YQtlWx8bdA23JFnWK4/640?wx_fmt=png&from=appmsg)

（6）Fedora Repository

Fedora Repository 是一款基于 Java 的开源‌数字资产管理系统，用于机构库、数字档案馆存储和管理复杂数字对象（如论文、数据集、多媒体），支持元数据标准（MODS, Dublin Core）及持久标识符。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokCbrVNOu5BIJ2PGkKib04bxTgJRKvURhJoiccZ1jL03OvfQQmiaS9siagKE2b03aIFaaBjzic4fa9SztKMQtIibrX1pJ3wkib3ZpCSqqo/640?wx_fmt=png&from=appmsg)

（7）ContentTools

ContentTools 是一个轻量级、框架无关的 ‌JavaScript 库‌，专为在网页中构建‌所见即所得（WYSIWYG）的内容编辑器‌而设计，支持直接编辑 HTML 元素并自定义样式与交互。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokCajgq8SaTAbgPHpmYyeSCibyibtjxcdPxRuV3PibgyYraZhKSUCpYiciaemVMfk1CuV6GmQ2Ra9DMqHxFQFPWoXHTrMfrYdwic1fUibo/640?wx_fmt=png&from=appmsg)

（8）Dozzle

Dozzle 是一款‌开源、轻量级、基于 Web 的 Docker 容器实时日志监控工具‌，无需数据库，通过浏览器即可实时查看、搜索和过滤多个容器的日志输出。‌‌

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokDSJqfrwhpUqQz3umRovmBuNMACLo5E9g88ACrkmKKxsTh8rEyIm5RB7Y0raY2GWBxHwyeIYvWVXuB6C0B0vLqdZmhYQoWBYeE/640?wx_fmt=png&from=appmsg)

（9）Vito

Vito作为一款免费且自托管的服务器管理工具，通过Docker容器化部署可以显著简化安装流程并提升系统稳定性。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokC7JECUMds7K2Of5ibKxRO1aZN5yCaEsdOK0ic9dDrqkqeNVzuMH2V7Napn0GMJEOuNtlib8SNebu2AUEvcB69dWKugJaLIBZuXak/640?wx_fmt=png&from=appmsg)

（10）FuelCMS

FuelCMS 是一款‌基于 CodeIgniter 框架开发的开源内容管理系统（CMS）‌，定位为‌开发者友好的混合型平台‌，兼具框架灵活性与 CMS 管理功能。‌‌

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokCdbGtxAUbskECJHVX5wtBVJM0rymKv8wWyG9FWLf1VSvs4mbzBosvTY7l6Xf2pXt6iciaLALK5rqdX6220oeZeiaS9NicnrpssGWY/640?wx_fmt=png&from=appmsg)

（11）Cal.com

开源预约调度基础设施，常被视为 Calendly 的开源替代。支持 1 对 1/群组/循环会议、双向日历同步（Google/Outlook/CalDAV）、时区检测、提醒与 Zoom/Meet/Teams 等视频会议；可自托管或云端使用，并提供 API 供开发者嵌入自有产品。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2vWkqc6FokB58L4mgagkmkzz6Ff9oE9iasK6wkNoeSNKbpSMK7jkN8icyRaFh3EmlesNly7SkLqKWpkEhIylOtVUOR1uOULytcnqVDibPUjEZk/640?wx_fmt=jpeg&from=appmsg)

（12）Indico

CERN 开发的开源 Web 活动管理系统。覆盖讲座、会议、工作坊到大型学术会议全流程，支持摘要征集与评审、注册缴费、论文审稿、拖拽式日程、胸牌打印、会议室预订及视频会议集成，并可长期归档活动资料。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokDORIAohkj2g0PQxH9v0FWfzdmWk3TrguJBO5YUic1CnTSv9D9ujjmaibcHySuoTJFlpe4k2bMQJohkSiaKJygv8vaXFe2EahzxC0/640?wx_fmt=jpeg&from=appmsg)

（13）HedgeDoc

开源自托管协作 Markdown 编辑器（前身 CodiMD）。浏览器内实时多人编辑，带分屏预览；支持演示模式（reveal.js）、图表/流程图嵌入、权限控制与版本历史，适合团队笔记、Wiki 与协作文档。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokCzGKYKk9FfXeGIGX46RlOc0zSxLYJkygVV5NtTWNjViavSQYaKW0FDKvsTZpXydhoucfHpWQBOAmCUgThJthdw4mGuyGESEfD4/640?wx_fmt=jpeg&from=appmsg)

（14）Emoncms

OpenEnergyMonitor 项目的开源 Web 应用，用于采集、记录与可视化能源、温度等环境数据。提供仪表盘、高级图表与灵活输入处理，可本地部署（如 Raspberry Pi/emonPi）或使用 emoncms.org 托管，常与 CT 电表、温湿度传感器等硬件配合使用。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2vWkqc6FokD5m9IBtUjZGb339w0KprjOrAAYOZd3tpKhN3YEvOzLL0AEF19iccxGNzdQ9lVd62V90v3lKl8srmThfqnnzjujEfMghNLGITdg/640?wx_fmt=jpeg&from=appmsg)

（15）Red Hat Single Sign-On / Keycloak

Red Hat Single Sign-On（基于 Keycloak）是企业级身份认证与访问管理产品，提供管理控制台与用户登录门户。

![](https://mmbiz.qpic.cn/mmbiz_png/2vWkqc6FokDtGwhh1oUjcv0TnTr9ibp3waic45pc1WxwRlDoeUMJbVgfmB2v86Vl41sTc5nM1x4o8n3bvN1xiaibxOYhOe3A1FAaxxWia5J6H8Mc/640?wx_fmt=png&from=appmsg)

（16）CKEditor 5

CKEditor 5 是现代化的 JavaScript 富文本（WYSIWYG）编辑器，通常作为组件嵌入各类 Web 应用以提供内容编辑能力；官方站点为 ckeditor.com。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokCtIXXKC6ibmFnibMwPWRyWn3nhDu2Ga6E5Gib7UfuleKNQxQupbQS4kBHNdI4ygkTpu6zusb72jw1j4Jn2GpMMjbGHAQTz2Tib8ibE/640?wx_fmt=png&from=appmsg)

（17）CVAT (Computer Vision Annotation Tool)

CVAT 是交互式视频与图像标注工具，提供浏览器端标注界面，用于计算机视觉数据集标注，可独立部署。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokB61n5S0biaiauo6zGvaBFzYsPslmCPLYDrJXfmN9JJu4vQ2mCWL50hSZV2giaot0RwQsupETh9NcsOGy7nyEFxdlHDokcN5iaagg8/640?wx_fmt=png&from=appmsg)

（18）PublicCMS（已公开）

PublicCMS 是 Java 内容管理系统，提供管理后台、模板与文件上传等能力，用于站点内容发布与维护，可独立部署。

![](https://mmbiz.qpic.cn/mmbiz_jpg/2vWkqc6FokBib5mtb3ucicXcxSog37edicuib3cchB7IUk8KwdxDW5XWtqNftnsFTuqp25IqLyIbs2HAHDlJMUorN5ptom3icXpqwLNxItAdDBZo/640?wx_fmt=jpeg&from=appmsg)

（19）Flarum

Flarum 是开源论坛 / 社区软件，提供讨论区前台与后台配置，可独立部署运行社区站点。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/2vWkqc6FokCMCAmlCcaPJRqiax4wjgbTW8MbsJJLoPCxnXz1sBmy0qWSa6pvnmqIvbQ7c9mgAzWWQ2Vk1eVA33VuCRn4C3iaxEaYibqpJ9icsks/640?wx_fmt=png&from=appmsg)

（20）Swagger Petstore

Swagger Petstore 是 SmartBear/Swagger 官方示例应用，用于演示 OpenAPI/Swagger 规范，提供 REST API 与 Swagger UI，可独立部署。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/2vWkqc6FokBvqhaWicjTlHQkIKpMId6TpDOrxx5pdT4W9A2w6iaBjufU5hIISrPBvD1ia3iafCtOsPy0auMYARLbnU1WabCXfumZuCMzmC9YJAA/640?wx_fmt=jpeg&from=appmsg)
