## Microsoft Defender 支持 Linux 桌面

[![Linux](https://icon.solidot.org/images/topics/topiclinux.png?123)](/search?tid=7 "Linux")

[Edwards](/~Edwards) (42866)发表于 2026年10月15日 14时27分 星期四 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=85617&appkey=1370085986&title=Microsoft%20Defender%20%E6%94%AF%E6%8C%81%20Linux%20%E6%A1%8C%E9%9D%A2 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自圣天秤星**

微软的企业安全软件 Microsoft Defender 正式支持包括 Ubuntu、Debian、Fedora 和 RHEL 在内的 Linux 发行版，其功能包括防病毒保护、端点检测与响应、漏洞管理、威胁搜寻以及设备隔离。Microsoft Defender 是企业安全套件，集成在 Windows 11 中的免费安全软件叫 Windows Defender，Windows Defender 是 Microsoft Defender 中一个功能有限的防病毒组件。使用 Microsoft Defender 需要用户订阅微软的服务，订阅 Microsoft Defender for Endpoint Plan 2 或者 Microsoft 365 E5 或 E7。
https://www.neowin.net/news/microsoft-defender-now-supports-linux-desktops/
