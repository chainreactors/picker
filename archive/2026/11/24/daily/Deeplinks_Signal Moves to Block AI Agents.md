# Signal Moves to Block AI Agents

![People communicating on devices with encryption, art by Chelsea Saunders](https://www.eff.org/files/styles/resized_banner/public/banner_library/encryption-poc-chelsea-saunders.png?itok=liGKio8N)

Artwork by Chelsea Saunders (CC-By)

[Signal announced an update](https://signal.org/blog/protecting-your-privacy/) to its mobile apps on iOS and Android that seeks to curb issues with AI agents accessing private chats. This is a useful new barrier against a problem we’ve been highlighting this year in our [Encrypt It Already](https://encryptitalready.org/) campaign. And good news, it’s enabled by default so you don’t need to do anything except update the app.

Over the last year, both Google and Apple\* have released AI features in their operating systems that can read the contents of apps. One of the ways it can do this is through screen analysis. Google calls this feature “[Intelligent Screen Context](https://support.google.com/gemini/answer/15850607?hl=en),” while Apple refers to it as either “[Onscreen Awareness](https://www.apple.com/newsroom/2026/09/siri-ai-a-profoundly-more-capable-and-personal-assistant-is-here/)” or “[Visual Intelligence](https://support.apple.com/guide/iphone/siri-ai-ask-siri-about-whats-on-your-screen-iphmk4p88mkuky/ios).”

Apple now provides a way [to block Siri AI’s](https://www.eff.org/deeplinks/2026/10/victory-you-can-now-exclude-apps-siri-ai) access to apps, but by default every app is available to Siri AI, so it’s up to the user to go in and put these guardrails up. Signal requests that protection on your behalf. Google doesn’t currently offer any sort of similar option. So Signal on Android does the best it can, by turning off screenshots when it detects an AI assistant attempting to access the screen. [Signal’s solution](https://support.signal.org/hc/en-us/articles/11338514641306-Screen-security-blocking-Google-Gemini-and-Siri-AI) helps ensure that, unless you go in and *change* the setting yourself, it defaults to the most private option.

While this is a clever solution to the current issues facing Signal (and potentially useful for any other app that does its best to promise privacy), we need all operating systems to provide stronger methods and clear documentation to developers so they can safeguard their users without needing to jump through hoops. Both developers and users should have the tools they need to safeguard their own data from AI agents and other AI tools.
