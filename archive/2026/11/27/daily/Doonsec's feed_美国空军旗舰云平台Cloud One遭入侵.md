# 2026年11月27日，路透社援引三名知情人士的说法报道，黑客已经侵入美国空军旗舰云计算平台Cloud One。平台上承载大量战术、人员与后勤数据，一旦被外部人员访问，涉及面可能很广。截至目前，黑客身份、入侵的完整范围，以及是否已有数据被窃取，路透社均无法确认。

# 升级期间暴露，平台运作受到干扰

两名知情人士介绍，这起入侵是在过去一个月左右的系统升级工作中被发现的，发现之后Cloud One的正常运作随即受到干扰。

美国空军在给路透社的声明中表示，军方不对特定网络和系统的安全态势、漏洞或运行状态发表评论，并称会持续采取审慎措施，保护空军部的信息、系统与任务能力。

# Cloud One：军方的一站式云上中枢

Cloud One于2017年启动，定位是美国空军IT需求的一站式平台。平台整合Microsoft、Amazon、Oracle和Alphabet四家供应商的资源，为数十个应用提供支撑，覆盖人员数据、薪资发放、物流与维护等业务。

这套平台上承载的系统分量不轻。其中包括Cloud-Based Command and Control，即基于云的指挥与控制系统，负责汇总来自北美各地的防空雷达和其他数据源；另有Theater Integrated Combat Munitions System，战区综合战斗弹药系统，用于追踪全球200多个美国空军基地的炸弹与导弹库存。

承包商方面，SAIC长期担任Cloud One总承包商，合同持续到2025年，之后由Leidos接手。SAIC没有回应置评请求，Leidos则把问题转介给美国空军。两名消息人士称，Cloud One是美军规模最大的云平台之一。一名消息人士直言，“这里要是出了安全漏洞，不是小事”。

# 被攻破的control plane，相当于拿到万能遥控器

一名消息人士透露，网络入侵者利用某个软件漏洞进入了系统的control plane，也就是控制平面。

在云平台架构里，control plane负责下发管理指令、调配计算与存储资源，属于整个集群的管理层级。这名消息人士把它比作万能遥控器：理论上，拿到这一层权限的人可以查看军用飞机的运行状态，也可以查看备件的调拨情况。不过目前尚不清楚，此次事件中的入侵者是否实际执行过这类操作。路透社也未能确定攻击者具体利用了哪一个漏洞。

调查人员已经请求美军Cyber Command，即网络司令部，介入评估事件造成的损害。网络司令部没有回应置评请求。

# 迁移暂停，补丁推送中断

入侵被发现之后，平台上出现了一连串具体干扰。

两名消息人士与另一名知情人士表示，把后台应用程序迁移到Cloud One的工作已经暂停。应用上云长期是军方优先事项，这次停顿意味着原有迁移计划被搁置。

已经在Cloud One上运行的应用同样无法更新，空军人员因此无法安装修复补丁。这段时间正值科技行业陆续披露一批新的严重软件漏洞，补丁中断的影响被进一步放大。第五名消息人士称，部分用户的administrator rights，即管理员权限，已经被撤销。

上述五名消息人士均要求保持匿名。

# 近期联邦机构遭遇的连环网络事件

这起事件发生在AI驱动入侵引发普遍担忧的背景下。AI模型能够在广阔的攻击面上迅速探测弱点，对基于云的网络来说，这类威胁尤为严重。模型可以批量扫描暴露的接口、配置疏漏和未修补组件，再把可利用的环节串联起来，攻击面越大，自动化筛查带来的风险越突出。

Cloud One并非近期唯一出问题的联邦系统。过去两个月，美国政府还在处理另外至少六起已披露网络安全事件的后果，覆盖执法、情报、国防、内务和财政多条线。

联邦调查局FBI先后涉及两起。9月，其招聘门户FBIJobs.gov被入侵，入侵组织ShinyHunters声称获取了几乎全部现任、前任雇员及求职者的个人资料，事后追溯到承包商未给Oracle PeopleSoft系统打补丁，攻击者随后进入FBI管理的AWS GovCloud环境。11月20日前后，全国犯罪信息中心NCIC被曝疑遭入侵，这套系统支撑联邦、州和地方执法机构查询在逃人员、失踪人员、犯罪历史和失窃车辆记录，目前尚不清楚是否有数据被盗，FBI也未公开确认这起事件。

国防部下属国防人力数据中心DMDC的一套文件共享系统存在漏洞，未授权访问从2025年10月持续到2026年7月中旬，前后接近九个月。被访问记录包含姓名、出生日期、社会保障号、联系方式和军种专业等个人信息，涉及数百万现役及退役军人，事件随后引发集体诉讼。

10月28日，泄密网站Distributed Denial of Secrets公开逾4万名国土安全部DHS雇员的信息，覆盖移民与海关执法局、海关与边境保护局、国土安全调查局、网络安全与基础设施安全局等下属机构，内容包括姓名、电话、邮箱和岗位归属，部分记录还涉及特种行动、监控、计算机取证和卧底岗位。这批数据据称经Okta单点登录服务，被一个自称“和平部”的组织获取。

11月24日，《纽约时报》率先报道，中央情报局CIA与国家情报总监办公室ODNI共用的一套开源情报OSINT分析系统遭到入侵。该系统聚合公开资料、社交媒体帖子、卫星图像和商业数据集，用于情报分析。事件触及部分非机密信息，机密系统未受影响，其他联邦机构的信息可能也在暴露范围内。攻击者身份和具体外泄数据尚未确认，ODNI称核心能力和涉密系统没有受到干扰，CIA拒绝置评。

11月25日，财政部下属金融犯罪执法网络FinCEN确认部分系统遭到未授权访问，已主动将一部分系统下线处置。

Cloud One长期处于黑客的重点目标之列。2023年，在线刊物FedScoop刊载过一篇平台管理层的评论文章。文中称，团队在抵御入侵尝试方面取得100%的成功率，并称遭遇的攻击尝试数量惊人。管理层在文章里写道，安全问题上绝不允许有任何差错。

对照这次披露的入侵事件，这套旧表述与平台当前处境之间已经形成明显落差。至于Cloud One上究竟留下多少访问痕迹、哪些数据被触及，现有公开信息还不足以给出结论。
