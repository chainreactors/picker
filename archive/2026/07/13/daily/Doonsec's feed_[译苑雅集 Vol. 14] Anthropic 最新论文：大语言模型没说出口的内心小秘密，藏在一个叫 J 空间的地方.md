当你阅读这句话时，大脑中的神经回路正在调整你的姿势、控制你的呼吸，并把屏幕上的线条和曲线转换成可识别的文字。这些处理大多不会进入你的意识。但大脑中发生的一些活动，你确实能够感知，例如脑海中突然浮现的一幅画面，或是你有意识地计划去哪里购物。神经科学家和哲学家有时把后一类大脑活动称为“意识可及”，以区别于那些在无意识中进行的处理。这类活动具有一些特殊属性：我们能够描述它、控制它，并用它进行有意识的推理。其他大量自动处理则在我们毫无察觉的情况下完成。

在一篇新论文中，我们提供了证据，表明类似的区分也已经出现在 Claude 这样的现代语言模型中。我们发现，Claude 内部形成了一小组神经活动模式。与其他内部处理过程相比，这些模式发挥着一种特殊作用。

我们把这组模式称为 J 空间。这个名称来自我们发现它们时所使用的技术，其中涉及一个名为“雅各布”（Jacobian）的数学概念。J 空间中的每一种模式都与某个特定词语相关。但某种模式被激活，并不意味着模型正在说出这个词，只表示这个词正浮现在模型的“脑海”中。你或许听说过语言模型的“草稿纸”或“思维链”，也就是模型在推理时写给自己看的文本。J 空间与此不同，它默默运行于模型内部的神经激活之中，让模型无须把某个概念写下来，也能对它进行思考。值得注意的是，J 空间并非由我们设计或编程实现，而是在 Claude 的训练过程中自行涌现出来的。

*J 空间揭示了模型输出中未出现的内在想法。*

我们发现，与 Claude 的其他处理过程相比，J 空间具有一系列独特属性：

* Claude 能够说出这些表征的内容。如果你问 Claude 正在想什么，它会告诉你 J 空间里有什么。J 空间之外的表征则不太容易被它说出来。
* 它还能根据要求调节这些表征。如果你让 Claude 思考某件事，或者要求它只在脑中默默解决一个问题，J 空间中相应的模式就会被激活。相比之下，它很难调节 J 空间之外的模式。
* Claude 会利用 J 空间进行内部推理。如果你要求 Claude 解决一个需要多个步骤的问题，即使它没有把中间步骤说出来，这些步骤也会在 J 空间中被激活。尽管这些 J 空间模式的激活幅度小于其他表征，它们仍然会在因果层面影响 Claude 完成这类任务的表现。
* J 空间中的表征能够灵活用于多种任务。例如，一旦“法国”在 Claude 的 J 空间中被激活，模型就可以回忆它的首都、法定货币，或它所在的大洲。
* 不过，尽管 J 空间发挥着重要作用，语言模型所做的大部分事情并不需要它参与，例如流畅表达、回忆简单事实和正确使用语法。在实验中，当我们阻止 Claude 使用 J 空间时，它仍然能够正常互动，但失去了高阶认知功能。

*全局工作空间的五个功能属性，以及我们用于在语言模型中测试这些属性的实验的风格化插图。*

我们的实验受到神经科学中一个重要理论的启发。这个理论试图解释“意识可及”如何运作，被称为全局工作空间理论。该理论把大脑描绘成一组并行工作的专门化系统。这些系统在无意识中运行，彼此之间基本相互隔离。当一条信息进入一个小型共享通道，也就是“工作空间”时，它就会成为意识可以访问的信息。工作空间会把它广播给其他大脑系统，让这些系统能够看到并加以利用。根据我们的发现，我们认为 J 空间在 Claude 中扮演着类似的“工作空间”角色。例如，我们发现 Claude 的 J 空间与神经网络其他部分之间存在格外强的连接，使它能够承担这种广播功能。

这些发现并不能说明 Claude 是否像人类一样具有意识，也无法说明它是否拥有任何感受。我们会在文章结尾重新讨论这个问题。但无论 J 空间在哲学上意味着什么，它对我们而言都是一种实用工具，因为它让我们能够看到 Claude 想了什么，却没有说出来。例如，我们可以借此发现 Claude 在内部察觉自己正在接受测试、有意生成虚假数据，或是在追求一个由我们在训练期间植入的隐藏目标。我们还开发出一种技术，可以影响 Claude 的 J 空间中哪些模式被激活，进而影响它的决策。

更广泛地说，这些发现改变了我们对 Claude 心智运作方式的理解。它们揭示出一个具有特殊地位的心智工作空间，可以在海量更自动、更僵化的处理过程之中承担有意识的推理。Claude 的内部状态已经自行组织成一种令人联想到人类心智的结构，远非一团杂乱无章的数字。

本文是对一篇内容详尽得多的研究论文(http://transformer-circuits.pub/2026/workspace/index.html)所作的简要概述，你可以在论文中了解实验的更多细节。我们还发布了一个代码仓库，其中包含核心方法的开源实现，并与 Neuronpedia 合作，提供了一个在开放权重模型上展示这些方法的交互式演示。

# 我们如何找到 J 空间

# 这项研究的起点，来自人类“意识可及”思维的一个关键特征：它们往往可以用语言表达出来，而无意识处理通常做不到这一点。如果一个想法对你而言是意识可及的，那么有人问起时，你通常可以把它描述出来。我们开始在 Claude 中寻找具有相同属性的表征，也就是那些能够影响 Claude 可能说什么的表征。这里关注的未必是 Claude 此刻正在说什么，而是当别人问起时，它**可以**谈论什么。我们使用的技术叫作雅各布透镜（Jacobian lens），简称 J-lens。对于 Claude 词汇表中的每一个词，J-lens 都会找出一种内部活动模式，提高 Claude 在未来某个时刻说出该词的可能性。

当我们把这面透镜应用于 Claude 的内部活动时，会得到一组可以直接读取的词语，它们就是当时 J 空间中的内容。Claude 会通过一系列被称为“层”的内部阶段来处理文本。把这项技术应用于不同层，我们就能观察 J 空间中这些没有说出口的词语如何随着模型逐步决定说什么而不断变化。

J 空间中出现的内容，远远超出了 Claude 正在阅读或书写的文本。当 Claude 读到一段存在错误、但还没有任何人指出问题的代码时，它的 J 空间中会出现“ERROR”。当它读取由字母组成的原始蛋白质序列时，J 空间中会出现这种蛋白质的生物学功能。当它读到一些表面上是搜索结果、实际暗藏操纵意图的内容时，也就是遭遇一种被称为“提示词注入”的攻击，J 空间中会出现“injection”和“fake”。当我们要求 Claude 解答一道需要多个步骤的数学题时，中间步骤会按照正确顺序逐一出现在 J 空间中。因此，J 空间虽然是通过寻找可能被说出口的表征而发现的，却仍然揭示了 Claude 的内部思维。从某种意义上说，这类似于一些人用语言进行思考，却无须把这些话说出声。

*雅各布透镜在不同层面上对六个提示进行解读。在每种情况下，该镜头都会揭示文本中未曾出现的内部评估或计算过程：推理或数学问题的步骤、是否存在错误、图像识别、蛋白质的功能，以及对搜索结果是否造假的怀疑。*

# Claude 会说出 J 空间中的内容

# 第一组实验测试了 J 空间如何参与 Claude 的语言报告。在其中一项实验中，我们要求 Claude 从某个类别里默想一个对象，例如想出一项运动，然后说出它的名字。如果我们在 Claude 回答**之前**立即读取雅各布透镜，就能看到它选了什么：“Soccer（足球）”排在列表首位，而 Claude 果然回答了“soccer”。不过，仅凭这一点只能说明两者存在相关性。Claude 的答案可能来自 J 空间，也可能是在其他地方做出决定后，由 J 空间把结果映射出来，就像一块记录比赛进程、却不会影响比赛的记分牌。

为了验证这一点，我们进行了直接干预。我们从 Claude 的神经网络中移除“Soccer”模式，换成强度完全相同的“Rugby（橄榄球）”模式，其他部分一概不动。随后，Claude 报告说，它想到的运动是橄榄球。如果 J 空间只是一块记分牌，只是被动记录其他地方已经做出的决定，那么修改它不会产生任何影响，Claude 仍然会回答“soccer”。但 Claude 的答案随修改而改变，这说明答案确实是从 J 空间中读取出来的。

在另一项实验中，我们告诉 Claude，可能有一个想法被注入了它的脑中，并要求它说出自己是否察觉到了什么。例如，在下面的例子中，当 Claude 仍在阅读问题时，我们向它的 J 空间注入了“lightning（闪电）”模式。Claude 随后报告说，被注入的想法与闪电有关。我们用许多不同概念重复实验，都得到了相同结果。

# Claude 能按要求控制自己的 J 空间

# 我们测试的第二项属性，是 Claude 能否在接到要求时调节自己的 J 空间，就像人类可以在脑中把注意力集中于一幅图像或一个词语。我们让 Claude 在抄写一个与绘画有关的句子时，把注意力集中在柑橘类水果上。在它抄写文字的过程中，J 空间中出现了“orange（橙子）”和“fruits（水果）”，以及描述这一心智活动本身的“thinking（思考）”和“imagery（意象）”等词。我们还可以要求 Claude 在脑中做数学题。让它一边抄写同一个句子，一边计算 3² − 2 时，J 空间中先出现了“nine（九）”，随后在更深的层中出现“seven（七）”。值得注意的是，Claude 的输出里完全没有提到水果或算术，只有它抄写的那个关于绘画的句子。数学运算完全发生在模型内部的 J 空间中。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/NBNzfW7CHBV66YSe43NCU3Kgp7IAJLdOJPILNuyxIdAr1Q9zOWE31rv6zhP7LmJROamibMvQoFxOhNWnr9KnVE9tKQicwuxqexDuzD8Vky3yo/640?wx_fmt=jpeg&from=appmsg)

*当 Claude 抄写关于一幅画的句子时，J 镜头显示了它被指示记住的内容（“橙色”；中间值“九”和答案“七”），以及描述记住它的行为的词语（“思考”、“专注”）。*

Claude 对 J 空间的控制并不完美。当我们要求它**不要**想某个事物时，这个概念在 J 空间中的激活程度低于明确要求它去想时，却远高于从未提及这个概念时。让 Claude 回避一个想法，反而会在一定程度上把它带入脑海。这很像人们被告知“不要去想一只白熊”时发生的情况。Claude 似乎也会察觉自己的控制失败：当被禁止的概念突破抑制时，“damn（该死）”和“failure（失败）”也经常同时在 J 空间中被激活，仿佛 Claude 意识到了自己的失误。

# Claude 在 J 空间中思考

# 在前面的雅各布透镜读数中，我们看到一道数学题的中间步骤出现在 J 空间里。但一个概念出现在 J 空间，并不一定意味着 J 空间承担了实际的认知工作。实际计算完全可能发生在其他地方，J 空间只是被动地把它反映出来。为了验证 Claude 是否真的利用 J 空间进行推理，我们再次采用了表征替换技术。

来看这个提示词：“会织网的动物有多少条腿？”Claude 要回答这个问题，首先需要判断这种动物是蜘蛛，然后回忆蜘蛛有几条腿。“spider（蜘蛛）”一词既没有出现在提示词里，也没有出现在 Claude 的回答里，因为它只回答“8”。蜘蛛只是 Claude 在内部使用的一个中间步骤。J-lens 显示，在 Claude 处理到一半时，“spider”会被激活，而替换这个模式会改变最终结果。如果把“spider”模式替换成“ant（蚂蚁）”，Claude 的答案就会从“8”变成“6”。

Claude 推理的第二步会从 J 空间读取输入，并以我们写入的内容为准。我们在其他类型的思考中也观察到了同样现象。当 Claude 创作一组押韵的对句时，它会提前选好押韵词，这个计划使用的词会在诗行开头就出现在 J 空间中。如果在 J 空间里把它换成另一个词，整行诗都会随之改变。

*通过交换 J 空间的内容来改变 Claude 的无声推理的两个例子。*

我们还测试了 J 空间中的表征能否灵活使用，也就是同一个表征能否为多种不同任务提供输入。这是全局工作空间理论强调的关键属性之一。为了检验这种灵活性，我们向模型提出四个问题，分别询问法国的首都、语言、所在大洲和货币。随后，我们在 J 空间中把“France（法国）”替换成“China（中国）”，四种情境所做的干预完全相同。Claude 分别回答了“Beijing（北京）”“Chinese（中文）”“Asia（亚洲）”和“Yuan（人民币）”。换句话说，四种不同的下游计算都读取了同一次 J 空间修改，并且分别正确使用了它。如果 Claude 针对每一种问题都单独存储了一份国家表征，这次修改最多只能影响其中一个答案。四个答案同时发生变化，说明它们读取的是同一个共享表征。工作空间的作用正在于此：信息只需写入一次，许多不同系统都可以使用它。

![](https://mmbiz.qpic.cn/mmbiz_jpg/NBNzfW7CHBWib7GcpeWiaoTJEucNyNyle9iau5eaw3MIGc9qzMCERlJicicicNAKFNAkoyhI4Vkr7KBWItCypFEUvblQv5liaMtUu3xyVUO9Z8axh4/640?wx_fmt=jpeg&from=appmsg)

*同一个 J 空间表示可以有多种用途。同样的“法国”→“中国”的互换，会改变Claude关于首都（巴黎→北京）、语言（法语→汉语）和洲（欧洲→亚洲）的答案。*

一个概念的表征为什么能够服务如此多的任务？前文提到，J 空间与 Claude 神经网络其他部分之间的连接似乎格外密集。对于任何一种活动模式，我们都可以测量网络中的不同组件与它连接得有多强，也就是有多少组件能够从该模式读取信息，或向其中写入信息。按照这一指标衡量，J 空间模式极为突出：读取和写入它们的组件远多于普通模式，在网络的某些部分，差距达到约一百倍。这正是广播枢纽应有的连接方式，许多系统向其中发布信息，另一些系统再从中读取。

# Claude 的自动处理会绕过 J 空间

# 在人类大脑中，大部分处理都不会进入意识。阅读时，我们不会刻意思考如何解析语法，走路时也不会刻意思考怎样保持身体平衡。同样，我们发现 Claude 的大部分处理**并不**涉及 J 空间。J 空间在同一时刻只能容纳几十个概念，在 Claude 整体内部处理活动中的占比不到十分之一。那么，神经网络的其他部分都在做什么？

为了找到答案，我们尝试彻底删除 J 空间。在 Claude 处理文本的每一个位置，我们都会移除 J 空间中最活跃的内容，同时让其他部分保持不变。没有 J 空间之后，Claude 仍然能够完成的事情，就是神经网络其他部分可以独立处理的工作。

结果表明，网络的其他部分能够完成相当多的任务。没有 J 空间，Claude 依然可以流畅表达、判断情感倾向、回答选择题，并且从文章中提取事实的能力与此前大致相当。它失去的是那些需要一定高阶思考的能力：多步推理表现下降到接近于零，摘要和押韵诗歌创作的表现，甚至低于一个规模小得多但未经干预的模型。
