## 01攻击者视角（情报通报，用于防守检测）

**1.1 定向攻击 IP（10 个）**
本期监测发现 10 个 IP 对 10 家重点单位存在攻击行为，攻击方式包括命令注入、跨站脚本攻击、扫描探测、代码注入、SQL 注入、组件漏洞攻击等。归属地以国内为主（上海、中国台湾台北、天津、江苏常州 2 个、河北张家口、湖南长沙），含加拿大魁北克蒙特利尔、美国（2 个，含加利福尼亚州洛杉矶）共 2 个境外。完整列表见 05 完整附表 · 附件一。

**1.2 恶意样本（7 个）**
本期捕获 7 个恶意样本，文件名包括 win32-googlqiang.msi（伪装成安装包）、KeyboardTestUtility.exe（伪装成键盘测试工具）、lat.exe、launcher.exe、m.exe、短信客户端2.0 版N.exe、洗群话术总结..bat（bat 脚本，典型钓鱼 / 远控载荷）。完整 MD5 与文件名见 05 完整附表 · 附件二。

**1.3 银狐组织 IOC（16 条）**
银狐组织近期针对金融、教育、能源行业实施钓鱼攻击，窃取用户敏感信息。本期 IOC 含 10 个全端口恶意域名（均集中在 cicfo.com 下，含 eddf0291-…-13a1d3d5c249.cicfo.com、3e9bb0fd-…-023f7c03afaf.cicfo.com 两个 UUID 特征子域）与 6 个恶意 IP 端口（31.13.208.209:443/80、103.73.119.124:8000、104.234.224.178:80、8.217.46.147:8917、103.240.196.115:7811）。攻击者把 C2 基础设施压到同一个域名下、注册一堆子域批量复用，拦截时别只封单个子域，得把整个 cicfo.com 拉黑。完整列表见 05 完整附表 · 附件三。

**1.4 高频漏洞和高危攻击 IP（30 个）**
安全监测团队本期收录 18 个高危漏洞，关联 30 个高危攻击 IP，涵盖金和 C6 SQL 注入、赛蓝企业管理系统任意文件读取、Fortinet FortiWeb（CVE-2025-25257）、蓝凌 OA 远程代码执行、泛微 e-cology SQL 注入、GeoServer SSRF、Agent Zero、SP Page Builder（CVE-2026-48908）、Balbooa Forms（CVE-2026-56291）、禅道 env.bak 等。其中禅道 env.bak 敏感信息泄露以 15 例（50%）位居第一，金和 C6 4 例、SP Page Builder 3 例紧随其后。完整列表见 05 完整附表 · 附件四。

## 03老宋说

**技术本质：**这期最该盯的不是攻击量，是那 15 例禅道 env.bak——9.1 刚清零，9.2 弹到 3、9.3 到 6、9.4 到 7、9.5 到 13、9.6 直接破 15 占五成，六周连涨、首次过半。公网上的配置备份文件还没撤干净；这不是新漏洞，是资产暴露面的老毛病，刚见好转就反复，说明清理压根没常态化。

**行业观察：**本期攻击侧其实有起伏——恶意样本从 2 弹回 7、银狐 IOC 扩到 16，但禅道 env.bak 一路逆势涨过五成最刺眼。攻击者换靶子快、盯着暴露面不放，咱们前几周那波清理刚见效就松劲，破窗户补了又漏，占比一松动反而涨回去，这次直接破五成。

**对读者的建议：**今天先做三件事：把文末附表的 16 条银狐 IOC（尤其整个 cicfo.com 域）拉进 WAF / 威胁情报拦截，别只封单个子域；核一遍 30 个攻击 IP 涉及的资产（金和 C6、赛蓝、Fortinet FortiWeb、蓝凌 OA、泛微 e-cology、GeoServer、Agent Zero、SP Page Builder、Balbooa Forms、禅道等）打没打补丁，重点看 SP Page Builder 的 CVE-2026-48908、Balbooa Forms 的 CVE-2026-56291、Fortinet FortiWeb 的 CVE-2025-25257；最后把公网禅道 / 用友的 .bak、env.bak 整个撤下来，别等占比再翻一倍。

## 04处置清单 R1–R6

以下均为防守动作，按优先级排序，今天即可执行。

|  |  |
| --- | --- |
| R1 | **封堵定向攻击 IP**将定向攻击 IP 列表的 10 个 IP 加入边界防火墙 / 云安全组黑名单，禁止入站与出站双向通信（含加拿大、美国 2 个境外 IP，需按实际线路同步拦截）。 |
| R2 | **查杀恶意样本**按恶意样本列表的 7 个 MD5 与文件名，在终端 EDR、邮件网关、文件服务器做一次全量检索与隔离，重点排查 win32-googlqiang.msi、KeyboardTestUtility.exe、洗群话术总结..bat，解压前先沙箱。 |
| R3 | **拦截银狐组织 IOC**将银狐组织 IOC 的 16 条（10 个全端口恶意域名 + 6 个恶意 IP 端口）写入 WAF / 威胁情报拦截策略，阻断 C2 回连；特别注意整个 cicfo.com 域（含 UUID 特征子域）一并拉黑，而非只封单个子域。 |
| R4 | **核查并修补漏洞涉及资产**对照 30 个攻击 IP 关联的 10 类产品漏洞，核查金和 C6、赛蓝、Fortinet FortiWeb、蓝凌 OA、泛微 e-cology、GeoServer、Agent Zero、SP Page Builder、Balbooa Forms、禅道等资产版本与补丁，确认 CVE-2026-48908、CVE-2026-56291、CVE-2025-25257 是否已完成修复或防护。 |
| R5 | **钓鱼邮件专项**针对银狐组织样本，向全员推送预警；邮件网关开启附件沙箱检测，对可疑 exe / msi / bat 附件执行先核验后打开，带密码的压缩包一律沙箱解压。 |
| R6 | **资产暴露面复盘**继续盘点禅道等系统的公网地址，移除 .bak / env.bak / \_bak 等配置备份文件，禁止敏感配置直接暴露公网；本期禅道 env.bak 15 例（50%）自 9.1 清零后连续六周反弹（0→3→6→7→13→15），说明清理还没稳定，必须常态化，别等占比再翻一倍。 |
