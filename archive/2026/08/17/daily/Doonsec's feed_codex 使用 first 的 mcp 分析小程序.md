## mcp

因为 frist 的 mcp 是 sse 的，codex 需要转一下

```
[mcp_servers.first_mcp]
command = "npx"
args = ["-y", "supergateway", "--sse", "http://127.0.0.1:4554/sse"]
enabled = true
```
