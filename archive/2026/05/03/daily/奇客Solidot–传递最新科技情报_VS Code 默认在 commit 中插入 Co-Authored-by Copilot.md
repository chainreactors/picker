## VS Code 默认在 commit 中插入 Co-Authored-by Copilot

[![人工智能](https://icon.solidot.org/images/topics/topicAI.png?123)](/search?tid=151 "人工智能")

[Edwards](/~Edwards) (42866)发表于 2026年05月03日 23时34分 星期日 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=84209&appkey=1370085986&title=VS%20Code%20%E9%BB%98%E8%AE%A4%E5%9C%A8%20commit%20%E4%B8%AD%E6%8F%92%E5%85%A5%20Co-Authored-by%20Copilot%20 "新浪微博分享")

**来自开普罗纳的魔法师**

微软的编辑器 VS Code 被发现默认在 commit 中插入了 Co-Authored-by Copilot，不管用户有没有使用其 AI 助手 Copilot。此事再次在用户中引发了大量批评。微软开发者回应称他们将会在下个版本中解决默认启用的问题，称如果用户没有使用 AI 助手那么就不应该说代码是 Copilot 合作编写的。
https://github.com/microsoft/vscode/pull/310226
