## PHP 项目淘汰 PHP 许可证

[![PHP](https://icon.solidot.org/images/topics/topicphp.png?123)](/search?tid=23 "PHP")

[Edwards](/~Edwards) (42866)发表于 2026年05月08日 13时57分 星期五 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=84240&appkey=1370085986&title=PHP%20%E9%A1%B9%E7%9B%AE%E6%B7%98%E6%B1%B0%20PHP%20%E8%AE%B8%E5%8F%AF%E8%AF%81 "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自风之影**

PHP 项目正式宣布淘汰 PHP 许可证，切换到 3-Clause BSD License。PHP 许可证属于与 GPL 不兼容的自由软件许可证，因为许可证限制了对“PHP”一词的使用。该许可证也赋予 PHP Group 修改许可证的权力，而修改许可证需要获得每一位 PHP Group 创始成员的书面同意。PHP 项目包含了由 Zend Technologies 开发的 Zend Engine，Zend Technologies 于 2019 年被 Perforce Software 收购，Perforce 也已经同意了许可证更改。PHP 项目宣布他们已经获得了修改许可证的完整授权。
https://wiki.php.net/rfc/php\_license\_update
