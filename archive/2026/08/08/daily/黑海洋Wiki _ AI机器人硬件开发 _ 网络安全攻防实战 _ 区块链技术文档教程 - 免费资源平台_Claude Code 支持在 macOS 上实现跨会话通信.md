# Claude Code 支持在 macOS 上实现跨会话通信

发布时间:
2026-08-08 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
2963

用户运行最新版本的 Claude Code 时，可以让不同的会话互相发送消息，以共享发现、提出问题并协调工作。作为 Claude Code v2.1.224 的新功能，当一个会话中的变更影响到另一个会话正在构建的内容时，Claude 可以在用户注意到之前向该会话发出警告；当一个会话解决了另一个会话受阻的问题时，Claude 可以将答案发送过去。

Anthropic 表示，该功能的最佳使用案例包括移交发现结果、协调并行工作树、获取长期运行任务的状态以及跨机器回复。需要注意的是，跨会话消息传递功能不适用于批准权限请求或更改配置。
