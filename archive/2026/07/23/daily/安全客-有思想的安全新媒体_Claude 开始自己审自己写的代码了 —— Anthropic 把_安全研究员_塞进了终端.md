дҪ еҲҡз”Ё Claude Code ж’ёе®ҢдёҖдёӘеҠҹиғҪпјҢе…үж ҮеҒңеңЁ commit е‘Ҫд»ӨдёҠгҖӮд»ҘеүҚеҲ°иҝҷе°ұеӣһиҪҰдәҶпјҢзҺ°еңЁеӨҡдәҶдёҖдёӘйҖүйЎ№пјҡи®© Claude е…ҲжӣҝдҪ жү«дёҖйҒҚпјҢзңӢзңӢиҝҷж®өд»Јз ҒйҮҢжңүжІЎжңүе®ғиҮӘе·ұеҶҷеҮәжқҘзҡ„жјҸжҙһгҖӮ

иҝҷеҗ¬зқҖеғҸж®өеӯҗпјҢдҪҶ Anthropic зңҹжҠҠе®ғеҒҡеҮәжқҘдәҶгҖӮжң¬е‘ЁпјҢClaude Security жҸ’д»¶д»Ҙ beta еҪўжҖҒдёҠзәҝпјҢзӣҙжҺҘеөҢиҝӣ Claude Code зҡ„з»Ҳз«Ҝе·ҘдҪңжөҒгҖӮејҖеҸ‘иҖ…дёҚз”ЁеҲҮеҲ°еҲ«зҡ„жү«жҸҸеҷЁпјҢеңЁе‘Ҫд»ӨиЎҢйҮҢе°ұиғҪжү«жңӘжҸҗдәӨзҡ„ж”№еҠЁпјҢд№ҹиғҪи·‘дёҖж¬Ўе…Ёд»“еә“дҪ“жЈҖгҖӮжүҖжңү Claude Code з”ЁжҲ·йғҪиғҪз”ЁпјҢз»„з»Үз®ЎзҗҶе‘ҳеңЁclaude.ai/admin-settings/claude-code зҡ„еҗҺеҸ°ејҖе…ідёҖејҖе°ұиЎҢгҖӮ

# 01В  е®ғеҲ°еә•жҖҺд№Ҳе№Іжҙ»пјҡдёҚжҳҜжӯЈеҲҷеҢ№й…ҚпјҢжҳҜвҖқеғҸдәәдёҖж ·жғівҖқ

и§„еҲҷеһӢжү«жҸҸеҷЁе№ІдәҶиҝҷд№ҲеӨҡе№ҙпјҢж ёеҝғиҝҳжҳҜйӮЈеҘ—пјҡжӢҝе·ІзҹҘжјҸжҙһзү№еҫҒеҺ»д»Јз ҒйҮҢжҜ”еҜ№гҖӮеҘҪеӨ„жҳҜеҝ«гҖҒжҳҜдҫҝе®ңпјҢеқҸеӨ„жҳҜиҜҜжҠҘе ҶжҲҗеұұпјҢйҒҮеҲ°йҖ»иҫ‘жјҸжҙһеҹәжң¬жҠ“зһҺгҖӮ

Claude Security иө°зҡ„жҳҜеҸҰдёҖжқЎи·ҜвҖ”вҖ”еӨҡжҷәиғҪдҪ“зі»з»ҹгҖӮе®ғе…ҲиҜ»дёҖйҒҚд»Јз ҒгҖҒжҠҠжһ¶жһ„з”»еҮәжқҘпјҢеҶҚеҺ»жүҫжҪңеңЁзҡ„еЁҒиғҒзӮ№пјҢз„¶еҗҺе…ій”®дёҖжӯҘжҳҜвҖқйӘҢиҜҒвҖқпјҡжҠҠеҸҜз–‘еҸ‘зҺ°иҝҮдёҖйҒҚпјҢиғҪжҺ’йҷӨзҡ„иҜҜжҠҘе°ұжҺ’йҷӨжҺүгҖӮжңҖеҗҺз»ҷеҮәи·ҹйЎ№зӣ®иҮӘиә«йЈҺж јеҜ№еҫ—дёҠзҡ„иЎҘдёҒе»әи®®гҖӮ

жіЁж„ҸжңҖеҗҺиҝҷзӮ№пјҡе®ғз»ҷзҡ„жҳҜвҖқйЈҺж јеҢ№й…Қзҡ„иЎҘдёҒвҖқпјҢдёҚжҳҜеҚғзҜҮдёҖеҫӢзҡ„йҖҡз”Ёе‘ҠиӯҰгҖӮж—©жңҹз”ЁжҲ·еӨёеҫ—жңҖеӨҡзҡ„пјҢжҒ°жҒ°е°ұжҳҜиҝҷдёӘйӘҢиҜҒзҺҜиҠӮвҖ”вҖ”еӣ дёәйӘҢиҜҒиҝҮдёҖиҪ®пјҢдҪ еҜ№з»“жһңжүҚж•ўдҝЎгҖӮAI иҜҙдҪ жңүжјҸжҙһпјҢе’Ң AI иҜҙвҖқжҲ‘её®дҪ зЎ®и®ӨиҝҮиҝҷзЎ®е®һжҳҜжјҸжҙһвҖқпјҢд»ҪйҮҸдёҚдёҖж ·гҖӮ

иҖҢдё”е®ғдёҚдјҡиҮӘдҪңдё»еј жӣҝдҪ ж”№е®Ңе°ұжҸҗдәӨгҖӮжҜҸдёҖжқЎдҝ®еӨҚйғҪиҰҒдәәиҝҮзӣ®гҖҒдәәжӢҚжқҝпјҢе·Ҙе…·жң¬иә«з»қдёҚиҮӘеҠЁ commitгҖӮиҝҷзӮ№ Anthropic иҜҙеҫ—жҳҺзҷҪпјҢд№ҹеҒҡеҫ—е…ӢеҲ¶гҖӮ

# 02В  е®ғзңҹжӯЈиЎҘдёҠзҡ„пјҢжҳҜдј з»ҹе·Ҙе…·зңӢдёҚи§Ғзҡ„йӮЈеқ—

и§„еҲҷеј•ж“ҺеҜ№вҖқе·ІзҹҘжЁЎејҸвҖқеҫҲеңЁиЎҢпјҢеҜ№вҖқйҖ»иҫ‘вҖқеҮ д№Һж— иғҪдёәеҠӣгҖӮClaude Security йҮҚзӮ№зӣҜзҡ„пјҢжҳҜеҮ зұ»дј з»ҹжү«жҸҸеҷЁе®№жҳ“ж”ҫиҝҮзҡ„дёҘйҮҚжјҸжҙһпјҡ

еҶ…еӯҳжҚҹеқҸгҖҒжіЁе…Ҙзұ»зјәйҷ·гҖҒи®ӨиҜҒз»•иҝҮгҖҒиҝҳжңүеӨҚжқӮзҡ„йҖ»иҫ‘й”ҷиҜҜгҖӮе®ғејәеңЁйӮЈдәӣи·Ёж–Үд»¶гҖҒдҫқиө–дёҠдёӢж–ҮжүҚиғҪзңӢжҳҺзҷҪзҡ„й—®йўҳвҖ”вҖ”жҜ”еҰӮдёҖеӨ„ж•°жҚ®д»Һ A ж–Үд»¶жөҒиҝӣ B ж–Үд»¶пјҢеҶҚеңЁжҹҗдёӘдёҡеҠЎеҲҶж”ҜйҮҢиў«й”ҷиҜҜдҝЎд»»гҖӮиҝҷз§ҚвҖқз»„д»¶жҖҺд№Ҳдә’зӣёдҪңз”ЁвҖқзҡ„еҲӨж–ӯпјҢжҒ°жҒ°жҳҜзәҜжЁЎејҸеҢ№й…ҚжҗһдёҚе®ҡзҡ„гҖӮ

е®ғе№Іжҙ»зҡ„е§ҝеҠҝд№ҹеғҸдёӘз ”з©¶е‘ҳпјҡиҜ» Git еҺҶеҸІгҖҒйЎәзқҖж•°жҚ®жөҒи·Ёж–Үд»¶иҝҪиёӘгҖҒеҺ»зҗҶи§Јиҝҷж®өдёҡеҠЎйҖ»иҫ‘еҲ°еә•еңЁе№Ід»Җд№ҲпјҢиҖҢдёҚеҸӘжҳҜйҖҗиЎҢзңӢиҜӯжі•гҖӮеҜ№йӮЈз§ҚвҖқзүҲжң¬еҢ№й…ҚдәҶдҪҶеҲ°еә•иғҪдёҚиғҪиў«еҲ©з”ЁвҖқзҡ„зҒ°иүІең°еёҰпјҢе®ғдјҡжҺЁзҗҶпјҢиҖҢдёҚжҳҜжңәжў°жү“ж ҮгҖӮ

# 03В  еҫ—з»ҷиҝҷд»ҪвҖқдёқж»‘вҖқжіјзӮ№еҶ·ж°ҙ

жҲ‘еҫ—еңЁиҝҷе„ҝеҲ№дёҖдёӢиҪҰгҖӮbetaгҖҒbetaгҖҒиҝҳжҳҜ betaгҖӮAnthropic зӣ®еүҚжІЎжңүе…¬ејҖиҜҜжҠҘзҺҮгҖҒжјҸжҠҘзҺҮзҡ„зЎ¬ж•°еӯ—пјҢдҪ жІЎжі•жӢҝзқҖдёҖд»Ҫз»ҹи®ЎиЎЁиҜҙвҖқе®ғжҜ” SonarQube еҮҶ 30%вҖқгҖӮж—©жңҹз”ЁжҲ·зҡ„ praise жҳҜдҪ“йӘҢеұӮйқўзҡ„вҖқйЎәжүӢвҖқпјҢдёҚжҳҜеҹәеҮҶжөӢиҜ•еұӮйқўзҡ„вҖқжӣҙеҮҶвҖқгҖӮиҝҷдҝ©дёҚжҳҜдёҖеӣһдәӢгҖӮ

жӣҙзҺ°е®һзҡ„жҳҜжҲҗжң¬гҖӮзҙ жқҗйҮҢиҮӘе·ұеҶҷдәҶпјҡи·‘дёҖж¬ЎеӨ§еһӢе…Ёд»“еә“жү«жҸҸпјҢtoken ж¶ҲиҖ—дјҡжҳҺжҳҫеҫҖдёҠиө°пјҢжңүж—¶еҖҷиҝҳдјҡеҲҮеҲ°жӣҙиҙөзҡ„жЁЎеһӢдёҠеҺ»и·‘гҖӮеҜ№еӨ§д»Јз Ғеә“пјҢе…ЁйҮҸжү«дёҖйҒҚеҸҜиғҪиӮүз–јпјҢеӣўйҳҹжӣҙзҺ°е®һзҡ„з”Ёжі•жҳҜвҖқйҷҗе®ҡзӣ®еҪ•жү«вҖқжҲ–вҖқеўһйҮҸжү«вҖқвҖ”вҖ”ж”№дәҶе“Әеқ—жү«е“Әеқ—пјҢиҖҢдёҚжҳҜеҠЁдёҚеҠЁе°ұйҖҡд»“дҪ“жЈҖгҖӮ

иҝҳжңүеҸҘеӨ§е®һиҜқпјҡAnthropic иҮӘе·ұиҜҙеҫ—еҫҲжё…жҘҡпјҢиҝҷдёңиҘҝжҳҜвҖқиЎҘе……пјҢдёҚжҳҜжӣҝд»ЈвҖқгҖӮе®ғдёҚжү“з®—жӣҝжҺүдҪ зҺ°жңүзҡ„ SASTгҖҒDASTгҖҒжҲ–иҖ…йӮЈеё®еҒҡе®үе…Ёзҡ„еҗҢдәӢгҖӮз»“жһңйҖҡиҝҮ webhook еҫҖ SlackгҖҒJira йҮҢзҒҢпјҢжҲ–иҖ…еҜјеҮәжҲҗ CSVгҖҒMarkdown з•ҷжЎЈпјӣдҪ  dismiss жҺүзҡ„жҹҗжқЎеҸ‘зҺ°дјҡиў«и®°дёӢжқҘпјҢи·Ёе·Ҙе…·йғҪзңӢеҫ—еҲ°вҖ”вҖ”иҝҷжӣҙеғҸз»ҷж—ўжңүе®үе…Ёж ҲеҠ дәҶдёҖеұӮеўһйҮҸйҳІеҫЎпјҢиҖҢдёҚжҳҜйқ©е‘ҪгҖӮ

# 04В  жҖҺд№Ҳз”ЁжүҚдёҚдәҸпјҡжҠҠе®ғй’үеңЁжҸҗдәӨеүҚзҡ„йӮЈйҒ“е…і

е…·дҪ“еҲ°ж—ҘеёёпјҢжңҖеҲ’з®—зҡ„е§ҝеҠҝдёҚжҳҜйҖҡд»“зӢӮжү«пјҢиҖҢжҳҜжҠҠе®ғж”ҫеңЁжҸҗдәӨеүҚгҖӮж”№е®ҢдёҖдёӘжЁЎеқ—пјҢжү«дёҖдёӢжңӘжҸҗдәӨзҡ„ diffпјҢеҮ зҷҫиЎҢд»Јз Ғзҡ„дәӢпјҢtoken иҠұдёҚдәҶеӨҡе°‘пјҢеҚҙиғҪеңЁеқҸдёңиҘҝиҝӣд»“еә“д№ӢеүҚжӢҰдёӢжқҘвҖ”вҖ”иҝҷжүҚжҳҜе®ғиҜҙзҡ„вҖқжҠҠе®үе…ЁжЈҖжҹҘз•ҷеңЁжҜҸеӨ©ејҖеҸ‘еҫӘзҺҜйҮҢвҖқзҡ„жң¬жқҘж„ҸжҖқгҖӮ

жғіиҰҒй•ҝжңҹиҰҶзӣ–д№ҹз®ҖеҚ•пјҡйҷҗе®ҡжҹҗдёӘзӣ®еҪ•гҖҒжҲ–иҖ…й…ҚдёӘе®ҡж—¶д»»еҠЎи®©е®ғиҮӘе·ұи·‘пјҢзңҒеҫ—жҜҸж¬ЎжүӢеҠЁиө·гҖӮз»“жһңйЎәзқҖ webhook иҝӣ Jira ејҖеҚ•пјҢжҲ–иҖ…еҜјеҮә CSV з»ҷе®Ўи®Ўз•ҷз—•пјҢдҪ жҠҠ dismiss жҺүзҡ„йЎ№и®°еҘҪпјҢдёӢж¬ЎеҗҢдёҖжқЎдёҚдјҡеҶҚиў«дәәзҝ»еҮәжқҘй—®вҖқиҝҷе’Ӣж”ҫиҝҮзҡ„вҖқгҖӮеҜ№дёҖдёӘе°ҸеӣўйҳҹжқҘиҜҙпјҢиҝҷеҘ—з»„еҗҲжӢіжҜ”еҶҚд№°дёҖеҘ—зӢ¬з«Ӣжү«жҸҸеҷЁиҪ»еҫ—еӨҡгҖӮ

05В  зңҹжӯЈеҖјеҫ—жғізҡ„пјҢжҳҜвҖқAI е®Ў AIвҖқиҝҷд»¶дәӢжң¬иә«

жҠҠи§Ҷи§’жӢүиҝңдёҖзӮ№гҖӮиҝҮеҺ»еҮ е№ҙпјҢAI д»Јз ҒеҠ©жүӢжҠҠдә§иғҪжӢүж»Ўзҡ„еҗҢж—¶пјҢд№ҹйЎәжүӢжҠҠвҖқAI з”ҹжҲҗзҡ„жјҸжҙһвҖқиҝҷдёӘж–°еһӢж”»еҮ»йқўй“әејҖдәҶвҖ”вҖ”еҲ«дәәз”Ё AI еҶҷеҸҲеҝ«еҸҲеӨҡзҡ„д»Јз ҒпјҢжјҸжҙһиҮӘз„¶д№ҹеҸҲеӨҡеҸҲеҝ«гҖӮClaude Security зҡ„еҮәзҺ°пјҢзӯүдәҺеңЁз»Ҳз«ҜйҮҢеЎһдәҶдёҖдёӘиғҪз”ЁеҗҢж · AI жҺЁзҗҶиғҪеҠӣеҸҚеҗ‘е®ЎжҹҘзҡ„вҖқз ”з©¶е‘ҳвҖқгҖӮ

иҝҷжҳҜдёҖдёӘжңүж„ҸжҖқзҡ„еҸҚи®Ҫпјҡз”Ёз”ҹжҲҗжјҸжҙһзҡ„еҗҢдёҖеҘ—жҷәиғҪпјҢеҺ»жҠ“иҝҷеҘ—жҷәиғҪдә§еҮәзҡ„жјҸжҙһгҖӮе®ғиғҪиЎҘдёҠдј з»ҹи§„еҲҷе·Ҙе…·еӨҹдёҚзқҖзҡ„и·Ёж–Үд»¶йҖ»иҫ‘й—®йўҳпјҢжҠҠе®үе…ЁеҹәзәҝеҫҖеүҚжҺЁдёҖж јвҖ”вҖ”е°Өе…¶еҜ№ејҖжәҗз»ҙжҠӨиҖ…е’ҢжІЎдё“иҒҢе®үе…Ёеӣўйҳҹзҡ„дјҒдёҡпјҢзӯүдәҺзҷҪжҚЎдёҖеұӮд»ҘеүҚиҜ·дёҚиө·зҡ„йҳІеҫЎгҖӮ

дҪҶеҲ«жҠҠе®ғзҘһеҢ–гҖӮе®ғдёҚиҮӘеҠЁжҸҗдәӨгҖҒдёҚжӣҝд»Јдәәе®ЎгҖҒжҲҗжң¬иҝҳж‘ҶеңЁйӮЈе„ҝгҖӮAnthropic зҡ„йҮҺеҝғжҳҜвҖқжҠҠ researcher зә§зҡ„еҲҶжһҗеЎһиҝӣз»Ҳз«ҜпјҢжҠ¬й«ҳжҜҸдёӘдҪ“йҮҸд»Јз Ғеә“зҡ„е®үе…Ёж°ҙдҪҚвҖқпјҢиҝҷдёӘж–№еҗ‘жҲ‘и®ӨеҗҢпјӣиҮідәҺж°ҙдҪҚеҲ°еә•жҠ¬еӨҡй«ҳпјҢеҫ—зӯү beta и·‘еҮәзңҹе®һж•°жҚ®еҶҚиҜҙгҖӮ

дҪ д»ҠеӨ©з”Ё Claude Code еҶҷе®Ңд»Јз ҒпјҢеӨҡж•ІдёҖиЎҢе‘Ҫд»Өе°ұиғҪи®©е®ғеңЁжҸҗдәӨеүҚжӣҝдҪ жҹҘдёҖйҒҚгҖӮй—®йўҳз•ҷз»ҷдҪ иҮӘе·ұпјҡеҪ“ AI ж—ўеҪ“иҝҗеҠЁе‘ҳеҸҲеҪ“иЈҒеҲӨпјҢдҪ ж„ҝж„ҸжҠҠеӨҡе°‘дҝЎд»»пјҢдәӨеҲ°йӮЈдёІ token иҙҰеҚ•иғҢеҗҺпјҹ
