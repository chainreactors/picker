紧扣新型工业化发展要求与上海工业企业全球化布局需求，落实2026年度“工赋砺网”上海市工业和信息化领域网络和数据安全能力提升行动工作部署，7月6日，由上海市经济和信息化委员会指导、上海市工业互联网协会主办、中国信息通信研究院华东分院承办、视听静界·元空间协办的工业领域企业出海数据安全与跨境合规专场培训在静安顺利举办！

本次培训活动上海市经济和信息化委员会软件处干部汪涵、上海市静安区科技经济委副主任傅光远、上海市工业互联网协会副秘书长王云出席，上海宝信软件股份有限公司、国家电投集团国际能源有限公司、中国船舶集团有限公司第 711 研究所等重点企业派员参加。

随着上海制造业与信息化企业加速海外布局，跨境业务拓展、智能产品出海已成为产业升级的重要方向。与此同时，全球数据监管规则持续分化，各国数据安全、个人信息保护、AI 治理要求差异显著，数据出境合规、跨境数据流转管控、AI 应用跨境安全、供应链数据风险等问题成为企业出海的核心挑战。本场培训聚焦企业出海合规刚需，面向有海外布局的链主企业、AI + 制造企业及工业互联网产业链重点单位，汇聚权威院所、专业服务机构与安全企业的资深专家，围绕政策解读、路径拆解、技术赋能、实战案例四大板块展开分享，助力企业厘清合规边界、掌握实操方法、防控跨境风险。

![](https://mmbiz.qpic.cn/mmbiz_png/8C1NLS8ickpdND99sL11hW8WKkxZRwZ6NGMfeicN7ib9wnApCfwY7W3ibHBpzHJF0zTAD3JjJ1fBu4iaNCV3zm2ErAL7iaCok3iaichskFhSF81hehk/640?wx_fmt=png&from=appmsg)

上海市静安区科技经济委副主任傅光远在开场致辞中表示，在全球地缘政治和数字贸易规则重塑背景下，静安作为数据要素高地和跨国总部集聚区，正依托市北高新等载体集聚合规服务机构，率先设立数据跨境服务中心并发布服务包。本次培训旨在解读数据出境负面清单，补齐AI时代安全技术短板，助企业将合规内化为竞争力。未来静安将深耕数据分类分级与跨境便利化，推动合规从被动应对转向源头治理，提炼可推广制度成果，服务实体经济。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8C1NLS8ickpedjcia2jHsiaFeLic0AGsiaFX8O1gs4cbT5GibeCI4icG99c1QDZ4MNJiaFjnIlpUo1iaShrvaspIWjlHjic7oZKBqic6yafeUcGoL8aYBw/640?wx_fmt=png&from=appmsg)

浙江东安检测技术有限公司博士后研究员韩龙博以《工业 AI 应用安全风险检测与防护体系建设》为题，结合典型安全事件拆解了工业 AI 应用的权限失控、数据污染、模型漂移等现实风险，介绍了工业 AI 可信成熟度五级模型与“可测、可控、可证”三步走建设路径，同时解读了网信、公安双线监管的合规要点，为企业 AI 应用出海提供了体系化的安全建设思路。

![](https://mmbiz.qpic.cn/mmbiz_png/8C1NLS8ickpcGicdqdEaTXAMTbVjmYiad3Q8UeBKnpgz0YRh3Tjgwqo22VfCXLCPRv9p9KRQiaUdOKylPGRp6LPnVibWxMA6tbhc1Cia3alTfvoHQ/640?wx_fmt=png&from=appmsg)

上海市信息安全测评认证中心创新研究院高级研究员李诗园围绕数据出境负面清单政策展开宣贯解读，梳理了国家数据跨境流动政策的演进脉络，详解了上海全域适用的负面清单管理框架、覆盖领域与个人信息量级放宽规则，清晰说明了负面清单的适用判断流程、备案材料与注意事项，帮助企业精准把握制度红利、降低合规成本。

![](https://mmbiz.qpic.cn/mmbiz_png/8C1NLS8ickpdtXbT7vRQtZe16Xcj62iaoS5z5Lb0oeLIuTXc6thH9HbyicGyRq5jNjicwBRR3IboZMg5iaAk3VXbmOIceTHEDOO3ibaHicpOgBGibP4/640?wx_fmt=png&from=appmsg)

中国信息通信研究院华东分院咨询顾问李沁元带来企业出海个人信息保护合规实践分享，明确了个人信息与个人信息出境的核心定义，拆解了数据出境安全评估、标准合同备案、个人信息出境认证三大合规路径的适用场景与办理流程，并结合典型案例与高频业务场景，给出了“管理+技术+应急”三位一体的跨境数据防护落地建议。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8C1NLS8ickpeOxcHzZsia4c2ejdzNJEzfUUK2Efqz3icoia3IdaodWpKC7ibKZRRkzIW01Ficgy86FhDcURP64ahYSOf1SQ5M45yMYoXhl42xtHtQ/640?wx_fmt=png&from=appmsg)

上海至云平数科技有限公司技术总监李相辉以《AI Native 数据安全之路》为主题，分析了智能化时代传统字段级安全方案的适配短板，讲解了语义资产建模、“五层两中枢一闭环” 架构等 AI 原生安全方案，并针对 Prompt 注入、RAG 越权、向量库泄露等 AI 特有风险提出防护策略，为企业应对 AI 出海的新型数据安全挑战提供解法。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8C1NLS8ickpcA1oFIFuNKtUUED0TJ6B8NnXzkqL16bE25ylcq12Bp9HgmkR4h1nvgsH6XibcSEdBic9et9svxS6EyUKv8k79YqYiaZsGOzm7VUo/640?wx_fmt=png&from=appmsg)

安永（中国）企业咨询有限公司大中华区网络安全与隐私保护咨询服务合伙人周旸结合中国企业国际化发展的三个阶段，剖析了全球数据合规监管差异带来的挑战，围绕人力资源管理、智能产品出海等典型场景，分享了数据合规体系建设方法、证据链构建思路与分阶段落地路径，为不同发展阶段的出海企业提供了可参考的合规建设框架。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8C1NLS8ickpcNefvZWlt4byQqj3HhrYIWKwFw3ibWPhOH1Dfpr2PJoccaTMa7ORqwFibaJ8RypibrWsVqGRvNqwElDSQicR7mhAlFTNZceh5azBQ/640?wx_fmt=png&from=appmsg)

上海观安信息技术股份有限公司AI安全专家周新阳以《AI 时代全球化业务中的身份安全治理实践 —— 企业出海 Token 安全》为主题，剖析跨云跨境场景下 Token 分散、AI Agent 越权等新型安全隐患，梳理 API Key 泄露、OAuth 滥用、CI/CD 凭证失控、Prompt 注入四类典型攻击路径，介绍资产盘点 - 风险分级 - 行为监测 - 自动处置 - 审计复盘全生命周期治理闭环，并提出 AI 场景 Token 最小权限、操作二次校验等管控准则，为出海企业完善机器身份防护体系提供落地方案。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8C1NLS8ickpeLFAhJlIUdEQHLEYsXlCXJsia5YBrvdV4nBND1c3AEQYcn5Bib8cKuCSYibhAuicMcmNuWHIhLJ51micvDZI58twiaryiaZbLfrow84g/640?wx_fmt=png&from=appmsg)

培训尾声设置自由交流研讨环节，参会企业代表踊跃举手提出自身出海业务遇到的合规难题。现场专家针对企业提出的数据出境备案、AI 模型跨境传输等实操疑问逐一细致解答，给出针对性落地建议。

本场出海数据安全与跨境合规专场是“工赋砺网”全年系列赋能活动的重要板块，也是上海支撑企业全球化发展、推动跨境合规落地的政企交流平台。培训覆盖政策、技术、管理、实践多个维度，参训企业代表围绕数据出境申报、跨境数据流转、AI出海合规等热点问题展开交流研讨。后续，参训企业将把培训成果转化为实际举措，持续完善自身跨境数据安全管理体系，提升全球化经营的合规保障能力。

**关于"工赋砺网"**

"工赋砺网"是上海市聚焦工业和信息化领域网络和数据安全打造的品牌专项行动，致力于为上海工业和信息化领域企业构建全方位的安全能力提升平台。2026"工赋砺网"持续深耕工业互联网安全、工控安全、数据安全、AI安全等前沿领域，通过专业培训、技术交流、产品体验等多种形式，全面提升上海市工业和信息化领域企业的安全防护水平，助力上海建设网络安全产业创新高地。
