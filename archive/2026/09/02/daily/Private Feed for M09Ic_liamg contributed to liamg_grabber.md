The tar and zip path-traversal guards rejected an entry naming the archive's own root.

`filepath.Join(dst, "./")` is exactly `dst`, which fails the `dst + separator` prefix test — so a legitimate root entry read as traversal and the whole archive failed to extract. GitLab package-registry Terraform tarballs carry a `./` entry, so those modules never loaded.

* Both guards now call `internal/safepath.Join`, which already allows the destination itself and already does `filepath.FromSlash` on the entry name. The check was copy-pasted in two places, so the bug existed twice; there is now one guard.
* Tests: `./` and `.` root entries for tar, `./` for zip, plus `..` and sibling-prefix escape cases that were not covered.

The only newly-permitted target is `dst` itself, which becomes a no-op `MkdirAll`. `..`, `../x` and sibling-prefix escapes are still rejected.

Fixes FIX-660.
