```
```
./PhishingDrill_linux  # linux

PhishingDrill.exe      # windows
```

# 高手版（自定义端口和密码）
```

```
```
./PhishingDrill_linux -p 80 -pwd niubi666  # linux
./PhishingDrill_macos -p 80 -pwd niubi666  # macos
PhishingDrill.exe -p 80 -pwd niubi666      # windows
```
```

### Step 2：配置模块（30秒）

访问后台管理，进入"模块管理"，添加你的第一个数据捕获接口：

| 配置项 | 填什么 |
| --- | --- |
| 名称 | 账号密码登录 |
| 接口路径 | /login |
| 数据表标识 | login\_data |
| 字段配置 | username:用户名,password:密码:md5 |

点击保存，搞定！

### Step 3：发邮件搞事情（1分钟）

1. 先在"邮件模板"里写一封以假乱真的邮件
2. 在"邮件列表"里导入目标邮箱
3. 选择模板和列表，点击发送！

坐下来喝杯茶，看谁上钩～
