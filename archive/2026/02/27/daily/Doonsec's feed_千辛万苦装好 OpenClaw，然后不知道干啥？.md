> OpenClaw（小龙虾）火了。GitHub 一周十万星标，Karpathy 专门买了台 Mac Mini 来折腾。全网都在教你怎么装、怎么配、怎么跑。但有个问题没人提：**装完之后，你拿它干什么？**

## 一、装好了，然后呢？

我在社区里观察到一个有趣的现象：很多人花了一两天时间，踩了无数坑，终于把 OpenClaw 跑起来了。然后呢？

发了条朋友圈："成功运行 OpenClaw！" 但是很快就会困惑的问到：我该拿它来干啥。。。感觉日常也用不上。

接下来……就没有接下来了。

**不是工具不行，是你没有需求。**

你的日常工作和生活里，到底有多少场景需要一个 AI Agent？如果你想不出来，那装了也白装。就像买了一把顶级厨刀，但你平时只吃外卖——刀再好，也只能落灰。

而我呢？我已经完全回不去了。

我用的是 AC-AIBot——一款和 OpenClaw 定位类似的产品，但它已经**彻底改变了我的日常交互习惯**。不是"偶尔用用"，是**每天都在用，随时在用，想到什么就用**。

别光听我说，看图。以下全是我这几天的真实使用记录。

---

## 二、社区有人晒磁盘，我随手就查了下自己的

事情是这样的：有个用户在群里贴了自己的电脑磁盘截图，说 C 盘没规划好，空间快满了。

![](https://mmbiz.qpic.cn/mmbiz_png/G0iaFtEibWU95btWcJUUicGwE8DLuXhjKmUZPcM5HnFElb0j7iag3Aupugf5B8QE0aibqiaIj9phCXicLCV5m8dCTz2qs1ScjuZVjUflg7dTBaEWL4/640?wx_fmt=png&from=appmsg)

用户贴的磁盘情况——C 盘 255GB 只剩 17.9GB好几个盘都红了

我一看，心想：我的盘啥情况来着？没起身，没开电脑，直接掏出手机，在 AC-AIBot 里打了一句："罗列下我当前所有的磁盘"。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/G0iaFtEibWU97B59bjCFHggf7I1E4S36ibIMVePJRcSxVyYic9IibbfSllRpgrGFQaUyvGoGo2WvvE40RWb3BVezjWAib5xzOwEXtqp7Qo28Bkq3w/640?wx_fmt=png&from=appmsg)

*几秒后，AC-AIBot 把我电脑的磁盘信息全列出来了：C盘 1.82TB 还剩 1.60TB，D 盘 476GB，F 盘 7.28TB*

**人在外面，手机一问，电脑的磁盘情况一目了然。** 我的 AC-AIBot 连了好几台机器，随时切换，随时查看。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/G0iaFtEibWU94NclxbWRVLEvGvAmDKTn7HWzlbSBmqXKibMWGohRFhNAJdevzOsooqiaaeibelXv9DiawGaInvN79ssbUy9nUjjbbkk36RQ0RQIzY/640?wx_fmt=png&from=appmsg)

*AC-AIBot 的电脑控制面板——macbook、wiliam2、William1 全部在线，随时可以进入聊天控制*

这个场景看起来很小，但它代表了一种习惯的改变：**你不再需要"在电脑面前"才能了解电脑的状态**。躺在沙发上、坐在地铁里、排队等咖啡的时候——想到什么，问一句就行。

## 三、想到个观点？一句话发四个平台

那天刷推看到 Karpathy 和 Shubham Saboo 在讨论 OpenClaw，我突然有了个想法，想发条动态分享我的观点。

以前的做法：打开微博写一遍，打开知乎写一遍，打开小红书写一遍，打开 Twitter 写一遍。四个平台，同一段话，复制粘贴四次。

现在的做法：

![](https://mmbiz.qpic.cn/mmbiz_png/G0iaFtEibWU95PByYX13oXicTrBOyLz8G9Peqt7lvS8NkmuRUEZLohDicsTBT2owUo7xoXFpEPQZjkh26jIul7V7O85xxl2Sarzm5uJBehnw794/640?wx_fmt=png&from=appmsg)

*直接在 AC-AIBot 里说："帮我在微博、知乎、小红书*、Twitter 发送如下内容"，把想发的内容贴进去**

![](https://mmbiz.qpic.cn/mmbiz_png/G0iaFtEibWU96N1Sic5dLicicMZ7QibsY8h5ocfmuUJtx42U3YSIsWVGd4PUmKcaOj60iay20kI6Z8XNccpiaEWljNbMuR5kQ55JWhTwjrlxRS5xkuo/640?wx_fmt=png&from=appmsg)

*微博 ✅ 已成功发布，知乎 ✅ 已成功发布（想法形式），小红书需要登录，Twitter 等待中*

一条指令，四个平台同步发。微博和知乎直接搞定，小红书因为没登录会提醒我先去登录。**整个过程不到一分钟，以前至少要折腾十分钟。**

这就是我说的"日常交互习惯的改变"——当发帖这件事从"打开四个App分别操作"变成"说一句话"，你就再也不想回到以前了。

## 四、看到一篇文章，截个图就让它帮我下载项目

有天晚上刷到一篇介绍 CLI 工具的文章，提到了好几个有意思的开源项目：go-cli、VibeTunnel、CodexBar、spogo……我懒得一个个去 GitHub 搜。

直接截了个图，发给 AC-AIBot："帮我用浏览器找到图片中提到的项目然后 clone 到 projects 目录下"。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/G0iaFtEibWU965G8VbiayibX5oibkHYbEcl0U996C44YgkJHI7YDhIrSziaOh3nW57eRG9cbfNZ818yXKasyafH4LwzH10iciaN1tXeIGnOYt3BuMtI/640?wx_fmt=png&from=appmsg)

*把文章截图发给 AC-AIBot，一句话搞定*

*然后*它就开始干活了——用浏览器搜索每个项目，找到 GitHub 地址，自动 clone。**

![](https://mmbiz.qpic.cn/mmbiz_png/G0iaFtEibWU95N3u8wSLQ4BelVk1uXrvrMxIhDhmVNulLPRaibVjqzZgSa3IVKRNeK2vU1Sw7gkfrMQN9svibAkib94xUKpEQ2dZY9GueXzKro78/640?wx_fmt=png&from=appmsg)

*go-cli ✅ 已克隆、VibeTunnel ✅ 已克隆 CodexBar ✅ 已克隆，wacli 和 spogo 需要进一步确认*

**三个项目自动找到并克隆完毕**，另外两个因为可能不是独立仓库，它也如实说明了。关键是——我全程没有打开电脑，没有打开浏览器，没有输入任何 URL。**一张截图 + 一句话，就把"看到 → 收藏 → 下载"这个流程自动化了。**

这种场景你用 OpenClaw 能做吗？理论上可以，但你得先在终端里配好环境，写好 Skill 脚本……等你折腾完，那篇文章你早就忘了。

## 六、用户说我的项目没带时间，我手机上就查了

有个用户在用我开发的 auto-coder 项目时反馈："@祝威廉 换了几个模型都不行，还是得自己加上时间"。

![](https://mmbiz.qpic.cn/mmbiz_png/G0iaFtEibWU96LKAlRx5BzMMrPadL8UGes6PalwpSRhmQEE0cIhkfnILMsD8FjLgR88YveYapykLMTd94zSRIWZQjAichBbg2SXf35ibCu719fg/640?wx_fmt=png&from=appmsg)

*用户说换了几个模型都不行，还是得自己加上时间*

他说是系统提示词里没有包含当前时间信息，导致模型不知道"现在是几点"。我心想：真的吗？让我查查。

直接在 AC-AIBot（iPad 上）输入："打开 auto-coder 项目，然后分析下 agentic\_edit.py 文件里的提示词是不是带了当前时间，并且展示对应的提示词给我看"。

![](https://mmbiz.qpic.cn/mmbiz_png/G0iaFtEibWU97TpPjpnRkx17OiaqQSEDicCskxJav8360pyLibgWa1Q4ujN8WdP1OXMkE7IaR16Fwmo3icia9MAf534sewDSzN6crN2p8qCicUDwOUM/640?wx_fmt=png&from=appmsg)

*AC-AIBot 打开项目，定位到 agentic\_edi.py 第 2445-2446 行的提示词模板，列出所有变量，得出结论：确实没有包含时间信息*

**结论清清楚楚：当前提示词中不包含任何当前时间信息（如日期、时间等）。** 用户说得对，我立刻知道了该怎么修。

这个场景的意义在于：**我不需要打开 IDE，不需要翻代码，甚至不需要记得文件叫什么名字**。一句话描述问题，AC-AIBot 帮我找到文件、分析代码、给出结论。这才是 AI Agent 真正该做的事——不是炫技，是帮你解决具体的、真实的问题。

## 八、不是工具牛不牛的问题，是你的生活里有没有它的位置

回到开头的问题：**千辛万苦装好 OpenClaw，然后呢？**

如果你装完之后发现自己想不出要用它干什么，那问题不在 OpenClaw——问题在于你还没有建立起"让 AI 帮你做事"的思维习惯。

而我想说的是：当你真的把一个 AI Agent 融入日常之后，它改变的不只是效率，而是你和信息交互的方式——

| 以前的我 | 现在的我 |
| --- | --- |
| 想发帖 → 打开四个App分别写 | 想发帖 → 一句话，四个平台同步发 |
| 想查磁盘 → 走到电脑前打开资源管理器 | 想查磁盘 → 手机上问一句 |
| 看到好项目 → 复制名字，打开 GitHub，搜索，clone | 看到好项目 → 截图，一句话，自动 clone |
| 用户问产品对比 → 自己打开两个网站人肉研究 | 用户问产品对比 → 一句话，五分钟出 PDF 报告 |
| 用户报 bug → 打开 IDE 翻代码 | 用户报 bug → 手机上问一句，定位到具体代码行 |
| 看到英文长文 → 收藏，回头再看（大概率不会看） | 看到英文长文 → 截图，立刻翻译成中文文档 |

**这不是"某个功能很强"的故事，是"整个日常都变了"的故事。**

OpenClaw 很好，Karpathy 都在用。但它更适合那些享受折腾的极客。对我来说，我需要的不是一个能跑 demo 的工具，而是一个**随时在线、随叫随到、融入生活每个角落的助手**。

AC-AIBot 就是这样的存在。

## 写在最后

AI Agent 时代最大的误区，不是"装不上"，而是\*\*"装上了不知道干嘛"\*\*。

技术从来不是瓶颈。瓶颈是你有没有意识到：你每天都在做大量重复的、琐碎的、其实可以一句话搞定的事情。

当你开始意识到这一点，你就再也不会问"装完之后干什么"了——因为你会发现，**到处都是可以让 AI 帮你做的事**。

而到了那个时候，你需要的不是一个让你折腾半天才能跑起来的工具，而是一个**拿起手机就能用的助手**。
