# SneakPeek, la falla in Claude Code Desktop che poteva esporre le credenziali degli sviluppatori

---

Indirizzo copiato

---

Una vulnerabilità ad alta gravità in Claude Code Desktop consentiva a file HTML malevoli di accedere a dati locali ed esfiltrare credenziali degli sviluppatori. Scoperta da Noma Labs e corretta da Anthropic, SneakPeek rivela i rischi di sicurezza nascosti nei componenti degli assistenti AI per la programmazione
