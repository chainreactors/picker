## 二、重点事件

### 1. laicaishuli.com 双 A 记录活跃：AtlasRAT 域名侧存活点确认，落地韩国双供应商

•**时间**：2026-10-26 本报 DNS/RDAP 实测（域名与 IP 状态为窗口内当前值）

•**来源**：本报 dig + APNIC RDAP 实测；背景披露 Netresec: Detecting AtlasRAT C2（2026-10-12）

•**要点**：

• Netresec 10-12 披露的 AtlasRAT 3 个语义化域名（laicaishuli.com / yilufafafa.club / zixungongsi.top）中，**仅 laicaishuli.com 当前有解析**（另两域无 A 记录），且同时挂双 A 记录；

•**118.128.151.51**：APNIC RDAP = KT 韩国电信（118.128.0.0/14 ALLOCATED PORTABLE，IP Manager / IRT-KRNIC-KR）——韩国电信家宽/企业段资源；

•**103.86.47.234**：APNIC RDAP = 103.86.47.0/24（ALLOCATED NON-PORTABLE，abuse IRT-MOACKCOLTD-KR 即 Moack Co. Ltd. 韩国托管商；administrative 联系人 **Shanghai Xima Internet Technology Limited 上海西玛网络科技**）——**与微步 10-18 热点 IP 103.86.47.125 同 /24**，本报 DNS 实测与微步热点榜在 103.86.47.0/24 形成双点命中，该段承载银狐谱系资产的可信度显著上升（待扩大样本核证）；

• 双 A 记录 = 单域名双供应商冗余：任一 IP 被封不影响连通，与银狐主线「域名池多落点形态」（本报 10-22 期）运营思路一致；

• 结合本报 10-25 期：Netresec 8 个 TLS C2 之一 23.226.57.50 在微步 10-25 热点在榜——**AtlasRAT IP 侧与域名侧存活点均已获独立第二源确认**，该支线基础设施活跃度实锤。

•**影响面**：NTA/出口设备可直接对 laicaishuli.com 域名层封禁（含泛解析）；103.86.47.0/24（Moack）建议列入观察名单并做命中率评估；韩国（KT/Moack）作为银狐谱系新观测落点区域，纳入 hunting 视野。

### 2. gadad.bvndjx.cn 解析整体轮换：第八批点名 IP 3 天即弃用，新落点全部指向阿里云国际

•**时间**：2026-10-26 本报 DNS/RDAP 实测；第八批通报 2026-10-23 发布

•**来源**：本报 dig + APNIC RDAP 实测；背景 CCTGA 第八批通报（2026-10-23）

•**要点**：

• 第八批点名条目 137.220.136.168:5178（BAYS220）关联域 gadad.bvndjx.cn 当前解析 **47.91.170.222 / 47.76.127.217 / 8.218.208.240** 三个 IP，原 IP 已不在解析列；

•**8.218.208.240 经 APNIC RDAP 实锤：Alibaba Cloud (Singapore) Private Limited（8.208.0.0/14，IRT-ASEPL-SG）**——银狐阿里云掩体带再添 SG 节点，与本报 10-23 实锤的 43.98.80.16（ASEPL-SG）同注册主体；

• 47.91.170.222 与 47.76.127.217 位于 APNIC IANA stub 段（47.0.0.0/8 二级分配未细分），按本报既往观测：47.76.x 与 10-19 实锤样本 C2 47.76.205.190 同区间、47.91.x 为阿里云 AP 区间惯用——**三 IP 高概率同属阿里云国际（待 PassiveDNS 扩证）**；

•**运营节奏判读**：官方通报发布（10-23）→ 3 天内关联域整体迁移——「点名即弃用」从本报历史推断升级为可直接观测的事实；同时 mlcrosoft.vip（同批主力 typosquatting 域）也迁离 177.4.3.x（见事件 3），**第八批全部关联域的 IP 依附性已在窗口内失效**。

•**影响面**：官方逐 IP 名单的处置时效 ≤3 天，企业侧应把第八批 10 IP 视为「取证快照」而非持续封禁清单；gadad.bvndjx.cn 及 bvndjx.cn 泛域、8.218.208.0/24 建议域名层+段级观察处置。

### 3. mlcrosoft.vip 迁离 177.4.3.x：第八批 typosquatting 域族 IP 依附性全面失效

•**时间**：2026-10-26 本报 DNS 实测

•**来源**：本报 dig 实测；RDAP 定性未成功（ARIN 端点无响应）

•**要点**：

• 第八批通报中承载最高日控（.99 6,549/.35 6,161/.101 4,153 等）的关联域族 mlcrosoft.vip / mlcrosoft.my / mlcro.net，其主力域当前解析 **98.159.108.61**——已脱离 177.4.3.x（HKCICL-HK）段；

• 98.159.108.61 归属查询失败（**待核实**）；mlcro.net 当前无 A 记录；

• 177.4.3.0/24 段封建议维持（该段六批次轮换历史深厚，IP 池未枯竭），但**域名族整族拉黑（mlcrosoft.vip/.my、mlcro.\*）的优先级高于段内逐 IP 追踪**——域名不变、IP 快换的对抗模式下，域名才是稳定锚点。

•**影响面**：与事件 2 合并结论——第八批 IOCs 的处置重心应从 IP 层切换到域名层；对「泛解析+随机串子域」形态域，DNS 层整族拦截成本最低。

### 4. 一手受害者报告：spacedesk 伪装安装包 + 挖矿载荷 + 三节点哨兵互守（银狐归属待核实）

•**时间**：2026-10-26 04:26 发布（hqwc.cn「编程知识」栏目，作者自述为高中生受害者，非厂商报告）

•**来源**：一次真实的银狐木马应急响应全过程——从CPU飙升到彻底清除

•**要点**：

•**投递链**：官网不可达 → 第三方下载站下载 spacedesk 服务端压缩包（spacedesk 为远程屏显工具，**本报首见伪装目标**）→ Defender 弹窗「不安全」→ 弹出「spacedesk 防商业使用验证」窗口诱导「信任并运行」——**利用弹窗社工强制信任**为新话术形态；

•**载荷行为**：挖矿主进程 NHdOoHGU.exe（i7 满 CPU）+ 挖矿池配置 .db + **PNG 隐写载荷（96×96 分辨率、4.5MB、下半区花屏——尺寸/体积严重失配）**；落盘于 Program Files / Program Files (x86) / ProgramData 三处乱码目录；

•**三节点分布式哨兵互守**：`true update client`（伪装更新客户端）、`Philips Speech Driver Client Configuration`（伪装飞利浦语音驱动）、乱码目录主程序——三进程互相监控、任一被杀即由其余节点复活（watchdog 互守），与本报 10-15 期观测的银狐守护机制同构；

•**反安全工具**：按进程名禁用腾讯电脑管家、360 系统急救箱（SuperKiller.exe）、Everything（改副本文件名可绕过）；文件以 Everyone 权限锁定（takeown+icacls+DiskGenius 强删组合可清除）；

•**⚠️ 归属甄别**：作者按 VT 结果自行判断为「银狐/挖矿」，未提供哈希与 C2；挖矿主载荷与银狐 RAT 混投可能性存在，**银狐家族归属待核实**——但 spacedesk 下载站投毒路径、哨兵互守、按名禁用安全工具三项与已知银狐 TTP 吻合度高，按「技术细节可信、家族归属存疑」入档。

•**影响面**：企业侧可直接引用的是话术与行为特征（见检测建议 3/4/5），而非 IOC；「防商业使用验证」类弹窗应纳入用户安全意识案例库。
