# NIST 800-218 revision

NIST 800-218 wants you!
![Secure Software Development Framework (SSDF) Version 1.2: Recommendations for Mitigating the Risk of Software Vulnerabilities](/images/blog/img/2026/nist-80-218-updates-1600w.png)

NIST has released an initial public draft of v1.2 of NIST
800-218. If that means nothing to you, move along. Otherwise, you
have until Jan 30 to comment. The draft is [here](https://csrc.nist.gov/pubs/sp/800/218/r1/ipd). (NIST did not set an unusually
short comment period, we’d missed it). ReversingLabs has a
story with various perspectives: [SSDF 1.2 sees AppSec as a
journey](https://www.reversinglabs.com/blog/ssdf-appsec-journey). I do wish they’d frame it as software security
issues, not software vulnerabilities.
