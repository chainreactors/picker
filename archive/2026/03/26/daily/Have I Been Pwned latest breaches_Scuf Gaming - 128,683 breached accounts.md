# Scuf Gaming Data Breach

## What Happened

In June 2015, custom gaming controller maker [Scuf Gaming suffered a data breach](https://www.malwarebytes.com/blog/news/2015/06/up-down-left-right-hack). The incident exposed 129k unique email addresses along with usernames, display names, IP addresses and password hashes.

## Compromised Data

Display names

Email addresses

IP addresses

Passwords

Usernames

## Recommended Actions

##### Change Your Password

If you haven’t already changed the password affected by this breach, do
so immediately on every account where it was used.

Wherever 2FA is supported, add an extra layer of security to your
