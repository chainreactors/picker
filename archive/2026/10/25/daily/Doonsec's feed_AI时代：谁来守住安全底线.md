引言：AI 时代，“安全底线”由谁来守？

当我们谈论“AI时代的安全底线”，人们最先想到的问题往往是“这到底是谁的责任”。有人觉得这件事只和安全部门有关，有人认为和普通岗位没关系，还有人觉得只要系统足够安全就能高枕无忧。但事实恰恰相反：在攻防态势不断加剧的AI时代，安全责任早已不再是某一个部门、某一位专家的专属工作，而是一个由“组织负总责、专职扛重担、全员守底线、供应链共担、技术作支撑”构成的责任共同体。安全底线，需要所有人共同守护。

本培训材料面向公司全体员工，设置了三个核心目标：第一，厘清安全责任的法律基础，明确责任究竟落在谁身上；第二，说明“守底线”为什么难度越来越大、也越来越重要；第三，梳理组织与个人各自的责任清单与行动要求。建议大家带着一个问题阅读：在我所在的岗位，我能为守住安全底线做哪几件事？

# 1  安全责任的法律基础：责任落在谁身上

## 1.1  组织的责任：网络运营者主体责任

《中华人民共和国网络安全法》明确将责任主体界定为“网络运营者”，即网络的所有者、管理者和网络服务提供者，并要求其履行网络安全保护义务；该法同时确立了监管部门对不履行义务的运营者法定代表人或主要负责人进行约谈、并依法处罚的工作机制。公安部发布的指导意见进一步明确，应当按照“谁主管谁负责、谁运营谁负责”的原则厘清责任边界，建立网络安全等级保护工作责任制并落实责任追究（引自公安部网站）。针对关键信息基础设施运营者，《关键信息基础设施安全保护条例》专门明确，其“主要负责人对安全保护负总责”。

## 1.2  专职的责任：负责人与专门机构

在组织内部，安全责任需要落实到专人专岗：《个人信息保护法》第九条要求个人信息处理者对其个人信息处理活动负责，第五十二条要求处理个人信息达到规定数量的处理者指定个人信息保护负责人并公开联系方式；《关键信息基础设施安全保护条例》要求运营者设置专门安全管理机构。这些“专人”是组织安全责任的落地抓手，但绝不意味着只有他们才需要承担安全责任。

## 1.3  个人的责任：员工是第一道也是最后一道防线

大量攻击——AI钓鱼、深度伪造、社会工程攻击——最终突破的都不是技术防线，而是人员防线。员工的一次误点击、一次违规转账审批、一次擅自外发敏感数据，都可能成为安全防线的缺口；反过来，一次主动核实、对可疑链接坚决不点、一次及时上报隐患，就能成功挡下一次攻击。个人安全责任从来不是抽象的口号，而是已经写入操作流程的具体行动。

## 1.4  供应链与第三方的责任

各类数据、系统与AI服务，往往都依赖供应商、云平台与第三方主体提供支撑。公安部在“护网—2025”专项工作典型案例中明确提示：供应链企业作为网络安全的重要参与者，必须切实履行自身的网络安全保护义务。组织在选择和使用第三方服务、AI服务商时，要将安全责任明确写入合同、纳入准入评估，避免“用了对方的服务，安全责任却无人认领”的情况。

## 1.5  监管与协同

国家网信部门负责统筹协调网络安全相关工作，电信主管部门、公安部门等依照各自职责开展监管；对违规主体可依法采取约谈、处罚、责令整改等处置措施。监管力量是外在约束，组织自身的自觉才是守住安全底线的前提——只有实现内外协同，责任链条才能真正闭合。

表1 AI 时代安全责任主体与法律依据

|  |  |  |
| --- | --- | --- |
| 责任主体 | 主要责任 | 法律与依据 |
| 组织/网络运营者 | 履行网络安全保护义务，负主体责任 | 《网络安全法》、等级保护责任制 |
| 主要负责人 | 对本单位安全保护负总责> | 《关键信息基础设施安全保护条例》 |
| 专职负责人/机构 | 指定个保负责人、设专门机构 | 《个人信息保护法》第52条等 |
| 员工个人 | 守好数据、终端、账号与行为 | 岗位安全职责、公司制度 |
| 供应链/第三方 | 供应商、云与AI 服务商履行义务 | 《网络安全法》、合同约束、护网执法 |
| 监管机构 | 统筹、监督、约谈、处罚 | 网信、工信、公安等部门 |

# 2  为什么“守底线”越来越难，也越来越重要

## 2.1  攻击技术升级，防线缺口常在“人”

大语言模型与深度伪造技术，让网络攻击变得更逼真、更精准，也更自动化：据公安部数据，2025年第一季度，全国AI换脸、拟声诈骗案件环比激增45%。虽然技术在不断发展，但社会工程攻击最终针对的是人的判断力与情绪，人的防线一旦失守，即便系统技术再先进，也会被绕过。

## 2.2  法规进入强执行期

《网络数据安全管理条例》、《个人信息保护合规审计管理办法》、《人工智能生成合成内容标识办法》等法规相继落地生效，监管要求也从“原则性要求”转向“可审计、可追责、可处罚”。公安部持续开展专项执法并公布典型案例，足以说明合规与责任已经不再是可以拖延的事项。

## 2.3  责任追究到人

《网络安全法》明确规定，网络运营者不履行法定责任义务的，除对单位处以处罚外，还可对“直接负责的主管人员和其他直接责任人员”处以罚款；针对国家机关政务网络运营者，还可依照规定对相关责任人员给予处分。责任不是“由组织集体兜底”，而是要明确落实到具体个人，一旦守不住底线，最终后果必然会落到具体责任人身上。

表2 责任失守的典型风险与后果

|  |  |  |
| --- | --- | --- |
| 风险场景 | 可能后果 | 主要责任主体 |
| 敏感数据泄露/违规出境 | 处罚、赔偿、声誉受损 | 组织+ 责任人 + 直接操作者 |
| AI 钓鱼/深伪致转账被骗 | 资金损失、内部追责 | 经办人（未核实） |
| 员工向外部AI 投喂数据 | 商业秘密与个人信息泄露 | 员工本人+ 管理失察 |
| 第三方违规处理数据 | 连带泄露、监管追责 | 供应链+ 采购/合规部门 |
| 不履行保护义务被执法 | 警告、罚款、约谈负责人 | 组织+ 主要负责人 |

# 3  谁来守：组织的责任体系怎么搭

## 3.1  治理架构：决策、管理、执行、监督

要将“谁来守”的要求落到组织架构层面，需要划分四个权责层级：决策层，由负责人与安全管理委员会组成，承担总责，负责确定方向、调配资源；管理层，由安全负责人统筹制定制度、协调资源；执行层，由安全团队与各岗位人员落实具体措施；监督层，负责审计、合规、内部检查以及个人信息保护合规审计。只有四层职责划分清晰、责任层层传导，安全责任才不会悬空。

## 3.2  制度与考核：责任到岗、纳入考核

建立安全责任制与岗位安全职责清单，将“守底线”的各项要求明确写入制度；针对高风险岗位清晰划定责任边界，把安全指标纳入绩效考核与责任追究机制，真正做到“守土有责、守土尽责”。制度不应是贴在墙上的摆设，而要做到可执行、可检查、可改进。

## 3.3  资源保障：人员、预算、工具、演练

责任落实需要资源作为支撑：要配备足额的专业人员、安排充足的安全预算，部署专业安全工具，定期开展安全培训与钓鱼演练，还要持续投入资源建设AI化防御能力。缺少资源投入的责任只是空头责任，只有落实了资源投入，安全责任才能真正“接得住”。

## 3.4  AI 时代的责任扩展

当组织引入大模型、AI应用与训练数据时，安全责任也会相应扩展：要明确模型、数据、AI应用的责任归属，参照NIST人工智能风险管理框架（AI RMF）与OWASP大模型应用十大风险，将AI安全纳入组织风险管理与责任体系，不能把风险交给“AI供应商”就一推了之。

表3 组织安全责任体系架构

|  |  |  |
| --- | --- | --- |
| 层级 | 主要职责 | 要点 |
| 决策层 | 负总责、定方向、配资源 | 主要负责人、安全管理委员会 |
| 管理层 | 统筹制度与资源、风险评估 | 安全负责人、个保负责人 |
| 执行层 | 落实技术措施与流程 | 安全团队、各岗位职责清单 |
| 监督层 | 审计、合规、内部检查 | 合规审计、绩效考核、追责 |

# 4  每个人如何守：员工的责任清单

## 4.1  我是“责任人”而非“旁观者”

安全从来不是“别人的事”，每一位员工都要对自己经手的数据、使用的账号、接触的系统承担岗位责任。应当转变认知视角：把每一次信息核实、每一次对可疑链接的拒绝、每一次安全事件上报，都当作自己分内的“守线”动作，而非额外负担。

## 4.2  岗位上的安全动作

数据：分清级别，按级处理；不将敏感数据输入未授权的外部AI、网盘或邮箱；不违规外发、导出敏感数据。

终端与账号：设置并妥善保管强口令，启用多因素认证；不点击不明链接、不下载不明附件、不安装来源不明的软件。

AI工具：仅使用公司批准的工具，对AI输出内容保持警惕，对外发布AI生成内容时落实标识要求。

## 4.3  异常上报与配合调查

发现疑似钓鱼邮件、异常登录、异常数据导出或可疑文件，应当立即上报信息安全部门，保留相关证据，不删除文件，不扩散风险。在安全事件调查与个人信息保护合规审计中，要如实配合工作、提供必要记录——这既是应尽责任，也是保护自己和组织的最佳方式。

表4 员工守底线行动清单

|  |  |  |
| --- | --- | --- |
| 场景 | 必做动作 | 红线 |
| 处理敏感数据 | 按级加密、脱敏、最小权限 | 不违规导出、不外发 |
| 使用账号/终端 | 强口令、多因素认证 | 不共享账号、不装不明软件 |
| 使用外部AI/网盘 | 只用批准工具、先评估 | 敏感数据严禁上传未授权服务 |
| 收到可疑邮件/链接 | 核实来源、不点击 | 不输入账号密码、不下载附件 |
| 发布AI生成内容 | 落实显式/隐式标识 | 不发布未经标识的生成内容 |
| 发现异常 | 立即上报、保留证据 | 不删除、不扩散、不自行补救 |

# 结语：底线，是所有人一起守出来的

回到最初的问题——AI时代，谁来守住安全底线？答案是：组织负总责，专职人员扛重担，供应链共担责任，技术提供支撑，而每一位员工，都是不可替代的一环。守住安全底线不是某个人的英雄主义，而是全员参与的日常行动。请把这份材料中的责任清单带回岗位：分清数据级别、守好个人账号、核实安全风险、及时上报异常。底线或许无声无形，但它就藏在你每一次做出的正确选择里
