# 第三届腾讯云智能攻防挑战赛线上赛冠军方案 **sapper-v2 已在 GitHub 开源。**

## 开源地址

https://github.com/N1nEmAn/sapper-v2

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/w4WPiaObtlpw1Oczl8nkZEulXN6GTy5ac7segCrYicazBGHERaibRltkjiaPapt2Qt5w6dopGPq62QAZ4fnZqfn9vwCejNQCV0uuowXOzMNIeg0/640?wx_fmt=webp&from=appmsg)

仓库 README 给出的线上赛结果：参赛 634 队，综合分 80.18，取得 85 面 flag，消耗约 10 亿 token（第二名约 45 亿），运行时长 8 小时且全程无人值守。

同方案另获 GeekCon 2026 AI 挑战赛一等奖。
