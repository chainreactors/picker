我们顺着域名，找到了那座城的"真身"。

到了城门口，接下来该干什么？

不是冲进去，也不是随便逛逛。

而是——**把它当一本书，从头到尾，"读"一遍。**

---

## 01 大多数人"看"网站，我"读"网站

先区分两个动作。

**"看"**，是消费者视角：

* 这个页面好不好看；
* 我要的东西在哪儿；
* 点哪个按钮能下单。

**"读"**，是分析者视角：

* 这个页面是怎么被"拼"出来的；
* 它背后连着哪些接口；
* 哪些地方，藏着可以被"改写"的输入。

**看，是接受它给你的样子；读，是猜它没告诉你的部分。**

一个网站，在"看"的人眼里是产品；在"读"的人眼里，是**一本摊开的书**。

---

## 02 第一遍读：读它的"结构"

读书先看目录。

读网站也一样。

* **首页**，是封面——它想让你第一眼看到什么；
* **导航栏**，是目录——它有哪些"章节"；
* **每个栏目**，是一章——关于我们、产品中心、新闻、联系我们……

但真正的"目录"，往往**不在导航里**。

* 有些页面没挂在导航上，却真实存在（比如 `/admin/`、`/test/`）；
* 有些目录列表，忘了关（一打开，就是整整齐齐的文件清单）；
* 有些"备份文件"，安静地躺在根目录下。

**导航是它"想给你看"的目录；真正的目录，藏在它的目录结构里。**

---

## 03 第二遍读：读它的"功能"

光有目录不够，还得读"每一章讲了什么"。

一个网站的功能，通常就那几类：

| 功能 | 它意味着什么 |
| --- | --- |
| **登录 / 注册** | 身份、会话、密码——一整套认证逻辑 |
| **搜索** | 一个直接把用户输入送进数据库的入口 |
| **上传** | 文件会落到服务器上，落到哪里、叫什么名，都是问题 |
| **留言 / 评论** | 用户内容会被存下来，再展示给别人 |
| **支付 / 下单** | 一整套业务逻辑，逻辑越复杂，越容易绕过 |
| **API 接口** | 前后端之间的"暗门"，常常缺少页面的那层保护 |

**每一个功能，背后都是一套"逻辑"。**

而逻辑，就可能被绕过。

**这就是为什么，读网站不能只读"页面"，还要读"功能"。**

---

## 04 第三遍读：读它的"输入点"

这是最关键的一遍。

因为**所有的漏洞，几乎都从一个"输入"开始。**

那"输入"在哪？

* **URL 里的参数**：`?id=1`、`?page=2`、`?url=...`
* **表单里的字段**：账号、密码、搜索词、留言内容
* **请求头**：`User-Agent`、`Referer`、`X-Forwarded-For`
* **Cookie**：你的身份凭证
* **上传的文件**：文件名、文件内容、文件类型

你要做的，是在脑子里给每一个输入点打个问号：

> "这里如果我填一个奇怪的值，它会怎么处理？"

**输入之处，就是信任可能被打破之处。**

---

## 05 第四遍读：读它的"边界"

最后一遍，读"谁能看到什么"。

一个网站，通常有好几种"身份"：

* **游客**：没登录，只能看公开内容；
* **普通用户**：能看自己的东西；
* **管理员**：能看所有人的东西。

**边界，就藏在这些身份之间。**

* 把 URL 里的 `id=1024` 改成 `1025`，我还能看到吗？（**水平越权**）
* 用普通用户的身份，能进管理员页面吗？（**垂直越权**）
* 不登录，直接访问某个接口，能拿到数据吗？（**未授权访问**）

**读懂了边界，你就读懂了"这个系统最怕什么"。**

---

## 06 读完之后：一张"攻击面地图"

四遍读下来，你脑子里应该浮出一张图：

```
资产（域名 / IP / 端口）
   ×
功能（登录 / 搜索 / 上传 / 支付 / API）
   ×
输入点（参数 / 表单 / Header / Cookie / 文件）
   ×
边界（游客 / 用户 / 管理员 / 内网）
```

这张图，就叫**攻击面**。

它不是"漏洞清单"，而是"**所有可能出问题的地方，被系统地列了出来**"。

有了它，你就不用再"瞎试"——

你能清楚地知道：**下一步，该读哪一页、试哪个点。**

---

## 07 但：读，也要有权限

照例，最后一句必须说的话。

"读"一个网站，听起来很温和。

但**未经授权地读**——扫描目录、探测接口、测试越权——**依然是入侵行为**。

所以，这四遍"读"，有一个不可绕过的前提：

> **你读的，必须是"你有权读"的网站。**

技术是本事，边界是底线。

---

## 结尾

你看的是页面，我读的是它的目录、功能和边界。

**会"读"网站的人，眼里没有秘密。**

**关注「从一串网址开始」这个系列**，下一篇我们来聊：

> 每一个参数，都是一扇没关严的窗。
