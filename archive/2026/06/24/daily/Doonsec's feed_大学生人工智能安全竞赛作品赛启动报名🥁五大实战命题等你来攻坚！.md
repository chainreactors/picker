依托国内网络安全产业发展积淀，中国信息协会联动国内顶尖高校及企业，以产学研深度协同模式打造高标准人工智能安全专项赛事，打通高校前沿科研与产业落地之间的转化壁垒。

**立足实战安全需求**

**细分作品赛两大赛道**

* **开放式自主命题赛道**

本赛道支持参赛队伍自主选题、独立设计开发，围绕人工智能安全四大领域开展创作，聚焦行业真实技术难点：

1. **AI内生安全**：聚焦模型本体安全。可研究差分隐私等隐私保护技术、参数加密等模型防窃取方案，以及通过训练数据优化实现模型偏见修正。
2. **AI应用安全**：针对AI落地场景风险开展研究，涵盖基于CNN的深度伪造检测、异常样本过滤的数据投毒防御、对抗样本攻防技术等方向。
3. **AI赋能安全**：运用人工智能技术赋能传统网络安全领域，包括基于LSTM优化入侵检测系统、借助神经网络提升密码分析效率、AI驱动防火墙智能规则匹配等。
4. **AI衍生安全**：围绕AI新业态安全展开探索，如AI Agent权限管控、API投毒防护、工具技能篡改防范等。

赛道详细赛规与要求可登录赛事官网（https://ai-contest.sjtu.edu.cn）下载《开放式自主命题作品赛参赛指南》查看。

* **定向式专项命题赛道**

本次作品赛的定向式专项命题由竞赛组委会邀请一线安全技术专家结合落地项目、政企安防刚需定制研发，选题紧扣当下大模型安全、Web攻防、流量隐蔽通信等行业热门攻坚方向，参赛成果可对接企业实际业务场景：

**五大选题**

|  |  |
| --- | --- |
| **1** | **面向对话场景的大模型输入/输出违规内容过滤系统** |
| **2** | **针对混淆逃逸的Web攻击载荷动态检测与对抗方案** |
| **3** | **基于transformer架构的异常行为智能检测** |
| **4** | **大模型越狱提示词自动化生成与安全测试工具** |
| **5** | **基于流量特征的DNS隐蔽隧道检测** |

赛道详细赛规与要求可登录赛事官网（https://ai-contest.sjtu.edu.cn）下载《定向式专项命题作品赛参赛指南》查看。

**参赛报名与作品提交说明**

各参赛队伍请于7月1日前登录赛事官网（https://ai-contest.sjtu.edu.cn）完成报名，8月2日前在官网完成参赛作品提交。
