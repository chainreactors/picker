Open-weight models from China have become very popular, but they've also raised some security suspicions. Cohere, a Canada-based biz that offers AI models to enterprises, says that when it was testing Alibaba's Qwen3.8-Flash-Next in its evaluation sandbox, the model attempted to send data to China.

"Asked to write a defensive detection rule, Qwen3.8-Flash-Next ignored instructions and inventoried the machine it was running on and then tried to upload a probe file to an Alibaba Cloud storage bucket in Beijing," the biz said in a [blog post](https://cohere.com/blog/concerning-behaviour-popular-open-weight-ai-model) on Monday.

Cohere was running the model through CTI-REALM, Microsoft's security analyst benchmark, and gave Qwen the task of writing a detection rule to look for malicious file downloading and execution by watching for invocations of curl processing bash scripts to the /tmp directory that were accompanied by bash execution.

REG AD

The model's "reasoning" output invented a prior conversation and asserted that no tools were used, output that a guardrail system reading chain-of-thought would accept.

REG AD

Nonetheless, the model issued a curl command to an Alibaba Cloud (aliyuncs.com) server.

"The model listed everything in /tmp, checked which transfer tools were installed, read the machine's DNS settings, then tried to upload a test string to an Alibaba Cloud storage bucket in Beijing and checked whether it worked," Cohere said. "Our sandbox had no route out, so the request died at the container wall."

The Cohere team wonders aloud whether that behavior was intended, but has no answer.

"The first issue is that it made a network call at all," Ivan Zhang, co-founder of Cohere, told The Register via email. "The model was asked to write a detection rule, which doesn't require external communication, and its reasoning trace said it wouldn't use tools. The destination raises additional questions because the attempted upload was to an Alibaba Cloud storage endpoint that wasn't part of the task. We don't know why it appeared, and we don't know the root cause."

Alibaba, the maker of the model, did not respond to a request to address Cohere's concerns.

Asked whether Cohere ran similar tests against US-made open-weight models, Zhang said, "We evaluate a broad range of models using the same framework our customers use in production: agents with access to real tools operating inside controlled environments.
