ANE Apple神经引擎

你知道你的 Mac 里藏着一块专门做 AI 运算的芯片吗？

苹果 M 系列内置 Apple Neural Engine，但从未对外开放。ANE 通过逆向工程破解了苹果内部接口，让你可以**直接用 Mac 神经引擎训练大模型**。

 **最强亮点：**功耗仅几瓦，能效碾压 RTX 3060。目前仅发挥峰值 2~3%，但思路超前，适合本地低功耗小模型训练。

Winhance Windows增强

Windows 用久了各种预装软件、遥测追踪、臃肿设置让人头大。Winhance 是一款 C# 开源优化工具，支持 Win10/11：

* 一键卸载系统内置应用（小组件、游戏栏、Cortana……）
* 隐私与遥测控制，关掉微软数据收集
* 任务栏 / 开始菜单深度定制
* 创建自定义安装镜像，多设备批量部署
* 配置导出/导入，换机一键还原

**装机必备**，效率党必收！

Win11 键盘连击修复 实用贴士

Windows 11 有个让人抓狂的 Bug：按一下键盘，系统识别成两次——俗称「**双击连击问题**」。换了键盘也没用，根源在系统设置。

️ **解决思路：**通过调整 Windows 11 的键盘筛选键设置或注册表参数，可以有效消除误判。具体步骤网上已有详细教程，搜索「Windows 11 键盘重复输入修复」即可找到。

如果你或者身边朋友有这个问题，转发给他们，能省不少麻烦

RSSBox AI日报生成

信息爆炸时代，如何筛出真正有价值的内容？RSSBox 已从纯翻译工具进化为完整的信息处理管道：

**RSS 订阅** → **AI 摘要处理** → **自动生成日报**

自托管部署，数据完全掌握在自己手里。再也不用每天刷几十个公众号了。

bobpony 镜像站 资源宝库

让我惊呼「这也有？！」的神奇网站，几乎涵盖所有系统镜像：

* Windows 全版本（XP 到 11）
* MS-DOS 2.11、Windows 1.04（你没看错）
* macOS 各版本 + 虚拟机镜像
* 驱动包、Flash Player 存档……

怀旧党、搭虚拟机、重装系统，一个网站全搞定。

screen-commentator 屏幕弹幕

这个项目有点离谱，但真的太好玩了

大模型**实时读取你的 Mac 屏幕内容**，自动生成弹幕在屏幕上滚动——就像在看直播，但主播是你自己。

支持本地/云端模型切换，赛博朋克感拉满，截个图发朋友圈绝对抢镜

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/BuYWgUUoia04cicTx9UajISdibxs1aS92DqBmF35ZxhOyXfco57zQ8ZhsyNkTjiasm02su15ADmD4NXKd7hL5CqkSPMgrWwWiapwZfu9I0icDMMJ4/640?wx_fmt=png&from=appmsg#imgIndex=3)

HiFier 发烧级播放器

安卓 / iOS 双端，面向发烧友的高品质播放器，核心亮点：

* 自研内核，支持 **Bit-Perfect 输出**
* 支持最高 **DSD128 via DoP**（iOS 天花板）
* 支持杜比视界视频格式
* 兼容几乎所有主流音频格式

**安卓版完全免费**，有台好 DAC 的必试！

OpenCut 开源剪辑

GitHub 上 **4 万+ ⭐ 的明星项目**，目标只有一个：

**替代 CapCut（剪映国际版）**让视频剪辑彻底免费、无水印、无订阅

目前已发布 0.2.0，功能还在快速完善中。不想被订阅费薅羊毛的，现在就加入 Watch 名单。
