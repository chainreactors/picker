VMware has discovered so many flaws in its products using AI that it felt the need to create a new product to help users manage them.

Prashanth Shenoy, vice president of product marketing in the VMware Cloud Foundation (VCF) division of Broadcom, told *The Register* that VMware recently moved to deliver monthly software updates, in part to address bugs found by AI.

He admitted, however, that users struggled to keep up with the pace of change before the move to monthly releases because it takes time to test the impact of patches – even though VCF allows non-disruptive live patching.

REG AD

Shenoy said customers therefore need "room to breathe." Enter a new tool called HyperArmor, which does three things.

REG AD

One is "virtual patching" – blocking attempts to exploit a vulnerability without changing the vulnerable software itself.

VMware already offers virtual patching in its vDefend network security product and [explains](https://blogs.vmware.com/security/2026/04/virtual-patch-guard-tsunami-ai.html) how it works by referring to CVE-2024-5806, the [bug in file transfer tool MOVEIt](https://www.theregister.com/security/2024/06/26/progress-tells-users-to-patch-new-moveit-auth-bypass-bugs/1224622) that made waves in 2024. VMware says vDefend can detect patterns associated with attempts to exploit the authentication bypass flaw and block the traffic.

HyperArmor will do similar things to block malicious traffic heading toward VCF implementations.

Another job HyperArmor takes on is rejecting any actions that alter known good states in VCF. If a human approves a change, the tool will update policies to allow the altered state.

The third job is multi-factor authentication (MFA). *The Register* put it to Shenoy that MFA is now table stakes for security. He agreed but explained that VMware designed HyperArmor to protect against attackers using stolen privileged credentials to access VMware's ESX hypervisor.

To (hopefully) stop attackers using those creds to take over a host, HyperArmor requires users to input SSH credentials and a secondary time-based one-time password sent to a user with a verified identity.

HyperArmor is a discrete product that VMware will sell as an add-on to VCF. That means VMware thinks its customers are going to be OK paying extra for MFA.

While VMware will sell HyperArmor, it didn't create the product. Broadcom's security businesses Symantec and Carbon Black cooked it up.
