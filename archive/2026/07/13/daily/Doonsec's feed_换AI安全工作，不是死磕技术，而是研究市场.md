这半年，很多人问我，怎么找到一份AI安全工作。其实这疑问，一时也不知道从哪里回答起。

周末看到一群友转发的资料，说如何AI去招聘网站找工作，加上前几天看到的邪修玩法。其实，只要能把招聘网站这个思路打通，这个问题根本不是个事。

# 1. 先别找工作，先去“逛”高薪岗位

打开招聘网站，先别搜“网络安全工程师”，也别搜“渗透测试”。

把薪资条件拉高，直接搜30K以上、50K以上，甚至80K以上，城市锁定北上深杭。然后，一口气看30个AI安全方向的高薪岗位。

比如：AI安全工程师、AI红队招聘、LLM 安全架构师、AI安全架构师、AI合规工程师……

这时候千万别急着投简历，你唯一的任务，就是看清楚企业到底愿意为什么样的能力付真金白银。

很多人花两年闷头学安全技术，最后发现企业根本不买单。你要记住了，工资就是市场最真实的投票。

# 2. 把 JD 一个一个扒下来，做一份记录表

建一个Excel表格，看一个岗位，就记录一次要求，连续统计30个。

不要偷懒，一定要一个一个字地整理。整理完你会发现，很多岗位虽然名字花里胡哨，但核心要求高度一致：

* 大模型红队与安全测评
* AI Agent / MCP 安全
* Prompt Injection 攻防
* AI技术与 AI 编程工具（Cursor/Claude Code等）
* 云原生与安全架构
* 英文技术文档阅读与代码审计

这些高频出现的词，就是未来几年AI安全需要提升的能力。 别听别人忽悠该学什么，看企业花钱买什么。

# 3. 专门盯着近两年冒出来的“新职业”

继续搜，专门找近两年才爆发的新岗位，比如：AI安全研究员、Agent安全工程师、大模型安全工程师。

先别看工资，研究他们的工作职责是怎么写的，每天到底在干些什么。

看完你会明白，绝大多数所谓的新职业，本质上都是“传统安全能力 + AI/大模型基础 + 合规治理”的重新组合。

看懂了这个组合逻辑，你就提前看透了行情的走向。

# 4. 贪多嚼不烂，死磕一个细分方向

AI安全现在的岗位细分也是挺多的，有人做模型红队，有人做Agent安全，有人做AI合规治理，有人做大模型架构安全。

不要想着什么都学，贪多嚼不烂。

挑一个你最想进、薪资高、未来空间最大的细分赛道。然后，连续研究30~50个同类岗位的招聘JD，反复拆解，看看到底要什么项目经验？一定要用什么工具？认不认哪几个证书？

要做到，闭着眼睛都能把这些要求背出来。

# 5. 倒序学习：市场要什么，你才学什么

大部分人的老路子是：学基础 ➔ 考证书 ➔ 做项目 ➔ 海投简历，最后学了一堆过时的东西，面试一问三不知。

真正高效的方法，是反过来。

如果岗位核心要求写的是：OWASP Top 10 for LLM、prompt、MCP、Agent攻防、大模型合规。那你就只学这几样！

岗位不需要的，先一概不管它。你投入学习的每一分钟，都必须精准对应企业真实的付费意愿和能力要求。

# 6. 看谁在疯狂招人

看岗位JD，更要看哪些企业在招人。

如果一家大厂同时在招20个AI安全工程师、15个Agent工程岗位，说明什么？说明它在这个方向上有巨大的业务增量和预算，正在重金押注。

把这些大厂、安全独角兽、AI大模型基础厂商全部列入关注清单。哪里招聘最疯狂，哪里就有最多的真金白银和业务机会。

# 7. 每星期看一眼薪资，当作行业晴雨表

每星期天抽10分钟，搜同一个岗位看薪资动态。

去年平均30K，今年涨到50K，说明人才供不应求，赛道在爆发；

去年平均50K，今年降回30K，说明要求拉高了，或者开始内卷了。

连续观察三个月，你的商业嗅觉会直线上升。因为企业的招聘预算，永远发生在新闻通稿和行业风向标之前。

# 8. 构建你的能力拼图

拿出一张白纸，写下你的目标：未来两年，成为AI安全专家。

然后在每周列出四五个问题：

* 这个赛道薪资最高的岗位是哪几个？
* 它们的核心能力是什么？
* 这些能力里，我已经具备了哪些？
* 最致命短板是哪一块？
* 未来6个月，我第一步先补什么？

......

不要盲目努力，只围绕市场需求走，一步一步补齐自己的能力拼图。

# 9. 谋定而后动，降维面试

完成至少30~50个岗位的拆解之后，你对市场的理解会发生质的改变。

这时候你再去改简历、投简历，你会清楚地知道哪句话能击中HR的软肋，哪个项目经验能让技术总监眼前一亮。

你带着对他们业务需求的深度理解去聊天的，成功率自然远远甩开那些靠运气的人。

最后，祝你好运，早日找到AI安全的新工作！
