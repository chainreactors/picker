## Take your YOLO and box it up

![](/design_picker/d2e337b97204af4aa34dda04c4e5d56d954b216f/graphics/icons/social_share_icon.svg)

exclusive NanoClaw, an open source agent platform, can now run inside Docker Sandboxes, furthering the project's commitment to security.

[NanoClaw](https://www.nanoclaw.dev/), as we [noted recently](https://www.theregister.com/2026/03/01/nanoclaw_container_openclaw/), followed from an effort to address the [security holes](https://www.theregister.com/2026/02/03/openclaw_security_problems/) opened by OpenClaw, which attracted widespread attention earlier this year as a way to empower AI models to roam about the web and operate applications on users’ behalf and without many constraints.

NanoClaw already runs inside of containers, which makes it safer than running agent software on a local machine. Through a partnership with Docker, users can now install NanoClaw into a [Docker Sandbox](https://www.docker.com/blog/docker-sandboxes-a-new-approach-for-coding-agent-safety/), a kind of micro VM that is more secure than a container because it's isolated from the host system. A container is an isolated process on a shared kernel; micro VMs have their own kernel.
