Chinese and North Korean state-sponsored hacking crews are among the growing number of groups known for using the ARTEX pentesting tool in attacks, Microsoft said this week.

ARTEX is an open source, AI-powered penetration testing framework that attackers have adopted to automate reconnaissance, credential attacks, and exploitation since its public release in July.

Campaigns that have been linked to ARTEX have targeted cloud environments, IT software like [ConnectWise](https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/), and financial institutions globally, sometimes reaching privileged access in under three hours.

Salt Typhoon is arguably the most recognizable name on the list of ARTEX beneficiaries – the group responsible for attacks on [telcos AT&T and Verizon](https://www.theregister.com/security/2025/01/17/fcc-says-us-telcos-by-law-must-secure-networks-from-spies/929923), [US government systems](https://www.theregister.com/security/2025/01/15/salt-typhoon-spies-spotted-on-us-govt-networks-before-telcos/428808), UK [prime minister's aides](https://www.theregister.com/security/2026/01/27/hackers-suspected-of-spying-on-uk-officials-calls-for-years/4139993), and more.

The lesser-known Crystal Typhoon – the group behind the [ArcaneDoor attacks](https://www.theregister.com/security/2025/09/26/critical-cisco-firewall-holes-under-active-attack/1023271) back when Microsoft called it Storm-1849 – was also named alongside it, as were North Korea's [Onyx Sleet](https://www.theregister.com/security/2024/05/29/new-north-korean-group-tied-to-ransomware-gaming-campaigns/670496) and Pearl Sleet.

Microsoft also named China-state-aligned Storm-0940, linked to the [ConnectWise](https://www.theregister.com/security/2026/10/22/microsoft-says-connectwise-breach-let-chinese-spies-loose-on-2250-cloud-tenants/5304687) compromise, and financially motivated, Cambodia-based Storm-3358. It had previously reported both groups' use of ARTEX.

Chinese cybersecurity company ThreatBook claimed ownership of ARTEX in November. GitHub user "Autumn-27" originally published its source code with a Chinese-language interface in July.

Various forks of the repo, which was taken down in October, have meant that the same framework is available in multiple languages.

According to [Infrawatch](https://infrawatch.com/blog/the-autonomy-of-the-autonomous-intrusions), there are more than 130 variants of ARTEX in circulation, and it is the most widely used agentic offensive framework (AOF) at present.
