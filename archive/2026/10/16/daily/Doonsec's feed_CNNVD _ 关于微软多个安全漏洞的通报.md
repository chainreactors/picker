**漏洞情况**

近日，微软官方发布了多个安全漏洞的公告，全部为影响微软产品本身的漏洞，共1423个。微软Microsoft Windows、Microsoft Windows Credential Manager、Microsoft Windows SMB Server、Microsoft Windows Performance Monitor等多个产品和系统受漏洞影响。目前，微软官方已经发布了漏洞修复补丁，建议用户及时确认是否受到漏洞影响，尽快采取修补措施。

## 一 **漏洞介绍**

2026年10月13日，微软发布了2026年10月份安全更新，共1423个漏洞的补丁程序，CNNVD对这些漏洞进行了收录。本次更新主要涵盖了Microsoft Windows、Microsoft Windows Credential Manager、Microsoft Windows SMB Server、Microsoft Windows Performance Monitor、Microsoft Windows Internet Connection Sharing、Microsoft Defender for Endpoint等。CNNVD对其危害等级进行了评价，其中超危漏洞61个，高危漏洞1001个，中危漏洞361个。微软多个产品和系统版本受漏洞影响，具体影响范围可访问微软官方网站查询：

https://portal.msrc.microsoft.com/zh-cn/security-guidance

## 二 **漏洞详情**

此次更新共1423个漏洞的补丁程序，包括1405个新增漏洞的补丁程序和18个更新漏洞的补丁程序。

此次更新共包括1405个新增漏洞的补丁程序，其中超危漏洞61个，高危漏洞986个，中危漏洞358个。

## 三 **修复建议**

目前，微软官方已经发布补丁修复了上述漏洞，建议用户及时确认漏洞影响，尽快采取修补措施。微软官方补丁下载地址：

<https://msrc.microsoft.com/update-guide/en-us>

CNNVD将继续跟踪上述漏洞的相关情况，及时发布相关信息。如有需要，可与CNNVD联系。联系方式: cnnvd@itsec.gov.cn
