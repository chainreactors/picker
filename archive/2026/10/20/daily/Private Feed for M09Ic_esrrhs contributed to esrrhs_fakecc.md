A CI run on master (`194a4084`, run 39143711720) took **135.7 min of wall clock**, and every bit of it was gated by one job: `macos-latest · clang ASan` at **118.7 min**. macOS minutes also bill at 10x, so one run spends ~3270 billed minutes.

## Where the time actually goes

Build is **0.1 min** of that 118.7 min leg — none of the wall clock is the compiler being built. Measured per e2e case on arm64:

| action | cost |
| --- | --- |
| fakecc compiles one case | 89 ms |
| gcc compiles one case | 33 ms |
| `python3` start-up (difftest runs two per case) | 165 ms |
| `compat.sh` timeout fallback (0.1 s polling) | 115 ms |

So a difftest case pays ~600 ms of fixed overhead against ~120 ms of real compiling, and JOBS only divides it by 3 on a 3-vCPU runner. That is also why a macOS leg ran about 3x its Linux twin: Linux has a real `timeout`, macOS polls.

Inside the ASan leg: difftest ×2 = 48%, e2e ×2 = 38%, compile ×4 = 8%.

* **`test/compat.sh`** — reach GNU `timeout`/`nproc` through their `g`-prefixed names (Homebrew puts those in `/opt/homebrew/bin`; the unprefixed ones live in `libexec/gnubin`, which stays off PATH so it cannot shadow BSD sed/date/stat). 115 ms → ~5 ms per call.
