# 通道规则二：Linux

Obsidian（笔记）+Github（云盘/私盘）+Obsidian插件+VIM+Discord 目前我们暂时不考虑太过于深入的。

  需要构建和本地强化的技能有：[Git/Github基础设施知识学习 ] [ Markdown ] [ Vim ] ,我们无法完全覆盖在内,但我们社区和群组长期支持大家相互探讨和分享自己喜欢的插件。

# 认证标准三：执行

  从零开始注册Github然后去构建自己的私有仓库,通过下载Github客户端本地安装并关联到自己的Obsidian独有仓库！建立静态博客的问题只要你掌握了独有仓库的安装/更新就可以自然的掌握！不过我们目前不推荐浪费时间去构建静态博客。因为龙虾可以直接一键部署。所以我们没必要把时间浪费在这里。

  我们的文本讨论百分之80都是在Obsidian程序中构建的笔记,因为你可以在多个编辑器中直接使用独立项目,并且进行代码的实践。
