## Now if only device makers would deliver higher quality components

![icon](/design_picker/d518b499f8a6e2c65d4d8c49aca8299d54b03012/graphics/icon/vulture_red.svg)
[Thomas Claburn](/Author/Thomas-Claburn "Read more by this author")

Fri 6 Mar 2026  //
20:41 UTC

![](/design_picker/d2e337b97204af4aa34dda04c4e5d56d954b216f/graphics/icons/social_share_icon.svg)

Thanks to Anthropic's AI and its bug-detecting abilities, Firefox users can now enjoy stronger security. Unfortunately, if browser crashes rather than security flaws are the problem, Claude probably can't help.

Mozilla engineer Gabriele Svelto said in a recent Mastodon [post](https://mas.to/%40gabrielesvelto/116171750653898304) that he believes that about 10 percent of Firefox browser crashes can be attributed to bit flips – unintentional changes in memory – rather than software errors.

Bit flips can be caused by [a variety of things](https://blog.robertelder.org/causes-of-bit-flips-in-computer-memory/), such as cosmic rays and Rowhammer attacks. But often the explanation is more mundane – flawed electronic components.

[![](https://pubads.g.doubleclick.net/gampad/ad?co=1&iu=/6978/reg_software/aiml&sz=300x50%7C300x100%7C300x250%7C300x251%7C300x252%7C300x600%7C300x601&tile=2&c=2aauiDsyT99fPqZfpqz2BpAAAAFE&t=ct%3Dns%26unitnum%3D2%26raptor%3Dcondor%26pos%3Dtop%26test%3D0)](https://pubads.g.doubleclick.net/gampad/jump?co=1&iu=/6978/reg_software/aiml&sz=300x50%7C300x100%7C300x250%7C300x251%7C300x252%7C300x600%7C300x601&tile=2&c=2aauiDsyT99fPqZfpqz2BpAAAAFE&t=ct%3Dns%26unitnum%3D2%26raptor%3Dcondor%26pos%3Dtop%26test%3D0)

"Today I was looking at the data that comes out of these tests and now I'm 100 percent positive that … a lot of the crashes we see are from users with bad memory or similarly flaky hardware," he said.
