# 一款新插件使AI写作看起来更像真人写的

发布时间:
2026-01-24 New Article

分类:
[新闻简报/News](https://blog.upx8.com/news)

热度:
810

据报道，一款新工具旨在借助维基百科的人工智能检测指南，帮助人工智能聊天机器人生成看起来更像真人写的文本。开发者 Siqi Chen表示，他通过将维基百科志愿者编辑们为打击 “粗制滥造的AI生成内容” 而整理出的特征清单输入给Anthropic的Claude，创建了这款名为Humanizer的工具。根据其GitHub页面介绍，Humanizer是 Claude Code 的一项自定义技能，旨在通过移除这些AI生成文本的特征，使文本看起来更自然、更像真人写的，从而帮助AI助手避免被检测到。开发者表示，当维基百科的人工智能检测指南更新时，该工具将“自动推送更新”。
