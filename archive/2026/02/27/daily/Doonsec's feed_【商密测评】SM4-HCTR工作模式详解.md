# SM4-HCTR工作模式详解

![](https://mmbiz.qpic.cn/mmbiz_png/ZaibroIiatwe3Brnt5YLHeo9JeiaUpdCcHpPBlkgvtgulqRd1JfUicAYR7Mz4wjBic7MiaZe4b0h4EfGibUfV86dHEuOLic89icX62tJpC7bER8fnYJg/640?wx_fmt=png&from=appmsg)

## 一、概述

SM4-HCTR是将国密SM4分组密码算法应用于HCTR工作模式的一种加密方案。HCTR（带泛杂凑函数的计数器工作模式）是计数器模式（CTR）的重要变体，它使用一个泛杂凑函数生成一个秘密掩码，作为计数器模式的初始向量，从而实现更安全、更灵活的数据加密方案。

SM4-HCTR模式丰富了国密对称加密算法的应用形态，能够满足数据加密、身份鉴别、消息认证等多场景的安全需求，为我国信息安全领域提供了重要的技术支撑。

## 二、HCTR工作模式的基本概念

### 2.1 定义

HCTR（universal Hash function based CTR）即"带泛杂凑函数的计数器工作模式"，是分组密码算法的一种工作模式。HCTR是计数器模式的变体，其核心特征是使用一个泛杂凑函数生成一个秘密掩码，作为计数器模式的初始向量。

### 2.2 与传统CTR模式的区别

传统CTR模式直接使用计数器值作为分组密码的输入，而HCTR模式则通过泛杂凑函数对明文数据和调柄进行处理，生成一个秘密掩码，再与计数器结合使用。这种设计带来了以下优势：

* • **可调性**：通过调柄（Tweak）参数，同一密钥可以对不同数据产生不同的加密结果
* • **完整性关联**：加密过程中明文的任何变化都会影响整个密文输出
* • **长度保持**：明文和密文长度相同，适合磁盘加密等对数据长度敏感的应用

### 2.3 关键技术特点

HCTR工作模式具有以下关键技术特点：

1. 1. **双密钥机制**：使用两个密钥K₁和K₂，其中K₁用于分组密码加密，K₂用于泛杂凑函数
2. 2. **调柄参数**：引入调柄TW，增加加密过程的变化量，实现可调加密
3. 3. **泛杂凑函数**：使用基于有限域GF(2¹²⁸)乘法运算的泛杂凑函数，提供高效的压缩能力

## 三、SM4-HCTR的工作性质

### 3.1 应用场景

HCTR模式特别适用于以下场景：

1. 1. **磁盘扇区加密**：调柄值用于表示扇区地址，实现磁盘数据的透明加密
2. 2. **一般数据加密**：可用于各种需要可调加密的应用场景
3. 3. **身份鉴别**：通过调柄参数实现不同身份的区分
4. 4. **消息认证**：利用其完整性关联特性进行消息验证

**重要说明**：该工作模式不适用于明文长度小于分组密码分组长度的情形。

### 3.2 核心性质

#### （1）并行处理能力

除去第一个分组，HCTR支持并行加密和解密，这大大提高了处理效率，适合高性能应用场景。

#### （2）可调置换特性

HCTR模式对于不同的调柄值，得到在密钥控制下的不同置换。这意味着即使使用相同的密钥加密相同的明文，只要调柄不同，就会产生完全不同的密文。

#### （3）长度保持与扩散特性

HCTR模式明文和密文长度相同，无论是加密还是解密，任意输入数据的变化都会带来所有输出比特的变化。这种特性使其非常适合磁盘加密等对数据长度敏感的应用。

#### （4）可证明安全

HCTR模式具备可证明安全的理论保障。在底层分组密码算法（如SM4）具备超伪随机性质的情况下，HCTR模式被证明是超伪随机的，安全界是生日界。

### 3.3 填充要求

* • 明文长度应不少于一个分组
* • 数据经过泛杂凑函数处理时，需要填充

### 3.4 差错扩散特性

密文的任意比特的错误会导致明文每一个比特以50%概率出现错误。这种强扩散特性使得任何对密文的篡改都难以预测解密结果，从而增强了数据的安全性。

### 3.5 同步特性

HCTR模式不是自动同步的。无论是进行加密还是解密，都是在输入完所有数据后，才能计算出输出结果。这意味着：

* • 加密和解密操作需要保持严格的同步
* • 如果同步丢失，系统需要重新初始化
* • 每次重新初始化应使用新的调柄值

### 3.6 确定性特征

只要使用同样的密钥和调柄对相同的明文进行加密，HCTR模式将产生相同的密文。介意这种性质的用户需要采用某种方法来改变调柄值。

## 四、SM4-HCTR的安全意义

### 4.1 丰富国密应用形态

SM4-HCTR模式的引入，丰富了国密对称加密算法的应用形态，为以下领域提供了标准化的解决方案：

* • **数据存储加密**：磁盘加密、数据库加密
* • **通信安全**：VPN、安全传输协议
* • **身份认证**：基于调柄的身份标识
* • **消息认证**：完整性验证

### 4.2 满足多场景安全需求

SM4-HCTR模式能够满足多种安全需求：

| 安全需求 | SM4-HCTR的支持方式 |
| --- | --- |
| 数据加密 | 提供强安全的对称加密能力 |
| 身份鉴别 | 通过调柄参数区分不同身份 |
| 消息认证 | 完整性关联特性支持消息验证 |
| 随机性保证 | 可证明安全的理论基础 |

SM4-HCTR工作模式是GB/T 17964-2021国家标准中引入的重要工作模式之一，它将SM4分组密码算法与HCTR模式相结合，实现了以下目标：

1. 1. **安全性增强**：通过泛杂凑函数和调柄机制，提供比传统CTR模式更强的安全保障
2. 2. **灵活性提升**：支持可调加密，适应多种应用场景
3. 3. **性能优化**：支持并行处理（除第一个分组外），满足高性能需求
4. 4. **标准化推进**：丰富国密算法应用形态，推动国产密码技术发展

SM4-HCTR模式的推广应用，将为我国信息安全领域的数据加密、身份鉴别、消息认证等场景提供更加安全、高效、标准化的解决方案，有力支撑国家网络安全建设。
