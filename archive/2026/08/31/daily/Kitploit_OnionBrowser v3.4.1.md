# Onion Browser

[Official Site](https://onionbrowser.com/) | [Support](https://github.com/OnionBrowser/OnionBrowser/wiki/Help) | [Release History](https://github.com/OnionBrowser/OnionBrowser/releases) | [Donate](https://onionbrowser.com/donate)
© 2012-2024, Tigas Ventures, LLC ([Mike Tigas](https://mike.tig.as/))

*This is the Onion Browser **3.X branch**. The older versions of Onion Browser can be found [here](https://github.com/OnionBrowser/OnionBrowser/tree/2.X) and [here](https://github.com/OnionBrowser/OnionBrowser/tree/1.X).*

**Onion Browser** is a free web browser for iPhone and iPad that encrypts and tunnels web traffic through the [Tor network](https://www.torproject.org/) with the help of [Orbot iOS](https://orbot.app/). See the [official site](https://onionbrowser.com/) for more details and App Store links.

Please see the [LICENSE](https://raw.githubusercontent.com/OnionBrowser/OnionBrowser/3.X/LICENSE) file for usage and redistribution terms.

---

* **Onion Browser**: 3.4.1 - See [official release history](https://github.com/OnionBrowser/OnionBrowser/releases) and [changelog](https://raw.githubusercontent.com/OnionBrowser/OnionBrowser/3.X/CHANGELOG.md).

## Notable 3.X Features

The following features are new to Onion Browser, mostly by leveraging [Orbot iOS](https://orbot.app/):

* Use of newer, more secure, faster rendering engine `WKWebView`.
* Finally all traffic, including audio/video streams tunneled through Tor.
* Everything downloadable now, including web pages.
* Search in page from iOS 16 and up.
* Multiple windows support on iPad.
