## Mozilla 建议 Windows 7/8/8.1 用户切换到 Linux

[![Linux](https://icon.solidot.org/images/topics/topiclinux.png?123)](/search?tid=7 "Linux")
[![Firefox](https://icon.solidot.org/images/topics/topicfirefox.png?123)](/search?tid=39 "Firefox")

[Edwards](/~Edwards) (42866)发表于 2026年02月20日 18时37分 星期五 [新浪微博分享](//service.weibo.com/share/share.php?url=//www.solidot.org/story?sid=83583&appkey=1370085986&title=Mozilla%20%E5%BB%BA%E8%AE%AE%20Windows%207%2F8%2F8.1%20%E7%94%A8%E6%88%B7%E5%88%87%E6%8D%A2%E5%88%B0%20Linux "新浪微博分享")
![](https://icon.solidot.org/images/a7c7.png)

**来自苹果树下的宇宙飞船**

Mozilla 称，2023 年 7 月释出的 Firefox 115 ESR 是 Firefox 支持 Windows 7/8/8.1 的最后一个版本，它将在 2026 年 2 月底为 Firefox 115 ESR 释出最后一个安全更新，之后将停止对它的支持。它建议 Windows 7/8/8.1 用户升级到 Windows 10 或更新版本，如果他们的 PC 由于微软设定的限制无法升级到 Windows 10 或 11，Mozilla 建议用户切换到 Linux 发行版。
https://support.mozilla.org/en-US/kb/firefox-users-windows-7-8-and-81-moving-extended-support
